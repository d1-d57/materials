Сюда — карточки-темы по стандарту (`../../_studio/docs/kak-delat/PROGRAMMA-KURSA.md`, секция «Стандарт лекции»): **бриллиант + листок ~10 задач + «руками» + микросюжеты + мост + гейт доступности (после 6 кл.) + источники**. Позже — `00-KARTA-kursa.html` (обзор тем и мостов, нить = один объект на трёх языках).

**Карточек-тем пока нет — и это правильно.** По решению владельца сначала Ф1: разбор темы для него самого (он тему знает плохо), потом потолок и раскладка на 4 занятия, и только потом карточки. Пустая картотека = стадия не дошла, а не забыли. Листки при этом уже собираются и живут здесь.

## Листки: что источник, а что порождается

⚠ **В git только источники. Печатное и картинки собираются командой и в git их нет** (`.gitignore` в корне, там же почему). После свежего клона `L1-print.pdf`, `L2-print.html`, `L2-print.pdf` и все `*-fig*.svg` **вы не найдёте — их надо собрать.** Проверено: из содержимого git всё восстанавливается побайтово.

| Занятие | Источник (в git) | Собирается командой |
|---|---|---|
| Л1 | `L1-print.html` — **сам источник**, SVG вклеен руками; состав и ответы — `L1-listok-poloska.md`; фигура — `gen_l1_figs.py` | `L1-fig2.svg`, `L1-print.pdf` |
| Л2 (мини-листок, задачи 13–16) | `L2-print-tmpl.html` — **шаблон**; состав и ответы — `L2-mini-listok.md`; фигуры — `gen_l2_figs.py`; сшивка — `build_L2_print.py` | `L2-fig-*.svg`, `L2-print.html`, `L2-print.pdf` |
| Л3 (мини-листок «Слово», задачи 17–22) | `L3-print.html` — **сам источник**: картинок в листке нет, поэтому шаблон и сборка не нужны; состав и ответы — `L3-mini-listok.md`; разбор для владельца — вкладка «Слово — преподавателю» (`../razbor/tekst/5-slovo-prepodavatelyu.md`) | `L3-print.pdf` |

```bash
python3 gen_l1_figs.py                                  # Л1: фигура (вклеить в L1-print.html руками)
python3 gen_l2_figs.py && python3 build_L2_print.py     # Л2: фигуры + сшивка шаблона
python3 -m weasyprint L1-print.html L1-print.pdf        # печать Л1
python3 -m weasyprint L2-print.html L2-print.pdf        # печать Л2
python3 -m weasyprint L3-print.html L3-print.pdf        # печать Л3 (сборки нет, правится сам HTML)
pdftoppm -png -r 110 L3-print.pdf preview               # гейт: посмотреть глазами
```

⚠ **У Л3 `L3-print.html` — источник, и это НЕ та асимметрия, что у Л1.** У Л1 риск в том, что SVG вклеен руками и правка генератора в листок не доедет. В листке Л3 картинки нет вообще (убрана решением владельца 19.07), поэтому расходиться нечему — шаблон тут был бы пустой обёрткой. Генератор `gen_l3_figs.py` («слово на полоске») оставлен на случай, если картинка вернётся, но **сейчас не используется и ни во что не вклеивается**.

⚠ **Асимметрия Л1/Л2 намеренная.** У Л1 шаблона нет: SVG вклеен в `L1-print.html` руками, поэтому правка `gen_l1_figs.py` сама в листок **не доедет**. У Л2 эта дыра закрыта шаблоном. Свести Л1 к схеме Л2 — открытая задача; чинить асимметрию вслепую (например, положив `L2-print.html` в git «для симметрии») **не надо**: тогда шаблон и сборка разъедутся.
