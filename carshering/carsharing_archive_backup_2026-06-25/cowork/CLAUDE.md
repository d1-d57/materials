## Что это

Кейс по ценообразованию каршеринга (Москва). Параметрическая модель в `model/build_model.py` генерирует `model/carsharing_pricing.xlsx`. Цель — честная заземлённая модель (H1), затем один самодостаточный HTML-инструмент (H2). Стратегия и доки — у Cowork; ты исполняешь точный заход.

## 0. Перед работой

- **Сохранить точку отката** до правок (если проект под git — коммит/стэш; иначе копия `model/` в сторону). Холодный агент это проскакивает — поэтому отдельным первым шагом.
- **Вход соразмерен заходу.** Точный заход (Cowork назвал ЧТО менять) → прочитай только названные секции + **пол**: числа `../data_sources.md`, состояние из заголовка заходa. Триггер-аварийка (задача трогает структуру издержек / скоуп / противоречит данным) → полный Правило №0 (`../README.md`).
- **Числа — всегда из `../data_sources.md`**, не из памяти и не из прозы.

## Дисциплина прохода

- **Минимальные изменения + верификация.** Якорные строковые замены (abort, если совпадений ≠ 1). Контент-правка → функциональная эквивалентность.
- **Оракул вместо «выглядит правильно».** openpyxl формулы не считает → `build_model.py` рядом с записью формулы печатает ту же величину питоном; докладываешь конкретные «было → стало», а не «корректно».
- **Связка фазы нерушима:** правишь число → в `../data_sources.md` (источник) → пересборка xlsx → затронутые доки → запись в `../provenance/journal.md`.
- **Артефакт руками не правят:** `carsharing_pricing.xlsx` — только пересборкой из `build_model.py`.
