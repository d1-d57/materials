# reports/ — отчёты Cladkod

> **КОГДА читать:** когда принимаешь работу Cladkod. · **ЧТО сюда класть:** отчёт на каждый исполненный заход,
> файлом `<дата>_<имя>.md` (напр. `2026-06-25_migrate_structure.md`). · **КУДА дальше:** приёмка по гейтам — `../GUIDE.md §2`.

Сюда Cladkod кладёт отчёт по каждому заходу из `../briefs/`. Cowork читает их отсюда (вручную переносить не нужно) и принимает по гейтам.

Формат отчёта: что увидел · что сделал + зачем + как проверил · решения + почему · вынесено владельцу · контроль (числа сходятся с `../../data_sources.md`, пересборка/оракул, `check_docs` зелёный). Один заход — один отчёт. Имя отчёта отвечает имени захода.
