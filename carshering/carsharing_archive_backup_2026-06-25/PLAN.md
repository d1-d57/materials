## Приложение А. Полный список замечаний аудита и их статус

**Где глубина настоящая (зафиксировать, не трогать):** RM-классификация по Каймсу — верна по пунктам. FDC-таргет vs предельный пол (R5) — корректно и важно. Единая теневая цена ёмкости (статически peak-load / по длительности коммита опционная издержка / динамически Беллман) — настоящая, верная, элегантная мысль. Эконометрика (R3/R8) — человек трогал BLP руками: эндогенность через surge с верным знаком (cov(p,ξ)>0 → занижение чувствительности), инструменты Хаусмана с оговоркой, эндогенная сегментация как селекция Хекмана, carryover в switchback по Боджинову.

**Замечания (дыры):**
1. **Аппарат ≫ применение.** Ядро xlsx — cost-plus: издержки ÷ время-под-заказом ÷ (1−маржа). R6/R7/R8 вырезаются целиком — ни одно число не дрогнет. → чинится сквозной разметкой ⚙️/📄 (верхняя задача) + фазами 2–4, где аппарат реально включается.
2. **Модель не реализовывала своих поправок.** Проза «✅ исправлено», xlsx считал доисправленные 180 км / 2700 / 15.54 / лестницу 3.2× / util 0.30 / чек 671. → фаза 1 закрыла минутную базу; лестница 3.2× и чек — **ещё открыты** (фазы 2–3).
3. **Баг скорости.** `B8=25` использовался в двух несовместимых смыслах. → **разрешён данными:** 25 это эффективная (со стоянками) скорость ≈24; пробег чинится утилизацией, пол = 6.0 без ходовой доли. (Закрыто.)
4. **Предельный пол недосчитан и спорит с Q3.** В пол положено только топливо-в-движении; пер-трип косты (десятки ₽) — часть пола поездки, выкинуты. → **фаза 2** (пер-трип корзина + тест перелома по длине).
5. **Peak-load перехвалён.** Загадку «2× рынка» растворяет не Стайнер, а азбука «FDC+маржа ≠ пол» (Тироль, невозвратные vs избегаемые); в модели peak-load обнулён (B12=0). → разметка (📄/⚙️) + **фаза 4** (оживить B12).
6. **Натяжка «blended 30%» vs эндогенность.** Дифференциация марж меняет цены→количества→веса микса; держать 70/10/20 фиксированным и переоптимизировать нельзя. → **фаза 3** (blended как выход на миксе, оба режима).
7. **[1.2] и [1.3] не сверены** (формула пробега брала 7.2ч из 30% по парку, доказывая 15–25% для минутной подгруппы). → **закрыто фазой 1** (единый util 18%).
8. **Нет настоящей RM-оптимизации; 150 моделей схлопнуты; конкуренция не смоделирована.** → большие открытые вопросы (решить трактовку).
