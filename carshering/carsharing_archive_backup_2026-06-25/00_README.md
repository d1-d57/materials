# 00. README — индекс архива

Консолидированный архив исследования по кейсу **ценообразования каршеринга** (три вопроса: базовые цены, тестирование тарифов, сервисный сбор). Точка входа. Дальше архив дорабатывается в новом чате — этот набор и есть стартовая точка.

## Итог в одном абзаце

Задача — частный случай **управления доходностью** (revenue management). Базовый подход «издержечная база + дискриминация второй степени» правильный и совпадает с теорией и рыночной практикой. Конкретные числа теперь **заземлены на открытые данные по каршерингу Москвы** (реестр `carsharing_data_sources.md`) — приватных данных оператора нет и не будет. Это уже сдвинуло выводы (фаза 1): средний таргет ~**19.6 ₽/мин** (не 13–14), предельный пол ~**6** (без двойного учёта), рынок ~**8.5** — **рынок впритык над полом, более чем вдвое под таргетом (~2.3×)**, и загадка «рынок дешевле таргета» не растворилась, а выросла. Содержательные выводы держатся: издержки дают средний таргет, предельный пол ниже и спросозависим (peak-load, R5); плоская маржа 30% должна стать дифференцированной по эластичности сегментов; рынок ценит в четыре слоя, модель — в один. Честный финал — не «сходящийся к 10/10 с их данными», а **числа на открытых данных + анализ чувствительности**.

## Карта документов

Архив — **четыре слоя**, не плоская куча: (1) **спайн** `00`–`05` — то, что читают, в порядке; (2) **исследовательские приложения** R1–R8 — по одному источниковому модулю на каждый закрытый пробел, спайн ссылается на них по номеру; (3) **провенанс** — первичный разбор (`analysis`) и аудит (`audit`), длинные версии, которые спайн дистиллировал; (4) **модель** (`xlsx`/`py`) и **журнал** (`build_log`). Файлов много, потому что каждый закрывает свою вещь и отдельно цитируется — это структура, а не разрастание.

**Консолидированный финал (читать в этом порядке):**
- `00_problem_statement.md` — **постановка задачи** (исходный кейс: условия, три вопроса, параметры).
- `00_README.md` — этот индекс.
- `01_answer.md` — **ответ на кейс** по трём вопросам, с исправленными числами и сквозными выводами. Главный документ.
- `02_problem_and_math.md` — класс задачи (revenue management), почему подход верен, карта прикладной математики.
- `03_model_anatomy.md` — вскрытие модели: каждое число с разметкой статуса, две исправленные ошибки, пересчёт «было → стало».
- `04_demand_testing_ops.md` — спрос и эластичность, оценка из логов, методология тестов, операционная связка, петля Q1↔Q2.
- `05_open_questions.md` — что осталось: список данных к запросу, гетерогенность 150 моделей, критерий «10/10».

**Исходные артефакты (рабочий record, для глубины):**
- `carsharing_pricing.xlsx` — живая параметрическая модель (4 листа). Меняешь входы — пересчитывается сетка.
- `carsharing_pricing_analysis.md` — первичный теоретический разбор (5 актов).
- `carsharing_audit.md` — эпистемический аудит первого ответа.
- `carsharing_build_log.md` — журнал кампании: обе волны (R1–R8), методология и гейт (заменяет прежние два трекера).
- `carsharing_R1_benchmark.md` — конкурентный бенчмарк рынка.
- `carsharing_R2_elasticity.md` — эмпирика эластичности и сегментов.
- `carsharing_R3_demand_estimation.md` — как оценить эластичность из логов.
- `carsharing_R4_utilization.md` — декомпозиция понятия «утилизация».

**Вторая волна уточнений (теория, углубление каркаса):**
- `carsharing_R5_marginal_peakload.md` — предельные vs средние издержки и peak-load pricing (пол как средний таргет; настоящий предельный пол; теневая цена ёмкости).
- `carsharing_R7_option_value.md` — опционная издержка закоммиченной ёмкости и сетевое RM (длинный пакет дороже амортизации накладных).
- `carsharing_R6_screening_markup.md` — строгая наценка: информационная рента (Mussa–Rosen), условие Шмалензее для двухставочного, многомерный скрининг (уровни наценок — не Лернер-по-сегменту).
- `carsharing_R8_econometric_precision.md` — эконометрическая точность: инструменты Хаусмана с оговоркой об общем шоке, знак смещения привязан к surge, эндогенная сегментация, carryover/спилловер в дизайне тестов, сопоставимость время/деньги.

## Конвенция статусов (по всему архиву) — три оси

**Эпистемика:** 🟩 вычисление · 🟦 теория · 🟨 выбор · 🟥 допущение.
**Провенанс входа:** 📋 дано задачей · 📊 открытые данные (со ссылкой) · 🟥 допущение (данными не снимается).
**Внедрение:** ⚙️ посчитано в модели · 📄 только в тексте (карта, не машинерия).

Числовые входы и источники — канонически в `carsharing_data_sources.md`; он добавлен как точка правды, чтобы модель и проза не разъезжались.

## Как пользоваться в новом чате

1. Прочитать `01` (ответ) и `03` (анатомия) — это ядро.
2. Взять `05` как to-do: получить их данные (уровень A), задать вопрос про маржу (C7), спроектировать эксперимент (B6).
3. Подставить полученные числа в `carsharing_pricing.xlsx`, пересчитать.
4. Итерировать консолидацию с полным архивом.

Каркас прочен, две ошибки исправлены, тон честный — везде видно, где вычисление, где выбор, где гипотеза. Архив готов к доработке.
