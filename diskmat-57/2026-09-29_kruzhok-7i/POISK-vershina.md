# Поиск вершины для листка «Конструктивы» (7И, 29.09)

Задача: подобрать замену задаче 10⋆⋆ (число из цифр 1 и 2, делящееся на 2ⁿ) или подтвердить её. Нужна вершина уровня кружков ЦПМ или Сириуса для 8–9 класса: конструктив без специальных знаний, который разбивается на 3–4 пункта и вытекает из линий листка. Линии такие: (1) пример + запрет одной величиной; (2) «при каких n»; (3) «найдите все»; (4) пошаговое построение n → n+k.

Пометки. **[источник]** — условие или решение взято из источника, ссылка дана. **[своё]** — рассуждение моё. **[проверено]** — прогнано на компьютере, скрипты лежат в `verif10/`.

Где искал: problems.ru, листки ЦПМ (math.mosolymp.ru, Хамовники 8 кл. 2023–25, школа 444), архив Регаты, «Турнир городов», ВсОШ, а также Квант и зарубежные источники по классическим сюжетам. Сириус: на sochisirius.ru лежат только описания смен, материалов занятий в открытом доступе не нашлось. Прямой доступ к сайтам из песочницы закрыт прокси, поэтому всё читал через WebFetch.

## 0. Что сейчас: задача 10 (1 и 2, делится на 2ⁿ)

- **Источник:** Квант, 1971, №11, задача М113. На problems.ru это [№73648](https://www.problems.ru/view_problem_details_new.php?id=73648): классы 8–10, сложность 4−. Родственник — USAMO 2003/1 (цифры 1–5, делимость на 5ⁿ).
- **Сильные стороны.** Чистый алгоритм «приписывай цифру слева». Пункт (б) сам подводит к шагу, есть единственность. Порог входа пологий.
- **Слабые стороны именно как вершины этого листка.**
  - Нет «нельзя», хотя листок держится на паре «пример + запрет одной величиной». Единственность (г) — это не запрет, а та же индукция.

  - Это теория чисел (делимость на 2ⁿ, 10ⁿ = 2ⁿ·5ⁿ), а больше на листке теории чисел нет. Задача стоит особняком.
  - Задача очень известная. Школьник, прошедший «ТЧ-конструктивы» хоть в одном кружке, мог её видеть.
- **Связь с листком:** только линия (4).

## Кандидат A. Города по три дороги, из любого в любой — не больше одной пересадки (граф Петерсена)

**Источник** [источник]: Московская математическая регата 2011/12, 11 класс, 4 тур, задача 3 (11.4.3), [problems.ru №116441](https://www.problems.ru/view_problem_details_new.php?id=116441). Там спрашивается «каждый город соединён *не более чем* с тремя; наибольшее число городов». Ответ 10. Тот же сюжет («Зурбаган») есть в подборке по графам [zaba.ru, sms700.graphy3p, №16](http://www.zaba.ru/cgi-bin/tasks.cgi?tour=books.sms700.graphy3p).

**Предлагаемое условие для листка** (переформулировка под «при каких n»; ответ меняется, см. ниже):

> **10⋆⋆.** В стране n городов, каждый соединён дорогами ровно с тремя другими, и из любого города можно доехать в любой, сделав не более одной пересадки.
> **(а)** Приведите пример для n = 6 и для n = 8.
> **(б)** Докажите, что n чётно и n ≤ 10.
> **(в)** Приведите пример для n = 10.
> **(г)** При каких n так бывает?

**Ответ:** n ∈ {4, 6, 8, 10}.

**Решение** [своё, оценка — как в источнике]:
- (а) n = 6: полный двудольный граф K₃,₃ (три «дома» и три «колодца») или треугольная призма. n = 8: треугольник 0-1-2; вершины 0, 1, 2 соединены с 3, 4, 5 соответственно; каждая из 3, 4, 5 соединена с 6 и с 7.
- (б) Чётность: концов дорог 3n, это удвоенное число дорог (дословно задача 4б). Оценка: из города A выходят три дороги. У каждого из трёх соседей ещё не больше двух соседей, кроме A. Значит, за одну пересадку достижимо не больше 6 новых городов, и n ≤ 1 + 3 + 6 = 10.
- (в) Граф Петерсена: внешний пятиугольник 0-1-2-3-4, внутренняя пятиконечная звезда 5-7-9-6-8-5, «спицы» i–(i+5). Подсказка «по следам оценки»: при n = 10 оценка точна. Значит, соседи A попарно не соединены, у каждого соседа ровно два «своих» дальних города, и эти 6 дальних городов соединены между собой так, что «дети» одного соседа не соседствуют. Эта структура однозначно даёт Петерсена.
- (г) n = 4 — это K₄. С учётом (б) получаем ответ {4, 6, 8, 10}.

**Проверено** (`verif10/A_cubic_diam2.py`): полный перебор всех помеченных кубических графов на 4, 6, 8 вершинах. Для каждого n есть примеры нужного диаметра: на 8 вершинах их 5880 из 19355. Граф Петерсена удовлетворяет условию. При n = 10 из 32 случайных кубических графов диаметра 2 все изоморфны Петерсену (это согласуется с единственностью графа Мура).

**Разбивка для 7-классника:** 6 и 8 — это разминка, рисунки строятся руками. (б) — два запрета одной величиной (чётность концов и подсчёт «1 + 3 + 6»). (в) — поиск, настоящая вершина. (г) — сборка ответа.

**Сложность:** (а) 2–3, (б) 3, (в) 5, (г) 1. В 11 классе на регате это быстрая задача, для 7 класса пример из (в) — серьёзный поиск.

**Сравнение с 2ⁿ.**
- **Лучше:** прямое продолжение задачи 4 («телефоны по три» — та же конструкция плюс одно условие). Есть запрет одной величиной, причём двумя разными, есть «при каких n» с конечным ответом, есть «пример по следам оценки» (равенство в оценке подсказывает конструкцию). Граф Петерсена — одна из самых красивых конструкций, какие можно показать семикласснику.
- **Хуже:** нет пошагового n → n+k. Вершинный шаг (в) — «догадайся до картинки», его трудно разбить на ступени. Можно дать подсказку «пятиугольник снаружи, звезда внутри», но она съедает задачу.

## Кандидат B. ±1² ± 2² ± … ± n² = 0: при каких n?

**Источник:** фольклор. Обобщение — теорема Эрдёша–Шураньи: любое целое число представимо в виде ±1² ± 2² ± … ± m². Конкретный олимпиадный источник поиском подтвердить не удалось: формулировка «докажите, что любое целое представимо…» ходит по задачникам, но ссылку я не нашёл. Пишу это прямо.

**Условие:**

> **10⋆⋆.** Можно ли расставить знаки «+» и «−» в выражении ±1² ± 2² ± 3² ± … ± n² так, чтобы получился 0,
> **(а)** при n = 7? **(б)** при n = 8?
> **(в)** Докажите, что при n = 3, 4, 5, 6 так сделать нельзя.
> **(г)** При каких n это возможно?
> **(д*)** Докажите, что любое натуральное число можно получить так при подходящем n.

**Ответ:** (г) при n, дающих остаток 0 или 3 при делении на 4, кроме n = 3 и n = 4, то есть n = 7, 8, 11, 12, 15, 16, …

**Решение** [своё; проверено `verif10/B_kvadraty_znaki.py`]:
- Примеры. n = 7: 1 + 4 − 9 + 16 − 25 − 36 + 49 = 0. n = 8: −1 + 4 + 9 − 16 + 25 − 36 − 49 + 64 = 0. n = 11: +1 − 4 + 9 + 16 + 25 − 36 − 49 − 64 + 81 − 100 + 121 = 0. n = 12: −1 − 4 − 9 − 16 − 25 − 36 − 49 − 64 + 81 + 100 − 121 + 144 = 0.
- Запрет одной величиной — чётностью. Смена знака не меняет чётность суммы. Значит, чётность результата равна чётности числа 1² + … + n², а она равна чётности количества нечётных чисел среди 1, …, n. Их чётное число ровно при n ≡ 0 или 3 (mod 4). Отсюда отпадают n = 5, 6 (и все n ≡ 1, 2).
- Малые исключения. n = 3: 1 + 4 + 9 = 14, нужна «половина» 7, а из 1, 4, 9 её не набрать. n = 4: сумма 30, нужна половина 15; 16 > 15, а 1 + 4 + 9 = 14 ≠ 15.
- Шаг n → n + 8: на любых восьми подряд идущих квадратах знаки + − − + − + + − дают 0. Причина: k² − (k+1)² − (k+2)² + (k+3)² = 4 при любом k (разности соседних квадратов — подряд идущие нечётные числа, и 4 = (2k+5) − (2k+1)). Две такие четвёрки с противоположными знаками дают 0. Базы 7, 8, 11, 12, шаг +8 даёт всё.
- (д) Та же четвёрка даёт шаг +4: 1 = 1², 2 = −1 − 4 − 9 + 16, 3 = −1 + 4, 4 = −1 − 4 + 9, дальше к выражению приписываем четвёрки.

Перебор: при n ≤ 40 ноль получается ровно при n ≡ 0, 3 (mod 4), кроме 3 и 4 [проверено].

**Сложность:** (а)–(б) 2–3 (перебор руками, упражнение на «половину суммы»), (в) 2, (г) 4 — придумать восьмёрку (или четвёрку с разностью 4), (д) 4.

**Сравнение с 2ⁿ.**
- **Лучше:** закрывает сразу три линии листка — запрет чётностью (одна величина), «при каких n» с малыми исключениями и шаг n → n+8. По форме ответ почти повторяет задачу 5 про треугольники (все n ≥ 6) и 9⋆ (квадрат не на 5): «при всех подходящих, кроме маленьких». Задача красивая и почти не известна детям.
- **Хуже:** по уровню скорее 4, чем 5. Для школьника, который решил обе звёздочки прошлого листка, пункты (а)–(г) могут оказаться лёгкими, трудность держится на (д). Кроме того, там снова «сумма чисел», а критик уже жаловался на засилье сумм (задачи 2, 3, 5).
- **Вывод:** хорошая задача для середины или для 8⋆, как единоличная вершина мягковата.

## Кандидат C. «Запутанный» турнир: любых двоих кто-то обыграл (задача Шютте для k = 2)

**Источник.** Классика: «проблема Шютте», поставлена в 1962 году. П. Эрдёш, «On a problem in graph theory», Math. Gazette, 1963. Значение f(2) = 7 доказали Дж. и Э. Секереш (1965). Ссылки на обзорную литературу — в статье [Erdős, Moser, 1964](https://users.renyi.hu/~p_erdos/1964-03.pdf). Олимпиадный источник «под 8–9 класс» я не нашёл, хотя сюжет встречается в кружковых подборках про турниры. Пишу это прямо. Решение ниже целиком моё, для кружка оно проверено.

**Условие:**

> **10⋆⋆.** В турнире каждый сыграл с каждым по одному разу, ничьих не было. Назовём турнир *запутанным*, если для любых двух участников найдётся третий, который выиграл у обоих.
> **(а)** Докажите, что в запутанном турнире каждый участник проиграл хотя бы трём.
> **(б)** Докажите, что в запутанном турнире не меньше 7 участников.
> **(в)** Придумайте запутанный турнир с 7 участниками.
> **(г)** Докажите, что запутанный турнир с n участниками существует при любом n ≥ 7.

**Ответ:** запутанный турнир существует ровно при n ≥ 7.

**Решение** [своё]:
- (а) Пусть L(A) — те, кто выиграл у A. Для пары (A, X) нужен тот, кто обыграл A, так что L(A) не пусто. Возьмём любого B из L(A). Для пары (A, B) нужен C, обыгравший обоих. Такой C лежит в L(A) и обыграл B. Значит, *внутри L(A) каждый кому-то проиграл*. Если в L(A) один человек, проигрывать некому. Если двое, то победитель их встречи внутри L(A) не проигрывал. Значит, |L(A)| ≥ 3.
- (б) Поражений всего не меньше 3n, а поражений столько же, сколько партий, то есть n(n−1)/2. Из 3n ≤ n(n−1)/2 получаем n ≥ 7. Это запрет одной величиной: поражения подсчитаны двумя способами, так же как концы проводов в задаче 4а.
- (в) Посадим участников 0, …, 6 по кругу: i выигрывает у i+1, i+2, i+4 (по модулю 7). Подсказка «по следам запрета»: при n = 7 в (б) равенство, поэтому каждый проиграл ровно трём и выиграл ровно у трёх. Естественно искать «круговой» турнир, где каждый бьёт трёх, стоящих на фиксированных расстояниях по часовой стрелке. Из 8 таких вариантов работают ровно 2: шаги {1, 2, 4} и зеркальный {3, 5, 6} [проверено]. Самая естественная первая попытка «бьёт следующих трёх» {1, 2, 3} не работает, так что это настоящий поиск, а не угадывание.
- (г) Клонирование, шаг n → n+1. Возьмём запутанный турнир и участника X. Добавим «двойника» X′: он выигрывает и проигрывает тем же, кому X, а X выиграл у X′. Пара (X, X′): кто-то обыграл X (такие есть по (а)), он же обыграл и X′. Пара (X′, Y) при Y ≠ X: тот, кто обыграл X и Y в старом турнире, обыграл и X′ и Y. Остальные пары старые.

**Проверено** (`verif10/C_turnir.py`): полный перебор турниров с отсечением показывает, что при n = 3, 4, 5, 6 запутанных турниров нет, а при n = 7 есть. Круговой пример {1, 2, 4} работает. Клонирование даёт запутанные турниры при n = 8, …, 15.

**Разбивка для 7-классника:** 4 пункта, и каждый опирается на предыдущий. (а) — ключевая идея, «посмотри внутрь L(A)». (б) — одна строка. (в) — поиск, но (б) заранее говорит, что каждый бьёт ровно трёх, и подталкивает к кругу. (г) — шаг n → n+1, и он проще, чем в задаче про 2ⁿ.

**Сложность:** (а) 5, (б) 2, (в) 4, (г) 3. В целом это уровень «ЦПМ 8 кл., середина-верх листка». Вход острее, чем у 2ⁿ (там (а)–(б) — разминка), зато после (а) всё идёт гладко.

**Сравнение с 2ⁿ.**
- **Лучше, причём по всем четырём линиям сразу:**
  - пример (круговой турнир на 7);
  - запрет одной величиной (подсчёт поражений двумя способами, аналог 4а и 3а);
  - «при каких n» с порогом (n ≥ 7, как «n ≥ 6» в задаче 5);
  - пошаговое построение n → n+1 (клонирование — прямой аналог «режь кусок на 4»).
- Круговая рассадка перекликается с «круглым столом» в задаче 6, а нетранзитивность — с задачей 8⋆ (Ася, Бася, Вася): там цикл предпочтений на трёх, здесь «цикл побед» в более сильной форме. Возникает сквозной сюжет «нетранзитивность» внутри листка.
- Для будущего программиста: перебрать все турниры на 6 участников — это 2¹⁵ = 32768 вариантов, и там пусто. А подсчёт из (б) доказывает пустоту, не запуская перебора. Это ровно тезис манифеста «нельзя — значит поиск вернёт пустоту».
- **Хуже:** точного олимпиадного паспорта «ВсОШ такой-то год» нет. Пункт (а) требует непривычного хода: рассмотреть подтурнир L(A). Нужна устная подсказка на случай застревания: «посмотри на тех, кто обыграл A».

## Кандидат D. Таблица n×n из −1, 0, 1, все 2n сумм различны

**Источник:** фольклор. Точного олимпиадного паспорта не нашёл. Родственные задачи: [problems.ru №21990](https://problems.ru/view_problem_details_new.php?id=21990) (Генкин–Итенберг–Фомин, «Ленинградские математические кружки», гл. 5, №23: таблица 3×3, 8 сумм с диагоналями, среди них есть равные — принцип Дирихле) и [ТГ 2014/15, весна, сложный вариант, 8–9 кл., №5 (problems.ru №65162)](https://www.problems.ru/view_problem_details_new.php?id=65162).

**Условие:**

> **10⋆⋆.** В клетки таблицы n×n ставят числа −1, 0, 1 так, чтобы все 2n сумм (по строкам и по столбцам) были различны.
> **(а)** Сделайте это для n = 2 и n = 4.
> **(б)** Докажите, что для n = 3 это невозможно.
> **(в)** Докажите, что это можно сделать при любом чётном n.

**Ответ:** можно ровно при чётных n. Проверено точным потоковым алгоритмом до n = 9 (`verif10/D3_flow.py`). Там же видно, что при чётном n пропущенное значение всегда ±n.

**Решение** [своё; конструкция проверена для чётных n ≤ 20 в `verif10/D_tablica_pm1.py`]:
- (в) n = 2k. Выше диагонали стоят 1, ниже −1. На диагонали в первых k строках стоят 1, в остальных 0. Суммы строк: чётные 2, 4, …, n и нечётные −1, −3, …, −(n−1). Суммы столбцов: чётные −(n−2), …, 0 и нечётные 1, 3, …, n−1. Вместе это все числа от −(n−1) до n.
- (б) Сумма всех 2n сумм равна удвоенной сумме таблицы, то есть она чётна. Все 2n сумм лежат в [−3, 3], значит, ровно одно значение m пропущено, а сумма остальных равна −m. Отсюда m чётно, и значения ±3 присутствуют оба. Строка с суммой 3 и столбец с суммой −3 не могут встретиться (в общей клетке должно быть и 1, и −1). Значит, ±3 — обе строки (или оба столбца). Тогда третья строка задаёт суммы столбцов (каждая равна её элементу), а они должны быть {−1, 0, 1}. Значит, сумма третьей строки 0 и совпадает с суммой одного из столбцов. Противоречие.
- **Честно:** полный запрет для всех нечётных n (5, 7, …) по этой схеме превращается в длинный разбор. Короткого доказательства «одной величиной» я не нашёл. Чётность даёт только «m чётно», а дальше нужен перебор. Поэтому в листок стоит давать только n = 3, а «при каких n» не спрашивать.

**Сложность:** (а) 3, (б) 4, (в) 4.

**Сравнение с 2ⁿ.**
- **Лучше:** прямое продолжение задачи 3 (таблица, суммы по строкам и столбцам). Запрет для n = 3 — чётность суммы всех сумм, то есть снова «одна величина, посчитанная двумя способами». Конструкция «лестницы» красивая.
- **Хуже:** главный вопрос «при каких n» честно не закрывается. Пошагового n → n+2 в естественном виде нет, конструкция сразу общая. Однообразие «таблица, суммы» с задачей 3 усиливается.
- **Вывод:** годится как 8⋆ или замена 3б, но как вершина слабее C.

## Кандидат E. Набор чисел, где сумма любых двух делится на их разность

**Источник** [источник]: ЦПМ, кружок «Хамовники», 8 класс, 07.10.2023, листок «Конструктивы в ТЧ», задача 7 ([pdf](https://math.mosolymp.ru/upload/files/2024/khamovniki/8/2023-10-10_Konstruktivyi_v_TCH.pdf)): «Существует ли такой набор из 1000 различных натуральных чисел, что для любых двух чисел из набора их сумма делится на их разность?» Это ровно ЦПМ-конструктив 8 класса.

**Условие для листка:**

> **10⋆⋆.** Назовём набор различных натуральных чисел *хорошим*, если сумма любых двух его чисел делится на их разность.
> **(а)** Найдите хороший набор из трёх чисел; **(б)** из четырёх чисел.
> **(в)** Пусть a₁, …, aₖ — хороший набор, а число P делится на каждое aᵢ и на каждую разность aᵢ − aⱼ. Докажите, что набор P, P + a₁, …, P + aₖ — хороший.
> **(г)** Существует ли хороший набор из 1000 чисел?

**Ответ:** (а) 1, 2, 3 или 2, 3, 4; (б) 2, 3, 4, 6 или 12, 14, 15, 16; (г) да.

**Решение** [источник — идея; проверено `verif10/E_summa_raznost.py`]:
- Пара (P + aᵢ, P + aⱼ): разность aᵢ − aⱼ делит P, а значит, делит и 2P. Сумма равна 2P + (aᵢ + aⱼ), и старое свойство даёт делимость aᵢ + aⱼ на aᵢ − aⱼ.
- Пара (P, P + aᵢ): разность aᵢ делит P, а сумма равна 2P + aᵢ.
- Из {1, 2} шагами получаем {2, 3, 4} → {12, 14, 15, 16} → {1680, 1692, 1694, 1695, 1696} → …
- Наименьшие по максимуму хорошие наборы: (1, 2, 3), (2, 3, 4, 6), (6, 8, 9, 10, 12) [проверено].

**Сложность:** (а) 1, (б) 3, (в) 3 (с подсказкой в условии), без подсказки 5; (г) 1.

**Сравнение с 2ⁿ.** Жанр тот же (теория чисел плюс шаг n → n+1), паспорт ЦПМ-шный. Но задача хуже: нет единственности и нет запрета, числа растут как башня, а подсказка (в) почти всё выдаёт. Если хочется «ТЧ-индукцию», задача 2ⁿ элегантнее. Вывод: не заменять ею.

## Кандидат F. Сумма первых k делится на k: конечная версия нельзя, бесконечная можно

**Источник** [источник]: ВсОШ 1995, 10 класс, задача 95.5.10.3 (по кодировке problems.ru вариант 5 — заключительный этап), автор А. В. Шаповалов, [problems.ru №109603](https://problems.ru/view_problem_details_new.php?id=109603): «Существует ли последовательность натуральных чисел, в которой каждое натуральное число встречается ровно один раз и при этом для любого k сумма первых k членов делится на k?» Ответ: существует.

**Условие для листка** (конечные пункты мои):

> **10⋆⋆.** **(а)** Расставьте числа 1, 2, 3 в ряд так, чтобы сумма первых k чисел делилась на k при k = 1, 2, 3.
> **(б)** Докажите, что числа 1, 2, …, n так расставить нельзя ни при каком n ≥ 4.
> **(в)** Докажите, что можно выписать в бесконечный ряд *все* натуральные числа, каждое ровно один раз, так, чтобы при любом k сумма первых k делилась на k.

**Ответ:** (а) 1, 3, 2 или 3, 1, 2; (б) при конечном n подходят только n = 1 и 3; (в) можно.

**Решение:**
- (б) [своё; перебор до n = 10 в `verif10/F_prefiks.py`]. Сумма всех чисел n(n+1)/2 делится на n, значит, n нечётно, n = 2m + 1. Сумма первых n − 1 чисел равна n(n+1)/2 − aₙ и делится на 2m. Остаток n(n+1)/2 при делении на 2m равен m + 1, значит, aₙ = m + 1. Сумма первых n − 2 чисел равна (n+1)m − aₙ₋₁ и делится на 2m − 1. Отсюда aₙ₋₁ ≡ m + 1 (mod 2m − 1), и при m ≥ 2 единственное подходящее число от 1 до n — снова m + 1. Противоречие.
- (в) [источник] Строим по два шага. Пусть выписаны k чисел с суммой S, m — наименьшее ещё не выписанное число. Следующий член берём так, чтобы новая сумма была (k+1)·(m + (k+2)t) при большом t. Этот член новый и больше всех выписанных, а сумма делится на k + 1. Следующим ставим m: сумма становится (k+1)(m + (k+2)t) + m ≡ −m + m = 0 (mod k+2). Проверено на 40 членах в `verif10/F2_beskonechnaya.py`: 1, 3, 2, 10, 4, 52, 5, 115, 6, …

**Сложность:** (а) 1, (б) 4 (остатки, но без «сравнений по сложным модулям» не обойтись), (в) 6 — это заключительный этап ВсОШ для 10 класса.

**Сравнение с 2ⁿ.** Идейно прекрасная пара «конечно нельзя, бесконечно можно»: это мнимое противоречие в чистом виде, а «жадно подставляй наименьшее невыписанное» — чистый алгоритм. Но (в) для 7 класса за пределом «берущегося», а (б) требует работы с остатками по модулям n − 1 и n − 2, то есть того, чего задание просило избегать. Вывод: выше потолка, не брать.

## Резерв (без полной разработки). Числа 1, …, n без «среднего между»

Расставить 1, …, n так, чтобы ни одно число не стояло между двумя числами, средним арифметическим которых оно является. Фольклор, точного источника не нашёл. Конструкция: сначала нечётные, потом чётные, и в каждой половине то же правило рекурсивно (n → 2n): например, 1 5 3 7 2 6 4 8. Проверено до n = 299 (`verif10/G_srednee.py`). Задача красивая и «программистская», но в ней нет «нельзя» и «при каких n», поэтому это не вершина этого листка.

## Вердикт

**Заменить 2ⁿ на кандидата C (запутанный турнир).** Это единственный кандидат, который собирает в вершине все четыре линии листка. Причём его запрет устроен так же, как запреты в середине листка: *одна величина*, посчитанная двумя способами (поражения = партии, как концы проводов в 4а и общая сумма в 3а). У 2ⁿ запрета нет вовсе, а вершина листка «Построй или докажи, что нельзя» без «нельзя» — это перекос. По трудности C не легче 2ⁿ: вход острее, дальше гладко.

**Второй вариант — A (граф Петерсена).** Он подходит, если хочется, чтобы вершина была «этажом выше» задачи 4. Его минус — нет пошагового шага n → n+k.

**Что делать с 2ⁿ:** перенести в устный резерв для того, кто решит всё, или в будущий листок по теории чисел или индукции. Можно дать домашней задачей вместе с USAMO 2003/1.

**Сопутствующие правки, если брать C:**
- Манифест, абзац «Что это даёт будущему программисту». Вместо «вершина листка, число из единиц и двоек… приписывай цифру слева» примерно так: «Вершина листка — турнир, где любых двоих кто-то обыграл. Перебор всех турниров на 6 участников — это 32 768 вариантов, и все они не подходят. Подсчёт поражений доказывает это в одну строку, не запуская перебора. А пример на 7 участников растёт до любого n клонированием игрока».
- Устная подсказка к (а) для того, кто застрял: «посмотри на тех, кто обыграл A: что про них можно сказать?»
- В решениях отметить, что из 8 «круговых» вариантов на 7 участников годятся ровно 2 ({1, 2, 4} и {3, 5, 6}), так что проверка ученического примера требует честного перебора пар: их 21.
