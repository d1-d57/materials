% ДОМАШНЕЕ ЗАДАНИЕ к паре 22.09.  ВЕРСИЯ 5.
% ФОРМАТ (решения владельца): ОДИН вариант; два экземпляра на лист A4, режется
% пополам, 13 листов на 25 школьников; поля под запись и строка подписи есть.
%
% ПОВОРОТ ПО УРОВНЮ (решение владельца на v4). Сначала требование было «ничего
% проще базовой задачи листка». После сборки v4 он прочитал подборку целиком и
% отменил его: «кажется, мы пережестили... слабые дети тоже должны решить».
% Отмена касается УРОВНЯ, а не дублирования: условия листка по-прежнему нельзя
% повторять даже в облегчённом виде (на этом умерла v2).
% Поэтому первые две задачи намеренно простые — уровень продвинутого кружочка
% листка (его задачи 3 и 5), на обязательных навыках блока, но с другими сюжетами.
%
% ЧТО СНЯТО ПО ХОДУ.
% v2 целиком — четыре задачи из пяти были упрощениями конкретных задач листка.
% v3 курьер по сетке 4x4 (ответ 70) — это C(8,4). «Таблица накоплений» лишь
%   маскирует цешку: в клетках вырастает треугольник Паскаля. ПРАВИЛО: маршруты
%   по прямоугольной сетке в блок не входят, как бы «таблично» ни выглядели.
% v4 турнир 12 команд — снят: двойной счёт участий (полурёбра) относится к теме
%   БУДУЩЕГО занятия, а в подборке из четырёх он делал её сплошь трудной.
%   Задача сохранена как кандидат в тот будущий листок, с уже найденным порядком
%   пунктов: сначала сумма очков (12*11 = 132, без числа матчей), потом матчи (132/2).
%
% СОСТАВ v5 — пять задач, два этажа. Три с узким полем, две блоками в конце
% (порядок «числа и пентамино вместе» — решение владельца).
%   1 два множества, базовый вид        футбол и шахматы    8
%   2 разбор случаев по размеру         квадраты на 3x3     14
%   3 перебор наборов с условием        палочки 1..9        34
%   4 перебор по наибольшему слагаемому разбиения числа 8   22
%   5 перебор конфигураций до симметрии пентамино           12
% Числа 9 и 8 у задач 3 и 4 разведены по решению владельца: на 1..8 и 8 оба
% ответа выходили 22, и это лишний повод спутать их на проверке.
%
% Все ответы пересчитаны программой (см. SESSIYA.md, записи 22.09).
% Ни один из пяти мотивов не встречается ни в одном ВЫДАННОМ листке 7И —
% проверено грепом по listok_15-09_logika, listok_15-09_obratnyj-hod,
% listok_22-09_podschety (оба варианта).
% ОСТОРОЖНО при сборке контрольной: задачи 1-4 переносятся заменой чисел
% (множества — любой тройкой; квадраты 4x4 -> 30; палочки 1..8 -> 22;
% разбиения 9 -> 30), а пентамино числом НЕ меняется: тетрамино 5 -- вырождение,
% гексамино 35 -- гроб.
