## Правила
1. **Каждый id твоей группы получает исход** — ни один не пропадает. Исходы:
   - `novoe` — легло новой записью в твой выходной документ (укажи якорь/раздел);
   - `est` — уже записано в существующем доме (укажи файл и номер/раздел — найди грепом, не по памяти);
   - `dubl` — дубль другого id (укажи какого; оставшийся получает novoe/est);
   - `shum` — не знание (служебное, техника) — с причиной; таких должно быть мало.
2. **Слова владельца — дословно** (поле citata), с временем. Идеи аналитика/субагентов — помечать «предложено аналитиком/субагентом», НЕ выдавать за решение владельца.
3. Противоречия (владелец сказал А, позже не-А) не сглаживать: записать оба с временем и пометить, что действует позднее.
4. В каждой записи выходного документа — ссылки на id источников в квадратных скобках, например `[E5-031, E8-112]`. Это рычаг: скрипт потом проверит, что каждый id где-то стоит.
5. Писать по-русски, плотно, без воды. Секретов нет и не писать.
6. Выход писать скриптом/файлами в `/mnt/user-data/outputs/izvl/dom/`; карту исходов — `/mnt/user-data/outputs/izvl/dom/map-<K>.tsv` (строки: `id<TAB>ishod<TAB>kuda`), РОВНО по одной строке на каждый id входа.

Сколько id, разбивка по исходам, какие файлы созданы, что спорно/требует решения владельца. Сами записи в ответ не включай.
