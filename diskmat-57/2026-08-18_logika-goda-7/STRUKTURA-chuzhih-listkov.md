## Источник 1. Владелец, листок 01 «Постепенно, с первого шага» (8 класс, собственный курс)

Формат: чистый раздаточный листок, без решений и без авторских комментариев — в этом смысле беднее источников 3 и 4.

**Сколько задач:** 10 (№1–10; №1 — подпункты а–г, №7 — а–б, №9 — а–б⋆, №10 — а–и).

**Проверка памяти владельца** («давали задачки без формулы, надо было просто выписать всё»): **не подтверждается**. Ни одна из 10 задач не решается перебором/выписыванием без общей идеи. Разбор по номерам:
- №1(а–г) — построить прямоугольник, где квадрат отрезается ровно на 2-м/3-м/4-м/179-м шаге: конструктивное доказательство для произвольного шага (связано с алгоритмом Евклида), не перечисление.
- №2 — за 2n−4 разговора n человек узнают все новости: оценка для произвольного n.
- №3 — 50 чисел, сумма кратна каждому: конструктивное существование.
- №4 — 100 чисел с остатком 1 при делении на любое предыдущее: рекурсивная конструкция.
- №5 — квадрат режется на любое число квадратов >5: индукция (база + шаг).
- №6 — монеты 5 и 26 покрывают все суммы от 100: индукция.
- №7(а–б) — вырезанная клетка в 4×4 и в 64×64, уголки: классическая индукция на четвертины.
- №8 — 1024 стакана воды: алгоритм уравнивания удвоением групп.
- №9(а–б⋆) — газовые баллоны: тот же тип алгоритма, обобщение.
- №10(а–и) — n-мерный куб (вершины, грани, рёбра): требуются **общие формулы** по параметру n (2ⁿ и т. п.) — прямая противоположность «без формулы».

**Последовательность тем по номерам задач:** тема листка — не комбинаторное перечисление, а **серийная/пошаговая конструкция** (протo-индукция; название листка прямо об этом). Из словаря тем сюда ничего не подходит впрямую — это «иное». Внутри неё есть лишь градация по механизму шага: №1–4 — конструкция одного объекта пошагово; №5–9 — индукция «база + шаг» с явным алгоритмом; №10 — общая формула по параметру n.

🔴 **Где впервые произведение:** строго — нигде явно (ни разу не показана цепочка выборов или дерево). Ближайший намёк — №10(д–и): формулы для n-мерного куба (2ⁿ вершин) по существу кодируют произведение n бинарных выборов, но это подано как «найдите формулу», без вывода через дерево.

**Перебором без формулы:** 0 из 10.

**Авторские цели:** явного списка (как у Раскиной/Шеня) нет — это голый листок. Но есть рамочные методические ремарки-связки:
- перед №1: «Многоэтажные здания строят, ставя по очереди следующий этаж на предыдущий... То же с серийными примерами: их получают последовательно, сравнивая с предыдущими и достраивая по мере необходимости.»
- перед №3: «Иногда приходится начинать с построения нескольких этажей сразу.»
- перед №4: «Когда предыдущие примеры серии построены, можно для следующего шага использовать не один, а несколько из них, быть может, даже все. Также серия может распадаться на несколько подсерий.»
- перед №7: «Можно шагать не по всем числам, а только по числам избранного вида.»

**Чем кончается / куда ведёт:** последняя задача (№10) выходит на максимально абстрактный уровень — произвольную размерность n, а не конкретное число. Листок целиком воспитывает привычку доказывать «для всех n сразу»; это прямая подготовка к формальной индукции (листок 09 «Индукция» того же курса — не читан, известен только по заголовку в папке).

(перестановки с симметрией, самая тяжёлая).

🔴 **Где впервые произведение:** пограничный случай. №3а (письма, 20×19) эквивалентен таблице — только 2 шага. Первая настоящая цепочка из 3+ последовательных выборов, которую в таблицу уже не свернуть, — **№7а**. Строго по словарю (произведение = цепочка/дерево, не таблица) ответ — №7; при более мягком счёте — №3.

**Перебором без формулы:** решений в файле нет, поэтому это оценка по структуре, не подтверждение текстом. Правдоподобные кандидаты при малых числах — №1 (путь в маленькой решётке) и №2 (10 двоичных слов длины 5 реально выписать руками) — то есть ориентировочно 2 из 16.

**Авторские цели:** не выписаны — ни преамбулы, ни комментариев в файле нет. Единственный титульный текст — само название «3. Пары и тройки».

**Чем кончается / куда ведёт:** последняя задача (№16, хороводы, точная формула (3n)!) — самая тяжёлая в листке, сочетает перестановки, деление на симметрию и цветовое условие. Листок идёт по нарастающей: простое произведение/сумма (№1–6) → явное разграничение произведения и сочетаний (№7–9) → тяжёлые составные задачи (№10–16). ## Источник 3. Шень, «Листок 1» (shencomb_text.json)

Формат: JSON с 32 блоками (16 `task` + комментарии `comment` + `figure`). Комментарии — авторские пояснения метода, идут почти после каждой пары задач, а не собраны в начале/конце — этим источник отличается от всех остальных.

**Сколько задач:** 16 (№1–16, без подпунктов).

**Последовательность тем по номерам задач:**
№1–5 отрезок (сколько чисел от 1 до 9 / от 1 до 99 / трёхзначных / делений термометра −50…+50 / общая формула «от m до n») → комментарий про ошибку на единицу (off-by-one) · №6 отрезок/разность (этажи 1→5→10) → два комментария: сложение как объединение непересекающихся множеств (сумма) и его формальное определение через |A∪B| · комментарий-мост «Иногда полезно не складывать, а умножать» · №7 🔴 таблица (клетки прямоугольника — первое умножение, но поданное как таблица, не дерево) → комментарий о коммутативности умножения · №8 разность (заштрихованная часть = целое минус лишнее) · №9 вкл-искл (пересекающиеся заштрихованные части) → комментарий прямо называет метод: «формула включения и исключения» · №10–11 таблица/разность/вкл-искл (ещё картинки с клетками, без новых пояснений) · №12 пары (чётные/нечётные 1–100 через взаимно однозначное соответствие = деление на 2) → комментарий про биекцию и переходный комментарий «мы разобрали некоторые приёмы... сейчас чуть посложнее задачи» · №13 таблица (двузначные числа без цифры 0 / только нечётные цифры — тот же прямоугольник двух независимых разрядов, что и в №7–11, просто без картинки) · №14–15 перебор/сумма (сколько раз цифра 7 встречается / у скольких чисел встречается — разбор по разрядам, задачи специально парные, «в чём разница») · №16 отрезок (числа 1–100, делящиеся на 3).

🔴 **Где впервые произведение:** в строгом смысле (дерево/цепочка) — **ни разу**. Слово «дерево» не встречается ни в одном из 32 блоков Листка 1. Всё умножение подано через таблицу (прямоугольник клеток). Это принципиальное отличие от Раскиной, где дерево вводится явно и называется по имени. Если считать «произведение» просто как факт умножения (не обязательно дерева) — первое место №7.

**Перебором без формулы:** №1–3 буквально формулируются как «напишем/выпишем» (явный перебор), хотя тут же обсуждается общий сдвиг-формула (№5). Итого около 3–4 из 16 (№1, №2, №3 явно; №16 неявно для малых случаев).

**Авторские цели (дословно, из блоков `comment`):**
- после №5: «Поначалу хочется сказать, что от m до n будет n−m чисел... Но это не так — и эта ошибка даже имеет специальное название в программировании: ‘‘off-by-one error’’ (ошибка на единицу)... Примерно ту же ошибку допустили те, кто считали, что третье тысячелетие началось в 2000 году.»
- после №6: «...мы делили числа 1,…,99 на две части: однозначные от 1 до 9 и двузначные от 10 до 99. В первой группе 9 чисел, а всего чисел 99, так что во второй группе 99−9=90 чисел.»
- следом (формальное определение суммы): «Математики говорят, что множество всех чисел {1,2,3,…,99} является объединением двух непересекающихся подмножеств... и потому число элементов в нём равно сумме чисел элементов в этих подмножествах, и что это — определение сложения.»
- перед №7: «Иногда полезно не складывать, а умножать.»
- после №7: «Отсюда видно, что перестановка множителей не меняет произведения — как говорят математики, умножение коммутативно (ab=ba), равно как и сложение (a+b=b+a).»
- после №9: «Математики называют этот способ подсчёта формулой включения и исключения: чтобы подсчитать общее число элементов в двух пересекающихся множествах, можно сложить числа элементов и вычесть элементы, посчитанные дважды.»
- после №12: «Математики говорят, что группировка нечётных и чётных чисел в пары задаёт взаимно однозначное соответствие между чётными и нечётными числами... А если между множествами есть взаимно однозначное соответствие, то в них поровну элементов.»
- перед №13: «Мы разобрали некоторые приёмы решения задач, к которым ещё вернёмся более подробно. А сейчас несколько более сложных задач — если они поначалу покажутся трудными, то ничего страшного.»

**Чем кончается / куда ведёт:** последние задачи (14–16) — подсчёт цифр/чисел с условием и делимость, то есть листок заканчивается на арифметике, а не на новой комбинаторной технике. Явного анонса следующего листка нет, но структура (отрезок → сумма → умножение-как-таблица → вкл-искл → биекция) читается как систематический обзор ВСЕХ базовых приёмов подряд в одном занятии — необычно плотная программа по сравнению с остальными источниками.

**Авторские цели (дословно)** — итоговый список после вводного текста к задаче 1: «Итак: 1) ответ на вопрос «Сколько?» связан с перечислением; 2) вместо самих объектов бывает удобнее считать их имена (задача 1.2); 3) удобнее считать то, что разделено на группы; 4) разделение на группы можно оформить в виде таблицы (каждая группа –– строка или столбец), тогда задача сведётся к подсчёту заполненных клеток таблицы; 5) если группы равные, то число клеток таблицы находят умножением; 6) две задачи могут формулироваться совсем по-разному, но если им соответствует одинаковые таблицы (и вообще, одинаковые «картинки»), то и решения будут аналогичными, и ответы совпадут (задачи 1.2 и 1.3, а также 1.5 и 1.6).»

**Чем кончается / куда ведёт:** последняя разобранная задача (1.10) заканчивается комментарием «Мы выяснили, что каждое искомое число однозначно задаётся первыми двумя цифрами. Это значит, что можно было считать только пары первых двух цифр» — явный мостик к понятию «пары». ## Источник 4б. Раскина–Шаповалов, вып. 20, Занятие 4 «Отбрось лишнее» (вычитание в комбинаторике)

### Вопрос 1. Есть ли общий порядок тем, повторяющийся у разных авторов?

Единого номерного порядка («у всех авторов произведение впервые на задаче №K») — **нет**. Позиция разбросана от «задача №1» (Раскина, занятие 1 — умножение прямо в первой задаче, поданное как таблица) до «нигде явно» (Шень — весь Листок 1 остаётся на уровне таблицы; листок 01 владельца — другой жанр вообще). Разброс равен всей длине листков — это не шум, это разные пед. решения.

Но за этим разбросом видны три устойчивых, немного более тонких правила, которые выполняются во всех источниках без исключений:

1. **Таблица (2 независимых множителя, прямоугольник клеток) никогда не появляется позже дерева (3+ шагов).** Везде, где в источнике вообще есть и то и другое (владелец-03, обе части Раскиной, Корсаков), таблица либо предшествует дереву, либо они спутаны на границе (2-факторный случай), но обратного порядка — дерево раньше таблицы — нет нигде. Шень вовсе не доходит до дерева в Листке 1, оставаясь на «таблице» до конца.
2. **Перебор/выписывание либо идёт первым, либо вообще замещает формулу — но никогда не вводится «после» дерева как более сложная техника.** У Шеня (№1–3) и у Раскиной (1.2–1.3) перебор — это стартовая точка занятия, инструмент для малых случаев, на котором вводятся первые понятия (имя объекта, столбец/строка). После того как появляется дерево, к чистому перебору без всякой структуры уже не возвращаются.
3. **Сочетания (выбор без порядка) как самостоятельная, осознанно противопоставленная произведению техника всегда идут позже произведения, никогда раньше.** У владельца-03 это пары №7/№9 (порядок vs без порядка сравниваются напрямую), у Корсакова — пары №6/№7. Ни один источник не начинает занятие с сочетаний.

Так что общий порядок есть, но он не про номера задач, а про **зависимость понятий**: перебор → (сумма/отрезок как его первое обобщение) → таблица (умножение двух факторов) → дерево (умножение 3+ факторов) → сочетания (когда порядок специально снимается). Разность и вкл-искл встроены в эту цепочку сбоку, не по одной линии с произведением (Раскина, занятие 4, и Шень №8–9 показывают: разность/вкл-искл можно вводить и до, и после дерева — они с произведением ортогональны, а не последовательны).

### Вопрос 2. Что авторы ставят первым, до всякого произведения, и сколько этого материала набирается?

По источникам:
- **Шень, Листок 1:** отрезок + сумма — 6 задач из 16 (37% листка) до первого умножения. Самая длинная «разминка» среди всех источников.
- **Раскина, занятие 1:** ничего — умножение (как таблица) в первой же задаче. Но перебор (метод «перечисление») идёт сразу следом (№2–3), параллельно с таблицей, а не до неё. Настоящее дерево (произведение в строгом смысле) отложено до №4 — то есть 3 задачи «разминки» перед ним, но это разминка перебором и таблицей одновременно, не только «до».
- **Корсаков:** сумма — ровно 1 задача до произведения. Самый быстрый переход из всех пяти.
- **Владелец, листок 03:** формально 0 — но только потому, что произведение уже введено раньше, отдельным листком 02 «Правило суммы и произведения» (не читан, виден по названию). Внутри самого листка 03 разминки перед произведением нет вообще — с первой же задачи (счёт путей в решётке) фактически используется уже пройденное.
- **Владелец, листок 01:** вопрос неприменим — произведения в листке нет вовсе, это не про подсчёт, а про пошаговую конструкцию (протo-индукция).

Итог: там, где разминка вообще есть (Шень, Корсаков — оба строят занятие «с нуля»), её **содержание** совпадает — это всегда **сумма** (объединение непересекающихся групп): у Шеня сумма идёт вслед за отрезком, у Корсакова сумма и есть самое первое, отрезка вовсе нет (тропинки — сразу готовые непересекающиеся группы, без счёта диапазона чисел). А вот **длина** разминки не стандартизована совершенно: от 0 задач (Раскина, владелец-03) до 6 задач (Шень) — то есть нет общепринятого объёма «сколько перед умножением нужно накопить». Каждый автор решает по-своему; устойчиво только то, ЧЕМ он заполняет эту разминку (сумма/перебор), а не сколько.
