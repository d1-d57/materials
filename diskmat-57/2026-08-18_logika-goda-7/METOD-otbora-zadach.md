# Метод отбора задач обязательной части (кружки ○ и треугольники △)

Заведён 28.09 по Р183: задачи выбираются методом, а не вопросом владельцу; владельцу — только субъективная калибровка.
Первый прогон — листок 29.09 «Таблицы и группы»: `otbor.py` → `OTBOR-29-09.html`. План на будущее — этот файл;
кандидат на перенос в процедуру `disciplina/zagotovki/listok-7i` (фаза Ф6 «кандидаты и калибровка»).

## 0. Вход — решения владельца по листку
- **Вершины ядра** (3–4 штуки, Р180): что тестируем обязательно. Для каждой — старое (должны уметь) или новое (не знаем).
- **Словарь идей**: каждая вершина раскладывается на 1–4 идеи с кодом (T1, T2, …). Словарь закрытый: две карточки
  «про одно и то же» обязаны получить один код. Без словаря фильтр «новая идея» сравнивает тексты и пропускает дубли
  (урок 28.09: K02 и K03 прошли как «новые» из-за разных слов).
- **Цель кружков Z** — множество идей, которые кружки обязаны покрыть; что идёт только в треугольники/контрольную.
- **Фиксированные задачи** — выбранные владельцем прямо (29.09: K08, Р184).

## 1. Карточка задачи — поля
id · источник с адресом · дословное условие варианта А · ответ-строка (посчитан перебором) · идеи из словаря ·
пункты (число; каждый проверяет своё — не дубли) · время подготовленного / медленного (оценка) · нужно ли рассуждение ·
повтор ли того, что класс видел (листки, ДЗ, контрольная) · запрещённое (Р168, Р180) · вариант Б (изоморфизм, ответ скриптом) ·
выход в сторону (вероятность, картинка, «вселенная» — Р177).

## 2. Фильтры (объективные, считаются скриптом)
| код | условие | куда при провале |
|---|---|---|
| F1 | задействует ≥ 1 вершину ядра | в допзадачи или вон |
| F2 | нет запрещённого (цепочки выборов/дерево, деление-двойной счёт, треугольная таблица как необходимое, «имена вместо объектов») | допзадачи |
| F4 | время подготовленного ≤ 4 мин (○), ≤ 5 мин (△) | допзадачи |
| F6 | не повтор типа, который класс уже решал (тот же шаблон; другие числа — не спасают) | вон |
| F7 | рассуждение нужно → только △ | в △ |
| F8 | не тривиально: подготовленный тратит ≥ 1 мин («что сделают все, не дробить») | вон |
| F3, F5 | ответ не угадывается; вариант Б изоморфен и проверен скриптом | проверяются при сборке |

## 3. Правило покрытия
**Кружки.** Старт — фиксированные задачи. Далее жадно: берём задачу с наибольшим числом новых идей из Z на минуту;
ничья — больше новых идей, затем есть выход в сторону (картинка), затем меньше время. Стоп, когда Z покрыто.
Бюджет ≤ 10 пунктов. Порядок в листке — по времени (сложность растёт).
**Треугольники.** Три задачи не из кружков, ≥ 2 вершин каждая, ≤ 5 мин. Первой — та, что несёт идею ядра, которой нет
в кружках (29.09: V2, включение-исключение); далее максимум новых идей; ничья — другая «вселенная», чем в кружках,
меньше пунктов, меньше время. Вместе — все вершины ядра.

## 4. Что выносится владельцу (только субъективное)
- оценки времени и доли там, где аналитик может ошибиться (замеренное смещение: верхушку завышает, время занижает);
- «тривиально ↔ трудно» для входов и ловушек;
- вкус: красиво ли, «бриллиант» ли (допзадачи).
Вопрос владельцу — всегда с полным текстом условия в самом вопросе.

## 5. После урока
Оценки времени и долей в карточках сверяются со сдачей (Ф13) и переписываются — иначе метод не учится.

## Не покрыто методом (следующий прогон)
Допзадачи: замкнутый объём, максимум пунктов, «бриллианты», близнецы с вопросом «почему совпало», лабиринт.

## Уроки отбора 29.09 (Р196–Р200)

- **Не придумывать задачи.** Всё — из источников (РШ вып. 20, листки 179 для 8 кл., Шень); переформулировка — да,
  сочинение — нет. Придуманные «карты» и домино-фигура были сняты владельцем.
- **Тема «таблица и группы» не включает неявное C(n,2)** (половина таблицы, «пары», деление на 2): сняты отрезки/диагональ,
  хоккейные очки, Кругляндия; «произведения простых» не взяты в ДЗ по той же причине (Р198).
- **△ — счётные задачи,** не «искусственные на правило произведения» (рейсы Айск–Бийск сняты как «дурацкая»). Пример
  годной: «цифра 2 или делится на 2» — большое пересечение, тонкая работа (Р197).
- **ДЗ собирается набором:** 8 разных приёмов, по неделям; проверка «не повторяет листок/контрольную/ДЗ» — по всем выданным.
  Задача, ставшая △ листка, из ДЗ уходит (фишки).
- **Утверждение блоками с полными условиями** (контрольная → ○ → △ → доп → карта → ДЗ → шпаргалка). Ответ владельца
  потерялся — переспросить, а не решить за него (Р188).
