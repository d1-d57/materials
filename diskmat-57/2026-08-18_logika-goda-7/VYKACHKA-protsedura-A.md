# A. Идея и конструкция листка (сессия 18.09)

> Источник — только `VYGRUZKA-2026-09-18-3.md`. Явного упоминания «22.09» или названия «Комбинаторика 1» в тексте нет: 15.09 названо вторником («во вторник 15-го»), а решения ниже относятся к листку на «следующий вторник» — обсуждение идёт как продолжение разбора занятия 15.09 и правки текущего листка логики, чьи форматные решения переносятся дальше.

## Шаги

### 1. Правка поля ответа в текущем листке логики (черновик для печати)
- вход: свёрстанный черновик листка логики, уже частично напечатанный утром (не хватило экземпляров на класс)
- действие: владелец построчно разбирает вёрстку — просит одну область под ответ вместо раздельных полос «ответ» и «подпись», узкую полоску справа под плюсик и подпись, буквы А/Б/В вместо полных имён в задачах с несколькими вариантами, горизонтальные линии-разделители по пунктам, укрупнение кегля условий, перенос номера задачи к полю ответа
- артефакт: листок логики (путь не назван)
- слово владельца: «Может, надо сделать одну основную область, а справа отсечь узкую полоску, где можно поставить плюс и расписаться.»
- ошибка / переделка: в задаче 4 обрезалось слово «У» — не был настроен перенос перед пунктом 1; кегль условий признан «очень поджатым» при большом запасе свободного места на странице

### 2. Уточнение правил кегля и переносов
- вход: замечание про обрезанное слово и поджатый кегль (шаг 1)
- действие: зафиксирован алгоритм — переносы ставить по максимуму, пока они не увеличивают число строк, а для сжатия текста на странице убирать переносы; кегль условий — максимальный, при котором всё ещё влезает
- слово владельца: «12 задач при большем кегле могут не влезть на одну страницу.» → ответ владельца: «Снизить кегль обратно»

### 3. Стереть служебный комментарий из раздатки

- слово владельца: «Комментарий «Задача 1. Четыре базовая» надо стереть — он не нужен.»

### 4. Рефлексия по итогам занятия 15.09 — листок оказался слишком лёгким
- вход: фотографии сданных листков с двух уроков, восстановленный список учеников
- действие: сравнили время и результат самого быстрого ученика с ожиданием; вывод — базовая и продвинутая части не должны быть одинаковой сложности
- артефакт: листки занятия (фото), CSV-таблица сдачи
- слово владельца: «Идейно: листок должен быть не таким длинным, но более концептуальным и сложным.»
- ошибка / переделка: Карцев Фёдор решил весь листок «обратный ход» за ~35 минут и успел решить ещё две задачи продвинутого листка — предохранителей («гробов») для сильных учеников не было; поймано по факту сдачи, а не заранее

### 5. Первая версия системы уровней сложности — три значка
- вход: наблюдение о разбросе силы учеников в классе
- действие: предложена метка-система: кружочек — обязательно всем, восклицательный знак — важные задачи, звёздочка — «гробы» в конце; плюс свободные дополнительные задачи без значка

- артефакт: инфографика по итогам занятий (первая версия собрана мимо Клод Кода)
- слово владельца: «А я бы хотел, чтобы он сидел под двумя третями спектра, чтобы они были более размазаны внутри него.»
- ошибка / переделка: первая версия инфографики оказалась нечитаемой — «тут ничего не понятно( надо делать это в клод коде» — пришлось запускать отдельный заход в Клод Код на дизайн графиков

- действие: решили требовать от детей записывать ответ как выражение (например, «18 умножить на 23 плюс 17 на 6»), под разные задачи — разные формы поля ответа

### 9. Идея дробления задач на пункты ради более тонкой шкалы баллов

- действие: предложено разбивать задачу на пункты А (проще) и Б (чуть сложнее, использует результат А), получая шкалу 0/1/2 вместо 0/1
- слово владельца: «берешь и разбиваешь на маленькие вопросы, делаешь короткие задачи, которые быстро решаются»
- ошибка / переделка: на уже сданных листках несколько вопросов внутри одной задачи засчитывались целиком, а не по пунктам — это мешает точной статистике; решили старые фото не пересматривать, а зафиксировать идею на будущее

- слово владельца: «Но в моем представлении это не могут быть и треугольники, и кружочки одновременно. То есть это одно из двух.»

## Решения о формате листка

- Поле ответа объединено с полем подписи; справа — узкая полоска под плюс: «одну основную область, а справа отсечь узкую полоску» (8 слов)
- Служебные пометки для себя («Задача 1. Четыре базовая») из раздатки убрать: «он не нужен»
- Кегль условий — максимальный, при котором листок влезает на страницу (ответ владельца на вопрос про кегль)
- Переносы — ставить по максимуму, убирать только для сжатия: «пока они не увеличивают количество строк»
- Обязательный блок — один из двух путей: «либо решил все кружки, либо все треугольники — этого достаточно для четверки»
- Кружочек = технические простые задачи: «Технические простые, которые надо делать руками, — кружочек»
- Треугольничек = идейные, олимпиадного типа задачи: «уже условно олимпиадные — треугольничек»
- Ромб (без значка) = нестандартная интересная задача вне обязательной части, не разбирается на занятии
- Звёздочка/«гроб» — самая сложная задача в конце; статус под вопросом: «Может быть, звездочки вообще не будут нужны»
- Ответ — выражение, а не голое число: «нам нужен не ответ, а выражение»
- Задачи можно дробить на пункты А/Б для более тонкой шкалы баллов: «он сложнее, предполагает какую-то маленькую дополнительную идею»
- Базовые задачи не должны быть тяжёлыми по времени, только «посильно тяжёлыми»: «Базовые задачи не должны занимать много времени, быть тяжёлыми, но посильно тяжёлыми»
- Дополнительные задачи можно перемешивать между вариантами, порядок необязательно по нарастанию сложности: «Специально нарушив порядок сложности. Можно поэкспериментировать»
- Прогноз сложности задач фиксировать заранее в процентах: «Лучше предсказывать теперь в процентах»
- Следующий листок не должен содержать 22 задачи в одной теме, цель — уровень, достижимый для 80% класса: «вряд ли можно 22 задачи давать вот в какой-то одной теме»
