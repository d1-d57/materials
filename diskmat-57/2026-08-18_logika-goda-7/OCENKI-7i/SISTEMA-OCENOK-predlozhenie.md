## Главная находка 🔢: «база» работает для листков и не работает для КР
Правило «база (все ○ или все △) → 4, база и ещё ≥ 2 → 5» на живых данных:
- **Листки:** Л4 (29.09) — 5: 15, 4: 5, без базы: 6, без отметок: 2; Л3 (22.09) — 5: 11, 4: 3, без базы: 9. Работает: большинство закрывает базу.
- **КР:** КР1 (29.09) — базу закрыли 3 из 27; КР2 (06.10) — 1 из 26. Требование «все ○ без ошибки» на контрольной — почти недостижимо.
- Для КР нужно правило по навыкам (OCENKI-osnova §2в): по лучшей части навык засчитан при ≥ ½ его пунктов; «5» — все навыки, «4» — хотя бы один. КР2: 8 пятёрок · 18 четвёрок · 0 троек.

## Предложение 💡
1. **Листок:** база → 4; база и ещё ≥ 2 задачи → 5; без базы — **оценки нет** (не 3): листок можно добирать, пока идёт тема; оценка появляется в момент, когда база закрыта. Троек за листки не бывает вовсе.
2. **КР:** по навыкам, лучшая из частей (выше); здесь тройка возможна — она одна на работу и выправляется листками.
3. **Пересдача** заменяет отметку (последнее свидетельство, а не среднее); на экране — «−→+».
4. **Дополнительный листок** — только поднимает: даёт «5», никогда не ставит ниже; тот, кто сидел на разборе, ничего не теряет.
5. **Личный коэффициент** (четвёртый уровень, на теме): база для ребёнка — все ○ без одного; в журнале выглядит так же, отметка «личная база» видна только преподавателю.
6. **Четвертная:** среднее всех оценок четверти (КР и листки с весом 1), «5» от 4,5, иначе «4».
7. **Экран:** на главной справа — только оценка, одним цветом (правка владельца 03:04: «не понимаю, что означает зелёное… просто поставить оценку»); у листка без базы — пусто.
