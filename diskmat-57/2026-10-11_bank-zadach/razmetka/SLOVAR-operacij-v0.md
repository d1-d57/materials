# Словарь операций v0 — черновик для разметки И2

*Источник — инвентарь `INVENTAR-tegov.md` §3. Операции взяты из текстов 50 решений. Словарь — гипотеза: разметчик МОЖЕТ предложить новую операцию (код `X:<имя>`) с определением.*

Операция — действие, которое ребёнок обязан выполнить, чтобы получить ответ пункта. Это не тема и не сюжет. Пункт требует операцию, если без неё ответ пункта не получить **ни одним из известных решений**. Если операция нужна только в одном из решений, её отмечают у этого решения.

| код | операция | считается | НЕ считается |
|---|---|---|---|
| N1 | **нумерация сдвигом**: поставить объекты в ряд и сопоставить им номера 1…N (от a до b, вагоны, страницы, пролёты, места) | «от 17 до 123 — это 1…107», «пролётов на один меньше этажей», «листов вдвое меньше страниц» | просто прочитать число из условия |
| N2 | **нумерация делением**: кратные k на отрезке ↔ номера 1…M делением на k | «чётные до 52 — номера 1…26» | деление как арифметика без пересчёта объектов |
| R1 | **разрез на группы**: разбить объекты на группы без общих элементов по параметру, посчитать группы, сложить | группы по первой цифре, по числу пятирублёвых, по месту белой полосы | таблица, где группы — лишь способ выписать (это P1) |
| R2 | **дополнение**: посчитать всё и вычесть лишнее | «90 − 18», «2019 − 28», «всего минус плохие флаги» | вычитание как арифметика внутри формулы (N1: 123 − 17 + 1) |
| R3 | **общая часть**: при сложении двух или трёх совокупностей учесть то, что посчитано дважды (или нужно найти пересечение) | «18 + 15 − 25», «166 + 100 + 66 − 2 · 33», круги Эйлера | две группы без общих элементов (это R1) |
| K1 | **одна запись на объект**: выбрать каноническую запись, чтобы каждый объект записывался ровно одним способом | слагаемые по убыванию, тройки по возрастанию | порядок уже задан условием (тогда P2) |
| P1 | **таблица по главному**: зафиксировать главный параметр — строки; внутри строки перебрать один параметр от наибольшего до нуля | «троек 2, 1, 0; внутри — число двоек» | разрез без перебора внутри (R1) |
| P2 | **следующий по правилу**: по объекту найти следующий или предыдущий в заданном порядке | словарный порядок флагов, «после 189» | — |
| P3 | **место в списке**: найти номер объекта или k-й объект, считая группы перед ним | «20-е число», «Вася в 16-м вагоне от головы» — только если считают группы | — |
| S1 | **определённость**: часть объекта однозначно задаётся остальными, поэтому считаем только свободную часть | «последняя цифра дополняет сумму», «остаток добирается рублёвыми», «вторая цифра = 11 − первая» | — |
| S2 | **соответствие**: перевести объекты в другие, которые уже посчитаны или легче считаются (взаимно однозначно) | «флаг из 5 полос без нижней — флаг из 4», «квадрат ↔ рамка + сдвиг», «пара пересекающихся кругов ↔ кратные 30» | нумерация (N1, N2) |
| D1 | **двойной подсчёт**: считать не объекты, а вхождения, позиции или линии, складывая по другому признаку | смены цифр по разрядам, точки домино по числам, спички по линиям | — |
| Z | **предметный факт** (не операция, отдельная колонка): условие треугольника, признак делимости, простые числа, лист = 2 страницы, наименьшее общее кратное | — | — |

Группы — гипотеза, их проверяют данные, разметчик группы НЕ ставит:
- идея 1 «заменить более простой» — R1, R2, R3, D1;
- идея 2 «одно имя» — N1, N2, K1, S1, S2;
- идея 3 «перебор по правилу» — P1, P2, P3.
