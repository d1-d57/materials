## 2. Почему системы разъезжаются

- **Одно слово, три уровня.** «Навык» в системе 1 смешивает три разных вида меток:
  - операции (2, 3, 4);
  - класс ошибки (1: ±1 — это «не те места» из системы 4);
  - стратегии (5а, 5б).

  Отсюда спорные места в `NAVYKI-7I-chernovik.md` §6. Например, КР2 ○6 «смешивает разрез, ±1 и чтение чужого рассуждения».
- **Трудность и форма пункта живут отдельно, и это правильно.** Уровни (система 8) и генераторы (система 7) — не умения. Их место — поля варианта, а не теги умения.
- **Разметка дырявая.** Листки размечены на треть. Разметка 22.09 и 29.09 сделана «по ответам детей», условий тогда не было (§6). Значит, весь корпус надо размечать заново по решениям, а не дополнять старое.
- **Есть живая зависимость.** Оценки КР в боте считаются по навыкам 1, 2, 3. Новая система обязана иметь таблицу перехода «операции → старые навыки», иначе оценки молча поменяются.

## 3. Что видно для следующего шага (И2) — гипотеза, не решение

Операции, которые встречаются в 50 решениях. Их называют сами тексты решений, это не литература:

- **Нумерация:**
  - отрезок со сдвигом (от a до b, вагоны, страницы);
  - делением (кратные).
- **Разбиение и счёт частей:**
  - разрез на группы без общих элементов и сложение;
  - дополнение — всё минус лишнее;
  - поправка на общую часть.
- **Одна запись на объект:** каноническая форма — по убыванию, словарный порядок.
- **Перебор по правилу:**
  - главный параметр как строки таблицы, внутри — один параметр;
  - правило «следующего»;
  - место элемента в упорядоченном списке.
- **Сведение к знакомому:**
  - взаимно однозначное соответствие (флаги из 5 полос → из 4; рамка квадрата; последняя цифра определена);
  - двойной подсчёт: по позициям или разрядам — часы, домино «по числам».
- **Проверка:** вторым способом или на маленьком случае.

Это около 10–12 операций. Они раскладываются по трём идеям (система 3) почти без остатка. Значит, идеи можно сделать группами операций, то есть теми «вспомогательными группами», о которых сказал владелец, а не отдельной системой. Это проверяется на шаге И2 разметкой.

## 4. Что из этого следует для плана

- Уровень «умеет» — операции, как решил владелец. Группы — три идеи. Трудность и форма пункта — поля варианта. Классы ошибок (пропуск, повтор, не те места) — поле попытки.
- И2 (Q-матрица) размечает **все 50 решений заново** по операциям. Старая разметка `punkty.csv` идёт только в таблицу перехода.
- Таблица перехода «операции → навыки 1, 2, 3» — обязательный выход И5, иначе разъедутся оценки в боте.
