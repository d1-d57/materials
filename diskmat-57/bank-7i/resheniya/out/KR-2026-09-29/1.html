Ответ. А: 64 листа, Б: 69.

План. превратить номера страниц в числа 1, 2, 3, … — тогда страницы считаются сразу, — а потом объединить страницы в листы.

  1. Страницам пачки дадим новые номера: 87 → 1, 88 → 2, … Для этого из каждого номера вычтем 86. Тогда последняя страница получит номер 214 − 86 = 128. Значит, в пачке 128 страниц.
  2. Лист — это две страницы, лежащие одна за другой: первая страница пачки (87) нечётная, а последняя (214) чётная, поэтому пачка состоит из целых листов, и ни одна страница не осталась без пары.
  3. Страниц 128, на каждом листе по две, значит, листов 128 : 2 = 64.

Вариант Б. вычитаем 94: 232 − 94 = 138 страниц, листов 138 : 2 = 69.
