## ДЫРЫ

Кандидаты — темы, которые встречаются **минимум у двух** источников. Каждое «нет у нас» проверено двумя командами по живому `diskmat-57/_sajt/god.json`:

- (А) команда захода дословно: счёт по всему файлу;
- (Б) тот же счёт только по элементам `tip == "blok"`.

Они расходятся, и вот почему. Поле `sluzhebnoe` в `god.json` содержит служебный текст «Чего на кружке быть не может: простые числа, разложение на простые, ОТА, алгоритм Евклида…». Поэтому (А) даёт «простые 3», «Евклид 2», «разложен 1», хотя ни один блок эти темы не называет. Определение дыры — «не названы ни одним блоком», значит судит (Б). Расхождение названо, а не спрятано.
