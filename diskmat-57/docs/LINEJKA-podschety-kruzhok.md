## ДЫРЫ

Кандидаты — темы, которые встречаются **минимум у двух** источников. Каждое «нет у нас» проверено счётом по живому `diskmat-57/_sajt/god.json` в трёх срезах:

- (А) команда захода дословно, по всему файлу;
- (Б) только элементы `tip == "blok"`;
- (K) только элементы кружка.

Определение дыры — «не названы ни одним блоком», поэтому судит (Б). (K) показывает, стоит ли тема на кружке.
