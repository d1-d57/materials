Те же числа Фибоначчи считают и другие объекты. Вот ещё семь

- Bₙ — подмножества множества {1, …, n−1}, в которых нет двух соседних элементов
- Cₙ — последовательности длины n из нулей и единиц без двух нулей подряд, оканчивающиеся на 1
- Dₙ — упорядоченные разбиения числа n+2 в сумму слагаемых, больших 1
- Eₙ — упорядоченные разбиения числа n+1 в сумму нечётных слагаемых
- Fₙ — перестановки π множества {1, …, n}, для которых |π(i) − i| ≤ 1
- Gₙ — последовательности (a₁, …, a_{n−1}) нулей и единиц, для которых a₁ ≤ a₂ ≥ a₃ ≤ a₄ ≥ …
- Hₙ — последовательности длины n цифр от 1 до 4, где вначале стоит 1 и рядом стоят соседние цифры

Дальше разберём их по одному. У каждого — то же определение → примеры → та же рекуррента → соответствие с полоской
