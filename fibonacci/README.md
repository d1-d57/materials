# Числа Фибоначчи — мини-курс биективных доказательств для 8–9 класса с интерактивным деком

<!-- gen:podrobno — пишет генератор описаний; правки сюда пропадут, править ответы анкеты -->

Мини-курс «Числа Фибоначчи» в том же духе, что курс о числах Каталана: каждое тождество доказывается не индукцией и не формулой, а биекцией или картинкой. Курс делался для летнего лагеря школы 179, для перехода из 8 в 9 класс: три лекции на две группы разной силы, одна база и две подачи. Опоры — авторский листок на 15 задач и книга Benjamin, Quinn «Proofs that Really Count». Главная задумка — интерактив: слева меняешь объект, справа меняется соответствующий ему по биекции.

`SPEKA.md` — единственный источник того, что строится. Первая лекция закрывает задачи 1–5 листка: восемь объектов, которые считаются числами Фибоначчи (замощения, подмножества без соседей, коды без «00», композиции, перестановки, зигзаги и другие). Для каждого сделан слайд из четырёх сцен: определение, примеры, рекуррента, биекция с замощениями. Финал — теорема Цекендорфа. `src/` — источник дека из 16 слайдов с движком и симуляциями, три скрипта `verify_*.py` проверяют модели и биекции перебором.

Дек собирается генератором `build_deck.py` из markdown: смотреть `src/dist/index.html`, править только `src/content/*.md`. Все машинные гейты зелёные, дек прошёл ревью с визуальным контролем. Курс был пилотом формата дека фабрики: уроки ревью и стандарт канваса ушли в `_studio`, а стандарт карточки отсюда потом взяли другие проекты.

Папка заведена 11.07.2026, за 11–12.07 собрана первая лекция: спецификация, движок, дек, биекции для всех восьми моделей. После этого арку закрыли. Вторая и третья лекции не собраны; сложные места первой (явная карта 3-к-1, двойная сумма, тождество Каталана) записаны как материал для сильной группы. Прочитан ли курс, по файлам не видно.

Сюда идти за готовой интерактивной лекцией о Фибоначчи и биекциях для 8–9 класса или за образцом дека «условие → доказательство» с анимацией. Связи: `catalan/` (тот же подход и та же школа), `buffon/` (движок `lab.js`), арка `_studio/zhurnal/2026-07-11_fibonacci-kurs/`.
