## Слой 1 — СТАБИЛЬНЫЙ

### Проект — один абзац
Мини-курс «Числа Фибоначчи» для 179 школы (8→9 класс, лагерь: 2 группы — сильнее/слабее, одна база, две подачи). Профиль **ОТ-КНИГИ**: якорь — листок автора (`istochniki/pdf/Числа_Фибоначчи.pdf`, 15 задач) + книга Benjamin–Quinn «Proofs that Really Count». Курс = 3 лекции; интерактивные слайды, где биекция живёт в canvas. **Throughline:** одно лицо под восемью масками — каждое тождество про Фибоначчи доказывается не индукцией, а красивой биекцией/картинкой.

### Метод — как доказываем
**Двойной счёт / биекция.** Каждое равенство листка = одно множество, посчитанное ДВУМЯ способами → левая часть ↔ правая; ответ один ⇒ равны. **Правило листка** (кроме задачи 5а): нельзя индукция и ссылки на другие тождества — только комбинаторика. Рекурсия-как-конструкция (задача 2б, «первый элемент») разрешена — это построение явного соответствия, не «предположим для n−1». Строгий слой и численная сверка — `kotly/matematika.md` (+ `verify_skelet.py` / `verify_H.py` / `verify_models.py`, все зелёные).

### Охват — ЧТО входит (Лекция 1 = задачи 1–5, ПО ПОРЯДКУ)
**Базовое правило:** идём по листку и закрываем ВСЕ утверждения задач 1–5 по порядку; ничего не паркуем молча. Что не разворачиваем в Л1 — **named-исключение здесь** (с уровнем), а не тихий срез в заходе.

- **Все 8 объектов A–H** (листок, задача 2), каждый — полный слайд по ритму **4 сцены**: определение (дословно из листка) → примеры в СВОём языке при малых n → рекуррента по первому элементу → **биекция с A**.
  A замощения 1×n · B подмножества {1..n−1} без соседних · C коды 0/1 без «00», конец 1 · D композиции n+2 из частей ≥2 · E композиции n+1 из нечётных · F перестановки \|π(i)−i\|≤1 · G зигзаг (a₁≤a₂≥a₃≤…) · H цифры 1–4, старт 1, соседние (длина **n+1** → fₙ).
- **Задача 1** (замощение 2×10 → полоска A) · **Задача 3а** (одно условие на языках всех объектов) · **Задача 3б** (Σfᵢ=f_{n+2}−1) · **Задача 4** (суммы через одну) · **Задача 5 Цекендорф** (финал: жадный + биекция C_n→{1..fₙ}).
- **Обзор «ещё семь объектов»** (две колонки) — оставлен (решение владельца): карта всех восьми до разбора.

**Named-исключения (в Л1 не разворачиваем; уровень «сильной группе / вне-школы», НЕ выкинуто):** явная 3-к-1 карта (з.7б), полный биективный разбор двойной суммы (з.10б), тождество Каталана (з.11г). H даём длиной **n+1** и сдвиг помечаем честно (буквальная длина n даёт f_{n−1}, `matematika` Утв.8). Задачи 6–15 (разрез/Кассини/Люка) — Лекции 2–3, не Л1.

### Наследование фабрики — «дефолт, кроме…»
Дефолт берём как есть: движок-примитивы `src/sims/lab.core.js` (единый canvas-kind `fib-strip`, секвенсор сцен `engine.js`, слайд = КОНФИГ); формат вёрстки `_studio/konvejer/07-verstka`; гейты `build_deck.py` (линтер) + `verify_*`. **Отклонения проекта:**
1. **Каждая модель — в СВОём языке.** Примеры и рекуррента рисуются в родном объекте (C=строки, B=подмножества, F=перестановки, D/E=композиции, G=зигзаг, H=обходы). Полоска-A входит ТОЛЬКО в сцене «биекция». (Отменяет «модель-носитель = полоска везде» из старого STANDART.)
2. **Формат опоры — цветное СЛОВО** (не буквица-цифра). См. формат-отклонения ниже.
3. **Ритм модели — 4 сцены** (пусто → примеры → рекуррента → биекция с A), у КАЖДОГО из 8. Не 3.
4. **Живой self-contained артефакт с первого шага** — ревью только по кликабельному деку (`dist/index.html`, инлайн-шрифты), не по PNG.

### Формат-отклонения (визуальный контракт; токены — `src/tokens.css`)
- **Опорные слова (Р23, новая редакция «цветное слово»):** «Задача N» — `--brick` #bf5b4f + крупный номер по листку; «Определение» — `--cgreen` #7ea474, без номера; «Утверждение» и «Теорема» — **один общий тон `--steel` #8195ad, между собой НЕ различаются** (решение владельца). Слово — Forum caps; формулировка — Noto, ЗАМЕТНО ниже слова, начинается у ЛЕВОГО поля, на всю ширину слайда (не мерная колонка). **Точек в конце абзацев-формулировок нет.** Картинка/канвас — ПОСЛЕ формулировки (порядок всегда ЧТО→как).
- **Сцена «примеры»:** таблица «**n** │ список объектов», n **крупно** слева, объекты той же строки справа; счёт-значение НЕ пишем (видно и так); включаем **n=0** (пустой объект — он один); «0» рисуем чёрным (`--ink`), не горчичным.
- **Сцена «рекуррента»:** интерактив по первому элементу, **бессловесно** (цвет первого элемента + скобка над остатком; ни метки, ни прозы). Связь с f_{n−1}+f_{n−2} проговаривает лектор.
- **Прочее (канон-кандидаты #14):** формулы НЕ разрывать переносом строки; обложка без несогласованных подписей; «доказательство проявляется» (сначала без ключевого элемента → добавить = ответ); единый размер плиток (поворот, не масштаб); подписей к иллюстрациям-доказательствам НЕТ. Раскладку варьировать (Р24), не гнать все слайды «текст-сверху/илл-снизу».
- **Тексты** — Cowork в голосе владельца (`TEKSTY-L1.md`), формулировки и определения из листка ДОСЛОВНО; исполнитель ставит дословно, своей прозы 0 (grep «меняй ленту\|строка меняется» = пусто). БЕЗ russian-editor (директива владельца).
