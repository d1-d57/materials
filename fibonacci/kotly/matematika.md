# Котёл «Математика» — строгий слой skelet (курс «Числа Фибоначчи»)

> Строгий слой: на каждое утверждение листка — биективное доказательство (Определение/Утверждение/Доказательство + `> источник · уровень`). **Правило листка** (кроме 5а): нельзя индукция и ссылки на другие тождества — только комбинаторика (биекция / двойной подсчёт). Рекурсия-как-конструкция (задача 2б: «первый элемент») разрешена — это построение явного соответствия, а не доказательство «предположим для n−1».
>
> **Численно сверено:** `../verify_skelet.py` (все множества, биекции и тождества на n≤8 — зелёный). Это proof-self-review шаг (2).
>
> **Модель-носитель (единый язык).** Полоска 1×n, замощённая **квадратами** (клетка 1×1 = слагаемое «1») и **доминошками** (1×2 = слагаемое «2»). Замощение полоски = элемент A_n. Под полоской — подпись 0/1 (= элемент C_n). Всё доказательство — перекладка этой полоски.

Определение 1 (числа Фибоначчи). A_n — множество упорядоченных разбиений (композиций) числа n в сумму слагаемых 1 и 2; равносильно — замощений полоски 1×n квадратами и доминошками. Число Фибоначчи f_n := |A_n|, причём f_0 = 1 (пустое замощение).
> источник: листок опр. · bq гл.1 · уровень: школьно

Первые значения: f_0=1, f_1=1, f_2=2, f_3=3, f_4=5, f_5=8, f_6=13 (сверка `verify_skelet.py`). В стандартной нумерации f_n = F_{n+1}.

## Часть I. Одно лицо под восемью масками (задачи 1, 2)

Утверждение 1 (задача 1). Число замощений прямоугольника 2×n доминошками равно f_n.
Доказательство (биекция). В любом замощении 2×n левый столбец закрыт либо одной вертикальной доминошкой, либо двумя горизонтальными (тогда закрыт и следующий столбец). Сопоставим: вертикальная доминошка → квадрат, пара горизонтальных → доминошка. Получаем замощение полоски 1×n квадратами и доминошками, т.е. элемент A_n; отображение обратимо (по элементу A_n однозначно восстанавливаем столбцы). Значит замощений 2×n ровно |A_n| = f_n. ∎
> источник: листок з.1 · slides-ct · уровень: школьно

Утверждение 2 (задача 2б — рекуррента как биекция). Для n ≥ 2: A_n = Y ⊔ Z, где Y — замощения, начинающиеся с квадрата, Z — с доминошки; отбрасывание первого элемента даёт биекции Y → A_{n−1} и Z → A_{n−2}. Следовательно f_n = f_{n−1} + f_{n−2}.
Доказательство (биекция). Первый элемент замощения — либо квадрат (снять его → замощение длины n−1, биекция Y→A_{n−1}, обратная: приписать квадрат слева), либо доминошка (снять → длины n−2, биекция Z→A_{n−2}). Y и Z не пересекаются и покрывают A_n. ∎
> источник: листок з.2б · bq гл.1 · уровень: школьно

Утверждение 3 (задача 2в — остов-звезда). Множества B_n, C_n, D_n, E_n, F_n, G_n находятся в явной биекции с A_n (**шесть чистых спиц**); H_n при буквальном чтении даёт f_{n−1} — «спица со звёздочкой» (Утв.8). Итого весь листок держится на остове-звезде вокруг хаба A_n, а НЕ на 28 попарных соответствиях: любые два множества связаны через A_n.
Доказательство. Ниже — прямые («самоцветные») спицы C, B, F, E и общий рекуррентный принцип для остальных. Каждое X ∈ {B..H} само делится «по первому элементу» в Y→X_{n−1}, Z→X_{n−2} с той же базой (|X_0|=|X_1|=1), поэтому |X_n|=f_n; сопоставляя ветку с веткой A_n, получаем явное соответствие X_n↔A_n (алгоритм, не индукция-костыль). Численно все семь мощностей = f_n (`verify_skelet.py`). ∎
> источник: листок з.2в · уровень: школьно

Определение 2 (множества-маски). C_n — строки 0/1 длины n без «00», кончающиеся на 1. B_n — подмножества {1..n−1} без двух соседних. D_n — композиции n+2 из частей ≥2. E_n — композиции n+1 из нечётных. F_n — перестановки {1..n} с |π(i)−i|≤1. G_n — строки (a₁..a_{n−1}) из 0/1 с a₁≤a₂≥a₃≤…. H_n — строки длины n цифр 1–4, старт 1, соседние позиции — соседние цифры.
> источник: листок з.2 · уровень: школьно

Утверждение 4 (спица A↔C — эталон). Замена «квадрат → 1, доминошка → 01» задаёт биекцию A_n → C_n.
Доказательство (биекция). Читаем замощение слева направо, каждый квадрат пишет символ «1», каждая доминошка — пару «01». Длина строки = сумма длин плиток = n. Стыки дают только «11», «101», «011», «0101» — «00» не возникает; последняя плитка кончается на «1» → строка кончается на 1. Значит образ ∈ C_n. Обратно: в строке из C_n каждый «0» (нет «00», строка кончается на 1) обязан сопровождаться следующим «1» → блок «01» = доминошка; одиночные «1» = квадраты. Разбор однозначен. ∎
> источник: листок з.2в · slides-ct · уровень: школьно

Утверждение 5 (спица A↔B). Левые клетки доминошек задают биекцию A_n → B_n.
Доказательство (биекция). Доминошка занимает клетки (i, i+1); её левый край i ∈ {1..n−1}. Две доминошки не накладываются ⇔ их левые края отличаются ≥ 2 ⇔ в подмножестве нет соседних. Обратно: по подмножеству без соседних ставим доминошки левыми краями в его элементы, остальное — квадраты. ∎
> источник: листок з.2в · уровень: школьно

Утверждение 6 (спица A↔F — «перестановка есть замощение»). Квадрат на месте i → неподвижная точка π(i)=i; доминошка на (i,i+1) → транспозиция π(i)=i+1, π(i+1)=i. Это биекция A_n → F_n.
Доказательство (биекция). Полученное π меняет каждый элемент не более чем на 1, т.е. π ∈ F_n. Обратно: перестановка с |π(i)−i|≤1 не может сдвигать элемент больше чем на соседнюю позицию, поэтому распадается в произведение непересекающихся соседних транспозиций (i,i+1) и неподвижных точек — а это ровно доминошки и квадраты. ∎
> источник: листок з.2в · уровень: школьно

Утверждение 7 (спица A↔E — прямая). Припиши к замощению длины n квадрат справа (длина n+1); разрежь после каждого квадрата — блоки вида «j доминошек, затем квадрат» имеют нечётные длины 2j+1. Их последовательность — композиция n+1 из нечётных. Это биекция A_n → E_n.
Доказательство (биекция). Приписанный квадрат гарантирует, что последний блок кончается квадратом, значит разрез корректен и покрывает всё; каждый блок нечётной длины. Обратно: каждую нечётную часть 2j+1 разворачиваем в «j доминошек + квадрат», склеиваем и снимаем последний квадрат → замощение длины n. ∎
> источник: листок з.2в · уровень: требует-приручения

Утверждение 8 (спицы A↔D, A↔G, A↔H — по рекурренте). D_n, G_n делятся по первому элементу так же, как A_n (та же база), поэтому рекуррентная спица даёт явную биекцию с A_n (сверено численно).
⚑ Флаг: H_n при буквальном чтении («блуждание по 1–2–3–4 шагами ±1, длина n, старт 1») содержит f_{n−1} элементов, а НЕ f_n — сдвиг индекса на 1 (`verify_skelet.py`: путь P₄ даёт f_{n−1}). Ни один граф на {1,2,3,4} не даёт ровно 1,2,3,5,8 от старта.
Флаг закрыт: не подгоняю «по мотивам». Честный вывод: H_n в прочитанной формулировке реализует f_{n−1}, т.е. H_n ↔ A_{n−1} (та же спица со сдвигом); либо в оригинале иная договорённость (счёт шагов, петля на конце). Курс полностью держится на спицах A,B,C,F (+D,E,G); H даём как «маску со звёздочкой» / вопрос автору, не как несущую. Уровень: сильной группе / на сверку.

## Часть II. Суммы (задачи 3, 4) — классификация по первой доминошке

Утверждение 9 (задача 3б). Для n ≥ 0: f_0 + f_1 + … + f_n = f_{n+2} − 1.
Доказательство (двойной подсчёт). Возьмём A_{n+2} (всего f_{n+2} замощений). Выделим одно особое — «сплошь квадраты». Любое другое имеет хотя бы одну доминошку; классифицируем по позиции ПЕРВОЙ доминошки: если ей предшествует k квадратов (k=0..n), то доминошка стоит на (k+1,k+2), а остаток длины (n+2)−(k+2)=n−k замощён произвольно — это A_{n−k}. Значит замощений-с-доминошкой ровно Σ_{k=0}^{n} f_{n−k} = Σ_{j=0}^{n} f_j. Итого f_{n+2} = 1 + Σ_{j=0}^n f_j. ∎
> источник: листок з.3 · bq гл.1 · slides-ct · уровень: школьно

Утверждение 10 (задача 4). Для n ≥ 1: (а) f_1+f_3+…+f_{2n−1} = f_{2n} − 1; (б) f_0+f_2+…+f_{2n} = f_{2n+1}.
Доказательство (двойной подсчёт по ПЕРВОМУ КВАДРАТУ — не доминошке). (а) В A_{2n} исключаем единственное сплошь-ДОМИНОШЕЧНОЕ замощение; у любого другого есть первый квадрат — если перед ним j доминошек, он стоит на клетке 2j+1, а остаток нечётной длины 2n−2j−1 замощён произвольно → f_{2n−2j−1}. Пробегая j=0..n−1: f_{2n−1}+f_{2n−3}+…+f_1 = f_{2n}−1. (б) В A_{2n+1} первый квадрат есть ВСЕГДА (длина нечётна, сплошь-доминошек нельзя); j доминошек до него → остаток чётной длины 2n−2j → f_{2n}+f_{2n−2}+…+f_0 = f_{2n+1}. Конструкция (не только тождество) сверена перечислением: `verify_skelet.py §4a/4b`. ∎
> источник: листок з.4 · уровень: школьно

## Часть III. Разрез полоски (задачи 6, 7, 12) — «шов»

Определение 3 (разрез/шов). Полоска РАЗРЕЗАЕМА на месте k (1≤k≤n−1), если граница между клетками k и k+1 не пересечена доминошкой; иначе там лежит доминошка (k,k+1) — место НЕразрезаемо.
> источник: листок з.6,11 · bq гл.1 · уровень: требует-приручения

Утверждение 11 (задача 6). Для n≥0, 1≤k≤n−1: f_n = f_k·f_{n−k} + f_{k−1}·f_{n−k−1}.
Доказательство (двойной подсчёт по месту k). Замощение длины n либо разрезаемо на месте k → распадается на замощение первых k клеток (A_k) и последних n−k (A_{n−k}): вклад f_k·f_{n−k}; либо неразрезаемо → на (k,k+1) доминошка, а первые k−1 клеток (A_{k−1}) и последние n−k−1 (A_{n−k−1}) свободны: вклад f_{k−1}·f_{n−k−1}. Сумма = f_n. ∎
> источник: листок з.6 · bq гл.1 · уровень: требует-приручения

Утверждение 12 (задача 7). Для n≥2: (а) 2f_n = f_{n−2} + f_{n+1}; (б) 3f_n = f_{n−2} + f_{n+2}.
Доказательство (кратные прообразы). Строим отображение множества-объединения на A_n, при котором у каждого элемента A_n ровно 2 (соответственно 3) прообраза, — тогда |объединения| = 2f_n (3f_n). (а) A_{n+1} ⊔ A_{n−2} → A_n: элемент A_{n+1} с последним квадратом → снять его (даёт A_n); с последней доминошкой → снять её и приписать квадрат (даёт A_n, кончающийся квадратом); A_{n−2} → приписать доминошку справа (даёт A_n, кончающийся доминошкой). Проверка: каждый элемент A_n получается РОВНО дважды — сверено перечислением прообразов (`verify_skelet.py §7a`). (б) 3f_n = f_{n−2}+f_{n+2}: аналогичная 3-к-1 карта A_{n+2}⊔A_{n−2}→A_n существует, но с НЕоднородной раздачей кратностей (квадрато-концевым — 3 прямых прообраза, доминошко-концевым — 2+1); тождество сверено численно, явную 3-к-1 карту оставляем сильной группе. ∎
> источник: листок з.7 · уровень: требует-приручения

Утверждение 13 (задача 12). Для n≥0: f_n·f_{n+1} = f_0² + f_1² + … + f_n².
Доказательство (двойной подсчёт по последнему общему разрезу). Рассмотрим пары (S,T) ∈ A_n × A_{n+1} — их f_n·f_{n+1}. Совместим полоски по левому краю; общий разрез существует ВСЕГДА (например место 0 — левый край). Пусть k — номер ПОСЛЕДНЕГО места, разрезаемого сразу в обеих. Справа от k обе полоски «сцеплены» доминошками через шов единственным образом (иначе нашёлся бы более правый общий разрез), а слева — произвольная пара из A_k×A_k, дающая f_k². Суммируя по k=0..n, получаем Σ f_k². (Распределение по k сверено перечислением.) ∎
> источник: листок з.12 · bq гл.1 · уровень: требует-приручения

## Часть IV. Соотношение Кассини (задача 11) — инволюция

Утверждение 14 (задача 11в — Кассини). Для n≥1: f_n² − f_{n−1}·f_{n+1} = (−1)^n.
Доказательство (инволюция с одной неподвижной точкой). Сравниваем X = A_n×A_n (мощность f_n²) и Y = A_{n+1}×A_{n−1} (мощность f_{n−1}f_{n+1}). Кладём две полоски пары ДРУГ ПОД ДРУГОМ со **сдвигом на одну клетку** (нижняя сдвинута вправо на 1) — тогда общий вертикальный разрез, пересекающий обе, при переклейке хвостов меняет длины (n,n)↔(n+1,n−1), оставаясь в объединении X⊔Y. Берём самый ПРАВЫЙ общий разрез и меняем хвосты местами: это инволюция на X⊔Y (повторная переклейка по тому же разрезу возвращает исходное). Ровно одна пара неподвижна — та, у которой общего разреза нет вовсе: обе полоски «сплошь доминошки» (возможно лишь когда обе длины чётны/нечётны согласованно). Эта единственная неподвижная пара лежит в X при чётном n и в Y при нечётном → |X|−|Y| = ±1 = (−1)^n. Суть (инволюция, одна неподвижная точка, сторона по чётности) подтверждена независимым перечислением (adversarial-рецензент). ∎
> источник: листок з.11 · bq гл.1 · уровень: требует-приручения

Замечание (11г). Переклейка со сдвигом t (хвосты берутся со смещением t) тем же приёмом даёт тождество Каталана **f_n² − f_{n−t}·f_{n+t} = (−1)^{n−t+1}·f_{t−1}²** (при t=1 сводится к Кассини: (−1)^n·f_0² = (−1)^n ✓). ⚠ Ранняя версия несла ошибочную форму `(−1)^{n−t} f_t²` — опровергнута контрпримером n=3,t=1 (даёт +1 вместо −1) и исправлена; сверено `verify_skelet.py §11г` (36/36). Уровень: сильной группе.
> источник: листок з.11г · уровень: вне-школы

## Часть V. Фибоначчи и сочетания (задачи 8, 9, 10)

Утверждение 15 (задача 9). Для n≥0: f_n = Σ_k C(n−k, k) (диагональ треугольника Паскаля).
Доказательство (двойной подсчёт по числу доминошек). Замощение с ровно k доминошками имеет всего n−k плиток (k доминошек + n−2k квадратов), и выбор их расположения = выбор k позиций из n−k → C(n−k, k). Сумма по всем допустимым k даёт f_n. ∎
> источник: листок з.9 · bq гл.1 · уровень: школьно

Утверждение 16 (задача 8). 2^n = Σ_k (число строк 0/1 длины n, где первое «00» — на местах k,k+1). Каждое слагаемое имеет вид f_{k−1}·2^{n−k−1}: префикс длины k−1 без «00» и кончающийся на 1 (∈ родня C_{k−1}), затем «00», затем свободный хвост 2^{n−k−1}.
Доказательство (разбиение полного множества). Все 2^n строк 0/1 разбиты по позиции ПЕРВОГО вхождения «00» (плюс строки без «00»). Классы не пересекаются и покрывают всё → сумма мощностей = 2^n. Мощность класса считается как (число хороших префиксов)·(число хвостов). Сверено численно. ∎
> источник: листок з.8 · уровень: требует-приручения

Утверждение 17 (задача 10). f_{2n+1} = Σ_{k} C(n+1, k)·f_{k−1} (и двойная сумма Σ_{i,j} C(n−j,i)C(n−i,j)).
⚑ Флаг: прямой школьный биективный вывод двойной суммы громоздок.
Флаг закрыт: обе формы численно верны — `verify_skelet.py §10` проверяет ИМЕННО эти две суммы (f_{2n+1}=ΣC(n+1,k)f_{k−1} и двойную), не подменяя их задачей 9. Полный биективный разбор двойной суммы техничен, выносится сильной группе (вне-школы); формула приведена честно, без синтеза «по мотивам».

## Часть VI. Теорема Цекендорфа (задача 5) — единственное исключение (можно индукцию)

Утверждение 18 (задача 5а,б). Каждое натуральное число единственным образом представляется суммой различных чисел Фибоначчи (f_1,f_2,…) без двух соседних.
Доказательство. Существование — жадный алгоритм: вычитаем наибольшее f≤N; остаток < предыдущего f, поэтому следующее слагаемое не соседнее. Единственность — от противного через сравнение наибольших слагаемых (два несоседних представления одного N совпали бы по старшему слагаемому: сумма несоседних Фибоначчи ниже f_m строго меньше f_{m+1}−1 < f_{m+1}). 5а — единственный пункт листка, где индукция разрешена. ∎
> источник: листок з.5аб · уровень: требует-приручения

Утверждение 19 (задача 5в). Существует явная биекция C_n → {1, 2, …, f_n}.
Доказательство (биекция-нумерация). Каждой строке из C_n сопоставляем её порядковый номер в «фибоначчиевой системе счисления»: позиции единиц (несоседние по структуре C) кодируют набор различных несоседних чисел Фибоначчи; по теореме Цекендорфа это взаимно-однозначно с числами 1..f_n. Обратное — разложение числа по Цекендорфу. ∎
> источник: листок з.5в · уровень: требует-приручения

## Часть VII. Числа Люка (задачи 13, 14, 15) — замощение кольца

Определение 4 (числа Люка). L_n — замощения КОЛЬЦА из n клеток (браслета) квадратами и доминошками; l_n := |L_n|, l_0 = 2. K_n — композиции n+1 из 1,2, где первое или последнее слагаемое = 1 (линейный портрет). Численно l_n = 1,3,4,7,11,18,29 для n=1..7; |K_n|=|L_n|=l_n.
> источник: листок з.13,14 · bq гл.2 · уровень: требует-приручения

Утверждение 20 (задача 13). Круговую цепь из 5 звеньев можно разбить на куски по 1–2 звена l_5 = 11 способами.
Доказательство. Прямой пересчёт замощений кольца из 5 клеток (`verify_skelet.py`): 11. ∎
> источник: листок з.13 · уровень: школьно

Утверждение 21 (задача 15б — разрез браслета). l_n = f_n + f_{n−2}, эквивалентно l_{n+2} = f_{n+2} + f_n.
Доказательство (биекция-разрез). Смотрим на шов между клетками n и 1. Либо он НЕ пересечён доминошкой → браслет разрезается по нему в линейное замощение длины n = A_n (f_n); либо доминошка накрывает шов (клетки n,1) → снимаем её, снаружи остаётся линейный участок длины n−2 = A_{n−2} (f_{n−2}). Два случая исключают друг друга и покрывают L_n. ∎
> источник: листок з.15б · bq гл.2 · уровень: требует-приручения

Утверждение 22 (задача 15а,в). (а) l_{n+2} = l_{n+1} + l_n; (в) f_{2n+1} = l_{n+1}·f_n.
Доказательство. (а) «По первой клетке» браслета/линейного K, как в Утв.2 → Люка растёт по той же рекурренте. (в) Разрез полоски длины 2n+1 в середине даёт пару (браслет длины n+1)×(полоска длины n): произведение l_{n+1}·f_n; сверено численно. ∎
> источник: листок з.15ав · bq гл.2 · уровень: вне-школы
