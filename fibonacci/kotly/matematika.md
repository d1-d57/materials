# Котёл «Математика» — строгий слой skelet (курс «Числа Фибоначчи»)

> Растёт в стадии 3 из карточек котла математика в строгий слой: на КАЖДОЕ утверждение листка — Определение / Утверждение / Доказательство-биекция / Источник / Уровень. Мат-долг — `⚑ Флаг:` → `Флаг закрыт:`. Гейт G3 «математика верна». Правило листка: доказательства комбинаторные (биекция / двойной подсчёт), без индукции и без ссылок на другие тождества.

*(наполняет Стадия 3 «skelet»)*
