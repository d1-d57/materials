# START-HERE — курс «Числа Фибоначчи» (вход для Cowork)

> **Свежая сессия Cowork:** прочитай ЭТО + `../_studio/COWORK.md`, войди в активную арку — и веди владельца по стадиям (`ARKA §10`). Не читай лишнего.

## Что это
Мини-курс «Числа Фибоначчи» — комбинаторно-**биективный** взгляд (как на числа Каталана): каждое тождество про Фибоначчи доказывается НЕ индукцией и не формулами, а красивой биекцией/картинкой. Превращаем листок в **интерактивный** материал: доказательства + слайды, где биекция живёт в canvas (слева меняешь → справа меняется соответствующее).

## Профиль и циферблаты (выставлено на входе, до шага 1)
- **Профиль: ОТ-КНИГИ** (`../_studio/docs/spravka/PROFILI-CIFERBLATY.md` — Фибоначчи буквально её пример): содержание уже в одной книге → ресёрч почти не нужен, якорь = книга → сразу разбор → тонкая матбаза → HTML.
- **Масштаб: курс, 3 лекции** (лёгкий полюс — ОДИН растущий источник = листок, не тяжёлый рекурсивный концепт-курс).
- **Строгость: тонкая** (биекции, не формальная машинерия). **Слайды: да** (интерактивные).
- **Аудитория:** 179 школа, 8→9 класс; на лагере 2 группы (сильнее/слабее) — **одна база, две подачи** (разный темп). Всего 6 занятий = 3 лекции × 2 группы.
- **Интерактив биекций** → шаг 9 фабрики, ветка «плоский интерактив → canvas + `lab.js`» (уже есть в `../buffon/`).
