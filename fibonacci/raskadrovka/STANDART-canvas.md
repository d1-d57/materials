# Стандарт «двузонный canvas» — дистиллят (курс «Числа Фибоначчи»)

> Переиспользуемый на лекциях 2–3. Выведен из референса владельца (`istochniki/pdf/Комбинаторные тождества.pdf`, стр. 8–9) и §3 захода Л1. Эталон-реализация — спица **A↔B** (подмножество↔полоска), `slides/s08-subset.html` + режим `subset` в `sims/lab.core.js`.

## Шесть правил стандарта
1. **Две зоны разделены ФОНОМ, без подписей.** Светлое поле (`--paper`) сверху — короткое условие «что делаем». Цветная полоса (`--board`) снизу — сам canvas, без слов. *(Разрыв фоном уже даёт сетка слайда: `.copy` на бумаге + `.board` синий — трогать не нужно.)*
2. **Соответствие — ВЫРАВНИВАНИЕМ.** Образ строго под своей клеткой: код-цифра под плиткой, лунка — под левым краем доминошки, дуга — между центрами соседних клеток. Плюс лёгкая подсветка пары (число снизу ↔ доминошка сверху) — тонкий коннектор, не везде.
3. **Обе стороны РЕДАКТИРУЕМЫ**, где осмысленно (`data-editimg="1"`): клик по образу правит ту же полоску. Верх и низ — два входа в одно состояние.
4. **Ограничение — во ВВОДЕ, не в тексте.** Подмножество: соседние лунки к занятой гаснут (нельзя два подряд), клик по ним — фидбек-кольцо, не действие. Код: «0» структурно тянет «1» (доминошка = блок «01», одиночный «0» не собрать). Правило показывает интерактив.
5. **Один canvas — весь путь объекта** (определение → примеры → рекуррента → биекция); меняется только что показано (сцены), геометрия заморожена.
6. **Клик по полоске сохранён:** клик по плитке — доминошка распадается на два квадрата / два квадрата сливаются; так добираемся до любого замощения (связность движений проверена).

## Ритм каждого объекта (сцены, плавно)
(1) определение сверху → (2) примеры при малых n руками через генератор → (3) **рекуррента как canvas** (верх фикс. длины n ↔ низ «квадрат + объект n−1» / «доминошка + объект n−2») → (4) биекция X↔A, выведенная из рекурренты. Рекуррента и суммы — ТОТ ЖЕ формат (одна сторона фикс., другая пробегает).

## Переиспользуемые примитивы (в `sims/lab.core.js`; слайд = КОНФИГ, не новый код)
Один canvas-kind `fib-strip`; слайд задаёт только атрибуты, кода не пишет:

| атрибут | значения | что делает |
|---------|----------|-----------|
| `data-sim="fib-strip"` | — | подключает движок |
| `data-mode` | `recur`·`code`·`subset`·`perm`·`sum`·`firstsq`·`cassini` | какой образ рисуется под полоской |
| `data-n` | целое | длина полоски (число клеток) |
| `data-editimg` | `"1"` | включает редактируемый НИЗ + ограничение-во-вводе |

Внутренние примитивы (общие для всех режимов):
- **`layout(parts,cy)` + `cellCenterX`/`boundaryX`** — единая колоночная геометрия; образ берёт `x0/u` полоски → выравнивание «под клеткой» бесплатно.
- **`drawStrip`** — рендер полоски (зелёный квадрат `--cgreen` / горчичная доминошка `--mustard`), опц. подсветка плитки.
- **`toggleAt` (пиксель) / `toggleCell` (модель)** — правка полоски; `toggleCell(parts,p,preferRight)` = семантика левого края доминошки.
- **`drawImage`** — образ, выровненный по колонкам; собирает `st._hit` (зоны клика низа) для редактируемых режимов.
- **`toggleImage` + `flashAnim`** — двусторонняя связка + микрофидбек «нельзя» (кольцо, ~320 мс).

## Как добавить новый объект-спицу на Л2–Л3
1. Если образ выражается через полоску — добавить ветку в `drawImage` (и, для редактируемого, в `toggleImage`), выровнять по `cellCenterX/boundaryX`. 2. Слайд-конфиг: `<canvas data-sim="fib-strip" data-mode="НОВЫЙ" data-n="..">`. 3. Ритм 4 сцен (см. выше). НЕ писать bespoke-canvas на слайд — это провал критерия масштабируемости (§3 захода).
