## Задача 1 — замощение доски
**Надзаголовок:** Задача 1
**Условие (листок):** Сколькими способами можно разрезать доску 2×10 на доминошки?

- сцена 1 — условие + пустая доска 2×10.
- сцена 2 — одно замощение доски (канвас).
- сцена 3 (связка, верх): Разбиение восстанавливается по верхней строке. Оставим только её — полоску 1×10 из квадратов и доминошек.

## A — Модель A (полоска)
**Надзаголовок:** Определение
**Верх (листок, дословно):** Aₙ — упорядоченные разбиения числа n в сумму единиц и двоек. То же самое — замощения полоски 1×n квадратами и доминошками. Число таких замощений обозначим fₙ, положим f₀ = 1.

- сцена «примеры»: выписаны все замощения для n = 0, 1, 2, 3, 4 (канвас).
- сцена «счёт»: 1, 1, 2, 3, 5. Это числа Фибоначчи.
- **Надзаголовок:** Утверждение · сцена «рекуррента»: fₙ = fₙ₋₁ + fₙ₋₂. *(канвас: первая плитка — квадрат или доминошка; без подписи)*
- сцена «биекция»: полоска A — сама себе образец (эталон, к которому приведём остальные). *(канвас; без подписи)*
- закладка (верх, тихо): у доски 2×10 замощений f₁₀ = 89.

## Обзор — ещё семь объектов (две колонки)
**Надзаголовок:** Определение
**Верх:** Те же числа Фибоначчи считают и другие объекты. Вот ещё семь.

**Левая колонка (списком, определения — из листка дословно):**
- Bₙ — подмножества множества {1, …, n−1}, в которых нет двух соседних элементов
- Cₙ — последовательности длины n из нулей и единиц без двух нулей подряд, оканчивающиеся на 1
- Dₙ — упорядоченные разбиения числа n+2 в сумму слагаемых, больших 1
- Eₙ — упорядоченные разбиения числа n+1 в сумму нечётных слагаемых
- Fₙ — перестановки π множества {1, …, n}, для которых |π(i) − i| ≤ 1
- Gₙ — последовательности (a₁, …, a_{n−1}) нулей и единиц, для которых a₁ ≤ a₂ ≥ a₃ ≤ a₄ ≥ …
- Hₙ — последовательности длины n цифр от 1 до 4, где вначале стоит 1 и рядом стоят соседние цифры

**Правая узкая голубая колонка:** по одному примеру каждого объекта при n = 5 (канвас).
**Низ (связка):** Дальше разберём их по одному. У каждого — то же определение → примеры → та же рекуррента → соответствие с полоской.

## B — Модель B (подмножества)
**Надзаголовок:** Определение
**Верх (листок):** Bₙ — подмножества множества {1, …, n−1}, в которых нет двух соседних элементов

- сцена «примеры»: все подмножества для n = 0, 1, 2, 3, 4 (канвас) → 1, 1, 2, 3, 5.
- **Надзаголовок:** Утверждение · «рекуррента»: смотрим, входит ли крайний элемент. Нет — остаётся Bₙ₋₁; да — сосед запрещён, остаётся Bₙ₋₂.
- сцена «биекция»: подмножество ↔ полоска (левый край доминошки — выбранный элемент). *(канвас; без подписи)*

---

## C — Модель C (коды)
**Надзаголовок:** Определение
**Верх (листок):** Cₙ — последовательности длины n из нулей и единиц без двух нулей подряд, оканчивающиеся на 1

- сцена «примеры»: все последовательности для n = 0, 1, 2, 3, 4 (канвас) → 1, 1, 2, 3, 5.
- **Надзаголовок:** Утверждение · «рекуррента»: смотрим на первый символ. Единица — впереди Cₙ₋₁; ноль — за ним обязана идти единица, впереди Cₙ₋₂. Значит fₙ = fₙ₋₁ + fₙ₋₂.
- сцена «биекция»: код ↔ полоска (квадрат — «1», доминошка — «01»). *(канвас; без подписи)*

---

## D — Модель D (разбиения на слагаемые больше 1)
**Надзаголовок:** Определение
**Верх (листок):** Dₙ — упорядоченные разбиения числа n+2 в сумму слагаемых, больших 1

- сцена «примеры»: все разбиения для n = 0, 1, 2, 3, 4 (канвас) → 1, 1, 2, 3, 5.
- **Надзаголовок:** Утверждение · «рекуррента»: смотрим на первое слагаемое. Двойка — отбрасываем её, впереди Dₙ₋₂; больше двойки — уменьшаем на единицу, впереди Dₙ₋₁.
- сцена «биекция»: разбиение ↔ полоска (по той же рекурренте). *(канвас; без подписи)*

---

## E — Модель E (разбиения на нечётные)
**Надзаголовок:** Определение
**Верх (листок):** Eₙ — упорядоченные разбиения числа n+1 в сумму нечётных слагаемых

- сцена «примеры»: все разбиения для n = 0, 1, 2, 3, 4 (канвас) → 1, 1, 2, 3, 5.
- **Надзаголовок:** Утверждение · «рекуррента»: смотрим на первое слагаемое. Единица — отбрасываем её, впереди Eₙ₋₁; больше (значит не меньше трёх) — уменьшаем на два, впереди Eₙ₋₂.
- сцена «биекция»: разбиение ↔ полоска (каждая нечётная часть 2j+1 — это j доминошек и квадрат). *(канвас; без подписи)*

---

## F — Модель F (перестановки)
**Надзаголовок:** Определение
**Верх (листок):** Fₙ — перестановки π множества {1, …, n}, для которых |π(i) − i| ≤ 1

- сцена «примеры»: все перестановки для n = 0, 1, 2, 3, 4 (канвас) → 1, 1, 2, 3, 5.
- **Надзаголовок:** Утверждение · «рекуррента»: смотрим на первый элемент. π(1) = 1 — впереди Fₙ₋₁; π(1) = 2 (тогда π(2) = 1) — впереди Fₙ₋₂.
- сцена «биекция»: перестановка ↔ полоска (неподвижная точка — квадрат, соседняя транспозиция — доминошка). *(канвас; без подписи)*

---

## G — Модель G (зигзаг)
**Надзаголовок:** Определение
**Верх (листок):** Gₙ — последовательности (a₁, …, a_{n−1}) нулей и единиц, для которых a₁ ≤ a₂ ≥ a₃ ≤ a₄ ≥ …

- сцена «примеры»: все последовательности для n = 0, 1, 2, 3, 4 (канвас) → 1, 1, 2, 3, 5.
- **Надзаголовок:** Утверждение · «рекуррента»: смотрим на первый символ. Единица тянет за собой единицу — впереди Gₙ₋₂; ноль снимается — впереди Gₙ₋₁ (в зеркале 0 ↔ 1).
- сцена «биекция»: зигзаг ↔ полоска (по той же рекурренте). *(канвас; без подписи)*

---

## H — Модель H (цифры 1–4)
**Надзаголовок:** Определение
**Верх (листок, с поправкой длины):** Hₙ — последовательности цифр от 1 до 4, где вначале стоит 1 и рядом стоят соседние цифры *(в листке длина n даёт fₙ₋₁; берём длину n+1 — тогда ровно fₙ)*

- сцена «примеры»: все последовательности для n = 0, 1, 2, 3, 4 (канвас) → 1, 1, 2, 3, 5.
- **Надзаголовок:** Утверждение · «рекуррента»: по первому шагу — впереди Hₙ₋₁ или Hₙ₋₂.
- сцена «биекция»: обход ↔ полоска (по той же рекурренте). *(канвас; без подписи)*

## Пуанта
**Верх:** У всех объектов одна и та же рекуррента и одно и то же начало: |X₀| = |X₁| = 1, дальше fₙ = fₙ₋₁ + fₙ₋₂. Значит все они считают числа Фибоначчи.
- сцена-бонус (тихо): мало того — между любыми двумя есть и прямое соответствие. *(канвас Xₙ↔Aₙ; без подписи)*
