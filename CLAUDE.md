## Три вида папок

`_studio/` — **фабрика** (как делать: стандарты, конвейер, борд) · `_generator/` — **движки** (`build_doc.py` — документ, `build_deck.py` — слайды) · остальные — **проекты** (карта: `README.md` §3).

## Четыре правила, которые нарушают чаще всего

1. **HTML — только готовым генератором** (`_generator/`). Новый не писать; чего не хватает — дорабатывать.
2. **После сборки документа — гейт:** `python3 _generator/tools/check_view.py <src>` (ловит «текст съеден при отрисовке»; в формулах писать `\lt`/`\gt`, не `<`/`>`).
3. **Иллюстрация — по словарю** `_studio/konvejer/09-illustracii/SLOVAR-primitivov.md`. Взял примитив, вышло плохо → **чинить словарь**, а не только свой рисунок.
4. **Предпосылку проверяй по живым файлам** — включая свою и включая написанную владельцем. Ложна → скажи с доказательством, не гоняйся за фантомом.
