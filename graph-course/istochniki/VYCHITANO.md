## 1. Гуровиц В. М., Ховрина В. В. «Графы» — МЦНМО, 2009, 32 стр. (серия ШМК №2)
Локально: `istochniki/pdf/graf_02-Grafy.pdf`. **ПОЛНЫЙ текст** (проверено — Оглавление на стр. 32 совпадает с реальным содержимым файла: Предисловие(3) → Занятие 1(5) → Занятие 2(12) → Занятие 3(16) → Занятие 4(22) → Разные задачи(27) → Ответы(29) → Приложение формальных определений(30) → список литературы(31)). Скан-OCR (ABBYY), `pdftotext` не извлекает текст из-за нестандартной кодировки шрифта (PDFXC30-Identity) — вычитано ВИЗУАЛЬНО постранично через Read.

**Занятие 1 «Знакомство с графами. Степень вершины»** (стр. 5–11, 6–7 кл.).
ЕСТЬ: граф как модель (пример «9 домов-соседей» → путь через граф; пример с фишками на пятиугольнике → граф-цикл, инвариант «нельзя переставить две фишки, не трогая нить»); определение графа/вершины/ребра/степени/чётной-нечётной вершины; задачи 1–6: 9 планет (граф связности), 4 коня 3×3 (граф позиций — коня можно двигать только по рёбрам «дистанция хода коня», доказательство через инвариант чётности перестановки), цифры 0–9 в ряд с условием на сумму (эйлеров путь в графе!), кабели/рёбра-подсчёт (2 варианта: лемма о рукопожатиях), 15 городов степень ≥7 → связность (принцип Дирихле на графе), мальчики-девочки на дискотеке (двойной подсчёт, неравное число).
→ **A** (двойной подсчёт/степени, задачи 4,6), **C** (пример с 4 конями и цифрами 0–9 — по сути обходы/пути в специально построенном графе, не классический Кёнигсберг, но тот же язык), **D** (граф связности — задача 1,5).

**Занятие 2 «Двудольные графы. Лемма о рукопожатиях»** (стр. 12–15).
ЕСТЬ (по заголовку раздела и оглавлению; текст не вычитан построчно в этом заходе — визуальный проход остановлен на стр. 11, остаток по названию раздела).
→ **A**, двудольность — смежный кластер D/H (не расписан детально, для второго прохода).

**Занятие 3 «Основные понятия. Обходы»** (стр. 16–21) и **Занятие 4 «Деревья»** (стр. 22–26) — по оглавлению присутствуют полностью, НЕ вычитаны построчно в этом заходе (только заголовки подтверждены).
→ **C** (обходы, занятие 3), **E** (деревья, занятие 4) — кандидаты для прицельной вычитки следующим заходом.

**ЧЕГО НЕТ:** планарность/формула Эйлера, раскраски, турниры, ДНВ, игры-как-графы — книга строго про вход (степень/двудольность/обходы/деревья), это первая брошюра серии, авторы сами пишут о продолжении для старших.
Мост подтверждён явно текстом: задача 3 занятия 1 (расстановка цифр 0-9 по условию делимости суммы) — авторский комментарий прямо называет её «представителем ещё одного класса задач [...] расстановки чисел» через граф, не называя эйлеров путь по имени — скрытый ярлык зафиксирован.

## 2. Шаповалов А. В. «Принцип узких мест» — МЦНМО, 2-е изд. 2008, 32 стр.
Локально: `istochniki/pdf/shapovalov_uzkoe.pdf`. **ПОЛНЫЙ текст** (текстовый слой корректный, `pdftotext` работает; сквозная постраничная нумерация 3→31 подтверждена, включая доп. главу «Двенадцать задач», добавленную во 2-м издании).

Далее (по оглавлению, не процитировано построчно) — вероятно главы про экстремальный принцип и раскраску как отдельные разделы, плюс новая глава «Двенадцать задач».
**ЧЕГО НЕТ (в вычитанном фрагменте этого захода):** дальше примера 6 (стр. 8+) текст не процитирован построчно — общая структура/название всех глав не выписаны, только первые две.
→ **K** (ДНВ — прямое попадание, авторский термин «засада на переправе» СОВПАДАЕТ с формулировкой в project_text_v4.md §3, подтверждает мост на уровне первоисточника, а не только вторичного пересказа), **B** (раскраска Г-поворотов — пример 3, раскраска-как-доказательство).
