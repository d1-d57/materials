## 4. Как продолжать (рабочий цикл)
Этот чат — **аналитик**: планирует и принимает, код НЕ пишет. Исполнитель — **Claude Code**, работает по «заходу» (самодостаточный файл `ZAHOD-NN.md`) с пустым контекстом. Цикл:
1. Обсудить идею с автором → (для анимаций) собрать прототип-виджет прямо в чате, обкатать вид.
2. Написать `ZAHOD-NN.md` по скиллу **`agentic-coding-session-brief`** (риск-фазы, дисциплина Карпатова, гейты, верификатор, точные тексты/цели).
3. Автор запускает заход в Claude Code (модель — первой строкой сообщения; `opusplan` для судительных задач, Sonnet для механики).
4. Принять отчёт по ГЕЙТАМ (критерий · границы · время+токены · нет тихого недобора · верификатор зелёный); аналитик дополнительно сверяет по коду.
5. Записать вердикт в `WORKLIST.md`, обновить этот `HANDOFF.md`.

## 5. Ключевые решения (с обоснованием)
- **Не рефакторить дек — точечные правки + документация.** Код уже на контракте скилла (4 блока, движок verbatim), плотно закомментирован; рефактор = риск сломать ровно то, чего автор боится.
- **Системные баги чинятся в ОДНОМ месте (ядро/CSS), не по слайду** (G1–G6). Корень «канвас не стартует / замирает / стартует с середины» — мёртвый `settle()` (движок шёл в обход) + само-стоп на `target`; починено в жизненном цикле (`activate`→`settle`, `endless`, `measure`).
- **Золото — сигнал** (ответ/reveal/спотлайт), им НЕ заливать всё. Толчковый (мигающий между сценами) жирный → цвет `.acc`; постоянный жирный — оставить.
- **Анимации по СМЫСЛУ, без обобщений** (просьба автора): без линейности матожидания, всегда равные части.
- **Анимация cos-area иллюстрирует УЖЕ написанный текст p4–p6** слайда; математику `S=2` не трогали (S=2 — вся область, показанная четверть = 1).

## 7. Gotchas (грабли)
- **В песочнице Cowork НЕТ браузера** — аналитик не может рендерить/смотреть глазами, только грепом по коду. Визуальную проверку делает Claude Code (системный Chrome через `channel="chrome"`; playwright-браузер не качается без сети).
- **`index.html` — 2.8 МБ, очень длинные строки** (вшитые шрифты/base64). Грепать УЗКО, исключая `data:image`/`data:font`; целиком Read не тянет.
- **Якориться по `id`/сигнатуре, НЕ по номеру строки** — строки сместились после трёх заходов. Номера в `WORKLIST §5` — ориентир прошлой версии, не истина.
- **Блок `[4]` ENGINE — verbatim.** Движок `activate()` сам поднимает `data-sim`-канвасы; не трогать.
- **Канон-пример скилла проваливает свой же `audit.py`** (5 пред-существующих FAIL: title/coin/condition/thanks). `audit exit 0` недостижим без нарушения границ — приняты как ограничение; кандидаты на правку скилла — `WORKLIST §3`.
- **Ветка не влита в `main`.** Свежая сессия: `git checkout buffon-zahod-01`, `git log` — сверить коммиты.
