## 3. Идеи на будущее / кандидаты в скилл

Скилл `html-slides-studio` из этой сессии **read-only** (менять — только через Настройки → Capabilities). Здесь копим, что занести, чтобы дефекты не воспроизводились в будущих деках:

- **Канон канваса (G3).** Базовый `Lab` должен ГАРАНТИРОВАТЬ autostart-from-zero + reset-on-reentry + no-self-stop единообразно. Сейчас каждый sim реализует по-своему → регрессы и init-баги. Вынести в жизненный цикл ядра (`settle()`/`onEnter`), не в патч.
- **Единый механизм подсветки (G5).** Класс-акцент цветом вместо `<b>`; подсветка «что изменилось» между сценами. Убрать bold-акцент из канона (сдвигает вёрстку).
- **Инвариант масштаба (G1).** Общий токен «шаг разлиновки» для всех боковых канвасов + хелпер геометрии (периметр = 1 ⇒ сторона = 1/n).
- **Инвариант цвета пересечения (G2).** Единая функция `cross ? red : blue`, запрет прочих цветов для бросаемых объектов.
- **Золото ответов (G4).** blur-reveal по умолчанию раскрывается акцентным золотом.
- **`audit.py` — доп. проверки:** «канвас стартует с нуля», «нет bold-акцента в теле», «ответ раскрывается золотым».
- **Канон-пример проваливает свой же `audit.py`** (5 FAIL в `buffon-canon-EXAMPLE`: title/coin/condition/thanks — переполнение и box-shadow/radius). Тогда гейт «audit exit 0» недостижим без нарушения границы «не переписывать». → либо привести пример в соответствие своему аудиту, либо в скилле явно пометить эти проверки как advisory (WARN, не FAIL) для перегруженных текстом слайдов, чтобы приёмка не спотыкалась о заведомое.
- **Харнес рендера жил в эфемерном `scratchpad/` исполнителя** — после его сессии харнеса нет, а у ревьюера в песочнице браузер не ставится в лимит времени → визуальную приёмку нечем сделать. → харнес (`shot.py`) + набор PNG ключевых слайдов класть в папку проекта как артефакт приёмки (не в /tmp), чтобы следующий агент смотрел картинки без пересборки браузера.

## 5. Диагностика кода (research, 2026-07-04)

Аудит ядра `lab.js` + движка `[4]`. Правок не делали — только диагноз. Это то, что чинить в ОДНОМ месте (иначе баги вернутся).

**Жизненный цикл канваса — корень G3:**

1. **`settle()` — мёртвый код.** Задуман «покой при входе», но не вызывается ниоткуда (`grep '.settle(' `→ пусто). Вход на слайд идёт через `activate(justShown)` (L1268) → напрямую `pause()+reset()+play()` (L1276), в обход `settle()`. Поэтому пер-sim покой не работает — в частности преролл convergence `throwN(100)` в `Conv.settle` (L1352) не запускается → график с нуля (слайд 5). **Fix:** `activate` должен звать `settle()` (sim переопределяют его), либо перенести преролл в `reset`/`onScene`; мёртвый код убрать.
2. **Само-остановка на `target`.** `play()` встаёт при `n>=target && !endless` (L940). autoTarget низкие: coin 200, circle 100, result 120, polygons 110, prob 500 — и ни у кого `endless`. Отсюда «стоит на 200», «нарисовано 120», «идёт и сам останавливается». **Fix:** experiment-канвасам `endless:true` (стоп только рукой автора).
3. **Сброс-на-возврате есть, но незаметен.** Слайд прячется `display:none` → `MutationObserver` (L1285) ловит повторный показ и делает reset+play. Механизм рабочий; «с середины» — следствие п.2 (успел добежать и встать). После `endless` станет наглядно.
4. **Init-race** (yellow «не включился с первого раза»): размеры канваса берутся раз в конструкторе из `clientWidth` (L818), без повторного замера при показе. Первый показ при неготовой вёрстке → 0/дефолт. **Fix:** мерить размеры в момент показа (в `activate`).

**Масштаб — G1:** `spacing` в px вразнобой (список в Q1) + circle использует `H/12`, остальные фикс-px. **Fix:** единый принцип для всех боковых канвасов.

**Цвет — G2:**
- **yellow:** две «другие» стороны треугольника рисуются `C.steel` (синие), L1088. Нужны оранжевая + зелёная. **Блокер:** `tokens()` (L797) НЕ пробрасывает `--cgreen`/`--corange` (они есть в CSS L29, но в объект `C` не попали). → сперва добавить их в `tokens()`.
- **coin:** круги только `brick`/`steel` (stamp L1565, contours L1574) — жёлтого в коде нет. «Жёлтый круг» проверить рендером (вероятно, мустардовая линия уровня 2/π или артефакт вспышки, не круг).

**Вывод для захода:** порядок — сначала системный слой (оживить `settle`/единый lifecycle + `endless` + `tokens` с зел/оранж + принцип масштаба), затем пер-слайдовые правки поверх.
