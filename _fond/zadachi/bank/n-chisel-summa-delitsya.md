## Условие
Докажите, что для любого целого n ≥ 3 можно найти n различных натуральных чисел, сумма которых делится на каждое из них.

## Решение
Три числа найти легко: 1, 2, 3 — сумма 6 делится и на 1, и на 2, и на 3.

Дальше — шаг. Пусть есть набор из n различных чисел a₁, …, aₙ с суммой S, делящейся на каждое из них. Построим набор из n + 1 числа: удвоим все прежние и добавим ещё одно число 2S.

Новая сумма равна 2S + 2S = 4S. Она делится на каждое из чисел 2aᵢ, потому что S делилось на aᵢ; и делится на 2S. Все числа по-прежнему различны, а 2S больше любого из 2aᵢ, потому что S больше каждого aᵢ.

Начав с 1, 2, 3, получаем 2, 4, 6, 12; затем 4, 8, 12, 24, 48 — и так далее до любого n.

**Для преподавателя.** Индукция здесь не доказывает существование, а **строит** объект: из ответа для n делается ответ для n + 1. Самопроверка у ученика полная — он может выписать свой набор и поделить сумму на каждое число столбиком. Хорошо ставить рядом с задачами, где индукция доказывает свойство: пусть увидит разницу между «доказали, что бывает» и «предъявили, как получить».
