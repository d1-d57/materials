## Условие
Сколько существует попарно неизоморфных деревьев на шести вершинах? Нарисуйте их все.

## Ответ
6.

## Решение
В дереве на шести вершинах пять рёбер, сумма степеней равна десяти. Переберём по наибольшей степени d.

d = 5. Звезда: одна вершина соединена со всеми остальными. Один вид.

d = 4. Центр с четырьмя соседями, к одному из соседей подвешена шестая вершина. Один вид.

d = 3. Пусть v — вершина степени 3. Удалим её: дерево распадается на три части общим размером пять вершин, каждая часть — дерево с максимальной степенью не больше 3, висящее на v. Размеры частей: 3 + 1 + 1, 2 + 2 + 1, 1 + 1 + 3 — то есть с точностью до порядка либо (3, 1, 1), либо (2, 2, 1). Тройка сама бывает двух видов: цепочка из трёх вершин, прицепленная к v концом, и цепочка, прицепленная серединой, — но во втором случае у прицепленной вершины степень 3, и получается дерево с двумя вершинами степени 3 (две «тройки», соединённые ребром). Итого три вида: ветки (3, 1, 1) цепочкой, ветки (2, 2, 1), и дерево с двумя вершинами степени 3.

d = 2. Все степени не больше двух — это цепочка. Один вид.

Всего 1 + 1 + 3 + 1 = 6.
