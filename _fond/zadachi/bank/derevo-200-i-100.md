## Условие
В дереве имеется 200 вершин степени 5, 100 вершин степени 3, а остальные — висячие. Сколько висячих вершин в этом дереве?

## Ответ
702.

## Решение
Пусть висячих вершин x. Всего вершин 200 + 100 + x, значит рёбер на одно меньше: 299 + x.

Теперь посчитаем сумму степеней всех вершин двумя способами. С одной стороны, каждое ребро даёт по единице в степень каждого из своих концов, поэтому сумма степеней равна удвоенному числу рёбер: 2(299 + x). С другой стороны, она равна 200 · 5 + 100 · 3 + x · 1 = 1300 + x.

Приравниваем: 1300 + x = 598 + 2x, откуда x = 702.

Двойной подсчёт здесь работает в паре с фактом «в дереве на n вершинах ровно n − 1 ребро». Без него уравнение было бы одно на два неизвестных, поэтому вспомнить этот факт (и понимать, почему он верен) — половина задачи.
