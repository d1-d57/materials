## Условие
Разложите на множители: xy + x + y + 1; a³ − b³; x³ − 1; n³ − n.

А теперь вернитесь к трём местам, где это уже понадобилось: (1) в задаче про a + b + ab получилось (x + y + 1)⁄xy — что будет, если прибавить единицу? (2) 2p + 1 = k³, где p простое; (3) верно ли, что n⁴ + 4 составное при n > 1?

## Решение
xy + x + y + 1 = x(y + 1) + (y + 1) = (x + 1)(y + 1). Группировка: вынести из первой пары, из второй, увидеть общую скобку.

a³ − b³ = (a − b)(a² + ab + b²); отсюда x³ − 1 = (x − 1)(x² + x + 1).

n³ − n = n(n² − 1) = (n − 1)n(n + 1) — произведение трёх подряд идущих, поэтому делится на 6.

(1) 1 + (x + y + 1)⁄xy = (xy + x + y + 1)⁄xy = (x + 1)(y + 1)⁄xy. Вот почему величина «произведение всех (1 + a)» и не меняется.

(2) 2p + 1 = k³ ⇒ 2p = k³ − 1 = (k − 1)(k² + k + 1). Второй множитель больше первого и больше 2, поэтому k − 1 = 2, k = 3, p = 13.

(3) n⁴ + 4 = n⁴ + 4n² + 4 − 4n² = (n² + 2)² − (2n)² = (n² − 2n + 2)(n² + 2n + 2). При n > 1 первый множитель больше единицы — число составное. Здесь та же разность квадратов, которую вы знаете, просто её пришлось создать.
