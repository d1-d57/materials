## Условие
В каждом из трёх доказательств есть ошибка. Найдите её.

**(а)** Утверждение: если треугольник разбит на n треугольников, то хотя бы один из них не остроугольный.

*База.* При n = 2 верно: два угла новых треугольников дополняют друг друга до развёрнутого, значит один из них не острый.
*Шаг.* Рассмотрим треугольник, разбитый на n треугольников. Разобьём один из них на два. Один из двух новых треугольников не остроугольный, значит утверждение верно и для n + 1.

**(б)** Утверждение: любые n точек лежат на одной прямой.

*База.* При n = 1 и n = 2 верно: через любые две точки проходит прямая.
*Шаг.* Возьмём точки p₁, …, pₙ₊₁. По предположению первые n точек лежат на прямой l, а последние n — на прямой l′. Прямые l и l′ имеют две общие точки p₂ и pₙ, значит совпадают. Стало быть, все n + 1 точек лежат на одной прямой.

**(в)** Утверждение: если в связном графе на n вершинах степень каждой вершины не меньше двух, то при удалении любого ребра он остаётся связным.

*База.* При n = 3 верно: из треугольника можно убрать ребро, связность сохранится.
*Шаг.* Возьмём граф на n вершинах и добавим ещё одну. Если из неё выходит хотя бы два ребра, то при удалении любого из них она остаётся соединённой со старым графом. А при удалении ребра старого графа он остаётся связным по предположению индукции.

## Решение
**(а)** Шаг доказывает не то. Он показывает: если разбиение на n треугольников получено делением одного треугольника из разбиения на n − 1, то всё в порядке. Но не всякое разбиение на n треугольников так получается — есть разбиения, которые не сводятся к меньшему делением одного куска. Индукция обязана уметь разбирать **любой** объект размера n, а не только те, что построены нашим шагом.

**(б)** Шаг ломается ровно один раз — при переходе от n = 2 к n = 3. Тогда «первые два» и «последние два» пересекаются только по одной точке p₂, а двух общих точек у прямых l и l′ нет. Одна цепочка порвалась в самом начале, и дальше всё рушится.

**(в)** Здесь ошибка серьёзнее: **само утверждение ложно.** Возьмём два треугольника и соединим их одним ребром. Степень каждой вершины не меньше двух, граф связен, но соединяющее ребро — мост, и после его удаления граф распадается.

А шаг неверен по той же причине, что и в пункте (а): не всякий граф с n + 1 вершиной получается из графа с n вершинами, у которого все степени не меньше двух, добавлением одной вершины. Убрав вершину из графа примера, мы нарушим условие про степени.

**Для преподавателя.** Прямое продолжение «всех коров одного цвета», которое сработало на занятии №9. Пункты идут по возрастанию: (б) — сломанная цепочка, ошибка в одном переходе; (а) — шаг строит не все объекты; (в) — то же самое, но вдобавок утверждение попросту неверно, и его контрпример полезнее любого разбора. Просить не только «где ошибка», но и **что именно доказывает это рассуждение, если оно вообще что-то доказывает.**
