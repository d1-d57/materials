## Условие
Сколько остовов имеет граф с вершинами V_0, ..., V_n и 2n − 1 рёбрами, где вершина V_0 соединена рёбрами с остальными вершинами, и при 1 ≤ i < n соединены ребром вершины V_i и V_{i+1}?

## Ответ
Число Фибоначчи с чётным номером: F_{2n}. Первые значения: 1, 3, 8, 21, 55.

## Решение
Рёбра V_iV_{i+1} назовём ободом, рёбра V_0V_i — спицами. Обозначим через a_n искомое число, a_0 = a_1 = 1.

**1. Блоки.** Выбранные рёбра обода разбивают номера 1, ..., n на блоки идущих подряд номеров: внутри блока все рёбра обода взяты, между блоками — нет.

**2. Сколько спиц.** Если блоков k, то рёбер обода взято n − k. Всего в остове должно быть n рёбер, значит спиц ровно k. При этом в каждый блок обязана вести ровно одна спица: без спицы блок отвалится от V_0, а с двумя спицами замкнётся цикл.

**3. Подсчёт.** Блок длины s даёт s способов выбрать спицу — по вершине, в которую она идёт. Значит a_n равно сумме произведений s_1 · ... · s_k по всем разбиениям числа n на упорядоченные слагаемые.

**4. Рекуррента.** Отделим последний блок: если его длина s, то он даёт множитель s, а всё остальное — разбиение числа n − s. Отсюда a_n = 1·a_{n−1} + 2·a_{n−2} + ... + n·a_0.

**5. Короткий вид.** Записав ту же сумму для a_{n−1} и вычтя, получаем a_n − a_{n−1} = a_{n−1} + a_{n−2} + ... + a_0, и ещё раз вычтя аналогичное равенство для a_{n−1}, приходим к a_n = 3a_{n−1} − a_{n−2} при n ≥ 3, где a_1 = 1, a_2 = 3.

**6. Ответ.** Рекуррента x_n = 3x_{n−1} − x_{n−2} с началом 1, 3 — это в точности числа Фибоначчи чётных номеров: F_2 = 1, F_4 = 3, F_6 = 8, F_8 = 21, F_10 = 55. Значит a_n = F_{2n}.

Маленькие случаи считаются руками и подтверждают: 1, 3, 8, 21, 55.
