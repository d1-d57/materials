## Условие
На прямой отмечены четыре точки: 0, 1, 2, 3. Частица стоит в точке 0. За один ход она переходит в соседнюю отмеченную точку — влево или вправо; уйти за крайние точки нельзя.

(а) Сколько существует различных траекторий длиной в n ходов? Посчитайте для маленьких n и угадайте ответ.

(б) Докажите его.

(в) А если отмеченных точек пять — 0, 1, 2, 3, 4? Посчитайте и объясните, почему ответ устроен иначе.

## Ответ
(а) 1, 1, 2, 3, 5, 8, 13, 21, … — числа Фибоначчи.
(в) 1, 1, 2, 3, 6, 9, 18, 27, … — здесь каждое число втрое больше того, что стояло двумя шагами раньше.

## Решение
**(б)** Обозначим через f(v, n) число траекторий длиной n, выходящих из точки v. Нас интересует f(0, n).

Из точки 0 первый ход только один — в точку 1, поэтому f(0, n) = f(1, n − 1). Из точки 1 ходов два: f(1, n) = f(0, n − 1) + f(2, n − 1).

Теперь главное — **симметрия**. Замена v ↦ 3 − v переводит наши четыре точки в себя и сохраняет соседство, значит f(2, n) = f(1, n) и f(3, n) = f(0, n). Подставим:

f(1, n) = f(0, n − 1) + f(1, n − 1) = f(1, n − 2) + f(1, n − 1).

Это в точности правило чисел Фибоначчи. Начальные значения f(1, 0) = 1, f(1, 1) = 2 дают 1, 2, 3, 5, 8, …, а f(0, n) = f(1, n − 1) сдвигает последовательность на шаг: 1, 1, 2, 3, 5, 8, …

**(в)** Для пяти точек симметрия v ↦ 4 − v тоже есть, но у неё появляется неподвижная точка — середина 2, и середина живёт по своему правилу: f(2, n) = 2 f(1, n − 1). Вместе с f(1, n) = f(0, n − 1) + f(2, n − 1) и f(0, n) = f(1, n − 1) это даёт уже не Фибоначчи, а утроение через два шага: 1, 1, 2, 3, 6, 9, 18, 27.

**Для преподавателя.** Задача-двойник того, что разбиралось на занятии №10: снова Фибоначчи вылезают там, где их не ждали, но объект совсем другой — не коды и не подмножества, а траектории. Пункт (в) — настоящая исследовательская развилка: считать одинаково легко, а ответы разные, и причина именно в том, что у пятиточечного отрезка есть центр. Проверка у ученика в руках: обе последовательности он получает перебором за десять минут.
