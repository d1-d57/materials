## Условие
В стране Графинии n (n > 2) городов. Некоторые города соединены беспосадочными авиалиниями (по каждой авиалинии выполняются рейсы в обоих направлениях) таким образом, что из любого города можно самолётами (возможно, с пересадками) добраться до любого другого, но закрытие любой авиалинии нарушает это свойство. При этом из любого города выходит не больше d авиалиний. Докажите, что все города Графинии можно разбить не более чем на n/2 + d групп таким образом, чтобы каждая авиалиния соединяла города из разных групп и для любых двух групп существовало не более одной авиалинии, соединяющей города из этих групп.

## Решение
**1. Это дерево.** «Граф связен, но удаление любого ребра рушит связность» — в точности одно из равносильных определений дерева. Значит сеть авиалиний есть дерево T, и все степени в нём не больше d.

**2. Двудольность.** Дерево двудольно: покрасим вершины в чёрный и белый так, чтобы соседи были разного цвета. Пусть чёрная доля не меньше половины; тогда белых вершин не больше n/2.

**3. Белые группы.** Каждой белой вершине отведём отдельную персональную группу. Таких групп не больше n/2.

**4. Лемма о раскраске чёрных.** В дереве с максимальной степенью не больше d чёрные вершины можно покрасить в d цветов так, чтобы любые две чёрные вершины с общим соседом получили разные цвета.

Индукция по числу вершин. Возьмём белую вершину x; её соседи y_1, ..., y_k чёрные, и k ≤ d. Удаление x разбивает дерево на k меньших деревьев, в каждом из которых лежит ровно одна из вершин y_i. К каждому применим предположение индукции. Осталось согласовать: цвета внутри каждого куска можно переставить как угодно, поэтому переставим их так, чтобы y_1, ..., y_k получили попарно различные цвета — это возможно, так как цветов d ≥ k. Условие для пар с общим соседом внутри куска сохранено, а единственная новая пара «общий сосед» — это пары среди y_i, и они теперь разноцветны.

**5. Разбиение.** Группы: по одной на каждую белую вершину и по одной на каждый из d цветов чёрных. Всего не больше n/2 + d. Каждое ребро соединяет белую с чёрной, то есть города из разных групп.

**6. Между парой групп не больше одной линии.** Пусть рёбра a_1b_1 и a_2b_2 (a — белые, b — чёрные) соединяют одну и ту же пару групп. Белые группы одноэлементны, значит a_1 = a_2. Тогда b_1 и b_2 — соседи одной вершины, и они лежат в одной группе, то есть одного цвета. По лемме две чёрные вершины с общим соседом одного цвета быть не могут, кроме случая b_1 = b_2. Значит это одно и то же ребро.
