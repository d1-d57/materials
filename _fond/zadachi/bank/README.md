# Банк задач — формат

> Одна задача = один файл. HTML — **артефакт**: правится банк или манифест, не выход. Движок — `../../../_generator/build_listok.py`.
>
> ⚠ Статус: **прототип на согласовании** (30.07.2026). Заведён вместе с первым живым листком `ucheniki/danya/dz/dz-posle-04`. Если формат утверждается — переезжает в `_studio/docs/spravka/` и получает гейт; если нет — сносится вместе с движком, потерь на два файла.

## Карточка задачи — `bank/<id>.md`

```markdown
---
id: avtobiograficheskoe-chislo     # = имя файла без .md; латиницей
tema: konstruktiv                  # чем задача является
priyom: ekonomiya-perebora         # каким ходом берётся — ось поиска
uroven: 6-7
otvet: 6210001000                  # ЛИБО bez_otveta: da (для «докажите»)
proverka: perebor 2026-07-30       # чем ответ подтверждён и когда
status: gotova                     # kandidat | gotova | otklonena
istochnik: ...
---

## Условие
Единственная обязательная секция.

## Подсказка
Показывается открытым текстом (врезка слева).

## Ещё подсказка
Под катом.

## Ответ
Под катом.

## Решение
Под катом.
```

Ключи фронтматтера — **только латиницей и в нижнем регистре** (та же регулярка, что у `build_doc.py`). Секции — по `## `; их набор фиксирован, лишние движок молча пропустит.

**Два поля — гейт, а не украшение.** `otvet` (или явное `bez_otveta: da`) и `proverka` обязательны: без них сборка падает. Причина в `../../../ucheniki/METOD.md` — «ученик не должен получить неверный ключ»; поле `proverka` заставляет назвать, чем именно ответ подтверждён.

## Манифест листка — рядом с учеником

Лежит там, где артефакт: `ucheniki/<кто>/dz/dz-posle-04.md`.

```markdown
---
vid: dz
kicker: Математика
zagolovok: Домашнее задание
data: 30 июля 2026
pokazyvat: usloviya          # usloviya | podskazki | polnyj
---

## Задачи

- avtobiograficheskoe-chislo
- zhuki-5x5 | podskazka        # переопределить показ для одной задачи
- ★ doska-nxn-raznost-sosedej  # звёздочка вместо номера
- mantel-30-uchenikov | -      # ничего кроме условия
```

Режимы показа:

| `pokazyvat` | что попадает в вид | для чего |
|---|---|---|
| `usloviya` | только условия | ДЗ ученику |
| `podskazki` | + подсказки | ДЗ с трудными задачами |
| `polnyj` | + ответы и решения под катом | лист занятия для себя |

Один и тот же банк, три вида — это и есть защита от расползания: HTML не источник.

## Сборка

```
python3 _generator/build_listok.py <манифест.md> [-o out.html] [--lint]
```

`--lint` — проверить банк и манифест, ничего не собирая. Падает на: неизвестном `pokazyvat`, отсутствующем id, задаче без `## Условие`, пустых `otvet`/`proverka`.

## Чего движок пока НЕ умеет

Названо честно, чтобы не выглядело готовым:

- **интерактивной проверки ответа** (`<input>` + сверка) — она есть в руками собранных файлах Максима, здесь нет; добавляется полем `otvet` + одним блоком JS, но пока не сделано за ненадобностью Дане;
- **формул** — KaTeX не подключён, математика идёт текстом (для 6–7 класса пока хватало);
- **карточек Miro** — PNG режутся отдельно; естественное следующее применение того же банка;
- **тем под ученика** — стиль один (бумажный), у Максима свои рубрики `Указание / Ответ / Решение`.
