# Курс «Математика компьютеров» — ключевые решения

> «Математика компьютеров» — рабочее название одной из идей-кандидатов; центральная идея ещё не зафиксирована.

## Принятые

1. **Тип курса.** Математика для широкой аудитории, НЕ история науки/инженерии. В центре каждой лекции — теорема/вычисление, проделываемое в зале, + доказуемый обзорный кусок (à la Райгородский). Математика — на стыке элементарной и высшей, закрывает лакуны перед встречей с серьёзной математикой.
2. **Двухслойная структура.** Заход — настоящее («вот эта штука у тебя в кармане»); позвоночник — исторический мир (эпоха, города, война, машины, кочующие люди). Математика нарочно разная в каждой лекции — лёгкая, но удивляющая.
3. **Временна́я рамка ~1936–1950** («рождение компьютера»). Курс «разной красивой прикладной математики» укладывается до 1950 с запасом (9+ сюжетов; кочующая троица фон Нейман / Тьюринг / Шеннон). Актуальность живёт в хуке, не в дате математики. Три темы форсируют выход за рамку: P vs NP (1971), современная крипта/RSA (1977; якорь — Энигма), глубокие сети (перцептрон 1958; якорь — Маккаллок–Питтс 1943) — решаются флешбеком/якорем. Рамка гибкая в обе стороны (флешбек вниз к Кантору, флеш-форвард в современность).
4. **Связность = мир, не последовательность.** Сквозная нить + паутина рифм между ЛЮБЫМИ лекциями (не линейно, чем больше — тем лучше); цель — «всё происходит в одном мире», лекцию можно пропустить. Держат связь математические рифмы (сила автора), а не биография; персонажи возвращаются подмигиванием. Мета-рифма — универсальность/сводимость («одна вещь, к которой сводится всё»): машина Тьюринга, полнота ЛП, NP-полнота, аппроксимация сетей. → P=NP живёт хвостом лекции про ЛП.
5. **Арка внутри лекции.** Формат «зарождение идеи → применение» живёт ВНУТРИ одной лекции (не разнесён по частям, как в книге). Мастер-арка «вещь-в-себе → объединяющее → прикладное → в кармане» — двусторонняя (часть сюжетов стартует с прикладного: фанера → ЛП). Разные форматы и разная математика по лекциям — фича.
6. **Соучастие зала — центральная проблема автора.** В математической части автор держит зал (вопрос→ответ), в нарративе теряет. Дихотомия «нарратив/математика» ложная — переменная одна: есть ли у зала что додумать. Годный вопрос — мини-задача с путём рассуждения (не угадайка-факт, не наброс). Движок — обыденное понятие с глубиной (как тервер/Ереван). Приёмы: прогноз-перед-раскрытием (Мазур), провокация неверной интуиции, голосование руками, спорный вопрос, микро-задача в истории. Не оставлять зал без дела дольше ~2 минут. Биография — подмигиванием.
7. **Решётка слоёв** (`sloi-arhitektura.md`) — рабочая система отбора: позиционирование + вертикаль (внутри лекции) + форма + горизонталь (мир) + система пол/баланс. Курс амортизирует слои: лекция может быть слабее сама по себе, важен баланс курса. База для гейтов-баллов (Ф2).
8. **Система оценки тем — гейты и баллы** (Ф2; рабочий инструмент → [`sistema-ocenki.md`](sistema-ocenki.md)). Решётку слоёв (п.7) операционализировали в единый механизм; собран из всех источников критериев, провалидирован (Монте-Карло + вычислимость) и откалиброван на пуле 16. Решённое, чего не было в каноне:
   - **Гибрид.** Ворота (бинарные ✅/❌) отсекают как пол, баллы ранжируют выживших, баланс — на уровне набора. Каждый ворот = **наблюдаемый факт о лекции** (есть/нет конкретная вещь), не впечатление.
   - **Баллы — грубая 0–3 без весов.** Чисел 0–10 не вводим (ложная точность). Читаем как **квадрант A×B** и ранжируем **к эталону Монте-Карло** (Pugh: лучше/=/хуже), не по абсолютной сумме. Каждый критерий дожимаем к якорному дескриптору «3 = портрет эталона» (рычаг «куда дожимать» — вместо весов).
   - **Ось A «продаваемость»** (A1–A5: killer-заголовок, ширина, драма-лица, визуал-вау, вписанность в имя-центр) — надстройка, которой в Пл.4 не было: мерит «почему КУПЯТ» (до курса) отдельно от оси B «качество» (почему ДОВОЛЬНЫ, во время). **Режиссёрское правило:** A → вход/название, B → тело.
   - **Discovery-fiction-афорданс** — различающий keystone-движок: тему можно подать как *переоткрытие* (естественный вопрос → почти-очевидные шаги → результат, с честными тупиками). Восстанавливает мастер-арку эпизода; за один сигнал метит ядро по драме/соучастию/честности/квизу. **Не** история науки (ложится на п.1); цена 2–5× → «одно ядро руками» (Г1).
   - **Ворота набора:** Н1 «≤2 дорогих»; Н2 **антология-с-throughline** (throughline-как-**мотив** ✅ / throughline-как-**зависимость** = скрытый season-arc ❌); Н3 контекст; Н4 покрытие разных областей.
   - **Двойной счёт разведён:** честность обещания = только ворот Г8 (не балл B); квиз-аффорданс = движок отбора **темы** (≠ ворот соучастия Г6 — тот про подачу).

   - **Курс — задача УПАКОВКИ:** тема зарабатывает слот ПЛОЩАДЬЮ КОНТАКТА (сколько объединяющих линий зажигает); сироты выселяются, плотное вытесняет рыхлое. Сшивка — целевая функция, не украшение.
   - **Типизированные квоты (§14.3, проваливаемые):** 5–8 ДЕЙСТВУЮЩИХ ЛИЦ (портреты на сайт) ×2–5 лекций · ≥3 сквозных через ≥5 · ≥6 через ≥4 · ≥10 парных · каждая лекция ≥5 нитей · ≥4 типа · 0 сирот. Типы нитей: люди / места / эпоха-событие / страна / мат-идеи-теории / рифмы / формат-арки / в-кармане.
   - **Слои + единство-в-разнообразии (§14.4–14.5):** каждая лекция заполняет большинство слоёв; каждый слой МЕЖДУ лекциями когерентен — унисон ИЛИ дополняющее разнообразие; плохо только рассогласование.    - **Шкала 0→4** (было 0–3): во все балльные таблицы добавлен «4 = эталонно, на голову выше 3»; тянем к 4. (Заменяет «0–3» из п.8.)
   - **Критерий = МАКСИМАЛЬНЫЙ ЧЕСТНЫЙ ПРОХОД (§14.7), не обязательный 100%:** выжать максимум, честно метить «здесь 3, не 4, потому что…»; **анти-фабрикация (§14.9)** — фейковая связь хуже честного недобора; изолированный судья иной модели проверяет связи на реальность.
