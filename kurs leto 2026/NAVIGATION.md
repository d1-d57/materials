# НАВИГАЦИЯ — единственный индекс проекта

Мозг архива и **единственный** список файлов: куда идти по типу работы, куда дописывать новую мысль, и у кого «источник правды». Полный вход в контекст — `COWORK.md` (Правило №0).

> **⚙️ Правило регистрации (enforced).** Любой новый / удалённый / переименованный `.md` получает строку здесь ТЕМ ЖЕ ходом. **Документ-сирота = не существует.** Ловит `tools/check_docs.py` (0 сирот · 0 битых ссылок · индекс покрывает все .md · NFC-имена · нет абс-путей). *(Чекер заводится заходом Code этой арки.)*

## Возобновляешь работу?
→ `1-START-HERE/dnevnik-i-plan.md`, разделы «Текущее состояние» и «Ближайший шаг».

## Правило
Любая новая мысль обязана получить дом по таблицам выше — иначе теряется. Что осталось только в журнале сессии — **не существует**: в конце сессии разнеси осевшее по домам (ритуал — `COWORK.md §6`, закрытие арки — `ARKA.md §7`). Каждый новый док — строку сюда тем же ходом; целостность проверяет `tools/check_docs.py`.
