# СИСТЕМА ОЦЕНКИ ТЕМ — гейты и баллы (единый механизм, Ф2)

_Один знаменатель: ТЗ курса (из чего состоит идеальная лекция и набор) и формальная оценка — в одном. Через него гоняем конкретные идеи лекций/наборов до идеальных сюжетов. Draft арки; durable → `1-START-HERE/` на закрытии (поглощает `sloi` Пл.4 + пул-баллы)._

**Механика (решения владельца):** гибрид — ворота отсекают, баллы ранжируют; шкала грубая **0–3 без весов**; читаем как **квадрант A×B** и ранжируем **к эталону** (Монте-Карло), не по абсолютной сумме.

## 0. Поток (как пользоваться)
1. **Ворота лекции** (§2) — все ✅? Нет → тема выбыла или на доработку (или флаг «связка», §5).
2. **Баллы** (§3) — оценить по осям A и B (0–3/критерий) → профиль-полоса, не оракул.
3. **Движки** (§4) — отметить различающие сигналы.
4. **Позиция и роль** (§5) — поставить в плоскость A×B относительно эталона, назначить роль.
5. **Набор из 6** — прогнать ворота набора + баланс (§6).

## 1. Рамка (под что настроено)
Аудитория — культурный багаж образованного человека, **НЕ айтишники** (ширина = условие выручки). Функция — стык элементарной/высшей, закрытие лакун. Курс, не доклад — важен баланс, не пик каждой лекции. Коммерческий приоритет — продаётся ДО (название/лендинг), радует ВО ВРЕМЯ (тело); оси A и B мерят это **раздельно**.

Временна́я рамка — рождение компьютера (~1936–1950); актуальность живёт в крючке, не в дате; математика **нарочно разная** по лекциям (`resheniya` п.2–3). Подъёмность за час: **одно ядро переоткрывается руками** (Г1), тяжёлое — подмигиванием. Уровень/время — настройка отбора, не балл.

## 2. ВОРОТА (HARD, бинарные ✅/❌ — не баллы)
Отсекают негодное разом; провал любого → выбыл или доработка. Минимум присутствия, не степень. Каждый ворот формулируем как **наблюдаемый факт о лекции** (есть/нет конкретная вещь), не как впечатление — это и есть «объективность ворот».

**Лекция (8):**
| # | Ворот | ✅ если |
|---|---|---|
| Г1 | Матядро | есть теорема/вычисление, проделываемое в зале |
| Г2 | Крючок-заход | есть сегодняшнее «в кармане», видимое вокруг |
| Г3 | Драматургия + «ого» | есть эмоц. арка и хотя бы один момент удивления |
| Г4 | Пересказуемая фраза | есть одна мысль, которую унесут и перескажут |
| Г5 | Честное упрощение | облегчённая версия не стала враньём |
| Г6 | Петля соучастия | зал не без дела дольше ~2 мин (есть что **додумать**) |
| Г7 | Автор тянет | понимает, как рассказать И доказать |
| Г8 | Честность обещания | даёт понимание, не мнимый навык (защита от «ошибки тервера») |

**Набор (4):**
| # | Ворот | ✅ если |
|---|---|---|
| Н1 | ≤2 дорогих | дорогих по подготовке не больше двух (нейросети — согласованный дорогой) |
| Н2 | Единство (антология-с-throughline) | каждая лекция держится **сама** (можно пропустить, порядок гибкий) **И** набор — один мир: центр-заголовок + мотивы + кочующие люди + контекст + мета-рифма. Связь НЕ порядковая: throughline-как-**мотив** (рифма всплывает в разных лекциях) ✅, throughline-как-**зависимость** (лекция требует предыдущей = скрытый season-arc) ❌ |
| Н3 | Контекст | каждая вписана в «математику компьютеров» (эпоха/люди/событие/идея) |
| Н4 | Покрытие | набор закрывает РАЗНЫЕ области математики (не 6 про одно) |

_Ворот может пройти **условно:** пограничное ✅ пишем с условием в строку «что докрутить» (напр. Г7 ✅, если ядро держится на доказуемом, а тяжёлая часть идёт подмигиванием). Условие — граница скоупа, не баллы._

## 3. БАЛЛЫ — две оси, 0–3, без весов
Только «чем больше — тем лучше» свойства, где темы различаются по степени. Шкала: **0** нет · **1** слабо · **2** крепко · **3** эталонно. Оси независимы, между собой не складываются — тема это точка (A, B).

**Каждый критерий дожимаем к своему «3» — якорному дескриптору эталона** (колонка «3 =»): «3» это не «высокий балл вообще», а конкретный портрет идеала по этому критерию, к которому тему и тянем. Чисел 0–10 не вводим (ложная точность, которую убрали не зря); грубые полосы + якорь работают на «куда дожимать».

**Ось A — Продаваемость** (почему КУПЯТ; до курса):
| | Мерим | «3» = |
|---|---|---|
| A1 | Killer-заголовок | суперинтерес виден из названия |
| A2 | Ширина аудитории | цепляет далеко за айтишников |
| A3 | Драма и лица | персонажи/история — готовое топливо анонса |
| A4 | Визуальный вау | красиво уже в промо |
| A5 | Вписанность в имя-центр | усиливает пакет «математики компьютеров» |

**Ось B — Качество** (почему ДОВОЛЬНЫ; во время):
| | Мерим | «3» = |
|---|---|---|
| B1 | Самоценность/глубина | богатое поле идей; уносят, даже забыв выкладки |
| B2 | Теор. содержание | плотная доказуемая математика, не «разговор вокруг» |
| B3 | Домашка руками | сильный код/крафт, который доделывают дома |
| B4 | Интерактив | есть что тыкать/решать на лекции |

_Визуал двухуровневый: «вау-картинка» → A4 (промо); «визуализация, дающая понимание» → читается в B1/B4 (не в A)._

_Честность обещания НЕ здесь — она ворот Г8 (бинарный минимум), чтобы не считать дважды._

## 4. Различающие движки (не баллы — сигналы для близких случаев и хабов)
Отмечаем ⊕ / – / сильный; разрешают ничьи и метят ядро:
- **Квиз-аффорданс** — тема афордит рассуждение-к-идее (мини-задачи), а не угадайку/факты. Критерий отбора **темы** (≠ ворот соучастия Г6 — тот про подачу).
- **Обыденное понятие с глубиной** — тема берёт бытовое слово (информация, случайно, оптимально…) и вскрывает смысл. Сильнейший генератор соучастия и квиз-вопросов.
- **Двойная ценность** — тема ещё и хороший мост (горизонталь): рифмы к другим лекциям. Слабая в одиночку, но дающая сильный мост, проходит как «связка» (§5).
- **Discovery-fiction-афорданс (keystone).** Тему можно подать как *переоткрытие*: естественный вопрос → цепочка простых, почти очевидных шагов (часто включая открытие самой задачи) → результат, с честными тупиками. Сильный — если зал реально может пройти шаги сам. Это восстановленная **мастер-арка эпизода** (генезис → объединяющее → прикладное → в кармане) в рабочей форме: за один сигнал метит ядро по драме, соучастию (Г6), честности упрощения (Г5) и квизу. **Не** история науки (`resheniya` п.1) и не пересказ статьи. Цена — текст в 2–5× длиннее → дозировать: **одно ядро руками** (Г1), прочее подмигиванием. Сильный DF-афорданс — серьёзный аргумент на роль ядра/вход. Если DF и «обыденное понятие» срабатывают по одной причине (один естественный вопрос) — это **один** keystone-сигнал, не два (не разводить ничьи двойным счётом).

## 5. Чтение результата (ранжирование и роль)
Не по абсолютной сумме — по позиции и относительно эталона.
- **Эталон — Монте-Карло** (A-сильный, B-сильный; двойной максимум прежнего пула). Каждую тему сравниваем с ним по каждой оси (**лучше / = / хуже** — Pugh), не назначаем «истинное число».
- **Полосы** (грубо, на каждую ось из своих критериев): силён / средний / слаб.
- **Роли (режиссёрское правило):**
  - сильна по A и по B → **ядро** (вход + держит);
  - сильна по A, слабее по B → **продажник** (на вход и в название);
  - сильна по B, слабее по A → **тело** (в середину, держит и радует);
  - слаба в одиночку, но сильный мост → **связка** (только если ворота лекции пройдены);
  - провалила ворота → **выбыла / доработка** (одной строкой — что докрутить).
- **Размещение ≠ только баллы A.** Роль по A/B назначает место по умолчанию. Но сильная ГОРИЗОНТАЛЬНАЯ роль (мета-рифма, хребет, вводная-под-имя) оправдывает место, которого A-балл не дал бы: тема со средней A, но несущая хребет курса, идёт на вход не как продажник, а как структурный вход. Решается на уровне НАБОРА (§6), не по одиночной теме.

## 6. Баланс набора (проверки на 6, не на тему)
Тема может быть слабее сама по себе, если несёт функцию в композиции (курс амортизирует слои). По сумме:
- Покрытие разных **областей** (вероятность, числа, графы, лин. алгебра, логика…) — где лакуны?
- Чередование **форматов** и **пиковой силы удивления** (нет шести одинаковых).
- Распределены **личности / машины / байки** — не скучены.
- **Паутина мостов** — рифмы между любыми лекциями, кочующие люди; чувствуется единый мир?
- **Щупаемость распределена** — есть лекции с демонстрацией руками в зале (доска Гальтона, дартс, глайдеры), не только слайды.
- **Антология-с-throughline (общая проверка набора):** каждая лекция держится сама (можно пропустить) И весь набор ощущается одним миром (мотивы, кочующие люди, контекст, мета-рифма); связь НЕ порядковая — без seed→payoff. **Различитель:** «плотная нить» хороша как мотив-рифма (всплывает в любых лекциях), но если она требует смотреть по порядку (лекция N опирается на N−1) — это скрытый season-arc, ❌ (предупреждение концепциям с линейной нитью).
- Единый **визуальный мотив** через весь курс.
- **Живой фронтир** в мощных местах (открытый вопрос / незатухающее движение).
- Разный **вес истории** (где ядро в окне, где флешбек).
Дыра в балансе → добрать темой под дыру (даже средней по A/B, если закрывает функцию).
- **Структурная роль** (хребет / мета-рифма / вводная-под-имя) — самостоятельное основание включить и разместить тему, даже если её одиночные A/B средние (см. §5). Размещение набора решается здесь, не по одиночной теме.
