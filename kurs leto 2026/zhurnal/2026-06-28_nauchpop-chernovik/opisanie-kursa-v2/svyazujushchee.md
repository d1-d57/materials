## 2. КАРТА / ГЕНЕАЛОГИЯ ИДЕЙ (что из чего выросло; бьёт по оси «мат-идеи и рифмы»)

Узлы — идеи; стрелки — «выросло из / тот же приём».

- **ДИАГОНАЛЬ (один приём, три теоремы):** Кантор (несчётность) → Гёдель (неполнота, Л1) → Тьюринг (остановка, Л1) → возврат в финал как «программа наоборот» (Л7).
- **СВОДИМОСТЬ (свести задачу к задаче, перенести трудность):** остановка (Л1, 1936) → 10-я проблема Гильберта (Матиясевич, Л3, 1970) → SAT/NP-полнота (Кук–Левин, Л3, 1971) → «всё сводится к одному» = универсальность (Л7).
- **УНИВЕРСАЛЬНОСТЬ / «одна вещь, к которой всё сводится»:** машина Тьюринга считает всё (Л1) · симплекс решает всё планирование (Л2) · всё сводится к SAT (Л3) · сеть приближает любую функцию (Л7).
- **ПРЕДЕЛ / НИЖНЯЯ ГРАНИЦА (у каждой способности — стена):** нельзя вообще (остановка, Л1) → нельзя быстро (NP, Л3) → нельзя дешевле (ключ ≥ сообщения, Шеннон, Л4) → нельзя плотнее (граница Хэмминга, Л5) → физический предел стирания бита (Ландауэр, Л5) → предел для ИИ (Гёдель, Л7).
- **СЛУЧАЙНОСТЬ КАК ИНСТРУМЕНТ (монетка вместо точного ответа):** Миллер–Рабин и ZKP (Л4) → Монте-Карло и MCMC (Л6) → сэмплинг генеративных моделей (Л7).
- **СПРЯТАННАЯ ГЕОМЕТРИЯ:** оптимум в вершине многогранника + транспорт как градиент выпуклой функции (Л2) → эллиптические кривые (Л4) → коды = точки/шары в кубе (Л5) → аппроксимация = стопка ступенек (Л7).
- **ПРЕДСКАЗАНИЕ = СЖАТИЕ:** энтропия Шеннона (Л5) → колмогоровская сложность (Л5) → языковые модели как компрессоры (Л6, Л7).
- **ЧЕЛОВЕК → МАШИНА:** клерки диеты Стиглера (Л2) · SAT-доказательства вместо ручного перебора (Л3) · Марков карандашом / ENIAC / Кляра фон Нейман (Л6) · перцептрон учится сам и ИИ берёт золото IMO (Л1, Л7).

## 3. «ГДЕ И КОГДА» (институции; бьёт по оси «места»)

- **Принстон / IAS** — Гёдель, фон Нейман, Эйнштейн, заехавший Тьюринг (1936–38); встреча фон Неймана с Данцигом (1947); Вигдерсон; ZKP-верификация боеголовки (2014–16). → Л1·Л2·Л4·Л6.
- **Bell Labs (Murray Hill)** — Шеннон (с 1941) и Хэмминг (с 1946) — коллеги в одном здании; SIGSALY; чай Шеннона с Тьюрингом (1943). → Л4·Л5·Л6.
- **Лос-Аламос / Манхэттенский проект** — Улам, фон Нейман, Метрополис, Теллеры, MANIAC, нейтроны бомбы. → Л6.
- **Ленинград / СССР** — Канторович (фанерный трест, блокада), Марков, Колмогоров, Матиясевич; Левин (Москва, ученик Колмогорова). Нить-рифма «в другой стране независимо наткнулись на ту же структуру» (честно: контекст, не личные встречи). → Л2·Л3·Л6.
- **Кембридж / Блетчли-Парк** — Тьюринг (машина 1936; Banburismus, взлом Энигмы; единица «ban»). → Л1·Л5.
- **Корнелл** — Розенблатт (перцептрон Mark I). → Л7.
- **GCHQ (Челтнем)** — Эллис, Кокс, Уильямсон: тайный RSA и Диффи–Хеллман (1969–74). → Л4.
