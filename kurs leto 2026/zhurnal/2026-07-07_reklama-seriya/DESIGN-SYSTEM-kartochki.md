# Дизайн-система карточек курса — v1 (locked 2026-07-08)

Многоразовая форма для рекламных карточек курса (телефон-первый, Телеграм-карусель). Принципы — `MANIFEST-kartochki.md` (незыблемы). Точные значения — здесь. Эталон-реализация — **`forma-kartochki-r2.html`** (в этой папке; собрана на токенах). Тексты в эталоне — тервер-рыба; для нового набора см. §«Как собрать реальный набор».

## Формат
- **4:5**, холст **1080×1350**. Экспорт **PNG @2x**. Карусель — до 10 карт. НЕ A4.

## Токены (`:root`)
```
--bg:     #2E5A54   /* база — тёмная бирюза (фон карты) */
--ink:    #EAF1EC   /* заголовки, светлый текст */
--page:   #12100e   /* фон страницы-подложки */
--walk:   #E4CE93   /* песочное золото — ИЛЛЮСТРАЦИЯ («блуждание») + подзаголовок-lead */
--signal: #EF6A4B   /* коралл — АКЦЕНТ-«сигнал»: числа, маркеры, акцентный узел */
--muted:  #a7c3ba   /* приглушённый — глазки/вспомогательное */
--body:   #e2ebe5   /* тело списков */
--hero:  'Space Grotesk'  /* шрифт-герой (заголовки) */
--mono:  'JetBrains Mono' /* числа, даты, глазки, метки блоков */
--text:  'Manrope'        /* тело, подзаголовки */
--pad:    96px      /* боковой отступ body */
--safe:   200px     /* правая safe-zone: текст не заходит в зону иллюстрации */
```
Три цвета — со смыслом: **база (бирюза) · золото = линия-иллюстрация · коралл = сигнал/числа.** Два тёплых работают, потому что у них разные роли (§7 манифеста).

## Типографика (точные значения)
- **h1 (герой):** `--hero`, вес 700, letter-spacing −2px, цвет `--ink`. Кегль: обложка 100/‑lh.98 · разделы 94/lh1 · плотная «Программа» 82/lh1.
- **lead (подзаголовок):** `--text` 500, цвет `--walk`, 36–42px, lh1.26.
- **item (пункт списка):** `--text` 500, цвет `--body`, 40px, lh~1.26; маркер `.mk` — квадрат 15px, `--signal`; gap между пунктами 44–46px.
- **eyebrow (глазок):** `--mono` 600, 21px, ls .34em, uppercase, `--muted`.
- **foot (нижняя строка):** `--mono` 500, 23px, `#8fb0a5`.
- **числа/акценты:** класс `.num` → `--signal`. Даты: `--mono` 600, 24px, uppercase. Метка блока («Блок 1»): `--mono` 700, 20px, ls .16em, uppercase, `--signal`. Цена: `--mono` 700, 74px, `--signal`.

## Анатомия карты
- `.card` 1080×1350, фон `--bg`, overflow hidden.
- `.spine` — SVG во всю карту (z-1): **одна line-art иллюстрация**, обводка `--walk` (толщина 4–9), один акцентный узел `--signal` (точка + кольцо-ореол opacity .5). **Без подписей.** Живёт у правого края.
- `.body` (z-2), padding `100px 96px 92px`; на картах с иллюстрацией — **`padding-right: var(--safe)`**, чтобы текст не пересекал линию.
- `.main` — flex-колонка, по центру по вертикали. На обложке — лёгкий подъём `translateY(-96px)` (НЕ прижимать к верхнему краю).
- Порядок: (глазок/eyebrow при нужде) → **крупный h1** → lead → список/тело → foot (мета).
- **Колонтитула НЕТ** (бегущий «title» сверху запрещён, §8).

## Иллюстрация — по теме, одна на карту, без подписей
Крупный объект темы линией (не диаграмма с ярлыками): вероятность — блуждание на решётке · вычислимость — диагональ/лента · оптимизация — граф/маршрут · криптография — ключ · информация — сигнал/битовая дорожка · сложность — ветвление · мышление — сеть-узлы. Обводка `--walk`, один узел `--signal`, ноль подписей.

## Как собрать реальный набор (завтра)
1. Копию эталона `forma-kartochki-r2.html` → подставить **финальный текст** 6 карт из `6-lending/tz-post-anons-2.md §B` (голос — из манифеста; тексты причесать редактором канала).
2. На каждой карте заменить «блуждание» на **свою иллюстрацию темы** (список выше).
3. Токены/типографику/анатомию НЕ трогать — они и есть система.
4. Прогнать гейты: **тест-миниатюрой** (ужать до ширины телефона — заголовок/суть/иллюстрация живы), ноль подписей, один шрифт-герой, 4:5, ничего лишнего.
5. Экспорт PNG @2x; порядок карт — как в `tz-post-anons-2.md §B`.

## Открытое / необязательная полировка (не блокеры)
- Убрать мёртвый класс `.run` из CSS при чистке.
- Space Grotesk принят; если захочется ещё характернее — менять через `--hero` (один токен), система не ломается.
- «Программа»/плотные списки — держать ≤7 пунктов в колонке ради теста-миниатюрой.
- Возможная эволюция: на части карт иллюстрацию сделать крупнее/центральнее (сейчас — правый мотив).

*Локальный статус: канон арки. Фолд в durable-дом (6-lending) — при закрытии арки, владелец.*
