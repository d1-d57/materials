# Дизайн-схема карточек курса — v2 (2026-07-08)

Многоразовая форма рекламных карточек курса. Телефон-первый, Телеграм-карусель. Эталон — **`kartochki-vypusk-1.html`**. Незыблемые принципы — `MANIFEST-kartochki.md`. Эта редакция фиксирует то, что откристаллизовалось на выпуске-1: систему мотивов, типографические правила набора и философию заполнения.

## Формат и носитель
- **4:5**, холст **1080×1350**. Карусель до 10 карт. Экспорт PNG @2x. НЕ A4.
- Смотрят с телефона, мелко. **Гейт:** не читается в миниатюре — считай, элемента нет.

## Токены (`:root`)
```
--bg:#2E5A54  /* петроль — фон карты */      --ink:#EAF1EC  /* заголовки, светлый текст */
--walk:#E4CE93 /* золото — линия-иллюстрация + lead + приложения */
--signal:#EF6A4B /* коралл — сигнал/акцент: числа, узел, подчёркнутые фразы */
--muted:#a7c3ba /* приглушённый — второстепенный текст */   --body:#e2ebe5 /* тело абзацев */
--page:#12100e /* фон-подложка стенда */
--hero:'Space Grotesk'  --text:'Manrope'  --mono:'JetBrains Mono'
--pad:96px  --safe:200px  /* правая safe-zone под вертикальный мотив */
```
**Три цвета со смыслом:** петроль-база · золото = линия/лид · коралл = один сигнал. Коралл — скупо: числа/даты и подчёркнутые смысловые фразы (по разметке акцентов), не «где красиво».

## Типографика — стандартная шкала (не ломать)
- **h1 (Space Grotesk 700, ls −2px, `--ink`):** обложка 100 · разделы 92–94 · плотные/двухколоночные 78–82. Перенос строк в заголовке ставим руками (`<br>`) ради ровной композиции.
- **lead / подзаголовок** (`--text` 500, `--walk`): 34–42.
- **тело** (`--text` 500, `--body`): 30–42 (эталон плотного текста — 40–42, как на «Как устроено»). Минимум на листе — 27.
- **пункт списка / тема** (`--text` 600, `--ink`): 34–40; маркер `.mk` — квадрат 15px `--signal`.
- **глазок/eyebrow** (`--mono` 600, ls .34em, uppercase, `--muted`): 21.
- **нижняя мета/foot** (`--mono` 500, `#8fb0a5`): 23–27. **лента 0/1** — `--mono` 600, золото.

## Правила набора (программно, всегда)
- **Без точки в конце абзаца.** Точка внутри абзаца остаётся; финальную убираем — она лишний акцент и лишнее место.
- **Неразрывный пробел перед тире** (` — ` → ` —`): тире никогда не начинает строку.
- **`text-wrap: balance`** на абзацах/лидах — строки выровнены по длине, ни одно слово не торчит. Для длинных колонок (>6 строк) — **`text-wrap: pretty`** (без висячих слов).
- Кавычки-ёлочки — только в тексте-содержании (цитаты). В стилевых заголовках-вопросах (карта 6) кавычек нет.
- Один шрифт-герой на весь набор.

## Философия заполнения
Текст занимает **большую часть объёма**. Если снизу пусто — сперва аккуратно поднять кегль к верху шкалы и/или раздвинуть абзацы, и только потом думать о графике. Пустоту не «затыкать» декором. Эталон плотности — карта «Как устроено».

## Анатомия карты
- `.card` 1080×1350, фон `--bg`, overflow hidden.
- `.body` padding `100 96 92`; на картах с правым мотивом — `padding-right: var(--safe)`.
- `.main` — flex-колонка, по центру по вертикали (заполняет объём). *Открытое решение — см. ниже.*
- `.spine` — SVG во всю карту (z-1) под мотив; текст (z-2) поверх.
- Колонтитула/бегущего заголовка НЕТ. Рамок, легенд, подписей к иллюстрации НЕТ.

## Система мотивов (мало средств, крупно, без подписей)
1. **Обложка — единственный «богатый» кадр.** Сейчас: длинная тонкая лента Тьюринга 0/1 сверху (лёгкий акцент) + крупный заголовок-герой по центру. Глазок «онлайн-курс» — верхним ярлыком под лентой.
2. **Повторяющийся элемент — вертикальная изломанная линия** (меандр «сигнал/дорожка») у правого края. Живёт на части одноколоночных карт (в выпуске-1 — «Математика в кармане» и «Для кого»), с одним коралловым узлом. Это «подпись» набора.
3. **Лента 0/1 как скобки карусели:** открывается лентой сверху (обложка) — закрывается лентой снизу (последняя карта). Рифма начала и конца.
4. **Один коралловый узел** на иллюстрацию — единственный тёплый укол. Ноль подписей.
5. Текстовые/двухколоночные карты без мотива держатся типографикой и воздухом.

## Двухколоночный паттерн (карты «Программа», «Уровень сложности»)
- Две равные колонки (`flex:1`), узкий gap (~40). Заголовки-вопросы — коралл, приведены к одинаковому числу строк (`<br>` + `min-height`), тело выравнивается по общей базовой линии.
- Плотные списки — ≤7 пунктов в колонке; проверять тест-миниатюрой.

## Открытые решения (для «идеальной схемы» / сайта)
- **Вертикальный уровень заголовка.** Сейчас `.main` центрирует контент → на лёгких картах заголовок стоит ниже, чем на плотных (видно в миниатюре). Для строгой шаблонной сетки (особенно на сайте) — прижать заголовки к общей верхней линии (`justify-content:flex-start`), приняв умеренный воздух снизу у лёгких карт. Для этого набора оставлено центрирование (ровнее заполнено). **Решить при переносе на сайт.**

## Производство и перенос
- Один **самодостаточный HTML на токенах**; шрифты — Google Fonts `@import` (для офлайна можно вшить woff2).
- **Тексты дословно** из чистовика; из нетекстового свободно всё. Сверять слова программно (нормализуя намеренные правки: убранные точки/кавычки).
- Ревью — рендер каждой карты в PNG и просмотр глазами (+ тест-миниатюрой). См. память `render-html-sandbox-pipeline`.
- **На сайт переносится 1:1:** токены, шкала кеглей, роли цвета, правила набора (точки/тире/balance), система мотивов. **Адаптируется:** сетка (ресайз вместо фикс-1080), safe-zone, длины строк. Формат карточки 4:5 остаётся модулем-«плиткой».
