# Бриф: сторонний заход «Верификация текста + внос идей в KONCEPT» (Track B арки «Питч»)

**Как использовать.** Открой ОТДЕЛЬНЫЙ чат проекта «Курс Лето 2026» (чтобы не смешивать с дизайном/HTML — Track A). Войди по арк-ритуалу арки «Питч»: `NAVIGATOR.md` → `PLAN.md` («СЕЙЧАС») → хвост `SESSIYA.md`. Дальше работай по этому брифу. Это НЕ дизайн-трек — тут только текст-факты и концепт.

## Зачем отдельно
Дизайн-трек (HTML) идёт в своём чате и не должен забиваться биографическим ресёрчем и правкой концепта. Здесь — только верификация утверждений питча и перенос найденных идей в мастер-концепт. Так контекст обоих треков остаётся чистым.

## Цель
1. **Верифицировать «абсолютизации».** В ручной правке владельца hedge «почти все» местами стал «все». Проверить по источникам, честно ли «все» — иначе вернуть «почти все» (правило проекта: не переобещать). Два места:
   - «**всё** в вашем телефоне работает на этой технике» (шифрование / сжатие / поиск / расписание / чат-бот — это примеры; «почти всё» честнее?);
   - концовка: «**все** шестеро уперлись в жизни в границу». Проверить каждого из шести — **Тьюринг, фон Нейман, Гёдель, Шеннон, Колмогоров, Винер**: правда ли у каждого есть арка с драматизмом (преодоление или нащупанная граница; может кончаться хорошо, но история серьёзная). Сверить с `0-koncept/dramaturgiya.md` — там уже заявлено «у каждого граница возможного у человека»; проверить **обоснованность** этого, не только текст питча.
2. **Внести сформулированные идеи в KONCEPT.** Владелец коротко сформулировал главные идеи питча с нужными акцентами; **не все отражены** в `0-koncept/KONCEPT.md` (манифест). Занести с правильными акцентами; где влияет на манифест — прокатить по лекциям. *Материал владельца (его формулировки) — приложить/вставить в начале захода.*
