**Новая арка — «Сайт курса: от одного экрана к полному рассказу». Проект «Курс Лето 2026». Ты — аналитик (Cowork).**

Первым делом прочитай `COWORK.md` и следуй ему (роли, среда, роутер). Это новая многосоставная арка — заведи её по `ARKA.md` (Ф0-скрипт): папка `zhurnal/2026-07-09_sayt-rasshirenie/` + `NAVIGATOR / PLAN / SESSIYA`. Весь проект не читай — бери только то, что назову ниже.

**Эта сессия — стратегия, не сборка.** Проведи стратегическую сессию (вход через `brainstorming` / `project-kickoff`), «разговор первым»: сориентируйся, предложи, дождись моего слова — и только потом пиши файлы. Итог сессии — компактное **ТЗ арки**: цель · целевое состояние сайта · решение по архитектуре (или варианты на выбор со мной) · scope / анти-scope · роадмап с указанием нужных скиллов · открытые вопросы ко мне.

**Что есть сейчас.** Сайт — супер-минималистичный лендинг на один экран (расширенный анонс: место, куда положить весь текст, не влезающий в телеграм). Источник — `6-lending/lendingi/mashina-myslit.html`, деплой https://d1-d57.github.io/kurs_2026/. На нём: вопрос-доминанта «Может ли машина мыслить?», ось 1936/1950, семь тем, абзацы про концепт / военное поколение / шестерых героев, один CTA. Ни цен, ни форматов участия, ни «для кого / как устроено» — намеренно минимально. (Актуальный `index.html` приложу в чат.)

**Что изменилось.** Пока делали рекламные карточки, набралось много готового текста и смыслов, которых на лендинге нет: **цены и форматы участия, «для кого», «как устроено», «уровень сложности», раскрытая программа.** Бери это как сырьё:
- карточки выпуска 1 (много готового текста): `zhurnal/2026-07-07_reklama-seriya/teksty-vypusk-1.md` — **но при сборке я вносил свои правки; финальные формулировки уточни у меня;**
- концепт курса (семь лекций как одно движение, шестеро героев, границы возможного): `0-koncept/KONCEPT.md`;
- канон формулировок и честность (анти-фабрикация): `0-koncept/formulirovki.md`, `1-START-HERE/resheniya.md`;
- замороженный питч: `6-lending/pitch-kurs.md`;
- дизайн-система карточек (для согласованности бренда): `zhurnal/2026-07-07_reklama-seriya/DESIGN-SYSTEM-kartochki.md`.

**Рамка решения (это вопрос, не ответ — думаем вместе).** Мне нравится, что страница занимает ровно один экран и ощущается законченной; хочу сохранить это чувство, но дать больше. Варианты на обсуждение: (а) один экран с вкладками — «для кого», «формат», «программа», «цены»…; (б) несколько одноэкранных страниц на GitHub с переходами между ними; (в) полноценный многостраничный сайт. В перспективе (НЕ сейчас): страница на каждую лекцию, общий обзорный текст, диаграммы про содержание и про героев/персонажей, комплексный рассказ о всём курсе.

**Темп и ограничения.** Не срочно: этим летом группа, скорее всего, не наберётся — запуск расширенного сайта осенью или когда решу; строим постепенно. Живёт на GitHub Pages. Держим минималистичный бренд — согласованность с текущим лендингом и с дизайн-системой карточек. Честность формулировок — как в проекте.

**Полезные скиллы по фазам:** вход — `project-kickoff` / `brainstorming`; вёрстка и публикация — `site-cross-device-audit` (проактивно), `web-typography`, `refactoring-ui`; при сюжетной/скролл-подаче — `cinematic-longread` / `scrollytelling` / `gsap-*`; визуальная проверка — `visual-design-review`.
