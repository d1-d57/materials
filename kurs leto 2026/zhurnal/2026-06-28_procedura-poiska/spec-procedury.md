## 1. Архитектура — субстрат и поток

**Субстрат — Dynamic Workflows** (Code ≥ v2.1.154; фон, 16 одновр./1000 агентов за прогон, петля и промежутки в переменных скрипта → контекст чата чист; `claude -p`+SDK). Внутри волны fan-out идёт workflow-скриптом; **последовательность волн** держит тонкий **оркестратор-над-волнами**.

**Поток (5 волн, durable-артефакт после каждой):**
```
GATHER → TRIAGE → DEEPEN → ASSEMBLE(чемпион+развилки) → DOSSIER
Haiku    дёшево    Sonnet    Opus-скупо                  Sonnet
ширина   ворота    углубл.   сборка-6 + MMR + судья       питч
60 яч.   отвал     изолир.   изолир.+анти-хак             досье
 ↓w1     ↓w2       ↓w3        ↓w4                          ↓w5
jsonl    jsonl     jsonl      json                         md
```

**Возобновляемость — несущая (Max 20x).** Workflow НЕ переживает выход из Code (стартует заново; resume только внутри сессии). Поэтому **каждая волна — отдельный вызов `claude -p`**, читает durable-артефакт прошлой и пишет свой. Троттл 5-час окна между волнами → resume = просто перезапустить следующую волну (предыдущие лежат на диске). Внутри волны троттл → волна перезапускается целиком (поэтому волны режем под комфортный размер).

**Тиринг (раздельные бакеты лимитов → не конкурируют; кэш-инпут не в ITPM):**
- **Haiku** — GATHER (ширина, дёшево).
- **Sonnet** — TRIAGE, DEEPEN (масса суждения/крафта), DOSSIER.
- **Opus** — только ядро ASSEMBLE (узкое элитное плетение чемпиона+развилок). **Скупо** — Max 20x душит на недельных Opus-капах (авто Opus→Sonnet на 50% окна).
- Общую рубрику+якорь **кэшируем** (shared context) — не считается в ITPM, множит эффективный инпут.

## 3. Пять волн — I/O каждой

### Волна 1 — GATHER (Haiku, fan-out по сетке ~60 ячеек)
- **Вход:** `grid.md`, `rubric.md` (кэш), `scorecard.schema.json`.
- **Делает:** на ячейку (область×мотив) — агент предлагает 1–3 темы-кандидата, живущие в ней; собирает сырьё (книги/научпоп/известные результаты — **НЕ история науки**, `resheniya` п.1; ищет discovery-fiction-афорданс); заполняет **черновой** scorecard (схема-конформный); **источник-на-факт**. Возвращает **сжато** (scorecard+источники), не сырой корпус.
- **Засев:** ячейки предзасеяны 16 темами пула, где подходят (**seed + кросс-чек, не с нуля**); пустые ячейки разведуют новое.
- **Выход:** `w1_candidates.jsonl` (~80–150 черновых scorecard'ов). Durable.

### Волна 2 — TRIAGE (дёшево; механика + лёгкое суждение)
- **Вход:** `w1_candidates.jsonl`, `rubric.md`, `anchor.md`.
- **Делает:** мёрж; **дедуп** (хэш+семантика — много ячеек переоткроют Монте-Карло/крипто/Тьюринга); **ворота-отвал** (ε-ограничение: провал любого Г1–Г8 → отвал или «доработка»); **ранг к эталону Монте-Карло** (Pugh лучше/=/хуже по осям). Свежий контекст на батч, истории оптимизации НЕ видит.
- **Выход:** `w2_survivors.jsonl` (~12–18 выживших + статус ворот + грубый ранг). Durable.

### Волна 3 — DEEPEN (Sonnet, изолированный контекст на тему — рабочая лошадь)
- **Вход:** каждый выживший из w2 (свежий изолированный Sonnet).
- **Делает:** **discovery-fiction-крафт** (естественный вопрос → простые шаги → результат, честные тупики; одно ядро руками Г1, тяжёлое — подмигиванием Г5); **факт-чек отдельным проходом** (пер-факт, источник-на-факт, NLI-проверка «сказал ли источник это», право «не нашёл» — защита от фабрикации цитат); **полный scorecard** (все ворота + A1–A5 + B1–B4 + движки + vs-якорь); **крючки/параллели** к другим темам (для паутины мостов ASSEMBLE). Вердикт: заморозить / копать / выкинуть.
- **Выход:** `w3_deepened.jsonl` (~10–15 углублённых лекций: полный scorecard, DF-черновик, лог факт-чека, крючки-параллели). Durable.

### Волна 4 — ASSEMBLE (Opus-ядро скупо; чемпион + развилки)
- **Вход:** `w3_deepened.jsonl`, `rubric.md` §6 (ворота набора Н1–Н4 + баланс), `anchor.md`.
- **Один остров-чемпион:** позвоночник = «математика компьютеров» (тьюринговский узел); **оператор дрейфа-недалеко** разрешён (переакцент/переобрамление рядом, не замена).
- **Beam по наборам-6:** Opus предлагает наборы (мутация+кроссовер в одном вызове: «вот сильные лекции + текущий лучший набор — собери лучше, замени слабейший слот»); счёт набора = ворота Н1–Н4 + **MMR-покрытие** (λ≈0.7: слабая-дополняющая бьёт сильную-избыточную) + **изолированный судья когерентности**.
- **Острова-доноры (рефрейм):** 1–2 челленджер-фрейма («случайность приручённая», «язык-информация») рождают альтернативные сильные лекции; **сильная лекция-донор, что вписывается в позвоночник, мигрирует В чемпиона** (рандом-алгоритмы, Марков), сам фрейм затем **отбрасывается** (НЕ второй курс). Так польза island-модели (приток разнообразия, анти-схлопывание) без портфеля.
- **Вариации = ВНУТРЕННИЕ развилки (MAP-Elites):** ниши = дуга сложности / подобласть слота / тип входа / **lecturer-fit** (доказательно vs демонстративно vs историчный вход). Лучший-в-нише = готовая развилка. Пер-слот раннеры в пределах δ = сменные слоты. Это «развилки под меня как лектора».
- **Элитизм:** чемпион копируется нетронутым между поколениями. Кап **3–5 поколений**; стоп если чемпион не сменился 2 раунда / маржинальный выигрыш < ε / сработал tripwire.
- **Выход:** `w4_assembly.json` (чемпион-6 + внутр. развилки по нишам + сменные слоты + лог миграций + трейс анти-хака). Durable.

### Волна 5 — DOSSIER (Sonnet, единый синтез)
- **Вход:** `w4_assembly.json` + scorecard'ы w3.
- **Делает:** **досье решения** (md): курс-чемпион (6 лекций, порядок, роли) + **вау-питч** (научпоп, то что владелец перескажет) + **внутренние развилки** (под лектора) + сменные слоты + **карта параллелей-мостов** (мотивы, кочующие люди, мета-рифма) + scorecard'ы лекций + **открытые развилки владельцу** + честные флаги (где рубрика дала дыру / где факт-чек сказал «не нашёл» / где позвоночник дрейфанул). Отдельный проход цитат (CitationAgent-стиль).
- **Выход:** `w5_dossier.md`. Durable. **Это то, к чему просыпается владелец.**

## 4. Несущие механизмы (гениально-простое — здесь, не в числе агентов)

1. **Типизированный контракт** (`--json-schema`→`structured_output`): 100 агентов это map; магия — детерминированный reduce по жёсткой схеме. Не «просьба в промпте».
2. **Анти-ревард-хак** (verified 2407.04549 «Spontaneous Reward Hacking»): судья — **(а)** в СВЕЖЕМ изолированном контексте на кандидата (без памяти оптимизации) **и (б) ИНЫМ тиром, чем автор** (Opus предлагает → Sonnet судит, или наоборот). Почему оба: изоляция ломает общий *контекст*, разнотирьё бьёт общую *слепоту* модели (одна модель «тянет к общему adversarial-примеру»). **Вынесенный якорь** (Монте-Карло + ручные сверки) сверяется каждое поколение. **TRIPWIRE: счёт судьи растёт, а якорь — нет → СТОП, флаг, выигрышу не верить.**
3. **Анти-фабрикация цитат:** источник-на-факт + **отдельный** проход факт-чека (не на синтезе) + NLI «сказал ли источник» + право «не нашёл».
4. **Resume:** durable после каждой волны + оркестратор-над-волнами (workflow сам межсессийно не резюмится).
5. **Тиринг + кэш:** раздельные бакеты по классам + кэш рубрики/якоря (не в ITPM) → тиринг даёт и цену, и пропускную. Opus скуп (Max 20x).
6. **Один чемпион + внутренние развилки + lecturer-fit + острова-доноры:** на выходе ОДИН курс, не три.
7. **Два уровня оптимизации** (`sloi-arhitektura` вертикаль/горизонталь): вертикаль = scorecard лекции (§3 рубрики); горизонталь = ворота+баланс набора (§6 рубрики). **constraint-then-rank** (ворота=ε-пол, баллы=ранг), не взвешенная сумма — достаёт «гениально-странный, но цельный» курс.

## 5. Сетка область×мотив + засев

**10 областей** (покрытие разных областей математики, Н4; из `sistema-ocenki §6` + пул): вероятность/случайность · числа/криптография · графы/сети · информация/кодирование · логика/вычислимость · сложность/оптимизация · линейная алгебра/ранжирование · обучение/нейросети · языки/автоматы · геометрия/топология *(резерв — другой курс, фильтр Н3)*.

**6 мотивов** (разрезы, делающие тему вау — мапятся на движки/оси рубрики): discovery-fiction-переоткрытие · обыденное-понятие-с-глубиной · драма-и-лица · щупается-руками (крафт/интерактив) · killer-заголовок · мост-хаб (двойная ценность).

**Засев (прогон НЕ с нуля):** 16 тем пула разложить по ячейкам (Монте-Карло=вероятность×DF — **якорь**, всегда; крипто+Энигма=числа×драма; PageRank=лин.алгебра×обыденное; Шеннон=информация×обыденное; Марков=языки×мост-хаб; нейросети=обучение×killer, дорогой; Гёдель/Тьюринг=логика×DF; Игра жизни=логика×щупается; коды=информация×щупается; …). Тьюринговский узел (универсальная машина 1936, две ветки) — кандидат-каркас позвоночника. Пустые ячейки — разведка нового.

## 6. Пилот — де-риск контракта ПЕРЕД ночным прогоном

Прогнать **1–2 ячейки** через GATHER→TRIAGE→DEEPEN (~15 мин, дёшево). Цель — вскрыть дыры, пока дёшево:
- ячейка A: вероятность×DF → Монте-Карло (есть якорь — проверить, что Pugh к нему стабилен);
- ячейка B: информация×обыденное → Шеннон/бит.

**Гейты пилота (проверяемо):** (1) scorecard-схема держится на дешёвых агентах (валидный JSON по схеме, 100%); (2) факт-чек ловит **подсаженную** ошибку ИЛИ честно говорит «не нашёл»; (3) изолированный судья даёт **стабильный** ранг к якорю на повторе (не плывёт); (4) Haiku-вывод годен, не каша. Дыра → правка промптов/схемы → потом финальный заход. Пилот может вскрыть дыру в рубрике → **флаг владельцу, не правка втихую** (рубрика — канон).

## 10. Пилот — прогон здесь (Cowork-субагенты, тиринг)

**Метод (~де-риск контракта):** 2 ячейки GATHER (Haiku) + DEEPEN (Sonnet, «четыре краски» с **подсаженной ложью**) + изолированный судья (Sonnet). Обогащённый засев из книги-донора.

**Подтвердилось — несущее держит:**
- **Тиринг провабли верен.** Haiku даёт ширину (кандидаты + источники), но **завышает и не дискриминирует** (всё «ядро», всё «= эталону») и **дрейфует к престижно-недоступному** (предложил λ-исчисление с A2-ширина=3 для НЕ-айтишников, бросив доступные засевы).
