# rubric.md — фитнес-функция процедуры (v1, запинена)

> **САМОДОСТАТОЧНА.** Это единственная фикс-рубрика ночного прогона. Дистиллят канона `sistema-ocenki.md`. Агент судит ТОЛЬКО по ней; в проект за рубрикой не лезет.

## КАПКАН (читать первым)

**Фитнес процедуры = ЭТОТ канон:** ворота Г1–Г8 / Н1–Н4, оси A1–A5 / B1–B4 (грубо **0–3, БЕЗ весов**), ранг **Pugh к эталону Монте-Карло** (лучше/=/хуже), движки, discovery-fiction как keystone.

**Старая взвешенная система `A≤18 / B≤21` (G1–G3, веса) из `2-idei/syuzhety-pul-i-research.md` — `superseded`, НЕ ИСПОЛЬЗОВАТЬ.** Если в засеве встретятся числа A18/B21 — это исторический черновик для грубого сигнала роли, не балл. Scorecard ставится заново по этой рубрике.

## Рамка (под что настроено)

Аудитория — **НЕ айтишники**, культурный багаж образованного человека (ширина = условие выручки). Курс, не доклад: важен баланс набора, не пик каждой лекции. Коммерция двухтактна — **продаётся ДО** (название/лендинг → ось A), **радует ВО ВРЕМЯ** (тело → ось B); меряем раздельно. Подъёмность за час: **одно ядро переоткрывается руками** (Г1), тяжёлое — подмигиванием.

## §A. ВОРОТА ЛЕКЦИИ (HARD, бинарные ✅/❌ — не баллы)

Провал любого → `выбыла` или `доработать`. Каждый ворот — **наблюдаемый факт о лекции** (есть/нет конкретная вещь), не впечатление.

| # | Ворот | ✅ если |
|---|---|---|
| Г1 | Матядро | есть теорема/вычисление, **проделываемое в зале** |
| Г2 | Крючок-заход | есть сегодняшнее «в кармане», видимое вокруг |
| Г3 | Драматургия + «ого» | есть эмоц. арка и хотя бы один момент удивления |
| Г4 | Пересказуемая фраза | есть одна мысль, которую унесут и перескажут |
| Г5 | Честное упрощение | облегчённая версия не стала враньём |
| Г6 | Петля соучастия | зал не без дела дольше ~2 мин (есть что **додумать**) |
| Г7 | Автор тянет | понимает, как рассказать **И** доказать |
| Г8 | Честность обещания | даёт понимание, не мнимый навык |

_Ворот может пройти **условно**: пограничное ✅ с условием в «что докрутить» (напр. Г7 ✅, если ядро на доказуемом, а тяжёлое — подмигиванием). Условие — граница скоупа, не балл._

## §B. ВОРОТА НАБОРА (HARD, на 6 лекций)

| # | Ворот | ✅ если |
|---|---|---|
| Н1 | ≤2 дорогих | дорогих по подготовке ≤2 (нейросети — согласованный дорогой) |
| Н2 | Единство (антология-с-throughline) | каждая лекция держится **сама** (можно пропустить, порядок гибкий) **И** набор — один мир (центр-заголовок + мотивы + кочующие люди + контекст + мета-рифма). Throughline-как-**мотив** ✅; throughline-как-**зависимость** (лекция требует предыдущей) ❌ |
| Н3 | Контекст | каждая вписана в «математику компьютеров» (эпоха/люди/событие/идея) |
| Н4 | Покрытие | набор закрывает **РАЗНЫЕ** области математики (не 6 про одно) |

## §C. БАЛЛЫ — две оси, 0–3, без весов

Шкала: **0** нет · **1** слабо · **2** крепко · **3** эталонно. Оси независимы, между собой не складываются — тема это точка (A, B). Каждый критерий дожимаем к своему **«3=»** (якорный дескриптор идеала). Чисел 0–10 не вводить.

### Ось A — Продаваемость (почему КУПЯТ; до курса)
| Критерий | Мерим | **3 =** |
|---|---|---|
| A1 | Killer-заголовок | суперинтерес виден из названия |
| A2 | Ширина аудитории | цепляет далеко за айтишников |
| A3 | Драма и лица | персонажи/история — готовое топливо анонса |
| A4 | Визуальный вау | красиво уже в промо |
| A5 | Вписанность в имя-центр | усиливает пакет «математики компьютеров» |

### Ось B — Качество (почему ДОВОЛЬНЫ; во время)
| Критерий | Мерим | **3 =** |
|---|---|---|
| B1 | Самоценность/глубина | богатое поле идей; уносят, даже забыв выкладки |
| B2 | Теор. содержание | плотная доказуемая математика, не «разговор вокруг» |
| B3 | Домашка руками | сильный код/крафт, который доделывают дома |
| B4 | Интерактив | есть что тыкать/решать на лекции |

_Визуал двухуровневый: «вау-картинка» → A4 (промо); «визуализация, дающая понимание» → B1/B4, НЕ в A. Честность обещания НЕ здесь — она ворот Г8 (чтобы не считать дважды)._

## §D. ДВИЖКИ (не баллы — различающие сигналы; ⊕ / – / сильный)

Разрешают ничьи и метят ядро:
- **квиз-аффорданс** — тема афордит рассуждение-к-идее (мини-задачи), не угадайку/факты. Свойство **темы** (≠ ворот Г6 — тот про подачу).
- **обыденное-понятие** — берёт бытовое слово (информация, случайно, оптимально…) и вскрывает смысл. Сильнейший генератор соучастия и квиз-вопросов.
- **двойная-ценность** — тема ещё и хороший мост (горизонталь): рифмы к другим лекциям. Слабая одна, но дающая сильный мост, проходит как `связка` (если ворота лекции пройдены).
- **discovery-fiction (KEYSTONE).** Тему можно подать как *переоткрытие*: естественный вопрос → цепочка простых, почти очевидных шагов (часто включая открытие самой задачи) → результат, с честными тупиками. Сильный — если зал реально может пройти шаги сам. За **один** сигнал метит ядро по драме, соучастию (Г6), честности упрощения (Г5) и квизу. **НЕ** история науки, **НЕ** пересказ статьи. Цена — текст ×2–5 → дозировать: одно ядро руками (Г1), прочее подмигиванием. **Если DF и «обыденное-понятие» срабатывают по одной причине (один естественный вопрос) — это ОДИН keystone-сигнал, не два** (не разводить ничьи двойным счётом).

## §E. РАНГ И РОЛЬ (Pugh к эталону, не абсолютная сумма)

- **Эталон — Монте-Карло** (A-сильный, B-сильный; двойной максимум пула). Каждую тему сравниваем с ним по каждой оси: **лучше / = / хуже** (Pugh). НЕ назначаем «истинное число». Эталонный scorecard — в `anchor.md`.
- **Полосы** на ось: силён / средний / слаб.
- **Роли (режиссёрское правило → значения `verdikt`):**
  - сильна по A **и** по B → **`ядро`** (вход + держит);
  - сильна по A, слабее по B → **`продажник`** (на вход и в название);
  - сильна по B, слабее по A → **`тело`** (в середину, держит и радует);
  - слаба одна, но сильный мост → **`связка`** (только если ворота лекции пройдены);
  - провалила ворота → **`выбыла`** или **`доработать`** (одной строкой — что докрутить).
- **Размещение ≠ только баллы A.** Сильная горизонтальная роль (мета-рифма, хребет, вводная-под-имя) оправдывает место, которого A-балл не дал бы. Решается на уровне НАБОРА (§B/Н2), не по одиночной теме.

> **`verdikt` — РОВНО шесть значений, дословно (для structured_output):**
> `ядро` · `продажник` · `тело` · `связка` · `доработать` · `выбыла`

## §F. ЭТАЛОН И TRIPWIRE АНТИ-ХАКА

Якорь (`anchor.md`) — эталонный scorecard Монте-Карло + ручные сверки владельца — вынесен ВНЕ петли оптимизации и сверяется **каждое поколение** ASSEMBLE.

**TRIPWIRE:** если счёт судьи растёт, а ранг к якорю — нет → **СТОП, флаг, выигрышу не верить** (вероятный reward-hacking). Судья работает в **свежем изолированном** контексте на кандидата и **иным тиром, чем автор** (изоляция ломает общий контекст, разнотирьё бьёт общую слепоту модели).
