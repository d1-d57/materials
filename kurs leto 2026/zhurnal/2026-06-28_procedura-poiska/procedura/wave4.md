## Роль

## Один остров-чемпион
Позвоночник = **«математика компьютеров»** (тьюринговский узел 1936, две ветки). **Оператор дрейфа-недалеко** разрешён (переакцент/переобрамление рядом, НЕ замена); если дрейфанул — пометь флагом для досье.

## Beam по наборам-6
Opus предлагает наборы (мутация + кроссовер в одном вызове: «вот сильные лекции + текущий лучший набор — собери лучше, замени слабейший слот»). **Счёт набора** = ворота Н1–Н4 (пол) + **MMR-покрытие** (λ≈0.7: слабая-дополняющая бьёт сильную-избыточную) + **изолированный судья когерентности** (свежий контекст, ИНОЙ тир — Sonnet судит то, что Opus собрал; анти-хак). **Ворота набора Н1/Н2/Н4 считаешь ТЫ на конкретной шестёрке** (это их законный уровень — набор, не тема): Н1 ≤2 дорогих по подготовке, Н2 единство-антология (каждая лекция держится сама, связь — мотив-рифма, не порядковая зависимость), Н4 покрытие разных областей. Пер-темовые `n1/n2/n4` из `w3` — лишь подсказка, не приговор; баллы тем (оси A/B + ворота лекции Г1–Г8) бери из `w3_deepened.jsonl` как авторитетные.

## Острова-доноры (рефрейм)
1–2 челленджер-фрейма («случайность приручённая», «язык-информация») рождают альтернативные сильные лекции. **Сильная лекция-донор, что вписывается в позвоночник, МИГРИРУЕТ в чемпиона** (рандом-алгоритмы, Марков); сам фрейм затем **отбрасывается** (НЕ второй курс). Лог миграций — в выход.

## Вариации = ВНУТРЕННИЕ развилки (MAP-Elites)
Ниши: дуга сложности / подобласть слота / тип входа / **lecturer-fit** (доказательно vs демонстративно vs историчный вход). Лучший-в-нише = готовая развилка. Пер-слот раннеры в пределах δ = сменные слоты.

## Элитизм + стоп
Чемпион копируется нетронутым между поколениями. Кап **3–5 поколений**. **СТОП** если: чемпион не сменился 2 раунда / маржинальный выигрыш < ε / **сработал TRIPWIRE** (счёт судьи растёт, ранг к якорю — нет → выигрышу не верить, флаг).

## Анти-хак (несущее)
Якорь `anchor.md` сверяется **каждое поколение**. Судья — в свежем изолированном контексте и иным тиром, чем автор. Любой подозрительный скачок счёта без роста ранга к якорю → СТОП + трейс в выход.

## Выход
`artifacts/w4_assembly.json`: чемпион-6 (лекции, порядок, роли) + внутр. развилки по нишам + сменные слоты + лог миграций доноров + трейс анти-хака (поколения, сверки с якорем, сработал ли tripwire). Durable.
