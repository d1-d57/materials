## Концепция — что строим
Не инвентаризировать темы вручную, а **спроектировать запускаемую процедуру** (оркестрацию-мегапромпт для Claude Code), которая сама ведёт поиск курса волнами: широкий дешёвый сбор → триаж → углубление сильной моделью → сборка в **единый курс-организм** из ~6 сплетённых лекций (с внутренними развилками-вариациями). Функция качества — наш `1-START-HERE/sistema-ocenki.md` (судья, построенный прошлой аркой): эта арка строит **поисковик, максимизирующий судью в масштабе**. Поиск вправе **двигать позвоночник** (челленджеры соревнуются по тому же вау-критерию; «математика компьютеров» — действующий чемпион). Цель прогона — **один супер-вау курс + несколько очень хороших вариаций ОДНОГО курса** (развилки внутри), а не портфель разных курсов. **Выход арки:** спроектированная + пилотом проверенная процедура как готовый к запуску заход для Code — НЕ финальный курс (это результат прогона, отдельно).
