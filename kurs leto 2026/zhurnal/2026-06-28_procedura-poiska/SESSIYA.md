## 2026-06-28 — Старт (Ф0): мандат + go

**Намерение (владелец).** Не начинать со списка тем, а изобрести **запускаемую процедуру** поиска: оркестрация для Claude Code, которая волнами гоняет десятки дешёвых агентов (сбор по книгам/научпопу/описаниям YouTube/…), оценивает, отбрасывает слабое, углубляет сильное, собирает полотно (~10 тем), вытягивает 6, плетёт параллели/мотивы/арки в единый организм — каждая лекция идеальна сама и все гармонируют. Запустить на ~1.5–2 ч, дёшево, проснуться к результату. Идея «математика компьютеров» может сместиться; главное — вау на уровне **всей концепции** (чтобы сам загорелся и пересказывал). Просьба: гениальные решения — пусть простые, но бронебойные.

**Развилки (ответы владельца).**
- Граница арки — **дизайн + пилот + заход**: спроектировать процедуру, проверить 15-мин пилотом, написать готовый заход для Code. Полный прогон — отдельно.
- Выход прогона — **один курс-организм + несколько очень хороших вариаций ОДНОГО курса** (развилки внутри: сменные слоты, опц. углубления, ветки), а не 2–3 разных курса. «Что делать с тремя — не представляю; нужен один, что пущу в работу».

**Рефрейм (зафиксировать).** Прошлая арка построила судью (`sistema-ocenki`). Эта строит **поисковик, максимизирующий судью в масштабе**; выход — не темы, а организм курса. Два уровня оптимизации падают из инструмента: вертикаль (баллы лекции) + горизонталь (ворота набора/баланс). Позвоночник подвижен (челленджеры по тому же вау-критерию; «компьютеры» — чемпион).

**Скелет (черновой, до ресёрча).** 5 фаз map-reduce с типизированным scorecard-контрактом: широкий map (дёшево, Haiku, сетка «область×мотив») → триаж (дёшево, ранг к эталону Монте-Карло, ворота-провалы в отвал) → углубление (сильная модель: discovery-fiction-крафт, факт-чек, полный scorecard, крючки/параллели) → сборка организма (beam к ОДНОМУ курсу + внутр. вариации; включая челленджер-позвоночники) → досье решения + вау-питч. Сквозное: durable-артефакт после каждой волны (возобновляемость), стоп-правило на ветку (Старджон — уже в каноне), тиринг бюджета. **Гениально-простое:** ум не в числе агентов, а в типизированном контракте (scorecard в жёсткой схеме) → 100 агентов это map, магия в детерминированном reduce.

**Честные флаги (не свернул под энтузиазм).** (1) Вау не выйдет из Haiku — синтез/плетение только сильной моделью на узком ядре; бюджет = много дешёвого + дорогое ядро на кульминациях. (2) Один прогон = досье, готовое к решению, НЕ гарантированный глоб. оптимум — проектируем под «85% + вкусовой проход владельца». (3) Неоттестированный ночной прогон = риск проснуться над правдоподобным мусором (галлюцинации, дрейф рубрики, дубли, ватные параллели) → пилот обязателен.

Контр-довод («это просто большой промпт») снят: подвижный позвоночник + портфельная сборка к одному организму + контракт качества + возобновляемость = нетривиальный дизайн, требующий ресёрча и пилота.

## 2026-06-28 (II) — Ресёрч-основа закрыта → дизайн v2

**3 субагента вернулись** (детали + источники → `research-osnova.md`). Главное:

**Подтверждения (приятное).** (1) `sistema-ocenki` — провабли *правильная* функция качества для эволюц-поиска: мир независимо говорит «constraint-then-rank лучше взвешенной суммы; одна фикс-рубрика лучше комитета» — это ровно ворота→баллы. Мы построили не просто судью, а корректный фитнес. (2) Подвижный позвоночник = **island model** (FunSearch): острова=позвоночники-кандидаты, эволюция врозь + миграция элит → сходимость к одному чемпиону. Механика, не «на глаз». (3) Н4/баланс = субмодуляр/MMR (формальный движок «слабая-дополняющая бьёт сильную-избыточную»). (4) «Один курс + вариации» = MAP-Elites архив + пер-слот раннеры.

**Поправки к картинке (не свернул).** (1) Не «100 разом»: реально **~50–100 субагентов батчами по 3–5**, узкое место — rate-limits (ITPM/OTPM), не параллелизм; ширина — последовательными дешёвыми батчами. (2) **Судью изолировать** от генератора (свежий контекст на кандидата) + вынесенный якорь — иначе прогон спонтанно «полирует судью», а не курс (ревард-хак через общий контекст, arXiv 2407.04549). (3) **Durable на диск каждую волну** обязателен — авто-компакт может убить контекст, авто-resume нет; оркестрация — headless `claude -p` + Workflow tool, не один чат с Task-фан-аутом.

**Дизайн v2 (5 волн).** GATHER (Haiku, сетка область×мотив) → TRIAGE (дёшево, ворота-отвал, ранг к эталону) → DEEPEN (Sonnet, изолированно: DF-крафт + факт-чек + полный scorecard) → ASSEMBLE (island-beam: предлагает наборы-6, constraint-then-rank, элитизм→чемпион, MAP-Elites→вариации, кап 3–5 поколений, анти-хак-tripwire) → DOSSIER (чемпион + вариации + вау-питч + карта параллелей + развилки). Контракт — типизированный scorecard; источник-на-факт; пилот-дайрон перед ночным прогоном.

**Числа/свежие цитаты помечены «проверить»** (точные капы Code, arXiv-2026 ID); концепты твёрдые (FunSearch/MMR/MAP-Elites/Self-Refine/Anthropic multi-agent).

**СЕЙЧАС (развилка владельцу):** дизайн по сути собран ресёрчем. Перед тем как писать полную спеку процедуры — один параметр (бюджет/ширина сетки) + засев челленджер-позвоночников. Затем — полная спека → пилот → заход.
