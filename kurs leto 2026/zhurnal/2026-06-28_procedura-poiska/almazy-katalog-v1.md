# Каталог алмазов v1 — разведка популяризованного ландшафта

> **Что это.** Курируемая карта сюжетов-«алмазов» для курса «математика компьютеров / может ли машина думать», собранная РЕАЛЬНОЙ разведкой популяризованного ландшафта (Quanta, 3b1b/Numberphile/Veritasium, книги, документалки, русский научпоп + карта festival-скилла) — НЕ из нашей маленькой базы. Правило: у каждого сюжета есть **донор-текст** (на него можно опереться) и арка «конкретная задача → теория → нетривиальное современное приложение». Из этого пула отбираем 6, и **поверх отбора кристаллизуется концепция**.
> **Метки:** Л = тянет лекцию · м = микросюжет/врезка · 🆕 = за пределами канона/свежее · ★донор = сильный донор-текст · ⚠ = слабое место.
> Прогон 2026-06-28. Факты не финальны (нужен deepen+факт-чек), но источники проверены субагентами.

## ЛИНИЯ 1 — ПРЕДЕЛЫ / ВЫЧИСЛИМОСТЬ («что машина НЕ может»)

- **Бобёр-чемпион (Busy Beaver).** 🆕 Л · BB(5)=47 176 870 доказано интернет-сообществом (2024), формальное доказательство на Coq; BB(6) упирается в **Антигидру** — машину, эквивалентную гипотезе Коллатца. Конкретное число → осязаемая невычислимость, «числа, с которыми обычная математика не справляется». Показать: машина Тьюринга с N правил → BB растёт быстрее любой вычислимой функции. ★донор: Quanta ×2 (Брубакер, 2024 и 2025), блог Аронсона, личный блог Брубакера про Антигидру.
- **10-я проблема Гильберта.** 🆕 Л · Мечта об алгоритме для диофантовых уравнений (есть ли целые корни?) → Дэвис–Патнэм–Робинсон–Матиясевич: такого алгоритма нет → расширение 2025 (на любые кольца целых). Механизм показываем: «каждой машине Тьюринга — уравнение». ★донор: Quanta 2025 (история Джулии Робинсон); Матиясевич (книга МИТ).
- **Тао + AlphaProof + Lean.** 🆕 Л(финал) · ИИ берёт серебро IMO, доказывает в Lean; но пределы Гёделя/Тьюринга никуда не делись (что недоказуемо в системе — недоказуемо и для ИИ). Прямой мост «может ли машина думать» → сегодня. ★донор: Quanta 2026, DeepMind blog, Nature 2025.
- **Число Хайтина Ω.** 🆕 м · конкретно определённое невычислимое число (вероятность остановки); зная N цифр — решаешь остановку для программ ≤N, но цифры узнать нельзя. Донор: Chaitin «Meta Math» (есть рус. перевод?).
- **Домино Вана.** м · плитки с цветными рёбрами → замощение плоскости неразрешимо (+ родина апериодических замощений). Визуально. ⚠ нет научпоп-донора уровня Quanta, только Wiki/тех.
- *Доноры-видео для линии:* Veritasium «Math's Fundamental Flaw»; Computerphile «Halting Problem». *Рус.:* Беклемишев (Гёдель/вычислимость), Колмогоровская сложность — Шень.

## ЛИНИЯ 2 — СЛОЖНОСТЬ / ОПТИМИЗАЦИЯ («что машина может, но дорого»)

- **Оптимальный транспорт.** 🆕 Л · Монж (1781, военные земляные работы) → Канторович (ЛП, Нобель-1975) → Виллани/Фигалли (Филдс) → расстояние Вассерштейна в генеративном ИИ (WGAN). Уникальная арка длиной в 240 лет. Показать: задача о землекопах + дуальность. ★донор: Quanta (Фигалли) + пост Lilian Weng про WGAN. ⚠ **факт-чек:** книга Виллани «Рождение теоремы» — НЕ про транспорт (про теорему Ландау); как донор не годится.
- **Симплекс / Данциг.** Л · легенда (опоздал, принял открытые задачи за домашку) → задача о диете Стиглера ($39.93/год) → оптимум в вершине политопа → авиалинии/логистика + свежий результат 2025 о доказанной оптимальности рандом-варианта. ★донор: Quanta 2025 (всё в одном тексте).
- **P=NP и SAT-солверы.** Л · парадокс: NP-трудное «нерешаемо» теоретически, а SAT-солверы верифицируют чипы Intel с миллионами переменных. Идея **сводимости** (раскраска → 3-SAT). ★донор: Quanta (50 лет сложности) + hackerdashery (видео) + Аронсон. ⚠ нет единого текста от Кука до солвера.
- **Стабильные паросочетания.** 🆕 Л/м · Гейл–Шепли (1962) → Рот: это и есть система распределения врачей-ординаторов (с 1952!) → доноры почек, выбор школ, Нобель-2012. Алгоритм + доказательство в зале за 5 мин. ★донор: Нобель popular info + Numberphile + книга Рота «Who Gets What».
- **Колмогоровская сложность.** м(хаб) · «случайное = несжимаемое = кратчайшая программа». Связывает сложность ↔ информацию ↔ случайность. ★донор рус.: Шень (Лекториум), Верещагин–Успенский–Шень (МЦНМО).
- *Микро:* аукцион Викри → Google AdWords (Нобель ×2); задача о секретаре (правило 37%, Hannah Fry).

## ЛИНИЯ 3 — СЛУЧАЙНОСТЬ («как машина имитирует мир / учится через шум»)

- **Монте-Карло, переосмысленный.** 🆕 Л(вход) · НЕ «посчитать интеграл», а **«имитировать мир, который не подчиняется законам»**: Улам в больнице раскладывает пасьянс (1946) → письмо фон Нейману → MANIAC считает нейтроны бомбы → сегодня: физика, финансы, сэмплинг в ChatGPT. ★донор: Эккхардт (LANL 1987), «The MANIAC» Лабатута, «Turing's Cathedral» Дайсона.
- **Диффузионные модели.** 🆕 Л · броуновское движение Эйнштейна (1905) **обращают вспять**: обучи сеть убирать шум → из чистого шума рождается картинка (Stable Diffusion). Приручённая термодинамика XIX века → генеративный ИИ. ★донор: Quanta «The Physics Principle That Inspired Modern AI Art» + 3b1b/Welch Labs + блог Yang Song.
- **Миллер–Рабин: «монетка охраняет банк».** 🆕 Л/м · как RSA узнаёт, что число простое? Бросаешь случайное основание — составное ловится с вероятностью ≥¾; 10 бросков → ошибка <1/10⁶. Каждый HTTPS. Малая теорема Ферма, «свидетель/лжец». ★донор: Numberphile (число 1 662 803) + Quanta «How Randomness Improves Algorithms».
- **Цепи Маркова против джерримендеринга.** 🆕 м · MCMC по пространству всех нарезок округов → «типичная» карта → нечестная видна как аномалия; реально в судах США (Moon Duchin). ★донор: Quanta.
- **Вигдерсон: нужна ли случайность?** 🆕 Л(финал линии) · если трудные задачи существуют, любой рандом-алгоритм дерандомизируется — монетка не добавляет мощи, только упрощает (премия Тьюринга 2024). ★донор: Quanta.
- *Микро:* Башелье (1900) — случайное блуждание цен до Эйнштейна (Physics World; Мандельброт «(Mis)Behavior of Markets»). *Синтез-видео:* Veritasium «strange math predicts (almost) anything» (Улам→Марков→Google→ChatGPT).

## ЛИНИЯ 4 — ИНФОРМАЦИЯ («что машина передаёт / сжимает / предсказывает»)

- **Wordle → энтропия Шеннона.** 🆕 Л(лучший вход) · конкретная игра → нужно изобрести «бит информации» (сколько неопределённости снимает ответ) = энтропия Шеннона → мост к сжатию (Хаффман). ★донор: 3b1b «Solving Wordle using information theory» + Quanta про Шеннона.
- **Код Хэмминга.** Л · Bell Labs 1947, Хэмминг злится на перфокарты → самокорректирующийся код → геометрия шаров в кубе, граница Хэмминга; память, QR, спутники. Выводится за 20 мин. ★донор рус.: МЦНМО (Ромащенко–Румянцев–Шень), Цфасман.
- **Колмогоровская сложность** (см. линию 2 — хаб информация/случайность/сложность).
- **Фильтры Блума.** м · Chrome проверяет «вредоносный ли URL» без полной базы: битовый массив + хеши, может «соврать да», но никогда «соврать нет». ★донор: ByteByteGo + интерактив bloomfilter-tutorial. ⚠ только инженерные каналы.
- *Микро:* демон Максвелла / предел Ландауэра — «информация физична» (есть рус. Хабр-текст).

## ЛИНИЯ 5 — ЯДРО ИИ («как машина учится и думает») ← то, чего не хватало

- **Backprop + градиентный спуск.** 🆕 Л · как сеть учится распознавать рукопись → стоимостная функция → «шарик катится по поверхности в 13000 измерениях» → цепное правило. Единственная математика ИИ, честно показываемая на пальцах за 10 мин. ★донор высш.: 3b1b серия (2017), Nielsen (бесплатная книга + апплеты), Olah (backprop как граф).
- **Трансформеры / attention.** 🆕 Л · как «думает» языковая модель: каждое слово спрашивает все остальные → Q·K/√d → softmax → V; тепловая карта внимания. ★донор: 3b1b (2024, гл.5–6) + Jay Alammar «Illustrated Transformer» + Quanta. ⚠ нужна упрощённая версия (4 токена, 2 измерения).
- **Универсальная аппроксимация.** м · сигмоиды → ступеньки → любая функция (Сайбенко 1989). Интерактивный апплет. ★донор: Nielsen гл.4. ⚠ только один сильный донор.

## НОВЫЕ ОРГАНИЗУЮЩИЕ ИДЕИ (за пределами 4 линий — могут перевернуть концепцию)

- **«Доказательство и доверие».** 🆕🆕 Л · **Доказательства с нулевым разглашением (ZKP):** докажи, что знаешь секрет, ничего не раскрыв (пещера Али-Бабы / 3-раскраска графа) → zk-SNARK в блокчейне, проверка ядерного разоружения. Конкретная математика (вероятностные интерактивные доказательства). ★донор: Numberphile (Вигдерсон) + Quanta «How Do You Prove a Secret?» + Matthew Green primer. **Сильнейший кандидат на ПЯТУЮ линию.**
- **«Порядок из хаоса».** 🆕 Л · логистическое отображение x→r·x(1−x): из одного уравнения про популяции — удвоение периода, **универсальная константа Фейгенбаума 4.669**, бабочка Лоренца, Мандельброт. «Хаос и структура» (твои слова) с готовыми донорами. ★донор: Veritasium «logistic map» + Gleick «Chaos» (бестселлер) + Numberphile (Фейгенбаум) + Quanta.
- **«Неопределённость в мире».** 🆕 Л/м · **фильтр Калмана:** Аполлон-11 садится по его оценкам → GPS → твой телефон. Байес в линейном случае = «сжать эллипс неопределённости новым наблюдением». Мост «случайность → реальное приложение». ★донор: MIT Tech Review + Tim Babb «Kalman filter in pictures».
- **«Форма данных».** 🆕 Л/м · топологический анализ данных (persistent homology): в облаке точек ищем «дыры», barcode-диаграммы; предсказание рецидива лейкоза, форма данных как объект. ★донор: Quanta-трио + Ghrist. ⚠ нет сильного видео, для зала тяжелее.

## Что проступает (концепция — поверх пула, не из головы)

Пул даёт уже **8 линий атаки** на «может ли машина думать»: пределы · сложность/оптимизация · случайность · информация · ядро-ИИ · доверие(ZKP) · порядок-из-хаоса · неопределённость(Калман).
