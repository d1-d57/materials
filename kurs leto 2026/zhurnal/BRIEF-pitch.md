# Бриф: арка «Питч» (готовый текст → HTML-инфографика → карточки)

**Как использовать.** Открой НОВЫЙ чат проекта «Курс Лето 2026», **приложи архив с питчем** (см. §3), вставь этот бриф первым сообщением. Сначала прочитай `COWORK.md` (Правило №0), заводи арку по `ARKA.md` (Ф0). Преемник закрытой арки «Единое окно памяти».

## 1. Цель
Превратить ГОТОВЫЙ текст питча курса в осязаемый результат: (1) питч-мастер в одном доме; (2) красивый **однофайловый HTML** (инфографика/лендинг, быстрый, хорошо работает на телефоне); (3) опционально **промо-карточки** для Telegram (набор картинок к посту канала «Кроссворд Тьюринга»). Текст питча **уже почти готов** — основная работа ВИЗУАЛЬНАЯ (превратить в инфографику). Хочется быстрого осязаемого продвижения (лекции длинные — их отложили).

## 2. Что уже есть (не переоткрывать)
- **Источник фактов о курсе — `0-koncept/KONCEPT.md`** (мастер: 7 лекций, ансамбль героев, манифест на 2 столпах; рабочее имя курса «Пределы вычислимого»). Питч опирается на него и не противоречит; факты — оттуда.
- **Дом питча — `6-lending/`** (в `NAVIGATION` зарегистрирован; `pitch-kurs.md` — заготовка). Демо-затравка `6-lending/_out/pitch-generated.md` (сгенерирована из KONCEPT — только справка/старт, НЕ мастер).
- **Система памяти:** `NAVIGATION.md` (индекс + правило регистрации: любой новый `.md` → строка в индекс, иначе чекер `tools/check_docs.py` упадёт), дома durable в `1-START-HERE/`, гейт `tools/check_docs.py` (прогонять на консолидации).

## 3. Вход владельца — АРХИВ
Владелец приложит архив (zip) с: (а) готовым текстом питча; (б) свободными заметками-идеями «что ещё хочется». **Ф0:** распаковать → положить питч как редактируемый **МАСТЕР** в `6-lending/` (напр. `pitch-kurs.md` или подпапка `6-lending/pitch/`), заметки-идеи — рядом как сырьё арки; зарегистрировать новые доки в `NAVIGATION`. *(Распаковка/перенос = заход Code или владелец на Mac; Cowork из песочницы не двигает, но может создать файлы из содержимого upload.)*

## 4. Последовательность (набросок, уточнить в Ф0 интервью)
1. **Ф0:** распаковать архив → дом питча в `6-lending/` → мастер + заметки; интервью по объёму / тону / CTA / где публикуем.
2. **Питч-текст:** лёгкая доводка (почти готов) под аудиторию канала. Скиллы: `russian-editor`, `kt-channel-editor` (тёплая аудитория; честное позиционирование — без переобещаний).
3. **HTML-инфографика:** однофайловый лендинг/лонгрид — красиво и БЫСТРО. Скиллы: `cinematic-longread` (или `design-taste-frontend`/`web-typography`); перед публикацией/шэром — ОБЯЗАТЕЛЬНО `site-cross-device-audit`; визуальная сверка — `visual-design-review`.
4. **Карточки (опц.):** набор картинок к посту Telegram. Скиллы: `canvas-design` + `visual-design-review`.

## 5. Ограничения
- Факты — из `0-koncept/KONCEPT.md`; не выдумывать, не противоречить концепту. Рабочее имя «Пределы вычислимого» (финальное — открытый вопрос, `dnevnik`).
- **Честное позиционирование** (прошлый курс по терверу ощущался обманчиво сложным — урок; не переобещать).
- **Один риск за раз:** текст → HTML → карточки раздельными шагами; HTML — своя проверка на устройствах.
- Лекции Оптимизация/Криптография — НЕ вперёд питча (отложены, `beklog`).
