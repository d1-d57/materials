# COWORK.md — вход для Cowork (читать первым)

> **КОГДА:** первым в каждой сессии. · **ЧТО дописывать сюда:** только глобальное поведение Cowork + роутер. Арк-механику → `ARKA.md`; решения и числа → `1-START-HERE/`. · **КУДА дальше:** роутер §4.

## 1. Что это
Платный летний онлайн-курс по научпоп-математике (аудитория — культурный багаж инженера + те, кто любит математику саму по себе). Сейчас — фаза концепции. Дальше станет системой HTML-документов: сайт курса + презентации лекций, плюс лендинг. Работа идёт **арками** — многосоставными задачами, у каждой своя папка-память (`ARKA.md`).

## 2. Роли
- **Cowork (ты)** — ресёрч, аналитика, документация, тексты, позже сборка HTML. Видит файлы, есть память проекта.
- **Владелец** — решения и курация: математика, структура курса, голос текстов, скоуп.
- **Claude Code** — точечные кодовые/файловые заходы. Общается через ОДИН файл-заход в папке арки (`ARKA.md §5`); его вход — `CLAUDE.md`.

Дисциплина: **мутирующая правка — после слова владельца; чтение и аудит — сам.** «Разговор первым»: в начале сессии сориентируйся, скажи владельцу, что понял и что предлагаешь, дождись слова — потом пиши файлы.

## 3. Среда: песочница ≠ Mac
Cowork работает в Linux-песочнице, проект живёт на Mac. **Создавать и править файлы — могу; удалять, переименовывать, двигать — нет** (это владелец на Mac или отдельный Code-заход). Имена файлов — латиницей (translit): обходит баг песочницы с «й/ё» (NFD/NFC). Внутри — по-русски.

## 4. Роутер — куда идти (сердце прокладки)

| Ситуация | Куда |
|---|---|
| работа арк-формы (многосоставная, на неск. сессий) | завести/вести арку — `ARKA.md` (Ф0-скрипт) |
| вошёл в существующую арку | арк-ритуал — `ARKA.md §3` (`NAVIGATOR` → `PLAN` → `SESSIYA`), НЕ весь проект |
| разовая мелкая правка | мини-вход: `NAVIGATION.md` + нужный дом, без широкого чтения |
| нужен полный контекст проекта | Правило №0: `NAVIGATION` → `1-START-HERE/dnevnik-i-plan` → `resheniya` / `sloi-arhitektura` |
| вести Claude Code | заход в `zhurnal/<арка>/kod_<тема>.md` (методология — `RUKOVODSTVO-zahodami.md`); Code читает только его |
| источник / ссылка | `biblioteka/ISTOCHNIKI.md` |

**Принятые решения и факты бери из `1-START-HERE/resheniya.md` и `sloi-arhitektura.md`, не из памяти и не из живого дневника.**

## 5. Дисциплина сессии (чтобы память не терялась)
- **Живой дневник арки** (`SESSIYA.md`) — с первого хода (`ARKA §4`). Переживает обрыв окна контекста.
- **Окно конечно и схлопывается молча.** Когда первого сообщения сессии уже нет перед глазами, а работа на готовой точке — скажи владельцу, проведи ритуал конца, начни новый чат. Не уходи в авто-компакт молчком.

## 6. Ритуал конца
- **Конец ЧАТА** (арка продолжается): обнови `PLAN` и при нужде `NAVIGATOR`, строку в `SESSIYA`, выдай хэндофф (`ARKA §6`). Durable в дома НЕ переносим — живёт в арке до закрытия.
- **Конец АРКИ**: консолидация — durable по домам (`resheniya` / `dnevnik-i-plan` / `beklog` / `kotel` / `biblioteka`) + запись в `zhurnal/SVODKI.md` + пометить арку закрытой (`ARKA §7`). Что осталось только в дневнике — не существует.
