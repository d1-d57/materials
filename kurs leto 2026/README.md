# Архив: курс «Математика компьютеров»

Проектирование платного летнего онлайн-курса по научпоп-математике. Рабочий архив, который поднимается новой сессией без потери контекста.

> Рабочее название условно: центральная идея курса ещё не зафиксирована, «математика компьютеров» — одна из идей-кандидатов.

## Начни здесь
1. **`COWORK.md`** — вход: роли, среда, дисциплина сессии, Правило №0. Открывай первым.
2. **`NAVIGATION.md`** — единственный индекс: куда читать и куда дописывать любую новую мысль.
3. **`1-START-HERE/dnevnik-i-plan.md`** — где мы и ближайший шаг.

Карта всех файлов — в `NAVIGATION.md`. Второго списка нет нарочно, чтобы индексы не разъезжались.

## Resume
`COWORK.md` → `NAVIGATION.md` → `dnevnik-i-plan.md` («Текущее состояние», «Ближайший шаг»). Сейчас закончена Ф1; следующий шаг — **Ф2**: собрать из слоёв систему гейтов-и-баллов.

Режим: брейншторм-диалог, по одному вопросу; копить варианты, отбирать по системе. Скиллы: `brainstorming`, `popsci-research`, `popsci-narrative`, `session-handoff`.

## Принцип
Ничего не потерять, всё усилить. Каждый сюжет хорош сам по себе И связан с другими в один мир.
