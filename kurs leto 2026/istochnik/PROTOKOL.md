# PROTOKOL — «где что править» (из SHEMA §8)

Для каждого типа правки — дом (куда писать), задетое (что проверить), что поймает линтер.

| Появилось / правишь | Дом (куда) | Задето (проверь) | Линтер |
|---|---|---|---|
| Новое лицо | `karta/lica.md` (+`{id}`, фото) | лекции, где упомянуть `→[id]` | появления 2–5 |
| Лекция упоминает лицо | `→[id]` + фраза роли-здесь | `lica.md` поле `появления` | резолв id; счёт появлений |
| Новое/правка ребра или нити | `karta/graf.md` | обе лекции в `где:` | квоты графа |
| Сменил порядок лекций | поле `poryadok` в шапках | — (ссылки не трогаются) | `poryadok` уникальны 1–7 |
| Новая/правка теории | `karta/teorii.md` (+`{id}`) | лекции в `лекции:` | резолв `→[T:id]` |
| Матблок/проза лекции | раздел файла лекции | поля-сноски-нити на этот кусок | 4 поля; счётчик матблоков |
| **Правка РАМКИ** (цель лекции, манифест) | `cel` / `svyazujushchee.md` | манифест · таймлайн · карта-идей | **НЕ ловится → ФЛАГ на ревью** |

## Правило семантического рипла

Механический рипл (переименовал id → починить ссылки; сменил появление → счётчик) ловят бэклинк-индекс и линтер. **Семантический** (сменил рамку → надо пересмотреть манифест/таймлайн/соседние переходы) алгоритм не ловит — агент ОБЯЗАН флагнуть «задето по смыслу: {манифест, таймлайн} — на ревью» и вынести владельцу. Смысловые ripple-правки идут через владельца, не закрываются молча.

## Конвенция имён и порядка (renumber-безопасно)

- **Имя файла `istochnik/L{N}-{id}.md`** — стабильный идентификатор; `N` = порядок СОЗДАНИЯ, НЕ текущий порядок лекции. При смене порядка имя файла НЕ меняется (ссылки в проекте идут по `id`, а `build.py` находит лекции по маске `L*-*.md` и читает `id`/`poryadok` изнутри — число в имени ему безразлично).
- **Текущий порядок лекции** = поле `poryadok` в шапке (единственный источник правды порядка). Renumber = правка только этих полей.
- **Выходной HTML** `_out/L{poryadok}-{id}.html` именуется по `poryadok` → при renumber старый выход осиротевает. Правило: **после renumber почистить `_out/` перед пересборкой** (или удалить осиротевший файл вручную).
