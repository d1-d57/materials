# istochnik/ — единый источник правды курса

Правда о курсе лежит здесь, в Markdown. HTML — **чистая функция источника**: правишь MD, пересобираешь, смотришь HTML. Расхождений нет по построению.

## Как регенерить HTML — одна команда

```
python3 istochnik/_generator/build.py
```

→ кладёт самодостаточный офлайн-HTML в `istochnik/_out/L4-kriptografiya.html` (фото вшито base64, без сетевых зависимостей).

## Правило

**Правь источник, не HTML.** HTML перезаписывается при каждой сборке — любая правка в нём потеряется. Каждый сгенерённый блок несёт `data-source="L4-kriptografiya.md §N"` и HTML-коммент перед собой — по ним правка из HTML однозначно возвращается в нужный MD-блок.

## Что где (раскладка, SHEMA §2)

- `LN-<тема>.md` — файлы-лекции (формат v4). Сейчас наполнена `L4-kriptografiya.md`; остальные — скелеты.
- `karta/` — кросс-лекционное (рёбра/нити `graf.md`, лица `lica.md`, теории `teorii.md`, курсовые артефакты `svyazujushchee.md`).
- `_dizajn/` — машинерия сборки (CSS, шаблон, фото). Не правда курса.
- `_generator/build.py` — генератор + линтер + бэклинк-индекс.
- `_out/` — сгенерённый HTML (артефакт, в источник не входит).
- `PROTOKOL.md` — «где что править».

## Доп. команды

```
python3 istochnik/_generator/build.py --backlinks turing   # все места ссылки →[turing]
python3 istochnik/_generator/build.py --lint               # только линтер, без сборки
```

Линтер — падающий тест: структурные ошибки валят сборку (exit≠0), редакционный недобор при `status: chernovik` печатается, но не валит.
