Устный научпоп-рассказ на два урока (полтора часа с перерывом) для 4–6 сильных школьников, выбравших
проект В. Тиморина «Разрезания многогранников». Ресёрч-цикл, лёгкий режим.

## Бриф (лёгкий режим: три поля + логистика)

1. тема: равносоставленность; Бойяи — Гервин на плоскости, инвариант Дена и третья проблема Гильберта в пространстве
2. аудитория: 4–6 школьников проектной группы 179, сильные («прошарены»), формат диалога у доски
3. throughline: чтобы доказать «нельзя», нужна величина, не меняющаяся при разрезании; внутренний разрез
   считается дважды и сокращается — на плоскости без поворотов это даёт $J_u$, в пространстве — инвариант Дена
4. длительность: два урока с перерывом; бюджет слайдов не считается — доска, не дек
5. что режем: см. `PLAN.md` § «Что режем»
6. материал: записки Тиморина ЛШСМ-2024, рукописные слайды «режем», Айглер — Циглер; карточки — `KARTOCHKI.md`
7. строгость: формулировки полностью, доказательства ходами у доски; полные — в `SKELET.md`
8. формат: устный доклад-диалог, одна лекция; выход цикла — HTML-лента с картинками (следующий заход)
