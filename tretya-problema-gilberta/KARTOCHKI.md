## Нить (одна, для `PLAN.md`)

к-вопрос → к-бойяи → к-хадвигер → [перерыв] → к-призмы → к-гаусс/к-гильберт → к-ден → к-вершины → к-иррац → к-проверки
→ к-сидлер → к-выбор/к-банах → к-тиморин.
Вне нити (кунсткамера): к-краков, к-блэкмаунтин, к-хилл (как отдельная тема).

## «Но» в материале (гейт G2)

1. В 2D ответ «да», в 3D «нет» — разворот встроен в сюжет.
2. Предпосылка «у Айглера — Циглера этого нет» ложна: глава есть (И3).
3. Предпосылка «нужна аксиома выбора» неточна: для теоремы Дена — нет (к-выбор).
