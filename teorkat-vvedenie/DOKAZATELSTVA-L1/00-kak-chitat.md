# Доказательства к разделам 3–4 лекции 1

**Что это.** Шпаргалка лектора: всё, что напечатано на слайдах блоков `C`, `D`, `E` **и разбирается**, доведённое до состояния, проверяемого глазами. Не конспект и не сценарий — только выкладки.

**Закон записи, по которому собран документ.** Каждое отображение выписано явно: что куда переходит. Каждое равенство композиций проверено на элементе. Каждый нестандартный термин определён на месте. Ничего не надо достраивать в уме.

**Три линии, и каждая — связная последовательность.** После каждого утверждения стоит строка «**Зачем и что дальше**»: она называет, для чего утверждение и что мотивирует следующее. Утверждений, висящих без такой строки, в документе нет.

| линия | о чём | утверждений |
|---|---|---|
| **A** | Конструкция не функториальна → Брауэр | 4 (1 инструмент + 3 применения) |
| **B** | Естественных преобразований нет / сколько их бывает | 5 (1 инструмент + 4 применения) |
| **C** | Изоморфизм против эквивалентности → Стоун | 3 |

Итого **12**: два инструмента линий и десять применений.

> поле:mn Вкладка **«Находки»** — отдельная и важная: три настоящие математические ошибки в источниках и список мест, где слайд утверждает больше, чем доказывает. Прочитать до лекции: там сказано, чего произносить нельзя.

## Словарь обозначений — одно понятие, одно обозначение

Приведено к единому виду по всему документу.

| знак | значение |
|---|---|
| $g\circ f$ | сначала $f$, потом $g$ |
| $\mathrm{id}_A$ | тождественный морфизм объекта $A$ (нигде не пишем $1_A$) |
| $\mathbb Z_2=\{0,1\}$ | группа из двух элементов, сложение по модулю $2$. **Это не свободная группа и не $S_2$-как-множество** — ровно два элемента |
| $S_3$ | перестановки $\{1,2,3\}$; $(1\,2)$ — транспозиция, $(1\,2\,3)$ — цикл $1\mapsto2\mapsto3\mapsto1$ |
| $Z(G)$ | центр группы: $Z(G)=\{z\in G:\ zg=gz$ для всех $g\in G\}$ |
| $[n]$ | $\{1,\dots,n\}$; в частности $[0]=\varnothing$ |
| $\mathbf{Grp}$, $\mathbf{Set}$, $\mathbf{Top}$ | группы, множества, топологические пространства |
| $\mathbf{FinSet}$ | конечные множества и все отображения |
| $\mathbf N$ | объекты — числа $0,1,2,\dots$; морфизм $n\to m$ — отображение $[n]\to[m]$ |
| $V^{\ast}$ | $\mathrm{Hom}_k(V,k)$ — двойственное пространство |
| $\mathcal V$ | группоид: объекты — конечномерные $k$-пространства, морфизмы — **только изоморфизмы** |
| $\alpha\colon F\Rightarrow G$ | естественное преобразование; $\alpha_A\colon FA\to GA$ — его компонента |
| $\mathrm{Aut}(A)$ | обратимые морфизмы $A\to A$ |
| $\mathrm{At}(B)$ | атомы булевой алгебры — минимальные ненулевые элементы |
| $\langle x,y\rangle$ | скалярное произведение в $\mathbb R^2$, $\lVert x\rVert^2=\langle x,x\rangle$ |
| $D^2$, $S^1$ | $\{x\in\mathbb R^2:\lVert x\rVert\le1\}$ и $\{x\in\mathbb R^2:\lVert x\rVert=1\}$; $i\colon S^1\to D^2$, $i(x)=x$ |
| $\{e\}$ | тривиальная группа — **одно** обозначение на весь документ. На слайдах она местами записана аддитивно, как $0$ или $1$; это то же самое |

**Определение (функтор), для ссылок.** $F$ сопоставляет объекту объект, морфизму $f\colon A\to B$ морфизм $Ff\colon FA\to FB$, и выполняет два равенства: $F(g\circ f)=Fg\circ Ff$ и $F(\mathrm{id}_A)=\mathrm{id}_{FA}$. Оба используются постоянно и по отдельности.

**Определение (естественное преобразование).** $\alpha\colon F\Rightarrow G$ — семейство $\alpha_A\colon FA\to GA$, для которого при любом $f\colon A\to B$
$$\alpha_B\circ Ff=Gf\circ\alpha_A.$$
Это и есть «квадрат естественности». **Естественный изоморфизм** — такое $\alpha$, у которого каждая компонента обратима.
