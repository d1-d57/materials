Это главная таблица файла. Проект пересобран с нуля именно потому, что в прошлой папке один и тот же факт жил в пяти местах и они разъехались.

| Факт | Единственный дом | Правило |
|---|---|---|
| **Что строим:** зал · жанр · охват · потолок · финал · объём · профиль · карта понятий | **`SPEKA.md`** | Противоречит другой док — **прав SPEKA**. Дублировать факт в другом файле нельзя даже «для удобства»: копия и есть механизм расхождения |

| **Сюжеты и линии:** банк находок · вердикты по гейту · линии (гипотеза) | **`KOTYOL.md`** | Рабочий, дрейфует через гейт. **Не картотека** (та внешняя, переиспользуемая) — решения этого курса. Карта понятий кристаллизуется отсюда в `SPEKA §Охват` |

| **Ход работы, решения с «почему»** | арка в **`../_studio/zhurnal/<дата_тема>/`** | Арки всех проектов живут в фабрике, не в папке проекта — так их заводит `bootstrap_arka.py`. Ритуал — `_studio/docs/kak-delat/ARKA.md`. Активная: `2026-07-20_vvedenie-sborka` |

| **Как делать** (движки, гейты, стандарты, иллюстрации) | `_studio/` и `_generator/` | Канон не переписываем. Отклонения проекта — строкой в `SPEKA §Наследование` |

## Куда дописывать

| Появилось | Пиши сюда | Не пиши |
|---|---|---|
| решение владельца о рамке | `SPEKA.md` + запись в дневник арки | в README, в заход, в память |
| сдвиг духа / критерия отбора | `DUH.md` (редко, с датой) + арка | в SPEKA |
| новый сюжет / вердикт по сюжету / изменение линии | `KOTYOL.md` — **дрейф явным ходом, с проверкой, не молча** | молча; в SPEKA до того, как устоялось |
| понятие, узел, находка | **в картотеку по её адресу** — она вне проекта | ❌ не заводить картотеку внутри проекта |
| новый внешний ресурс | `VNESHNIE-RESURSY.md §Адреса` | не прописывать путь по месту использования |
| намеренное расхождение с ТЗ | закрытый список в шапке `SPEKA.md`, со ссылкой на решение | молча |
| новый проект или маршрут в фабрике | `../README.md §2–3` и `_studio/` | сюда |
