## Учёт кусков — считается командой, не вписывается руками

Куски ленты (заголовки `## ` в `LENTA-L2.md`):

```
grep -c "^## " teorkat-vvedenie/LENTA-L2.md
```

Кто какой кусок несёт (поле `matematika_iz` карточек):

```
grep -h "^matematika_iz:" teorkat-vvedenie/L2/slajdy/*/slaid.md \
  | sed 's/matematika_iz: //' | tr -d '[]' | tr ',' '\n' \
  | sed 's/^ *//;s/ *$//' | grep -v '^$' | sort -u
```

Кусок без хозяина (то есть настоящая вырезка) — разность этих двух списков. На **2026-08-12** разность
пуста: у каждого из тринадцати кусков есть минимум одна карточка.
