Дальний конец: стрелка ничего никуда не переводит, она сама предмет геометрии

**Кобордизмы.** Объектами служат конечные наборы окружностей, морфизм есть поверхность с этими наборами в качестве границы, с точностью до диффеоморфизма; композиция есть склейка по общей границе, тождество есть цилиндр

**Косы и танглы.** Объектами служат конечные наборы точек, морфизм есть сплетение нитей; композиция есть стыковка одного сплетения под другим, тождество есть нити без переплетений

Склеить две поверхности и скомпоновать два морфизма — буквально одна операция
