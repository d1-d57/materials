{.op-def} Определение

По ориентированному графу строится категория: вершины служат объектами, морфизм $u\to v$ есть путь из $u$ в $v\text{,}$ включая пустой путь при $u=v\text{;}$ композиция есть приписывание путей, тождество есть пустой путь

{.op-def} Определение

Произведение $\mathcal C\times\mathcal D\text{:}$ объектами служат пары объектов, морфизмами пары морфизмов покомпонентно

{.formula} $\displaystyle (\mathcal C\times\mathcal D)\bigl((C,D),(C',D')\bigr)=\mathcal C(C,C')\times\mathcal D(D,D')$

Композиция и тождества покомпонентные. Арена двуцветных множеств есть в точности произведение двух копий группоида конечных множеств
