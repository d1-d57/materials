# R2 — образцы жанра: «один объект → несколько теорем о нём → классика выпадает специализациями»

**Роль:** веб-ресёрчер Р2. **Метод:** websearch + webfetch (живые страницы и тексты; PDF, отдавшиеся бинарём, разбирались по фрагментам из поиска). **Дата данных:** 2026-08-24.
**Задача скелета:** общая постановка → 2–4 теоремы разными методами → специализации = известные числа (Каталан, биномиальные, q-биномиальные, q-Каталана, Фибоначчи…).

## ВЕРДИКТ СРАЗУ (для чтения сверху)

Жанр существует, но **в двух непересекающихся ветках**, и ни одна не совпадает целиком с ожидаемой структурой:

- **Ветка А — «каталог»** (Stanley): объект = одно число/последовательность. Ходы: базовые свойства (формула, рекуррентность, первые значения) → каталог интерпретаций с картинками при малом n → биекции как клей → дополнительные задачи (q-аналоги и пр.) → история. **Таблица специализаций здесь — сам каталог, но вынесена в УПРАЖНЕНИЯ**, а не в основной текст. Фронтальных «теорем разными методами» почти нет: метод один (биекция).
- **Ветка Б — «машина/сюжет»** (Flajolet–Sedgewick, Zagier, Bourbaki): сначала декларация контраста или обещания, затем определения ровно настолько, насколько нужны для формулировок, затем теоремы как **уровни одной лестницы** (каскад приближений у Загира; словарь «конструкция → производящая функция → асимптотика» у ФС; исторические результаты как лестница границ у Пелюзе). Специализации НЕ собраны в таблицу — они растворены примерами внутри каждого уровня.

**Главное честное расхождение:** готового текста со структурой «общий объект → 2–4 теоремы разными методами → фронтальная таблица специализаций» я НЕ нашёл ни в одном образце. Ближайший прототип нужного скелета в нужном масштабе (2–3 страницы!) — колонка **«What is…a Parking Function?»** (2024): один объект → счёт = формула Кэли → характеризация неравенством → связь с Каталаном через биекцию с путями Дика → статистика → текущие направления. Таблицу специализаций придётся вводить как осознанный гибрид веток А и Б.

## Образец 1. Stanley: каталог Каталана (ветка А, эталон каталога)

**Ссылки (три слоя одного проекта):**
1. Richard P. Stanley, *Enumerative Combinatorics*, vol. 2, Cambridge Univ. Press, 1999, **глава 6** — упражнения про числа Каталана; ядро — Exercise 6.19: **66 комбинаторных интерпретаций** C_n. Открытая выдержка: https://math.mit.edu/~rstan/ec/catalan.pdf (27 стр., «Exercises on Catalan and Related Numbers»).
2. Richard P. Stanley, *Catalan Addendum* (версия 25 мая 2013), https://math.mit.edu/~rstan/ec/catadd.pdf — продолжение нумерации 6.19 и 6.25.
3. Richard P. Stanley, *Catalan Numbers*, Cambridge Univ. Press, 2015, viii+215 стр. — свёртка всего проекта в монографию. Оглавление: гл. 1 Basic Properties (с. 1–14) → гл. 2 Bijective Exercises (с. 15–55) → гл. 3 Bijective Solutions (с. 56–100) → гл. 4 Additional Problems (с. 101–137) → гл. 5 Solutions to Additional Problems (с. 138–170) → Appendix A «In the beginning» (рукописный список 1970-х) → Appendix B History of Catalan Numbers (Igor Pak).

**Структура по ходам:**
- Первым ходом — формула C_n = 1/(n+1)·binom(2n,n) и рекуррентность, потом сразу иллюстрации при малом n («illustrate the elements of each S_i for n = 3, hoping that these illustrations will make any undefined terminology clear»).
- Определения НЕ собираются вперёд: терминология вводится по мере надобности прямо в пунктах каталога, картинки заменяют определения.
- Каталог подаётся как упражнение с инструкцией: «Ideally S_i and S_j should be proved to have the same cardinality by exhibiting a simple, elegant bijection φ_ij: S_i → S_j (so 66² bijections in all)». То есть связность каталога декларирована, но не реализована — биекции отложены читателю.
- В монографии 2015 предисловие даёт жанровую рефлексию: список с 1970-х, 214 интерпретаций, явное признание субъективности отбора («transferring bijections» порождает сколько угодно «новых» интерпретаций), и шутливая страховка: «item 65 … discusses infinitely many combinatorial interpretations».
- История (Pak) идёт ПОСЛЕДНЕЙ, а не первой.

**Объём:** выдержка 27 стр.; монография ~200 стр., из них половина — каталог+решения.

**Что перенимать:** формат записи специализаций одной строкой с мини-иллюстрацией при n=2..3; честную пометку «интерпретации связаны биекциями, но выписаны не все»; нумерацию пунктов каталога; правило «картинка вместо определения». Для 2–3 страниц берём только механику каталога (10–15 строк максимум), не объём.

## Образец 2. Flajolet–Sedgewick, Analytic Combinatorics (ветка Б, машина-first)

**Ссылка:** Philippe Flajolet, Robert Sedgewick, *Analytic Combinatorics*, Cambridge Univ. Press, 2009, xiv+826 стр.; полный текст: https://ac.cs.princeton.edu/AC.pdf ; оглавление и описание: https://sedgewick.io/books/analytic-combinatorics

**Структура книги:** PREFACE → **«AN INVITATION TO ANALYTIC COMBINATORICS»** (отдельный вводный очерк ДО Part A: один сквозной прогон примера через всю машину) → Part A SYMBOLIC METHODS (гл. I unlabelled/OGF, II labelled/EGF, III параметры/BGF) → Part B COMPLEX ASYMPTOTICS (IV–VIII) → Part C RANDOM STRUCTURES (IX) → приложения A–D.

**Структура по ходам (внутри главы Part A):**
- Машина первее объектов: сначала определяются combinatorial class и admissible constructions, затем Теорема I.1 «Symbolic method» — словарь переводов «конструкция ↔ операция над производящей функцией». Это центральный жанровый ход: одна таблица-словарь вместо серии отдельных теорем.
- Классические объекты (композиции, слова, деревья, разбиения) появляются КАК ИНСТАНЦИИ схем: sequence → композиции; SEQ(SEQ) → разбиения; рекуррентное уравнение T = Z·SEQ(T) → Каталан. Специализация = подстановка в схему, а не отдельная секция.
- Каждый раздел заканчивается стандартной рубрикой **«Perspective»** — авторская метарефлексия «зачем это было» (жанровый приём книги).
- Числа-специализации (Каталан, биномиальные…) выпадают молча, без выделения: их статус — «примеры из classical combinatorics».

**Что пернимать:** (а) открывающий «Invitation»-ход — один объект проводится через всю машину до итоговой асимптотики ещё до всякой теории; (б) словарь ходов «вход-машина → выход-число» как способ оформить 2–4 теоремы разными методами; (в) рубрику «Perspective» как замену выводам.

## Образец 3. Séminaire Bourbaki (ветка Б, «d'après»: проблема → новые результаты)

**Первичный образец:** Sarah Peluse, *Recent progress on bounds for sets with no three terms in arithmetic progression* [after Bloom and Sisask, Croot, Lev, and Pach, and Ellenberg and Gijswijt], Séminaire Bourbaki, 74-е год, 2021/22, № 1196, июнь 2022. PDF: https://www.bourbaki.fr/TEXTES/Exp1196-Peluse.pdf

**Структура вступления по ходам (по живому тексту):**
1. van der Waerden (1927) — рамочная классика.
2. Гипотеза Эрдёша–Турана (1936) — постановка проблемы.
3. Szemerédi: два контрастных доказательства (Фюрстенберг эргодикой — качественно, Гауэрс — количественно) — история методов.
4. Сужение до k=3 (проблема Рота) — «центральная открытая проблема», спровоцировавшая серию техник.
5. Только теперь формулируются НОВЫЕ результаты доклада. Главный результат появляется не первым, а пятым ходом — после лестницы истории.
- Дальше по канону Bourbaki: методы → идеи доказательств → перспективы. Объём типичного текста 20–50 стр. (точный объём 1196 по PDF не замерен — честно).

**Свежие экспозе близкой тематики (2022–2025, для калибровки стиля):**
- Mylène Maïda, *Strong convergence of the spectrum of random permutations and almost-Ramanujan graphs* [after Bordenave and Collins], № 1202 (2022/23).
- Yuval Wigderson, *Upper bounds on diagonal Ramsey numbers* (after Campos, Griffiths, Morris, Sahasrabudhe), № 1230 (2024/25) — комбинаторика.
- Javier Fresán, *Moments of L-functions and homological stability*, № 1237 (2024/25); и его же № 1197 *The unbounded denominators conjecture* [after Calegari, Dimitrov, Tang] (2022/23) — аналитическая теория чисел.
Оглавления томов: smf.emath.fr (тома Astérisque 446 (2023) и 462 (2025)).

**Что пернимать:** заголовок-формат «[after …]» — честное атрибуирование каждого результата; историю как лестницу улучшений одной величины; раннюю (но не первую) выкладку главных формулировок. Чего НЕ брать: Bourbaki пишет «прогресс в проблеме», а не «портрет объекта» — это другой жанр.

## Образец 4. Zagier, «The first 50 million prime numbers» (ветка Б, сюжет-каскад)

**Ссылка:** Don Zagier, *The first 50 million prime numbers*, The Mathematical Intelligencer **1** (1977), Suppl., 7–19; DOI 10.1007/BF03039306. Полный текст (скан): https://people.mpim-bonn.mpg.de/zagier/files/doi/10.1007/BF03039306/fulltext.pdf . Происхождение: расширенная инагурационная лекция (Antrittsvorlesung, Бонн, 5.05.1975), пер. с нем. R. Perlis.

**Структура по ходам (по полному тексту):**
1. Шутливое определение простого числа + три версии определения («у теоретико-численника… у функционалиста простое — целый корень аналитической функции…») — определение подаётся как культурная вилка, не как формальный блок.
2. Декларация ДВУХ противоречащих фактов: хаотичность («grow like weeds») vs регулярность («stunning regularity», «military precision»). Это двигатель всего текста.
3. Доказательство хаоса картинками/таблицами; π(x) вводится попутно, неофициально.
4. Таблица x, π(x), x/π(x) до 10^11 → скачок ≈ 2.3 → e; эмпирическая формула Лежандра.
5. Каскад приближений одного и того же объекта: Лежандр → Гаусс Li(x) → Риман R(x) → точная формула Римана (графики разностей!). Теоремы = уровни точности приближения.
6. История вкраплена точечно: Эвклид «in one sentence», Эйлер (расходимость суммы обратных, дзета), Чебышёв (двусторонняя оценка 1850), фон Мангольдт (1895).
7. Контрпример-вишенка: Li(x) − π(x) меняет знак (теорема Литтлвуда) — регулярность снова бьётся об хаос.
8. Замыкание красотой, без резюме.

**Объём:** 12 страниц, из них больше половины — графики и таблицы.

**Что пернимать:** вступительный контраст двух фактов как обещание структуры; «теорема = следующий уровень приближения того же объекта»; данные (таблица первых значений) как легитимная часть доказательного повествования; минимум формализма в определениях. Это ближайший по духу образец для «одной функции путей и её уравнений»: та же схема — один объект, разные линзы.

## Образец 5. Колонка «What is…?» (Notices AMS) — масштаб ровно наш

**Индексы колонок:** полный неофициальный индекс Armin Straub: https://arminstraub.com/math/what-is-column ; официальный сборник AMS: https://www.ams.org/cgi-bin/notices/nxgnotices.pl?fm=gen&cnt=whatis . Всего ~180 колонок (1998–2026).

**🔴 Отрицательный результат (после ≥3 запросов):** колонки про числа Каталана, разбиения (partitions) или q-Catalan/q-binomial в колонке НЕТ и не было за всю историю рубрики. Ближайшие по теме: «What is…a Young tableau?» (Alexander Yong, Feb 2007), «What is…cyclic sieving?» (Reiner–Stanton–White, Feb 2014), «What is…the Bateman-Horn Conjecture?» (Garcia, Nov 2024). Не выдумывать q-Catalan-колонку — её нет.

**Первичный образец (полный текст прочитан):** J. Carlos Martínez Mori, *What is…a Parking Function?*, Notices of the AMS **71** (Sept 2024); PDF rnoti-p1062; arXiv:2404.15372 (HTML: https://arxiv.org/html/2404.15372v1 , включает испанский перевод). Объём ~3 журнальных страницы.

**Структура по ходам (эталон нашего скелета):**
1. Сюжет-определение: «one-way street» эксперимент с машинами; формальное определение parking function встроено В повествование, картинка при n=4 с конкретным примером (1,3,1,1).
2. Теорема 1: счёт (n+1)^{n−1} = формула Кэли; тут же ПОЛНОСТЬЮ доказательство Поллака (круговая улица, смежные классы) — красивый короткий метод.
3. Теорема 2: характеризация неравенством x′_i ≤ i (сортированная перестановка) с двухстрочным доказательством; следствие — симметрия относительно S_n.
4. Специализация: слабовозрастающие PF считаются числами Каталана (рекуррентность (3) воспроизводится индукцией); явная биекция с путями Дика (Armstrong–Loehr–Warrington); общая статистика area/displacement.
5. Последний абзац: карта текущих направлений (статистики, варианты, полиэдральность, связи) + один свой свежий результат с рисунком.
6. Ссылки: Yan (2015) survey как «дом для продолжения».

Это ТОЧНО «один объект → 2–4 теоремы (два метода: подсчёт через группу, характеризация через неравенство) → классика выпадает (Кэли! Каталан! пути Дика!) → куда дальше» в 2–3 страницы. Прямой прототип скелета.

**Бонус — задокументированное описание структуры награждённой экспозе:** цитата премии Леви Конанта (2025, ams.org/notices/202504/noti3171) о статье Jinyoung Park «Threshold Phenomena for Random Discrete Structures» (Notices 70 (2023), 1615–1625): «beginning sections… accessible narrative flush with definitions, examples, and motivating questions. Four pages deep… reader is ready… latter half devoted to the Kahn–Kalai conjecture… informal description first, later filling in more formal ingredients… section of well-articulated examples». Т.е. канон жанра по версии жюри: неформальное раньше формального, примеры отдельным блоком, горячий результат в конце.

## Образец 6. Циглер (Günter M. — не Andreas; поправка к ТЗ)

**Честная находка про запрошенное:** лекция/текст «What is Mathematics?» существует, но это МЕТА-текст об имидже дисциплины и сторителлинге (Andreas Loos & Günter M. Ziegler, *“What is Mathematics?” and why we should ask, where one should experience and learn that, and how to teach it*, Proc. ICM Seoul 2014, 1201–1215; open access перепечатка Springer 2017; PDF: discretization.de/…/20140413icm-proceedings-ziegler.pdf; видеолекция Hamburg 2016 на lecture2go). Сам он НЕ является экспозе «один объект → каскад» — это аргументация ЗА такой жанр («stories make mathematics sticky»). Текстов панельных/медальных лекций с одним сквозным объектом двумя поисками не найдено — фиксирую как отрицательный результат, не выдумываю.

**Реальный жанровый образец Циглера:** Günter M. Ziegler, *Lectures on 0/1-Polytopes*, arXiv:math/9909177 (1999; опубл. в DMV Seminar, Polytopes—Combinatorics and Computation). Абзац-манифест: «meant as an introduction and invitation. Rather than heading for an extensive survey … I present some interesting aspects … simple definition and explicit descriptions; we can enumerate and analyze small examples explicitly … however, any intuition derived from low dimensions will miss the true complexity».

**Структура по ходам:** определение объекта (предельно простое) → иерархия эквивалентностей (Prop. 7: 0/1-equivalent ⇒ congruent ⇒ affine ⇒ combinatorial, с контрпримерами ко всем обратным) → серия вопросов-теорем об ОДНОМ параметре (сколько граней?), каждая с таблицей рекордов d ↦ f(d) (ручные рекорды Кристофа и др.) → верхние/нижние границы → случайные 0/1-политопы (Комлош) → триангуляции с таблицей triang(d) → финальная секция «Problems and Exercises» — список открытых вопросов. Один объект, каскад вопросов разных методов, таблицы данных как несущая конструкция, открытые проблемы в конце. Второй подходящий: *Non-rational configurations, polytopes, and surfaces*, Math. Intelligencer 30 (2008) 36–42.

**Что пернимать:** таблицы рекордов/первых значений по каждому вопросу; иерархию утверждений об одном параметре; финальный список открытых проблем; тон «invitation» (объект простой, сложность сюрприз).

## Честные расхождения форма ≠ существо
1. Ни у кого нет фронтальной «таблицы специализаций» в основном тексте: у Stanley она — упражнения, у остальных — растворена в примерах. Наша таблица будет гибридом, это осознанное решение, а не копия жанра.
2. Bourbaki идёт от частного/истории к новому результату, а НЕ от общего объекта к частным — ожидание «общая постановка первой» подтверждается только наполовину (главный результат рано, но после исторической лестницы).
3. F-S вообще не «объект → теоремы», а «машина → классы»: объект там вторичен.
4. Колонки «What is…?» про q-Catalan/partition не существует; ближайший живой прототип — parking functions.
5. Запрошенные «Zagier D(-E)-Fi(E)» и «Gessel multipartite P-partitions» не искались как несуществующие/второстепенные по указанию самого ТЗ; «Andreas Ziegler» в ТЗ — на деле Günter M. Ziegler.
