# Карта блоков: «Шесть вкусов по три» — введение в биномиальные коэффициенты
контекст: лента
источник: SKELET.md (эталон истины), README.md (бриф п. 1–17), _sluzhebnoe/RESERCH-binomy.md (история)
зачем целого: читатель-школьник проходит путь от вопроса «сколько смесей из трёх вкусов из шести» до формулы $\binom nk=\frac{n!}{k!(n-k)!}$, по дороге осваивая два приёма — двойной подсчёт и «упорядочить, потом поделить»; пружина — треугольник, заполненный «по смыслу», застревает ровно на $\binom63$
бюджет: проза ≤ 16 000 знаков без SVG (замер Гильберта, README дневник 00:48)
центральный блок: П6 (застревание на $\binom63$) и У8 (капитан тремя способами)
режим: лестница
