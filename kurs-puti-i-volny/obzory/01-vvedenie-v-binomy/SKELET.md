## Часть 0. Два правила счёта (общеизвестное)

**Принцип 0.1 (правило суммы).** Если конечное множество разбито на попарно непересекающиеся части $X_1,\dots,X_m$, то
$|X|=|X_1|+\dots+|X_m|$. *Без доказательства — общеизвестное.* `уровень: школьно`

**Принцип 0.2 (правило произведения).** Если объект выбирается в $k$ шагов, на $j$-м шаге, при любых выборах на
предыдущих шагах, есть ровно $m_j$ вариантов, и каждый объект получается ровно одной цепочкой выборов (разные цепочки
дают разные объекты, и любой объект какой-то цепочкой получается), то объектов $m_1m_2\cdots m_k$. *Без доказательства — общеизвестное.*
`уровень: школьно`

**Утв. 0.3 (правило деления).** Пусть $X,Y$ — конечные множества, $f\colon X\to Y$ — отображение, и у каждого $y\in Y$ ровно
$m\ge1$ прообразов. Тогда $|X|=m\,|Y|$, то есть $|Y|=|X|/m$.
*Идея.* Разложить $X$ на кучки по значению $f$.
*Доказательство.* Множества $f^{-1}(y)$, $y\in Y$, попарно не пересекаются и покрывают $X$; в каждом $m$ элементов.
По правилу суммы $|X|=\sum_{y\in Y}m=m|Y|$. ∎
`уровень: школьно` · *в статье — словами: «каждый предмет посчитан $m$ раз — делим на $m$»*

**Утв. 0.4 (биекция сохраняет число).** Если $f\colon X\to Y$ — биекция (взаимно однозначное соответствие), то $|X|=|Y|$.
Частный случай 0.3 при $m=1$. ∎ `уровень: школьно`

## Часть 1. Определение и два языка

**Опр. 1 (биномиальный коэффициент).** Для целых $n\ge0$, $k\ge0$ число $\binom nk$ («из $n$ по $k$») — это количество
подмножеств $A\subseteq[n]$ с $|A|=k$.
*Пример.* $\binom32=3$: подмножества $\{1,2\},\{1,3\},\{2,3\}$. *Проверка числа:* $\binom63=20$ — `proverki.py` (вступление).
*Обозначения.* В русской школе — $C_n^k$; скобочная запись **без черты дроби** — у Эттингсгаузена, 1826 (Р, A, ✓✓;
у Кахори — 1827; у Эйлера 1778/1781 — скобки с чертой). Происхождение $C_n^k$ не
найдено (Р, «на-сверку») — в статье не утверждать.
*Граница (v3, решение владельца 04.10 12:06, В15).* При $k>n$ подмножеств нет и $\binom nk=0$. При $k<0$ число не определяется.
`источник: З2, З3 доска 1` · `уровень: школьно`

**Замечание 1.1 (любое множество из $n$ элементов).** Если $|X|=n$, то $k$-подмножеств у $X$ ровно $\binom nk$.
*Доказательство.* Занумеруем элементы: $X=\{x_1,\dots,x_n\}$. Отображение $A\mapsto\{x_i: i\in A\}$ — биекция между
$k$-подмножествами $[n]$ и $k$-подмножествами $X$ (обратное — взять номера). Утв. 0.4. ∎
*Зачем:* дальше $\binom nk$ считает подмножества вершин, людей, множества $[n]\setminus\{c\}$ — всюду по этому замечанию.
`источник: рецензия 04.10, пробел 1` · `уровень: школьно`

**Утв. 2 (подмножество = слово).** Отображение $\varphi$, сопоставляющее множеству $A\subseteq[n]$ слово $w$ с $w_i=1\iff i\in A$,
— биекция между подмножествами $[n]$ и словами длины $n$; при этом $|A|$ равно числу единиц в $\varphi(A)$. Следовательно,
$\binom nk$ равно числу слов длины $n$ ровно с $k$ единицами.
*Доказательство.* Обратное отображение: слову $w$ сопоставить $\{i: w_i=1\}$. Композиции в обе стороны тождественны; число
единиц слова равно числу его позиций с $w_i=1$, то есть $|A|$. Остаётся утв. 0.4. ∎
*Пример.* $n=5$: $\{1,2,3\}\leftrightarrow11100$, $\{2,3,4\}\leftrightarrow01110$, $\{3,4,5\}\leftrightarrow00111$ (З3, доска 2).
`проверка: proverki.py утв. 2` · `источник: З2, З3 доска 2` · `уровень: школьно`
*Ловушка аудитории (З2, владелец):* переход между языками слушателей путает — в статье переход делается явно, рисунком.

## Часть 2. Края треугольника

**Утв. 3 (края).** Для всех $n\ge0$: $\binom n0=\binom nn=1$ и $\binom n1=n$ (при $n=0$ — ноль по опр. 1); для $n\ge1$: $\binom n{n-1}=n$.
*Доказательство.* Подмножество из 0 элементов одно — $\varnothing$; из $n$ элементов одно — само $[n]$. Подмножеств из одного
элемента $n$ — по одному на элемент. Подмножество из $n-1$ элемента однозначно задаётся единственным элементом, которого в
нём нет, — их тоже $n$. ∎

## Часть 3. $\binom n2$ семью способами

**Утв. 4.** Для $n\ge0$: $\displaystyle\binom n2=\frac{n(n-1)}2$ (при $n\le1$ обе части — ноль, В10).

Семь доказательств — все были на занятии 2 (порядок — порядок занятия; [сл.] — способ предложили слушатели). Первые три
выписывают сумму $1+2+\dots+(n-1)$ и считают её; последние четыре считают каждую пару дважды и делят.

*Доказательство (а) [сл.] — по наименьшему элементу.* Пара $\{i,j\}$, $i<j$, однозначно задаётся своим наименьшим
элементом $i\in\{1,\dots,n-1\}$ и бо́льшим $j\in\{i+1,\dots,n\}$; при данном $i$ вариантов для $j$ ровно $n-i$. По правилу
суммы $\binom n2=(n-1)+(n-2)+\dots+1$. Остаётся сосчитать сумму — способ (в). ∎

*Доказательство (б) — лесенка.* Клетки таблицы $n\times n$, стоящие строго выше диагонали, — это пары $(i,j)$ с $i<j$
(строка $i$, столбец $j$), то есть ровно подмножества $\{i,j\}$. В строке $i$ таких клеток $n-i$: лесенка из
$(n-1)+(n-2)+\dots+1$ клеток. По столбцам — та же лесенка: $1+2+\dots+(n-1)$. ∎
*В лесенке выписывали упорядоченные пары* (З2, владелец) — мостик к (г).

*Доказательство (в) — Гаусс.* Пусть $S=1+2+\dots+(n-1)$. Запишем ту же сумму задом наперёд и сложим почленно:
$$2S=\bigl(1+(n-1)\bigr)+\bigl(2+(n-2)\bigr)+\dots+\bigl((n-1)+1\bigr)=\underbrace{n+n+\dots+n}_{n-1}=n(n-1).$$
Значит, $S=\frac{n(n-1)}2$. ∎
*История (narrativ, не матбаза):* анекдот о школьнике Гауссе и сумме $1+\dots+100=5050$ — в первоисточнике 1856 г.
(Сарториус фон Вальтерсхаузен) чисел «1…100» нет, они появляются в 1938 г. в биографии Гаусса Бибербаха — по данным
Хейса (B. Hayes, 2006, оговорка «in the literature I have surveyed»; рецензия 04.10 подтвердила цитатами). Решение владельца:
давать прямо как анекдот со ссылкой на источник 1938 г. `проверка: proverki.py Гаусс`

*Доказательство (г) [сл.] — две лесенки в шоколадку.* Отражение таблицы относительно диагонали ($(i,j)\mapsto(j,i)$)
переводит клетки над диагональю в клетки под ней биективно. Вместе две лесенки — все внедиагональные клетки, то есть
упорядоченные пары $(i,j)$, $i\ne j$; их $n(n-1)$ (правило произведения: $i$ — $n$ способов, $j\ne i$ — $n-1$). Сдвиньте
нижнюю лесенку на одну клетку вверх — две лесенки сложатся в прямоугольник («шоколадку») из $n-1$ ряда по $n$ клеток. Итак,
$2\binom n2=n(n-1)$. ∎
*На языке утв. 0.3:* отображение «упорядоченная пара $\mapsto$ множество $\{i,j\}$» имеет у каждого множества ровно 2 прообраза.
⚑ Флаг: «сдвинуть на клетку и сложить в $n\times(n-1)$» — проверить, что сдвиг даёт ровно прямоугольник, а не «почти».
Флаг закрыт: нижняя лесенка — клетки $(i,j)$, $i>j$, $i\in\{2..n\}$; сдвиг $(i,j)\mapsto(i-1,j)$ даёт клетки $i\ge j$ в
строках $1..n-1$; вместе с верхней ($i<j$, строки $1..n-1$) — все клетки строк $1..n-1$, столбцов $1..n$: прямоугольник
$(n-1)\times n$, без наложений. Сверено выкладкой 04.10.

*Доказательство (д) [сл.] — стороны и диагонали многоугольника.* Отрезки, соединяющие вершины выпуклого $n$-угольника
(стороны и диагонали), — это ровно пары вершин. Из каждой вершины выходит $n-1$ отрезок; сумма по вершинам $n(n-1)$
считает каждый отрезок дважды (по разу с каждого конца). Значит, отрезков $\frac{n(n-1)}2$. ∎
*Условие:* $n\ge3$ (при $n=2$ «многоугольника» нет; формула верна и так — $\binom22=1$). *Выпуклость* нужна только для картинки (чтобы отрезки были видны); для счёта — нет.

*Доказательство (е) — рукопожатия.* $n$ человек, каждый пожал руку каждому. Рукопожатие — пара людей; каждый участвовал в
$n-1$ рукопожатии, сумма $n(n-1)$ считает каждое рукопожатие дважды. Тот же подсчёт (д) в другом наряде. ∎

*Следствие (ж) — только диагонали.* Диагоналей выпуклого $n$-угольника, $n\ge3$: $\binom n2-n=\frac{n(n-3)}2$. Или прямо: из
каждой вершины $n-3$ диагонали (не к себе и не к двум соседям), каждая посчитана дважды. ∎
`проверка: proverki.py утв. 4 (а–ж), n=2..14` · `источник: З2 (рассказ владельца, ответы 04.10); З3 доски 3, 13` · `уровень: школьно`

**Замечание 4.1 (что вынести из семи доказательств).** Два приёма, на которых держится всё дальнейшее:
(1) *двойной подсчёт* — одно множество считается двумя способами, ответы приравниваются (лесенка (б) по строкам и по
столбцам; (д) — по вершинам и по отрезкам); (2) *упорядочить,

## Часть 4. Симметрия — первая биекция

**Утв. 5 (симметрия).** Для $0\le k\le n$: $\binom nk=\binom n{n-k}$.
*Идея.* Выбрать, кого взять, — то же, что выбрать, кого оставить.
*Доказательство.* Отображение $A\mapsto[n]\setminus A$ переводит $k$-подмножества в $(n-k)$-подмножества и обратно к самому
себе; значит, это биекция. На языке слов — замена каждой цифры $0\leftrightarrow1$. Утв. 0.4. ∎
*Частные случаи:* $\binom n0=\binom nn$, $\binom n1=\binom n{n-1}$ (утв. 3), $\binom n2=\binom n{n-2}$ (З3, доска 3 слева).
*Виджет:* c1 «зеркало». При $n=2k\ge2$ отображение переводит $k$-подмножества в $k$-подмножества и не имеет неподвижных точек
($A=[n]\setminus A$ невозможно при $n\ge1$; при $n=0$ пустое множество — своё дополнение). *(Следствие «$\binom{2k}k$ чётно при $k\ge1$» в статью не идёт — задачи вынесены в листок, решение
владельца 01:19.)*
*История (Р, ✓✓):* у Чараки наборы из пяти вкусов описаны как «исключение одного вкуса» — дополнение; у Паскаля —
5-е следствие «каждая клетка равна своей взаимной».

## Часть 6. Правило Паскаля

**Утв. 7 (правило Паскаля).** Для $n\ge1$ и $1\le k\le n$ (v3: при $k=n$ второе слагаемое $\binom{n-1}n=0$ по опр. 1):
$$\binom nk=\binom{n-1}{k-1}+\binom{n-1}k.$$
*Идея.* Разделить слова по первой цифре.
*Доказательство.* Разобьём слова длины $n$ с $k$ единицами на две части (правило суммы).
**Случай 1: $w_1=1$.** Отбросив первую цифру, получим слово длины $n-1$ с $k-1$ единицами; обратно, приписав 1 спереди к
любому такому слову, получим слово первой части. Биекция — $\binom{n-1}{k-1}$ слов (утв. 2; условие $k-1\ge0$ выполнено).
**Случай 2: $w_1=0$.** Отбросив первую цифру, получим слово длины $n-1$ с $k$ единицами — биекция, $\binom{n-1}k$ слов
(условие $k\le n-1$ выполнено).
**Итог:** $\binom nk=\binom{n-1}{k-1}+\binom{n-1}k$. ∎
*Почему условие $1\le k\le n-1$.* При $k=0$ или $k=n$ одна из частей пуста, а соответствующий символ не определён (опр. 1);
края даёт утв. 3.
*Пример 7в — на языке людей (З3, доска 8):* из восьми человек выбрать троих дежурных; отметим одного (В): группы с В — выбрать ещё двоих
из семи, $\binom72$; без В — $\binom73$. Итого $\binom83=\binom72+\binom73$, $56=21+35$.
*Пример 7а (развязка):* $\binom63=\binom52+\binom53=10+10=20$. Ответ на вопрос вступления.
*Пример 7б (З3, доска 6):* $\binom52=\binom41+\binom42$, $10=4+6$ — все десять слов, разделённые по первой цифре.
*Виджет:* c2 «разъезд по первой цифре».
*История (П):* правило построения треугольника у Паскаля — «каждая клетка равна сумме соседней сверху и соседней слева»
(треугольник у Паскаля повёрнут: строки — диагонали таблицы).
⚑ Флаг: формулировку правила Паскаля в его ориентации таблицы («сверху и слева») сверить с переводом Pulskamp до текста.
Флаг закрыт: у Паскаля — «равна той, что предшествует ей в её перпендикулярном ряду, плюс той, что предшествует ей в её
параллельном ряду» (пер. Pulskamp, по рецензии 04.10); перпендикулярные ряды идут сверху вниз, параллельные — слева

## Часть 7. Капитан: три подсчёта одного множества

**Утв. 8 (команда с капитаном).** Для $n\ge1$ и $0\le k\le n-1$:
$$n\binom{n-1}k\;=\;(n-k)\binom nk\;=\;(k+1)\binom n{k+1}.$$
*Идея.* Все три числа считают одно и то же множество $T$ — команды из $k+1$ человека с капитаном.
*Доказательство.* $T=\{(A,c): A\subseteq[n],\ |A|=k+1,\ c\in A\}$ ($A$ — команда, $c$ — капитан). Считаем $T$ по правилу
произведения тремя способами.
**Шаг 1 (сначала капитан).** $c$ — любой из $n$; затем $A\setminus\{c\}$ — любое $k$-подмножество оставшихся $n-1$ человек:
$|T|=n\binom{n-1}k$.
**Шаг 2 (сначала рядовые).** $B=A\setminus\{c\}$ — любое $k$-подмножество $[n]$; затем $c$ — любой из $n-k$ не вошедших в $B$:
$|T|=\binom nk(n-k)$.
**Шаг 3 (сначала команда).** $A$ — любое $(k+1)$-подмножество; затем $c$ — любой из $k+1$ её членов: $|T|=\binom n{k+1}(k+1)$.
В каждом шаге пара (выбор 1, выбор 2) задаёт $(A,c)$ однозначно и каждую $(A,c)$ получаем ровно один раз — правило
произведения применимо. ∎
*Пример 8 (З3, доски 8–9):* 25 человек, команда из 11 с капитаном: $25\binom{24}{10}=11\binom{25}{11}=15\binom{25}{10}=49\,031\,400$.
*Почему капитан важен (З3, доска 8):* $\{В,К,П\}$ с капитаном В и $\{В,К,П\}$ с капитаном П — разные элементы $T$.
*Виджет:* c3 «капитан тремя способами».
`проверка: proverki.py утв. 8 (перебором), пример 8` · `источник: З3 доски 8–10` · `уровень: школьно`

**Следствие 9 (шаг вдоль строки).** Для $n\ge1$, $0\le k\le n-1$: $\displaystyle\binom n{k+1}=\frac{n-k}{k+1}\binom nk$.
Из второго равенства утв. 8 делением на $k+1\ne0$. ∎

**Следствие 9′ (шаг по диагонали).** Для $1\le k\le n$: $\displaystyle\binom nk=\frac nk\binom{n-1}{k-1}$.
Из первого и третьего выражений утв. 8 с заменой $k\to k-1$ (законна: $0\le k-1\le n-1$): $n\binom{n-1}{k-1}=k\binom nk$;
делим на $k\ne0$. ∎ *(Это и есть «капитан в команде из $k$ человек», подтверждено владельцем 04.10.)*

**Следствие 9″ (шаг вниз по столбцу).** Для $0\le k\le n-1$: $\displaystyle\binom nk=\frac n{n-k}\binom{n-1}k$.
Из первого и второго выражений утв. 8 делением на $n-k\ne0$. ∎

## Часть 8. Формула

**Опр. 10 (факториал).** Для целого $n\ge1$: $n!=1\cdot2\cdots n$; $0!=1$.
*Пример.* $10!=3\,628\,800$ (З3, доска 11: «$1\cdot2\cdot3\cdots10=10!$»). *Смысл* (принцип 0.2): $n!$ — число способов
расставить $n$ различных предметов по порядку.
$0!=1$ — одна пустая расстановка (и так формулы ниже верны при $k=0$).
`проверка: proverki.py опр. 10` · `уровень: школьно`

**Т. 11 (формула для биномиальных коэффициентов).** Для $0\le k\le n$:
$$\binom nk=\frac{n(n-1)\cdots(n-k+1)}{k!}=\frac{n!}{k!\,(n-k)!}.$$
(При $k=0$ произведение в числителе пусто и равно 1.)
*Второе равенство:* домножить числитель и знаменатель на $(n-k)!$: $n(n-1)\cdots(n-k+1)\cdot(n-k)!=n!$.

*Доказательство 1 — ходьба вдоль строки (любимое владельца; путь Паскаля).* Индукция по $k$. При $k=0$: $\binom n0=1$ (утв. 3).
Если формула верна для $k<n$, то по следствию 9
$$\binom n{k+1}=\frac{n-k}{k+1}\cdot\frac{n(n-1)\cdots(n-k+1)}{k!}=\frac{n(n-1)\cdots(n-k)}{(k+1)!}.$$
Развёрнуто: $\binom nk=\frac{n}{1}\cdot\frac{n-1}{2}\cdots\frac{n-k+1}{k}\cdot\binom n0$ — $k$ шагов от края строки. ∎
`источник: З3 доски 10–12; П, 12-е следствие + «задача»`

*Доказательство 2 — ходьба по диагонали.* По следствию 9′, применённому $k$ раз (законно: на $j$-м шаге $k-j+1\ge1$):
$$\binom nk=\frac nk\cdot\frac{n-1}{k-1}\cdots\frac{n-k+1}{1}\cdot\binom{n-k}0=\frac{n(n-1)\cdots(n-k+1)}{k!}.\ ∎$$
`источник: З3 доска 14`

*Доказательство 3 — упорядочить и поделить (обычное).*
**Шаг 1.** Последовательностей из $k$ *различных* элементов $[n]$ — $n(n-1)\cdots(n-k+1)$ (принцип 0.2: первый — $n$ способов,
второй — $n-1$, …, $k$-й — $n-k+1$).
**Шаг 2.** Каждое $k$-подмножество можно упорядочить ровно $k!$ способами (опр. 10, смысл).
**Шаг 3.** Отображение «последовательность $\mapsto$ множество её членов» имеет у каждого $k$-подмножества ровно $k!$ прообразов;
по утв. 0.3 $\binom nk=\frac{n(n-1)\cdots(n-k+1)}{k!}$. ∎
*Это тот же приём, что (г)–(е) для $\binom n2$:* там $k=2$, кратность $2!=2$; пример — четырёхугольник со стрелками,
$\frac{4\cdot3}2$ (З3, доска 13). *Виджет:* c4 «стрелки → отрезки».
`источник: З3 доска 13; З1 (дежурные, $\frac{8\cdot7\cdot6}{1\cdot2\cdot3}$)` · `уровень: школьно`

*Примеры:* $\binom63=\frac{6\cdot5\cdot4}{6}=20$ (вступление); $\binom83=56$; у Варахамихиры $\binom{16}4=1820$.
