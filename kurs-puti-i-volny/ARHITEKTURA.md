## §3. Поток — что во что даёт вклад

Стрелка читается «питает», и она односторонняя. **Нижнее ничего не знает о верхнем:** определение не подстраивается под лекцию; если лекции неудобно — меняют лекцию.

```
        ЗАМЫСЕЛ  ─────────── управляет всем ───────────┐
     (решения, границы)                                │
                                                       │
  счёт ──► КАРТОЧКА ──► СКЕЛЕТ ──► СВЕДЕНИЕ ──► КАРКАС ──► ТЕКСТЫ
proverki/   находка    утверждение   что к чему    состав    обзоры
 verify/                граф опор     сводится      года     прогулка
                                                             листки
              ▲                                                ▲
              │                                                │
        ЯЗЫК ─┴──── обслуживает каждую стрелку ────────────────┘
   OBOZNACHENIYA (буквы) · SLOVAR (слова)
```

Из этой схемы следуют три вещи, каждая проверяема:

**1. Находка входит в курс только через карточку.** Не через отчёт, не через «новые карточки» файлом-накопителем, не прозой в разборе. Находка без карточки — потеряна; это не назидание, а описание уже случившегося.

**2. Счёт стоит ПЕРЕД находкой, а не после текста.** Скрипт в `proverki/` — не проверка написанного, а условие того, чтобы находка получила пометку `проверено счётом`. ⚠ Сейчас поток здесь разорван: скрипты не трогались с 06.08, а карточки датированы 02.09.

**3. Пометка происхождения может только слабеть.** `литература по памяти` не становится `литература сверенная` оттого, что факт переписали в другой файл. Пять пометок: `проверено счётом` · `литература сверенная` · `литература по памяти` · `доказано здесь` · `гипотеза`.

## §4. Система символов и система смыслов

Два файла, и разрез между ними жёсткий: **`OBOZNACHENIYA.md` — про буквы, `SLOVAR.md` — про слова.** Вместе они отвечают на вопрос «чем курс вправе называть свои вещи».

**Буквы.** Канон на 18.09: $F_m(x\to y;\,z,q)$ — число путей из $x$ в $y$; $m$ — **высота коридора**, спектр $2\cos\frac{k\pi}{m+2}$; $z$ — длина, $q$ — площадь, считается **от старта**; $x$ — старт, не длина.

🔴 Отменено 03.09: $m$ как ширина в клетках со спектром $\frac{k\pi}{m+1}$. Следы живы — в `plan/src/voprosy.md` **обе конвенции стоят в одном файле**, группа C в отменённой, группа G в каноне, и ни одна не объявлена.

⚠ Занятые буквы, которые нельзя переиспользовать: $F$ занята героем — числа Фибоначчи писать словом или $\mathrm{Fib}_n$; нарушается в `SKELET.md` утв. 9, и именно при $m=3$, где Фибоначчи и появляются. $\varphi$ и $\theta$ несут по два значения каждая внутри одного файла. $\theta$ и $d$ в словаре букв отсутствуют вовсе.

**Слова.** Ведущее слово доски — **«отрезок»**; «коридор» — научпоп-синоним. ⚠ В `SKELET.md` ведущим осталось «полоса» (8 вхождений), сам `ZAMYSEL.md` пишет все три. Решение за владельцем, до него гейт эту пару не судит.

**Смыслы.** Есть одна мысль, которой подчинено всё остальное, и её место — `ZAMYSEL.md §1`:

> **Если одно число посчитано двумя способами, равенство двух ответов и есть тождество. Чем богаче вес, тем глубже тождество.**

Из неё выводится и название («пути» — левая колонка, «волны» — правая, мост между ними и есть предмет), и критерий отбора темы, и почему модулярность стоит в финале, а не в середине.

## §5½. КАНОН ПЛАНА — пункт есть атом, планы есть виды над ним

`принято 2026-09-19 владельцем`

**Задача, которую это решает.** Планы года, полугодия, четверти и лекции повторяют один и тот же
список пунктов — год короче, четверть подробнее, но **список тот же**. У повторяющегося списка обязан
быть один источник истины, иначе в одном месте курс состоит из трёх частей, а в другом из четырёх.

**Цена уже заплачена и посчитана:** `SBORKA/KARTA-rashozhdeniy.md` Р13 — три разных разбиения состава
года в трёх живых файлах; Р10 — число глав 6/7/8; Р5 — арифметика сведения 20/23/41, ни одна версия
не сходится. Все три от одной причины: список писали руками в нескольких местах.

**Механизм.** Пункт живёт **один раз**, в одном файле. Планы всех четырёх увеличений
**порождаются скриптом** и руками не пишутся — ровно как `INDEKS.md`. Тогда расхождение становится не
запрещённым, а невозможным: чтобы список разошёлся, скрипт должен напечатать два разных ответа из
одних данных.

### Поля пункта

Первые четыре помечены ⭐ и взяты из исторического стандарта этого курса. Владелец назвал его прямо:
когда писался план на год, каждая лекция содержала **красивую теорему, красивый вопрос и красивую
задачу** — и потому была интересной.

| поле | что это |
|---|---|
| `id` | `p-NN`, стабильный; по нему ссылаются все виды |
| ⭐ `имя` | название, которое, увидев главой в книжке, хочется прочитать |
| ⭐ `вопрос` | красивый вопрос, с которого пункт начинается |
| ⭐ `теорема` | красивая теорема — то самое «ого» |
| ⭐ `задача` | красивая задача |
| `доска` · `вес` | координата: прямая / луч / отрезок / предел · `q` выкл / вкл |
| `обобщается-в` | id пункта, которым это станет дальше — гейт `gejt-obobshchaemosti` из `ZAMYSEL.md §1` |
| `опирается` | id пунктов, без которых этот не читается: рёбра графа |
| `адрес` | где материал: утверждение скелета, карточка картотеки, файл |

### Виды, которые порождает скрипт

план года — все пункты по строке (имя + вопрос) · план полугодия — фильтр по половине, плюс теорема ·
план четверти — фильтр по четверти, все ⭐-поля целиком · план лекции — один пункт в раскадровке.

### Гейты, которые это даёт бесплатно

Сирот нет: у каждого пункта, кроме первого, заполнено `опирается` · висячих ссылок нет · сумма
пунктов по четвертям равна числу занятий из `proverki/kalendar_goda.py` · **у каждого пункта заполнены
все четыре ⭐-поля — пустое ⭐ красное**, потому что пункт без красивого вопроса и есть скучный пункт.
