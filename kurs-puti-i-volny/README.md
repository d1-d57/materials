# Пути и волны

**Годовой курс для старшеклассников. Одна задача — посчитать пути, — которую весь год считают двумя способами: по путям и по волнам. Каждое совпадение двух ответов оказывается тождеством; в конце это модулярность.**

*Читается с сентября 2026. Собрано 05.08.2026 из ресёрча 03–05.08.*

---

Если открываешь папку впервые и времени мало — читай только `KOSTYAK.md`. Остальное к нему справочное.

## Название

Курс не про «случайные блуждания» вообще: блуждания бывают по разным доскам, и половина той науки сюда не входит. Он про **одну задачу, увиденную с двух сторон**. Слева — пути: биекции, отражения, производящие функции, разбиения. Справа — волны: спектр, лапласиан, гармонический анализ. Мост между колонками и есть предмет курса.

### Корень

- **`KOSTYAK.md`** — математический скелет. Главный файл. Несущая мысль, таблица двух колонок, шесть шагов с формулами и честными статусами, ответ на вопрос «зачем вообще окружность», список долгов.
- **`OBRAZEC-summy-kvadratov.md`** — три страницы: от вопроса «сколькими способами число есть сумма четырёх квадратов» до формулы Якоби и теоремы Лагранжа. Написано потому, что текста этого жанра нет: у Загира выкладка занимает две страницы, но опирается на двадцать пять предыдущих. **Это образец арки для нашего собственного финала.**
- **`CHITAT.md`** — что почитать: Кац по-русски про лапласиан и диффузию, обзор Титаренко про изоспектральность, Конвей «Квадратичные формы, данные нам в ощущениях» (лекция 2 — прямо наш сюжет). Проверено на существование.
- **`HREBET-kursa.md`** — свод ресёрча по устройству курса: четыре четверти, обоснование порядка, материал по каждой, что переносится на другие доски и на много частиц, что отвергнуто и почему. Самый большой файл; читать по разделам, не подряд.

### `zahody/` — с чего начинались куски работы

- `ZAHOD-okruzhnost.md` — заход, породивший всю линию окружности: «правда ли, что на окружности проще?»
- `ZAHOD-okruzhnost-i-nepreryvnyj-predel.md` — отложенная ветка про непрерывный предел.
- **`ZAHOD-formy-yakobi.md`** — 🔥 **следующий заход, самый перспективный.** Не является ли центральная функция $F(z,q)$ формой Якоби; если да, четвёртая четверть работает прямо с ней, а окружность перестаёт быть обязательной ступенькой.

### `otchety/` — что выяснилось

Порядок примерно хронологический; последний файл важнее первых.

- `OTCHET-okruzhnost.md` — ответ на заход: да, проще, и вот в чём именно. Разметка «проверено / по памяти / не проверено».
- `ZAPISKA-iz-simmetrii.md` — рассуждение «как всё считается из симметрии» плюс вердикт по источникам: чего в литературе нет и что взять за образец.
- `KARTA-mosta.md` — что теория модулярных форм реально возвращает задаче о блуждании, и где натяжка. Два источника силы теории; конечномерность; изоспектральные торы.
- `GRANICA-chto-vidno-na-okruzhnosti.md` — решение об объёме: что из большой науки видно на одномерной окружности, а что нет.
- `RASSKAZ-dva-sposoba.md` — самостоятельный рассказ от задачи про фишку до функционального уравнения дзеты. ⚠️ Написан по спине, от которой потом отказались; держать как заготовку, не как план.
- `RAZBOR-i-perestroyka.md` — разбор забракованного обзора: где именно текст рвётся и почему. **Здесь же найденный вход в модулярность через вес по площади.** Читать вместе с `KOSTYAK.md`.
- `ZAMETKI.md` — рабочие заметки первых дней.

### `proverki/` — счёт

Все скрипты на stdlib, запускаются одной командой, ничего не берут из памяти.

```bash
python3 proverki/proverka.py             # отрезок: три формулы, спектр, изображения, складывание
python3 proverki/proverka_okruzhnost.py  # окружность: обмотки, волны, Пуассон, S²=R, Ландсберг—Шаар
python3 proverki/proverka_modulyarnost.py # решётки: r₄(n), E₈, изоспектральные торы, разбиения
python3 proverki/proverka_ploshchad.py   # вес по площади: гауссов бином, корни из единицы, лестница
```

Последний — самый свежий и самый важный: в нём проверен вход в модулярность.
