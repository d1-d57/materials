## §2.1 — зависимое произведение Πf как понятие для зала

```
id: zavisimoe-proizvedenie
род: понятие
суть: зависимая функция — функция, у которой ТИП результата меняется вместе с аргументом; обычная функция = частный случай
котёл: математика
находка: ВЕРДИКТ §2.1: определение в Set — ЭЛЕМЕНТАРНО, общая конструкция — НЕТ. Дословно (Riehl Example 4.5.7,
  печ. с.160): «elements of ∏ₓ Aₓ are dependent functions, functions f defined on the set X for which the output
  f(x) ∈ Aₓ belongs to the set Aₓ indexed by the input element x». То есть только: семейство множеств Aₓ, зависящее
  от x, + функция, попадающая в Aₓ. Ни функторов, ни сопряжений, чтобы СФОРМУЛИРОВАТЬ. Опора ровно на выданное залу:
  обычная функция X→B — это ∏ₓ B (все Aₓ равны), и HoTT §1.4 (печ. с.25) говорит это буквально: «If B is a constant
  family, the dependent product type is the ordinary function type ∏B ≡ (A→B)». ⚠ НО общий Πf-как-функтор (правый
  сопряжённый к пуллбэку) НЕ элементарен: Riehl строит его «by a pullback diagram … that requires some explanation»
  (печ. с.159), замкнутость в слайс = Πₐ∆ₐ (Cor 4.5.13) даром не поднимается. ⇒ залу: зависимую функцию в Set —
  руками; общий Πf — объявить-и-отложить (SPEKA «беглое упоминание»). Ловушка №1 названа в отчёте.
связи: verdict-rifma-lccc, riehl-lccc-donor, eksponenta-opredelenie, ccc-opredelenie, zachem-zavisimaya-funkciya, pf-est-pi-tip
уровень: зал берёт (определение в Set) / требует приручения (общая конструкция)
источник: `../istochniki/pdf/riehl-category-theory-in-context.pdf` §4.5 — Example 4.5.7 печ. с.159–160, пуллбэк-конструкция с.159, Cor 4.5.13 с.163; HoTT §1.4 печ. с.25
статус: черновик
```
```
id: zachem-zavisimaya-funkciya
род: мотивация
суть: n ↦ Iₙ — тип результата съезжает с аргументом; обычный тип X→B теряет, что выход n×n, нужен тип, который это ПОМНИТ
котёл: математика
находка: ГЕЙТ §2.3 ПРОЙДЕН — мотивация не идёт ни через один незнакомый залу объект. «Функция n ↦ (единичная n×n
  матрица)»: зал писал её сто раз, но у неё нет ОДНОГО кодомена — ℝ^{n×n} растёт с n. Обычный тип X→B слишком беден:
  он забывает, что выход именно n×n. Зависимое произведение — тип, который это ПОМНИТ (прямая рифма с
  `dekategorifikaciya-teryaet`: «число забывает КАК — категория помнит»; здесь: обычный тип забывает размер —
  зависимый помнит). Вторая, throughline-опора: зал переизобрёл +,×,^ как тень арифметики
  (`kategorifikaciya-arifmetiki`); последняя недостающая запись словаря — произведение РАЗНЫХ множителей a₁·…·aₙ, и
  его тень — ровно ∏ₓ Aₓ (|∏Aₓ| = ∏|Aₓ|), тогда как экспонента bⁿ = ∏ равных. Пропорция: зависимое произведение
  относится к экспоненте, как общее произведение к степени. Обе опоры — матрицы и школа — зал держит твёрдо;
  модули/сопряжения/Hom-пространства НЕ нужны. Контраст с эталоном болезни `zachem-zakryvat` (объясняет через
  ещё-не-понятое) — здесь наоборот, через уже-в-руках.
связи: kategorifikaciya-arifmetiki, zakon-stepenej-karrirovanie, dekategorifikaciya-teryaet, zavisimoe-proizvedenie, scena-zavisimaya-korobka
уровень: зал берёт
источник: `../SPEKA.md §Калибровка` (матрицы — твёрдая опора); HoTT §1.4 печ. с.25 (constant family = обычная функция; пример fmax : ∏ Fin(n+1)); склейка — вывод захода
статус: черновик
```
```
id: scena-zavisimaya-korobka
род: сцена
суть: слайдер по n: коробка-кодомен САМА меняет размер (1×1→2×2→3×3), а не только своё содержимое
котёл: математика
находка: честная (не «красивая») картинка требования захода — «тип результата меняется вместе с аргументом».
  Ведущий кадр — n↦Iₙ: ползунок n=1,2,3,4; справа выпадает n×n-таблица, и РАМКА растёт с каждым шагом. Обычная
  функция: меняется ЧТО в коробке. Зависимая: меняется САМА коробка. Второй кадр (для общего Πf и моста в Л9) —
  сечение расслоения: над каждым x∈X слой Aₓ своей высоты, зависимая функция = выбор одной точки в каждом слое =
  СЕЧЕНИЕ. Книга подтверждает дословно: HoTT Table 1 (печ. с.11) — строка «∏ₓB(x) | ∀ | product | space of
  SECTIONS», при этом B(x)=«fibration», b(x):B(x)=«section». Сечение — тот же кадр, что «график функции», только
  полоса допустимых y над каждым x разной высоты. Ведущий кадр — коробка (калибровка: матрицы твёрдо); сечение —
  вторичный, он же сеет геометрию путей для Л9. Ложится на единый приём курса (лента кадров, ползунок — как
  `scene-naturality-slide`).
связи: zavisimoe-proizvedenie, zachem-zavisimaya-funkciya, cep-univalentnost
уровень: зал берёт (коробка) / требует приручения (сечение)
источник: HoTT §1.4 печ. с.25 (пример Fin(n+1)); Table 1 печ. с.11 (∏ = space of sections, fibration/section); Riehl Example 4.5.7 (слои) печ. с.160
статус: черновик
```

## §2.2 — мост от Πf к унивалентным основаниям

```
id: pf-est-pi-tip
род: мостик
суть: Πf (LCCC) = Π-тип (Martin-Löf) = ∀ = пространство сечений — один объект, четыре языка. Несущая балка Л5→Л9
котёл: математика
находка: ⭐ то, чего в программе НЕТ, а финал на этом висит целиком. Дословный мост — HoTT Table 1 «Comparing points
  of view» (печ. с.11), строка «∏_{(x:A)}B(x) | ∀_{x:A}B(x) | product | space of sections». Πf с Л5 — буквально
  Π-тип пруф-чекера зала. Две НЕЗАВИСИМЫЕ опоры, не одна: (1) со стороны логики/типов — HoTT «read Π as „for all",
  Σ as „there exists"» (печ. с.32); (2) со стороны категорий — Riehl «type theoretic axiom of choice … a theorem,
  not an axiom» + Skolem-функция (печ. с.164) и «deep connections … Martin–Löf dependent type theory» (печ. с.163).
  Строго отождествлены в Thm 10.1.11 (печ. с.350): Set = ΠW-претопос = LCCC, и доказательство строит LCCC ИЗ
  «dependent function types». То есть Σf/Πf ↔ ∃/∀ ↔ зависимые сумма/произведение — не аналогия, а одна вещь. Вывод:
  «цена» Πf, заплаченная на Л5, И ЕСТЬ входной билет в цель финала — она не издержка, а мост.
связи: zavisimoe-proizvedenie, verdict-rifma-lccc, cep-univalentnost, tip-tozhdestva, nno
уровень: требует приручения (для лектора несущая; залу подаётся как «это то же, что ∀ в вашем пруф-чекере»)
источник: HoTT Table 1 печ. с.11, Π=∀ печ. с.32, Thm 10.1.11 печ. с.350; Riehl §4.5 печ. с.163–164
статус: черновик
```

```
id: tip-tozhdestva
род: понятие
суть: равенство a=b — само ТИП Id_A(a,b); его элементы — доказательства/пути, и их может быть НЕСКОЛЬКО
котёл: математика
находка: дословно HoTT §1.12 (печ. с.47): «these equality types or identity types must be type families dependent
  on two copies of A»; введение — refl : ∏_{a:A}(a =_A a) (печ. с.48). ⭐ гомотопич. чтение там же (печ. с.48):
  «we regard witnesses of a=b as PATHS … there can be more than one witness that two objects are equal». Зачем ЗАЛУ
  (гейт §2.3): (1) это равенство их пруф-чекера, наконец ставшее математическим объектом — узнавание, как
  `karrirovanie` («уже знаете руками из ФП»); (2) throughline-ответ на вопрос, открытый Л2 (`pochemu-do-izo`:
  «равенство объектов — зло») и Л3 (`dekategorifikaciya-teryaet`: «2+3=5, но биекций 2⊔3→5 много») — это РОВНО
  «a=b, но путей/свидетелей несколько». Тип тождества и есть тот «а изоморфизм-то какой?», который Л3 назвала корнем
  теории категорий. Группоидная структура (пути компонуются, обращаются, есть тождественный) — HoTT печ. с.20, развёрнуто гл.2.
связи: pochemu-do-izo, dekategorifikaciya-teryaet, cep-univalentnost, pf-est-pi-tip
уровень: требует приручения
источник: HoTT §1.12 печ. с.47–48 (Id, refl, «witnesses as paths»); группоид — печ. с.20 + §2.11 печ. с.91
статус: черновик
```
