# VYCHITANO — дайджесты источников (что ЕСТЬ / чего НЕТ)

> Запись после КАЖДОГО чтения, тем же ходом. Дисциплина: **источник без дайджеста = как не читан.** Форма записи: **что ЕСТЬ · чего НЕТ · стр./§ · уровень**.
>
> **Дайджест — не пересказ.** Он отвечает на один вопрос: стоит ли будущему-мне открывать этот файл и на какой странице. Находки при чтении уходят карточками в `../kartoteka/KARTA-OBLASTI.md` тем же ходом — сюда они НЕ дублируются.
>
> **Статус: ПУСТОЙ (2026-07-16).** Наполняет арка «Ландшафт».

## Форма записи (эталон)

```
## `<id>` — <файл> (<тип>)
**Прочитано:** <дата>, <целиком | §N–M | стр. X–Y>.
**Что ЕСТЬ:**
- <...>
**Чего НЕТ:**
- <...>
**Уровень:** <зал берёт | требует приручения | вне курса> — <одна фраза почему>
**Мотивирует?** <главный вопрос этого проекта: объясняет ли источник ЗАЧЕМ, или даёт
  определения задним числом. Источник, который не мотивирует, для нас донор фактов, не сюжета.>
**Картинки:** <есть ли живой визуал, какой; ТЗ: визуал несущий, найденную картинку не восстановишь>
```
