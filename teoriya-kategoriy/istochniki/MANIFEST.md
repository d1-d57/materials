## ⚠ Легальность и провенанс — прочитать перед использованием

- **Лицензия Category Theory Illustrated — CC BY-NC 4.0 (NonCommercial), сверена 16.07.** Курс — ПЛАТНЫЙ (~150 участников). Прямое заимствование картинок автора без его разрешения конфликтует с пунктом NC. **Решение не принято мной — за владельцем**: (а) написать автору (Boris Marinov, контакт на сайте) и спросить разрешения, (б) рисовать свои иллюстрации по мотивам идеи, не копируя, (в) не использовать вовсе. Текст глав сохранён для анализа композиции/идей, не для перерисовки без ответа на этот вопрос.
- **`awodey`, `maclane-en` — происхождение Anna's Archive** (теневая библиотека). То же самое соотношение, что уже было принято проектом для `lawvere`/`maclane-ru-*` при старте (см. «Провенанс» ниже) — копии для внутренней работы над курсом, легальных бесплатных версий этих изданий в сети нет (SPISOK §🟡 подтверждает: Awodey и MacLane английский — оба «зеркала пиратские»/«купить»). Решение о статусе этих копий принято на уровне всего проекта раньше моего захода — не пересматриваю, фиксирую факт.
- Все источники `pdf/` кроме явно свободных (arXiv/AMS/PNAS/GitHub) — копии для внутренней работы над курсом, не для публичной раздачи.
