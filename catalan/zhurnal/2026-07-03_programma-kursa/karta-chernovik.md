# Карта области — черновик (арка «Программа курса»)

> Рабочий черновик, **НЕ источник правды**. Мир 1 опирается на `../../spravochnik/_seed-kb.md`; Мир 2 — во многом **ресёрч-цель** (в `KARTA-OBLASTI` его пока нет). Проверенное потом промотируем в `spravochnik/KARTA-OBLASTI` через Code. Цель черновика — увидеть, что здесь интересного, ДО фиксации структуры лекций.

## Замысел (владелец, 2026-07-03)
Два мини-курса: **независимые** (можно слушать один без второго — это требование), но **единые по духу** (красивые биекции; каждый открывается исследовательской задачей). Не «доказать всё → потом переиспользовать»: каждый мир открывается ЗАДАЧЕЙ, биекции строятся, чтобы на неё ответить.

## МИР 1 — пути Дика / числа Каталана  · материал ЕСТЬ (`_seed-kb`)

**Затравочные задачи (независимые процессы):** баллотировка · возвращение 1D-блуждания.

**Модели:** пути Дика (в т.ч. несбалансированные — кончаются выше нуля, для вопросов о возвращении) · планарные/бинарные деревья · триангуляции.

**Доказательства формулы Cₙ — и их характер:**
- отражение (André) → Cₙ как **разность** биномов;
- циклическая лемма (Dvoretzky–Motzkin) → как **единую дробь** (интереснее — владелец);
- exceedance / Chung–Feller;
- раздутие/сдутие триангуляций.

**Кульминация:** возвращение — получить формулу **прямой биекцией**, а не суммой разностей. Тождество «нет возврата за 2n = оказались в 0 на шаге 2n» = C(2n,n)/2²ⁿ.

**Педагогический риск (владелец):** за 4 лекции трудно осмысленно закрыть и баллотировку, и возвращение со всеми биекциями. → что реально влезает — вопрос карты.

## МИР 2 — формула Кэли  · в основном РЕСЁРЧ-ЦЕЛЬ (в `spravochnik` НЕТ)

**Затравочная задача:** парковка (parking functions) — независимый процесс; считается двумя способами.

**Число:** помеченные деревья на n вершинах = nⁿ⁻² (Кэли). Парковочные функции длины n = (n+1)ⁿ⁻¹ = помеченные корневые леса на n вершинах = остовные деревья K₍ₙ₊₁₎.

**Доказательства — характер (прямая перекличка с Миром 1):**
- **Прюфер** — кодировка-биекция (деревья ↔ [n]ⁿ⁻²);
- **Жойяль (Joyal)** — эндофункции / дважды-корневые деревья;
- **Питман (Pitman)** — двойной счёт измельчающихся лесов;
- **Поллак (Pollak)** — парковки через **циклический аргумент** (n+1 мест по кругу, симметрия) → прямой аналог циклической леммы.

**Мост внутри мира:** парковочная функция ↔ помеченный лес/дерево ↔ **помеченный путь Дика** (путь-профиль + помётка шагов с условием возрастания).

**Литература-старт:** Aigner–Ziegler «Proofs from THE BOOK», глава про формулу Кэли (несколько доказательств) — отправная точка ресёрча.

---

## МОСТ между мирами  · это и есть «единство по духу»
- **Одна техника в двух мирах:** циклическая лемма доказывает и Каталан (Dvoretzky–Motzkin), и Кэли (Pollak).
- Непомеченные деревья (Мир 1) ↔ специальные помётки тех же деревьев (Мир 2).
- **Помеченный путь Дика = парковочная функция** → общий объект-хаб.
- Независимость сохраняется (каждый мир самодостаточен), единство — на уровне техники и «кивков».
