Отсюда пишутся research-отчёт и карточки. Уровень доверия: каждое утверждение с источником; расхождения конвенций разведены.

## Конвенция 231 vs 312 — не опечатка, разные чтения стека
| Чтение | Фиксируем | Избегаемый паттерн | Термин |
|---|---|---|---|
| A. «получаемые» (Кнут, ориг.) | вход 1..n → стек → выход p | **312** (нет i<j<k: p_j<p_k<p_i) | stack-realizable |
| B. «сортируемые» (совр.) | вход w → стек → выход 1..n | **231** | stack-sortable |

Множества взаимно-обратны (231⁻¹=312), оба = Cₙ. Кнут в Упр. 2.2.1.5 характеризует ПОЛУЧАЕМЫЕ в форме 312. Веб местами зовёт условие a_j<a_k<a_i «231» — ошибка пересказа (по рангам 312). Для курса: одна конвенция (реком. 231 = стек-сортируемые), оригинал Кнута 312 — врезкой.

## Ядро
- **Операция стек-сортировки** (Кнут, TAOCP т.1 §2.2.1, лин. алгоритм); рекурсивно (Уэст): S(w)=S(L)·S(R)·n для w=L·n·R. Сортируема ⟺ S(w)=12⋯n.
- **Теорема Кнута:** сортируема одним стеком ⟺ избегает 231; таких Cₙ. (TAOCP Упр. 2.2.1.4 счёт, 2.2.1.5 характеризация; Stanley 2015 item 119; Bóna гл. 8; обзор Bóna EJC 9(2) 2002.)
- **Wilf:** все 6 паттернов длины 3 — один класс Вилфа, каждый Cₙ. Симметрия-классы {123,321} и {132,213,231,312}. Первая прямая биекция между ними — Simion–Schmidt, EJC 6 (1985) 383–406, Prop. 19.
- **Разложение по максимуму (крест):** π=L·n·R (n=макс на поз. k+1); избегание 231 ⟹ все L < все R, L — перест. {1..k}, R — перест. {k+1..n−1}, обе избегают 231 ⟹ aₙ=Σ_{k} a_k·a_{n−1−k}=Cₙ. Док-во: пара a∈L, b∈R, a>b даёт на возр. позициях ранги (2,3,1)=паттерн 231 — противоречие. ∎ (Stanley 2015 реш. item 116 — зеркально, для 312/минимума; Уэст 1990/95.)
- **Рекуррента (1.1):** C_{n+1}=Σ C_k C_{n−k}, C₀=1 (Stanley гл. 1) — та же для триангуляций (разрез ребра) и деревьев (корень+поддеревья). Крест 231 ↔ дерево ↔ триангуляция ↔ путь Дика замыкается на одной рекурренте.

## Четыре биекции
- **231 ↔ путь Дика (стековая, главная):** при сортировке push=+1 «(», pop=−1 «)»; каждый элемент раз втолкнут/раз вытолкнут, частичные суммы ≥0 ⟹ путь Дика; биекция. (Stanley item 119 реш.; Knuth Упр. 2.2.1.4.) Альтернативы: Stump (2008, через maj), Linusson (2014, скобки, Thm 4, пример α(51243)=(()()(()))).
- **231 ↔ бинарные деревья:** рекурсия = разложение L·n·R; алгоритм Кнотта (in-order нумерация → выписать в preorder; обратно: первый = корень, след. x−1 = левое поддерево, остальные = правое). (Stanley item 4/85; Knott, CACM 20(2) 1977, 113–115.)
- **DFS ↔ стек:** содержимое стека при сортировке = путь текущего узла до корня; push = спуск к узлу, pop = завершение поддерева; preorder = порядок проталкивания; push/pop-слово = контур DFS-обхода. (Stanley EC2 «Catalan Addendum» Cor. 6.2.3.)
- **Бинарные деревья ↔ триангуляции:** фиксируем ребро (n+2)-угольника; разрез = рекурсия (1.1). (Stanley гл. 1, рис. 1.2/1.6.)

## Вероятностный вход + вердикт моста
- **P_n(τ)=Cₙ/n!** для любого паттерна длины 3; асимптотика Cₙ~4ⁿ/(√π·n^{3/2}) ⟹ P_n~(4e/n)ⁿ → 0 сверхэкспоненциально. Малые: 5/6, 7/12, 7/20, 11/60 (n=3..6); n=10 ≈ 0.0046. Формулировка: «n человек встали в случайном порядке — вероятность, что никакие трое не образуют узор 231». (Miner–Pak arXiv 1303.7313; Madras–Liu 1509.07941; вывод Cₙ — Pudwell 2022, Linusson 2014.)
- **ВЕРДИКТ МОСТА: настоящий и тугой — но ТОЛЬКО для 231 (или «углового» паттерна) и ТОЛЬКО через шаг подсчёта.**
  1. Подсчёт сам рождает рекурренту (разложение по максимуму). 2. Рекуррента = бинарное дерево (дерево рекурсии разложения). 3. Для 231 разложение совпадает со стек-сортировкой ⟹ push/pop = путь Дика. Три объекта = три прочтения ОДНОГО разложения, не импорт.
  - Оговорки: чисто лишь для {231,132} (по макс.) и {213,312} (по мин.); для монотонных **123/321 разложение по краю НЕ распадается** (нужен Simion–Schmidt/RSK) — брать 231. Сама вероятность дерева НЕ форсирует — шарнир «сколько избегающих»; без шага подсчёта прыжок «вероятность→дерево» = импорт.
  - Чистая линия курса: случайная перестановка → P(изб. 231)=Cₙ/n! → подсчёт по максимуму (Сегнер) → это разложение = стек-сортировка = дерево = путь Дика.

## Панорама поля (широкий обзор)
- **Длина 3:** один класс Вилфа, всё Cₙ.
- **Длина 4 — три класса Вилфа** (Wikipedia «Enumerations of specific permutation classes»; расходятся с n=6: 512/513/2762):
  - **1342** — алгебр. (нерациональная) п.ф., рост **8** (Bóna, JCTA 1997, arXiv math/9702223; OEIS A022558);
  - **1234** — голономная (D-конечная, не алгебр.), рост **9=(4−1)²** (Gessel, JCTA 1990; A005802);
  - **1324** — замкнутой формулы НЕТ, рост эмп. ≈**11.60**, границы [10.271, 13.5] (Bevan–Brignall–Elvey Price–Pantone, EJC 2020, arXiv 1711.10325; A061552).
- **2-стековая сортировка:** Уэст (⟺ изб. 2341 и барного 3-5̄-2-4-1) предположил; **Цейльбергер доказал** W₂(n)=2·(3n)!/((n+1)!(2n+1)!), рост 27/4 (Discrete Math. 102 (1992) 85–93; OEIS A000139). 3-stack — Defant 2020.
- **Стэнли–Уилф → Маркус–Тардос (2004):** любой собственный класс избегания — одноэкспоненциальный рост (не факториальный). Klazar (2000): Фюреди–Хайнал ⟹ Стэнли–Уилф; Marcus–Tardos доказали Фюреди–Хайнал (JCTA 107 (2004) 153–160).
