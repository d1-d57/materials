# ARKA.md — канон арок (стаб; полный порт — в очереди)

> Полный канон (Ф0 «заводить ли арку» · интервью · ресёрч · go/no-go · ритуалы · закрытие/консолидация) портируется отдельным Code-заходом из `../kurs leto 2026/ARKA.md`. До порта канон процесса — скилл `agentic-coding-session-brief`.

Коротко. **Арка** — многосессионная задача со своей папкой `zhurnal/<ГГГГ-ММ-ДД_тема>/` = локальная память (маленькая копия памяти проекта). Три режима: **ВХОД** (один раз читаем долгую память — `NAVIGATION` · `1-START-HERE` · нужное из `spravochnik`) → **РАБОТА** (живём в папке арки, из долгой подгружаем точечно) → **ЗАКРЫТИЕ** (durable из арки разносим по домам — консолидация).

Вход в арку — по 1–2 вопроса (`project-kickoff` / `brainstorming` / `the-interviewer`). Арка НЕ по умолчанию: разовое влезающее в один чат — не арка.
