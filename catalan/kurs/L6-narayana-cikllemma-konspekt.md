# Числа Нараяны + цикл-лемма — быстрый конспект (с картинками)

> Маленький конспект под лекцию: сначала цикл-лемма (как работает — картинка), потом числа Нараяны как «уточнённый Каталан» (готово к использованию в доказательстве). Всё сверено кодом. Термины по `spravochnik/TERMINY-russkie.md`.
> Картинки рядом: **`fig-cikl-lemma.svg`** (как работает цикл-лемма) и **`fig-narayana.svg`** (пики → Нараяны).

---

## 1. Цикл-лемма (лемма Рени) — как работает · картинка `fig-cikl-lemma.svg`

Берём `2n+1` шагов: `n+1` вверх (`+1`) и `n` вниз (`−1`), сумма `+1`. Замыкаем в **кольцо** и читаем с каждого из `2n+1` мест (поворота).

> **Лемма.** Ровно **один** поворот — *доминирующий* (все частичные суммы `> 0`). Он стартует сразу после самой нижней точки.

У доминирующего первый шаг всегда `↑`; **сотри его** → останется путь Дика длины `2n`. Значит на каждый путь Дика приходится ровно `2n+1` последовательностей:
$$C_n = \frac{1}{2n+1}\binom{2n+1}{n} = \frac{1}{n+1}\binom{2n}{n}.$$

На картинке `fig-cikl-lemma.svg` (пример `n=3`, кольцо из 7 шагов) видно все 7 поворотов: 6 где-то падают на `≤0` (✗, красная точка), ровно 1 — доминирующий (✓). `C₃ = 35/7 = 5`.

*(Общий вид: у `(k, qk+p)`-расстановки ровно `p` доминирующих сдвигов. При `q=1, p=1` — это Каталан выше; при `p>1` — баллотные числа `(p)/(k+p)·…`; см. `L6-cikl-lemma-konspekt.md`.)*

## 2. Числа Нараяны — что это · картинка `fig-narayana.svg`

Числа Нараяны **уточняют** Каталан: разбивают `Cₙ` путей Дика по числу пиков.

> **Определение.** $N(n,k) = \dfrac{1}{n}\dbinom{n}{k}\dbinom{n}{k-1}$, для `k = 1,…,n`.

> **Смысл (сверено кодом).** `N(n,k)` = число путей Дика длины `2n` с **ровно `k` пиками**. Пик = шаг `↑`, сразу за которым `↓` (вершинка `∧`).

**Ключевые свойства (все проверены перебором):**
- **Разбиение Каталана:** $\displaystyle\sum_{k=1}^{n} N(n,k) = C_n$. (Каждый путь Дика имеет какое-то число пиков от `1` до `n`.)
- **Симметрия:** `N(n,k) = N(n, n+1−k)` (пики ↔ долины, через разворот пути).
- **Края:** `N(n,1) = N(n,n) = 1` (единственный путь с 1 пиком — «одна гора `↑ⁿ↓ⁿ`»; с `n` пиками — «пила `↑↓↑↓…`»).

**Треугольник Нараяны:**

```
n=1:            1
n=2:          1   1
n=3:        1   3   1
n=4:      1   6   6   1
n=5:    1  10   20  10   1
```

(строка `n` суммируется в `Cₙ`: 1, 2, 5, 14, 42.)

На `fig-narayana.svg` для `n=3` показаны все 5 путей Дика, сгруппированные по пикам: **1 · 3 · 1** (пики обведены).

**Другие воплощения того же `N(n,k)`** (все — каталановские объекты, разбитые по естественному параметру):
- нескрещивающиеся разбиения `[n]` на `k` блоков;
- триангуляции `(n+2)`-угольника с `k` «ушами»;
- пути Дика с `k` возвратами на ось — тоже даёт треугольник Нараяны (по другому параметру, но те же числа при подходящем сдвиге).

**Связь с проектом:** в картотеке узел `most-lucky-spots-narayana` — число пиков пути Дика = «счастливые споты» убывающей парковки; матожидание `E[#пиков] = (n+1)/2` (Butler 2412.07873). То есть Нараяны — это «Каталан со счётчиком пиков».

---

## 3. Как это доказать / использовать в счёте

Если в твоём доказательстве пути Дика считаются **с контролем числа пиков** (или подъёмных/спусковых пробегов) — ответом будут именно Нараяны. Два рабочих пути к формуле:

1. **Через пробеги + баллотное условие.** Путь Дика с `k` пиками = `k` подъёмных пробегов `a₁,…,a_k > 0` (сумма `n`) и `k` спусковых `b₁,…,b_k > 0` (сумма `n`), причём каждый префикс баллотно-корректен. Число композиций каждого набора — `C(n−1, k−1)`; баллотное условие срезает их тем же круговым приёмом (цикл-лемма) до
   $$N(n,k) = \frac{1}{n}\binom{n}{k}\binom{n}{k-1}.$$
2. **Через уточнённую цикл-лемму** (Кирстед–Троттер / Нараяна): в `(k, qk+1)`-расстановке каждый `0` играет свою роль — это ровно рефинемент, дающий Нараяны/Чжуна–Феллера (Snevily–West, Lemma 4).

Полный вывод любого из двух — по запросу, распишу на скелете (формулировка + доказательство), как в других лекциях.

## 4. Твоя биекция (подтверждена кодом) — на всякий, чтобы связать нити

`loop` (путь `0→0`, длина `2n`) → **неотрицательный путь**: разрежь в (первом) минимуме на `A` (до) и `B` (после); новый путь `= B`, затем `A`, **повёрнутая на 180°** (reverse+negate, «инвертированная»).

- Результат неотрицателен; кончается на высоте `2·|min|`; обратно — по концу `2h` режешь **ровно посередине** (на высоте `h`) и разворачиваешь. **Биекция loop ↔ неотрицательные пути** — сверено (`n≤4`).
- Родня цикл-леммы: обе «смотрят на самую нижнюю точку». Если в счёте вылезут пики/возвраты — там и появятся Нараяны.

*(Извинение принято к сведению: в прошлом ответе я зря сказал, что чистой биекции нет — твоя работает и красива.)*

## Сверка (код)

1. `N(n,k) = (1/n)C(n,k)C(n,k−1)` = число путей Дика с `k` пиками — совпало перебором, `n≤5` (`1,3,1` · `1,6,6,1` · `1,10,20,10,1`). ✓
2. `Σₖ N(n,k) = Cₙ` и симметрия `N(n,k)=N(n,n+1−k)` — ✓.
3. Твоя биекция `loop ↔ неотриц` (разрез в 1-м минимуме, `B` + 180°-разворот `A`) — биекция, `n≤4`; конец на `2|min|`, разрез на середине. ✓
4. Цикл-лемма: ровно 1 доминирующий поворот из `2n+1`; `Cₙ = C(2n,n)/(n+1)` — ✓ (из прошлого конспекта).
