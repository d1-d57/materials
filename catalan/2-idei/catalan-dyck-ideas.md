# Числа Каталана и пути Дика — список идей

Свод двух веток проекта: комбинаторной (биективные доказательства) и вероятностной (случайные блуждания). Помечено, что проработано, а что пока только названо.

---

## A. Комбинаторный угол — проработано

### Структура «Лаборатории Каталана» (три блока)
1. **Рекуррентные разложения.** Для каждой модели: как объект размера n разрезается на два поменьше → C(n+1) = Σ C(k)·C(n−k). Разрез по первому возвращению (пути), по корню (деревья), по уху (триангуляции).
2. **Биекции между моделями.** Две модели на экране, стрелки в обе стороны. Реализация через хаб (скобочные последовательности). Все биекции согласованы с рекуррентой → коммутативная система.
3. **Доказательства формулы** C(n) = C(2n,n)/(n+1).

### Четыре биективных доказательства формулы
- **Принцип отражения** (André). Пути. Плохие пути ↔ пути в другую точку. Cₙ = C(2n,n) − C(2n,n+1).
- **Циклическая лемма** (Dvoretzky–Motzkin). Пути/слова. Из 2n+1 циклических сдвигов ровно один доминирующий. (2n+1)·Cₙ = C(2n+1,n).
- **Exceedance / Chung–Feller.** Пути. Все C(2n,n) путей разбиваются на n+1 равных классов по exceedance. Два взгляда на одно доказательство (сетка n×n ↔ горный профиль длины 2n).
- **Раздутие/сдутие триангуляций.** Триангуляции. (4n+2)·Cₙ = (n+2)·Cₙ₊₁. Прототип реализован.

Вывод исследования: три из четырёх работают на путях Дика, четвёртое — только на триангуляциях. Переформулировать раздутие на язык путей не удалось; перенести путевые доказательства на деревья/триангуляции — тоже (у путей привилегия: «снятие условия неотрицательности» даёт тривиально считаемое C(2n,n)).

### Модели
Базовые: пути Дика (= правильные скобочные последовательности), полные бинарные деревья, триангуляции (n+2)-угольника. Кандидаты: плоские деревья, stack-sortable перестановки.

## B. Вероятностный угол — список идей (из апрельского каталога)

Дика-связанные сюжеты, по убыванию близости к числам Каталана:

- **Задача о голосовании (ballot problem).** Прямо пути Дика: пути, не опускающиеся ниже нуля. Формула Бертрана для доли таких путей. Это тот же принцип отражения, что и в блоке A, но в вероятностной оболочке.
- **Первое возвращение симметричного блуждания.** Разложение по первому возвращению — это буквально рекуррента Каталана. Числа Каталана считают экскурсии блуждания (пути, вернувшиеся в ноль впервые на шаге 2n).
- **Теорема о возвращении.** Одномерное симметричное блуждание возвращается в ноль с вероятностью 1. Вероятности первого возвращения выражаются через числа Каталана.
- **Закон арксинуса.** Где блуждание проводит время выше/ниже нуля. Статистика, тесно связанная с распределением площади под путём Дика.
- **Разорение игрока.** Блуждание с поглощающими стенками. Тот же отражательный аппарат.
- **Возвратность 2D vs 3D (Пойа).** Примыкает как сюжет про блуждания, но с числами Каталана прямо не связано.

Более широкий каталог (не про Дика, для контекста): Бюффон, Монте-Карло π, дни рождения, купоны, самолёт-100-пассажиров, Монти Холл, секретарь, Пенни, ацтекский бриллиант, перколяция, парковка Реньи, ЦПТ, Бенфорд, Пуассон.

## C. Мостики: где комбинаторика и вероятность — одно и то же

Самое ценное для проекта — точки, где биекция из блока A и вероятностный факт из блока B совпадают:

- **Принцип отражения = формула Бертрана = разорение игрока.** Один отражательный приём в трёх обличьях.
- **Первое возвращение = рекуррента Каталана.** Разрез экскурсии по первому касанию нуля — это разрез пути Дика в блоке 1.
- **Exceedance ↔ закон арксинуса.** Обе про долю времени/шагов выше диагонали (нуля).

Эти совпадения — естественный throughline, если из проекта вырастает единый материал: одна конструкция, показанная и как комбинаторная биекция, и как вероятностная теорема.
