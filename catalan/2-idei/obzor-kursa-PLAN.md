# Обзор курса по перечислительной комбинаторике — план арки

Статус: **план, арка не заведена**. Заведение — отдельным решением владельца.
Дата: 2026-07-15. Источник ТЗ: «Документ 1.md» (загружен владельцем) + интервью 15.07.

---

## Что делаем

Академический обзор возможного курса по enumerative / introductory algebraic
combinatorics. Не программа, не реклама, не научпоп — **математический survey**.
Читатель знает базовую университетскую математику; всё остальное вводится в тексте.

Выход: **один HTML-документ** (документ-вид), собранный готовым генератором
`disciplina/../disciplina/_generator/build_doc.py` из `content/*.md`.

## Рамка (по интервью 15.07)

| Параметр | Решение |
|---|---|
| Отношение к картотеке | **Дополнение с другой стороны.** Картотека — вглубь по каталановским объектам; обзор — вширь по всей области. Может перерасти в основу большой годовой программы. |
| Охват | **~10 сюжетов** — объектов / идей / принципов / приёмов, которые пронизывают область и которыми она концептуально исчерпывается. |
| Объём сюжета | **~2 страницы**, ориентир, не догма. Критерий важнее объёма: текст самодостаточен — из него можно узнать новое **без обращения к посторонним источникам**. |
| Источники | Библиотека (`biblioteka/`, 84 МБ: книги, конспекты, обзоры, в т.ч. несколько вариантов Постникова) + **точечный веб** для закрытия дыр и сверки формулировок. |
| Иллюстрации | **Минимум.** Только там, где без картинки не понять: путь Дика, диаграмма Юнга, диаграмма Хассе, RSK-вставка. Ориентир 10–15 простых SVG. |

### Расхождение с исходным ТЗ — зафиксировано осознанно

ТЗ говорит «40–80 страниц», «не пытайтесь сделать документ коротким».
Интервью даёт ~20 страниц. **Побеждает интервью**: приоритет — самодостаточность
каждого сюжета, а не длина. Формулировка ТЗ «лучше меньше тем, но каждая раскрыта
содержательно» с этим согласуется.

## Фазы

Правило: **каждая фаза = отдельный заход** с пустым контекстом. Заходы маленькие.
Каждая фаза кончается артефактом-файлом, который читает следующая.

### Ф0 — Инвентаризация библиотеки (1 заход, дешёвый)

Не читаем содержимое. Строим **карту покрытия**: какой источник про что и насколько глубоко.
Вход: `biblioteka/istochniki/MANIFEST.md`, `VYCHITANO.md`, оглавления книг/конспектов.
Выход: `POKRYTIE.md` — таблица «тема → источники → качество покрытия → дыры».
Гейт: видно, какие сюжеты обеспечены источником, а какие придётся добирать вебом.
Попутно (дёшево): подтвердить, какая папка — «старая папка обзоров» для выхода.

**Ф0 закрыта 15.07.** Выход: `biblioteka/POKRYTIE.md`. 67 источников, вычитан 31.
Находка, изменившая план: библиотека перекошена в уже накопанный кластер
(парковки / Кэли / цикл-лемма — ~40 из 67 файлов), а названные владельцем интересы
(q-аналоги · ЧУМы · Юнг/RSK) обеспечены тонко или пусто. Строить Ф1 на этом —
значит получить скелет, перекошенный в сторону сделанного. Отсюда ↓

### Ф0.5 — Вычитать Notes 02–07 курса 18.212 (1 заход, добавлен 15.07)

`biblioteka/istochniki/konspekty/18.212 [official, Spring 2025]/` — 11 конспектов
Постникова (Catalan · Young Tableaux · Permutations · Posets · More Young Diagrams ·
q-Analogs · Partitions · Trees · Arrangements/Parking · More Graphs · Misc).
Notes 02–07 (96 стр.) не читаны ни разу и покрывают **ровно все три дыры**.
Дешевле любого веб-поиска и заодно даёт костяк-кандидат для десяти сюжетов.
Выход: дайджесты + бэкфилл `biblioteka/istochniki/VYCHITANO.md`.
Гейт: по каждой из трёх дыр видно, есть ли материал на самодостаточный сюжет.

### Ф1 — Скелет: список 10 сюжетов (1 заход + спор с владельцем)

Восстанавливаем естественную структуру области. Не следуем одному источнику.
Вход: `POKRYTIE.md` + `spravochnik/KARTA-OBLASTI.md` + `kurs/anons.md` (канон рамки).
Выход: `obzor/SKELET.md` — 10 сюжетов, на каждый: одно предложение о чём;
чем оправдан (какой источник, почему сюжет несущий); связи с соседями.
**Гейт владельца:** список сюжетов утверждается до любого наполнения.
Это самая дешёвая точка, где можно ошибиться бесплатно.

### Ф2 — Шаблон узла + пилот (1 заход)

Что именно лежит в двух страницах. Кандидат-шаблон (из ТЗ, п. «Что писать про каждую тему»):
объекты → основные определения → центральная теорема → метод → красивая биекция →
неожиданная связь → зачем сюжет → связи назад/вперёд → что упражнение, что теорема, что жемчужина.
Пилот на одном сюжете целиком (кандидат: **Каталановские объекты** — картотека уже питает).
Выход: `obzor/content/01-catalan.md` + уточнённый шаблон.
**Гейт владельца:** правит шаблон на живом примере. Дальше шаблон не меняется.

### Ф3 — Наполнение (4–5 заходов, по 2–3 сюжета)

По утверждённому шаблону. Каждый заход: свои сюжеты, свои источники поимённо, свой отчёт.
Выход: `obzor/content/NN-*.md`.
Гейт каждого захода: сюжет читается сам по себе; ни одного термина без определения.

### Ф4 — Сшивка (1 заход)

Сквозная линия, перекрёстные ссылки между сюжетами, оглавление, введение.
Здесь обзор превращается из десяти текстов в один. Скилл: `popsci-narrative` (композиция).
Выход: `obzor/content/00-vvedenie.md` + правки связок.

### Ф5 — HTML (1 заход)

**Только `build_doc.py`.** Новый генератор не писать. Правится источник (`content/*.md`,
`tokens.css`), HTML — выход. Плюс 10–15 простых SVG.
Выход: `kurs/obzor-perechislitelnaya.html`.

### Ф6 — Проверка (1 заход)

- термины — сверка с `spravochnik/TERMINY-russkie.md`, **без веб-поиска** (решение владельца);
- `russian-editor` — стиль (но текст математический, не научпоп: без «причёсывания» строгости);
- сверка ключевых формулировок и теорем по источникам;
- **проверка ссылок**: каждая ссылка обзор→картотека и картотека→обзор ведёт куда обещает;
- `visual-design-review` — беглый взгляд на вёрстку.

**Итого ≈ 10 заходов.**

## Решения (интервью 15.07, раунд 2)

1. **Язык — русский.** Терминологию **не искать**: уровень погружения такой, что всё
   легко находится, а в проекте уже лежит `spravochnik/TERMINY-russkie.md`.
   В Ф6 `math-russian-terminology` **не гоняем** — сверяемся с файлом проекта.
2. **Кладём в существующую папку обзоров**, отдельную не заводим. Плюс **сквозная
   система ссылок**: обзор ↔ картотека (`spravochnik/stati/*`) ↔ лекции (`kurs/*`).
   Ссылки — не украшение, а несущая конструкция: обзор вширь, картотека вглубь,
   переход между ними должен быть в один клик. Адресация картотеки — по `id`
   (`{dyck}`, `{cikl-lemma}`, `{hub}`), см. `spravochnik/KARTA-OBLASTI.md`.
   **Решено 15.07 (Ф0): выход в `kurs/`** — СЛОЙ 2 «публикации поверх знания», где уже
   лежат `kurs-obshchiy.html`, `mir2-statya.html`, `lekciya-vetvyashchiesya.html`.
   Обзор ссылается на `spravochnik/` по `id`, математику там не дублирует.
3. **q-аналоги — сюжет первого ряда.** Владельцу интересны; и они того стоят:
   q-аналог — это способ увидеть, что число было тенью многочлена, а статистика
   на объектах (major index, inv, area) — тем, что этот многочлен помнит.
   **Species — выносим в замечание, не в сюжет.** Теория видов Жуаяля — красивый
   категорный каркас над производящими функциями (структура на конечном множестве
   как функтор; экспоненциальные ПФ получаются автоматически). Но это машинерия
   *над* областью, а не несущая идея *внутри* неё: на нашем уровне она объяснит
   меньше, чем съест страниц. Место — одно замечание в сюжете про произв. функции.
4. **Годовая программа — отложена.** Сейчас собираем сюжеты. Как выстроить из них
   курс (порядок, семестры) — думаем потом, отдельно. В Ф1 сюжеты оправдываем
   **концептуальной несущестью**, а не местом в расписании.
