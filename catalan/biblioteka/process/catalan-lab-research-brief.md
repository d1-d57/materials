# Лаборатория Каталана — ТЗ на исследование

## Контекст проекта

Создаётся интерактивный сайт «Лаборатория Каталана» — первая глава большого проекта о визуальных биекциях в комбинаторике. Сайт состоит из одной HTML-страницы с тремя раскрывающимися блоками. Каждый блок содержит интерактивные виджеты, в которых пользователь строит комбинаторные объекты и видит результат биекции.

Аудитория — математически зрелые люди. Текст минимален, основное содержание — в интерактивных конструкциях.

Рабочий прототип одного виджета (биекция «раздутие/сдутие» для триангуляций) уже существует.

---

## Три блока проекта

### Блок 1: Рекуррентные разложения
Для каждой модели чисел Каталана показывается, как объект размера n разбивается на два объекта меньшего размера (first return decomposition и её аналоги). Это даёт рекуррентное соотношение C(n+1) = Σ C(k)·C(n-k).

### Блок 2: Биекции между моделями
Две модели на экране, стрелки в обе стороны. Пользователь строит объект в одной модели, получает соответствующий объект в другой. Все биекции согласованы с рекуррентными разложениями из Блока 1, поэтому образуют коммутативную систему. Реализация через «хаб» (скобочные последовательности): достаточно написать биекцию каждой модели в хаб и обратно.

### Блок 3: Доказательства формулы
Биективные доказательства формулы C(n) = C(2n,n)/(n+1). Каждое доказательство — это биекция между двумя множествами, размеры которых связаны тождеством, из которого формула выводится. Тот же интерфейс: слева одно множество, справа другое, стрелки.

### Задача 1: Обзор биективных доказательств формулы (ПРИОРИТЕТ)

**Почему это первое:** от результатов этой задачи зависит выбор моделей для Блоков 1 и 2.

Найди все известные биективные (не через производящие функции, не через индукцию) доказательства формулы C(n) = C(2n,n)/(n+1) или эквивалентных тождеств, из которых эта формула выводится.

Для каждого доказательства запиши в файл:

1. **Название / атрибуция** (кто придумал, как обычно называют)
2. **Тождество**, которое доказывается (например, (4n+2)·Cₙ = (n+2)·Cₙ₊₁, или C(2n,n) = (n+1)·Cₙ, или другое)
3. **Модель** — какие комбинаторные объекты используются (пути Дика, триангуляции, деревья, что-то ещё?)
4. **Левое множество** — что стоит слева в биекции, из каких компонентов оно собрано, какова его мощность
5. **Правое множество** — аналогично
6. **Описание биекции** — пошаговый алгоритм в обе стороны, достаточно подробный для программирования
7. **Визуализируемость** — оценка того, насколько это можно показать интерактивно (высокая / средняя / низкая) и краткий комментарий почему

**Известные на данный момент доказательства (проверить и дополнить):**

- **Принцип отражения (André, 1887):** модель — пути. Плохие пути (пересекающие диагональ) биективны путям из (0,0) в (n-1, n+1) через отражение относительно y=x+1. Даёт Cₙ = C(2n,n) - C(2n,n+1).
- **Раздутие/сдутие триангуляций:** модель — триангуляции. Тождество (4n+2)Cₙ = (n+2)Cₙ₊₁. Прототип уже реализован.
- **Циклическая лемма (Dvoretzky–Motzkin):** модель — пути/последовательности. Из (2n+1) циклических сдвигов последовательности из (n+1) X и n Y ровно один является доминирующим. Даёт Cₙ = C(2n,n)/(n+1) напрямую.
- **Exceedance-биекция:** модель — пути. Все C(2n,n) монотонных путей разбиваются на (n+1) классов одинакового размера по числу рёбер выше диагонали (exceedance). Биекция уменьшает exceedance на 1.
- **Теорема Чанга–Феллера (Chung–Feller):** все пути из (0,0) в (2n,0) (не обязательно неотрицательные) равномерно распределены по числу «плохих» отрезков. Путей Дика ровно 1/(n+1) от всех. Есть ли хорошая биективная версия?

**Что искать дополнительно:**
- Есть ли доказательства, работающие на языке деревьев (не путей)?
- Есть ли доказательства, работающие на языке триангуляций (помимо раздутия)?
- Есть ли доказательства через non-crossing partitions, таблицы Юнга 2×n, или другие каталановые объекты?
- Проверить книгу Stanley «Catalan Numbers» (2015) на предмет доказательств, не вошедших в Википедию.
- Проверить книгу Stanley «Enumerative Combinatorics, Vol. 2», Упражнение 6.19 — там перечислены 66+ интерпретаций чисел Каталана, возможно, некоторые содержат нетривиальные биекции.

**Формат записи в файл:**

```
## Доказательство N: [Название]

**Атрибуция:** ...
**Тождество:** ...
**Модель:** ...

### Левое множество
...

### Правое множество
...

### Биекция (→)
Шаг 1: ...
Шаг 2: ...

### Обратная биекция (←)
Шаг 1: ...
Шаг 2: ...

### Визуализируемость
[высокая/средняя/низкая] — комментарий
```

### Задача 2: Фиксация моделей

На основе результатов Задачи 1 зафиксируй окончательный список моделей.

**Базовый набор (точно входят):**
- Пути Дика (= правильные скобочные последовательности, = последовательности 0/1 с условием на префиксы)
- Полные бинарные деревья (каждая вершина — лист или имеет ровно двух детей)
- Триангуляции выпуклого (n+2)-угольника с выделенным основанием

**Кандидаты (включить, если есть содержательная причина):**
- Корневые планарные деревья с упорядоченными детьми (plane trees)
- Stack-sortable перестановки (перестановки, сортируемые одним стеком)
- Non-crossing partitions
- Другие модели, если какое-то доказательство из Задачи 1 работает именно на их языке

**Критерии включения модели:**
1. Визуальная выразительность (можно красиво нарисовать, пользователь может конструировать объект руками)
2. Содержательность рекуррентного разложения (оно должно быть естественным и видимым)
3. Необходимость для какого-то доказательства из Блока 3

Для каждой включённой модели запиши в файл:
- Точное формальное определение
- Чему равен параметр n (что считаем — вершины, рёбра, стороны?)
- Как выглядит рекуррентное разложение (first return / root decomposition / ear removal и т.д.)
- Набросок интерфейса: как пользователь строит объект (кликает вершины? перетаскивает рёбра? рисует путь на решётке?)

### Задача 3: Биекции между моделями (через хаб)

Для каждой модели из Задачи 2 опиши каноническую биекцию между ней и скобочными последовательностями (хаб).

**Требования к биекции:**
- Она должна быть согласована с рекуррентным разложением (перестановочна с first return decomposition)
- Описание должно быть алгоритмическим — достаточным для написания кода на JavaScript
- Биекция должна быть описана в обе стороны

**Важно проверить:** что все описанные биекции действительно образуют коммутативную систему. Т.е. если мы возьмём биекцию A→хаб→B и сравним с прямой «естественной» биекцией A→B, они должны совпадать. Если для какой-то пары это не так — отметить это явно.

Формат: для каждой модели — раздел в файле с алгоритмом в обе стороны и примером для n=3.

### Процесс
1. Начни с веб-поиска по каждому доказательству. Ищи точные алгоритмические описания биекций, не просто утверждения о существовании.
2. Для каждого доказательства проверяй: можно ли его визуализировать интерактивно? Что видит пользователь? Что он конструирует руками?
3. Если при поиске обнаружишь доказательство, которого нет в моём списке — добавь его.
4. Если какое-то доказательство существует только в виде ссылки на статью без свободного доступа — отметь это и опиши то, что удалось понять.

### Формат результата
Единый markdown-файл `catalan-lab-knowledge-base.md`, структурированный по задачам выше. Файл должен быть:
- Самодостаточным (не ссылаться на «контекст разговора»)
- Алгоритмически точным (описания биекций можно напрямую переводить в код)
- С примерами для малых n (n=2 или n=3)

## Ограничения и примечания

- **Не включать** доказательства через производящие функции или индукцию — только биективные.
- **Не включать** продвинутые обобщения (числа Фусса–Каталана, q-аналоги, числа Нараяна) — это потенциальное продолжение, но не сейчас.
- **Формулу** C(n) = C(2n,n)/(n+1) можно доказывать через разные промежуточные тождества. Все такие тождества нас интересуют, если доказательство биективное.
- Если два доказательства отличаются только языком (одно и то же на путях Дика и на скобочных последовательностях) — считать их одним и отметить оба языка.
