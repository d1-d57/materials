# Исследование: биективные доказательства для проекта «Лаборатория Каталана»

## Что это

Я готовлю интерактивный сайт, в котором пользователь руками конструирует комбинаторные объекты и видит, как работают биекции, связанные с числами Каталана. Мне нужен один исчерпывающий справочный файл, по которому можно будет программировать все виджеты.

Файл называется `catalan-lab-knowledge-base.md`. Ты будешь создавать его постепенно, шаг за шагом. После каждого шага — сохраняешь файл, коротко говоришь мне, что нашлось, и ждёшь моего «продолжай».

3. **Запись в файл.** Всё ценное записывай в файл сразу. Формат — markdown. Описания биекций — пошаговые алгоритмы, достаточные для перевода в JavaScript. Каждое описание сопровождай конкретным примером для малого n.
4. **Проверка.** После записи каждой биекции прогони её на примере: возьми конкретный объект, примени биекцию, примени обратную, убедись что вернулся к исходному. Если не сходится — разберись почему, исправь описание.

## Математический контекст

Три блока сайта:

**Блок 1 — Рекуррентные разложения.** Для нескольких моделей чисел Каталана (пути Дика, полные бинарные деревья, триангуляции (n+2)-угольника, возможно другие) показать, как объект размера n каноническим образом разбивается на два объекта меньшего размера → рекуррента C(n+1) = Σ C(k)·C(n-k).

**Блок 2 — Биекции между моделями.** Пользователь выбирает две модели из списка, строит объект в одной, нажимает стрелку → получает объект в другой. Реализация через «хаб»: каждая модель имеет каноническую биекцию в скобочные последовательности и обратно. Все эти биекции согласованы с рекуррентным разложением, поэтому композиция через хаб даёт ту же биекцию, что и прямая «естественная». Это ключевое свойство — его нужно проверить.

**Блок 3 — Доказательства формулы C(n) = C(2n,n)/(n+1).** Каждое доказательство — биекция между двумя конечными множествами, размеры которых связаны тождеством, из которого формула выводится. Тот же интерфейс: два поля, стрелки. Меня интересуют только биективные доказательства (не производящие функции, не индукция).

### Шаг 3. Детальный разбор: Раздутие/сдутие триангуляций

**Задача:** записать точный алгоритм, хотя прототип уже существует.

- Тождество: (4n+2)·Cₙ = (n+2)·Cₙ₊₁
- Левое множество: триангуляция (n+2)-угольника с выделенным основанием + ориентированное ребро (любое — сторона или диагональ, с выбором направления). Мощность: (4n+2)·Cₙ.
- Правое множество: триангуляция (n+3)-угольника с выделенным основанием + выделенная не-базисная сторона. Мощность: (n+2)·Cₙ₊₁.
- Алгоритм →: раздутие — ориентированное ребро расщепляется в треугольник, вершина с точкой расщепляется на две, новая сторона становится выделенной.
- Алгоритм ←: сдутие — треугольник при выделенной стороне стягивается, одна из оставшихся сторон получает ориентацию (точку у стянутой вершины).

Найди описание в нескольких источниках, сравни. Обрати особое внимание на то, как определяется направление ориентации при сдутии — это единственное тонкое место.

**Верификация:** для n=1 (треугольник, C₁=1): левое множество имеет (4·1+2)·1 = 6 элементов, правое (1+2)·C₂ = 3·2 = 6. Перечисли все 6 пар и проверь биекцию.

### Шаг 4. Детальный разбор: Циклическая лемма

**Задача:** разобрать лемму и её применение к формуле Каталана.

Ищи Dershowitz & Zaks 1990, раздел в Википедии, лекционные записки.

- Лемма: последовательность m символов X и n символов Y, m > n, имеет ровно m−n доминирующих циклических сдвигов (доминирующий = на каждом префиксе число X строго больше числа Y).
- Применение: m = n+1, получаем ровно 1 доминирующий сдвиг из 2n+1. Каждая последовательность из n+1 символов X и n символов Y однозначно определяет путь Дика (убрать первый X из доминирующего сдвига). Итого C(2n+1, n) последовательностей, у каждой один сдвиг → Cₙ = C(2n+1,n)/(2n+1) = C(2n,n)/(n+1).

Запиши точный алгоритм: как по произвольной последовательности найти доминирующий сдвиг. Как по пути Дика восстановить исходную последовательность.

**Визуализация:** это можно показать как «закольцованный путь», который вращается. Пользователь строит произвольную последовательность шагов, она замыкается в кольцо, кольцо крутится до единственного правильного положения → путь Дика. Или наоборот: пользователь строит путь Дика, кольцо крутится в случайное положение → произвольная последовательность.

**Верификация:** возьми все C(5,2) = 10 последовательностей из 3 X и 2 Y. Для каждой найди доминирующий сдвиг. Покажи, что получается ровно C₂ = 2 различных пути Дика, каждый ровно 5 раз.

### Шаг 5. Детальный разбор: Exceedance-биекция

**Задача:** разобрать биекцию, уменьшающую exceedance на 1.

Ищи в Википедии (Third proof), лекционных записках.

- Exceedance монотонного пути из (0,0) в (n,n) = число вертикальных рёбер выше диагонали.
- Биекция: путь с exceedance k ↦ путь с exceedance k−1. Алгоритм: найти первое ребро выше диагонали → следовать до возвращения на диагональ → обозначить точку X → поменять местами части до и после X.
- Следствие: все C(2n,n) путей разбиваются на n+1 классов равного размера → Cₙ = C(2n,n)/(n+1).

Запиши точный алгоритм. Запиши обратный алгоритм (увеличение exceedance на 1).

**Верификация:** для n=3 построй полную таблицу (как в Википедии): 20 путей, разбитых на 4 класса по 5 путей. Проверь, что алгоритм переводит каждый класс в следующий.
