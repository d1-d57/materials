# НАВИГАЦИЯ — единственный индекс проекта «Каталан»

Мозг архива и **единственный** список файлов: куда идти по типу работы, куда дописывать новую мысль, у кого «источник правды». Полный вход — `COWORK.md`.

> ⚙️ **Правило регистрации.** Любой новый / удалённый / переименованный `.md` получает строку здесь ТЕМ ЖЕ ходом. **Документ-сирота = не существует.** Целостность (0 сирот · 0 битых ссылок) проверит `tools/check_docs.py` — заводится Code-заходом.
>
> ⚙️ **HTML — готовым генератором** `materials/_generator/` (`build_doc.py` — документ-вид, `build_deck.py` — слайды). Новый генератор не писать; правь источник, HTML — выход.

## Два продукта в одной папке
1. **ЗНАНИЕ** — вечнозелёный справочник области (числа Каталана / пути Дика). Источник правды, markdown.
2. **ПУБЛИКАЦИИ поверх знания** — курс (сейчас), позже другие лекции и большой сайт. Деплоятся на GitHub.

**Односторонняя зависимость:** публикации ссылаются на знание, не наоборот. Математику правим только в `spravochnik/`, никогда — в отрендеренном HTML.

## Возобновляешь работу?
→ `1-START-HERE/dnevnik-i-plan.md` — разделы «Текущее состояние» и «Ближайший шаг».
