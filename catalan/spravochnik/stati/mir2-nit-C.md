# Нить C — сколько деревьев? (доказательства Кэли, задняя половина круга)

> Сюжет Мира 2, «счётная сторона»: одно число n^{n-2} (= (n+1)^{n-1} для наших деревьев на n+1 верш.) — сколько у него ЛИЦ? Разные доказательства = разные геометрии одного факта; одно из лиц (цикл-лемма) общее с Миром 1. Узлы в порядке нити. Объекты — `mir2-obiekty.md`. Карта — `KARTA-OBLASTI`. Формат — `STANDART-uzla.md`.

```
id: zagadka-skolko-derevev · затравка · сколько помеченных деревьев? Кэли: n^{n-2}
находка: помеченных деревьев на n верш. ровно n^{n-2} (Кэли); для наших деревьев на n+1 верш. —
  (n+1)^{n-1}, ровно счёт парковок (`zagadka-odno-chislo`). Мотор задней половины: у ОДНОГО числа
  много доказательств — и каждое высвечивает свою скрытую геометрию. Их и собираем.
связи: [obj-derevo — герой; zagadka-odno-chislo ↔ то же число у парковок; mnogolikost-keli → свод]
уровень: школьно · источник: Aigner–Ziegler Гл.30; Yan §1.2 · статус: черновик
```

```
id: dok-prufer · биекция · Прюфер-код: дерево ↔ последовательность
находка: дерево на m верш. ↔ последовательность из [m]^{m-2} (срезаем наименьший лист, пишем
  соседа; обратимо). Явный, наглядный, ШКОЛЬНЫЙ — прямой пункт круга владельца. Бонус (Yan §1.2.1):
  версия Прюфера/Поллака даёт ЕЩЁ и парковка↔дерево — ТРЕТЬЯ карта парковка↔дерево (после φ Кнута и
  наивной), несёт статистику «совпадающие соседи» a_i=a_{i+1} ⇒ (q+n)^{n-1}. NB: у Aigner–Ziegler
  алгоритма Прюфера НЕТ (только назван) — брать из Yan §1.2.1 / Yu §6.
связи: [obj-derevo, obj-parkovka — что связывает; zagadka-skolko-derevev ← лицо №1;

```

```
id: dok-joyal · биекция · функции ↔ деревья-с-2-концами (позвоночные) — скрытая геометрия
находка: {все функции [n]→[n]} (n^n) ↔ {деревья с 2 отмеч. концами} (n^2·T_n) ⇒ T_n=n^{n-2}.
  Механизм: функциональный граф f (из каждой вершины 1 стрелка) = ЦИКЛЫ + подвешенные деревья;
  циклическую часть разворачиваем в путь между двумя концами. Образцовая «комбинаторика→геометрия»,
  сильно визуально. Объект = случайное отображение (теорвер-вкус). СВЯЗЬ: та же картинка «цикл +
  деревья», что стоит за парковками и цикл-леммой Поллака ⇒ идейный мост к `most-cikl-lemma`.
связи: [obj-derevo — герой; zagadka-skolko-derevev ← лицо №2; most-cikl-lemma ↔ общая картина «функц.
  граф: цикл+деревья»; mnogolikost-keli → в свод]
уровень: требует-приручения · источник: Aigner–Ziegler Гл.30 (1-е док-во, Жойяль) · статус: черновик
```
