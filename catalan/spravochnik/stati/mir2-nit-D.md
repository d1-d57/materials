# Нить D — мосты наружу (бриллианты-обогащения)

> Не линейный сюжет, а набор «мостов из ядра наружу»: в теорвер, в другую область, между половинами курса, к Каталану. Найдены интернет-свипом (реш. №10). Каждый честно размечен по доступности. Объекты — `mir2-obiekty.md`. Карта — `KARTA-OBLASTI`. Формат — `STANDART-uzla.md`.

```
id: luckycars · утверждение · «счастливые машины»: в среднем ~половина — ТЕОРВЕР-бриллиант
находка: машина «счастлива», если встала ровно на желаемое место. E[счастливых] у СЛУЧАЙНОЙ парковки
  ≈ n/2, точнее (n/2)(1 + 2/(n+1)). Выводится НАШИМ приёмом Поллака (круг) + линейностью матожидания:
  приезжает i-я — занято i−1 из n+1 ⇒ P(счастлива) = 1 − (i−1)/(n+1). Без производящих функций.
  Настоящий теорвер на НУЛЕВОЙ новой технике; есть мост к путям Дика (lucky в неубыв. парковках).
  Лучший добор под вкус владельца.
связи: [most-cikl-lemma → тот же круговой приём Поллака; obj-parkovka — герой; obj-put-dika → мост к Дику]
уровень: школьно · источник: Slavík–Vestenická «Lucky Cars» (элементарно; формула сверена, совпала); Diaconis–Hicks, Adv. Appl. Math. 89 (2017) 125–155 (preprint arXiv 1611.09821) · статус: готово
```


```
id: most-qcatalan-area · мостик · area путей Дика → q-Каталан = мост половин курса
находка: суммируя q^area по путям Дика, получаем q-число Каталана C_n(q) = 1/[n+1]_q · [2n,n]_q
  (MacMahon). area — та же статистика, что несёт наш размеченный путь / парковка ⇒ area склеивает
  ПЕРВУЮ половину (Дик, Каталан) со ВТОРОЙ (парковки, Кэли). При q=1 → C_n, школьно на малых n.
  NB: q,t-Каталан (area,dinv) — уже вне школы, не тянуть.
связи: [stat-area — герой; hub-pomech-put → area как ось связности половин; obj-put-dika]
уровень: школьно (q-Каталан, малые n) / вне-школы (q,t) · источник: обзор Major Index on Catalan (2407.17168); Haglund q,t-Catalan (справка) · статус: черновик
```

```
id: bij-nc-parkovka · биекция · некроссинговые разбиения ↔ неубывающие парковки (резерв)
находка: NC-разбиения [n] считаются Каталаном C_n (наглядно: непересекающиеся хорды). Простая биекция
  NC → неубывающая парковка: в каждом блоке всё → минимум блока, сортируй. Лёгкий каталанов мостик в
  первую половину. Глубже (Stanley 1997): макс. цепи решётки NC = все парковки = (n+1)^{n-1} — красиво,
  но цепи для школы тяжелы. Держим лёгкую версию как резерв.

```
