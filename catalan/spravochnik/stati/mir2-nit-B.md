# Нить B — displacement ↔ инверсии (парковки ↔ деревья)

> Сюжет Мира 2, «сторона деревьев»: от загадки «один счёт у двух задач» к чистой биекции, несущей статистику. Узлы — в порядке нити (файл читается как история). Объекты-ручки — `mir2-obiekty.md`. Карта/индекс — `KARTA-OBLASTI`. Формат узла — `STANDART-uzla.md`. Пара к нити A (`mir2-nit-A.md`); сходятся на `area`.

```
id: zagadka-odno-chislo · затравка · один счёт (n+1)^{n-1} у двух РАЗНЫХ задач
находка: парковки (Поллак, круговой счёт) и помеченные деревья/леса на n+1 верш. (Кэли) —
  несвязанные задачи, ОДИН ответ (n+1)^{n-1}. Мотор нити: раз ответ один — обязана быть прямая
  биекция; и интересна не она сама, а КАКАЯ СТАТИСТИКА через неё переходит.
связи: [obj-parkovka, obj-derevo — герои; most-cikl-lemma ↔ Поллак и есть круговой счёт;
  bij-knuth → разрешение загадки]
уровень: школьно · источник: Yan §1.1–1.2 · статус: черновик

```
id: bij-knuth · биекция · парковка ↔ дерево, displacement=inv — ЯДРО нити (бриллиант)
находка: φ Кнута несёт displacement(парковки) = inv(дерева) ПОЭЛЕМЕНТНО — прямая элегантная
  альтернатива РЕКУРСИВНОЙ биекции Кревераса. Механизм: вспом. дерево («предок = первый бо́льший
  справа») + один preorder-релейбл; без сэндпайлов и рекуррент. ВАЖНО: это ОТДЕЛЬНАЯ биекция, НЕ
  наивная карта путь→парковка→дерево (та несёт лишь area=displacement, inv на ней ломается — пример
  Постникова: inv=4 против displacement=16). Честный уровень — требует-приручения (один хитрый шаг:
  релейбл через «k-ю наименьшую в поддереве»), не «школьно». Бонус: lucky-машины ↔ leaders дерева.
связи: [zagadka-odno-chislo ← разрешает; thm-kreweras → поэлементная реализация q-тождества;
  bij-burning-pyy ↔ визуальная альтернатива (DFS); vyhod-nit-A / A:vyhod-nit-B → трудная половина шарнира;
  stat-area (=displacement) / stat-inv-dereva — что↔что]
уровень: требует-приручения · источник: Yan §1.2.2 (φ Кнута, Example 1.7 a=(4,0,1,0,3,6,4), Fig 1.2, стр. 8–10) · статус: черновик
```

```
id: bij-shin · биекция · парковка ↔ лес, area=displacement, inv↔jump — ДОСТУПНОЕ ядро (сэндпайл-free)
находка: биекция Шина (arXiv 0810.0427) — та «прямая нерекурсивная», что просил Стэнли: несёт
  area↔inv ПОЭЛЕМЕНТНО (Lemma 2: inv(F:v) = jump машины), area=displacement выписана явной формулой
  jump = C(n+1,2) − |P|. БЕЗ сэндпайлов и БЕЗ линала, деревья вводятся с нуля. Самый доступный из трёх
  путей к area↔inv (против Кнута и burning) ⇒ рекомендованный школьный маршрут. Минус: три наложенных
  дерева (D,C,I) поначалу пугают, для «просто area=inv» половину можно выкинуть.
связи: [thm-kreweras → доступная реализация; bij-knuth ↔ элегантная, но со вспом. деревом;
  bij-burning-pyy ↔ вытесняет его (тот тащит сэндпайлы); stat-area, stat-inv-dereva]
уровень: требует-приручения (доступнее всех) · источник: Shin (0810.0427) шаги 1–8 + Lemma 2; вход — SymCat (symmetricfunctions.com/parking-functions) · статус: черновик
```

```
id: thm-kreweras · утверждение · displacement парковок ~ инверсии деревьев (q-тождество)
находка: Σ q^{displacement}(парковки) = Σ q^{inv}(деревья на n+1 верш.) = I_n(q), Yan Thm 1.4; при
  q=1 = (n+1)^{n-1}. Само тождество Yan доказывает АНАЛИТИЧЕСКИ — обе стороны бьют ОДНУ рекурренту
  (не биекцией). Биективных реализаций две: Креверас (рекурсивно) и Кнут φ (прямо, bij-knuth).
  q-уровень превращает совпадение ЧИСЕЛ в совпадение РАСПРЕДЕЛЕНИЙ — суть нити.
связи: [bij-knuth → поэлементная (Кнут) реализация; stat-area (=displacement), stat-inv-dereva;
  obj-put-dika → area — та же каталановская статистика ⇒ мост в Мир 1 (нить A)]
уровень: требует-приручения (q-версия) / школьно (q=1, счёт) · источник: Yan §1.2.2 Thm 1.4 (рекуррента) · статус: черновик
```

```
