# ТЕРМИНЫ (русские) — источник правды по именам и терминам проекта

> **Зачем.** Чтобы НЕ искать одни и те же термины по кругу. Раньше это делали каждую сессию — ошибка.
>
> **Правило (жёстко).**
> 1. Гейт `math-russian-terminology` СНАЧАЛА смотрит сюда (скилл сам ставит проектный глоссарий выше всех источников). Термин есть в таблице — вопрос закрыт, веб не трогаем.
> 2. Веб-поиск — ТОЛЬКО для термина, которого здесь нет. Нашёл — сразу дописал строку сюда (чтобы не искать второй раз).
> 3. Источники, которые ЛЕЖАТ В ПРОЕКТЕ, читаем напрямую, **не гуглим**. В частности **Айгнер–Циглер «Доказательства из Книги» уже есть**: `biblioteka/istochniki/knigi/Aigner, Ziegler — Proofs from THE BOOK (RU).pdf` (глава 30 — формула Кэли: Жуаяль, Питман). Другие переизложения — по `biblioteka/istochniki/MANIFEST.md` и `VYCHITANO.md`.
> 4. **Терминология для этого корпуса — НЕ критична.** Документ внутренний, адресат — владелец-математик. Латиница/оригинал рядом с русским (`промах` / displacement) — норма, не дефект. Область по-русски описана слабо; где канона нет — берём разумную транслитерацию/кальку и НЕ вылизываем. Не тратить на это отдельные проходы — только попутно.
>
> **Статусы:** `канон` — устоялось (рус. Википедия / современные учебники-конспекты); `проект` — наша калька/термин (область по-русски не описана), зафиксировано решением; `транслит` — транслитерация имени без рус-канона, зафиксирована проектом.
