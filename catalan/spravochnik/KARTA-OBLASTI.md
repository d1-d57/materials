### Мир 2 — Кэли / парковки · формат узла — `STANDART-uzla.md`
Спина (круг тем владельца): парковки → размеченные пути → деревья → Кэли → Прюфер → др. доказательства Кэли. Две нити сходятся на `area`.

**Нить A (сторона путей)** — `stati/mir2-nit-A.md`:
`zagadka-parkovka-lesenka` → `bij-put-parkovka` (area=displacement, лёгкий мост) → `hub-pomech-put` (снял метки → Мир 1) → `vyhod-nit-B`.

**Нить B (сторона деревьев)** — `stati/mir2-nit-B.md`:
`zagadka-odno-chislo` → `bij-knuth` (элегантное ядро) / `bij-shin` (доступная сэндпайл-free реализация — школьный маршрут) → `thm-kreweras` → (`bij-burning-pyy` демоут — сэндпайлы) → `most-cikl-lemma` → `vyhod-nit-A`.

**Нить C (доказательства Кэли — задняя половина круга)** — `stati/mir2-nit-C.md`:
`zagadka-skolko-derevev` → `dok-prufer` → `dok-joyal` → `dok-pitman` → `mnogolikost-keli` (свод; мост в Мир 1 через `most-cikl-lemma`).
Бриллианты: `dok-pitman` (двойной счёт + теорвер + рост) и `dok-joyal` (функц. граф ↔ дерево, скрытая геометрия). `dok-prufer` — код (Yan §1.2.1; там же 3-я карта парковка↔дерево). Линейная алгебра / рекурсия — справочный фон.

**Нить D (мосты наружу — бриллианты-обогащения)** — `stati/mir2-nit-D.md` (не сюжет, набор мостов):
`luckycars` (теорвер: ~половина машин счастливы, приёмом Поллака) · `derevya-zigzag` (возр. деревья ↔ зигзаги/числа Эйлера, биекция Пака) · `most-qcatalan-area` (area→q-Каталан = мост половин) · `bij-nc-parkovka` (NC↔неубыв. парковки, резерв).

**Шарнир A↔B = `area`, но ДВА моста разной силы** (не схлопывать): (1) area(путь)=displacement(парковка) — поэлементно, наглядно, школьно (нить A); (2) displacement=inv(дерево) — тождество Кревераса, поэлементно только через φ Кнута (нить B, требует-приручения). Само q-тождество `I_n(q)=P_n(q)` (Yan Thm 1.4) доказано рекуррентой; биекций две — Креверас (рекурсивно), Кнут (прямо).
Ядро находки: (n+1)^{n-1} и у парковок, и у деревьев (Кэли) ⇒ φ Кнута несёт displacement=inv (`Yan §1.2.2`); area — та же каталановская статистика ⇒ Мир 2 цепляется за Мир 1 (снял метки — обычный путь Дика).
Доступный сэндпайл-free маршрут к area↔inv — **Shin (0810.0427)**, вход в тему — **SymCat**; burning (сэндпайлы) демоутнут в фон (реш. №10). Вероятностный бриллиант — `luckycars`; мост половин через area — `most-qcatalan-area`.
