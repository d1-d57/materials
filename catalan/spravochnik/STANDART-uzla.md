## Что писать / чего НЕ писать
- **Писать:** находку (что несущего/удивительного открыли), структурные связи между узлами, нашу оценку школьного уровня, указатель на деталь.
- **НЕ писать:** определения, полные конструкции биекций, разборы примеров, методику «у доски». Всё это восстановимо — держим указатель `источник`, а не текст. Если строку можно убрать и мысль восстановима по указателю — убрать.

## Узел (компактно, ~5–10 строк)
```
id · род (объект | утверждение | биекция | мостик | затравка) · суть (1 строка)
находка: <что несущего/удивительного открыли — 1–3 фразы; связь, не определение>
связи: [id →/↔ однофразное «почему»]     # структурный веб (рёбра графа)
уровень: школьно | требует-приручения | вне-школы
источник: <файл § / стр. — куда смотреть за деталью; переизложение, не первоисточник>
статус: seed | черновик | готово
```

## Правила
- Новый узел → строка в `KARTA-OBLASTI.md` (индекс по роду + по нитям). Иначе сирота.
- `id` стабилен (переименование рвёт рёбра `связи`).
- Компактность — цель, не побочка. База должна помещаться в один взгляд, а не пересказывать источники.

## Ориентация — чтобы не мёртвый груз (главное)
Узлы сами по себе — куча. Сплетают их два слоя:
- **`KARTA-OBLASTI` = карта.** Резолвит КАЖДЫЙ `id` (суть одной строкой) и группирует узлы по роду. Любой `id`, упомянутый в `связях`, обязан находиться в карте — иначе ребро висит.
- **Нить = именованный УПОРЯДОЧЕННЫЙ маршрут по узлам** (сюжет: затравка → … → кульминация → выход). Узлы — бусины; `связи` — локальные рёбра между соседями; **нить** — глобальная сборка бусин в историю. Каждый узел лежит хотя бы на одной нити (иначе он мёртвый груз — либо привязать, либо удалить).

Курс = обход нити по карте. **Хранение (черновое):** файл на нить `stati/<нить>.md` (узлы в порядке сюжета — файл сам читается как нить) + общий `stati/*-obiekty.md` (объекты-ручки, которые делят несколько нитей). Когда нитей станет много — упорядочим/перепишем; формат намеренно черновой и эволюционирует.

```
  и она несёт статистику: area(парковки) = inv(дерева) = тождество Кревераса. Редкая ЧИСТАЯ,
  школьно-пригодная версия (перестановки + обход, без сэндпайла) — ради неё и копали.
связи: [thm-kreweras → её конструктивная реализация;
  bij-burning-pyy ↔ визуальная альтернатива, но с сэндпайлом (уровень «приручить»);

  most-cikl-lemma ↔ Поллак = цикл-лемма считает обе стороны]

```
