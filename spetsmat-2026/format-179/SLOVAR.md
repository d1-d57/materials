# Формат листков школы 179: словарь команд и перевод из нашего формата

Здесь описан формат, в котором коллеги (Н. П. Стрелкова) верстают листки спецмата в Overleaf, чтобы все листки выглядели одинаково. Наш `.tex` (листки 16α, 18α) у них не соберётся: у него своя преамбула и свои команды. Поэтому листок выпускается второй раз — телом в их формате.

## Откуда знание и насколько оно твёрдое

- **Видели (28.09).** Тело листка «17. Плоские графы», уровень А (прислал владелец), и его PDF: `2026/2027. Школа 179. КЛ 25-29`, справа большая «A». По нему восстановлено, что делает каждая команда.
- **Видели (17.09).** Тело листка 17ℵ (`spetsmat-bot/zhurnal/2026-09-02_spetsmat-bot/ISTOCHNIK-17alfa-ploskie-grafy.tex`). Там авторы определили аналоги `\z` и `\zp` для узлов TikZ: `\refstepcounter{z}\setcounter{lett}{0}\fbox{\textbf{\arabic{z}}}`. Отсюда видно устройство: номер задачи — счётчик `z`, буква пункта — счётчик `lett`, который обнуляется в каждой задаче.
- **Не видели.** Сам `macros.tex` из мастер-файла Overleaf. Точных определений у нас нет, только их действие на странице.

## Словарь

| Их команда | Что делает (видно по PDF) | Наш аналог (`18alpha-veroyatnost.tex`) |
|---|---|---|
| `\ListokName{17. Плоские графы}` | Задаёт название листка вместе с номером | `\centerline{\large\textbf{18$\alpha$. \textsc{Вероятность}}}` |
| `\shapkaUstnoA` | Печатает шапку: «2026/2027. Школа 179. КЛ 25-29», справа букву уровня «A», под чертой название из `\ListokName`. В листке ℵ прошлого года — `\shapkaUstno` без буквы | Две строки `\centerline` в начале листка |
| `\zp` | Задача без пунктов: окно для плюса, потом номер в рамке, потом текст | `\zad{n}{маркер}{текст}` |
| `\z` | Задача с пунктами: номер в рамке, текст, окна стоят у пунктов | `\blok{\nomer{n}{маркер}…}` внутри `samepage` |
| `\zn` | Номер, затем окно и «а)» в той же строке: первый пункт начинается сразу, без общего условия | Нет (у нас условие всегда перед пунктами) |
| `\lett` | Пункт с новой строки: окно и следующая буква (а, б, в…) | `\punkt{буква}{маркер}{текст}` |
| `\leth` | Пункт в той же строке: окно и следующая буква | Нет (у нас пункты в строку идут текстом `\textbf{а)}` под одним окном) |
| `\framebox{7}` | Ссылка на задачу 7 — номер в рамке, как у самой задачи | Текстом: «из задачи 9» |
| `\textit{…}` | Термин | `\term{…}` |
| `\textbf{Формула Эйлера.}` + `\medskip` | Выделенный абзац теории | `\tekst{…}` |
| Обычный абзац | Теория между задачами | `\tekst{…}` |
| `\footnote{…}` | Сноска (стандартная LaTeX) | То же |
| `\begin{wrapfigure}…` | Рисунок справа от задачи | В 18α рисунков нет |

**Буквы пунктов ставит стиль, а не автор.** В их файле после `\lett` буква не пишется.

**Одно окно или несколько.** Если у задачи пункты идут в строку под одним окном (у нас 1, 3, 17, 18, 20), в их формате это `\zp` с буквами `\textbf{а)}` в тексте: на задачу приходится одна клетка, как у нас. Если нужны отдельные плюсы за каждый пункт в строку, это `\leth` — но тогда в кондуите поменяется число клеток.

## Чего в их формате нет (или мы не знаем, как оно называется)

- **Маркеры ◦ † ⋆.** В образце 17А их нет. Переводчик ставит знак надстрочным символом сразу за номером: `\zp \unskip$^{\circ}$\ Текст`. `\unskip` снимает пробел, который стиль ставит после номера. Это обычный LaTeX, соберётся с любым стилем.
- **Шапка уровня α.** Для А это `\shapkaUstnoA` (печатает «A»), `\shapkaUstno` — без буквы. Команду для α мы не видели, поэтому переводчик набирает шапку обычным LaTeX по образцу 17А, с буквой α справа (три строки с комментарием). Если у коллег есть своя команда для α, её можно подставить вместо этих строк.
- **Разделитель частей.** Переводчик пишет `\divby` (владелец помнит такую команду в их стиле). В начале файла стоит `\providecommand{\divby}{…}` с линией `\hrulefill`: если команда есть в стиле, возьмётся она, если нет — наша линия.
- **Пакеты.** Неизвестно, подключён ли `amssymb`. Поэтому переводчик заменяет `\geqslant` → `\ge`, `\leqslant` → `\le`, `\varnothing` → `\emptyset`: эти команды есть в базовом LaTeX.

## Инструменты

- `perevod.py НАШ.tex ИХ.tex` — переводит наш листок в их формат. Уровень (α или ℵ) берёт из заголовка нашего листка `\textbf{18$\alpha$. …}` / `\textbf{18$\aleph$. …}` и ставит ту же букву в шапку (с 29.09). Короткие пункты (каждый не длиннее 50 символов) ставит в строку через `\leth`, остальные — с новой строки через `\lett`: клеток столько же, строк меньше. Понимает `\tekst`, `\zad`, блок `samepage` с `\nomer` и `\punkt`, `\zvezdy`. Шапку нашего листка отбрасывает: её делает их стиль.
- `maket-179.tex` — наша имитация их стиля по образцу 17А: 11pt, шрифт cm-super (как у них, pdfTeX), поля сняты с их PDF. Их `macros.tex` она не заменяет, нужна только для проверки, что переведённое тело компилируется и похоже на их вид. Сборка из этой папки:
  `lualatex -jobname=proba '\def\telo{ПУТЬ/К/ИХ.tex}\input{maket-179.tex}'`
- **Обратный перевод (их → наш) не написан.** Словарь обратим почти везде; теряются только `\zn` и `\leth`, у которых у нас нет своей команды.

## Прошлогодний формат — другой

`listok-derevya/overleaf_export.py` (04.09) выпускал листок в формате с `my.sty` и командой `\problem`. Судя по образцу 17А, в этом году формат другой (`\z`, `\zp`, `\lett`). Для новых листков используем этот словарь.

## Для сайта (на будущее)

Если сайт будет отдавать PDF в том виде, в каком листки печатают коллеги, нужен их `macros.tex`: его стоит попросить у Н. П. Стрелковой и положить рядом с этим файлом. Тогда вместо `maket-179.tex` можно будет собирать их PDF у себя.
