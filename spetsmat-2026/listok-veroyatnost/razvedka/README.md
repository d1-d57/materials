## Рамка, под которую отбирали (решение владельца 27.09)

Только классическая вероятность в одной конечной модели, инструмент — подсчёт. Без независимости,
условной и полной вероятности, Байеса, матожидания, бесконечных процессов, геометрической вероятности,
беспорядков/экспоненты, биномиального распределения как темы. Включения-исключения в 8 классе не проходили.
