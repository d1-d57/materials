# Разведка A: материалы `materials/catalan/` под листок «18ℵ. Вероятность»

Участок: `/mnt/user-data/uploads/GitHub/materials/catalan/`. Все адреса ниже — относительно него, номера строк реальные (по `cat -n` файла). Читал только локальные файлы.

Условные обозначения.
- «дословно» — цитата из файла; «пересказ» — близко к тексту.
- **[мой вывод]** / **[проверено мной]** — не из материалов: я выписал следствие или сверил перебором (скрипты `chk.py`, `chk2.py` рядом с этим отчётом). Что именно проверено — в тексте.
- Роль: вход / звено / БТ (большая теорема) / вбок.
- Рамка: «В РАМКЕ» / «ЗА РАМКОЙ: …».
- Сложность: лёгкая / средняя / трудная / ⋆.

Общая оговорка про вероятностность. Почти всё в материалах — счёт путей ±1 (комбинаторика); вероятностное слово стоит только в заголовках и в «Утв.12–13» скелета. Перевод в рамку 18α везде одинаков: n бросков монеты = 2^n равновероятных последовательностей ±1 (Ω, p(ω)=2^{-n}); событие «путь не заходит ниже 0» = подмножество Ω; вероятность = (число путей)/2^n. Слова «независимо», «почти наверное», «когда-нибудь вернётся» — за рамкой, но почти всегда обходятся конечной формулировкой «за N бросков».

## 1. Кандидаты в задачи

### Группа I. Входы и метод (отражение → баллотировка → Каталан)

**A1. Задача о голосовании, слабая версия (вход).**
- Формулировка, дословно (`kurs/mir1-skelet.md:132`): «На выборах кандидат $A$ набрал $p$ голосов, кандидат $B$ — $q\le p$ голосов; бюллетени вскрывают по одному в случайном порядке. Сколькими способами это можно сделать так, чтобы на **каждом** промежуточном подсчёте число голосов за $A$ было не меньше числа голосов за $B$ (т.е. $A$ ни разу не оказался позади, хотя ничьи допускаются)?»
- Вероятностная версия, дословно из канона рамки курса (`kurs/anons.md:17`): «с какой вероятностью победитель всё время лидирует, ни разу не уступив?»
- Адрес: `kurs/mir1-skelet.md:128-133` (несбалансированный путь + постановка); `spravochnik/stati/mir1-nit-2.md:79-85` (`zatravka-ballot`).
- Ответ (счёт): $\binom{p+q}{p}-\binom{p+q}{p+1}$ (`mir1-skelet.md:136-145`, Утв.8). Вероятность **[мой вывод, проверено мной перебором p≤6]**: $\dfrac{p-q+1}{p+1}$. Частный случай p=q=n: $1/(n+1)$.
- Идея: путь ±1 от оси; «плохие» пути отражаются. Решение — A3.
- Роль: вход. Источник наполовину вероятностный («в случайном порядке» + слово «вероятность» в анонсе). Перевод: «p орлов и q решек выпали в случайном порядке (равновероятны все $\binom{p+q}{p}$ порядков); с какой вероятностью орлов было не меньше, чем решек, после каждого броска».
- Рамка: В РАМКЕ. Сложность: лёгкая (постановка), средняя (ответ).

**A2. Формула Бертрана, строгая версия.**
- Формулировка, дословно (`mir1-skelet.md:153-154`): «кандидат $A$ набрал $a$ голосов, $B$ — $b<a$, и спрашивается, в скольких случаях $A$ **строго** опережает $B$ на протяжении всего подсчёта (без ничьих вовсе, включая начало)».
- Адрес: `mir1-skelet.md:151-158`; вывод цикл-леммой — `kurs/L6-cikl-lemma-konspekt.md:90-101`, `kurs/L7-konspekt/konspekt.md:37-47`.
- Ответ: $\frac{a-b}{a+b}\binom{a+b}{a}$; вероятность $\frac{a-b}{a+b}$ (`L6-cikl-lemma-konspekt.md:101`, `L7-konspekt/konspekt.md:43`). **[проверено мной, a+b≤12]**.
- Идея (отражение): первый шаг обязан быть +1, дальше путь ≥0 длины a+b−1 (`mir1-skelet.md:158`). Идея (цикл-лемма): из a+b поворотов ровно a−b хороших (A7).
- Роль: звено / кандидат в БТ. Материалы подают её как две разные идеи для одного ответа (`mir1-skelet.md:160`: «один приём в двух костюмах»).
- Оговорка про выбор версии: слабая vs строгая — `L6-cikl-lemma-konspekt.md:105`, `1-START-HERE/resheniya.md:62` (№15: «Баллотировка — слабая версия (путь ≥0), строгий Бертран замечанием»).
- Рамка: В РАМКЕ. Сложность: средняя.

**A3. Принцип отражения (André) как задача.**
- Формулировка, дословно (`mir1-skelet.md:136-138`): «Пусть $p\ge q\ge0$. Число путей длины $p+q$ из шагов $\pm1$ ($p$ шагов $+1$, $q$ шагов $-1$), остающихся неотрицательными на всём протяжении (не опускающихся ниже оси), равно $\binom{p+q}{p}-\binom{p+q}{p+1}$.»
- Адрес: доказательство `mir1-skelet.md:139-145`; полный разбор n=3 (таблица 15↔15) `spravochnik/_seed-kb.md:101-256` (пример `:191-227`); нить `mir1-nit-2.md:97-103` (`bij-otrazhenie`).
- Идея: первое касание прямой y=x+1, отразить хвост; конечная точка $(q-1,p+1)$ не зависит от момента касания.
- Роль: звено (инструмент). Источник чисто комбинаторный. Перевод: «вероятность, что после каждого из n бросков орлов не меньше, чем решек, и всего орлов k».
- Рамка: В РАМКЕ. Сложность: средняя (идея отражения) / трудная (доказать биекцию строго).

**A4. Каталан как ответ на голоса при равенстве (следствие).**
- Формулировка: пересказ. «Оба кандидата набрали по n голосов. Сколькими способами / с какой вероятностью первый ни разу не отстал?»
- Адрес: `mir1-skelet.md:147-150` (Следствие); `_seed-kb.md:22-100` (обзор четырёх доказательств формулы).
- Ответ: $C_n=\frac1{n+1}\binom{2n}{n}$; вероятность $1/(n+1)$ **[мой вывод из A1]**.
- Роль: звено (вход в Каталан). Источник комбинаторный. Перевод: «2n бросков, ровно n орлов; вероятность, что орлов ни разу не было меньше решек, равна $1/(n+1)$».
- Рамка: В РАМКЕ. Сложность: средняя.

**A5. Циклическая лемма (лемма Рени / Дворецкий–Моцкин).**
- Формулировка, дословно (`mir1-skelet.md:178`): «Пусть дана последовательность из $m$ символов $X$ и $k$ символов $Y$, $m>k$. Тогда среди $m+k$ её циклических сдвигов ровно $m-k$ доминирующих.» Доминирующая (`:176`): в каждом непустом префиксе X строго больше, чем Y.
- Адрес: `mir1-skelet.md:172-181`; `L6-cikl-lemma-konspekt.md:33-53` (доска, «старт сразу после последнего минимума» `:53`); `_seed-kb.md:388-410`. Строгое доказательство для суммы −1 (через первый минимум и единственность) — `kurs/mir1-skelet-vetvyashchiesya.md:38-50` (Утв.3). Замечание: доказательство в `mir1-skelet.md:180` («XY-уничтожение», confluence — ссылкой) слабее; строгое лежит именно в скелете «ветвящегося».
- Ключевая идея: расставить по кругу; сдвиг доминирует ⇔ старт сразу после позиции минимума частичных сумм.
- Роль: звено / кандидат в БТ (в материалах — «стержень курса»: `mir1-skelet.md:194-203`, `mir1-nit-3.md:23-30`).
- Источник комбинаторный. Перевод: «последовательность из 2n+1 бросков, n+1 орлов; с какой вероятностью она доминирующая» — все $\binom{2n+1}{n}$ равновероятны. Ответ 1/(2n+1) **[мой вывод]**.
- Рамка: В РАМКЕ. Сложность: средняя (применение) / трудная (доказать лемму).

**A6. Каталан через цикл-лемму: $(2n+1)C_n=\binom{2n+1}{n}$.**
- Формулировка: `mir1-skelet.md:184`: «$(2n+1)\,C_n=\binom{2n+1}{n}$, то есть $C_n=\dfrac1{2n+1}\dbinom{2n+1}{n}$».
- Адрес: `mir1-skelet.md:182-190`; `L6-cikl-lemma-konspekt.md:55-86` (мини-пример n=2 для доски `:77-86`); `L6-konspekt/konspekt.md:12-25`; `mir1-nit-3.md:14-20`.
- Идея: у каждой последовательности из n+1 X и n Y ровно один доминирующий сдвиг; стереть ведущий X → путь Дика; каждый путь Дика получается ровно из 2n+1 последовательностей.
- Роль: звено. Источник комбинаторный. Перевод — как A5.
- Рамка: В РАМКЕ. Сложность: средняя.

**A7. Баллотное число из цикл-леммы (общий случай).**
- Формулировка (`L6-cikl-lemma-konspekt.md:96-97`, дословно): «Число путей из $p$ шагов $+1$ и $q$ шагов $-1$ ($p>q$), у которых **все** частичные суммы строго положительны, равно $\frac{p-q}{p+q}\binom{p+q}{p}$.»
- Адрес: `L6-cikl-lemma-konspekt.md:90-105`; `L7-konspekt/konspekt.md:37-47`; `L6-konspekt/glubzhe.md:49`.
- Идея: из p+q поворотов ровно p−q хороших, каждый хороший путь встречается в круге p+q раз («вывод в одну реплику» `:99`).
- Роль: звено (то же, что A2, другим методом). Источник комбинаторный/вероятностный (то же, что A2).
- Рамка: В РАМКЕ. Сложность: средняя.

### Группа II. Возвращение и невозвращение (кандидаты в БТ)

**A8. Первое возвращение в 0 ровно на шаге 2n.**
- Формулировка, дословно (`mir1-skelet.md:219`): «Пусть $f_{2n}=\Pr[S_1\ne0,\dots,S_{2n-1}\ne0,\,S_{2n}=0]$ — вероятность того, что *первое* возвращение в $0$ происходит ровно на шаге $2n$.»
- Адрес: `mir1-skelet.md:213-224` (Утв.12; Опр.8 симметричного блуждания `:217-218`); нить `mir1-nit-4.md:53-67`; `kurs/mir1-rasskaz.md:63-67`; идея `2-idei/catalan-dyck-ideas.md:32`.
- Ответ: $f_{2n}=2C_{n-1}/2^{2n}$ (`:221`). **[проверено мной, n≤7]**.
- Идея: убрать первый и последний шаг, опустить на 1 → путь Дика длины 2n−2, плюс выбор знака; это то же «разложение по первому возврату», что рекуррента Сегнера.
- Роль: звено (мост «Каталан ↔ блуждание»). Источник вероятностный по форме. Замечание: во второй половине Утв.12 («подчиняется рекурренте Сегнера»: $u_{2n}=\sum f_{2k}u_{2n-2k}$) сформулировано неаккуратно: это рекуррента возобновления, не Сегнера. Брать первую половину.
- Рамка: В РАМКЕ (без слова «независимо»: 2^{2n} равновероятных путей). Сложность: лёгкая/средняя.

**A9a. Лемма: число неотрицательных путей длины m.**
- Формулировка (`mir1-skelet.md:231`): «Число путей длины $m$ (шаги $\pm1$, старт в $0$), остающихся $\ge0$ на всём протяжении (Дик-подобных, но не обязанных вернуться в $0$), равно $\binom{m}{\lfloor m/2\rfloor}$.»
- Адрес: `mir1-skelet.md:231-235`.
- Идея: суммировать по конечной высоте формулу отражения $\binom mu-\binom m{u+1}$; сумма телескопируется.
- Роль: звено. Перевод: «вероятность, что блуждание за m шагов ни разу не ушло ниже 0, равна $\binom m{\lfloor m/2\rfloor}/2^m$».
- Рамка: В РАМКЕ. Сложность: средняя.

**A9. «Не вернуться за 2n шагов» ⇔ «быть в 0 на шаге 2n» (Утв.13; кандидат в БТ).**
- Формулировка, дословно (`mir1-skelet.md:227`): $\Pr[S_1\ne0,\dots,S_{2n}\ne0]=\dfrac{\binom{2n}{n}}{2^{2n}}=u_{2n}$, где $u_{2n}=\Pr[S_{2n}=0]$.
- Адрес: `mir1-skelet.md:225-244`; нить `mir1-nit-4.md:69-76` (`nevozvrat-formula`, «КУЛЬМИНАЦИЯ»); `kurs/mir1-rasskaz.md:63-71`.
- Ответ: число путей без возвращений $=2\binom{2n-1}{n-1}=\binom{2n}{n}$. **[проверено мной, n≤7]**.
- Идея: после первого шага путь остаётся по одну сторону оси → путь ≥0 длины 2n−1 → A9a (Шаг 2, `:236-240`) → $2\binom{2n-1}{n-1}=\binom{2n}n$. Бескоординатная версия — A10.
- Роль: БТ. Источник вероятностный по форме. Честная пометка материалов (`:229`): «в источниках дословно не найден, собираем сами». Формулировка про $u_{2n}$ — это ровно кандидат владельца «лемма ⇔».
- Рамка: В РАМКЕ для конечного n. Хвост про $1/\sqrt{\pi n}$, «убывает к нулю → почти наверное вернётся» (`:241-242`): ЗА РАМКОЙ (пределы, Стирлинг, бесконечный процесс) — в самом материале «в курс не входит».
- Сложность: средняя (по цепочке A3→A9a→A9), трудная (без готового отражения).

**A10. Теорема Феллера: неотрицательные пути = пути, вернувшиеся в 0, и биекция владельца (⋆).**
- Формулировка, дословно (`kurs/L6-cikl-lemma-konspekt.md:113-114`): «Число путей длины `2n` шагами `±1`, которые **всё время ≥ 0** (не заходят в минус; конец — на любой высоте), равно числу путей длины `2n`, которые **кончаются в 0**. Оба равны `C(2n,n)`. В вероятностях: `P(S₁≥0, …, S₂ₙ≥0) = P(S₂ₙ=0) = C(2n,n)/2^{2n}`.»
- Адрес: `L6-cikl-lemma-konspekt.md:109-131` (доказательство отражением + телескоп `:118-125`); биекция «разрежь в минимуме» — `kurs/L6-konspekt/konspekt.md:54-58`, `kurs/L6-narayana-cikllemma-konspekt.md:71-78`; семейство из шести биекций и выбор «класса» — `spravochnik/stati/mir1-nit-mosty-nonneg.md` (весь файл; `bij-razrez-min` `:28`, «конструкция владельца»; «выбирается не конструкция, а класс» `:23`; открытый долг про подачу `:50-54`).
- Ключевая идея биекции (два описания в материалах): (а) режем в первом минимуме на A (до) и B (после), новый путь = B, затем A, повёрнутая на 180° (`L6-konspekt/konspekt.md:56`); (б) режем в последней точке минимума −k, первый кусок проходим задом наперёд, второй приставляем, подняв на k (`mir1-nit-mosty-nonneg.md:28`). **[проверено мной: оба описания — биекции «мосты → неотрицательные», n≤7]**.
- Связка с A9: неотрицательных путей длины 2n столько же, сколько путей длины 2n без возвращений (обе $\binom{2n}{n}$); в материалах это две отдельные теоремы. Предлагаемая для листка «лемма ⇔» = A9 + A10.
- Роль: БТ / звено. Источник вероятностный только в скобках («В вероятностях…»). Перевод: «у 2n бросков нет ни одного момента, когда решек было больше, чем орлов; вероятность такого события равна вероятности того, что орлов и решек поровну» — В РАМКЕ.
- Внимание — внутреннее противоречие материалов: `L6-cikl-lemma-konspekt.md:127-131` (пишет, что единой биекции для этой пары «не получилось») против `L6-narayana-cikllemma-konspekt.md:78` («в прошлом ответе я зря сказал, что чистой биекции нет — твоя работает и красива») и `mir1-nit-mosty-nonneg.md` (шесть биекций). Верно последнее.
- Рамка: В РАМКЕ. Сложность: средняя (счёт) / трудная ⋆ (построить биекцию самим).

**A11. Пара путей длины n с общим концом ↔ мост длины 2n (вход через Вандермонда).**
- Формулировка: пересказ (`mir1-nit-mosty-nonneg.md:9-12,27`): «Вход через Вандермонда: $\sum_k\binom nk^2=\binom{2n}n$ — это пары траекторий длины n с общим концом, и они же мосты». Ручка `bij-razryv` `:27`.
- Ответ: $\binom{2n}{n}$. Идея: чередование шагов $(p_1,-q_1,p_2,-q_2,\dots)$; разворот времени не требуется.
- Роль: вход/звено к A8–A10. Перевод (мой): «двое бросают монету по n раз; с какой вероятностью число орлов у них одинаково?» Ответ $\binom{2n}{n}/4^n=u_{2n}$ **[мой вывод]**.
- Рамка: В РАМКЕ. Сложность: средняя.

**A12. Теорема Чжуна–Феллера: время над осью равнораспределено среди петель (⋆, «большая теорема»).**
- Формулировка, дословно (`mir1-skelet.md:247`): «Среди всех $\binom{2n}{n}$ путей длины $2n$ из шагов $\pm1$, оканчивающихся в $0$ («большие пути Дика», без ограничения на знак), число путей, ровно $2k$ шагов которых проведены выше оси, **не зависит от $k$** и равно $C_n$, для каждого $k=0,1,\dots,n$.» Короче (`L7-konspekt/konspekt.md:51`): $\binom{2n}{n}=(n+1)C_n$.
- Адрес: `mir1-skelet.md:245-256`; явная биекция «хирургия» — `kurs/razbor-cf-narayana/razbor.md:31-54` (шаги `:35-42`: $[A]X[B]\to[B]X[A]$, снимает ровно 2 шага над осью); `L7-konspekt/konspekt.md:49-67`; `spravochnik/_seed-kb.md:54-60,541-694` (exceedance, таблица n=3 `:644-670`); нить `mir1-nit-4.md:78-85`.
- Ответ: по $C_n$ на каждое $2k$. **[проверено мной, n≤8]**. Идея: найти первый подъём с оси, идти до первого возврата на ось, поменять местами «до» и «после» (обратимо).
- Роль: БТ. Источник комбинаторный. Перевод: «из всех $\binom{2n}{n}$ блужданий, вернувшихся в 0 на шаге 2n, наугад выбирают одно (равномерное распределение на конечном множестве); число шагов над осью принимает каждое значение 0,2,…,2n с одинаковой вероятностью 1/(n+1)». Вероятности здесь только равномерные на конечном множестве: В РАМКЕ. Условная вероятность не нужна: Ω = мосты.
- Сложность: трудная ⋆ (биекция); формулировка лёгкая. Есть предупреждение из `L6-cikl-lemma-konspekt.md:133-135`: это НЕ «неотрицательный=возвращение» (A10), термины не смешивать (и в `L6-cikl-lemma-konspekt.md:11-19` автор извиняется за путаницу).

**A13. Закон арксинуса (только в виде упоминания).**
- Что в материалах: только упоминание «вне школы». `L7-konspekt/konspekt.md:60-67` (плотность «ванна», «Сам арксинус без интегралов не берём — но как «вот куда это ведёт» это сильнейший финал»), `mir1-skelet.md:254`, `mir1-nit-4.md:78-85` («Тень арксинуса, но сам арксинус НЕ берём (anti-scope)»), `2-idei/catalan-dyck-ideas.md:34`. Формулы дискретного закона и его доказательства в материалах нет.
- **[Мой вывод, проверено мной перебором n≤8]** дискретный закон (без предела): для блуждания из 2n шагов вероятности «ровно 2k шагов над осью» и «последний нуль на шаге 2k» равны $u_{2k}u_{2n-2k}$, где $u_{2j}=\binom{2j}{j}/4^j$. Доказательство из материалов не выводится напрямую; естественный путь — разложение по последнему нулю + A9 + A12, но я его строго не оформлял.
- Роль: БТ-кандидат (у владельца: «арксинус — вне», см. п.3). Рамка: дискретная формула В РАМКЕ; предел, плотность, интегралы — ЗА РАМКОЙ (пределы). Сложность: ⋆.

### Группа III. Вероятностные жемчужины с цикл-леммой

**A14. Эпидемия 0/2: вероятность затухнуть, заразив ровно N человек (жемчужина).**
- Формулировка, дословно (`spravochnik/stati/mir1-nahodki.md:352-354`): «Каждый заражённый заражает 0 или 2 других (по монетке). Эпидемия из одного нулевого пациента. С какой вероятностью она затухнет, заразив ровно N человек?»
- Адрес: `mir1-nahodki.md:351-356` (набросок жемчужины-задачи), `:296-323` (узел `gem-vetvyashchiesya-cikllemma`); `kurs/L7-konspekt/konspekt.md:69-90`; `kurs/mir1-rasskaz-vetvyashchiesya.md:60-68`; `kurs/mir1-skelet-vetvyashchiesya.md:84` (Следствие 6, бинарное).
- Ответ (`mir1-nahodki.md:355`): N нечётно, $N=2m+1$, $P=C_m/2^{2m+1}$. **[проверено мной: число цепочек из N бросков ±1, впервые попавших в −1 ровно на шаге N, равно $C_m$, m≤6]**.
- Идея: обход дерева в глубину (внутренняя вершина +1, лист −1) переводит дерево заражений в блуждание, которое впервые попадает в −1 на шаге N; счёт — цикл-лемма (A5) для суммы −1.
- Роль: БТ / вбок (hitting-time theorem в простейшем случае: $P=\frac1N P(S_N=-1)$, тот же множитель 1/N, что в A6, A7). Источник вероятностный.
- Рамка: ЗА РАМКОЙ в эпидемической подаче: вероятностное правило умножения по дереву, независимость потомства. Но эквивалентная формулировка В РАМКЕ: «N бросков; с какой вероятностью блуждание впервые окажется в −1 ровно на N-м шаге»; ответ $\frac1N\binom{N}{m}/2^N$ (при N=2m+1) = $C_m/2^N$. Эту формулировку и надо брать, эпидемию — как мотивацию.
- Сложность: средняя (после A5), трудная ⋆ (самостоятельно).

**A15. Формула Оттера–Дуасса (общий закон потомства; за рамкой).**

- Роль: вбок. Рамка: ЗА РАМКОЙ (независимые одинаково распределённые шаги с произвольным законом; ветвящийся процесс; код Лукасевича). Сложность: ⋆. Для листка — только как «откуда 1/N».

**A16. Вымирание рода: $q=f(q)$.**
- Адрес: `mir1-skelet-vetvyashchiesya.md:91-99` (Утв.7–8), `mir1-rasskaz-vetvyashchiesya.md:15-29`.
- Роль: вбок. Рамка: ЗА РАМКОЙ (условная вероятность/независимость, ряды, бесконечный процесс, производящие функции). Сложность: ⋆. В листок не годится; упомянута для полноты.

**A17. Разорение игрока (только формулировка-мост).**
