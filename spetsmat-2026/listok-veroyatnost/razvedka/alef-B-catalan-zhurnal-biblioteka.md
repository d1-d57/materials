## 1. Кандидаты в задачи

### Группа I. Отражение и баллотировка (Мерзон)

**B1. Лемма об отражении.**
- Формулировка (дословно, Мерзон, Лемма 1): «Количество путей из точки (0, 0) в точку (n, n), поднимающихся выше диагонали y = x, равно количеству всех путей из точки (0, 0) в точку (n−1, n+1).»
- Адрес: `CAT/biblioteka/istochniki/stati-obzory/Merzon — Диаграммы Юнга, пути на решётке и метод отражений.pdf`, журн. стр. 114 = PDF 3 (доказательство и картинка там же).
- Ответ и идея: биекция. Всякий плохой путь пересекает прямую y = x+1; берём ПЕРВУЮ точку пересечения и отражаем весь оставшийся путь относительно этой прямой. Обратное отображение строится так же. Следствие в тексте: C_n = C(2n,n) − C(2n,n+1) = (1/(n+1))·C(2n,n). Там же оговорка: «доказательство объясняет только первую (разностную) из формул; для второй нужны другие методы» (стр. 114, PDF 3).
- Роль: звено (главный инструмент цепочки: отражение).
- Формулировка комбинаторная (пути на решётке вправо/вверх). Перевод: ход вправо = «решка», вверх = «орёл»; «Какова вероятность, что при 2n бросках с ровно n орлами и n решками орлов в какой-то момент станет больше, чем решек?» Ответ через лемму: C(2n,n+1)/C(2n,n) = n/(n+1). ✔ (следует из формулы).
- Рамка: В РАМКЕ. Модель = все C(2n,n) последовательностей с n орлами и n решками равновероятны (описание эксперимента); условная вероятность не нужна.
- Сложность: средняя (само отражение лёгкое, придумать «по первой точке» — средняя).

**B2. Число «хороших» путей в точку (a, b) и слабая баллотировка.**
- Формулировка (Мерзон, 1.3, формула (1); близко к тексту): число путей Дика из (0,0) в (a,b), a > b, равно C(a+b,a) − C(a+b,a+1) = ((a−b+1)/(a+1))·C(a+b,a); в тексте — «Действительно… (проверьте!)».
- Адрес: тот же PDF, журн. стр. 114–115 = PDF 3–4.
- Ответ и идея: отражаем плохие пути относительно y = x+1; они соответствуют всем путям из (0,0) в (b−1, a+1).
- Роль: звено (ступень между B1 и баллотировкой Бертрана B3).
- Перевод: «За A отдано a голосов, за B — b < a. Бюллетени вынимают по одному в случайном порядке. Какова вероятность, что A ни разу не отставал (в любой момент ≥ B)?» Ответ (a−b+1)/(a+1). ✔ перебор для (3,1)→3/4, (4,2)→3/5, (5,3)→1/2.
- Рамка: В РАМКЕ.
- Сложность: средняя.
- Ремарка: в источнике «слабая» версия (не заходить выше диагонали = ничьи разрешены). Бертрановская «строгая» — B3. Различие «слабая/строгая» само по себе конфликт-магнит; в записи проекта об этом отдельно: `CAT/zhurnal/2026-07-05_mir1/SESSIYA.md:130` («для HTML вести СЛАБУЮ баллотировку, строгую Бертрана — замечанием»).

**B3. Теорема Бертрана о выборах (в источнике сразу вероятностная).**
- Формулировка (дословно, Мерзон, Упр. 15а): «Докажите, что вероятность того, что на выборах с участием двух кандидатов, в которых первый набрал a голосов, а второй набрал b < a, первый будет опережать второго в течение всего времени подсчёта голосов равна (a−b)/(a+b).»
- Адрес: тот же PDF, журн. стр. 139 = PDF 28 (§8, «Дополнительные упражнения»).
- Ответ (в условии): (a−b)/(a+b). ✔ перебор для (3,1)→1/2, (5,3)→1/4, (6,2)→1/2.
- Идея решения (мои выкладки, не в источнике): первый бюллетень обязан быть за первого (доля a/(a+b)); дальше — слабая баллотировка из (1,0) = B2 с отражением; либо циклическая лемма (B8–B10) даёт ответ одной строкой.
- Роль: большая теорема (ядро баллотировки) либо звено к ней.
- Вероятностная в источнике; модель — равновероятный порядок бюллетеней. В цепочке школьников «а больше b» надо явно сказать, что «опережать» = строго впереди после каждого бюллетеня.
- Частный случай владельца: 7 шагов вверх и 3 вниз, путь не возвращается на ось (`CAT/zhurnal/2026-07-05_mir1/zamechaniya-issledovanie-idei.md:5` и `SESSIYA.md:84`) — это строгая баллотировка a=7, b=3: (7−3)/(7+3)·C(10,3) = 48 путей из 120, вероятность 2/5. ✔ перебор.
- Рамка: В РАМКЕ (условной вероятности нет; «вероятность» = доля последовательностей).
- Сложность: средняя (⋆ если требовать оба доказательства, отражение и цикл).

**B4. Многокандидатная баллотировка (Зильбергер).**
- Формулировка (дословно, Мерзон, Упр. 15б): «Докажите обобщение для случая, когда кандидатов k и они набрали a₁ > a₂ > … > a_k голосов соответственно.»
- Адрес: тот же PDF, журн. стр. 139 = PDF 28; инструмент — теорема 1 (журн. стр. 118 = PDF 7): знакопеременная сумма по S_k, разбиение неправильных перемещений на пары обменом хвостов после первой встречи; ссылка [18] Zeilberger, Discrete Math 44 (1983) — только библиографическая, текста Зильбергера в участке нет.
- Ответ: В МАТЕРИАЛАХ ОТСУТСТВУЕТ (в условии не сформулирован). Не проверял, поэтому формулу не привожу.
- Роль: вбок (обобщение, для ⋆-задачи).
- Рамка: В РАМКЕ по формулировке, но требует определителей/знакопеременной суммы по перестановкам (в Мерзоне это определения 3–5, стр. 118–120) → для 9 класса это тонкий лёд, скорее ⋆ на потом.
- Сложность: ⋆.

**B5. Пути Дика ↔ таблицы 2×n (порядок подсчёта голосов как таблица).**
- Формулировка (Мерзон, Упр. 1, дословно): «Установите биекцию между путями Дика и «стандартными таблицами» 2 × n, т. е. таблицами 2 × n, заполненными натуральными числами от 1 до 2n так, что числа в каждой строке и в каждом столбце возрастают.» Лемма 2 (стр. 115): то же для путей в (a,b) и таблиц из двух строк длин a и b (k-й ход по горизонтали → число k в первую строку, иначе во вторую).
- Адрес: тот же PDF, журн. стр. 113 (PDF 2, упр. 1) и 115 (PDF 4, лемма 2).
- Ответ/идея: номера ходов, сделанных за первого и за второго кандидата, записываем в две строки.
- Роль: вбок (другой язык для C_n; мост к диаграммам Юнга).
- Комбинаторная; в вероятностный вопрос переводится только через B2.
- Рамка: В РАМКЕ. Сложность: лёгкая.

**B6. Пути в полосе 0 ≤ y ≤ d: конечное блуждание, разорение, Фибоначчи.**
- Формулировка (дословно, Мерзон, Упр. 18): «Рассмотрим пути в полосе 0 ≤ y ≤ d, состоящие из сдвигов либо на вектор (1,1), либо на вектор (1,−1). Докажите, что число путей из точки (0,i) в точку (n,j), где 0 ≤ i,j ≤ d, n+j−i чётно, имеет вид Σ_{k ≡ (n+j−i)/2} C(n,k) − Σ_{k ≡ (n−i−j−2)/2} C(n,k) (формула (12)), где сравнения берутся по модулю d+2.» Комментарий (там же): при d = 0 путей нет, при d = 1 путь один, «при d = 2 получаются степени двойки, а при d = 3 получаются числа Фибоначчи»; при d = 1 три суммы Σ_{k≡i (mod 3)} C(n,k) попарно отличаются не более чем на 1 и равны 2ⁿ/3 с округлением.
- Адрес: тот же PDF, журн. стр. 139–140 = PDF 28–29.
- Ответ: формула (12). Идея: отражения относительно обеих стенок (y = −1 и y = d+1), зеркальные изображения дают период 2(d+2) → сравнения по модулю d+2 (в источнике доказательство ОСТАВЛЕНО читателю).
- ✔ перебор: формула (12) верна для d = 1…5, n ≤ 13, всех допустимых i,j. Какие именно «Фибоначчи» при d = 3 (в источнике не указано): замкнутые пути 0→0 длины 2m: 1, 2, 5, 13, 34, 89 (каждое второе число Фибоначчи); пути 0→1 длины 2m+1 — те же 1, 2, 5, 13, 34…; пути 0→3 длины 2m+1: 0, 1, 3, 8, 21, 55, 144. При d = 2: 1, 2, 4, 8, 16 (0→0 длины 2m). ✔
- Роль: вбок → большая теорема (ядро «блуждание на отрезке за конечное время»; двойное отражение).
- Перевод: «Игрок с i монетами против соперника с d−i монетами; в каждой партии ±1 монета. Какова вероятность, что через n партий ни один не разорился и у первого j монет?» Ответ = (12)/2ⁿ.
- Рамка: В РАМКЕ (конечное n; «никогда не разориться» = бесконечный процесс — ЗА РАМКОЙ и в задаче не участвует).
- Сложность: трудная/⋆ (формула (12) — двойное отражение с чередованием). Лёгкая часть: d = 2 (степени двойки) и d = 3 (Фибоначчи) руками по рекурренте — средняя.

**B7. Ловушка про перемножение вероятностей (не задача, а предупреждение).**

- Роль: вбок. Возможная «задача с подвохом», проверяющая, что школьники не пользуются несуществующим правилом умножения. Ответа-задачи в источнике нет (только комментарий).
- Рамка: ЗА РАМКОЙ: независимость и вероятностное правило умножения (не введены). Использовать только как пример «почему нельзя».
- Сложность: — (не задача).

### Группа II. Цикл-лемма и Чжун — Феллер (Dershowitz–Zaks, Huq)

**B8. Циклическая лемма Дворецкого — Моцкина (формулировка).**
- Формулировка (дословно, Dershowitz–Zaks, «Cycle Lemma»): «For any sequence P₁P₂…P_{m+n} of m boxes and n circles, m ≥ kn, there exist exactly m − kn (out of m+n) cyclic permutations P_iP_{i+1}…P_{m+n}P₁…P_{i−1}, 1 ≤ i ≤ m+n, that are k-dominating.» Определение: последовательность k-доминирующая, если в каждом её начале число «коробочек» больше, чем k·(число «кружочков»). Частный случай (там же): «if m = n+1, then there is a unique dominating permutation».
- Адрес: `CAT/biblioteka/istochniki/stati-obzory/Dershowitz, Zaks — The Cycle Lemma and some applications (1990).pdf`, PDF 1 (журн. 35). Эквивалентная форма для целых шагов — Huq, PDF 14 (стр. 6 диссертации): «For any n-tuple of integers from {1,0,−1,−2,…} with sum k > 0 there are exactly k values of i for which the cyclic permutation has every partial sum positive. The special case in which each aᵢ is either 1 or −1 gives the solution to the ballot problem.»
- Ответ/идея: два доказательства в источнике — B11.
- Роль: звено (альтернатива отражению; единый счёт баллотировки).
- Перевод в вероятность (мои выкладки; ✔ перебор для m,n = (4,3),(5,2),(3,2),(7,3)): пусть k=1, m шагов вверх и n вниз, все C(m+n,n) расстановок равновероятны. Тогда P(все частичные суммы строго > 0) = (m−n)/(m+n). Вывод двойным подсчётом пар (расстановка, сдвиг): сдвиг — биекция на множестве расстановок, значит число пар «сдвиг i делает расстановку доминирующей» = (m+n)·(число доминирующих расстановок) = (число расстановок)·(m−n). Никакой условной вероятности. Это и есть теорема Бертрана B3.
- Рамка: В РАМКЕ (лемма — чистая комбинаторика; вероятность — доля от равновероятных расстановок).
- Сложность: средняя (формулировка) / трудная (придумать доказательство самим).

**B9. Число Каталана и вероятность 1/(2n+1).**
- Формулировка (DZ §2.1 при s = 1, t = 2; близко к тексту): число бинарных деревьев с n внутренними вершинами равно (1/(2n+1))·C(2n+1,n) = (1/(n+1))·C(2n,n). Общий случай s деревьев с n внутренними вершинами степени t: (s/(tn+s))·C(tn+s,n).
- Адрес: тот же PDF, PDF 3 (журн. 37, §2.1). Вывод: правильная скобочная запись (постфиксная) при обходе в постпорядке ↔ (t−1)-доминирующая последовательность; цикл-лемма даёт долю s/(tn+s).
- Идея (частный случай, мои выкладки, ✔ перебор n ≤ 6): последовательность из 2n+1 шагов с n+1 шагом вверх и n вниз строго положительна ровно при одном из 2n+1 сдвигов → «случайное блуждание из 2n+1 шагов с n+1 вверх и n вниз строго положительно в каждый момент с вероятностью ровно 1/(2n+1)», отсюда C_n = C(2n+1,n)/(2n+1). Отсюда же «первое достижение −1 ровно на шаге 2n+1» = C_n (см. B17).
- Роль: звено/большая теорема (вывод C_n без отражения).
- Рамка: В РАМКЕ для варианта «блуждание из 2n+1 шага» (модель = равновероятные расстановки); деревья/леса — не нужны.
- Сложность: средняя.

**B10. Баллотировка через циклическую лемму (как вероятность).**
- Этот кандидат — то же, что B8 (перевод) + B3, оформленный как отдельная задача: «Докажите, что P(A строго впереди всё время) = (a−b)/(a+b) одним рассуждением про сдвиги, без отражения».
- Адрес: DZ PDF 1–2 (лемма и оба доказательства), Huq PDF 14 (удостоверение «±1 = ballot problem»), Krattenthaler по `CAT/biblioteka/istochniki/VYCHITANO.md:248–252` (в участке только дайджест, PDF нет).
- Роль: звено/большая теорема. Рамка: В РАМКЕ. Сложность: трудная (идея сдвига).

**B11. Доказательство циклической леммы (два в источнике, оба короткие).**
- Первое (DZ PDF 1, журн. 35–36, рис. 1): на окружности из m «коробочек» и n «кружочков» вычёркиваем подряд «k коробочек + один кружочек» (на числе доминирующих сдвигов это не сказывается: ни один доминирующий сдвиг не может начинаться с вычеркнутой пары, и она сама на доминируемость не влияет); по принципу Дирихле такая подпоследовательность есть, пока m ≥ kn; остаётся m−kn коробочек = m−kn доминирующих сдвигов.
- Второе (DZ PDF 2, журн. 36, рис. 2): рисуем «горный хребет» (шаг ↗ на коробочку, шаг вниз на k на кружочек); циклический сдвиг = смена начала; допустимое новое начало — точка, правее которой нет такой же или более низкой впадины, и которая менее чем на m−kn выше самой глубокой впадины; таких точек ровно m−kn.
- Роль: звено (доказательство ключевой леммы; можно дать как «⋆ докажите самостоятельно, картинка — хребет»).
- Рамка: В РАМКЕ. Сложность: трудная (первое доказательство — средняя: понять, что вычёркивание не меняет ответ).

**B12. Один циклический сдвиг на каждое k («модификация цикл-леммы» из Huq).**
- Формулировка (дословно, Huq, Thm 2.1.1): «Suppose that a₁+…+a_n = 1 where each aᵢ ∈ ℤ. Then for each k, 1 ≤ k ≤ n, there is exactly one conjugate of the sequence a with exactly k nonpositive partial sums.» Геометрически (Thm 2.1.2, PDF 17): для пути из P(n,1,1), шаги ±1, конец на высоте 1, для каждого k = 1…n есть ровно один сдвиг, у которого ровно k вершин на оси или ниже.
- Адрес: `CAT/biblioteka/istochniki/stati-obzory/Huq — Generalized Chung-Feller Theorems for Lattice Paths (arXiv 2009).pdf`, PDF 15–17 (стр. 7–9 диссертации; доказательство — 1 страница).
- Идея: вместо частичных сумм берём Sᵢ = a₁+…+aᵢ − i/n; все Sᵢ (i=0…n−1) различны (дробные части разные), ранжируем их; сдвиг, начинающийся с j-й по высоте точки, имеет ровно j неположительных сумм.
- Роль: звено к теореме Чжуна — Феллера (B13).
- Рамка: В РАМКЕ. Сложность: трудная/⋆ (трюк с «наклоном» на i/n).

**B13. Теорема Чжуна — Феллера (бридж: время над осью равномерно).**
- Формулировка (дословно, Huq, Thm 1.1.3): «Among the C(2n,n) paths from (0,0) to (2n,0), the number of paths with 2k steps lying above the x-axis is independent of k for 0 ≤ k ≤ n, and is equal to (1/(n+1))·C(2n,n).» Приписывается: MacMahon 1909, Chung–Feller 1949 (произв. функции), Narayana (циклический метод).
- Адрес: тот же PDF, PDF 13 (стр. 5 диссертации). Вывод из цикл-леммы: Thm 2.3.1 (1) (PDF 19, стр. 11) — «paths in P(n,1,1) that start with an up step, exactly k up steps starting on or below the x-axis, k = 1,…,n+1: (1/(n+1))C(2n,n)»; «часть (1) — по существу классический Чжун — Феллер: убрать первый шаг вверх и опустить путь на единицу» (PDF 19–20).
- Ответ: C_n путей для каждого k ✔ перебор n ≤ 6 (для каждого k = 0…n ровно C_n).
- Идея решения: циклический метод (B12 + «особые вершины»: Thm 2.2.1, PDF 18); в проекте: `VYCHITANO.md:82–85` (что прочитано).
- Роль: большая теорема (кандидат «время над осью», парадокс «около половины»; `CAT/kurs/mir1-rasskaz.md:73` — «кричит около половины», вне участка).
- Перевод (мои выкладки): «Бросили монету 2n раз; орлов и решек поровну (условие: выбираем равновероятно одну из C(2n,n) таких последовательностей). Сколько времени игрок A был в плюсе, определяем как число шагов по «крыше»; тогда P(ровно 2k шагов над осью) = 1/(n+1) для каждого k = 0…n».
- Рамка: В РАМКЕ, но модель = равновероятные последовательности с равным числом орлов и решек (это не условная вероятность, а описание эксперимента: «выбираем равновероятно одну из тех…»). Вариант без «в конце в нуле» — арксинус, см. B21.
- Сложность: трудная (⋆ при выводе).

**B14. Число вершин не выше оси равномерно на {1,…,2n+1}.**
- Формулировка (близко к тексту; Huq, Thm 2.3.1 (3)): «Число путей из P(n,1,1) (2n+1 шаг, n+1 вверх, n вниз, конец на высоте 1) ровно с k вершинами на оси или ниже, для k = 1,…,2n+1, равно (1/(2n+1))·C(2n+1,n)» (= C_n для каждого k). Тот же PDF 19.
- Роль: вбок (форма «время под осью» для нечётной длины, где нет спора о «ничьей»; без «бридж = в нуле в конце»).
- Рамка: В РАМКЕ. Сложность: трудная.

### Группа III. Возвращение, первое достижение, разорение (журнал и дайджесты)

**B15. Не вернуться в 0 за 2n шагов ⇔ быть в 0 на шаге 2n.**
- Формулировка (владелец/дневник, пересказ): P(нет возврата в 0 за 2n шагов) = P(в 0 на шаге 2n) = C(2n,n)/2^{2n}.
- Адрес: `CAT/zhurnal/2026-07-03_programma-kursa/SESSIYA.md:19` («Классика (Феллер т.1), верно; оформить биективно как кульминацию МК1»); `CAT/zhurnal/2026-07-03_programma-kursa/TZ.md:42` (кульминация — «тождество «нет возврата за 2n = попал в 0 на шаге 2n»»); `CAT/zhurnal/2026-07-05_mir1/SESSIYA.md:119` (Н4 «Случайное блуждание», кульминация P(не вернуться за 2n) = C(2n,n)/2²ⁿ); строгий вид — `CAT/kurs/mir1-skelet.md` §4 Утв. 13 (вне участка, не открывал).
- Ответ: C(2n,n)/4ⁿ ✔ перебор n ≤ 6 (и P(все S_i ≥ 0) = то же).
- Идея (дневник): суммируем по путям Дика в точки 1, 2, 3, … (разности биномов по отражению), сумма телескопируется. Мои выкладки: число положительных путей длины 2n, кончающихся на высоте h, равно (h/2n)·C(2n,(2n+h)/2) (баллотировка, B3); сумма по чётным h > 0 телескопируется в C(2n,n)/2.
- Роль: большая теорема (кандидат ℵ: «в каких случаях блуждание не возвращается»).
- Вероятностная по сути. Перевод: «с какой вероятностью при 2n бросках счёт ни разу не станет равным?» Ответ C(2n,n)/4ⁿ.
- Рамка: В РАМКЕ (конечное n). Формулировка «когда-нибудь вернуться» = ЗА РАМКОЙ: бесконечные процессы, пределы.
- Сложность: трудная.
- Предупреждение: в `CAT/kurs/L6-cikl-lemma-konspekt.md:19,108–114` (вне участка, увидел grep-ом) прежний ответ исправлен: «неотрицательный ⇔ вернувшийся в 0» — это теорема Феллера, а НЕ Чжун — Феллер; чистое доказательство — отражение + телескоп.

**B16. Теорема Феллера: P(все S_i ≥ 0) = P(S_2n = 0).**
- Формулировка (`CAT/kurs/L6-cikl-lemma-konspekt.md:108–114`, вне участка): число путей длины 2n шагами ±1, всё время ≥ 0 (конец на любой высоте), равно числу путей, кончающихся в 0, оба C(2n,n). «В вероятностях: P(S₁≥0,…,S₂ₙ≥0) = P(S₂ₙ=0) = C(2n,n)/2^{2n}.»
- Роль: звено к B15 (два «невероятно равных» события); вбок.
- Рамка: В РАМКЕ. Сложность: трудная. ✔ перебор.

**B17. Первое достижение уровня −1 (разорение за конечное время) и первое возвращение.**
- Формулировка (дневник, формула Оттера — Дуасса / hitting time theorem, `CAT/biblioteka/istochniki/VYCHITANO.md:231–237` и `CAT/zhurnal/2026-07-05_mir1/zapros-vetvyashchiesya.md:28–29`): P(первое попадание блуждания в −1 ровно на шаге n) = (1/n)·P(S_n = −1); «множитель 1/n — прямое проявление циклической леммы»; элементарное доказательство — van der Hofstad–Keane 2008, Amer. Math. Monthly 115(8) 753–756 (PDF в участке НЕТ, только дайджест).
- Частный случай для простого блуждания (мои выкладки, ✔ перебор n ≤ 5): «первый раз оказаться в −1 ровно на шаге 2n+1» происходит на C_n последовательностях из 2^{2n+1}; вероятность C_n/2^{2n+1}. Первое возвращение в 0 на шаге 2n — 2·C_{n−1} последовательностей (пути первого возврата ↔ Каталан: `zapros-vetvyashchiesya.md:16`, `SESSIYA.md:119`, Yu/Ko 18.212: C_{k−1}C_{n−k}).
- Роль: большая теорема / звено (первое достижение и «разорение за конечное время» на одном уровне: игрок с одной монетой).
- Перевод: «Игрок с 1 монетой играет по монете за партию (±1); с какой вероятностью он разорится ровно в 2n+1-й партии?» Ответ C_n/2^{2n+1}.
- Рамка: В РАМКЕ для варианта «ровно на шаге N» (конечное N). Вопрос «с какой вероятностью он когда-нибудь разорится» — ЗА РАМКОЙ: бесконечный процесс, пределы. Ветвящиеся процессы и общее распределение шагов (Гальтон — Ватсон, общий закон потомства) — ЗА РАМКОЙ: независимость, матожидание.
- Сложность: средняя/трудная.

**B18. Первое возвращение как рекуррента Каталана.**
- Формулировка (дневник; Утв. 12 скелета, вне участка): «возвращение в 0 в первый раз на шаге 2n» разлагается по первому возврату: C_n = Σ C_k·C_{n−1−k}.
- Адрес: `CAT/zhurnal/2026-07-05_mir1/SESSIYA.md:119` (Н4: «пути первого возврата ↔ Каталан»); `zapros-vetvyashchiesya.md:11`.
- Роль: вход/звено (даёт числа Каталана из блуждания).
- Перевод: «с какой вероятностью первое возвращение произойдёт на шаге 2n» → 2·C_{n−1}/2^{2n}.
- Рамка: В РАМКЕ. Сложность: средняя.

**B19. Вход: «куда и с какой вероятностью за 5 шагов».**
- Формулировка (владелец; `CAT/zhurnal/2026-07-03_programma-kursa/SESSIYA.md:28`, эскиз первой лекции): «точка, шаги ±1 с p = 1/2; «куда / с какой вероятностью за 5 шагов»». Затем «пере-открываем Паскаля с разных сторон (траектории, буквы, картинки, рекуррента), связь вероятность ↔ число путей».
- Ответ (мой пересчёт): распределение положения после 5 шагов: 1,5,10,10,5,1 из 32 (позиции −5,−3,−1,1,3,5).
- Роль: вход.
- Рамка: В РАМКЕ (равновероятность 2^n последовательностей). Сложность: лёгкая.

**B20. Единое соответствие: лестница «с какой вероятностью…».**
- Формулировка (владелец, `CAT/zhurnal/2026-07-12_l1-dorabotka/SESSIYA.md:49,64`): «с какой вероятностью случайная перестановка НЕ содержит паттерн» (подать как «школьники встали в случайном порядке», без формализма); «какова вероятность, что случайную очередь можно разложить одним стеком» → подсчёт сортируемых → рекурсия = дерево → C_n.
- Роль: вбок (вход к Каталану не через блуждание). Вердикт моста: `SESSIYA.md:55` («мост «вероятность → деревья» настоящий и тугой, но ТОЛЬКО для 231 и ТОЛЬКО через шаг подсчёта»).
- Рамка: В РАМКЕ. Сложность: средняя. (Вне темы «блуждание», но у владельца вероятностный вход именно такой — «доля от равновероятных».)

**B21. Арксинус (только конечная версия).**
- В участке формулировки НЕТ. Для блуждания БЕЗ условия «в конце в нуле» число последовательностей длины 2n с ровно 2k шагами над осью — C(2k,k)·C(2n−2k,n−k) ✔ перебор n ≤ 6 (моя проверка, из общих знаний: Феллер т. 1, гл. III; Эрдёш — Кац). Даёт «арксинусную» картину без пределов: значения 2k=0 и 2k=2n самые вероятные.
- Связь с B13: Чжун — Феллер — версия «бридж», равномерная; арксинус — версия «без условия», U-образная. Разбивка по первому возврату + Чжун — Феллер даёт вторую из первой (мои соображения, в источниках не проверено).
- Решение владельца: `CAT/zhurnal/2026-07-05_mir1/zamechaniya-L1-process-first.md:25` («арксинус здесь не влезает») и `SESSIYA.md:40`, `TZ.md:44` (для курса лагеря; для листка ℵ решение не принималось).
- Роль: большая теорема (по списку кандидатов), но ссылки на нужные источники в участке НЕТ.
- Рамка: конечная формула В РАМКЕ; предельная форма (распределение arcsin, интеграл) — ЗА РАМКОЙ: пределы, интеграл.
- Сложность: ⋆.

**Ц7. Цепочка Huq (PDF 13–20).** Классический Чжун — Феллер (Thm 1.1.3) → цикл-метод (Thm 2.1.1, 2.1.2) → «особые вершины» (Thm 2.2.1) → три формы C_n (Thm 2.3.1: (1) классический Чжун — Феллер, (2) вниз-шаги, (3) 1/(2n+1)·C(2n+1,n) по всем вершинам) → числа Нараяны (§2.5) → Моцкин/Шрёдер (гл. 3).

**Ц8. ЗА РАМКОЙ по рамке ℵ (ветвящиеся процессы не входят), но строчка про контраст «отражение vs цикл-лемма» — готовая драматургия для 2 доказательств.
