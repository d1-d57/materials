## Сквозная логика (одной строкой на переход)

баллотировка → исходы = порядки → нарисовать, чтобы «не отставал» было видно → пути → 35 путей не нарисуешь → считать по узлам → треугольник Дика → на оси 1,1,2,5,14,42 → имена → первое возвращение → рекуррента → сравнить с C(2n,n) → гипотеза формулы → те же числа у деревьев и триангуляций → «что доказано?» → гипотеза отвечает на баллотировку при a−b=1 → ответ красивый → общий тоже красивый → числитель через знаменатель, знаменатель = все пути → три записи одной формулы = три дороги (все − плохие; все : (a+b); все : (n+1)) + триангуляции + индукция → теорема → **сюжет 2:** ни разу не поровну → 2, 6, 20, 70 — «мы их знаем» → телескоп → «почему сократилось?» → биекции → первое возвращение → двое гуляют → **сюжет 3:** последний ноль = мост × невозврат → U-форма → 100 бросков → то же распределение у времени лидерства → имя «арксинус» → смены лидера → делится на 4 → половинки строк Паскаля → ноль самое вероятное → 2u_n и касания оси.

**Поправка к брифу аналитика.** В брифе сюжета 3 стояло «P(ни одной смены) = u_n»; исполнитель C поймал: 2·C(2n−1,n−1)/2^{2n−1} = C(2n,n)/2^{2n−1} = 2u_n (12/16, 40/64, 140/256). В черновике 1.1 ответ не печатался, ошибки в листке нет.

**Не восстановлено своими руками (⋆, «верно ли»):** равенство распределений времени лидерства и последнего нуля (Феллер III §4) и биекция «r смен ↔ финиш на ±(2r+1)» (Феллер III §5). Численно верно; в листке — только как ⋆-вопросы без обещания конструкции.
