# Сюжет 1б. Формула C_n = C(2n,n)/(n+1) и баллотные числа — пятью дорогами

**Дорога сюжета.** Вход — гипотеза из 1а (C(2n,n)/C_n = 2,3,4,5,…) и таблица треугольника Дика. Гипотеза сразу отвечает на баллотировку при разнице голосов 1: 1/(n+1) и 1/(2n+1). Ответы красивые → в общем случае тоже должны быть красивые; дети угадывают их по таблице: (a−b+1)/(a+1) и (a−b)/(a+b). Знаменатель — биномиальный коэффициент = все пути, значит, хорошие пути надо выразить через все. Три записи одной гипотезы — три дороги: «все минус плохие» (отражение), «все : (a+b)» (циклическая лемма), «все : (n+1)» (Чжун — Феллер); четвёртая — по триангуляциям, где вместо оси — треугольники и рекуррента; пятая — «в лоб», индукцией по треугольнику. Теорема формулируется в самом конце, как итог; каждая дорога кончается вопросом «выведите формулу для C_n».

Обозначения для автора (не для листка): T(k,h) — число в точке (k,h) треугольника Дика; u = (k+h)/2 — число шагов вверх; «хороший путь» — не опускающийся ниже оси; «мост» — путь из (0,0) в (2n,0), любой.

## 0. Мост из 1а: от гипотезы к общей баллотировке

**0.1** **Вопрос.** Гипотеза из 1а: C_n = C(2n,n)/(n+1). Что она говорит о задаче 1? а) При a = b = n — с какой вероятностью А ни разу не отставал? б) При a = n+1, b = n — с какой вероятностью А после каждого бюллетеня был строго впереди? (Что известно про первый бюллетень?)
- *Зачем здесь:* связывает гипотезу с исходной задачей; даёт два «красивых» ответа, из которых растёт всё дальше.
- *Что откроют:* а) C_n/C(2n,n) = 1/(n+1). б) первый шаг вверх, дальше путь Дика: C_n/C(2n+1,n) = 1/(2n+1), так как C(2n+1,n) = C(2n,n)·(2n+1)/(n+1).
- *Картинка:* путь при a=4, b=3 (первый шаг вверх, затем путь Дика над прямой y=1).
- *Риск спойлера:* скобка про первый бюллетень — уже подсказка; можно снять.
- Трудность: лёгкая.

**0.2** **Вопрос.** 1/(n+1) и 1/(2n+1) — подозрительно простые дроби. Верно ли, что и при любых a, b ответы задачи 1 — простые дроби? Найдите по треугольнику Дика обе вероятности для всех a+b ≤ 8 и угадайте общие формулы.
- *Зачем здесь:* «ответ красивый → в общем случае тоже красивый». Гипотеза для всей баллотировки — цель всех дорог.
- *Что откроют:* 1а: (a−b+1)/(a+1); 1б: (a−b)/(a+b). Заодно: T(k,h)/C(k,u) = (h+1)/(u+1) — «доля хороших путей».
- *Картинка:* треугольник Дика, в котором рядом с каждым числом дети пишут дробь T/C(k,u) (образец — две-три точки).
- Трудность: средняя.

**0.3** **Вопрос.** В знаменателе стоит C(a+b,a) — число всех путей в точку (a+b, a−b). Значит, хорошие пути надо как-то выразить через все. Запишите гипотезу для C_n тремя способами: C(2n,n) − ?, C(2n,n) : ?, C(2n+1,n) : ?. Каждая запись — намёк на свой способ счёта. Ниже — четыре дороги; выберите свою.
- *Зачем здесь:* явная развилка; логика владельца «как здесь возникает биномиальный коэффициент? это все пути».
- *Что откроют:* C(2n,n) − C(2n,n+1); C(2n,n) : (n+1); C(2n+1,n) : (2n+1).
- *Картинка:* —
- *Риск спойлера:* мета-вопрос; можно оставить как текст-вступление без окна.
- Трудность: лёгкая.

## Дорога 1. Отражение: «все минус плохие»

**1.1** **Вопрос.** По гипотезе хороших путей в (2n,0) — C(2n,n)/(n+1). Сколько тогда плохих (опускающихся ниже оси)? Упростите разность. Не встречалось ли это число раньше — как число ВСЕХ путей из (0,0) в какую-то другую точку?
- *Зачем здесь:* 0.3, первая запись. Совпадение двух чисел — повод искать биекцию.
- *Что откроют:* C(2n,n)·n/(n+1) = C(2n,n+1) = C(2n,n−1) — все пути в (2n,2), они же все пути в (2n,−2).
- *Картинка:* сетка с двумя концами (2n,0) и (2n,−2), без путей.
- Трудность: лёгкая.

**1.2** **Вопрос.** Итак, плохих путей в (2n,0) должно быть столько же, сколько всех путей в (2n,−2). Что общего у всех плохих путей? А у всех путей в (2n,−2)? Нарисуйте разные плохие пути: который коснулся прямой y=−1 и сразу развернулся; который её пересёк; который касался несколько раз.
- *Зачем здесь:* из 1.1: числа равны → нужна биекция; сначала надо увидеть общий признак.
- *Что откроют:* все плохие пути касаются прямой y = −1; все пути в (2n,−2) тоже (и пересекают её).
- *Картинка:* ОБЯЗАТЕЛЬНО: плохой путь в общем виде — касается y=−1, уходит ниже, возвращается, касается ещё раз; прямая y=−1 пунктиром. Отражение НЕ рисовать, первую точку касания не выделять.
- Трудность: средняя.

**1.3** **Вопрос.** У плохого пути есть особенная точка. Разрежьте путь в ней на два куска. Что можно сделать с одним из кусков, чтобы путь стал начинаться в (0,−2), а конец остался на месте? Убедитесь, что по результату исходный путь восстанавливается — и что у каждого пути из (0,−2) в (2n,0) есть прообраз.
- *Зачем здесь:* 1.2 дало признак; теперь строится биекция.
- *Что откроют:* первая точка касания y=−1; начало пути (до неё) отражается относительно y=−1. Обратно: любой путь из (0,−2) в (2n,0) обязан пересечь y=−1 — отражаем до первого касания. (Можно отражать хвост — тогда получаются пути из (0,0) в (2n,−2), столько же.)
- *Картинка:* дети рисуют сами на своих путях из 1.2.
- *Риск спойлера:* «первое касание прямой y=−1» — если стоят, сказать «какая точка плохого пути самая первая из особенных?».
- Трудность: средняя.

**1.4** **Вопрос.** Работает ли то же для путей в любую точку (m,h), h ≥ 0: плохих из (0,0) в (m,h) столько же, сколько всех из (0,−2) в (m,h)? Сколько тогда хороших путей в (m,h)? Сравните с треугольником Дика и с гипотезой 0.2.
- *Зачем здесь:* биекция из 1.3 не зависела от конца — обобщение бесплатно; отсюда вся таблица.
- *Что откроют:* T(m,h) = C(m,u) − C(m,u+1), u = (m+h)/2. В точке (a+b, a−b): C(a+b,a) − C(a+b,a+1) = C(a+b,a)·(a−b+1)/(a+1).
- *Картинка:* —
- Трудность: лёгкая.

**1.5** **Вопрос.** а) Выведите ответ 1а и формулу для C_n. б) Как этим же способом получить ответ 1б? Что обязано быть после первого бюллетеня, и относительно какой прямой тогда отражать?
- *Зачем здесь:* закрытие дороги; б) — второе применение того же отражения (позиция владельца: отражение доказывается один раз, применяется дважды).
- *Что откроют:* а) (a−b+1)/(a+1); C_n = C(2n,n) − C(2n,n+1) = C(2n,n)/(n+1). б) первый шаг вверх, затем путь из (1,1) в (a+b, a−b), не касающийся оси = сдвинутая задача 1а для (a−1, b): C(a+b−1,a−1) − C(a+b−1,a) = C(a+b,a)·(a−b)/(a+b).
- *Картинка:* путь при a=5, b=3, первый шаг вверх, прямая y=0 пунктиром как «запретная».
- Трудность: средняя.

## Дорога 2. Циклическая лемма: «все : (a+b)»

**2.1** **Вопрос.** Ответ 1б — (a−b)/(a+b). Знаменатель a+b — не число путей, а число бюллетеней. Дробь со знаменателем a+b обычно появляется, когда что-то делят поровну между a+b объектами. Что можно сделать с последовательностью из a+b бюллетеней ровно a+b способами?
- *Зачем здесь:* 0.3, третья запись; логика владельца: «как будто мы что-то делили на все положения по кругу».
- *Что откроют:* замкнуть в круг и начать читать с любого из a+b мест.
- *Картинка:* a+b бюллетеней (+1/−1) по кругу, стрелка «начало чтения».
- Трудность: средняя.

**2.2** **Вопрос.** Выпишите по кругу a чисел +1 и b чисел −1, a > b. Выберите начало, читайте по часовой стрелке и после каждого числа складывайте всё прочитанное. Из скольких начал все суммы положительны? Переберите все расстановки при a=3, b=1 и a=4, b=2, нарисовав частичные суммы как путь. Верно ли, что ответ не зависит от расстановки?
- *Зачем здесь:* 2.1 предложило круг; теперь эксперимент, из которого видна лемма.
- *Что откроют:* всегда ровно a−b хороших начал (проверено при a ≤ 6).
- *Картинка:* ОБЯЗАТЕЛЬНО: круг с числами при a=4, b=2 и рядом путь частичных сумм для одного начала; дети рисуют для остальных начал.
- Трудность: средняя.

**2.3** **Вопрос.** Почему хороших начал всегда a−b? Разверните круг: повторите последовательность несколько раз подряд и нарисуйте путь частичных сумм — за оборот он поднимается на a−b. Какие точки этого пути — хорошие начала? Что видно про их высоты?
- *Зачем здесь:* 2.2 дало число; путь на 2–3 оборота делает ответ видимым.
- *Что откроют:* хорошее начало = точка, ниже которой путь больше никогда не опускается (последнее посещение уровня); за один оборот путь навсегда покидает ровно a−b уровней. (Другой путь: найти +1, за которым сразу −1, и выкинуть пару — число хороших начал не меняется; индукция по b.)
- *Картинка:* ОБЯЗАТЕЛЬНО: периодический путь на 3 оборота при a=4, b=2, хорошие точки НЕ отмечены.
- *Риск спойлера:* «что видно про их высоты» — уже направление; мягче: «отметьте хорошие начала на пути; чем они отличаются от остальных точек?».
- Трудность: ⋆.

**2.4** **Вопрос.** Выведите ответ 1б. Сосчитайте двумя способами число пар (последовательность бюллетеней, место начала чтения), при которых чтение с этого места идёт при постоянном лидерстве А: сначала по кругам, потом по местам.
- *Зачем здесь:* лемма → баллотировка. Двойной счёт пар обходит вопрос о периодических последовательностях (не нужна взаимная простота a и b).
- *Что откроют:* по кругам: (a−b)·C(a+b,a); по местам: при фиксированном начале сдвиг — биекция последовательностей, значит (a+b)·G. Отсюда G = C(a+b,a)·(a−b)/(a+b).
- *Картинка:* —
- Трудность: средняя.

**2.5** **Вопрос.** Возьмите a = n+1, b = n: хорошее начало ровно одно. Сколько тогда хороших последовательностей и что это за пути? Выведите формулу для C_n. Та же ли это формула, что в гипотезе?
- *Зачем здесь:* закрытие дороги; «формула одной дробью» (позиция владельца: цикл-лемма интереснее отражения).
- *Что откроют:* G = C(2n+1,n)/(2n+1); хорошая последовательность = шаг вверх + путь Дика, G = C_n; C(2n+1,n)/(2n+1) = C(2n,n)/(n+1).
- *Картинка:* —
- Трудность: лёгкая.

## Дорога 3. «Все : (n+1)» — равные группы (Чжун — Феллер, без имени)

**3.1** **Вопрос.** Гипотезу можно прочесть так: C(2n,n) = (n+1)·C_n — все пути из (0,0) в (2n,0), включая заходящие под ось, делятся на n+1 равных групп, и пути Дика — одна из них. Нарисуйте все 6 путей при n=2 и все 20 при n=3. По какому признаку они делятся на n+1 равных групп по C_n путей?
- *Зачем здесь:* 0.3, вторая запись; вместо «плохих» — все пути равноправны, надо найти параметр с n+1 значениями.
- *Что откроют:* число звеньев над осью: 0, 2, …, 2n; при n=2 группы {DDUU, DUDU}, {DUUD, UDDU}, {UDUD, UUDD}.
- *Картинка:* 6 путей при n=2 без выделений; 20 путей при n=3 дети рисуют сами.
- Трудность: средняя.

**3.2** **Вопрос.** Значит, путей ровно с 2k звеньями над осью столько же, сколько с 2k−2, при каждом k = 1, …, n. Найдите обратимую операцию, уменьшающую число верхних звеньев ровно на 2. Разрежьте путь в точках на оси на «арки» (над осью и под осью) — какие куски и куда переставить?
- *Зачем здесь:* 3.1 дало равные группы → нужна биекция между соседними; «ровно на 2» подсказывает, что портится одна арка.
- *Что откроют:* путь = A·(U X D)·B, где A — арки под осью до первой верхней арки (может быть пуста), U X D — первая арка над осью (X — путь Дика, может быть пуст), B — остаток. Образ: X·D·A·U·B — кусок A опускается на уровень −1 внутрь новой нижней арки D A U. Верхних звеньев на 2 меньше. Обратно: X — начальный отрезок из верхних арок, D A U — первая нижняя арка, B — остаток; единственно. Проверено перебором n ≤ 6 (биекция {2k верхних} → {2k−2}).
- *Картинка:* ОБЯЗАТЕЛЬНО: путь длины 12 с 2–3 арками разных знаков, точки на оси выделены, куски подписаны A, X, B; образ НЕ рисовать.
- *Риск спойлера:* «переставить куски» — направление; если стоят: «первую верхнюю арку надо испортить, но куда деть её содержимое?».
- Трудность: ⋆.

**3.3** **Вопрос.** а) Выведите формулу для C_n. б) За А и Б подано по 10 голосов, подсчёт нарисован путём. Что вероятнее: что нет ни одного звена над осью или что звеньев над осью ровно половина?
- *Зачем здесь:* закрытие; б) — вероятностный «вау»: время лидерства распределено равномерно, а не «обычно поровну».
- *Что откроют:* а) C_n = C(2n,n)/(n+1). б) одинаково: 1/11.
- *Картинка:* —
- Трудность: лёгкая.

## Дорога 4. Триангуляции: рекуррента вместо оси (любимая дорога владельца)

**4.1** **Вопрос.** Из 1а: C_n — ещё и число триангуляций (n+2)-угольника. У триангуляций нет оси и нет «плохих», зато есть треугольники, которые можно выкидывать, — то есть удобнее рекуррента, а не готовая формула. Что гипотеза говорит об отношении C_{n+1}/C_n? Проверьте по таблице 1, 1, 2, 5, 14, 42, 132 и запишите в виде равенства двух произведений.
- *Зачем здесь:* переводит гипотезу на язык, где нет путей; (n+2)·C_{n+1} = (4n+2)·C_n — два произведения = двойной счёт.
- *Что откроют:* C_{n+1}/C_n = (4n+2)/(n+2): 2/1=6/3, 5/2=10/4, 14/5, 42/14=18/6, 132/42=22/7; (n+2)C_{n+1} = 2(2n+1)C_n. (Проверено n ≤ 7.)
- *Картинка:* —
- Трудность: лёгкая.

**4.2** **Вопрос.** Слева — триангуляции (n+3)-угольника, в каждой что-то выбрано n+2 способами; справа — триангуляции (n+2)-угольника, в каждой что-то выбрано 2(2n+1) способами. Чего в (n+3)-угольнике ровно n+2, если одна сторона — «база»? Чего в триангуляции (n+2)-угольника ровно 2n+1? Откуда двойка?
- *Зачем здесь:* 4.1 дало равенство; надо угадать, ЧТО считать. Считать рёбра дети умеют (1а: n−1 диагоналей).
- *Что откроют:* n+2 небазовых стороны; 2n+1 = (n+2) сторон + (n−1) диагоналей; двойка — ориентация ребра.
- *Картинка:* триангуляция шестиугольника с базой (жирная сторона); дети пересчитывают рёбра.
- Трудность: средняя.

**4.3** **Вопрос.** Отметьте в триангуляции (n+3)-угольника сторону, не базу. К ней примыкает ровно один треугольник. Как его «выкинуть», чтобы осталась триангуляция (n+2)-угольника, в которой отмечено ребро со стрелкой? Обратимо ли: как по ребру со стрелкой «вставить» треугольник назад?
- *Зачем здесь:* 4.2 назвало объекты; теперь соответствие. «Треугольник, который можно выкинуть» — мотив с самого начала дороги.
- *Что откроют:* стянуть отмеченную сторону в точку: треугольник исчезает, два его других ребра склеиваются в одно ребро; стрелка на нём — в тот из двух концов, который при обратном ходе надо расщепить на два (вставив треугольник). База переходит в базу, поэтому все (n+2)-угольники отождествляются. Двойка = выбор расщепляемого конца. (Соответствие 2-к-1 без стрелки — согласуется с (n+2)C_{n+1} = 2(2n+1)C_n; проверить перебором явно.)
- *Картинка:* ОБЯЗАТЕЛЬНО: триангуляция пятиугольника с отмеченной стороной и её треугольником, рядом пустой четырёхугольник — дети дорисовывают результат; второй пример, где склеенное ребро — сторона.

## Итог сюжета (текст листка, в самом конце)

**Теорема.** C_n = C(2n,n)/(n+1) = C(2n+1,n)/(2n+1) = C(2n,n) − C(2n,n+1). Вероятность того, что А ни разу не отставал, — (a−b+1)/(a+1); что А всё время строго впереди (a>b), — (a−b)/(a+b).

**Последний вопрос-мост.** Какой ответ на исходную задачу о баллотировке даёт каждая дорога? Где 1а, где 1б, где только случай a = b?
- Отражение: 1а прямо, 1б — сдвигом (оба). Цикл-лемма: 1б прямо, 1а — добавив бюллетень за А в начало (a → a+1). Равные группы: только a = b (зато распределение времени лидерства). Триангуляции: только C_n. Индукция: оба.
