# Оптика «теорема → листок» (на примере 18ℵ)

> Владелец, 01.10 03:52: «чему мы хотим научить, что ученик должен вынести — и каждую задачу проверить, соответствует ли ей наш путь». Ниже — способ превращать теорему (или 2–3 теоремы) в листок ℵ. На этом файле должен строиться будущий универсальный скилл. Пример всюду — 18ℵ, его таблица — `LOGIKA-18alef.md`.

## 1. Пять вопросов до первой задачи

1. **Что ученик вынесет.** Ответ — 4–7 навыков-итогов, каждый одной фразой с глаголом. Не «узнает теорему», а «умеет …».
2. **Какие вершины.** 2–3 утверждения, к которым ведёт листок. Меньше лучше. Ответ каждой вершины должен ставить вопрос следующей.
3. **Рамка.** Один инструмент законного решения и список того, что в листок не пускаем.
4. **Где «вау».** Места, где ответ противоречит интуиции или неожиданно совпадает с другим. Их не объясняют — к ним подводят.
5. **Какие объекты надо увидеть глазами.** У каждого — картинка или требование нарисовать все малые экземпляры.

## 2. Итоги обучения 18ℵ (ответ на вопрос 1)

- **И1. Моделировать.** Эксперимент → равновероятные исходы → пути; вероятность как доля путей. Задачи 2, 12 (момент k), 16 (путь игры).
- **И2. Считать локальным правилом и строить предположения по данным.** Треугольник Каталана, таблица → формула. Задачи 3, 4в, 7а (малые случаи).
- **И3. Раскладывать объект по первому событию и получать рекурренту.** Первое возвращение. Задачи 4, 6а.
- **И4. Видеть одно число в разных моделях; равенство чисел — повод искать биекцию.** Задачи 5†, 6б, 13†, 14, 15, 17б.
- **И5. Доказывать одно утверждение разными способами, где каждый способ объясняет свою запись ответа.**
  - все минус плохие — отражение, задача 7†;
  - все делим на a+b — циклическая лемма, задача 9;
  - все делим на n+1 — равные группы, задача 10;
  - рекуррента в другой модели — задача 11.
- **И6. Не доверять интуиции в случайности.** Три разных события равновероятны (12). Последний ноль скорее у краёв (16). Лидер почти не меняется (18). Ничьих верхних звеньев столько же, сколько «ровно половины» (10в).
- **И7. Собирать новое из старого.** Последний ноль — это мост длины 2k, а за ним путь без возвращений. Поэтому вероятность — произведение двух ответов части III.

## 3. Проверка каждой задачи (гейт)

| Вопрос к задаче | Плохой признак | Ход исправления |
|---|---|---|
| Какой итог И1–И7 она двигает? | никакой | выкинуть или сделать отступлением (полоска ушла) |
| Из какого ответа она растёт? | «с неба» не в начале части | добавить мостик-пункт или переставить |
| Какой ответ она даёт дальше? | никакой, и задача не вершина | убрать или превратить в пункт соседней |
| Есть ли малый случай «руками»? | сразу общий n | добавить пункт а) с n = 2, 3 (так переделана 7а) |
| Не выдаёт ли формулировка метод? | точка отражения, «первое возвращение» в скобках | заменить конкретным заданием: «разложите на группы по…» |
| Не спрашивает ли о совпадении? | «где видели», «сравните» | поставить события рядом в одной задаче (12б–г) или «постройте биекцию» |
| Нужен ли объект глазами? | новый объект без картинки | картинка или «нарисуйте все при n = 4» |
| Письменная ли? | ключевое рассуждение сдаётся устно | † — образец рассуждения или набор объектов (5, 7, 13) |

## 4. Ходы преобразования (словарь)

- **Разбить:** пункт «малый случай» перед общим (7а).
- **Объединить:** однородные вопросы — цепочкой в одной фразе (16: «от 0 до 10? от 90 до 100? от 45 до 55?»).
- **Поставить рядом:** события, совпадение которых должен заметить ребёнок, — пунктами одной задачи (12б–г).
- **Дать большой пример глазами:** все объекты при n = 4 (14 путей Дика), а ребёнку — следующий размер (5†).
- **Подсказать картинкой, а не словом:** самая низкая точка моста (13), прямая y = −1 без отражения (7).
- **Редакторская строка на границе частей:** одна фраза о том, что будет дальше, в духе 16ℵ («Дальше — несколько разных доказательств предположения из задачи 3б»). Ответ она не выдаёт.
- **Закрыть вершину задачей:** «Решите задачу 1» (7в), а не текстом-теоремой.
- **Отступление** — в конец или удалить.

## 5. Оформление: что проверять глазами

1. **Первая страница — витрина.** Самая большая картинка (треугольник) стоит на ней. Текст определения — в пустом углу, по форме угла (трапеция вдоль диагонали, верхние строки широкие). Оси подписаны тихо: серым, мелко.
2. **У каждой функции подпись на самом графике.** Оси x, y и метки 0, ½, 1.
3. **Одна система мер.** Сетка, ось и путь заданы в `kartinki.py`. Масштабы: мелкие серии 0,27–0,3, одиночные пути 0,38–0,46.
4. **Картинка рядом с текстом, если текст короче картинки по высоте; во всю строку — если это серия.**
5. **Ни одного провала больше 2 см.** Длинную картинку сжимать раньше текста, текст сокращать раньше, чем уменьшать шрифт.

## 6. Пять математических улучшений (v9–v10)

1. **7а — малые случаи перед общим.** «Сколько плохих путей в (4,0)? в (6,0)? в (2n,0)?» Ответы 4 и 15 узнаются как C(4,1) и C(6,2), и это мотивирует отражение.
2. **9а — сначала пример с рисунка.** «На рисунке a = 4, b = 3. Со скольких мест все суммы положительны? А при любых a > b?» Картинка перестаёт быть украшением и становится первым шагом.
3. **11 — одно задание вместо двух пунктов** (владелец, 04:03). Проверка рекурренты «при n ≤ 3» сама по себе неинтересна. Задача сформулирована так: построить соответствие → вывести (n+2)T_{n+1} = (4n+2)T_n → найти T_n, то есть получить формулу новым способом.
4. **14а — построить T для S с рисунка до доказательства биекции.** Конструкция сначала проходится руками.
5. **Треугольник заполнен меньше** (k ≤ 5 вместо k ≤ 8). Правило в 3а ребёнок выводит сам, и числа 14, 28 на оси больше не подсказывают ответ.

Сопутствующие правки:
- **Формулировки.**
  - «Найдите ответ в задаче 1» вместо «Решите задачу 1» (так не говорят).
  - 3б укладывается в одну строку.
  - Висячие последние строки убраны в 2а, 14б, 17а, 17в, 18в. Правило: каждая формулировка кончается полной строкой или занимает на строку меньше.
- **Оформление.**
  - Шапка по стандарту коллег: буква ℵ в правом верхнем углу, в заголовке только номер.
  - Номер страницы внизу по центру (4 страницы печатают с двух сторон).
  - График подписан формулой, поэтому в тексте 17в формулы больше нет.
