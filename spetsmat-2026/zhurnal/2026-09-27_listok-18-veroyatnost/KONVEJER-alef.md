# Конвейер листка ℵ и рычаги (Ф3 закрытия арки 18, 01.10.2026)

> Как листок идёт от источника до двух PDF и что на каждом шаге может покраснеть. Здесь собрано то, что в 18ℵ жило в головах и командах чата. Правила — в каноне (`materials/spetsmat-2026/listki-kanon/KANON-alef.md`, К9, К11; с 01.10); этот файл — про механику.

## 1. Файлы листка (на примере 18ℵ)

| файл | что это | правится руками? |
|---|---|---|
| `alef-istochnik/telo.tex` | текст задач на макросах `\zad`, `\zadp`, `\punkt`, `\blok`, `\nomer`, `\celoe`, `\sboku`, `\risunok`, `\zvezdy`, `\term`, `\tekst`; картинки — метками `@имя@` | **да, единственный источник текста** |
| `alef-istochnik/kartinki.py` | все картинки TikZ кодом, единый стиль; пишет `kartinki.json` | да |
| `alef-istochnik/sobrat.py` | преамбула из готового листка + `telo` + картинки → `18alef-veroyatnost.tex`; идемпотентен (повторная сборка совпадает побайтно) | редко |
| `18alef-veroyatnost.tex` / `.pdf` | наша вёрстка (LuaLaTeX) | **нет**, только через `sobrat.py` |
| `format-179/perevod.py` | наш tex → их формат (`\z`, `\zp`, `\lett`); переносит хук «Фамилия, имя» | редко; после правки — `cmp` перевода 18α |
| `18alef-veroyatnost-179.tex` | вёрстка коллег | **нет**, только через `perevod.py` |
| `format-179/maket-179.tex` | имитация их стиля для pdflatex-проверки | нет |
| `lint_alef.py` | линтер аксиом, сверка значков с таблицей LOGIKA | да (рычаги) |
| `prov_alef_vN.py` | перебор всех ответов и конструкций → ALL OK | да, на каждую новую задачу |
| `visyachie.py` | висячие строки в PDF → rc=1 | да |
| `renumber.py` | перенумерация задач и ссылок «задачу N» | нет |
| `LOGIKA-<листок>.md` | концепция и таблица задач; линтер читает таблицу | да |

## 2. Сборка (как было в 18ℵ)

```
python3 kartinki.py && python3 sobrat.py <преамбула>.tex 18alef-veroyatnost.tex
lualatex -interaction=nonstopmode 18alef-veroyatnost.tex          # наша вёрстка
python3 perevod.py 18alef-veroyatnost.tex 18alef-veroyatnost-179.tex
pdflatex -jobname=… "\def\telo{…-179.tex}\input{maket-179.tex}"   # вёрстка коллег
```

Грабли, которые стоили времени:
- обтекание `wrapfig` протекает через страницы — только `\sboku`;
- ширина `\sboku` не меньше ширины картинки с подписями, иначе overfull;
- `\LenToUnit` не определён без eso-pic — координаты хуков в pt;
- двойные `\\` в r-строках Python при подстановке текста;
- картинка, увеличенная ради «воздуха», вылезла за поля (v19) — смотреть глазами;
- перевод коллегам ломает свои переносы: висячие строки проверять в обеих вёрстках (v20).

## 3. Гейт перед показом владельцу (К11.1) — одной командой

```
cd materials/spetsmat-2026/listok-veroyatnost
python3 gate_alef.py 18alef-veroyatnost.tex --logika ../zhurnal/2026-09-27_listok-18-veroyatnost/LOGIKA-18alef.md \
        --prov prov_alef_v21.py --sosed 18alpha-veroyatnost.tex
```

Собирает всё во временной папке, папку листка не трогает. Печатает одну строку на проверку и вердикт «ЗЕЛЁНЫЙ» или «КРАСНЫЙ — что именно».

| пункт К11.1 | проверка в гейте |
|---|---|
| 7 | `alef-istochnik` воспроизводит tex побайтно (kartinki.py + sobrat.py в копии) |
| 1 | `lint_alef.py --logika` — красного 0; число жёлтых печатается |
| 2 | `prov` — rc 0 и «ALL OK» |
| 4 | наша вёрстка: ошибок 0, страниц `--stranic`, Overfull 0 |
| 7 | свежий перевод = `…-179.tex`; переводы соседей (`--sosed`) не изменились |
| 4 | вёрстка коллег (pdflatex + `maket-179.tex` + tikz): страниц `--stranic`, Overfull ≤ 3 pt (К13.4) |
| 3 | `visyachie.py` по обоим PDF |
| К9.7 | `polya.py` по обоим PDF |
| 5 | «∗ ∗ ∗» не последняя строка страницы |
| 6 | номер страницы внизу (наша), «Фамилия, имя» на стр. 3 (обе) |
| 8–11 | **не автоматизировано:** md5 доставки, рецензия, стилистика, осмотр |

- На Mac у pdfTeX нет кириллицы (t2aenc.def): вёрстку коллег там не собрать, гейт так и пишет. Целиком гейт идёт в облачной сессии.
- После правки `lint_alef.py` — `python3 test_lint_alef.py`: портит v21 по одному правилу (22 порчи) и требует нужный код; на чистом v21 — зелёный.

### Что гейт сказал о напечатанной v21 (01.10, Ф3)

1. стр. 1, картинка «все 14 путей Дика в (8,0)» шире полосы набора: у коллег на 13–14 pt с каждой стороны, у нас на 4–5 pt;

## 4. Рычаги, заведённые в Ф3 (решение владельца 01.10: все четыре)

| рычаг | файл | что краснеет | чем проверен |
|---|---|---|---|
| Р-гейт | `gate_alef.py` | любой из пунктов §3 | прогон на v21: ловит 2 настоящих дефекта |
| Р-lint | `lint_alef.py` (коды = номера канона), `test_lint_alef.py` | см. докстринг; новые: К5.5, К5.9, К6.10, К9.9, К3.10 «куда»; жёлтые К5.24, К7.2 | 22 порчи; выключенное правило → тест красный |
| Р-поля | `polya.py` | чернила за полосой набора > 3 pt | v19: 30–42 pt (известный случай); v21: стр. 1 |
| Р-закрытие | рецепт в К2.14 | `dnevnik.py proverit` / полный `sdelat_handoff.py` отказывают без покрытия | транскрипт облака → gzip → `_sessii-cowork/` на Mac → proverit rc=0 |

**Отступления от плана §4 (записаны в дневнике):**
- «изменим условие задачи» — жёлтое, а не красное: по К5.24 оно законно, если вопрос тот же;
- wrapfig/`\obtek` в преамбуле — жёлтое: в напечатанной v21 они ещё там; в теле листка — красное;
- К5.25 на `\zad`/`\zadp` не сделан: эвристика путает заголовок с коротким условием («Монету бросают 2n раз.»).

**Чего рычагом не сделать** (надежда, говорить вслух): математика и лестница, «вау» и мотивировка, спойлеры, примеры общего положения, стиль, «не править руками стартовую строку VHOD»; правил канона только на надежде — 86 (К11.7).
