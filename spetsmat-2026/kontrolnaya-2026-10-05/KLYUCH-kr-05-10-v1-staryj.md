# Контрольная 05.10: деревья и плоские графы — ключ для проверяющих

Это черновик, готовый примерно на 80 %. Формат как у весенней контрольной: у каждой задачи свои баллы, в зачёт идут три лучшие задачи. Максимум — 12 + 8 + 8 = 28. Для ориентира: ученик, который только начал α, должен взять задачи 1–4, это 8–10 баллов.

Почему такая трудность (по кондуиту на 30.09):
- 17A сдан широко (17–27 человек).
- В 17αℵ формулу Эйлера доказали 9–14 человек, 2Р ≥ 3Г — 9, K₅ — 12, «есть вершина степени < 6» — всего 3–4.
- Поэтому формулу Эйлера даём как известную. Оценки вида Р ≤ 3В − 6 и непланарность K₅ — это уже середина контрольной.

## 1 [2]. Импликации
**Ответ: 33.**
- Пример: цикл а ⇒ б ⇒ … ⇒ я ⇒ а.
- Оценка: из каждого утверждения должно что-то следовать, иначе из него не вывести остальные. Значит, каждое из 33 утверждений — посылка хотя бы одной импликации, и импликаций не меньше 33.
- Языком графов: ориентированный граф, в котором из каждой вершины можно добраться до любой.
- Предупредить детей: «буква алфавита» включает ё (всего 33).

## 2 [3]. Листья
**Ответ: 22.**
- Пусть листьев L, вершин степени 2 — t. Тогда вершин n = 15 + L + t.
- Сумма степеней: 30 + 20 + L + 2t = 2(n − 1) = 28 + 2L + 2t. Отсюда L = 22.
- Ответ не зависит от t: это и есть «изюминка».
- Общая формула: L = 2 + Σ(deg v − 2) по вершинам степени ≥ 3.
- Запасной вариант той же идеи — «царь Гвидон» (problems.ru, задача 35362), но её многие знают.

## 3 [3+4]. Многогранник с 7 рёбрами
**а) Нет.**
- В + Г = Р + 2 = 9.
- Степени вершин не меньше 3, поэтому 2Р ≥ 3В и В ≤ 4. Грани — хотя бы треугольники, поэтому 2Р ≥ 3Г и Г ≤ 4.
- Значит, В + Г ≤ 8, противоречие.

**б) Все n ≥ 6, кроме 7.**
- Рёбер не меньше 6, так как 2Р ≥ 3В ≥ 12.
- Чётные n = 2k: пирамида над k-угольником (k ≥ 3).
- Нечётные n = 2k + 3 ≥ 9: у такой пирамиды срезать вершину степени 3 у основания, это добавляет 3 ребра.
- Баллы за б) — только за полный ответ с примерами.

## 4 [4]. Красный лист
- Каждое ребро имеет ровно один красный конец, поэтому Р = сумма степеней красных вершин.
- Если красных листьев нет, у красных вершин степень ≥ 2. Тогда Р ≥ 2K.
- Но Р = K + С − 1 ≤ 2K − 1. Противоречие.

## 5 [3+4]. По 5 и по 6 линий
**а) Да.**
- Плоский рисунок икосаэдра: 12 точек, 30 линий.
- Конструкция: маленький треугольник внутри шестиугольника, а он внутри большого треугольника. Каждая вершина обоих треугольников соединена с тремя ближайшими вершинами шестиугольника. Принимать любой правильный рисунок.
- Ранний этап: октаэдр (по 4) и тетраэдр (по 3) ребята рисовали в 17A.

**б) Нет.**
- Иначе Р = 6В/2 = 3В.
- Для простого плоского графа Р ≤ 3В − 6. Для несвязного графа — применить к компоненте.
- Если оценку Р ≤ 3В − 6 ребёнок не доказал, а сослался на неё, — решать коллективно. Предлагаю ставить не больше 2 из 4. Есть ли вершина степени < 6, решали всего 3–4 человека, а 2Р ≥ 3Г — 9.

## 6 [5]. Пять граней, попарно соседних
**Ответ: нельзя.**
- Внутри каждой грани отметим точку. Для каждой пары граней выберем общее ребро и соединим точки линией через это ребро.
- Ребро граничит ровно с двумя гранями, поэтому для разных пар рёбра разные, и линии можно провести без пересечений.
- Получился плоский K₅, а K₅ непланарен (17αℵ). Противоречие.
- Это и есть «ещё одна задача про двойственные графы», которую просил Даня. Его исходная задача («для каких графов двойственный без петель и кратных рёбер») расплывчата, поэтому заменена.

## 7 [3+5]. Сумма расстояний
**а) 576 (звезда).**
- Пар на расстоянии 1 ровно 24 (это рёбра), остальные 300 − 24 = 276 пар — на расстоянии ≥ 2.
- Отсюда сумма ≥ 24 + 552 = 576. У звезды сумма ровно такая.

**б) Нет.**
- Ребро, разбивающее дерево на части из s и 25 − s вершин, входит в пути ровно s(25 − s) пар.
- Сумма = Σ по рёбрам s(25 − s), и каждое слагаемое чётно: одно из чисел s и 25 − s чётно.
- А 1225 нечётно.
- 1225 = C(50, 2) лежит между 576 и максимумом C(26, 3) = 2600 (путь), так что ответ «нет» не виден из оценок.

## 8 [3+4]. Ошибка Пети
**а) Ошибки.**
- Главная: переход доказывает утверждение только для деревьев, которые получаются из меньшего дерева нашего класса подвешиванием листа. Не всякое дерево так получается. Пример: у звезды с тремя лучами (4 вершины) нет «предка» — деревьев на 3 вершинах без вершин степени 2 нет вовсе. Правильно начинать с произвольного дерева на n + 1 вершинах.
- Вторая: если подвесить лист к листу, тот становится вершиной степени 2, листьев остаётся L, а не L + 1, и новое дерево вообще не из нашего класса.
- За а) полный балл — за главную ошибку. Только за вторую — 1 балл.

**б) Верно.**
- Пусть L листьев, остальные n − L вершин степени ≥ 3.
- Тогда 2(n − 1) ≥ L + 3(n − L), откуда 2L ≥ n + 2 > n.
- Связь с задачей 2: та же формула L = 2 + Σ(deg − 2).

## 9 [8]. Семиугольник
- Граф разбиения: В вершин, Р рёбер, n₅ + n₆ внутренних граней и внешняя. Пусть b ≥ 7 — число рёбер на границе семиугольника.
- Все вершины имеют степень ≥ 3. Для внутренних вершин это следует из выпуклости кусков. Вершины семиугольника — по условию. Остальные граничные вершины — из них выходит внутреннее ребро.
- Значит, 2Р ≥ 3В.
- Длины граней: 2Р ≥ 5n₅ + 6n₆ + b. Вершина одного куска может лежать на стороне другого, тогда «длина» грани только больше.
- Эйлер: n₅ + n₆ = Р − В + 1 ≥ Р/3 + 1 ≥ (5n₅ + 6n₆ + b)/6 + 1.
- Отсюда n₅ ≥ b + 6 ≥ 13.

## 10 [3+4+5]. Калитки
Обозначим Г = число дач + 1 (улица).

**а) Р − В + 1.**
- Граф «дачи + улица, рёбра — калитки» должен быть связен, поэтому калиток ≥ Г − 1.
- Г − 1 калиток хватит: граф «дачи + улица, рёбра — все пролёты» связен, возьмём его остов.
- По Эйлеру Г − 1 = Р − В + 1.
- В примере на рисунке: В = 10, Р = 13, калиток 4.
- Связь с 16A №2 (спички 8 × 8): там калитки на улицу не нужны.

**б)**
- Нет циклов: цикл из глухих пролётов отрезал бы дачи внутри него от улицы.
- Глухих пролётов Р − (Р − В + 1) = В − 1.
- Граф без циклов, у которого рёбер на одно меньше, чем вершин, — дерево (листок 16).

**в) Биекция «калитки ↔ глухие пролёты».**
- По б) минимальному набору калиток соответствует остов.
- Обратно: пусть глухие пролёты образуют остов T. Калиток тогда Р − В + 1 = Г − 1. Проверим, что они соединяют все области.
- Допустим, области разбились на две группы, между которыми калиток нет. Все пролёты между группами глухие.
- Вокруг каждого столба области меняют группу чётное число раз. Поэтому у каждого столба чётное число пролётов «между группами», и хотя бы у одного столба оно ненулевое.
- Значит, среди таких пролётов есть цикл — цикл в T, противоречие.
- Это первое знакомство с теоремой «остов плоского графа ↔ остов двойственного» и с числом τ(G) = τ(G*). Хороший выход для ℵ.

## Запас (если что-то заменить)
- **Царь Гвидон** (problems.ru 35362) — вместо задачи 2.
