# kartochka-slajda.md — поля карточки слайда, связанные с вёрсткой

Дом формата ТОЛЬКО тех полей шапки `slaid.md`, которые решает эта дисциплина: `tip_verstki`,
`zagolovok_na_ekrane`, `illustracii`, плюс два поля, заведённые заходом `verstka-v-faze-1`
(`obosnovanie_verstki`, `zagolovok_snyat_namerenno`). Полная шапка карточки (`imya`, `nazvanie`,
`tip_idei`, `matematika_iz`, `opiraetsya_na`, `bez_opredeleniya_namerenno`, `status` и т. д.) —
других полей этот файл не специфицирует: живой пример полной шапки — докстринг
`_generator/sborka/formaty.py`, парсер поля не выдумывает, а читает как есть.

Формат шапки — flat `key: value`, инлайн-список `[a, b]`, строка в кавычках или без. Тот же диалект,
что у остальных полей карточки (`formaty.py`).

## `tip_verstki` — обязательное, строка

Один из `REESTR` (`_generator/sborka/tipy.py`): `polosa_gorizontalnaya`, `polosa_vertikalnaya`,
`polnyj_ekran`, `tolko_tekst`, `oblozhka`, `vizitka`, `finalnyj`, `razdelitel`, `kompozit` — плюс
отложенные (`ОТЛОЖЕННЫЕ` в `tipy.py`), не собираются. Решение, ПОЧЕМУ выбран именно этот тип, — в
`obosnovanie_verstki` ниже, не в самом значении. Дом решения выбора — `SKILL.md`, ФАЗА 2, п.1.

## `obosnovanie_verstki` — заведено заходом `verstka-v-faze-1`, строка

Обязательно при ЛЮБОМ `tip_verstki`, не только у полосных типов. Свободный текст — почему выбран
именно этот тип, в жанре образцов владельца (`SKILL.md`, ФАЗА 2, п.3): называет объём текста,
нужность иллюстрации и, если решение пограничное, альтернативу, которая не выбрана.

Пример (жанр, не шаблон для копирования; строка одна, без переноса — тот же плоский диалект
`key: value`, что у `zachem`/`akcent`/`centralnyj_blok`, кавычки не нужны):
```
obosnovanie_verstki: текста мало, иллюстрация обязательна — горизонтальная полоса, картинка большая
```

Пусто или отсутствует → `_generator/tools/gejt_verstki.py` красный, поимённо (Д6).

## `zagolovok_na_ekrane` — строка, может быть пустой

Заголовок слайда, если он показывается на экране. Включён по умолчанию (ожидается текст). Пустая
строка легальна ТОЛЬКО вместе с `zagolovok_snyat_namerenno: da` — иначе это забытое поле, не
решение (Д5, `SKILL.md` ФАЗА 1 п.1).

## `zagolovok_snyat_namerenno` — заведено заходом `verstka-v-faze-1`, `da` | отсутствует

По образцу уже существующего в карточке `bez_opredeleniya_namerenno` — тот же приём «намеренно» как
явный флаг сознательного снятия дефолта, не второй словарь имён. Ставится ТОЛЬКО когда
`zagolovok_na_ekrane` пусто и это осознанное решение (например, места на слайде нет). Значение —
буквально `da`; любое другое значение или отсутствие поля при пустом заголовке трактуется гейтом как
«флага нет».

Пусто без флага → `gejt_verstki.py` предупреждение (не красный) — счёт «пусто на N из M» (Д5).

## `illustracii` — обязательное, инлайн-список (может быть пустым `[]`)

Имена иллюстраций из пула лекции (`<лекция>/illustracii/<имя>/`), нормализованные до `stem` файла —
та же нормализация, что `_generator/sborka/slaid.py:load_illustrations` и
`_generator/tools/gejt_illyustracij.py:slide_illustracii`. Пустой список — легально, если тип
вёрстки не полосный (Д2 ниже) и картинка слайду не нужна (`SKILL.md`, ФАЗА 2, п.1).

**Полоса без иллюстрации — запрещена (Д2).** `tip_verstki`, начинающийся на `polosa_`, И
`illustracii: []` одновременно → `gejt_verstki.py` красный, поимённо. Живой случай —
`teorkat-vvedenie/L2/slajdy/izomorfizm`.

Формат заказа за каждым именем (`zakaz.md`, пять полей) — `SKILL.md`, ФАЗА 2, п.4; проверяется
`gejt_illyustracij.py`, не этим гейтом.
