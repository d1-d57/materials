Фикстура захода `kod_graf-zavisimostej.md` (Г2, критерий 2): три термина `A`, `B`, `C`, каждый
определён на своём слайде и в определении пользуется термином, который определён на СЛЕДУЮЩЕМ
слайде — A нужен для B, B нужен для C, C нужен для A. Граф терминов обязан найти цикл `A → B → C → A`
и вернуть `rc=1`.
