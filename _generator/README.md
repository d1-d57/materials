# `_generator` — illustration-aware сборщик слайд-колод

Собирает **папку-источник** (`<lecture>/src/`) в один самодостаточный `index.html`
канона `html-slides-studio`. Обобщение `kurs leto 2026/istochnik/_generator/build.py`
на формат слайд-колод: каждая иллюстрация — отдельный файл, палитра и шрифты — в одном
месте, текст слайдов — markdown. HTML — чистая функция источника; правь источник, не HTML.

Полный контракт и решения — в `DESIGN.md`. Ниже — как пользоваться.

## Команды
```bash
python3 _generator/build_deck.py dandelin/src            # линтер-гейт + сборка → dandelin/src/dist/index.html
python3 _generator/build_deck.py dandelin/src --lint     # только линтер
python3 _generator/build_deck.py dandelin/src --no-banner # без баннера (для byte-exact сверки с оригиналом)
```
Только stdlib — ни pip, ни сети. Выход несёт HTML-коммент-баннер «СГЕНЕРИРОВАНО …
РУКАМИ НЕ ПРАВИТЬ» (не влияет на рендер).

## Рабочий цикл (ради чего всё)
- **Правка текста слайда** → редактируешь `src/content/sNN.md` (markdown) → пересборка.
  Диалект: пустая строка = абзац; `**слово**` = акцент `.acc`; `*слово*` = курсив;
  строки `- ` = список. Меняется только этот слайд.
- **Правка иллюстрации** → редактируешь один файл `src/illustrations/NAME.svg` (или
  `chapters/NAME.html` для 3D-главы) → пересборка. Ничто другое в 2360-строчном файле
  не сдвигается (проверено).
- **Палитра/шрифты** (единый стиль всех иллюстраций) → `src/tokens.css` (`:root{…}`).
  Линтер ловит `var(--x)`, не определённую в токенах (иначе SVG зальётся чёрным).

## Папка-источник `<lecture>/src/`
```
brief.md            фронтматтер: id, title, canvas, slide_order, provenance(sha256)
shablon.html        каркас = оригинал с извлечёнными кусками, заменёнными на {{ПЛЕЙСХОЛДЕРЫ}}
tokens.css          :root — палитра + типографика (единый источник стиля)
fonts/faces.css     @font-face (base64 woff2), дословно
engine.js           блок [4] движок канона, дословно, НЕ править
lib/three.min.js    вшитая three.js, дословно
content/  sNN.md    текст слайдов (markdown) — поверхность быстрых правок
slides/   sNN.html  layout-фрагмент слайда: <section> с зонами, слотом {{MD:sNN}} и data-ill
illustrations/ NAME.svg|.html   по файлу на иллюстрацию (SVG-вектор или base64-растр)
chapters/ NAME.html 3D-главы (документы для iframe), дословно
drivers/  NN.js     анимационные скрипты 3D-сцен, вынесенные из глав
```

## Проверка (гейт «может провалиться»)
Пересборка **рендер-идентична** оригиналу. Доказано без браузера: после снятия
HTML-комментариев и схлопывания пробелов пересобранный `dist/index.html` совпадает
с `dandelin/index.html` **символ-в-символ** (обе нормали = 3 004 501 симв.); все 21
шаблон иллюстраций, 10 3D-глав, 5 шрифтов, 15 растров на месте, список потерь ПУСТ.
Это сильнее скриншот-сверки: на вход рендереру подаётся идентичный DOM.

Глазная попиксельная сверка — на своей машине (в песочнице браузера нет):
```bash
python3 _generator/render.py --compare dandelin/index.html dandelin/src/dist/index.html _render
```
(нужен Chrome + `pip install playwright pillow && playwright install chrome`.)

## Статус
- **dandelin** — распилена. M1: дословно, byte-exact (sha `69812415…`). M2: текст 12/19
  слайдов в `content/*.md`; 7 (тайтл, перебивки, финал, благодарности, визитка) оставлены
  дословным HTML (escape-hatch: верность важнее охвата).
- **buffon** — следующая (M3): та же схема + KaTeX (математика печётся заранее) и
  `lab.js`-симуляции. Снапшот оригинала уже снят в `_snapshots/`.

## Границы
Не переписывает `istochnik`/`spetsmat`. Движок не трогает. Оригинальные `index.html`
не изменяются (только читаются). Снапшоты оригиналов — в `_snapshots/`.
