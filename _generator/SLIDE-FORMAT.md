# Формат текста слайда (`content/*.md`)

Как хранить текст слайда — проще, чем HTML, но с разметкой сцен. Один файл на слайд
(`content/<slide-id>.md`); в `slides/<slide-id>.html` на месте текстовой зоны стоит слот
`{{MD:<slide-id>}}`. Генератор (`build_deck.py`, `render_md`) разворачивает файл в канон-HTML.
Число сцен слайда задаётся `data-scenes="N"` на `<section>` (в `slides/*.html`); теги `{@N}`
ниже ссылаются на эти сцены.

## Правила

| Пишешь | Получаешь | Смысл |
|---|---|---|
| пустая строка между блоками | новый `<p>…</p>` | абзац |
| строка кончается на `\` | `<br>` | жёсткий перенос строки (ты ставишь их сам) |
| обычный перенос строки | пробел | мягкий перенос (браузер и так схлопнул бы) |
| `{@2}` в начале абзаца | `<p data-scene-from="2">` | абзац появляется на сцене 2 |
| `{@2-4}` | `data-scene-from="2" data-scene-until="4"` | виден со сцены 2 до 4 |
| `{@-3}` | `data-scene-until="3"` | виден до сцены 3 |
| `{.note}` (можно `{@2 .note}`) | `class="note"` (+ сцена) | класс абзаца |
| `{@2\| текст}` (инлайн) | `<span data-scene-from="2">текст</span>` | кусок внутри абзаца появляется на сцене 2 |
| `{fill@2\| ____ \| 2/π}` | канон-«шторка» бланк→ответ на сцене 2 | `<span class="fill">…</span>` |
| `{blur@3\| p·N }` | blur-reveal-«шторка», раскрытие на сцене 3 | `<span class="blur-reveal" data-reveal="3">…</span>` |
| `{.bullets}` строкой над списком `- …` | `<ul class="bullets"><li>…` | список с классом (по умолч. `tlist`) |
| `$\boldsymbol{p}$` | готовый KaTeX из кэша `math/katex.json` | формула (TeX как в `<annotation>`; кэш собирает `harvest_katex.py` из колоды) |
| `**слово**` | `<b\|span class="acc">слово</…>` | акцент; тег из `accent_tag` в brief.md (`b` — Dandelin, `span` — Buffon) |
| `*слово*` | `<em>слово</em>` | курсив |
| любой сырой HTML (`<b>`, `<br>`, `<span…>`) | как есть | **escape hatch** — точечно, на кусок |

**Escape hatch** = запасной выход: если кусок слишком хитрый для формата (например обычный
жирный `<b>` без акцента, или нестандартная разметка) — пишешь прямо HTML этого кусочка, он
проходит без изменений. Цель — чтобы это требовалось редко.

## Пример — `sl-plan` (2 сцены)

`content/sl-plan.md`:
```
Разрежем иглу на три равные части. Сложим из\
них треугольник и будем бросать на плоскость\
<b>Сколько</b> (примерно) <b>будет точек пересечения\
треугольников и линий?</b>

{@2} Покрасим стороны треугольников в зелёный,\
жёлтый и оранжевый

{@2} Сначала мы найдём количество пересечений\
линий со сторонами <b>жёлтого</b> цвета\
…
```
→ разворачивается в три `<p>`, второй и третий с `data-scene-from="2"`, все переносы `<br>`
на местах. Пересобранный слайд рендер-идентичен оригиналу (проверено).

## Правки — как это работает в жизни
- «убери слово X на 4-м слайде» → правишь `content/sN.md`, пересборка — меняется одна строка.
- «этот абзац пусть появляется позже, на 3-й сцене» → ставишь `{@3}` перед абзацем.
- «подпись лишняя на рисунке» → правишь `illustrations/NAME.svg` (текст слайда не трогается).
Пересборка: `python3 ../disciplina/_generator/build_deck.py <lecture>/src` — секунды, копейки токенов.
