### Шаг 5. Склейка блоков в микро-сюжеты
Блок должен быть размером **со слайд**, а не с карточку картотеки. Три определения, идущие подряд и ничем не разделённые, — **один** блок «категория · функтор · естественное преобразование», а не три. Определение вместе со своим примером — один блок. Заголовок блока может быть тематическим, а не «Определение 14».

Однородные короткие примеры **группировать в один список**: например «категории, связанные с алгоритмами и процессами» — один блок с перечнем из трёх-четырёх строк, а не отдельный блок на каждую, поскольку ни функторов, ни утверждений про них не будет.

## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
```
git --no-optional-locks add -- teorkat-vvedenie/KONSPEKT-L1/ teorkat-vvedenie/KONSPEKT-L1.md _studio/zhurnal/2026-07-28_konspekt-l1/
git --no-optional-locks commit -m "конспект Л1: 12 вкладок, ярусы, переписанное введение" -- teorkat-vvedenie/KONSPEKT-L1/ teorkat-vvedenie/KONSPEKT-L1.md _studio/zhurnal/2026-07-28_konspekt-l1/
python3 _generator/tools/git_zona.py check --zone teorkat-vvedenie/KONSPEKT-L1
git --no-optional-locks show --stat
```
🔴 **ОБА хода обязательны** (`_studio/docs/kak-delat/GIT-disciplina.md §3`): `add` вводит новые пути в индекс (без него pathspec-коммит даёт `did not match any file(s) known to git`); `-- <пути>` в самом `commit` отсекает чужой индекс — репозиторий общий, писателей трое. *Обе половины оплачены 21.07: голый `commit` подмёл чужое — 89 файлов вместо трёх.*
⚠ **Хук `pre-commit` покраснел — смотри, на ЧЬИХ путях.** Красное на твоих (новый `.md` не зарегистрирован в `KARTA §6`) — это **ожидаемо**: регистрацию делает аналитик, ты её сделать не можешь. Тогда законный обход **с причиной**:
```
python3 _generator/tools/git_zona.py commit --zone teorkat-vvedenie/KONSPEKT-L1 \
    --no-verify "12 новых вкладок ждут регистрации аналитиком, строки сданы в ## ВОПРОСЫ" -m "<что и зачем>" --push
```
**Коммит не прошёл по ВНЕШНЕЙ причине** (чужой лок, конфликт) — чужое состояние не чини: зафиксируй файлы и напиши в отчёт отдельной строкой «коммита нет, причина такая-то». Молчаливое «сделано» при незакоммиченной зоне — брак.
