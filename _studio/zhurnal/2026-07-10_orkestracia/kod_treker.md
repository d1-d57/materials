## 3. ЗАДАЧА — два выхода

**(1) `../_generator/tools/sostoyanie.py`** (stdlib): `python3 sostoyanie.py <папка-лекции>` —
- обходит папку лекции, по КАЖДОМУ гейту из `GEJTY.md` считает PASS/FAIL/WARN по его «признаку-на-диске»;
- печатает таблицу: `гейт · статус · деталь`;
- вычисляет **`⏺ ТЫ ЗДЕСЬ`** = первый ЖЁСТКИЙ гейт не-PASS;
- exit 0, если нет жёстких FAIL (WARN не валит), 1 — если есть;
- **гейты-не-рельсы:** артефакт стадии N+1 при не-PASS гейта N → WARN «прыжок вперёд», НЕ FAIL;
- **дисциплина-хуки** (карточка без источника, источник без дайджеста, висячее ребро в `KARTA-OBLASTI`, открытый `⚑ Флаг`, `slide_order`-сироты) — WARN/FAIL по типу из реестра;
- гейты `src/` — переиспользовать функции `build_deck.py` (импортом/вызовом), не переписывать логику;
- «слайды: нет» в `brief.md` → гейты Фазы II и `src/` помечать «N/A (доска)», не FAIL.

**(2) Формат журнала** — новый файл `konvejer/ZHURNAL.md`: описывает append-only журнал вызовов, строка на сессию/волну:
```
дата · функция · волна# · гейт · результат(PASS|недобор) · время · токены
```
(его дописывает драйвер/аналитик после сессии; физически лежит в `<лекция>/dnevnik/zhurnal.md` или в `SESSIYA.md` — реши и зафиксируй, отрази форму в `ZHURNAL.md`). `sostoyanie.py` при наличии журнала: (а) печатает последовательность вызовов; (б) **сверяет журнал↔диск** — строка говорит PASS, а аудит гейта FAIL → флаг `⚠ молчаливый недобор`. Это ядро ценности.

**КРИТЕРИЙ ГОТОВНОСТИ (может провалиться):**
- `python3 sostoyanie.py <папка от bootstrap_lekcia.py --slides no>` печатает гейты Фазы I как pending/FAIL, `ТЫ ЗДЕСЬ = бриф`, exit 1.
