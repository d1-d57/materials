**Решение по разбивке.** 4 захода, 2 волны по 2 параллельно (①∥② → ③∥④). Файлы заходов не пересекаются; `KARTA §6`-регистрацию делает Cowork между волнами (заходы её не правят — иначе параллельный конфликт). Тяжёлая сборка — Claude Code (свежий контекст); Cowork держит стратегию, роя субагентов не разводит.

**Открыто (на закрытие/по факту прогонов).** Точные имена (`GEJTY.md`, `KATALOG.md`, `ZHURNAL.md`, `_generator/tools/`) — предложены в заходах, финал по факту.
