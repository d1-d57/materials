## Концепция — что строим
Достроить **ОБЁРТКУ** вокруг уже готового конвейера (не содержание лекций). 4 грани ОДНОЙ вещи:
- **(a) трекер состояния** = журнал вызовов + аудит диска (диск = правда, ловит молчаливый недобор);
- **(b) единый спинной `ALGORITM`** на ОБЕ фазы + **реестр гейтов** `GEJTY.md` (сейчас ALGORITM только 6→10);
- **(c) каталог функций** «инструмент-под-задачу» (станции + микрофункции); skill-файлы НЕ заводим (Р17);
- **(d) бутстрап папки лекции** — одна папка, всё по ролям, слайды опциональны.

Цель — сквозная процедура идея→публикация, по которой идётся просто/быстро/**дёшево по токенам** (сессия = один вызов функции на пустом контексте). Согласовано с владельцем 2026-07-10. **НЕ прогон #14.**
