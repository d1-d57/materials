## §Каталан — микрофункции из живых прогонов (готовое сырьё, не переоткрывать)
- **скачать источник:** curl PDF → имя `Автор — Название (id/год).pdf` (авторы со страницы arXiv abstract, не выдумывать) → подпапка → строка в `MANIFEST`+`SPISOK`
- **извлечь текст из PDF:** `pdftotext`/`pdfplumber`, НЕ листать картинками — предусловие любого чтения
- **дайджест `VYCHITANO`:** «что ЕСТЬ / чего НЕТ / стр. / уровень»; правило «источник без дайджеста = не читан»
- **карточка-узел** (STANDART-uzla): находка + связи + указатель источника; правило «находка без карточки = потеряна» — **авто-хук**
- **индекс `KARTA-OBLASTI`:** резолвит каждый id; висячее ребро = дефект — **авто-хук**
- **`verify_*.py`:** численно сверить тождество на малых n (напр. рекуррента, вставка листа)
- **tar-снапшот** перед мутацией — **авто-хук** (перед правкой)
- **extract конструкции** (read-only): вынуть биекцию/пример + вердикт о «школьности» (отрицательный результат валиден)
- **бэкфилл дайджестов:** механически из старых отчётов, ноль выдумки
- **переупаковать проработанное** → скелет по актам
- **расширить HTML:** текст ×3–4, типографика, боковое оглавление, плейсхолдеры под картинки (SVG рисует аналитик, не Code)
- **сборка/нарезка карты** детерминированным скриптом (общий HTML → N лекций)
- **сверка `ls`↔`MANIFEST`** (0 сирот)
