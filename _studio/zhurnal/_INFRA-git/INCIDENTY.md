# INCIDENTY — сырые симптомы неуспешных коммитов (пишет сам git_zona.py)

> Входящая корзина, НЕ журнал уроков: при каждом неуспешном `commit`
> инструмент САМ дописывает сюда строку — в любом чате, без просьбы.
> Руками строки не заводятся. Разобранное переносится в `ZHURNAL.md`
> уроком с ЦЕНОЙ; здесь у строки статус меняется на `→ ZHURNAL`.
> Формат: `- дата время · ветка · симптом · → подсказка · статус`.
