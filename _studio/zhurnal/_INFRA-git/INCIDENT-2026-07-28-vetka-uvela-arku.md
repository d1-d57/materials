# ИНЦИДЕНТ 2026-07-28 — переключение ветки увело двухдневную работу, и никто не заметил

> Текст для чата коммит-дисциплины. Требуется **изменение инструмента**, не правило прозой.
> Обнаружено владельцем глазами; автоматика молчала.

## Что случилось

Ночью 28.07 в 02:57 рабочее дерево переключили с ветки `zahod/dek-paskal-v2` на `arka/mat-kostyak`:

```
02:34  последний коммит арки Л1 («арка закрыта: шкала актуализирована…»)  → zahod/dek-paskal-v2
02:57  checkout: moving from zahod/dek-paskal-v2 to arka/mat-kostyak
03:33  первый коммит захода tool-contract                                  → arka/mat-kostyak
```

На ветке `zahod/dek-paskal-v2` осталось **19 коммитов двух арок** — вся сборка лекции 1 по теории категорий (два дня работы, 7 разделов плана) и вся арка дека Паскаля. На `arka/mat-kostyak` их нет и не было.

**Что увидел владелец утром:** файл `_studio/zhurnal/2026-07-28_teksty-l1/KARTA-KUSKOV.md` — 159 строк вместо 574. Пять файлов арки отсутствовали целиком (`INVENTAR-L1.md`, оба ТЗ, два хэндоффа). Выглядело как удаление данных.

**Данные не терялись.** Восстановлено штатно: `adopt --branch zahod/dek-paskal-v2 --zone _studio --yes`, затем `commit --zone _studio` → `1038d24`, 38 файлов, 3688 вставок. Всё на месте.

## Почему это опаснее, чем кажется

**Это не пропажа, а тихая подмена.** Файл остался на месте, открывается, внутренне непротиворечив — просто это его версия двухдневной давности. Владельца спас только размер расхождения (159 против 574). При разнице в один раздел он бы не заметил, а следующий агент, получив адрес файла, честно доложил бы по тому, что видит, — и был бы прав относительно видимого.

## Почему ни один гейт не сработал

1. **`INCIDENTY.md` ведётся автоматически, но только по НЕудачным коммитам.** Здесь все коммиты прошли успешно — каждый в своё время, на своей ветке. Событие «работа успешно закоммичена не туда, где её будут искать» инструментом не отслеживается вовсе. В файле про 28.07 нет ни строки.
2. **`doctor` показывает текущую ветку и что вне git, но молчит про соседние.** Он не задаёт вопрос «нет ли моей зоны на другой ветке в более свежем виде» — а это единственный вопрос, который вчера спас бы два дня.
3. **Имя ветки не совпадало с содержанием.** Работа по теоркату легла на ветку, названную по деку Паскаля, потому что две линии работы шли на одной ветке. При переключении вторая линия ушла из виду молча.

## Что требуется сделать — конкретно

**Гейт в `doctor`, красный, на входе в каждую сессию.** Для каждой зоны вида `_studio/zhurnal/<арка>/` сравнить дату последнего коммита, тронувшего её на текущей ветке, с максимумом по остальным веткам. Если на чужой ветке зона новее — печатать громко, с готовой командой:

```
🔴 ЗОНА ОТСТАЁТ ОТ СОСЕДНЕЙ ВЕТКИ
   _studio/zhurnal/2026-07-28_teksty-l1
   здесь:  b93d112  27.07 12:33
   там:    6da92fd  28.07 02:34   (ветка zahod/dek-paskal-v2, +19 коммитов)
   → python3 _generator/tools/git_zona.py adopt --branch zahod/dek-paskal-v2 --zone _studio
```

**Три требования к реализации:**

- **Гейт обязан объявлять охват.** Это общий урок дня, выведенный отдельно: зелёный результат без указания, сколько единиц проверка НЕ смотрела, читается как «всё в порядке», хотя означает «в порядке то, что я смотрел». `doctor` сегодня честно смотрит одну ветку и молчит, что веток девять.
- **Проверка read-only и не берёт `.git/index.lock`.** Сравнение по датам коммитов, без обращения к индексу.
- **Срабатывает автоматически в `doctor`**, а не отдельной командой, которую надо вспомнить. Вспоминают только то, что уже болело.

**Дополнительно, дешёвое:** при `checkout` на другую ветку — если на покидаемой ветке есть коммиты, которых нет на целевой, сказать об этом вслух в момент переключения. Тогда инцидент не случился бы вовсе.

## Как проверить, что починка работает

Воспроизводится за минуту: закоммитить что-нибудь в зону на ветке A, переключиться на B, запустить `doctor`. Пока он не краснеет — гейта нет.

- За всю историю проекта **19 переключений веток**; коммиты разошлись по шести веткам (`arka/mat-kostyak` 150, `teorkat-istochniki` 94, `buffon-zahod-01` 46, `zahod/dek-paskal-v2` 19, `fibonacci-l1` 18, `main` 1). Опасный переход — «накоммитили и ушли, не забрав» — за всю историю **один**, вчерашний. Систематической потери в прошлом нет.
