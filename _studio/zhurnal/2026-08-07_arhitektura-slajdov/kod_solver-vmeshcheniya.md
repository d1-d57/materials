### Э2. Измеритель вмещения — один браузер на слайд, перебор внутри страницы

🔴 **Это ядро захода.** Помещается текст или нет, знает только браузер: зависит от метрик шрифта,
места разрыва строки, высоты формул. Питон сам не вычислит. Но поднимать браузер на каждую пробу
дорого — поэтому:

**браузер стартует ОДИН раз на слайд, а перебор идёт внутри страницы на JS.** Скрипт меняет
CSS-переменные в живом документе и читает, вылезает ли содержимое за край зоны
(`scrollHeight > clientHeight`). Одна проба — доли миллисекунды.

Выход: функция, которой дают слайд и набор кандидатов, а она возвращает для каждого — влезло или
нет, и насколько заполнена зона.

### Э3. Солвер — ищет лучшее из влезающих, а не первое попавшееся

Ручки (из Я1): **у слайда** — `liniya`, кегль по умолчанию, межстрочье по умолчанию;
**у блока** — кегль, межстрочье, отступ после блока.

Два правила, которые делают перебор коротким:
- 🔴 **вмещение МОНОТОННО по кеглю** (меньше кегль — помещается не хуже) ⇒ бинарный поиск,
  5–7 проб вместо сотни. То же с межстрочьем;
- диапазоны известны замером: межстрочье 1,24–1,44 · отступ блока 14–20px · кегль — из живых деков.

🔴 **Целевая функция, иначе солвер найдёт мелкий шрифт и остановится.** Критерий владельца
дословно: «чтобы с одной стороны дышало, с другой — не слишком много свободного места, и чтобы не
слишком мелко». Формализовать как: заполнение зоны **75–90 % высоты** · кегль не ниже порога ·
среди влезающих выбирается **самый крупный**.

Не сошлось даже на минимуме — солвер **не решает сам**, а возвращает отказ с числами: сколько
пришлось бы срезать. Резать текст, делить слайд или заменить слова иллюстрацией — содержательное
решение, оно принадлежит человеку.

⚠ **Чего в этой версии НЕ делать:** висячие строки, разорванные формулы, одинокое слово в конце

## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- `_generator/sborka/**` `_generator/skeleton/**` `_generator/tools/fixtures/sborka/**`                     # вводит НОВЫЕ пути в индекс
git --no-optional-locks commit -m "<зона>: <что сделано>" -- `_generator/sborka/**` `_generator/skeleton/**` `_generator/tools/fixtures/sborka/**`   # отсекает всё чужое
python3 _generator/tools/git_zona.py check --zone <зона>   # из корня репо; должен быть ✅
git --no-optional-locks show --stat                        # обязаны быть ТОЛЬКО твои пути
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*
