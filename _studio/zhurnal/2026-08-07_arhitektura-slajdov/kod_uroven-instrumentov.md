### Шаг 2. Разметить каждый уровнем — четыре значения

Добавить в таблицу реестра колонку **`УРОВЕНЬ`** со значением из четырёх. **Ось — не «насколько
инструмент универсален», а ЧТО ИМЕННО ОН ЗНАЕТ:**

| значение | инструмент знает про… | и потому переносится… |
|---|---|---|
| **МЕТА** | ведение работы: заход · арка · дом · урок · инцидент · долг · очередь · git · реестр документов | во ВСЕ проекты владельца без изменений — они все на этой дисциплине |
| **КОНТЕНТ** | материал: лента · лекция · термин · вес темы · курс · источник | в проекты, где производится содержание (ресёрч, курс, лекция без слайдов) — но не в те, где его нет |
| **СЛАЙДЫ** | дек: карточка слайда · тип вёрстки · кегль · полоса · иллюстрация на слайде · HTML-сборка | никуда — прибит к слайдам |
| **СПОРНО** | — | по коду не решается; законное значение, не признак лени |

🔴 **Разметка вида «назови понятие» — не «поставь ярлык».** Для КАЖДОГО инструмента ты обязан
назвать **одно понятие, при потере которого он становится бессмысленным**, и уровень следует из
понятия механически:
- потеряли **заход / арку / дом / урок / долг / git** → МЕТА;
- потеряли **ленту / лекцию / термин / курс** → КОНТЕНТ;
- потеряли **карточку / вёрстку / кегль / дек** → СЛАЙДЫ.

Понятие пиши в ту же колонку рядом с уровнем, одним словом. *Так вердикт становится оспоримым:
владелец сможет не согласиться с понятием, а с голым ярлыком спорить не с чем.*

**Вычислимое ПЕРВОЕ приближение — два грепа, а не один.** Они сортируют, решает докстрока.
```
grep -ciE 'zahod|arka|arki|dom[ao]|urok|dolg|ochered|git|KARTA|incident' <файл.py>   # сигнал МЕТА
grep -ciE 'slaid|slajd|kartochk|verstk|kegl|polosa|deck|dist/|illustrac' <файл.py>   # сигнал СЛАЙДЫ
```
Оба нуля — почти наверняка КОНТЕНТ. Оба ненулевые — самый интересный случай: инструмент **живёт
на двух уровнях сразу**, и это находка, которую надо назвать поимённо в отчёте, а не гасить
выбором одного ярлыка. Именно такие мешают разрезать скиллы.

🔴 **Разошлись греп и докстрока — верь докстроке и скажи об этом в отчёте с именем файла.**
Инструмент может не поминать слайдов и быть про них; может помянуть их одной строкой в примере и

## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- _studio/konvejer/KARTA-ZHIVOGO-KONVEJERA.md                     # вводит НОВЫЕ пути в индекс
git --no-optional-locks commit -m "<зона>: <что сделано>" -- _studio/konvejer/KARTA-ZHIVOGO-KONVEJERA.md   # отсекает всё чужое
python3 _generator/tools/git_zona.py check --zone <зона>   # из корня репо; должен быть ✅
git --no-optional-locks show --stat                        # обязаны быть ТОЛЬКО твои пути
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*
⚠ **Хук `pre-commit` покраснел — сначала посмотри, на ЧЬИХ путях.**
- Красное на ТВОИХ путях (новый `.md` не зарегистрирован в `../../docs/KARTA.md §6`, битая ссылка) — **чини, не обходи**: там только твоё, обходить нечего.
- Красное на ЧУЖОМ, унаследованном долге (ворота дают сотни ❌ старых нарушений) — законный обход, но ТОЛЬКО с причиной; голый `--no-verify` инструмент отклонит, а причина сама уедет в `INCIDENTY.md`:
```
python3 _generator/tools/git_zona.py commit --zone <зона> \
    --no-verify "чужой долг: <что именно покраснело>" -m "<что и зачем>" --push
```
Ту же причину назови отдельной строкой отчёта долгом. *Урок 9: обход был законен по канону и не существовал в инструменте — первый же коммит владельца встал на чужом долге.*
**Коммит не прошёл по ВНЕШНЕЙ причине** (чужой лок, конфликт, detached HEAD) — чужое состояние репозитория НЕ чини: зафиксируй файлы и напиши в отчёт отдельной строкой «коммита нет, причина такая-то, нужно ваше действие». Это законный отчёт. Молчаливое «сделано» при незакоммиченной зоне — брак: приёмка гоняет тот же гейт первым ходом и завернёт отчёт, не читая (`RUKOVODSTVO §Приёмка`, гейт 0).
