```bash
cd _studio/zhurnal/2026-07-20_teorkat-motivacia
grep -n '^#' PERECHOT-kataloga.md                      # карта секций → 22 заголовка
awk 'NR>=10 && NR<=18 && /^[0-9]+\. /' PERECHOT-kataloga.md | wc -l   # КОРЗИНА A → 5
awk 'NR>=22 && NR<=31 && /^[0-9]+\. /' PERECHOT-kataloga.md | wc -l   # КОРЗИНА C → 8

awk 'NR>=348 && NR<=394 && /^- /'      PERECHOT-kataloga.md | wc -l   # СПОРНЫЕ → 39
grep -c '^- ' PERECHOT-kataloga.md                     # все буллеты файла → 307
grep -n '800' PERECHOT-kataloga.md                     # → ПУСТО, строки «800» в файле нет
```

**Пустые и почти пустые области — и что это значит.**

- **`теория-категорий` = 0.** Это не дыра, а работа критерия: перечёт по построению выбрасывал всё, где приз — понимание самой ТК. Ожидаемо и правильно; замечаю только чтобы не приняли за потерю.
- **`методика-курса` = 0.** Дыра **нашей слепоты именно в этом файле**: PERECHOT читал два источника как склад математических примеров, и любой узел про сам курс (темп, бюджет, «глава ≠ лекция») попадал в 780 «мимо-критерия» без следа. - **`геометрия` = 4 из 242 — настоящая дыра, и самая болезненная.** Бриф прямо велит брать энергию из уже красивых полей (геометрия, дифгео, Ли), а каталог даёт ровно четыре геометрические строки, из них ко мне прошла одна (`metricheskoe-est-kategoriya`). - **`физика` = 3.** Дыра **предмета под этим потолком**: естественная физическая история в ТК — TQFT и кобордизмы, а это моноидальные категории, то есть за потолком (карточка `kobordizmy-kameo` в «спорных» ровно про это).
