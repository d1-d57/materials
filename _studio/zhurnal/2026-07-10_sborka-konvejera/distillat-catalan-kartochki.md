# Дистиллят: карточная память «Каталана» — грунтовка редизайна верхней части Фазы I

> Заход с пустым контекстом. Прочитаны ТОЛЬКО: `catalan/spravochnik/{STANDART-uzla,KARTA-OBLASTI,_seed-kb}.md`, `TERMINY-russkie.md`, `spravochnik/stati/{mir1-nit-3,mir1-obiekty,mir2-obiekty,mir1-nahodki}.md`, `zhurnal/2026-07-05_mir1/zamechaniya-disciplina-kartochek.md`, `kurs/{mir1-rasskaz,mir1-skelet}.md`, `biblioteka/` (только ls). Рамка — `_studio/docs/spravka/FAZA-1-REDESIGN.md`.

## 1. Карточка-узел

Формат (`STANDART-uzla.md`), 5–10 строк, рабочая память АГЕНТА (не для владельца):
```
id · род (объект|утверждение|биекция|мостик|затравка) · суть (1 строка)
находка: <1-3 фразы — связь/удивительный несущий момент, НЕ определение>
связи: [id →/↔ однофразное «почему»]
уровень: школьно | требует-приручения | вне-школы
источник: <файл §/стр>
статус: seed | черновик | готово
```
Прямой запрет: определения, полные конструкции биекций, разборы примеров, «методика у доски» — всё восстановимо по `источник`, не дублируется. Правило: «если строку можно убрать и мысль восстановима по указателю — убрать». На практике род шире пяти канонических: встречаются `находка`, `выход`, `объект/находка`-гибрид (`stat-area-depth · находка`, `vyhod-k-blujdaniyu · выход`, `kunst-s-catalan · объект/находка`).

Лёгкая сестра-формат — «объекты-ручки» (`stati/mir1-obiekty.md`, `mir2-obiekty.md`): `id · род · суть · счёт · источник`, одна строка, без находки/связей/уровня/статуса — чистый указатель, чтобы резолвились `связи` ДРУГИХ карточек (`obj-put-dika`, `stat-area`).

Особый каталожный формат (`stati/mir1-nahodki.md`, исключение в STANDART): добавлена строка `простыми словами:` — этот файл владелец реально читает и отбирает по нему материал в курс; базовые узлы-память остаются терсными.

Примеры-якоря (не пересказаны целиком): `most-drevo-cikl-lemma` — статус ПОДТВЕРЖДЁН, стержень курса; `zadacha-bricklayer-opt` — статус «опция/на переформулировку» (владелец не понял условие — карточка не удалена, а припаркована); `kunst-s-catalan` — статус «кунсткамера» (владелец решил «обобщения не нужны» — понижена, не стёрта).

## 2. Граф/карта связей

`KARTA-OBLASTI.md` резолвит КАЖДЫЙ `id` (суть одной строкой) + группирует по роду (доказательства формулы / модели / биекции между моделями / вероятностные сюжеты / Мир1 и Мир2 отдельно). `id`, упомянутый в чьих-то `связи` и отсутствующий в карте — «висящее ребро».

Второй слой — **нить**: именованный УПОРЯДОЧЕННЫЙ маршрут (затравка → … → кульминация → выход); узлы — бусины, `связи` — локальные рёбра, нить — глобальная сборка в сюжет. Узел вне всех нитей — «мёртвый груз» (привязать или удалить). Хранение: файл на нить (узлы в порядке сюжета — файл сам читается как нить, напр. `stati/mir1-nit-3.md`) + общий файл объектов-ручек на мир.

Конкретно: Мир2 — 4 нити (A пути, B деревья с двумя доказательствами разной доступности — `bij-knuth` изящное / `bij-shin` без сэндпайлов, C доказательства Кэли Прюфер/Жуаяль/Питман, D «не сюжет, набор мостов»). Мир1 — 4 нити-лекции (Л1 балансир-only, Л2 голоса/отражение, Л3 цикл-лемма СТЕРЖЕНЬ, Л4 блуждание) + нить S «сквозная, не лекция», вплетённая в остальные. Группы нитей несут throughline/ABT прямо в карте (Мир1: «одно число — много языков… переход в несбаланс отсеивает случайные красоты от настоящих идей»).

«Шарнир» — узел/статистика между половинами (напр. `area` Мир1↔Мир2) — карта явно предупреждает «ДВА моста разной силы, не схлопывать». По сути это доска детектива со стикерами и нитками: карточки сами по себе — куча (дословно в STANDART: «узлы сами по себе — куча»), карта+нити превращают кучу в читаемое расследование.

## 3. Дисциплина карточек

`zamechaniya-disciplina-kartochek.md` (надиктовка владельца, 2026-07-05): написание карточек должно стать СТАНДАРТОМ и работать как автоматический хук после каждого ресёрча/нового вывода; то же — для записи скачанной литературы. Несоблюдение названо «большой проблемой», требующей закрепления в документации проекта как обязательное.

`STANDART-uzla.md` уже впитал это: раздел «КОГДА (обязательно, авто-хук)» — карточка пишется ТЕМ ЖЕ ходом, не откладывается до консолидации в конце арки; гейт-мантра **«находка без карточки = потеряна»**. Программная проверка `tools/check_docs.py` заявлена, но в очереди (не построена).

Другие правила/ловушки: `id` стабилен (переименование рвёт входящие рёбра); новый узел без строки в KARTA-OBLASTI — сирота; компактность — цель, не побочка («база должна помещаться в один взгляд, а не пересказывать источники»). Практика добавляет две дисциплины сверх STANDART: (а) понижать, не удалять — правки владельца («обобщения не нужны») уводят узлы в «кунсткамеру», а не стирают — сохраняется след «проверили и отклонили», не перересёрчивается; (б) честность развилки — открытые несогласия литературы фиксируются как явный «на сверку» узел (`otkrytoe-area-inv-soglashenie`, спор 231 vs 312), а не тихо разрешаются. Параллельный механизм уже на уровне SKELET (не карточки): **⚑ Флаг → Флаг закрыт** — напр. §1.6 `mir1-skelet.md`, авторский (не дословно цитируемый) перенос доказательства на новую модель, честно помечен «не цитата», проверен вручную для малых n и закрыт только после программной верификации (`spravochnik/verify/verify_tree_leaf_insertion.py`, n≤4).

## 4. Компоновка rasskaz ‖ skelet

`mir1-rasskaz.md` — непрерывная смысловая линия, «process-first» (каждый объект — из конкретной задачи, ничего не падает с неба), 5 актов (§0–§5), ДО стилевого гейта `russian-editor`; закрывается блоком «Пометки для сборки (не часть рассказа)» — throughline/ABT, прозрения по актам, граф зависимостей актов, честная разметка «полностью/эскизом/за кадром», черновая разбивка акт→лекция.

`mir1-skelet.md` — строгий мат-текст, ЯВНО наследующий порядок rasskaz («Логика и порядок — из `kurs/mir1-rasskaz.md` (5 актов); здесь — строгость»): те же §, сквозная нумерация определений/утверждений по всему файлу, КАЖДЫЙ сегмент закрывается строкой `Источник:` + меткой уровня (школьно/со звёздочкой/вне-школы) — это поля карточки `источник`+`уровень`, развёрнутые в прозу и несомые дальше как inline-провенанс (не классическая сноска).

Важный нюанс для редизайна: эта вилка происходит ПОСЛЕ того, как линия уже выбрана (skelet порядково привязан к rasskaz) — это НЕ целевой «двух-котловой» разрез. В «Каталане» два текста — это (читаемая история) vs (строгость ТОЙ ЖЕ истории), а не (математический каталог) vs (научпоп-каталог), написанные независимо до всякой линии.

## 5. Роль источников/biblioteka (только ls)

`process/` — постатейные промпты для ресёрч-агентов (`prompt-inflation-on-dyck.md`, `prompt-two-proofs-detailed.md`, HANDOFF/PROMPT); `istochniki/knigi/` — 5 якорь-книг (Stanley *Catalan Numbers*, Aigner–Ziegler *Proofs from THE BOOK* RU, Ландо, Спивак, Loehr); `istochniki/konspekty/` — университетские конспекты, включая полный постатейный набор MIT 18.212; `istochniki/stati-obzory/` — ~40 отдельных arXiv-статей, по одной на конкретную биекцию/результат, которую цитирует карточка; плюс `MANIFEST.md` (реестр), `VYCHITANO.md` (дайджест по каждому источнику — обязательная первая остановка перед веб-поиском, по `TERMINY-russkie.md`), `SPISOK-skachat.md` (очередь на закачку).

Конвейер сжатия по косвенным следам во всех файлах: сырой PDF → дайджест `VYCHITANO.md` → `_seed-kb.md` (всё ещё многословный, с псевдокодом и таблицами верификации — потому что ИЗНАЧАЛЬНО писался для другого продукта, интерактивного сайта-визуализатора биекций, и лишь позже переиспользован как матбаза курса — это переиспользование, не шаблон для копирования) → терсная карточка STANDART → карточка занимает место в файле-нити → `KARTA-OBLASTI` индексирует → rasskaz/skelet цитируют seed-kb/nahodki/ideas по разделам в замыкающей строке `Источник:`.

## 6. Маппинг на редизайн Фазы I (02–03)

Карточный граф (STANDART-uzla + KARTA-OBLASTI + stati/*) — это рабочая, обкатанная реализация именно того, что FAZA-1-REDESIGN называет абстрактно выходом Стадии 2 — «карта сюжетов по теме, ещё БЕЗ единой линии» (плавильный котёл). Переносим напрямую:
- формат карточки (id·род·находка·связи·уровень·источник·статус), 5–10 строк, память, не проза;
- двухслойность карта+нить (карта резолвит id; нить = упорядоченный сюжетный маршрут; непривязанный узел = мёртвый груз) — даёт Стадии 3 (нарратив) буквальный механизм «пройти/собрать нить по карте» вместо неопределённого «вытащить линию»;
- хук «карточка тем же ходом» + «находка без карточки = потеряна» как обязательную гигиену Стадии 2 (сейчас в редизайн-документе не прописано);
- общий словарь состояний: уровень (школьно/требует-приручения/вне-школы), статус (seed/черновик/готово/ПОДТВЕРЖДЁН), понижение в «кунсткамеру», бакет «на сверку», ⚑Флаг/Флаг закрыт для авторских (не цитатных) результатов до верификации.

Адаптировать, не копировать один-в-один: карточный граф «Каталана» де-факто ОДИН математический граф с наративной куратор-меткой поверх («несущие» находки, слой «простыми словами» — это глосса-перевод математических узлов, а не отдельная популяция карточек истории/людей/приложений). Целевая модель требует настоящего разреза на два котла (математика: «каждый шаг из логичного вопроса»; научпоп: «каждый факт — маленькая законченная история») — решение не показано в прочитанном, нужно явно выбрать: либо два параллельных набора карточек с одной картой-индексом и тегом котла, либо добавить поле «котёл» в `род`. Слой объектов-ручек (`obj-*`/`stat-*`) стоит перенести как есть — удобный паттерн для общих объектов, на которые ссылаются несколько нитей.

НЕ тащить: многословность `_seed-kb.md` уровня «псевдокод для реализации» — артефакт её изначального чужого назначения, не шаблон для нового пре-карточного слоя; и сам прецедент «карта Мира 1 ещё не нарезана — задача #7» — полезный прецедент, что карточки-каталог-без-нитей — нормальное непринудительное промежуточное состояние, ранним пакетам Фазы I не нужно форсировать нарезку нитей до того, как котёл достаточно наполнен.

Явная развилка для редизайна: роль `mir1-skelet.md` как «строгого мат-текста» стоит ПОСЛЕ выбора нарратива (порядково привязана к rasskaz) — структурно другой артефакт, чем пред-нарративный «математический» документ Стадии 2 (который обязан оставаться порядково свободным/исследовательским). Не переименовывать одно в другое, несмотря на общую вывеску «строгий мат-текст».
