# Верификация стыка C (base.css) — независимый проход

Дата прогона: 2026-07-10. Верификатор: свежий контекст, без опоры на предыдущие пересборки.

## Метод

Правка C — вынос общего base-CSS в отдельный `base.css`, а в `shablon.html` на его
месте плейсхолдер `{{BASE_CSS}}`. Цель проверки — доказать, что собранный дек не
изменился ни на байт.

Труп-истина берётся **не** из рабочей копии и **не** из свежей «контрольной»
пересборки, а из закоммиченного `dist/index.html`, извлечённого прямо из
zip-бэкапа `_backup_infra_20260710-043240.zip` (собран ДО правки, С баннером).

- **Оригинал (истина):** `dandelin/src/dist/index.html`, `buffon/src/dist/index.html` из zip.
- **Пересборка:** `python3 _generator/build_deck.py <copy_src> -o <deck>_rebuilt.html`
  по модифицированным копиям (с уже вынесенным `base.css`), **с дефолтным баннером**
  (без `--no-banner`).
- **Нормализация** (одинаковая для обоих файлов, на Python `re`):
  1. удалить все HTML-комментарии `<!-- … -->` (non-greedy, DOTALL — в т.ч. баннер и многострочные);
  2. схлопнуть межтеговые пробелы: `>` + `\s+` + `<` → `><`;
  3. обрезать ведущие/замыкающие пробелы.
  Содержимое внутри тегов (CSS/JS/base64) не трогается.
- **Сверка:** sha256 нормализованного оригинала vs нормализованной пересборки,
  плюс независимая страховка через `cmp` нормализованных байтовых файлов (exit 0 = совпало).

Метод отличается от «cmp двух свежих пересборок»: сравнивается закоммиченный
артефакт из бэкапа против пересборки модифицированного src.

## Размеры файлов (байты)

| Дек | оригинал raw | пересборка raw | оригинал норм. | пересборка норм. |
|-----|-------------:|---------------:|---------------:|-----------------:|
| dandelin | 3 020 201 | 3 020 201 | 3 016 204 | 3 016 204 |
| buffon | 2 821 731 | 2 821 731 | 2 819 169 | 2 819 169 |

Примечание: raw-размеры оригинала и пересборки совпадают точь-в-точь — то есть
дек идентичен байт-в-байт даже ДО нормализации (баннер и комментарии тоже
совпали). Нормализация снимает комментарии/межтеговые пробелы и подтверждает
равенство ещё и на нормализованном уровне.

модифицированного src; `cmp` вернул exit 0. Список расхождений пуст — гейт зелёный.
