## 3. 🎯 ЗАДАЧА ЭТОЙ АРКИ — три шага, в этом порядке

**Шаг 1. Карта ~10 микроарок.** Владелец: *«наша лекция будет состоять из таких микроарок, где какая-то мысль начинается, заканчивается, подхватывается другая»*. Сшить `PUL` (внутренняя математика) с 21 сюжетом: у каждого куска — своя мысль, своя мотивация, свой материал.

**Шаг 2. Сквозные линии — ДО текстов.** Иначе десять текстов не сошьются. Три линии корпус уже дал (`BYUDZHET §5`):
- лестница «изоморфизм есть, канонического нет» → «формула без выбора» → «$V$ и $V^*$» — единственная, проходящая насквозь;
- «прообраз в начале» → «Стоун в финале» — вход и финал одним разворотом стрелки;
- ретрактный приём через три куска.

Отметить, какой кусок какую подхватывает и что передаёт дальше.

**Шаг 3. Тексты — ПО ОДНОМУ.** Владелец: *«длинный текст сложно редактировать; лучше с разными текстами работать и по очереди их собирать»*. Каждый кусок — отдельная вкладка (`tab:` в шапке, движок `build_doc.py` уже это умеет и краснеет на пустом ярлыке).

## 4. 🔴 Единицы измерения — не слайды

**Кусок = 5–15 минут. Слайд производен от куска**, иногда один на весь кусок. Образцы калибровки от владельца: кобордизмы — 1 слайд, 3 минуты, без диалога с залом · ретрактная связка — 1 слайд с несколькими сценами, ~10 минут (объяснили подробно → быстро → просто назвали теорему).

Оценка «22–28 слайдов при бюджете 26» из `BYUDZHET §8` **отменена владельцем** — планировать по ней нельзя.

## 5. Что блокирует и требует решения владельца

- 🔴 **Вход не выбран.** Кандидат найден (прообраз против образа, $X\mapsto 2^X$) и отложен сознательно. Другие кандидаты: «сравнить не считая» · комбинаторные виды. **Карта начинается с входа — дальше откладывать не выйдет.**
- 🔴 **Три классификации НЕ сверены** — определитель, Фробениус, Шур–Вейль. Несверено ровно то утверждение, которое делает их теоремами. **До сверки в лекцию нельзя.**
- 🔴 **Конструкции категорий выпали** из разбора (произведение, факторкатегория, слайс, скелет, группоид) — они внутренние, а разбирался внешний корпус. Вплести при сборке карты по правилу `PUL §0.5`: конструкция появляется там, где появился просящий её пример.
- **Единый язык для «формулы без выбора»** не найден — найдётся, сюжет из трёх примеров станет теоремой блока.

## 6. Ловушки — на чём предшественница спотыкалась

- **Аналитик трижды заявил ОТСУТСТВИЕ без проверки по живым файлам** («зал из комбинаторики», «$\chi$ — функтор», «конспекта Василия нет»), все три неверны, все поймал владелец. Правило внесено в `KONSTITUCIYA` п. 10: отрицательное утверждение = производный факт, команда рядом или формулировка «я не нашёл».
- **Владелец корпус не помнит.** Одно имя сюжета = потерянный ход. Разворачивать содержание, и обязательно — **где тут категорный язык и каким словом**.
- **Просуд большого списка одним ходом отвергается.** Порция 5–8, сильное вперёд.
- **Фильтр по роду карточки — лоссовая операция.** Объявлять как объявляется охват.
- **Durable в дневник не кладут.** Решение → в дом тем же ходом; урок фабрике → сразу в `UROKI-FABRIKE.md`, в дневнике только ссылка.
