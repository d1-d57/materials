## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- teorkat-vvedenie/KONSPEKT-L1.md _studio/zhurnal/2026-07-28_teksty-l1/kod_skelet-konspekt-l1.md                     # вводит НОВЫЕ пути в индекс
git --no-optional-locks commit -m "<зона>: <что сделано>" -- teorkat-vvedenie/KONSPEKT-L1.md _studio/zhurnal/2026-07-28_teksty-l1/kod_skelet-konspekt-l1.md   # отсекает всё чужое
python3 _generator/tools/git_zona.py check --zone <зона>   # из корня репо; должен быть ✅
git --no-optional-locks show --stat                        # обязаны быть ТОЛЬКО твои пути
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*
⚠ **Хук `pre-commit` покраснел — сначала посмотри, на ЧЬИХ путях.**
- Красное на ТВОИХ путях (новый `.md` не зарегистрирован в `../../docs/KARTA.md §6`, битая ссылка) — **чини, не обходи**: там только твоё, обходить нечего.
- Красное на ЧУЖОМ, унаследованном долге (ворота дают сотни ❌ старых нарушений) — законный обход, но ТОЛЬКО с причиной; голый `--no-verify` инструмент отклонит, а причина сама уедет в `INCIDENTY.md`:
```
python3 _generator/tools/git_zona.py commit --zone <зона> \
    --no-verify "чужой долг: <что именно покраснело>" -m "<что и зачем>" --push
```
Ту же причину назови отдельной строкой отчёта долгом. *Урок 9: обход был законен по канону и не существовал в инструменте — первый же коммит владельца встал на чужом долге.*
**Коммит не прошёл по ВНЕШНЕЙ причине** (чужой лок, конфликт, detached HEAD) — чужое состояние репозитория НЕ чини: зафиксируй файлы и напиши в отчёт отдельной строкой «коммита нет, причина такая-то, нужно ваше действие». Это законный отчёт. Молчаливое «сделано» при незакоммиченной зоне — брак: приёмка гоняет тот же гейт первым ходом и завернёт отчёт, не читая (`RUKOVODSTVO §Приёмка`, гейт 0).

### Карта называет ДОМОМ математики восемь карточек, которых в картотеке не существует

Отсутствуют `invariant-estestvennosti-fix`, `nat-L-S-polnyj-spisok`, `estestvennost-est-ekvivariantnost`, `graf-est-funktor-raskraska-ep`, `kategoriya-n-numerovannye-mnozhestva`, `verbickij-b1-b2-funktora-net`, `pi1-bez-tochki-ne-funktor`, `zapret-klonirovaniya-lambda` — единственный файл в репозитории, где эти id встречаются, сама `KARTA-KUSKOV.md`. При этом карта ссылается на них утвердительно и с ценой («карточка заведена 28.07», «цена записана в ней», «проверка в карточке»), то есть читатель не может отличить существующий дом от обещанного. Заплачено: три из двадцати одного куска ушли в конспект формулировкой с флагом вместо математики (полный список Nat(L,S) — D1, задачи Вербицкого — C2, $\pi_1$ без отмеченной точки — E4); пять я восстановил сам, то есть повторил работу, которую карта уже числила сделанной, — ровно тот случай, который сама карта записала как «ЦЕНУ хода» в D1 («аппарат уже лежал в корпусе, а аналитик вывел его заново»), и он повторился в третий раз. ### Юникодные подстрочные индексы в SVG-метке молча не рисуются
ЦЕНА: подстрочный минус U+208B (`₋`) в шрифте вида не существует, и метка `Pₙ₋ₖ(A)` в определяющем коммутативном квадрате отрисовалась как `Pn_k(A)` — то есть рисунок, стоящий вместо формулы, показывал не ту формулу. Гейт `check_view` этого не видит (SVG — сырой блок, он его пропускает), линтер тоже; поймано только тем, что я отрендерил PNG и посмотрел. Цена одного случая — неверная картинка в определении, которую владелец принял бы за верную. Лечение — одна строка в ловушки `SLOVAR-primitivov.md`: **подстрочные индексы в метке писать `<tspan dy="4" font-size="9.5">…</tspan>`, а не юникодными знаками ₀₁₂ₖₙ₋: часть их в гротеске отсутствует и рисунок молча врёт.** Файл вне моей зоны, поэтому строка здесь, а не там.

### Заход обещает «~10 вкладок», а вкладка движка = отдельный файл — и зона разрешает один
ЦЕНА: два обязательных указания захода несовместимы буквально (шаг 2 требует десять вкладок, контракт зоны — один файл), и разрешать это пришлось мне, потратив круг на чтение `build_doc.py` вместо содержания. Разошлись слова: у движка «вкладка» — это `*.md` в папке-источнике, у аналитика — «кусок вида, между которыми переключаются», а это в doc-виде даёт `##`-раздел с аккордеоном. Дешёвое лечение — в шаблоне захода писать «разделов вида», а «вкладки» оставить за файлами: иначе каждый следующий исполнитель либо заведёт десять файлов мимо зоны, либо потратит тот же круг.
> **Не про задачу — про САМУ ФАБРИКУ.** Ты работаешь с пустым контекстом и потому видишь то, чего не видит аналитик: он писал этот заход и ему приятно, что заход хорош. Сломался ВХОД (издание не то, id врёт, зона не содержит файла с ответом)? Критерий готовности кривой? Инструкция канона противоречит живому файлу? — сюда, строкой.
> Формат жёсткий (по нему гейт): `### <что произошло>` / `ЦЕНА: <что сломалось и сколько стоило>`.
> **ЦЕНА обязательна.** Без неё это наблюдение, а не урок, и в канон оно не пойдёт. Не знаешь цены — не пиши.
> **Не сочиняй.** Пустая секция — законный отчёт. Выдуманный урок хуже отсутствующего: он попадёт в канон, который читают ВСЕ будущие проекты.
