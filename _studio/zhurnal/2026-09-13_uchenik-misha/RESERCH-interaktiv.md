# РЕСЁРЧ — движок интерактивных занятий для Миши (27.09.2026)

> Дата данных: 2026-09-27. Вход: правила владельца после занятия №3 (дневник, запись «общие правила интерактива»). Внешний ресёрч — субагент, источники открывались; где исследований нет — сказано.

## Что говорят данные (выжимка)
- **Пошаговые поля оправданы числом.** VanLehn 2011 (мета-анализ): человек-репетитор d=0.79, пошаговые тьюторы d=0.76, ответные — заметно меньше. Мельче шага «одно поле на шаг» отдачи нет. https://www.tandfonline.com/doi/full/10.1080/00461520.2011.611369
- **Две формы починки ошибки** (ASSISTments): лестница подсказок с «дном» (≈ответ) и scaffolding — после ✗ задача раскладывается на под-вопросы. Промежуточные ответы ещё и диагностичны. https://web.cs.wpi.edu/~mfeng/pub/USER562.pdf
- **Угадывание перебором ловится признаками** (Baker, Corbett, Koedinger): слишком быстрый ответ относительно медианы, повтор одного ответа, пустые ответы. Наше «звезда только с первого ✓» уже гасит главное. http://pact.cs.cmu.edu/pubs/Baker,%20Corbett,%20Koedinger%20ITS04.pdf
- **Журнал событий — по схеме xAPI без инфраструктуры:** {время, экран, пункт, шаг, попытка, ответ, верно, подсказка, длительность, простой}. https://xapi.com/statements-101/
- **Ввод у 8–9 лет:** клики и клавиатура лучше перетаскивания; цели ≥1 см и зазор ≥2 мм. https://www.nngroup.com/articles/children-ux-physical-development/ · https://www.nngroup.com/articles/touch-target-size/
- **Один экран:** фиксированная сцена и масштаб `min(W/w, H/h)` через transform — у владельца это уже формат колод 1440×810 (`_generator/`, скилл `slajdy`). https://css-tricks.com/scaled-proportional-blocks-with-css-and-javascript/
- **Пробелы:** нет исследований UI судоку для 8–9 лет; нет данных по Beast Academy/Alcumus; «панель репетитора по хоткею» и хранение — инженерная практика, не педагогика.

## ⚠ Ограничение среды
В артефакте (claude.ai) скачивание файлов страницей запрещено, печать из страницы — тоже. Экспорт статистики там — «скопировать в буфер» или через хранилище артефакта; скачивание JSON работает только в локальном файле.

## Предложение — «движок» (кандидат в отдельную арку)
Источник занятия — данные (как `content/*.md` у колод), генератор собирает ОДИН html: экраны 16:9 с масштабированием + печатный листок в формате 20.09 из того же источника.

**Слой 1 — сразу (малая сложность):** сцена 16:9 без прокрутки · пункты с промежуточными полями · ✗ → перерешать без звезды · палитра значений + клавиатура + прощёлкивание, отмена хода, «сбросить всё» · журнал событий + скрытый таймер + простой (idle) · скрытая панель репетитора по хоткею: таблица «экран — время — попытки — ✓/✗», копировать в буфер · прогресс по занятию.
**Слой 2 — потом:** режим репетитора «пропустить / отметить / подсказать» · возврат ошибочных пунктов в конце занятия (очередь Лейтнера) · шаблоны задач с параметрами («25·16»-ловушки генерируются) · подсветка конфликтов в головоломке только после первой ошибки в клетке.
**Слой 3 — не сейчас:** адаптивная сложность по журналу, классификатор типов ошибок, серверная аналитика.
