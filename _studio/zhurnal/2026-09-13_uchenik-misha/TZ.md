Скоуп арки — подсистема `ucheniki/`: папка `misha/` целиком, `CIKL.md`, фонд начальной школы в `_fond/`. Читатель всех документов — Claude, не владелец; исключение — `INTERVYU.md` и материалы занятия, они написаны для людей.
- **Deliverable** — рабочий цикл занятий с Мишей: профиль закрыт по всем слотам интервью, три занятия проведены по CIKL.md с замерами в журнале
- **Границы / anti-scope** — развёрнуто в `NAVIGATOR.md §Границы`. Коротко: скилл из цикла НЕ делаем (решение владельца — документ `ucheniki/CIKL.md`); перенос калибровки с Дани на Мишу ЗАПРЕЩЁН владельцем; школьную линию «умножение и деление» отдельным продуктом не собираем; `METOD.md` не переписываем под одного ученика; инструменты фабрики (`sdelat_handoff.py`, `build_listok.py`) чинятся не здесь; коммитов арка не делает — только заявки в очередь.
- **Ворота go/no-go** — АРКА НУЖНА. Ворота пройдены: работа с Мишей заняла целую сессию 13.09 (приём ученика, первое занятие с замерами, фонд начальной школы), продолжается еженедельно по воскресеньям, и у неё есть незакрытый предъявимый результат — рабочий цикл занятий.
