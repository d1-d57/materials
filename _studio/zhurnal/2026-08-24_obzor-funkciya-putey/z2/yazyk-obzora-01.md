# Язык обзора 01 «Биномиальные коэффициенты»: v4 → v6 → v7d

Только повторяющиеся преобразования, без добавок по содержанию. Метки: **В** — номер из OPIS, **набл.** — видно только по диффам, отчёту редактора или README. Колонка «есть?» показывает, закрыто ли правило в ZHANR-statya (С…) или gigiena-teksta (§…).

## Правила (от главного к второстепенному)

**1. Сначала способ на числах, потом результат. Явление → «похоже, что…» → утверждение → доказательство.**
❌ v4, «Правило Паскаля»: сначала утв. 7, за ним «Например, $\binom52=\binom41+\binom42=4+6=10$.»
✅ v7d, там же: «Разберём сначала один случай: почему $\binom52=\binom41+\binom42$? Выпишем все слова длины 5 с двумя единицами…» и только потом утв. 9. В «Сумме строки»: «Похоже, что сумма строки $n$ равна $2^n$. Объясним это подсчётом.»
Источник: В5, В12, В16, В25, В27, В40, В42. Нарушение повторилось дважды за день (В25, В40). · Есть? **частично**: С13 «от явного к общему» говорит о порядке частей. Фразы «результат не раньше способа» и запрета «Например» сразу после утверждения там нет.

**2. Вопрос раздела выносить отдельной врезкой «Задача N (имя)» в одну фразу, а ответ давать сразу в прозе под ней.**
❌ v4, «Число пар»: «Сколько пар можно выбрать из $n$ предметов? Из таблицы: из трёх предметов три пары…» — вопрос утоплен в абзаце.
✅ v7d: «**Задача 3 (число пар).** Сколькими способами можно выбрать два предмета из $n$?»; «**Задача 5** … ни одного? / Ответ: одним.»; «**Задача 20** … / Ответ мы знаем, это 56; получим его ещё раз.»
Источник: В26 («распространить везде»), В9. · Есть? **частично**: врезку «Задача N» вводит только С14, и только для статьи под урок. Бриф README п. 15 («задач внутри текста нет») этому **противоречит** и устарел.

**3. Один раздел и один абзац несут одну мысль. Два вопроса не смешивать, длинный абзац резать.**
❌ v4, «Края и симметрия»: «Почему не выбрать ничего можно одним способом и почему ряд одинаково читается с обоих концов?»
✅ v7d: раздел «Пустой выбор и края» (Задача 5) и отдельный раздел «Симметрия», который открывается словами «Ряд 1, 4, 6, 4, 1 одинаково читается с обоих концов.»
Источник: В23, В24, В8; редактор v6 (#36: «абзац про Паскаля в 13 строк разбит на три»). · Есть? **частично**: С15 требует «сначала простое свойство, потом сложное», но не «одна мысль — один раздел». Порога длины абзаца нигде нет.

**4. От чисел к буквам переходить отдельной фразой-мостом: что именно заменяем и на что.**
❌ v4, «Формула»: «Из $n$ человек выбирают команду из $k+1$ человека… Пусть, например, $n=6$…» — сначала общий случай, пример внутри него.
✅ v7d: «Задача 16… В классе 25 человек» → три способа → «$25\binom{24}{10}=15\binom{25}{10}=11\binom{25}{11}$» → «Самих чисел мы пока не знаем, но связь между ними уже есть. Теперь заменим 25 человек на $n$, а 11 игроков — на $k+1$…»
Источник: В27. · Есть? **нет**.

**5. Утверждение записывать фразой «Для любых целых … выполняется равенство» и формулой по центру. Равенство не переносить.**
❌ v4, утв. 8: «Для любых $n\ge1$ и $0\le k\le n-1$ …» и формула через `gathered`, разорванная посреди равенства («…\\=(k+1)\binom n{k+1}»).
✅ v7d, утв. 17: «Для любых целых $n\ge1$ и $k\ge0$ выполняются равенства $$n\binom{n-1}k=(n-k)\binom nk=(k+1)\binom n{k+1}.$$»

**6. Крайние случаи не оговаривать в определении и не перечислять. Выводить их из определения в обсуждении, вопросом на числах.**

✅ v7d, «Определение»: «В определении $k$ может быть и больше $n$. Чему равно $\binom3{10}$? … Отдельно договариваться об этом не нужно: это следует из определения.»
Источник: В10, В22. · Есть? **нет**.

**7. Двойной подсчёт подавать как равенство двух произведений: «С одной стороны… / Посчитаем иначе… / Приравниваем». Не делить.**

```python
# golos.py — запуск: python3 -I golos.py v4.md v6.md v7d.md
import re, sys, statistics
def load(p):
    t = open(p, encoding='utf-8').read()
    return re.sub(r'\A---\n.*?\n---\n', '', t, flags=re.S)          # frontmatter
def sections(t):
    parts = re.split(r'^## (.+)$', t, flags=re.M)
    return [('(вступление)', parts[0])] + [(parts[i].strip(), parts[i+1]) for i in range(1, len(parts), 2)]
def clean(par):
    par = re.sub(r'\$\$.*?\$\$', ' ', par, flags=re.S)            # display math
    par = re.sub(r'\$[^$]*\$', ' ', par)                          # inline math
    par = re.sub(r'<[^>]+>', ' ', par)                            # html
    par = re.sub(r'\{\{.*?\}\}', ' ', par, flags=re.S)            # widgets
    par = re.sub(r'\*\*(Задача|Утверждение|Определение|Теорема) \d+[^*]*\*\*', ' ', par)
    return par
def prose_pars(body):
    res = []
    for p in [p.strip() for p in re.split(r'\n\s*\n', body) if p.strip()]:
        if p.startswith(('#', '|', '{{')): continue                # headings, tables, widgets
        c = clean(p)
        if len(re.findall(r'[А-Яа-яЁё]+', c)) >= 3: res.append(c)
    return res
def sentences(text):
    text = re.sub(r'\s+', ' ', text)
    ss = re.split(r'(?<=[.!?…])\s+(?=[«(А-ЯЁA-Z*0-9])', text)
    return [s for s in ss if re.search(r'[А-Яа-яЁё]', s)]
def words(s): return re.findall(r'[А-Яа-яЁёA-Za-z0-9]+(?:-[А-Яа-яЁё]+)?', s)
for p in sys.argv[1:]:
    t = load(p); secs = sections(t); allS = []
    print('==', p.split('/')[-1])
    for name, body in secs:
        pp = prose_pars(body)
        for par in pp: allS += sentences(par)
        print(f'  {name[:40]:40s} абзацев {len(pp):2d}')
    L = [len(words(s)) for s in allS]
    print('  разделов', len(secs)-1, '| абзацев', sum(len(prose_pars(b)) for _, b in secs))
    print('  предложений', len(L), '| средн. %.1f' % statistics.mean(L), '| медиана', statistics.median(L),
          '| >25: %d (%.0f%%)' % (sum(x > 25 for x in L), 100*sum(x > 25 for x in L)/len(L)))
    for kw in ['Задача', 'Утверждение', 'Определение', 'Теорема']:
        print('  блок', kw, len(re.findall(r'^\*\*'+kw+r' \d+', t, flags=re.M)))
    print('  виджетов', len(re.findall(r'\{\{[SR]:', t)))
```

```python
# poryadok.py — пример до/после утверждения и длина абзаца
import re, sys
num = re.compile(r'\\binom\{?\d+\}?\{?\d+\}?|\d\^\{\\underline|\b\d+\s*[\\\+=·]|\b\d+\\cdot')
for p in sys.argv[1:]:
    t = re.sub(r'\A---\n.*?\n---\n', '', open(p, encoding='utf-8').read(), flags=re.S)
    pars = [x.strip() for x in re.split(r'\n\s*\n', t) if x.strip()]
    before = after_ex = tot = 0; wpp = []
    for i, x in enumerate(pars):
        if not x.startswith(('#', '|', '{{', '$$')):
            wpp.append(len(re.findall(r'[А-Яа-яЁё]+', re.sub(r'\$[^$]*\$', ' ', x))))
        if re.match(r'\*\*(Утверждение|Теорема) \d+', x):
            tot += 1; prev = ' '.join(pars[max(0, i-2):i])
            if num.search(prev) and not prev.lstrip().startswith('*Доказательство'): before += 1
            if i+1 < len(pars) and pars[i+1].startswith('Например'): after_ex += 1
    print(p.split('/')[-1], tot, before, after_ex, round(sum(wpp)/len(wpp), 1), max(wpp))
```

Оговорки по методу. Математика удалена, поэтому слова считаются без формул. Таблицы и заголовки исключены. Тела врезок (фраза «Для любых…», доказательства) засчитаны как проза. Признак «пример ДО» эвристический: в двух абзацах перед блоком есть число вида `\binom{6}{3}`, `8\cdot7` или `4+6`.
