## Аппарат Л1 — зафиксирован владельцем (стартовая рамка, уточняется в Ф0)

- **Понятия Л1:** категория · функтор · естественное преобразование / эквивалентность функторов · эквивалентность категорий.
- **НЕ в Л1 (→ Л2):** универсальные свойства, пределы, Йонеда. **Вне курса (Василий):** сопряжения, ДЗК, КХЛ-как-теорема.
- **Последовательность (владелец 23.07 веч.):** функтор (сначала только для Set) → «что НЕ функтор» ($Z(G)$) → категория рождается внутри Set (Set$^{op}$, Set-с-биекциями) → естественное преобразование → «ЕП не существует» (перестановки vs линейные порядки) → классификация ЕП.
- **Примеры:** ядро — множества / линейная алгебра / группы; касания — топология, анализ, логика (полиморфная функция = естественное преобразование).
