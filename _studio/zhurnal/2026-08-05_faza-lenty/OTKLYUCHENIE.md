## Как проверить, что погасло (выполняет ИСПОЛНИТЕЛЬ, не владелец)

Инструмент снятия инвентаря установленных скиллов — `disciplina/tools/inventar.py` (канонический, вне зоны этого захода, только вызывается):

```
cd ~/Documents/GitHub/disciplina && python3 tools/inventar.py
```

Снапшот «до» уже снят этим заходом 2026-08-06 и сохранён (вне репозитория, в scratchpad сессии; при повторном прогоне видно текущее состояние независимо от снапшота). Признак того, что скилл именно ОТКЛЮЧЁН (не просто временно не выбран субагентом): в блоке 1 вывода (`§ УНИКАЛЬНЫХ ИМЁН СКИЛЛОВ`) имя пропадает из перечисления, а физические пути `.../skills/<имя>/` для соответствующей группы становятся отсутствующими.

Разница «до/после» — по всем четырём именам разом:
```
python3 tools/inventar.py > /tmp/inventar_posle.txt
diff <(grep -o 'html-slides-studio\|popsci-research\|consolidate-memory\|skill-creator' /tmp/inventar_do.txt | sort -u) \
     <(grep -o 'html-slides-studio\|popsci-research\|consolidate-memory\|skill-creator' /tmp/inventar_posle.txt | sort -u)
```
Строки со знаком `<` — то, что пропало (погашено); без изменений — ничего не сделано; строки `>` в норме появиться не должны.
