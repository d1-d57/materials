### 2.1 Определить границу — что вообще считать инцидентом

Правило владельца, записанное в шапке `UROKI-FABRIKE.md` и обязательное здесь: **инцидент — это то, у чего названа ЦЕНА.** Без цены это наблюдение, и в корпус ему нельзя. Цена — что сломалось и сколько стоило: ходов, заходов, кругов правки, лекций, и кто поймал.

### 2.4 Разметка «разобрано / новое» — то, чего владелец просит прямо

У каждой записи улова — статус, и он **вычисляется, а не назначается**:

- **новое** — в корпусе нет;

Итог печатается числами: «просмотрено источников X, найдено записей Y, из них дублей D, без цены N, новых M». Каждое число — командой.

## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- `_studio/zhurnal/2026-08-05_faza-lenty/dobor_incidentov.py`                     # вводит НОВЫЕ пути в индекс
git --no-optional-locks commit -m "<зона>: <что сделано>" -- `_studio/zhurnal/2026-08-05_faza-lenty/dobor_incidentov.py`   # отсекает всё чужое
python3 _generator/tools/git_zona.py check --zone <зона>   # из корня репо; должен быть ✅
git --no-optional-locks show --stat                        # обязаны быть ТОЛЬКО твои пути
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*
⚠ **Хук `pre-commit` покраснел — сначала посмотри, на ЧЬИХ путях.**
- Красное на ТВОИХ путях (новый `.md` не зарегистрирован в `../../docs/KARTA.md §6`, битая ссылка) — **чини, не обходи**: там только твоё, обходить нечего.
- Красное на ЧУЖОМ, унаследованном долге (ворота дают сотни ❌ старых нарушений) — законный обход, но ТОЛЬКО с причиной; голый `--no-verify` инструмент отклонит, а причина сама уедет в `INCIDENTY.md`:
```

    --no-verify "чужой долг: <что именно покраснело>" -m "<что и зачем>" --push
```
Ту же причину назови отдельной строкой отчёта долгом. *Урок 9: обход был законен по канону и не существовал в инструменте — первый же коммит владельца встал на чужом долге.*
**Коммит не прошёл по ВНЕШНЕЙ причине** (чужой лок, конфликт, detached HEAD) — чужое состояние репозитория НЕ чини: зафиксируй файлы и напиши в отчёт отдельной строкой «коммита нет, причина такая-то, нужно ваше действие». Это законный отчёт. Молчаливое «сделано» при незакоммиченной зоне — брак: приёмка гоняет тот же гейт первым ходом и завернёт отчёт, не читая (`RUKOVODSTVO §Приёмка`, гейт 0).

### Дедупликация — метод, число, три примера (условие 4)

**Четыре канала, у каждого измеренная область применимости:**

Спасло то, что рядом в заходе стояло «отсекай по содержанию, а не по `mtime`» — он взял покрытие вместо даты. Но это его решение, а не моё указание. → урок 38: **параметр, который источник объявляет о себе сам, берётся из источника, а не из документа о нём.** Здесь хватило одного грепа по шапке.

### 🔴 Находка про `^ЦЕНА:` бьёт по нашим собственным гейтам, и сильнее, чем он думал

Шаблон стоит в греп-гейтах шапки каждого `UROKI-FABRIKE.md` и в `check_uroki.py`. Проверил по всем аркам:

| арка | секций | видит гейт | есть с жирными |

| `2026-07-25_lekcia-1` | 19 | **6** | **18** |
| `2026-07-16_teorkat-programma-dizajn` | 19 | 8 | 8 |

То есть на арке `lekcia-1` гейт закрытия **видит меньше трети записей**. Он не «краснеет зря» — он судит не то, что думает. → урок 40, правка на один символ в регулярке в трёх местах.

### Метод дедупликации — сделан так, как и надо было

**Главная методическая находка его, а не моя:** «дубль» и «новое вхождение известного механизма» — **разные вердикты**, и разводит их твёрдый факт, а не порог: индексировал ли корпус этот файл. Из 244 совпадений **146 лежат в файлах вне индекса корпуса** — свалить их в дубли значило бы объявить учтённой неделю работы.

**Пороги выбраны по измеренной кривой, а не на глаз** (0.40 → 96.6 %, 0.50 → 92.1 %, 0.60 → 82.8 %), и он прямо назвал слепую зону замера: широкое окно контекста начнёт совпадать со всем подряд, а эту ошибку кривая не видит.

**Положительный контроль честно проваливался трижды** — 2 из 5, потом 4 из 5, потом 5 из 5, — и каждый раз чинился метод, а не выборка. Контрольные записи не переподбирались ни разу. Это ровно то поведение, ради которого условие 5 и писалось.

**Верификатор дал 43 из 50 после починки** (было 35), и главный пропуск оказался общим, а не частным — те самые жирные `**ЦЕНА:**`.

### Решения приёмки по остальным вопросам

**Вопрос 1 — работа по покрытию вместо даты УТВЕРЖДЕНА** и уже исполнена. Дата в заходе была ошибкой составителя.

**Вопрос 4 — секции `## ЗАДАНИЕ` / `## ПЛАН` читать НЕ надо, решение верное.** Там аналитик цитирует уже известные инциденты; добор оттуда вернул бы в корпус его же содержание. Оговорку «просмотрено X — разные множества у меня и у корпуса» принимаю: сравнивать эти числа напрямую нельзя, и это сказано вслух.

**Вопрос 7 — транскрипты остаются по требованию, флагом `--vygruzki`.** Выход низкий: 111 реплик дают 6 записей, при том что три первых источника дали 201. Включать постоянно — платить за самый дорогой источник ради трёх процентов улова.

**Вопрос 5 — битая ограда в `2026-07-30_dovodka-l1/UROKI-FABRIKE.md`** (открыта на 11, закрыта на 32, внутри два настоящих урока): чинится одной правкой в источнике, пойдёт пунктом ближайшего захода в `_studio/`.

**Вопрос 8 принят как ответ на оговорку критерия:** из 3719 блоков с признаком поломки цену несут **338** — меньше одной десятой. Механизм сбора богат описаниями и беден ценами; это диагноз механизму, а не упрёк улову.

### Что теперь есть и чего нет

**Есть:** инструмент добора, воспроизводимый одной командой, и первый улов — **201 запись с ценой сверх корпуса**. Из них 87 — из арки, которую сборщик корпуса не видел по построению (урок 39).

**Нет:** раскладки по домам — она запрещена заходом намеренно, потому что параллельно двигались границы. Колонка «дом» пуста и ждёт следующего захода, который разложит улов по пересчитанной карте.
