# KARTA-INCIDENTOV — разметка инцидентов по фазе → разметка по будущим домам

> **Зачем.** Владелец: *«я собрал кучу инцидентов, я хочу делать рычаги, которые будут их
> закрывать. Но единым проходом это невозможно — надо работать не со всей фабрикой вместе, а
> с каждым конкретным инструментом»*. Классификация инцидентов ПО ФАЗЕ конвейера уже сделана и
> куплена (`KARTOTEKA-problem.md`, ~5 млн токенов). Этот документ её НЕ переделывает — он
> переводит фазу в один из пяти будущих домов, чтобы в каждый дом можно было прийти отдельно.
> Ничего не перенесено: корпусы остаются байт в байт, карта только показывает, куда какой кусок
> корпуса поедет при будущем выносе.

Дата данных: 2026-08-06. Собран заходом `kod_karta-incidentov.md`.

## §3. Единственная новая работа — под-разбор `вне-фаз` на 4 под-дома (§B захода)

`вне-фаз` — крупнейший класс (724 из 2264 Σ кратности, самый большой блок будущего дома МЕТА).
Разложен на 4 под-дома **позаписно, по симптому**, тремя независимыми субагентами (по корпусам:
Раздел 1 `КРТ-*`/142 строк, Раздел 2 `КРВ-*`/38 строк, Раздел 5/121 строка) плюс Раздел 4
(git-автолог) — тот уже был разложен по классам в `RAZBOR-povtorov.md`, поэтому весь целиком
взят готовым под-домом «коммиты и git» без повторной классификации.


**Метод для Раздела 1/5 сработал сразу** (симптом уже сформулирован полной фразой в самой
картотеке/`KRATNOST.md`) — доля СПОРНО единицы процентов. **Для Раздела 2 (`КРВ-*`) метод
пришлось поправить**: `KARTOTEKA-problem.md` хранит для `КРВ-NNx` только НОМЕР группы
(`КРВ-03j`), а название темы группы («компоновка кадра») — общее на ВСЕ инстансы группы,
разнесённые по многим разным фазам. Первый прогон субагента без цитаты дал 74% «СПОРНО» — не
потому что записи спорные, а потому что общее название темы («компоновка кадра», «порядок
подачи материала») звучит как контент слайда, даже когда конкретный ПОМЕЧЕННЫЙ `вне-фаз`
инстанс этой темы — общий принцип, сформулированный владельцем в сессии по мета-работе над
самой фабрикой (проверено: адреса вида `dovodka-fabriki/SESSIYA.md:N` — это сессии арки
мета-доводки, не работы над конкретным деком). Починка: для каждой `КРВ-NNx` строки по её
адресу вытянута КОНКРЕТНАЯ цитата владельца из `KRATNOST-vladelca.md` (мэтчинг по файлу+строке,
тем же приёмом, что и для `КРТ-РАЗН` в §4) и передана субагенту вместо общего названия темы.
Второй прогон — 1–2 спорных из 26–38 вместо 74%.

**Отдельная находка — баг в разворачивании `КРТ-РАЗН · вне-фаз` (85 разнородных находок в одной
строке-агрегате).** Одна из 85 находок (`kod_bootstrap-guard.md#ЗАДАНИЕ, строка 42; #ОТЧЁТ,
строка 125`) несёт СОСТАВНОЙ адрес (две ссылки в одном пункте), а парсер резал только до первой
запятой — получал хвост `"42; #ОТЧЁТ"` вместо чистого `"42"` и не находил совпадения ни разу, то
есть 1 живая запись пропадала МОЛЧА (ни в доме, ни в `--spornye`). Нашёл не автор карты, а
независимый верификатор (§6), считавший, а не читавший смысл. Починено в `_raznoe_bullets()`
(`karta_domov.py`, разрез составного адреса по `;`); после починки — 85 из 85, число сошлось.
