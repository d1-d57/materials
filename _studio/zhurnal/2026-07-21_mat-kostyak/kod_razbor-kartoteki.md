### 2.1. По каждому блоку — ровно один вердикт из трёх

Судья — **только** `STANDART-uzla.md`, не твоё чувство важности. Он говорит прямо: писать — «находку, структурные связи между узлами, оценку берёт ли зал»; **НЕ писать** — «определения, полные конструкции, разборы примеров, методику». И там же: «находка без карточки = потеряна».

- **A — карточка не полагается.** В блоке нет ничего сверх определения/рутинного вывода: всё восстановимо по маткостяку, класть в картотеку нечего. Пометка «нет в картотеке» верна и долгом НЕ является. Обоснование — одна фраза, ссылающаяся на строку стандарта.
- **B — находка есть, карточка не заведена. ЭТО И ЕСТЬ ДОЛГ.** В блоке есть структурная связь, мотивация или несущий момент, который по стандарту обязан жить в картотеке. Пишешь **одной фразой, ЧТО именно за находка** — не «важное утверждение», а сама связь. Плюс предлагаемый `id` (slug по форме стандарта) и `род`. **Саму карточку НЕ пишешь и в `KARTA-OBLASTI.md` НЕ лезешь** — файл вне зоны.
- **C — пометка протухла.** Узел на эту тему в картотеке **уже есть**, просто блок на него не сослался: картотека выросла до 229 узлов, часть пометок старше. Называешь найденный `id` дословно. Правку в маткостяк не вносишь — он вне зоны, идёт в отчёт строкой.

**Категория C — не формальность.** Проверь её честно грепом по `KARTA-OBLASTI.md`: по теме блока, а не только по угаданному slug. Ложное «нет узла» стоит дороже ложного «есть»: по нему заведут дубль под другим именем, и картотека разъедется.

🔴 **Опасность этого захода — занижение.** Объявить блок категорией A дёшево, тихо и почти всегда правдоподобно; никакой гейт этого не поймает. Поэтому: **сомневаешься между A и B — ставь B** и говоришь в строке, что сомневаешься. Список B смотрит владелец, лишний пункт там стоит ему одной строки чтения; пропущенный не стоит ничего сегодня и теряет находку навсегда.

### 2.2. Выход — один файл `RAZBOR-kartoteka.md`

Самоценный: владелец читает ТОЛЬКО его, ни маткостяк, ни этот заход открывать не должен.

- Шапка: дата данных, команда состава и её живой вывод, охват («разобрано X из Y»), **три числа — |A|, |B|, |C|** и строка «настоящий долг картотеки = |B| + |C|».
- Три раздела, в каждом таблица: `блок` · `о чём он одной строкой` · `обоснование вердикта` (для B — что за находка + предлагаемый id и род; для C — найденный id).
- Внизу — «Что я НЕ смог решить»: блоки, где вердикт не встал, с вопросом владельцу. Пустой раздел законен.

**КРИТЕРИЙ ГОТОВНОСТИ (может ПРОВАЛИТЬСЯ):**
1. Файл `RAZBOR-kartoteka.md` существует и закоммичен, хэш назван.
2. **|A| + |B| + |C| = числу блоков, которое напечатала команда §2.0.** Не сошлось — критерий красный, блок потерян или посчитан дважды.
3. Ни один блок не стоит в двух разделах: `grep -o '^| У\?П\?[0-9]*' | sort | uniq -d` пуст.
4. **Все id, названные в разделе C, существуют в живой картотеке:** каждый находится грепом `^id: <тот-id>$` по `KARTA-OBLASTI.md`. Битых — **0**.
5. Ни один файл вне зоны не изменён: `git --no-optional-locks show --stat` печатает ровно один путь.
6. У каждой строки раздела B заполнено «что за находка» непустой фразой по существу — «важное место» и «несущий момент» без содержания не считаются.

**Отрицательный вердикт несёт ОХВАТ В СЕБЕ:** не «долга нет», а «в категорию B попало N, разобрано X из Y». Без охвата вердикт не принимается — «проверено 2 из 41» и «41 из 41» выглядят одинаково.

Операция не лоссовая (ничего не двигается), поэтому программная сверка тут не нужна. Нужна другая: **проверка на занижение.** Твой список A — то место, где ошибка невидима.

Свежему субагенту с пустым контекстом дай **только** `STANDART-uzla.md` и **только** список A: заголовки блоков и твой текст блоков из маткостяка. **Ни своих обоснований, ни вердиктов, ни этого захода** — иначе он будет соглашаться с тобой, а не проверять. Вопрос ему: «по этому стандарту — есть ли в каком-нибудь из этих блоков находка, структурная связь или мотивация, которую стандарт велит положить в картотеку? Назови блок и что именно.»

Каждый блок, который он вытащил, ты **переносишь в B** или письменно объясняешь в отчёте, почему остаётся в A — с цитатой из стандарта, а не «мне кажется, это рутина». Результат — таблица «его находки → перенёс / оставил, почему» — в отчёт целиком, включая те, где ты с ним не согласился.

Субагентов ≤5. Список A большой — режь на части, но каждую часть отдавай **свежему** агенту.

## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- _studio/zhurnal/2026-07-21_mat-kostyak/RAZBOR-kartoteka.md                     # вводит НОВЫЕ пути в индекс
git --no-optional-locks commit -m "<зона>: <что сделано>" -- _studio/zhurnal/2026-07-21_mat-kostyak/RAZBOR-kartoteka.md   # отсекает всё чужое
python3 _generator/tools/git_zona.py check --zone <зона>   # из корня репо; должен быть ✅
git --no-optional-locks show --stat                        # обязаны быть ТОЛЬКО твои пути
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*
⚠ **Хук `pre-commit` («УРОК БЕЗ ЦЕНЫ») судит staged-пути.** Коммитишь свою зону — там только твоё, `--no-verify` не нужен. Хук покраснел — значит в коммит уехало чужое: **не обходи, пересобери коммит.**
**Коммит не прошёл по ВНЕШНЕЙ причине** (чужой лок, конфликт, detached HEAD) — чужое состояние репозитория НЕ чини: зафиксируй файлы и напиши в отчёт отдельной строкой «коммита нет, причина такая-то, нужно ваше действие». Это законный отчёт. Молчаливое «сделано» при незакоммиченной зоне — брак: приёмка гоняет тот же гейт первым ходом и завернёт отчёт, не читая (`RUKOVODSTVO §Приёмка`, гейт 0).
