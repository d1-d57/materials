**Зачем первой.** Единственная работа, которая (а) не зависит от финального списка родов, (б) снимает несущее ограничение выше, (в) даёт видимый проверяемый результат сразу.

**Что делаем.**

2. `build_doc.py` перестаёт держать собственный `_STMT_CLS`/`_BOLD_STMT` как источник правды и читает список оттуда. Кириллические имена во ВИДЕ сохраняются — это отображение на печать, а не второй словарь.
3. Синтаксис источника сводится к одному. Какой именно — решение фазы; кандидат по умолчанию `### [rod] мысль`, потому что он уже парсится, уже сверяется по составу и уже живёт в 18 карточках L2.
4. Список родов на этой фазе **НЕ меняется**. Меняется только число его домов: 2 → 1.

**Гейт.**


## Ф2 · Инвентарь дефектов (узко)

**Зачем.** Даёт ЦЕНУ каждому будущему красному гейту. Правило без цены не заводится (`KONSTITUCIYA §11`). Для этой работы корпус обязан быть именно плохим — и он такой.

**Что считаем — три класса, не больше.** Поимённо, с адресами, без распределений:

1. **Определение невосстановимо** — формулировку нельзя восстановить, не уходя в источник. Это главная претензия владельца к нынешним текстам.
2. **Утверждение без формулировки** — факт растворён в прозе и не выделен как утверждение.
3. **Абзац не принадлежит ничему** — прямая мера того, насколько «без остатка» не соблюдается. Это и есть «вода», ставшая адресом.

**Вход.** Ленты, собранные `build_doc.py` (список — командой, не памятью):

```bash
grep -rl "ГЕНЕРАТОРОМ _generator/build_doc.py" --include="view.html" . | grep -v "^./_generator" | wc -l
```

**Выход.** `INVENTAR-defektov.md` в этой арке: три списка с адресами `файл:строка` и кратностью. Числа — командой.

**Чего тут НЕТ.** Ни доли нарратива, ни коридоров, ни длин. Норма из этого корпуса не выводится (см. §Что отменено).

## Ф3 · Корпус образцов — чужих, не своих

**Решение владельца.** Эталон не пишется, а находится. Целевой жанр назван точно: **конспекты лекций, а не книги** — *«там целая лекция превращается в три страницы, очень ёмко, только основная суть, и там очень часто всё уже размечено»*.

**Что собираем.** Конспекты (lecture notes), в которых разметка на блоки уже есть авторская: `Definition / Theorem / Proof / Example / Remark` с нумерацией. Книги (Милнор, Хартсхорн, Гриффитс–Харрис, Вуазен) — **ориентир регистра точечно, не корпус**: другой жанр, другой объём, у них нет ни нарратива обзора, ни бюджета.

**Кто кладёт.** Владелец скачивает и кладёт файлы; папку заводим в арке. Разметка задним числом и разбор — заходом.

**Что из корпуса вынимаем.** Не распределения — а **раскладки подраздела**: какие блоки и в каком порядке образуют законченный кусок у людей, которые пишут ёмко профессионально. Это тот же предмет, что Т1–Т5 у слайдов, но добытый с чужой стороны, пока своя движется.
