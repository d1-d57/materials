### 2.1. Ось разметки — ПЯТЬ МЕСТ ЛЕКЦИИ, а не четыре лупа

Ось задал владелец дословно:

> *«У нас есть первый кусок лекции, там мало всего ещё известно. Вообще есть самые первые, это когда про множества там вообще ничего не известно. Но потом есть, когда появляются функторы, категории. Вот так надо разложить, этого будет достаточно.»*

Отсюда шесть меток. Метка отвечает на ОДИН вопрос: **какой минимум языка нужен, чтобы этот сюжет вообще можно было рассказать?**

| метка | что уже введено к этому месту | что здесь можно рассказывать |
|---|---|---|
| **М0** | ничего категорного | только множества, отображения, биекции, переименования. Сюжет живёт на школьном/комбинаторном языке |
| **М1** | категория: объекты, стрелки, композиция, тождество, изоморфизм, ретракт | вопросы к объектам и стрелкам ОДНОЙ категории: что здесь изоморфизм, есть ли ретракция, чем эти два объекта отличаются |
| **М2** | функтор и $\mathcal C^{\mathrm{op}}$ | «эта конструкция — функтор» / «а эта — не функтор»; перенос вопроса из одной категории в другую; смена класса стрелок меняет ответ |
| **М3** | естественное преобразование, квадрат естественности | «этот изоморфизм естественный, а тот — нет»; классификация всех преобразований между двумя конструкциями |

| **ЗА** | требует того, чего в Л1 НЕ БУДЕТ | универсальные свойства, пределы/копределы, лемма Йонеды, представимость, сопряжения, монады, топосы, моноидальность, обогащённые категории, ДЗК, расслоения |

**Правило разметки — одно, и оно дешёвое:**

> Метка = **самое РАННЕЕ место, начиная с которого сюжет уже можно рассказать целиком.** Не «где он красивее звучит» и не «к какой теме относится по смыслу» — а где введено всё, что нужно для его формулировки и разбора.

Пограничный случай разрешается так же дёшево: **сомневаешься между двумя соседними метками — ставь БОЛЕЕ РАННЮЮ и пиши одной фразой, что тебя смущает.** Владелец сдвинет позже; потерянный сюжет он не вернёт.

⚠ **«ЗА» — не помойка и не приговор.** Сюжет за потолком Л1 может быть отличным материалом для лекций 2–3 или для Василия. Метка «ЗА» обязана называть, ЧТО ИМЕННО за потолком («нужны пределы», «нужны сопряжения») — иначе она непроверяема.

5. **Раздел «Мимо»** — позиции, не попавшие никуда, одной строкой с причиной.

**КРИТЕРИЙ ГОТОВНОСТИ (может ПРОВАЛИТЬСЯ) — три условия, все обязательны:**


**(б) Отрицательный вердикт несёт ОХВАТ В СЕБЕ.** Не «сюжетов на М3 мало», а «на М3 попало 4 группы из 61». «Проверено 2 из 9» и «проверено 9 из 9» выглядят одинаково — поэтому число внутри самого вердикта.

**(в) У каждой группы абзац-объяснение по §2.3 есть и он не ярлык.** Самопроверка перед сдачей: прочитай пять случайных абзацев подряд как человек, не знающий этого раздела. Хоть один непонятен — переписывай, а не сдавай.

⚠ **Числа групп заранее НЕ назначаю** — ни «должно быть 40», ни «не больше 60». *Цена урока 4 этой арки: числовые планки в поисковом заходе владелец снял — снизу они подталкивают натянуть список до числа, сверху дают право остановиться. Сколько там сюжетов, заранее не знает никто. Назови число, которое вышло.*

## 3. ВЕРИФИКАТОР
**НЕ НУЖЕН — и это решение владельца, не экономия.** Операция не лоссовая: исходные файлы ты не трогаешь, ничего не двигаешь и не удаляешь, выход — новый файл рядом. Охват держит команда из критерия (а). Субагента-верификатора не заводи.

## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- _studio/zhurnal/2026-07-25_lekcia-1/
git --no-optional-locks commit -m "priruchenie-vneshnego: внешний корпус размечен по местам лекции и сгруппирован" -- _studio/zhurnal/2026-07-25_lekcia-1/
python3 _generator/tools/git_zona.py check --zone _studio/zhurnal/2026-07-25_lekcia-1/
git --no-optional-locks show --stat
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*

⚠ **Хук `pre-commit` покраснел — сначала посмотри, на ЧЬИХ путях.**
- Красное на ТВОИХ путях (твой новый `.md` не зарегистрирован в `../../docs/KARTA.md §6`, твоя ссылка битая) — **чини, не обходи.** Регистрация нового файла — твоя обязанность тем же ходом: `../../docs/KONSTITUCIYA.md` п. 9, документ-сирота не существует.
- Красное на ЧУЖИХ путях (ворота дают 241 ❌ унаследованного долга — 47 карточек вне картотеки, 51 мёртвая секция рамы, 141 незарегистрированный `.md`; всё это было до тебя) — законный обход с обязательной причиной:
```
python3 _generator/tools/git_zona.py commit --zone _studio/zhurnal/2026-07-25_lekcia-1/ \
    --no-verify "чужой долг: <что именно покраснело>" \
    -m "priruchenie-vneshnego: ..." --push
```
Обход сам пишется в `INCIDENTY.md`; **ту же причину назови отдельной строкой отчёта долгом.** Голый `--no-verify` без причины инструмент отклонит.

**Коммит не прошёл по ВНЕШНЕЙ причине** (чужой лок, конфликт, detached HEAD) — чужое состояние репозитория НЕ чини: зафиксируй файлы и напиши в отчёт отдельной строкой «коммита нет, причина такая-то, нужно ваше действие». Это законный отчёт. Молчаливое «сделано» при незакоммиченной зоне — брак: приёмка гоняет тот же гейт первым ходом и завернёт отчёт, не читая.

## УРОКИ ФАБРИКЕ — (заполняет исполнитель; пусто — нормальный исход)
> **Не про задачу — про САМУ ФАБРИКУ.** Ты работаешь с пустым контекстом и потому видишь то, чего не видит аналитик: он писал этот заход и ему приятно, что заход хорош. Сломался ВХОД (издание не то, id врёт, зона не содержит файла с ответом)? Критерий готовности кривой? Инструкция канона противоречит живому файлу? — сюда, строкой.
> Формат жёсткий (по нему гейт): `### <что произошло>` / `ЦЕНА: <что сломалось и сколько стоило>`.
> **ЦЕНА обязательна.** Без неё это наблюдение, а не урок, и в канон оно не пойдёт. Не знаешь цены — не пиши.
> **Не сочиняй.** Пустая секция — законный отчёт. Выдуманный урок хуже отсутствующего: он попадёт в канон, который читают ВСЕ будущие проекты.
