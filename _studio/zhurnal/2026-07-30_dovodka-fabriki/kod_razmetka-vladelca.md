- **ПРИ КАКОМ МАСШТАБЕ** — жанр артефакта, длительность, формат файла, тип лекции: всё, что видно из записи и её источника. Не выдумывай: чего в источнике нет, того не пиши. Скрипт краснеет на пустом и куцем масштабе — он и есть смысл файла.
- **ФОРМА** — одно из `ориентир` · `WARN` · `гейт`.

**Почему контекст обязателен — цена названа владельцем 31.07 дословно:** *«сказать, что не может быть больше 50 слайдов, хотя в теории в одном html может быть содержание нескольких лекций»*. Число, вынутое из контекста и вбитое в гейт, начинает краснеть на здоровом; гейт, краснеющий на здоровом, отключают, и тогда пропадает вся защита, а не одна проверка (`RESHENIYA Р31`, оплачено 21.07).

**Отдельный раздел файла — `## КОНФЛИКТУЮЩИЕ`:** одна и та же величина, названная разными числами в разных источниках (например, длительность лекции). Не примиряй их и не выбирай правильное — **выпиши обе с датами**. Это развилки для владельца, и они ценнее согласованного свода.

## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- _studio/zhurnal/2026-07-30_dovodka-fabriki/verdikt-vladelca.tsv _studio/zhurnal/2026-07-30_dovodka-fabriki/verdikt-chisla.tsv _studio/zhurnal/2026-07-30_dovodka-fabriki/RAZMETKA-VLADELCA.md _studio/zhurnal/2026-07-30_dovodka-fabriki/CHISLA-s-kontekstom.md _studio/zhurnal/2026-07-30_dovodka-fabriki/POKRYTIE-karkasa.md _studio/zhurnal/2026-07-30_dovodka-fabriki/kod_razmetka-vladelca.md _studio/docs/KARTA.md                     # вводит НОВЫЕ пути в индекс
git --no-optional-locks commit -m "<зона>: <что сделано>" -- _studio/zhurnal/2026-07-30_dovodka-fabriki/verdikt-vladelca.tsv _studio/zhurnal/2026-07-30_dovodka-fabriki/verdikt-chisla.tsv _studio/zhurnal/2026-07-30_dovodka-fabriki/RAZMETKA-VLADELCA.md _studio/zhurnal/2026-07-30_dovodka-fabriki/CHISLA-s-kontekstom.md _studio/zhurnal/2026-07-30_dovodka-fabriki/POKRYTIE-karkasa.md _studio/zhurnal/2026-07-30_dovodka-fabriki/kod_razmetka-vladelca.md _studio/docs/KARTA.md   # отсекает всё чужое
python3 _generator/tools/git_zona.py check --zone <зона>   # из корня репо; должен быть ✅
git --no-optional-locks show --stat                        # обязаны быть ТОЛЬКО твои пути
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*
⚠ **Хук `pre-commit` покраснел — сначала посмотри, на ЧЬИХ путях.**
- Красное на ТВОИХ путях (новый `.md` не зарегистрирован в `../../docs/KARTA.md §6`, битая ссылка) — **чини, не обходи**: там только твоё, обходить нечего.
- Красное на ЧУЖОМ, унаследованном долге (ворота дают сотни ❌ старых нарушений) — законный обход, но ТОЛЬКО с причиной; голый `--no-verify` инструмент отклонит, а причина сама уедет в `INCIDENTY.md`:
```
python3 _generator/tools/git_zona.py commit --zone <зона> \
    --no-verify "чужой долг: <что именно покраснело>" -m "<что и зачем>" --push
```
Ту же причину назови отдельной строкой отчёта долгом. *Урок 9: обход был законен по канону и не существовал в инструменте — первый же коммит владельца встал на чужом долге.*
**Коммит не прошёл по ВНЕШНЕЙ причине** (чужой лок, конфликт, detached HEAD) — чужое состояние репозитория НЕ чини: зафиксируй файлы и напиши в отчёт отдельной строкой «коммита нет, причина такая-то, нужно ваше действие». Это законный отчёт. Молчаливое «сделано» при незакоммиченной зоне — брак: приёмка гоняет тот же гейт первым ходом и завернёт отчёт, не читая (`RUKOVODSTVO §Приёмка`, гейт 0).

### Гейт захода отвергает пометку, которую сам же считает: критерии готовности №1 и №4 несовместимы
ЦЕНА: `sobrat_razmetku.py` валидирует ярус по словарю `YARUSY` (строки 28, 68–69) и материю по `MATERII` (строки 30, 70–71), поэтому предписанный заходом `1?` даёт `неизвестный ярус` и exit 1 — а счётчик спорных в том же скрипте ищет ровно `y.endswith("?") or "?" in m` (строка 87). Исполнить инструкцию = провалить критерий 1; не исполнить = провалить критерий 4. Проверено прогоном, а не чтением. Стоило одного захода вхолостую на пробу и обходного канала (спорность в четвёртое поле); главная цена не у меня, а дальше: **строка «Помечено спорными: 0» в собранном `POKRYTIE-karkasa.md` ложна и останется ложной у всех четырёх пачек** — судья, читающий её как факт, получит ноль вместо 43 в моей пачке. ### Сборщик молча съедает разделы, которые заход обязан дописать в собираемый им файл
ЦЕНА: `sobrat_razmetku.py` пишет `POKRYTIE-karkasa.md` и `CHISLA-s-kontekstom.md` через `write_text` целиком (строки 92, 118, 150), а `## РАЗБОР` и `## КОНФЛИКТУЮЩИЕ` заход дописывает в те же файлы. Но корпус нарезан на четыре пачки, и **разбор пачки 1 умрёт при первом прогоне пачки 2 — молча, без строки в выводе скрипта и без следа в git, если исполнитель пачки 2 не знает про эту ловушку.** Общее правило: инструмент, который перезаписывает файл целиком, не может быть единственным писателем файла, у которого есть второй писатель; либо раздел живёт в отдельном файле, либо сборщик его сохраняет.
