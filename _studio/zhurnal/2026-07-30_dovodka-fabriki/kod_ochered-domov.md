## 2. ЗАДАЧА

### 🔴 Ф1 — ФАЗА СУЖДЕНИЯ. Оспорь форму до того, как её строить

Аналитик выбрал форму для шага «разнесение по домам» и **хочет, чтобы ты её атаковал**, а не исполнил. Пиши вывод в `## ПЛАН` **до первой строки кода**.

**Задача, которую надо решить.** Исполнитель находит вещь, которая принадлежит не его зоне, а чужому дому: термин → глоссарий курса; вопрос → владельцу; источник → манифест; урок → дом уроков; результат захода → следующий заход. Контракт зоны запрещает ему писать в чужой дом, значит он сдаёт находку отчётом, а переносит аналитик. **Замер канона: 0 из 8 вопросов дошло до владельца, 1 из 17 уроков дошёл до канона.**

**Форма аналитика — очередь с адресом, а не эвристика по словам.** Секции `## ВОПРОСЫ` и `## УРОКИ ФАБРИКЕ` уже де-факто очереди; им не хватает двух полей: **дом назначения** (явный путь) и **отметка доставки**. Тогда приёмка проверяет не смысл («связан ли урок с записью в дневнике»), а факт: по названному адресу появилась новая строка — сверяется `git diff`. Отвергнутая альтернатива — эвристика по ключевым словам («в отчёте есть слово „термин“ → в глоссарии прибавилась строка»): она угадывает намерение по лексике, шумит и обманывается тривиально.

**Твоя работа в Ф1 — ответить на четыре вопроса и обосновать каждый живыми файлами репозитория, а не общими соображениями:**

1. **Верна ли форма?** Если очередь с адресом хуже альтернативы — назови альтернативу и цену выбора. Тебя не накажут за отказ: неверный механизм дороже отсутствующего, потому что создаёт уверенность.
2. **Кто заполняет поле «дом»** — исполнитель при написании или аналитик при приёмке? У обоих ответов есть цена, назови обе. Учти: исполнитель работает с пустым контекстом и адресов домов может не знать; аналитик знает, но именно он и забывает — ради этого всё и строится.
3. **Что считать доставкой?** Новая строка в целевом файле — достаточный признак? Хуже: файл мог быть дописан по другому поводу тем же коммитом. Лучше ли требовать, чтобы отметка несла адрес с номером строки или заголовком?
4. **Где очередь физически живёт** — в самом файле-заходе (там же, где находка родилась) или в отдельном файле арки? Файл-заход регенерируем и его секции уже растут; отдельный файл — ещё один документ, который надо регистрировать и который может осиротеть.

**Гейт фазы:** в `## ПЛАН` есть раздел «Ф1», в нём даны все четыре ответа, и **как минимум один опирается на команду, прогнанную по живым файлам** (например: сколько сегодня в файлах-заходах репозитория вопросов исполнителей, и сколько из них имеют хоть какой-то след ответа). Ответ «согласен со всем» без единого замера фазу не закрывает.

### ЧАСТЬ A — шаг «запись по ходу»: гейт ставится в правильную точку

`dnevnik.py proverit` уже считает «покрыто N из M» по живому транскрипту, но вызывается один раз — при закрытии сессии, когда исправлять поздно. Владелец описывает боль так: *«я всё время чувствую, что мы теряем информацию в процессе»*.

**Сделать:** `priyomka.py` вызывает сверку дневника и печатает отставание в блоке «печать для рук» — с номерами и первыми строками неразнесённых реплик. Приёмка отчёта случается посреди сессии несколько раз, значит отставание становится видно тогда, когда его ещё можно закрыть.

- Это **печать, а не гейт.** Красным делать нельзя: посреди сессии дневник законно неполон, а гейт, который шумит зря, отключают. Печать при этом обязана быть **всегда**, включая полностью зелёный прогон.
- Транскрипт может не найтись (чужая машина, другой канал) — тогда печатается честная строка «сверка недоступна: причина», а не молчание. *Молчание неотличимо от «всё разнесено» — ровно тот класс, против которого весь механизм.*

```

```
🔴 **ОБА хода обязательны:** `add` вводит новые пути в индекс; `-- <пути>` в самом `commit` отсекает чужое, застейдженное рядом. *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх.*
⚠ **Хук покраснел — смотри, на ЧЬИХ путях.** На твоих — чини. На чужом унаследованном долге — законный обход, но только с причиной:
```
python3 _generator/tools/git_zona.py commit --zone _generator/tools \
    --no-verify "чужой долг: <что покраснело>" -m "<что и зачем>" --push
```
**Коммит не прошёл по ВНЕШНЕЙ причине** — чужое состояние репозитория НЕ чини: напиши отдельной строкой «коммита нет, причина, нужно ваше действие». Молчаливое «сделано» при незакоммиченной зоне — брак.
