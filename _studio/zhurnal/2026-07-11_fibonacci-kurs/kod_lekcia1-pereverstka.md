## 3. ЗАДАЧА — Лекция 1 (задачи 1–5) по стандарту «двузонный canvas»

**Формат-контракт (жёстко):** каждая задача = **УСЛОВИЕ** (короткий текст-формулировка из листка/`matematika.md`) → **ДОКАЗАТЕЛЬСТВО** (иллюстрация/интерактив, почти без слов). Текст — минимум; никаких эссе-подводок и навязанного «стиля». Иллюстрация — ТОЛЬКО к доказательству, не декоративная к каждой фразе. Порядок сцен всегда: сперва ЧТО (вопрос / какую биекцию строим) → потом ответ/построение.

**Стандарт «двузонный canvas»** (эталон — подмножество↔полоска; выведен из референса владельца, стр. 8–9):
1. **Две зоны разделены ФОНОМ, без подписей.** Светлое поле сверху — короткое условие/комментарий «что делаем» (буквы `A_n`/`B_n` — только при формулировке задачи из листка). Цветная полоса снизу — сам canvas, без слов.
2. **Соответствие — ВЫРАВНИВАНИЕМ:** образ строго под своей клеткой (код-цифра под своей плиткой, как на стр. 9 референса) + подсветка пары там, где естественно (число снизу ↔ разрез/склейка сверху). Не насильно везде.
3. **Обе стороны РЕДАКТИРУЕМЫ**, где осмысленно. Сейчас `lab.core.js` правит только верх-полоску (клик по плитке), низ read-only — **достроить редактируемый низ**.
4. **Ограничение — во ВВОДЕ, не в тексте:** подмножество — соседние кнопки/лунки гаснут (нельзя два подряд); строки 0/1 — после «0» доступна только «1» (нет «00»). Правило показывает интерактив.
5. **Один canvas — весь путь объекта** (определение → примеры → рекуррента → биекция); меняется только что показано.
6. **Клик по полоске оставляем** (владелец подтвердил): клик по плитке — доминошка распадается на два квадрата / два квадрата сливаются; достроить, чтобы добираться до ЛЮБОГО замощения.

**Ритм каждого объекта (B, C, D, E, F, H) — больше сцен, плавно:** (1) определение сверху; (2) примеры при малых n, руками через генератор объекта; (3) **рекуррента как canvas** (верх фикс. длины n ↔ низ: «квадрат + объект n−1» / «доминошка + объект n−2»); (4) биекция X↔A, ВЫВЕДЕННАЯ из рекурренты. **Рекуррента и суммы — ТОТ ЖЕ формат canvas** (одна сторона фикс. длины, другая пробегает), не исключение.

**Дешёвый переиспользуемый метод (ГЛАВНАЯ архитектурная директива владельца):** НЕ bespoke-код на каждый слайд. Выдели МАЛЫЙ набор переиспользуемых примитивов (в `lab.core.js`/рядом) и внедри на ВСЕ канвасы: (а) двузонный layout (фон-зоны + разделитель); (б) рендер полоски с выравниванием образа под клетки; (в) редактируемый ввод-с-ограничением (полоска-клик; кнопки 0/1; выбор-без-соседних); (г) живая двусторонняя связка. Каждый слайд = КОНФИГ над примитивами, не новый код. Это критерий масштабируемости.
