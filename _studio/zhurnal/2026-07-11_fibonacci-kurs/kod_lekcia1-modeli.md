## 3. ЗАДАЧА — Л1 как серия МОДЕЛЕЙ

### Контракт слайда-МОДЕЛИ (жёстко)
Каждая модель = **ОДИН слайд, ОДИН канвас** (не три). Устройство:
- **ВЕРХ (светлая зона) постоянен = ОПРЕДЕЛЕНИЕ объекта** (дословно из листка/`TEKSTY-L1.md`) + как устроен элемент. НЕ про биекцию. Между сценами верх не меняется (no reflow).
- **НИЗ проходит СЦЕНЫ** (≥3, можно больше), меняется только образ снизу:
  1. **пусто** (только определение);
  2. **маленькие примеры** — выписаны ВСЕ элементы для n=1,2,3;
  3. **пример побольше** — n=4 (счёт 1,1,2,3,5…);
  4. **рекуррента-биекция** — элемент делится **по первому элементу** на `Y→X_{n−1}` и `Z→X_{n−2}` (`matematika.md` Утв.2–3, листок з.2б).
- **Минимум текста.** Никаких инструктивных подписей («меняй ленту…») и подписей к иллюстрациям-доказательствам («квадрат + A₆») — УБРАТЬ.

### Формат ОПОРНЫХ ТОЧЕК (директива владельца — вариант C «номер на поле»)
Опорные точки — «**Задача** / **Условие** / **Утверждение** / **Теорема**» — единым форматом (раньше в лекциях их не было явно, разрабатываем сейчас):
- **Крупный НОМЕР на ПОЛЕ, не по центру:** слева на поле крупная Forum-цифра-номер (по листку) как буквица; рядом мелкий Forum-caps надзаголовок («Задача»); тонкая линейка `--rule` под блоком; формулировка — Noto в мерной колонке справа от номера. Семья «Определение/Утверждение/Теорема» — тем же языком (крупный акцент + надзаголовок; номер там, где уместен). Референс — виджет Cowork, вариант **C**.
- **Картинка ПОСЛЕ формулировки:** сначала «Задача»+условие (сцена), потом доказательство-канвас (следующая сцена). Порядок всегда ЧТО→как.
- Финальный контракт формата занеси в `STANDART-canvas.md`.

### Роутер моделей Л1 (порядок; тексты — дословно листок/TEKSTY)
1. **s01 Обложка** — только «Числа Фибоначчи», **без подписи** (убрать `.sub`).
2. **Задача 1** (2×10). Поток: показать замощение доски 2×10 → «разбиение восстанавливается по ВЕРХНЕЙ строке» (НЕ «снять лишние измерения») → переход к полоске 1×n квадрат/доминошка. ⚠ формулу «2×10» НЕ разрывать переносом (зона во всю ширину: либо влезает целиком, либо переносится слово «доминошки»).
3. **Модель A** — упорядоченные разбиения n в сумму 1 и 2 (замощения 1×n). Сцены: определение → выписать ВСЕ малые примеры (1,1,2,3,5) → **гипотеза: это Фибоначчи** → рекуррента по первой плитке → доказательство. *(расширить `s04-recur` сценами)*
4. **Две колонки — «ещё семь объектов»** (замена звезды-хаба s05): СЛЕВА список определений объектов (B,C,D,E,F,G,H — из листка), СПРАВА узкая голубая колонка с примером КАЖДОГО при n=5. Без картинки-звезды. Отсюда — «дальше разбираем по одной модели».
5. **Модель C** — 0/1 длины n без «00», кончаются на 1: определение → примеры → рекуррента по первому символу. *(repoint `s07-code`)*
6. **Модель B** — подмножества {1..n−1} без соседних. *(repoint `s08-subset`)*
7. **Модель F** — перестановки {1..n}, |π(i)−i|≤1. *(repoint `s09-perm`)*
8. **Модель H** — цифры 1–4, длина n, старт 1, соседние позиции — соседние цифры. **Свой слайд.** ⚠ длина n даёт f_{n−1}; бери ИСПРАВЛЕННУЮ длину n+1 (f_n, сверено `verify_H`); отметь сдвиг честно.
9. **Пуанта** — у всех одна рекуррента `f_n=f_{n−1}+f_{n−2}` и база `|X_0|=|X_1|=1` ⇒ все f_n. Кросс-биекция (задача 2в, X_n↔A_n) — **лёгкий бонус** (одна сцена), не основное.
10. **Задача 3а** (была пропущена) — ОДНО условие переговорённое на РАЗНЫХ языках: «элементы Aₙ: сначала k единиц, потом двойка» → что это в Bₙ, Cₙ, …, Hₙ. **Один слайд** (payoff серии). Текст — листок з.3а.
11. **Задача 3б** — `f_0+…+f_n = f_{n+2}−1`, по первой доминошке (Утв.9). ⚠ картинка сначала БЕЗ красной доминошки → потом добавить красную = ответ.
12. **Задача 4** — `f_1+f_3+…=f_{2n}−1`, `f_0+f_2+…=f_{2n+1}`, по первому квадрату (Утв.10, режим `firstsq`).
13. **Задача 5 (Цекендорф) — финал.** 5а существование — индукция (единственное место листка, где можно); 5б единственность — «сюръекция между множествами равной мощности есть биекция»; 5в явная биекция `C_n→{1..f_n}`: последовательность `a ↦ Σ_n (1−a_n)·f_n` (⚠ сверить численно отдельным скриптом — как `verify_H`).

D, E, G — в Л1 НЕ разворачиваем (листок сам помечает «курсу не нужны»); в двух колонках (п.4) присутствуют определением+примером, детально — задел.
