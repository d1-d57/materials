**Три новые модели (математика СВЕРЕНА — см. ниже, все счёты = fₙ, split — точная биекция):**
- **D** (`data-mode="compGE2"`): Dₙ = композиции n+2 из частей ≥2. Рекуррента по первому слагаемому: **=2 → отбросить → Dₙ₋₂**; **≥3 → уменьшить на 1 → Dₙ₋₁**.
- **E** (`data-mode="compOdd"`): Eₙ = композиции n+1 из нечётных. Рекуррента: **=1 → отбросить → Eₙ₋₁**; **≥3 → уменьшить на 2 → Eₙ₋₂**. Прямая биекция с A (Утв.7): приписать квадрат справа, резать после каждого квадрата → блоки нечётной длины 2j+1 = «j доминошек + квадрат».
- **G** (`data-mode="zigzag"`): Gₙ = (a₁..a_{n−1}) 0/1, a₁≤a₂≥a₃≤… Рекуррента по первому символу: **a₁=1 → форсит a₂=1 → снять оба → Gₙ₋₂**; **a₁=0 → снять a₁, ОСТАТОК ИНВЕРТИРОВАТЬ 0↔1 → Gₙ₋₁** (зеркало — критично, без него не биекция).

**Биекция-сцена у A/F/H (сейчас stages кончаются на recur):**
- **F** (`perm`) — самое дешёвое: `s09-perm.html` `data-scenes 3→4`, `data-stages` += ` bijection`. Ветка `perm` в `drawImage` уже есть — JS не трогать.

- **H** (`hwalk`) — добавить мапу обход→полоска (по рекурренте) + ветку `hwalk` в `drawImage` + bump.

**Единый метод биекции `xToTiling`:** у каждой X — функция «элемент X → замощение Aₙ», по рекурренте (тот же split, база |X₀|=|X₁|=1). Прямые (C/B/F) и E-прямая — уже осмысленны; A — тождество; D/G/H — рекуррентная. Сцена «биекция» = two-zone: полоска A сверху ↔ объект снизу, выровнены по рекуррент-чанкам; бессловесно.
