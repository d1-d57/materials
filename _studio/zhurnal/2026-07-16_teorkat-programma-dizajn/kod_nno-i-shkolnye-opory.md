## 2. ЗАДАЧА

### 2.1 ГЛАВНОЕ — адрес NNO. Делать ПЕРВЫМ, до всего остального

**Что случилось.** Объект натуральных чисел (NNO) стоял на Л8 рядом с монадами. Обоснование было: «и то и другое — алгебры эндофунктора». **Оно опровергнуто** (`kod_motivacii-l1-l8-l9.md`, страницы сверены глазами):
- алгебра **функтора** (Awodey, упр. 10.6.2, печ. с.274): «an object $A$ and an arrow $a: TA \to A$» — **аксиом нет** ⇒ (точка, **преемник**), начальная = $\mathbb{N}$;
- алгебра **монады** — две аксиомы; для монады $1+(-)$ (Riehl, Example 5.2.6(i), печ. с.189) единица «restricts to the identity on the $A$ component», категория Эйленберга–Мура $\cong \mathrm{Set}_*$;
- ⇒ **аксиома единицы монады убивает ровно преемника.** Сюжеты противонаправлены.

**⇒ адрес NNO сейчас НЕ обоснован ничем.** Куклев (заказчик) хотел NNO на Л3 — там перебор и нет функторов. Владелец 17.07: *«наверное, это важный сюжет, который хочется использовать по максимуму»* — то есть **вырезать жалко, арифметика есть базовое знание зала**.

**Что решаешь — где NNO садится ЧЕСТНО, по источникам.** Кандидаты (это гипотезы аналитика — **проверить или опровергнуть, не подтверждать из вежливости**):

Но `nno-prodolzhenie` дословно: «по минутам это перегруз». **Владелец 17.07 сказал «перебора на Л3 нет — вопрос дозировки»** ⇒ довод «перегруз» ослаб, перепроверь его по существу, а не по памяти карточки.
