### 2.1 ГЛАВНОЕ — зависимое произведение $\Pi_f$ как понятие для ЗАЛА. Делать ПЕРВЫМ

Riehl строит $\Pi_f$ «by a pullback diagram … that requires some explanation» (с.158–159). Для нашего зала это неподъёмно **в общем виде**. Но Riehl **Example 4.5.7 (с.159–160)** даёт случай Set руками: слайс над $X$ = индексированные семейства, экспонента = поточечная $(B_x^{A_x})$, элементы = зависимые функции.

**Вопрос захода — ровно один, и он про существо, а не про источник:**
> **Что минимально нужно залу, который знает CCC (Л3) и расслоённое произведение (Л4), чтобы понять зависимую функцию — и сколько это стоит в минутах?**

Что дать в карточках:
1. **Определение $\Pi_f$ в Set — руками**, дословно с номером страницы. Проверить: правда ли оно элементарно, то есть формулируется через уже выданное залу (произведение, экспонента, УС), без сопряжений и функторов. **Если НЕТ — так и скажи, это главный результат захода.**

Ищи опору в том, что зал держит по `SPEKA §Калибровка`: **матрицы (отлично) · векторные пространства (хорошо) · школьная арифметика**. Модули — НЕ знают. Абстрактное в.п. — слайд.

### 2.2 МОСТ — от $\Pi_f$ к унивалентным основаниям. Второе по порядку, но это ЦЕЛЬ КУРСА

**Аудит 17.07 нашёл дыру, и она твоя:** финал курса обещает «равенство есть изоморфизм», но **звена нет**. Нужна цепь: равенство $a = b$ — это тип → его элементы — доказательства → для пространств это пути → значит равенство несёт структуру группоида → унивалентность. **Сейчас это в программе слоган, а не построение.**

### ВЕРДИКТ ПО Πf — **ЭЛЕМЕНТАРНО (определение), с обязательной оговоркой (конструкция)**

Источник ответил, и однозначно. Вердикт — расщеплённый, и расщепление несущее:

- **Определение зависимой функции в Set — ЭЛЕМЕНТАРНО.** Дословно, Riehl **Example 4.5.7, печ. с.160**: *«elements of the set ∏ₓ Aₓ are dependent functions, functions f defined on the set X for which the output f(x) ∈ Aₓ belongs to the set Aₓ indexed by the input element x»*. Формулируется через ровно выданное залу: семейство множеств Aₓ, зависящее от x, + функция, попадающая в Aₓ. Обычная функция X→B — частный случай (все Aₓ равны): это не мой домысел, это дословно HoTT **§1.4, печ. с.25**: *«If B is a constant family, the dependent product type is the ordinary function type ∏B ≡ (A→B)»*. **Ни функторов, ни сопряжений, чтобы СФОРМУЛИРОВАТЬ, не нужно.**
- **Общая конструкция Πf-как-функтора — НЕ элементарна.** Riehl строит её *«by a pullback diagram … that requires some explanation»* (**печ. с.159**); слайс-экспонента = Πₐ∆ₐ (**Cor 4.5.13, с.163**) — замкнутость в слайс даром не поднимается. Я это **проверил прямым чтением конструкции**, а не унаследовал: подтверждаю вывод предшественника (`verdict-rifma-lccc`) с источником в руках.
- **Следствие для зала:** зависимую функцию в Set дать руками (~15 мин, см. бюджет); общий Πf — объявить-и-отложить (SPEKA «беглое упоминание»). Πf — настоящая, неустранимая цена LCCC, и она же (с.163–164) — входной билет в цель финала.

- **Π-тип**, **Σ-тип** (Pi-type, Sigma-type) — язык Martin-Löf; Π-тип = тип зависимых функций.
