## 1а. 🔴 СПОСОБ РАБОТЫ: скрипты вместо ручного труда

Это не совет, а требование заказчика, и оно определяет, как ты тратишь бюджет.

**Принцип.** Токен уходит на решение («какой должна быть картинка»), а не на исполнение
(«впечатать сорок пар координат»). Всё исполнение — скриптом, и скрипт можно гонять
бесконечно: он бесплатный.

**Заведи себе инструменты ПЕРВЫМ делом, до содержательной работы:**

1. **Генератор рисунков.** Не пиши SVG руками по точке. Напиши `tools/gen_ill.py`, который
   строит нужные фигуры из параметров: ломаная по списку шагов ±1, треугольник Паскаля на
   $N$ строк, ряд узлов, сетка-решётка, стрелка. Тогда «сделать треугольник до 10 строки
   вместо 7» — это правка одного числа, а не перерисовка. *Прошлый заход рисовал руками,
   и каждая правка владельца стоила полной перерисовки файла.*
2. **Петля «пересобрал → посмотрел».** `build_deck.py` работает секунды и не стоит ничего.
   Гоняй после каждой правки. У тебя, в отличие от аналитика, есть браузер — **пользуйся им
   постоянно**, а не в конце. Всё, что владелец назвал «некрасиво», «не влезло», «поехало»,
   ловится только глазами.
3. **Скриншоты пачкой.** `render.py` из канона дека снимает все слайды разом. Снимай все
   ~22 слайда одним прогоном и смотри — это дешевле, чем открывать по одному.
4. **Программные гейты — пиши свои, они окупаются мгновенно.** Обязательный минимум:
   - `data-scenes` на слайде **≥** максимума из `{@N}` и `blur@N` в его `content`;
   - каскады в `base.css` и `shablon.html` покрывают **все** сцены, какие есть в деке;
   - в собранном `dist` нет буквальных `{@N}` и `{blur@…}` (значит, разметка не распозналась);

   Оба ловятся десятью строками Python и не ловятся глазами.*
5. **Проверяй математику перебором, а не рассуждением.** В лекции есть числа, которые обязаны

## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- lsh-2026-perechislitelnaya/otkrytaya-lekcia-paskal/src/ _studio/zhurnal/2026-07-27_paskal-lekcia-sborka/kod_dek-paskal-v2.md                     # вводит НОВЫЕ пути в индекс

python3 _generator/tools/git_zona.py check --zone <зона>   # из корня репо; должен быть ✅
git --no-optional-locks show --stat                        # обязаны быть ТОЛЬКО твои пути
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*
⚠ **Хук `pre-commit` покраснел — сначала посмотри, на ЧЬИХ путях.**
- Красное на ТВОИХ путях (новый `.md` не зарегистрирован в `../../docs/KARTA.md §6`, битая ссылка) — **чини, не обходи**: там только твоё, обходить нечего.
- Красное на ЧУЖОМ, унаследованном долге (ворота дают сотни ❌ старых нарушений) — законный обход, но ТОЛЬКО с причиной; голый `--no-verify` инструмент отклонит, а причина сама уедет в `INCIDENTY.md`:

    --no-verify "чужой долг: <что именно покраснело>" -m "<что и зачем>" --push

Ту же причину назови отдельной строкой отчёта долгом. *Урок 9: обход был законен по канону и не существовал в инструменте — первый же коммит владельца встал на чужом долге.*
