## 4. 🔴 КОММИТ СВОЕЙ ЗОНЫ — ПОСЛЕДНИЙ ХОД ЗАХОДА, НЕ ОПЦИЯ
Ты работаешь host-side и в `.git` ПИШЕШЬ — значит коммитишь САМ, никому не передавая:
```
git --no-optional-locks add -- _generator/tools/sostoyanie.py _generator/tools/fixtures/sostoyanie _studio/konvejer/FORMAT-ISTOCHNIKA.md _studio/konvejer/GEJTY.md _studio/konvejer/KATALOG.md _studio/konvejer/06-tekst                     # вводит НОВЫЕ пути в индекс
git --no-optional-locks commit -m "<зона>: <что сделано>" -- _generator/tools/sostoyanie.py _generator/tools/fixtures/sostoyanie _studio/konvejer/FORMAT-ISTOCHNIKA.md _studio/konvejer/GEJTY.md _studio/konvejer/KATALOG.md _studio/konvejer/06-tekst   # отсекает всё чужое
python3 _generator/tools/git_zona.py check --zone <зона>   # из корня репо; должен быть ✅
git --no-optional-locks show --stat                        # обязаны быть ТОЛЬКО твои пути
```
🔴 **ОБА хода обязательны, ни один не лишний** (полное «почему» и цена — `../docs/kak-delat/GIT-disciplina.md §3`):
- **`add`** — pathspec-коммит знает только **отслеживаемые** пути; новый файл без `add` даёт `did not match any file(s) known to git`.
- **`-- <пути>` в самом `commit`** — иначе `commit` забирает индекс ЦЕЛИКОМ, вместе с чужим, застейдженным кем угодно рядом с тобой (репо `materials/` общий, писателей трое). *Обе половины оплачены 21.07 в один вечер: голый `commit` подмёл чужой индекс — коммит на 89 файлов вместо трёх; «починка», убравшая `add`, завалила все 10 коммитов повторно.*
⚠ **Хук `pre-commit` покраснел — сначала посмотри, на ЧЬИХ путях.**
- Красное на ТВОИХ путях (новый `.md` не зарегистрирован в `../../docs/KARTA.md §6`, битая ссылка) — **чини, не обходи**: там только твоё, обходить нечего.
- Красное на ЧУЖОМ, унаследованном долге (ворота дают сотни ❌ старых нарушений) — законный обход, но ТОЛЬКО с причиной; голый `--no-verify` инструмент отклонит, а причина сама уедет в `INCIDENTY.md`:
```
python3 _generator/tools/git_zona.py commit --zone <зона> \
    --no-verify "чужой долг: <что именно покраснело>" -m "<что и зачем>" --push
```
Ту же причину назови отдельной строкой отчёта долгом. *Урок 9: обход был законен по канону и не существовал в инструменте — первый же коммит владельца встал на чужом долге.*
**Коммит не прошёл по ВНЕШНЕЙ причине** (чужой лок, конфликт, detached HEAD) — чужое состояние репозитория НЕ чини: зафиксируй файлы и напиши в отчёт отдельной строкой «коммита нет, причина такая-то, нужно ваше действие». Это законный отчёт. Молчаливое «сделано» при незакоммиченной зоне — брак: приёмка гоняет тот же гейт первым ходом и завернёт отчёт, не читая (`RUKOVODSTVO §Приёмка`, гейт 0).

### Признак-на-диске писался по памяти об инциденте, а не грепом по живым файлам
Четыре из шести реализованных здесь признаков называют то, чего в репозитории нет: `G13` требует атрибут `data-scene="N"` (в четырёх живых деках — ноль вхождений, живой словарь `data-scene-from`/`data-scene-until`); `G14` считает сцены «по маркерам в тексте» (слайд с одной сценой маркеров не имеет по устройству, sim-слайд держит стадии в канвасе); `G15` требует каскад `.scene-1 … .scene-N` (`.scene-1` не бывает: сцена 1 — базовое состояние); `G7` требует ≤1 акцент-блока (а `06-tekst/DOK.md` тем же файлом велит набирать вопрос-заголовок жирным целиком). Каждая формулировка верна как описание инцидента и неверна как условие на диск.

**ЦЕНА:** буквальная реализация давала бы на первом же прогоне **24 ложных ❌ по `G14`, ❌ по `G15` на всех четырёх живых деках, 2 по `G13` и 12 разделов из 14 по `G7`** — при нуле настоящих долгов среди них. Заход сам называет, чем это кончается: гейт, краснеющий на здоровом деке, обходят `--no-verify`, и пропадает вся защита. Фактически оплачено здесь: заход на реализацию превратился в реализацию плюс полный перебор четырёх деков с замером каждого отступления, и без этого перебора результат был бы не «гейты есть», а «гейты есть и их обходят». Правило, которое из этого следует: **записывая признак-на-диске, прогнать его грепом по всем живым декам ТЕМ ЖЕ ходом и вписать в запись число совпадений** — иначе признак остаётся описанием прошлого, а не условием на настоящее.
