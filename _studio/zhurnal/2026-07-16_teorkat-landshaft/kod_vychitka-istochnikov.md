1. ⭐⭐ **У Маклейна элементарный топос определяется через 3-4 страницы после CCC** (гл.4 §§4.6→4.9→4.10), без отдельного тяжёлого аппарата — CCC (через сопряжения) → классификатор подобъектов → топос (пределы+классификатор+CCC). Это меняет расчёт бюджета лекции 9 (финал): путь короче, чем предполагалось волной 1, ЕСЛИ сопряжения уже даны залу к этому моменту.
2. ⚠ **Lawvere-Schanuel называет «cartesian closed» только на Session 31 из ~35** (~90% книги) — книга НЕ образец темпа для «CCC к 3-й»: годится как склад мотивационных ходов (Галилей, сократический диалог), но не как учебный план для копирования 1:1.
3. **CCC в источниках определяется ДВУМЯ разными путями** — элементарный (Ловер/Awodey, через evaluation map, без функторов) и через сопряжённые функторы (Маклейн). Для зала — только первый путь; второй — для лектора, как «другой язык той же вещи» в конце.
4. **Riehl §4.5 «Locally cartesian closed categories»** — прямой кандидат на закрытие дыры №1 (LCCC/Σ⊣f*⊣Π), не прочитан целиком — долг перед версткой лекции про LCCC.
5. **Лицензия CTI (CC BY-NC) конфликтует с платным курсом** — решение нужно от владельца до заимствования картинок (см. ВОПРОСЫ).
