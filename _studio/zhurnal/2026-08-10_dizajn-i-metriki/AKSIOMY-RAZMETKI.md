## §0. Словарь ролей — на чём всё держится

Модель владельца 2026-08-11: слайд состоит из блоков, и каждый блок несёт одну из
четырёх **ролей**.

| роль | сколько на слайде | кто это по типу |
|---|---|---|
| **центральный** | ровно 1 | `opredelenie` / `utverzhdenie` / `primer`; на служебных слайдах — `narrativ` |
| **вспомогательный** | 0 или 1 | `opredelenie` / `utverzhdenie` / `primer` |
| **нарратив** | сколько угодно | `narrativ` |
| **доказательство** | сколько угодно | `dokazatelstvo` |

🔴 **Роль ≠ тип.** Тип говорит, что это за математический кусок; роль говорит, какое место
он занимает на слайде. Один и тот же `utverzhdenie` бывает и центральным, и
вспомогательным. Сегодня в разметке есть только тип и поле `centralnyj_blok`; роль
«вспомогательный» не названа никак и вычисляется как «статусный блок, не являющийся
центральным».

**Живая картина ролей по 18 карточкам** (C — центральный, V — вспомогательный,
N — нарратив, D — доказательство, порядок слева направо — порядок на слайде):

```
bazis-i-matricy              VC        itog                         C
centr-gruppy                 CVD       itogi                        C
dvazhdy-dvojstvennoe         VCD       napominanie                  C
dvojstvennoe-prostranstvo    CV        razdelitel-estestvennost     C
fundamentalnaya-gruppa       NVC       razdelitel-retrakty          C
inyekcii                     CNVD      nekanonicheskij-izomorfizm   CD
izomorfizm                   NCV       teorema-brauera              CN
kategoriya                   CN        vektornye-prostranstva       CV
retrakt                      CVV  ⚠    zamena-bazisa                NCN
```

## §1. А1 — роли и их количества

**Предлагается.** На слайде ровно один центральный блок, не более одного вспомогательного,
любое число нарративов и доказательств.

**Держится ли.** Да, на **17 карточках из 18**. Единственное исключение — `retrakt` (`CVV`:
определение «язык ретракта», пример «в каких случаях подобъект оказывается ретрактом»,
утверждение «ретракт переживает функтор»). Владелец 2026-08-11 уже решил делить его надвое.

**Цена.** Ноль плюс деление одного слайда.

**Что даёт вёрстке.** Главное: она всегда знает, что выделять, и знает, что выделяемое
место ровно одно. Без этого любое правило выделения приходится обвешивать проверками
«а если их три» — именно на этом развалились два предыдущих варианта схемы.

**Вопрос.** Вносим А1 как обязательное правило фазы 1, с красным флагом гейта на нарушение?

## §2. А2 — вспомогательный примыкает к центральному

**Предлагается.** Вспомогательный блок стоит **вплотную** к центральному — непосредственно
до или непосредственно после, без блоков между ними.

**Держится ли.** Да, на **8 вспомогательных из 9** (не считая двух в `retrakt`).
Единственное исключение — `inyekcii` (`CNVD`): между центральным утверждением и примером
вклинился нарратив.

**Цена.** Перестановка двух блоков на одной карточке — либо признание, что там нарратив
законно разделяет, и тогда аксиома формулируется мягче.

**Что даёт вёрстке.** Это **прямой ответ на ваше опасение**, что вспомогательный сольётся
с нарративом. Если он стоит вплотную к выделенному центральному, он читается как его
спутник даже без единого собственного средства: рядом с выделенным блоком — значит про
него. Нарратив, стоящий отдельно, так не прочтётся. То есть А2 позволяет **не выделять
вспомогательный вовсе** — и не потерять его.

Побочно: направление примыкания уже несёт смысл, и размечать его не нужно.
Вспомогательный **до** центрального — подготовка (определение вводит понятие, дальше
главное утверждение: `VC`, `VCD`, `NVC` — 3 случая). Вспомогательный **после** —
развитие (главное сказано, дальше пример: `CV`, `CVD`, `NCV` — 5 случаев). Вёрстка может
дать этим двум случаям разный воздух, ничего не спрашивая.

**Вопрос.** Вносим А2? И если да — `inyekcii` переставляем или ослабляем аксиому до «между
центральным и вспомогательным допускается один нарратив»?

## §3. А3 — у каждого блока есть название, годное в печать

**Предлагается.** У блока есть название — как у слайда, — сформулированное академично:
оно называет, какой именно математический кусок блок несёт. Название **не обязано**
совпадать с тем, что печатается на экране (у слайда уже так: `nazvanie` и
`zagolovok_na_ekrane` — разные поля).

**Держится ли.** Поле есть у всех блоков — это текст после типа в `### [tip] название`.
По качеству картина такая:

- **Годятся в печать сразу** — центральные на содержательных слайдах: «категория и функтор»,
  «изоморфизм векторных пространств», «векторные пространства и линейные отображения»,
  «диск не садится на свою границу», «функтора центра не существует», «координаты вектора —
  линейные функции». Длины от 13 до 58 знаков, медиана около 30.
- **Не годятся и не должны** — центральные на служебных слайдах: «о чём лекция», «что мы
  видели», «о чём первая половина». Это чистая служебка, но там центральный блок нарративный
  и по правилу С1 спецификации не печатается вовсе. Конфликта нет.

🔴 **Отдельная находка, из-за которой аксиома вообще появилась.** Название центрального
блока **ни разу** не совпадает с названием слайда — 0 из 18. То есть на каждой карточке
уже написана вторая короткая формулировка, и она нигде не печатается. Это готовый
подзаголовок, который сегодня пропадает зря.

**Цена.** Дисциплина письма на фазе 1: формулировать название блока так, чтобы его не
стыдно было напечатать. Фактически уже соблюдается.

**Что даёт вёрстке.** Возможность напечатать у центрального блока **и родовое слово, и
название** — как вы и просили. Родовое слово («Определение», «Утверждение», «Пример»)
одним взглядом сообщает жанр слайда: вводим понятие, формулируем факт или разбираем
пример. Название сообщает, что именно. Вместе они дают слайду структуру, которой сейчас
не чувствуется, — ровно исходная жалоба.

**Вопрос.** Вносим А3? И печатаем ли по умолчанию у центрального блока обе строки — родовое
слово и название, — с возможностью отменить?

**Принята владельцем 2026-08-11.**

**Как сейчас.** В шапке карточки `illustracii: [izomorfizmy-primery]` — плоский список на

напротив определения.

**Цена.** Одно поле у элемента списка иллюстраций.

## §5. А5 — доказательство стоит за тем, что доказывает

**Предлагается.** Доказательство стоит **непосредственно** за блоком, который оно
доказывает.

**Держится ли.** Наполовину: из четырёх доказательств два стоят сразу за утверждением
(`nekanonicheskij-izomorfizm` — `CD`, `dvazhdy-dvojstvennoe` — `VCD`), а два — сразу за
**примером** (`centr-gruppy` — `CVD`, `inyekcii` — `CNVD`), хотя доказывают, судя по
названиям, центральное утверждение.

**Цена.** Перестановка блоков на двух карточках — либо явное поле «что доказываю».

**Что даёт вёрстке.** Две вещи. Первая: пару «утверждение + его доказательство» можно
**склеить** — не разрывать их при перевёрстке, держать общий отступ, при делении слайда
уводить вместе. Сейчас склеивать нечего, потому что связь неизвестна. Вторая: красный флаг
«утверждение без доказательства», который вы завели 09.08, становится точным вместо
эвристического.

**Вопрос.** Вносим А5? И если да — переставляем блоки на двух карточках или заводим поле?

## §6. А6 — слайд из одного блока — нарративный

**Предлагается.** Если на слайде ровно один блок, этот блок нарративный.

## §7. А7 — жанр слайда согласован с типом центрального блока

**Предлагается.** Поле слайда `tip_idei` согласовано с типом центрального блока:
`definition` ↔ `opredelenie`, `proof_step` ↔ `utverzhdenie`, `narrative` / `divider` ↔
`narrativ`.

**Держится ли.** Почти: **17 из 18**. Расхождение одно — `bazis-i-matricy`, где
`tip_idei: definition`, а центральный блок — утверждение «изоморфизм есть ровно тогда,
когда базисы одинаковой длины». Похоже на след старой редакции: слайд задумывался как
вводящий понятие, а стал формулирующим факт.

**Цена.** Ноль плюс разбор одной карточки.

**Что даёт вёрстке.** Не столько вёрстке, сколько честности разметки: два поля описывают
одно и то же с разных сторон, и их расхождение — сигнал, что карточка поехала. Дешёвый
гейт, который ловит именно тот класс ошибок, который вы ловили руками 09.08 («четырнадцать
определений на четырнадцать слайдов — я бы сказал, что что-то не так»).

**Вопрос.** Вносим А7 как гейт согласованности? Или `tip_idei` вообще выводить из

### А8 — доказательство всегда последний блок слайда

**Держится ли.** **4 из 4.** Ни одного исключения: `centr-gruppy` (`CVD`),
`dvazhdy-dvojstvennoe` (`VCD`), `inyekcii` (`CNVD`), `nekanonicheskij-izomorfizm` (`CD`).

**Цена.** Ноль.

**Обоснование владельца** (не подгонка под данные, а причина, по которой так и будет):
после длинного доказательства хочется перейти на следующий слайд; доказательство забивает
лимит времени, который лектор готов провести на одном кадре, независимо от того, что было
до него.

**Что даёт вёрстке.** Много: доказательство — единственный блок, который всегда прижат к
низу текстовой области. Значит его можно верстать как хвост — мелким кеглем, с прижимом к
нижней границе, и при переполнении резать слайд именно по его началу. Ни один другой блок
такого свойства не имеет.

### А9 — определение всегда первое среди статусных блоков

**Держится ли.** **7 из 7** — на всех слайдах, где определение есть: `bazis-i-matricy`,

### А10 — нарратив не разделяет два ненарративных блока

**Держится ли.** **17 из 18.** Единственное нарушение — `inyekcii`
(`utverzhdenie · narrativ · primer · dokazatelstvo`).

🔴 **Это тот же самый нарушитель, что у А2** — и не случайно: А2 (вспомогательный примыкает
к центральному) и А10 — одно и то же свойство, увиденное с двух сторон. Принимать их можно
одной правкой одной карточки. Итого **все нарушения всех семи аксиом сводятся к двум
карточкам**: `retrakt` (А1, вы уже решили делить) и `inyekcii` (А2 и А10).

**Что даёт вёрстке.** Нарратив становится честной рамкой: он бывает только в начале и в
конце, между содержательными блоками его нет. Значит выделенный центральный блок и его
спутник всегда стоят сплошным куском, и разрез можно вести по границе «рамка / ядро».

**Вопрос.** Вносим А10, правя `inyekcii` заодно с А2?

### А11 — пример всегда содержит маркированный список

**Держится ли.** **6 из 6.** Все шесть блоков-примеров несут маркированный список.

🔴 **Но обратное неверно, и это важно.** Список есть у 15 блоков из 39, и лишь 6 из них —
примеры. Остальные девять: `utverzhdenie` 4, `narrativ` 3, `opredelenie` 1,
`dokazatelstvo` 1. Пять буллетов стоят внутри определения «категория и функтор», четыре —
внутри нарратива «о чём лекция».

**Что это значит.** Замысел «пример узнаётся по списку и потому не нуждается в отдельном
коде» **не работает**: список примера ничем не отличается от списка утверждения, и читатель
по нему пример не опознает. Импликация односторонняя.

**Что из А11 всё-таки следует, и это полезно.** Раз пример гарантированно список:
- его высота предсказуема, смета может считать её точнее, чем для абзаца;
- структурный ход солвера «раздробить абзац в список» (наговор §7.2, `PLAN.md` Ч2.3) к
  примеру **неприменим** — там дробить уже нечего. Одной ветвью перебора меньше.

**Вопрос — и он новый.** Если примеру нужен собственный деликатный код (как у

## §8. Команды — числа считаются, не переписываются

Все числа выше сняты этими командами (`KONSTITUCIYA §10`).

```bash
# роли по слайдам, паттерны, окружение вспомогательного (§0, §1, §2, §6)
cd <корень materials> && python3 - <<'EOF'
import glob, re, collections
STAT = {'opredelenie', 'utverzhdenie', 'primer'}
pat = collections.Counter(); sosed = collections.Counter()
for f in sorted(glob.glob('teorkat-vvedenie/L2/slajdy/*/slaid.md')):
    txt = open(f, encoding='utf-8').read()
    c = re.search(r'^centralnyj_blok:\s*(.+)$', txt, re.M)
    cval = c.group(1).strip() if c else ''
    seg = re.search(r'^## Текст слайда.*?$(.*?)(?=^## |\Z)', txt, re.S | re.M)
    pairs = re.findall(r'^### \[([a-z_]+)\]\s*(.+)$', seg.group(1) if seg else '', re.M)
    roles = ['C' if m.strip() == cval else 'D' if t == 'dokazatelstvo'
             else 'V' if t in STAT else 'N' for t, m in pairs]
    print(f"  {f.split('/')[-2]:28s} {''.join(roles)}")
    pat[''.join(roles)] += 1
    for i, r in enumerate(roles):
        if r == 'V':
            sosed[(roles[i-1] if i else '·') + 'V' + (roles[i+1] if i+1 < len(roles) else '·')] += 1
print('паттерны:', dict(pat)); print('окружение V:', dict(sosed))
EOF
```
