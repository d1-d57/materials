# ТЗ арки «2026-07-13_l3-kodirovanie»

> Короткое ТЗ арки — форма из `../../docs/spravka/PROFILI-CIFERBLATY.md §TZ`. Фиксирует, ЧТО и ЗАЧЕМ.

- **Цель** — 3-е занятие курса «Информация и коды»: магические карточки → двоичная запись → листок кружковых задач на кодирование. Собрать **большой пул** задач-кандидатов, из которого владелец выберет состав листка.
- **Аудитория / скоуп** — сильный 6 класс, кружок-листок; профиль лёгкий-научпоп. Рассказ ≤30 мин + самостоятельное решение листка с устной сдачей преподу (как Л1/Л2).
- **Deliverable** — (1) **большой пул** задач на кодирование с УСЛОВИЯМИ (в картотеку `kartoteka/03-l3-kodirovanie.md`, для выбора владельцем — модель Л2 «пул→листок+резерв»); (2) после owner-ok — листок в 2 форматах (дети ч/б + препод с решениями, прецедент L1/L2) + гейты.
- **Границы / anti-scope** — «соврать один раз»/ошибки/Хэмминг/мудрецы → ПОСЛЕДНЕЕ занятие. Только БУМАЖНЫЕ задачи (без физического реквизита). Двоичное — на уровне «код», без формул.
- **Ворота go/no-go** — в пуле есть **≥3 простых ГАРАНТИРОВАННО неизвестных** задач (иностранные/непереведённые) + добор простых; центр лекции (карточки Клепцына) в руках.
- **Открытые вопросы (дефолты, не блок):**
  - Объём листка — ~10 (владелец: число задач не проблема, проблема — известность). Дефолт: ~10, из них ≥3 гарантированно-новых.
  - «Двоичный код» произносить термином или нет — владелец решит вживую на занятии.
  - Двоичное «на пальцах» ≈ кошельки #30278 (та же идея разрядов) → брать как ПОДВОДЯЩУЮ/разминку, переформулировать; не считать отдельной «новой».
