# РАЗВОД-156 — разбор корпуса «заходы и приёмка» на два дома

Судейская классификация 156 id из `_studio/zhurnal/2026-08-13_arhitektura-doma/srez-7.2-vhodnye-156.md` по критерию: **zahody** — про написание задания исполнителю (критерий готовности, зона, конвенции, `check_zahod.py`, каналы запуска, форма файла-захода); **priyomka** — про вернувшийся отчёт (гейты `priyomka.py` Г0–Г7, перегон числовых утверждений, влитие веток, уроки фабрике, хенд-офф-долг); **СПОРНЫЕ** — когда по одной строке без адреса первоисточника нельзя уверенно решить, или запись явно не про ни один из двух моментов. Судейство только по колонкам «что за инцидент» и «рычаг» исходной таблицы, максимально консервативно.
