## Контракт
**Вход.** Раскадровочная строка слайда (архетип + текст из арки 6 дословно + описание илл.) ИЛИ существующий слайд под правку; всегда — `tokens.css` дека (палитра/типо-токены).
**Выход.**
- `slides/<id>.html`: `<section class="slide" data-scenes="N">`, грид-зоны, слоты `{{MD:<id>}}`/`{{copy:zone}}`, пустые `data-ill` боксы под илл.;
- `content/<id>.md` (плакатный текст арки 6) — или дословный HTML как escape hatch;
- per-slide грид-CSS `#<id> .grid{…}` **внутри `shablon.html`** (см. решение ниже).
**Гейт.** Правка существующего → Р1 (render-identity). Новый слайд → машинно (в арке 10): 0 overflow `.zone`; `.t-body` ≥ 35px (4.3%H@810), НИКОГДА не уменьшать `--t-body`; фон-плашки только из `:root`-токенов дека; fit-группы консистентны. Плюс глаз (`render.py <src-путь>/dist/index.html [outdir]` — все слайды PNG; конкретный слайд — `?only=N&scene=99` в браузере, у `render.py` нет CLI-флага `--only`). Переполнение = делить слайд (SPLIT), не ужимать шрифт.

## Алгоритм (адаптация `per-slide-algorithm.md`, шаги 1→2→5→6)
1. **Текст сначала** — взять плакатный текст арки 6 дословно, не переписывать при вёрстке.
2. **Архетип → грид.** Выбрать архетип по справочной таблице (сайдбар 25%W · рейка 74%W · плашка 15/19.5%H · доска-полоса 44%H — статистика Canva-корпуса из `decks/02-buffon.md`), но CSS грида писать **point-wise на id слайда** (`#sNN .grid{}`), не абстрагировать в общие классы (см. решение).
3. **Роль fit vs body.** На display-элементы (Forum caps, цифры, рубрики) вешать `.fit`+`data-max`; body-текст — фиксированный `--t-body`, НИКОГДА не фитится. «Куда вешать `.fit`» — решается по типу элемента, слайд за слайдом.
4. **Порядок починки переполнения** (уже в `overlay.css`/`shablon.html` обоих деков, здесь — чек-лист): блок-гэп → отступ формулы → перераспределение grid-rows → **только в конце** фиттер. Не влезло после этого → SPLIT слайда наверх, в раскадровку.
   🔴 **Почему блок-гэп стоит ПЕРВЫМ — с числом:** база даёт промежуток между абзацами = ПОЛНАЯ пустая строка (58px при кегле 38), и у слайда с девятью блоками одни промежутки съедали **428px из 740 — половину зоны**. Без этого числа чинят грид и кегль, то есть не то.
   🔴 **Кегль и ступень плотности считаются от САМОЙ ТЯЖЁЛОЙ СЦЕНЫ, а не от всего текста слайда.** *Цена: медиана слайда 968 знаков, максимум 2441 при медиане КАДРА 410 ⇒ наивный прогон опустил бы все 32 слайда на пол 35px под текст, которого зал никогда не видит разом.*
5. **Рендер + глаз:** `render.py <src-путь>/dist/index.html [outdir]` (все слайды PNG); конкретный слайд — `?only=N&scene=99` в браузере (у `render.py` нет CLI-флага `--only`).

## Переносим дословно
Two-plane core (paper/board/card, острые стыки, текст всегда `#333`, акцент = Bold + один охряный `.acc`); блочный ритм — ОДИН `copy p+p{margin-top:26px}`, ОДИН `--t-body` без уменьшенных `.t-small` (`.t-small{font-size:var(--t-body)}`); порядок починки переполнения (выше). Это документируется как чек-лист — не изобретается. **Уточнение:** «нет уменьшенной `.t-small`» верно только благодаря буффон-оверрайду `overlay.css:36` (`.t-small{font-size:var(--t-body,38px)!important}`, комментарий автора «не кустарно»), который бьёт `#sl-result .t-small{26px}` из `shablon.html`; у dandelin ни токена `--t-small`, ни этого правила нет вовсе — greenfield-дек, скопировавший только `tokens.css`+`shablon.html`, получит РЕАЛЬНО уменьшенный `.t-small`, если не перенести нейтрализацию (или осознанно принять меньший размер).

## Решение: bespoke грид, не общие классы
Ни dandelin, ни buffon НЕ используют общие классы `fr-sidebar`/`fr-board` — каждый `#sNN .grid` bespoke под слайд, грид живёт в `<style>` шаблона (отдельный `grids.css` из `DESIGN.md §4` — аспирационный контракт, на деле не используется). **Арка 7 наследует практику:** архетипы = справочная таблица «что где сидит», код грида — point-wise на id. Общие архетип-классы НЕ вводить преждевременно (для GREENFIELD можно пересмотреть, но по умолчанию — bespoke).

## Уточнение про padding (вскрыто сверкой с живым кодом)
«No padding on zone» — правило только для зон С `.fit`-элементами (фиттер читает `clientWidth/Height`, паддинг искажает измерение). Зоны с фиксированным `--t-body` спокойно носят паддинг через утилиту (`.pad{padding:46px 56px 0 56px}`, слито с `.zone`: `<div class="zone pad">` в dandelin). Закрепить это разделение явно, не копировать общее «zero padding» буквально.

Ничего (Р3). `frontend-design`/`web-typography` — только свободный режим, вне scope (канон заморожен).

## Разнообразие вёрстки (Р24) + типографика
- **Варьировать раскладку** — не гнать все слайды одной (текст-сверху / илл-снизу). Архетипы дают словарь: горизонтальная полоса, вертикальная полоса слева/справа, без полос, сайдбар. Единый визуальный ЯЗЫК ≠ одинаковая РАСКЛАДКА (прецедент #14 — монотонность).
- **Опорные точки (Р23)** — выделенное **цветное СЛОВО-надзаголовок** (Forum caps): «Задача N» `--brick`+номер · «Определение» `--cgreen` без номера · «Утверждение»/«Теорема» общий `--steel` (между собой не различаются); слово у левого поля, формулировка ниже на всю ширину, БЕЗ точки в конце; не растворять в потоке; картинка ПОСЛЕ формулировки. (НЕ буквица/цифра-номер на поле — развёрнуто в #14.)
- **Формулу НЕ разрывать переносом строки** («2×10» цельно; переносится соседнее слово, не формула).
- **Обложка** — без несогласованных подписей (только название, если подзаголовок не задан явно).

## Ловушки

### 🔴 Оплачено на арке `2026-07-28_konspekt-l1` (дата данных: 2026-07-30)

- **КЛЮЧ ФАЙЛА СОСТОЯНИЯ — УСТОЙЧИВОЕ ИМЯ, А НЕ ПОЗИЦИЯ `sNN`.** Пер-слайдовые словари ручной доводки (`plotnost.json`, `ritm.json`, `reflow.json`, `PRAVKI`, `KARTINKI`) адресуются по позиции в потоке; любое снятие, слияние или перестановка слайда сдвигает всё ниже, и **оплаченная глазами правка молча уезжает на чужой слайд**. «Ни один гейт этого не ловит по построению: ключ существует, css применяется, линтер зелёный, `audit.py` ALL PASS.»
  *Цена — пять независимых записей четырёх исполнителей плюс два закомментированных ключа с тем же диагнозом в самом сборщике: вернувшееся переполнение **+182px** на слайде, доведённом до нуля предыдущим заходом, и **+351px** на другом; **7 слайдов молча зажаты** до максимальной ступени вместо нужных 2, потому что подгонщик умеет только ПОДНИМАТЬ ступень (пришлось обнулять состояние и считать с нуля); 6 переполнений на слайдах, к которым исполнитель не прикасался; **~20 минут диагностики за час до эфира**; две ручные правки применились к слайду с другим числом сцен и к слайду, которого в деке нет вовсе. И мёртвая запись **ОЖИВАЕТ** при следующем сдвиге нумерации, наводя чужие интервалы.*
  ⇒ **Нужен ГЕЙТ, а не абзац** (правило «переносить состояние по карте» существовало и было нарушено четырежды подряд теми, кто его знал — `../../docs/KONSTITUCIYA.md §11`): сборка роняется, если ключ ручной доводки указывает на слайд, сменивший заголовок или число сцен. Долг — в `../../docs/sostoyanie/OTKRYTYE-ZADACHI.md`.
- **НОМЕР СЛАЙДА ЧИТАЕТСЯ С ЭКРАНА РЕПЕТИЦИИ** — это инструмент адресации правок, а не декор. *Цена: владелец **дважды называл слайды наугад и сбивался**, пока не разглядел номера в середине второго акта: «я увидел нумерацию, наконец… **А я не вижу. Она просто полупрозрачная так, мелкая**» — то есть весь первый акт и половина второго адресовались по неверным номерам, и это питало главную болезнь арки (адрес правки, `../../docs/kak-delat/RUKOVODSTVO-zahodami.md §Заход`). «Чинится кеглем и контрастом за один ход.»* ⚠ **И как это НЕ делается: CSS-счётчик здесь не работает по построению** — движок листает дек через `display:none` (`engine.js`), а `counter-increment` на элементах без бокса не применяется, поэтому на всех слайдах стоит «1». *Цена: один лишний круг реализации; спасло только то, что исполнитель померил номер В БРАУЗЕРЕ, а не грепом — `grep -c 'counter-increment'` по собранному деку давал 1 и был бы принят как доказательство пункта критерия.* Работающая форма: отдельный элемент `.nomer` внутри `.slide`, но ВНЕ `.grid` и без класса `.zone` (иначе попадёт в промер), номер в него пишет генератор из ПОЗИЦИИ в потоке — руками не вписывается нигде (`../../docs/KONSTITUCIYA.md §10`).
- **ЗАГОЛОВКА СЛАЙДА В ДЕКЕ НЕТ — названный долг.** Проверено дважды двумя заходами: `<h1>/<h2>` в собранном `dist/index.html` — **0 штук**. Владелец при этом требует заголовок у каждого слайда (`../06-tekst/DOK.md`). Пока слоя нет, всякая правка заголовка есть правка ленты и оглавления документ-вида, и заход обязан сказать это вслух, а не исполнить молча.
- **Доля одного архетипа ДОКЛАДЫВАЕТСЯ ЧИСЛОМ и краснеет выше двух третей, но арка 7 архетип не меняет** — это мандат арки 5 (`../05-raskadrovka/DOK.md`).
- Процентная высота внутри auto-sized grid-row молча схлопывается в размер контента (тянет SVG до ~2000px) → всегда `minmax(0,1fr)` или явные px/fr в `grid-template-rows`.
- Два `.fit` в одной зоне проходят по отдельности, переполняют вместе → один `.fit` на зону.
- Архетипные проценты — ориентир поиска, не копипаст: слепой перенос на новый слайд без проверки объёма текста поймает только глаз (Р1-гейт есть лишь для регрессии, не для нового слайда).
