# Арка 6 — Плакатный текст · GREENFIELD (семя-корпус готов)

> **Когда:** раскадровка (арка 5) дала слайды с архетипом+смыслом+сценами; надо написать текст слайда. · **Вход:** на слайд — archetype + дистилляция смысла + сцены + описание илл. + унаследованные регистр и бюджет слов деки. · **Выход:** содержимое `.text` в md со шорткатами Р2. · **Гейт:** «плакатный баланс достигнут» (8 пунктов). · **next:** арка 7 (вёрстка). · **Семя:** `../../zhurnal/2026-07-10_sborka-konvejera/distillat-text-stil.md`.

Локальный инструмент стиля (Р4): плакатный баланс собран из корпуса `content-studio/assets/corpus/texts-corpus.md` (6 деков, 189 текстовых слайдов) + `references/slide-voice.md`. `russian-editor` (литературный) для слайда НЕВЕРЕН — только гигиена опечаток/«ё». Термины — точечно во внешний `math-russian-terminology`, всё остальное локально.

## Контракт
**Вход** (на слайд, из арки 5): `archetype` + «дистилляция смысла» (сжатый тезис, НЕ проза) + список сцен (что появляется на каждой) + описание илл. (род+смысл, чтобы текст её не дублировал) + **унаследованные на уровне ДЕКА**: регистр (устная лекция vs самостоятельное чтение) и бюджет слов. Регистр/бюджет НЕ решаются заново на каждом слайде.
**Выход** — `.text` в md: обычные предложения + `**acc**` + `{@N}` + `{fill@N|бланк|заполнение}` + `{blur@N|ответ}` + `$tex$` (формула, транскрибированная из уже выверенного гибрид-источника, не изобретённая). Без html-тегов, без подписей-на-картинке, без финальной точки.
**Гейт «плакатный баланс достигнут»:** (1) объём в бюджете регистра деки; (2) мысль закончена — слайд читается без лектора; (3) архетипный паттерн соблюдён; (4) акцент экономен (0–1 `**acc**`); (5) без подписи-описания илл.; (6) сцены — шорткатами, не дублированием почти одинаковых слайдов; (7) формулы перенесены, не передоказаны и не юникод-приближены; (8) не влезло после честного сжатия → сигнал «делить слайд» наверх, в раскадровку, не уминать.

## Правила плакатного стиля
- **Плотность — потолок, не квота.** Медиана корпуса ≈45 слов/3 предложения; НО регистр деки решает: устные (Бюффон 30, «Мороженое» 33 слов/слайд — лектор договаривает голосом) vs читаемые (Графы 57, Бертран 55, Марковские 49, Тождества 44). Плотный `text-only` без картинки — до 3 абзацев/350–650 знаков; слайд с илл. — заметно меньше. Ориентир — медиана, не «max» корпуса (там шум: pdftotext считает словами цифры внутри картинок-решёток).
- **Голос** — приглашающий «мы/вы»: раздуем, вспомним, возьмём, вернёмся, рассечём. Слайд — общий шаг, не лозунг и не диктовка.
- **Заголовки называют тему, не спойлерят и не открываются разговорно:** «Оптические свойства», не «А теперь про оптику». Вопрос-заголовок — жирным целиком: «**Что такое эллипс?**».
- **Без финальной точки** в конце блока; точки между предложениями внутри блока — остаются.
- **Тире по минимуму** (0–1 на слайд); где было бы третьим на двух строках — точка с запятой/точка.
- **`**acc**` экономно** (0–1 на слайд): на тезис-вывод или вопрос-заголовок целиком («Кратчайший путь — там, где углы равны»), не декоративно.
- **Читать вслух** — убирать неестественное и слова с двойным дном («кнопка» = *button*).
- **Точность термина — где содержание требует** (сечение конуса даёт эллипс, не «срез»). Сам термин фиксирует внешний скилл, но РЕШЕНИЕ «здесь нужна точность» — локальное.
- **Списки — только для перечней** (биография, программа), не замена связной мысли.
- **Caps — это CSS-трансформ сборки, НЕ авторская печать.** Писать `Введение в графы`, НЕ `ВВЕДЕНИЕ В ГРАФЫ` (`.title` в mockup-template обычным регистром, капс делает `text-transform`).
- **Текст не описывает иллюстрацию** — несёт мысль, которую картинка поддерживает, без «на картинке показано X».

## Архетип → текст (паттерны)
| Архетип | Паттерн | Пример корпуса |
|---|---|---|
| `title` | Название + повод/место, без глагола, ~5–8 слов | «Геометрия мороженого / Наука и мороженое · 12 июня» |
| `vizitka` | Микро-блок, список строк | «Про меня / Матфак ВШЭ / 179 школа / …» |
| `divider` | 1–3 слова, называет главу, без спойлера | «Оптические свойства», «II. Связность» |
| `divider`-микро (в слайде) | 1–4 слова капс-ярлык, называет только что выведенное | «Сумма степеней», «Лемма о рукопожатиях» |
| `text-illu` | 1–3 предложения; часто открывается голой строкой-подзаголовком/вопросом, затем тело; payoff → `**acc**` | «Что такое эллипс?» → «Зацепим нитку…» |
| `full-illu` | Минимум текста или ярлык 2–8 слов, никогда абзац | «Граф коня» |
| `proof` | Сцена = один шаг построения, 5–15 слов, кончается связкой «значит/поэтому»; через `{@N}` | «Раздуём…» {@1} → «…значит, сечение это эллипс» {@2} |
| `sim` | Рамочный текст задаёт правило/вопрос, не спойлерит результат (он в canvas) | «После каждого броска найдём долю игл…» |
| `text-only` | Единственный, где можно 3 абзаца/до ~650 знаков | — |

**Под-паттерн «биография»:** «Имя (годы) — идентичность[, факты]»: «Жорж-Луи Буффон (1707–1788) — французский биолог, математик…». Готовый шаблон слайда-знакомства.

## Опорные точки (Р23)
«Задача N» (номер по первоисточнику) / «Утверждение» / «Теорема» / «Определение» — выделенный узнаваемый ярлык, не растворять в научпоп-потоке. Формулировка задачи/определения — из первоисточника ДОСЛОВНО (не переписывать через голос, в отличие от связок-прозы); картинка/доказательство появляется ПОСЛЕ формулировки. Визуальный контракт — `../07-verstka/DOK.md`.

**Доказательный дек: условие-слайд vs proof-слайд (прецедент #14).** Различай два типа: **условие-слайд** несёт текст (Задача/Определение — из первоисточника дословно); **proof-слайд** несёт ≈НОЛЬ текста (доказательство = картинка/канвас, текст — только ярлык). Плакатный потолок «до 3 абзацев» — для `text-only`, НЕ для proof. **Голос-корпус обязателен на входе** (`content-studio/assets/corpus/texts-corpus.md`) ИЛИ текст даёт владелец/Cowork готовым — сборщик своей прозы НЕ пишет (иначе не тот голос: ночной прогон #14 сочинял текст сам → эссе-подводки, забраковано).

## Алгоритм: раскадровка → md
1. Прочитать вход слайда + унаследованный регистр/бюджет деки (не выбирать регистр на слайде).
2. Свернуть «дистилляцию смысла» в одно предложение-тезис — кандидат на `**acc**`.
3. Выбрать текстовый паттерн по архетипу (таблица).
4. Черновик в голосе корпуса; новый/спорный термин — пометить для `math-russian-terminology` (батчем по деку, дешевле).
5. **Сцены — шорткатами, не дублированием.** Дельта между сценами: (а) новый кусок → `{@N|…}`; (б) плейсхолдер→контент → `{fill@N|бланк|заполнение}`; (в) готовый ответ скрыт до реакции зала → `{blur@N|ответ}`. **Схлопывать** старый анти-паттерн reveal-дублей (Бюффон 16→17, 18→19→20) в ОДНУ md-запись со сценами.
6. Формулы — `$tex$`, ровно то, что прошло гейт «математика верна» в источнике; не передоказывать/упрощать/юникод-приближать (настоящий LaTeX для статического KaTeX-кэша, Р7).
7. `**acc**` экономно (0–1), убрать финальную точку, тире ≤1, прочитать вслух.
8. Гейт «плакатный баланс». Не прошёл → шаг назад к 3–4, не точечная правка. Не влезло после честного сжатия → «делить слайд» в раскадровку.

## Граница: стиль ИСТОЧНИКА vs СЛАЙДА
Источник (арка 4) — ближе к журнальной прозе (полные связки, вводные, мета-рассказ, `<details>`). Слайд (арка 6) — плакатный: связки и мета-рассказ вырезаются, 2–3 предложения, слайд = законченный бит. **Запрет:** НЕ копировать абзацы источника на слайд дословно — всегда переписывать через фильтр голоса корпуса, даже если смысл идентичен.

## Открытые вопросы
- **Раскадровка (арка 5) должна передавать регистр+бюджет слов деки как структурное поле** — иначе арка 6 не знает, целиться в 30 или 45+ слов. (Вход в контракт арки 5→6.)
- Нет проработанного примера перевода reveal-дубля (Бюффон 18→19→20) в одну Р2-запись — прогнать вручную ДО первого дека.
- Связка `**acc**`→`accent_tag` (`b`/`span`) читается арками 7/8/10 — end-to-end не проверена.
- Момент вызова `math-russian-terminology` (по слайду vs батч по деку) — рекомендация батч, решением не зафиксировано.
