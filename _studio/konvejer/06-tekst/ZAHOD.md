## 2. ЗАДАЧА — что снять, что сохранить дословно
На каждый раздел `^## ` ленты — один файл `src/content/<id>.md`.

**СНЯТЬ (в дек не идёт):**
- `<figure>` … `</figure>` целиком вместе с `<figcaption>` — в ленте подпись объясняет рисунок читателю,
  на слайде рисунок объясняет лектор (`DOK.md §Оформление внутри ленты`). Иллюстрация приезжает в дек
  отдельным слоем `illustrations/` через `data-ill` в `slides/<id>.html`, не текстом.
- строку бокового поля `> поле:mn **Раскладка.** …` — раскладку реализует арка 7, читая её из ленты;
  в тексте слайда ей делать нечего. Другие `поле:mn`-врезки — так же.
- сам заголовок раздела `## …`, если он служебный (совпадает с названием слайда в раскадровке и на
  слайде не печатается). Заголовок, который ЕСТЬ текст слайда (вопрос-заголовок жирным целиком) —
  оставить как обычную строку.
- фронтматтер файла ленты (`tab:`/`status:`/`poryadok:`/`registr:`) и заголовок блока `# Блок …`.

**СОХРАНИТЬ ДОСЛОВНО, посимвольно:**
- шорткаты Р2: `{@N}`, `{@N|…}`, `{fill@N|бланк|заполнение}`, `{blur@N|ответ}`, классовые `{.cls}`;
- акценты `**acc**` — ровно столько и там же, где в ленте (тег `b`/`span` подставит генератор из
  `accent_tag`, руками его не писать);
- формулы `$tex$` и `$$tex$$` — символ в символ, без «упрощений» и юникод-приближений;
- разбиение на абзацы и отсутствие финальной точки.

**НЕ ДОБАВЛЯТЬ:** html-теги (единственное исключение — точечный escape hatch, уже стоявший в ленте вне
`<figure>`), подписи-описания иллюстраций, свои связки между абзацами.

**КРИТЕРИЙ ГОТОВНОСТИ** (проверяемый, способен провалиться — по каждому файлу, не одной галочкой):
1. Для каждого `id` из `slide_order` существует непустой `src/content/<id>.md`; файлов-сирот вне
   `slide_order` нет. Проверка — сравнением множеств, не глазами.
2. `grep -c '^## ' <лекция>/raskadrovka/teksty/*.md` в сумме == длине `slide_order`, и каждый раздел
   ушёл ровно в один файл (таблица из `## ПЛАН` сошлась построчно).
3. `grep -l '<figure\|<figcaption\|поле:mn' <лекция>/src/content/*.md` → пусто.
4. `grep -nE '<[a-zA-Z]' <лекция>/src/content/*.md` → только заранее названные в отчёте escape hatch'и,
   ноль неучтённых (это же требует G6: `regex <[a-zA-Z]` не должен совпадать).
5. Число `{@`/`{fill@`/`{blur@` и число `**` в порождённых файлах совпадает с их числом в ленте после
   вычета снятых `<figure>`-блоков. Расхождение = шорткат или акцент потерян при переносе.
6. `python3 _generator/tools/sostoyanie.py <лекция>` — G7 остался PASS (ленту ты не тронул), G6 не
   краснеет по строке «`content/<id>.md` порождены».
7. `python3 _generator/build_deck.py <лекция>/src --lint` → **exit 0** (код возврата назвать первым):
   0 нерезолвленных `{{…}}`, 0 `⟦MISSING-MATH⟧`, все шорткаты сцен резолвятся.

## 3. ВЕРИФИКАТОР
Операция **лоссовая по построению** — ты выбрасываешь `<figure>` и `поле:mn`, а значит можешь выбросить
лишнее. Поэтому отдельным свежим проходом (холодным взглядом или субагентом), НЕ тем же, что переносил:
- **механически:** пп. 3, 4, 5 критерия — грепом, с числами в отчёте;
- **посимвольно:** взять три случайных раздела ленты и их порождённые файлы и сверить текст между
  снятыми блоками дословно — не «похоже», а посимвольно. Тихая потеря одного абзаца или одной формулы
  видна только так.
Результат — по каждому файлу «прошёл / не прошёл + почему», не общий вердикт на дек.
