# GEJTY — реестр гейтов конвейера (данные для трекера)

> **Когда читать:** строишь трекер-скрипт (заход ③) или каталог (заход ④); нужен полный список дверей фабрики и способ проверить каждую по диску. · **Что это:** структурная таблица — КАЖДЫЙ гейт как запись `id · стадия/граница · что проверяет · признак-на-диске · тип · возврат-разрешён`, которую скрипт-трекер проверяет автоматически (или помечает браузерным для ручного прогона). НЕ алгоритм-проза (та — `ALGORITM.md`) и НЕ реализация трекера (та — заход ③, вне этого файла). · **Куда дальше:** драйвер, который эти гейты вызывает — `ALGORITM.md`; формат Фазы II — `FORMAT-ISTOCHNIKA.md`.

## Как читать эту таблицу
- **тип** — `жёсткий-стоп-вперёд` (блокирует переход на следующий шаг, пока не зелёный) · `автор-чекпоинт` (требует вкуса/взгляда владельца, механически не решается) · `дисциплина-хук=WARN` (предупреждает по ходу работы ДО гейта-границы, не блокирует). Гейт может нести оба типа сразу (авто-часть + чекпоинт-часть) — тогда указаны через `+`.
- Пометка **[браузерный]** — трекер (заход ③) не проверяет автоматически в CI/скрипте без браузера; выносит отдельным пунктом «прогнать локально у владельца» (Playwright/`render.py`/`audit.py`).
- **возврат-разрешён** — да/нет по смыслу «гейты не рельсы» (`ALGORITM.md §Модель исполнения`): да означает, что провал этого гейта — штатный повод для волны назад по конвейеру, а не тупик.
- ✅ **Размещение Фазы I РЕШЕНО** (Cowork, консолидация Волны 1): канон — `../docs/spravka/PAPKA-LEKCII.md` (`brief.md` в корне · `kartoteka/KARTA-OBLASTI.md` · `istochniki/{MANIFEST,VYCHITANO,TERMINY}.md` · `kotly/matematika.md` · `kotly/naupop.md` · `chernovik/rasskaz.md`). Признаки-на-диске ниже приведены к нему. Слой `skelet` физически = **`kotly/matematika.md`** (математика-котёл, растущий в строгий слой, Р19); `chernovik/skelet.md` — опциональный замороженный снимок сборки 4b, по умолчанию цитируется `kotly/matematika.md`.

## Гейты-границы Фазы I (5)

### G1 · бриф закрыт (граница 1→2)
- **что проверяет:** бриф полон (8 полей: тема · аудитория · длительность→бюджет слайдов · throughline-кандидат · что резать · материал/референс · уровень строгости · формат события+лекция/курс); throughline назван ОДНОЙ фразой; бюджет слайдов посчитан арифметически (не угадан).
- **признак-на-диске:** `<лекция>/brief.md` существует; содержит 8 непустых полей (точные ключи фиксирует `01-brief/ZAHOD.md`, напр. `тема:`,`аудитория:`,`длительность:`,`бюджет_слайдов:`,`throughline:`,`что_резать:`,`материал:`,`строгость:`,`формат_события:` — свериться при первом деке); поле `throughline:` — однострочное значение; поле `бюджет_слайдов:` — целое число, кратное делению длительности на 2.
- **тип:** жёсткий-стоп-вперёд
- **возврат-разрешён:** да (throughline не подтверждается ресёрчем/раскадровкой → правка брифа, контракт B14)

### G2 · ресёрч закрыт (граница 2→3)
- **что проверяет:** ≥5 разных источников; ни одной находки без карточки; в материале реально есть «но» (разворот, не пересказ).
- **признак-на-диске:** в `<лекция>/kartoteka/KARTA-OBLASTI.md` каждый блок-карточка рода `находка|утверждение|биекция|мостик` содержит непустое поле `источник:` (0 карточек без источника при грепе блоков); ≥5 уникальных значений `источник:` (по префиксу файла/книги/URL); поле `статус: на-сверку` ИЛИ явная текстовая пометка разворота присутствует хотя бы у одной карточки.
- **тип:** жёсткий-стоп-вперёд (источники+карточки — авто) + автор-чекпоинт (честность разворота «но» — вкус, не грепается надёжно)
- **возврат-разрешён:** да (разворота нет → тема нечестно не тянет, чекпоинт владельцу B8)

### G3 · математика верна (граница 3→4)
- **что проверяет:** 0 открытых `⚑ Флаг`; уровень-тег на каждом мат-блоке; нотация единообразна по всему потоку; термины сверены с `TERMINY.md`; adversarial ре-ревью пройдено.
- **признак-на-диске:** grep `⚑ Флаг` по `<лекция>/kotly/matematika.md` → каждое совпадение имеет ниже по файлу парный `Флаг закрыт:` (0 непарных); grep `Утверждение|Определение|Лемма|Следствие|Теорема` → в пределах следующих ~5 строк каждого совпадения есть `> поле:уровень`.
- **тип:** жёсткий-стоп-вперёд (флаги+уровень-тег — авто) + автор-чекпоинт (adversarial ре-ревью, нотация единообразна — вкус/внимательное чтение)
- **возврат-разрешён:** да (флаг не закрыт/нотация плывёт → доработка внутри арки 3, не выход из неё)

### G4 · источник закрыт (граница 4→5)
- **что проверяет:** 0 открытых `⚑ Флаг`; математика в видимом слое в финальном объёме; throughline держит от начала до конца; каждый такт имеет 🖼-описание; цитаты-сноски резолвятся в реальные `skelet`-якоря (0 сирот).
- **признак-на-диске:** grep `⚑ Флаг` по `<лекция>/chernovik/rasskaz.md` → 0 непарных; grep `🖼` по `chernovik/rasskaz.md` → число вхождений ≥ число тактов нити (сверить со списком тактов в карте); каждая цитата-сноска в `chernovik/rasskaz.md` (напр. `[skelet#<якорь>]`) резолвится в существующий якорь слоя skelet `kotly/matematika.md` (0 висячих ссылок).
- **тип:** жёсткий-стоп-вперёд (греп-часть) + автор-чекпоинт (полнота/нарратив — B10, механический греп и человек ловят разное)
- **возврат-разрешён:** да (throughline не держит / дыра в ресёрче → назад в арку 2/4a, добор, не выдумка)

### G5 · раскадровка закрыта (граница 5 → вход Фазы II)
- **что проверяет:** `slide_order` покрывает `slides/` без пропусков/сирот; на каждый слайд заполнены archetype+дистилляция+сцены+илл.-описание; регистр+`word_budget_per_slide` зафиксированы явно в `brief.md`.
- **признак-на-диске:** `<лекция>/src/brief.md` фронтматтер содержит непустой список `slide_order:`; для каждого `<id>` из списка существует файл `<лекция>/src/slides/<id>.html`; множество id из `slide_order` == множеству basename-файлов `slides/*.html` (0 сирот/дублей — тот же чек, что линтер арки 10 §1); `brief.md` содержит непустые `register:` и `word_budget_per_slide:`.
- **тип:** жёсткий-стоп-вперёд
- **возврат-разрешён:** да (throughline не режется на слайды чисто → назад в арку 1/4, эхо B14)

- **возврат-разрешён:** да (не готово → назад в Фазу I, арка 5)

## Гейты Фазы II (5)

### G7 · плакатный баланс (граница 6→7)
- **что проверяет:** 8 пунктов гейта арки 6 — объём в бюджете регистра; мысль закончена; архетипный паттерн соблюдён; акцент экономен (0–1 `**acc**`); без подписи-описания илл.; сцены шорткатами, не дублированием; формулы перенесены, не передоказаны; не влезло после честного сжатия → сигнал SPLIT.
- **признак-на-диске:** для каждого id из `slide_order` существует непустой `<лекция>/src/content/<id>.md`; подсчёт слов файла укладывается в `word_budget_per_slide`±допуск из `brief.md`; файл не содержит html-тегов (regex `<[a-zA-Z]` не совпадает — запрет по контракту `06-tekst/DOK.md`); grep `**` — не более одного акцент-блока на файл (эвристика).
- **тип:** жёсткий-стоп-вперёд (бюджет слов, отсутствие html — авто) + автор-чекпоинт (голос/паттерн/законченность мысли — вкус)
- **возврат-разрешён:** да (не влезло после честного сжатия → SPLIT слайда наверх в раскадровку, B-аналог)

### G8 · вёрстка (граница 7→8)
- **что проверяет:** 0 overflow `.zone`; `--t-body` не уменьшен; палитра только из `:root`; fit-группы консистентны.
- **признак-на-диске:** [браузерный] `_generator/audit.py <src>/dist/index.html` → overflow `.zone`==0; статически — grep hex-цветов (`#[0-9a-fA-F]{3,6}`, вне `tokens.css`) в `slides/*.html` == 0 (палитра только токенами); grep значения `--t-body` в `slides/*.html`/`shablon.html` не встречает переопределения меньшим числом, чем в `tokens.css`.
- **тип:** жёсткий-стоп-вперёд [часть браузерная] + автор-чекпоинт (глаз — `render.py`)
- **возврат-разрешён:** да (переполнение → починка по чек-листу порядка; не влезло → SPLIT в раскадровку)

### G9 · сцены без дед-кликов (граница 8→9/10)
- **что проверяет:** каждый клик что-то меняет (нет дед-кликов); связка вне блюра; геометрия заморожена между сценами.
- **признак-на-диске:** [браузерный] `--scene-diff` (`_generator/audit.py`) → последовательные сцены отличаются только добавленными пикселями; статически — grep `{blur@` в `content/*.md`: связка-символ (`≈`,`=`,`⇒` и т.п.) НЕ является первым child внутри того же `{blur@…|…}` (регулярка «связка вне фигурных скобок blur»).
- **тип:** жёсткий-стоп-вперёд [браузерный — локально у владельца] + дисциплина-хук (связка вне блюра — статически грепаемо)
- **возврат-разрешён:** да (дед-клик найден → назад в арку 8, разметка шорткатов)

### G10 · иллюстрации (граница 9→10)
- **что проверяет:** каждый `var(--x)` внутри иллюстрации определён в `tokens.css` (иначе чёрная заливка без ошибки в консоли); SVG не переполняет бокс; id внутри SVG несут per-file префикс (0 конфликтов при инлайне нескольких).
- **признак-на-диске:** статический lint `build_deck.py.lint()` — regex `var\(--[\w-]+\)` из каждого `illustrations/*.svg` сверяется с `:root{}` собранного `tokens.css` (0 неопределённых имён, без браузера); [браузерный] `audit.py` `svgOverflow`==0; grep `id="` по всем `illustrations/*.svg` одной колоды — 0 совпадающих значений id без stem-префикса.
- **тип:** жёсткий-стоп-вперёд (lint-часть — авто без браузера) + [браузерный — локально у владельца] (`svgOverflow`)
- **возврат-разрешён:** да (неопределённый var/переполнение/id-конфликт → починка внутри арки 9)

### G11 · сборка + QA, 5 слоёв (финальный, дёшево→дорого)
- **что проверяет:** линтер → render-identity (только правка, greenfield N/A) → аудит → scene-diff → глаз; FAIL на любом слое → назад на виновный шаг конвейера.
- **признак-на-диске:** exit-код `python3 _generator/build_deck.py <лекция>/src` == 0 (0 нерезолвленных `{{...}}`, 0 `⟦MISSING-MATH⟧`, `data-ill`/`data-iframe` резолвятся, `var(--x)` определён, 0 внешних src/href, `slide_order` = точное покрытие `slides/`); для правки существующего дека — [браузерный] `render.py --compare orig rebuilt` даёт `cmp` exit 0 (нормализованный посимвольный дифф); [браузерный] `audit.py` PASS (WARN не валит FAIL); [браузерный] `--scene-diff` PASS; финально — глаз владельца на `render.py`-PNG (не автоматизируется).
- **тип:** жёсткий-стоп-вперёд (слой 1 — авто без браузера; слои 2–4 — [браузерный]) + автор-чекпоинт (слой 5, глаз)
- **возврат-разрешён:** да (FAIL на любом слое → назад на виновный шаг, не только внутри арки 10). Greenfield-нюанс: слой 2 (render-identity) N/A без `provenance_sha256` — гейт = слои 1+3+4+5.

## Дисциплина-хуки (5, WARN — continuous, не граница)

### H1 · карточка без источника
- **стадия:** арка 2 (ресёрч), continuous по ходу сессии, до гейта G2.
- **что проверяет:** карточка рода `находка|утверждение|биекция|мостик` заведена без поля `источник:`.
- **признак-на-диске:** grep блоков карточек в `<лекция>/kartoteka/KARTA-OBLASTI.md` — блок между `id:` и следующим `id:` не содержит строки `источник:`.
- **тип:** дисциплина-хук=WARN
- **возврат-разрешён:** н/п (WARN не блокирует; чинится тем же ходом сессии; эскалирует в G2, если не починено к гейту)

### H2 · источник без дайджеста VYCHITANO
- **стадия:** арка 2, continuous, до первой карточки, ссылающейся на источник.
- **что проверяет:** источник упомянут (заведён в списке источников/карточках), но нет предшествующего дайджеста `VYCHITANO`.
- **признак-на-диске:** для каждого уникального значения `источник:` в `<лекция>/kartoteka/KARTA-OBLASTI.md` — существует запись-дайджест для `<источник>` в `<лекция>/istochniki/VYCHITANO.md`.
- **тип:** дисциплина-хук=WARN
- **возврат-разрешён:** н/п

### H3 · висячее ребро в KARTA-OBLASTI
- **стадия:** арка 2, continuous.
- **что проверяет:** `id`, упомянутый в чьих-то `связи:`, отсутствует как заведённый узел графа.
- **признак-на-диске:** множество всех `id:` в `kartoteka/KARTA-OBLASTI.md` минус множество всех id, встречающихся в любом `связи: [...]` любой карточки — разность в сторону «упомянут, но не заведён» должна быть пустой.
- **тип:** дисциплина-хук=WARN
- **возврат-разрешён:** н/п

### H4 · открытый `⚑ Флаг` без парного `Флаг закрыт` (раннее предупреждение)
- **стадия:** арка 3 (и остаточно арка 4 — только сверка), continuous ДО гейта G3/G4.
- **что проверяет:** маркер долга висит незакрытым дольше текущего шага сессии (мягче G3 — предупреждает по ходу, не только на выходе).
- **признак-на-диске:** grep `⚑ Флаг` по `<лекция>/kotly/matematika.md` в произвольный момент сессии (не только на гейте) → количество непарных >0 → WARN.
- **тип:** дисциплина-хук=WARN
- **возврат-разрешён:** н/п (эскалирует в жёсткий G3, если не закрыт к границе 3→4)

### H5 · `slide_order`-сироты/дубли (раннее предупреждение)
- **стадия:** арка 5/10, continuous при любой правке `brief.md`/`slides/`.
- **что проверяет:** `slide_order` расходится с фактическим множеством файлов `slides/` (пропуск, файл-сирота без записи, дублирующая запись).
- **признак-на-диске:** `set(slide_order)` == `set(basename(slides/*.html) без .html)`; любое расхождение → WARN до сборки (на слое 1 гейта G11 то же расхождение эскалирует в жёсткий FAIL).
- **тип:** дисциплина-хук=WARN (эскалирует в жёсткий-стоп-вперёд на слое 1 гейта G11)
- **возврат-разрешён:** н/п
