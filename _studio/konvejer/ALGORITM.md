Фабрика — две фазы одного конвейера. **Фаза I «индивидуальность»** (1–6): интерактив, вкус автора, гейты автора, возвраты-волны — нормальный режим работы (математика/ресёрч растут волнами, не линией); кончается **предвёрсточным документом** (шаг 6), а не раскадровкой. **Фаза II «механика»** (7–10): индивидуальность уже заперта в гибрид-источнике, раскадровке и принятых текстах — линия детерминирована, «почти как на Python». Обе фазы делит один принцип: **гейт — не декорация, гейт — реальная дверь**, и одна дисциплина: **состояние живёт на диске, не в памяти сессии**.

## Модель исполнения (общий преамбул — обе фазы)
- **Состояние живёт на диске** (KONSTITUCIYA §8), не в памяти чата. Фаза I: карточный граф + котлы (doc-движок) + слой `skelet` + гибрид-источник (`rasskaz`‖`skelet`) — растут per-лекция (расположение — канон `../docs/spravka/PAPKA-LEKCII.md`, решено консолидацией В1). Фаза II: `<лекция>/src/` по `FORMAT-ISTOCHNIKA.md`.
- **Сессия = вызов функции.** Между шагами (и часто внутри волнового шага) контекст НЕ держится в памяти — каждый вызов стартует с пустого контекста, читает названное (пакет шага + накопленный контекст лекции на диске), пишет обратно на диск, отдаёт наверх дистиллят, а не сырьё. Исключение, явно прописанное DOK: арки 2→3 (B9) и 4a→4b идут ОДНОЙ сессией без обнуления — состояние передаётся через контекст чата, не только через диск.
- **Гейты — НЕ рельсы.** Гейт — это дверь между шагами (закрыта → не дальше), а не одностороннее конвейерное движение. **Возвраты-волны разрешены и являются нормой**, особенно в Фазе I: математика и ресёрч растут волнами (grounded в модели Каталана — карточный граф пополняется, нить перерисовывается, находка на шаге 4 дописывает карточку в шаге 2). Волна = явно поднятый и зафиксированный откат назад с починкой upstream-слоя, потом повтор гейта. **Дефект — не сама волна, а МОЛЧАЛИВЫЙ прыжок вперёд через незакрытый гейт** (сборка со старым гибрид-источником, раскадровка при открытом `⚑ Флаг`, слайд-текст без зафиксированного регистра). Гейт закрыт — либо чинить на месте, либо явно откатиться на виновный upstream-шаг; тихо продолжать вперёд — запрещено.
- **Cowork судит по гейту** (не построчно), двигает дальше или возвращает на точечную дочистку. Развилку, требующую вкуса, поднимает владельцу.

## Фаза I (шаги 1–6): ВОЛНОВОЙ драйвер

```
# драйвер Фазы I (псевдокод, волновой — возвраты не исключение, а режим)
state = <лекция>/          # brief.md · kartoteka/ (карточки+KARTA-OBLASTI, оба котла тегом) · istochniki/ (VYCHITANO,TERMINY) · kotly/ (matematika=skelet ‖ naupop) · chernovik/rasskaz.md
                            # ^ канон размещения — ../docs/spravka/PAPKA-LEKCII.md (решено В1); см. GEJTY.md
for step in [1, 2, 3, 4, 4.5, 5, 6]:       # 4.5 — интервью с владельцем, БЛОКИРУЮЩАЯ (G16); 6 — предвёрсточный документ, последний авторский чекпоинт
    assert precondition(step, state)          # гейт предыдущего шага закрыт; иначе стоп → предыдущий шаг
    chat = open_claude_code() if not same_session(step) else current_chat
      # ^ 2→3 (B9) и 4a→4b — ОДНА сессия без обнуления; иначе — свежий пустой контекст
    feed(chat, f"konvejer/{step}/ZAHOD.md")
    run(step)                                  # растит/пишет state; волна допускает несколько проходов ДО гейта
    for fork in forks(step):                   # напр. throughline-кандидат, тег-котла, proof-self-review
        if fork.needs_taste: ask_owner(fork)       # точка взаимодействия
        else: decide_by_criterion(fork)            # по правилу из DOK
    if wave_finds_gap(step):                   # НАХОДКА ВОЛНЫ (напр. нить 4a обнажила дыру в графе 2)
        raise_to_owner(gap)                        # поднять явно, не чинить молча
        back_to(upstream_step)                     # ПЕТЛЯ назад — нормальный режим, не исключение
    if not gate(step).passed:                  # критерий-который-может-провалиться из ZAHOD/GEJTY
        fix_in_place() or back_to(step or upstream)
    snapshot(state)                            # точка отката (git), сверка после
# выход: шаг 5 наполнил <лекция>/src/, шаг 6 дал предвёрсточный документ (лента + view.html)
#        — СТОП-точка автора; см. «Стык Фаза I → Фаза II» ниже
# ВАЖНО: шаг 6 идёт в Cowork с владельцем, а не в свежей сессии Claude Code (исключение из строки chat выше).
#        Кругов правки может быть много — это норма шага, а не провал гейта.
```

Для каждого шага: **вход · действие(→DOK) · выход(слой) · гейт · развилки/чекпоинты**. Полный контракт — в `NN/DOK.md`.

**1 · Бриф / лёгкая разведка** (`01-brief/`). Вход: запрос владельца (тема + минимальный контекст, одна фраза допустима). Действие: короткая фикс. последовательность вопросов с предложенными дефолтами (метод the-interviewer+brainstorming, перенесённый внутрь, Р17); НЕ решает «тянет ли тема» — это работа арки 2. Выход: бриф фиксированной формы, **8 полей** (тема · аудитория · длительность→бюджет слайдов · throughline-кандидат · что резать · материал/референс · уровень строгости · формат события+лекция/курс). Гейт: все 8 полей полны · throughline одной фразой · бюджет посчитан арифметически · строгость и формат события явные. Развилки: формат микро-интервью (A1 — уже развилка редизайна, НЕ переоткрывать здесь, см. `01-brief/DOK.md`); throughline не держится дальше по конвейеру → возврат сюда (контракт B14, ниже).

**2 · Ресёрч = карточный граф** (`02-reserch/`). Вход: бриф (1). Действие: широкий ресёрч БЕЗ навязанного сюжета — гуглим широко, ходим в стороны; каждая находка ТЕМ ЖЕ ходом становится карточкой-узлом (`id·род·суть·котёл·находка·связи·уровень·источник·статус`), тегом котла `математика|научпоп` на ОДНОМ графе (не два набора — решено, Р19); карта связей `KARTA-OBLASTI`; per-project `TERMINY.md` заводится и пополняется. Выход: карточный граф + `KARTA-OBLASTI` + `TERMINY.md`, читаемые doc-движковым двухвкладочным видом. Гейт: ≥5 разных источников · ни одной находки без карточки (греп по `источник:`) · в материале реально есть «но» (разворот, не пересказ). Развилки: разворота нет → тема нечестно не тянет — **чекпоинт владельцу** (B8), не тянуть дальше.

*(2→3 — одна сессия без обнуления, B9: карточный граф остаётся в контексте чата, арка 3 не пересобирает его с нуля.)*

**3 · Строгая матбаза = слой `skelet`** (`03-matbaza/`). Вход: карточки котла математика той же сессии (2). Действие: разворачивает каждую находку-карточку в полный блок Определение/Утверждение/Доказательство+Источник+Уровень; честный мат-долг маркером `⚑ Флаг:` → закрывается `Флаг закрыт:` с обоснованием, СНИМАЕТСЯ здесь, до выхода из арки; проверка `proof-self-review` **ВНУТРЬ, шагами** (холодная пере-читка как рецензент, численная сверка на малых значениях, при доступности — свежий субагент-рецензент, Р17, ratified владельцем 2026-07-10). Выход: слой `skelet` финального объёма, с якорями, 0 открытых флагов. **Гейт «математика верна?» — жёсткая дверь**: каждое утверждение сверено с источником · без логических прыжков · нотация единообразна по всему потоку · термины сверены с `TERMINY.md` · adversarial ре-ревью пройден (по блокам «прошёл/не прошёл+почему»). Развилки: нет короткого доказательства в литературе → честный `Флаг закрыт: краткого нет`, НЕ синтез «по мотивам» (не вкусовая развилка — жёсткое правило).

**4 · Нарратив + гибрид-источник** (`04-gibrid-istochnik/`, линчпин Фазы I). Вход: карточный граф с выросшим `skelet` (гейт 3 зелёный — жёсткое предусловие, антипаттерн «платоновых тел»). **4a Нарратив** (своя сессия, тянет нить из графа): выбирает именованный маршрут узлов (затравка→…→кульминация→выход), собирает `rasskaz` (5 актов, process-first, «из-за этого» между актами, закольцовка на §0, честный зазор напоследок); нить обнажила дыру → добор ресёрча возвратом в арку 2 (НЕ выдумывать факт). **4b Сборка**: сшивает `rasskaz`(видимый)‖`skelet`(строгий) цитатой-сноской (решено, Р19 — не `<details>`); 🖼-описания (род·смысл·N сцен) на каждый такт. Выход: закрытый гибрид-источник. Гейт «источник закрыт?»: 0 открытых `⚑ Флаг` (греп) · математика в видимом слое в финальном объёме (сверено со `skelet`) · throughline держит от начала до конца · каждый такт имеет 🖼-описание · цитаты-сноски резолвятся в реальные `skelet`-якоря (0 сирот) · **автор-чекпоинт** на нарратив/полноту (B10 — механический греп и человек ловят разное). Развилки: под-стадия 4a housed внутри `04-gibrid-istochnik/` (без renumber — решено, Р19, НЕ переоткрывать).

**4.5 · Интервью с владельцем** (`04.5-intervyu/`, **БЛОКИРУЮЩАЯ фаза**, заведена 05.08.2026). Вход: закрытый гибрид-источник (4) + бриф (1) + **живой артефакт-эталон того же жанра** для замера габарита командой. Действие: интервью кругами — вопросы, допускающие ответ «да/нет», у каждого варианта названа ЦЕНА в величине артефакта (минуты/слайды/знаки/круги), не больше четырёх вопросов за раз, пропорция спрашивается ЧИСЛОМ, порядок сброса назначается заранее; кругов **сколько угодно**, признак последнего — «не знаю, как ответить» или повтор владельца (на живой сессии 05.08 их было шесть, и шестой дал архитектуру лекции); интервью ДВУСТОРОННЕЕ — интервьюер проверяет математику владельца, называет противоречия с ранее записанным и спрашивает «в чём ось», прежде чем чинить; перечень выясняемого — `04.5-intervyu/ANKETA.md`, **которая дополняется тем же ходом** всяким вопросом, найденным в живом интервью. Выход: **`<проект>/KONTRAKT-<артефакт>.md`** — утверждённый владельцем контракт из пяти частей (0 рамка с ИЗМЕРЕННЫМ габаритом · 1 законы формы · 2 перечень единиц выхода поимённо карточками `ВОПРОС · ОТЛИЧИЕ · ОПИРАЕТСЯ · ВВОДИТ · ОТКУДА · ВРЕМЯ` · 3 открытые пункты с датами · 4 порядок работы) + запись кругов в `<арка>/INTERVYU.md`. Гейт: **G16 «контракт утверждён владельцем»** (шесть пунктов, **автор-чекпоинт, БЛОКИРУЮЩИЙ**: пока красный — арки 5–10 не стартуют; пункт «названия предъявлены владельцу в чате» механически не проверяется). Развилки: владелец отвечает «надо думать» → **законный ответ**, кладётся в открытые пункты с датой, дожимать запрещено; ответ зависит от того, как это выглядит → делать макет, а не спрашивать словами (но макет идёт после текстовых кругов, если владелец так распорядился); ответ отменил прежнее решение → пометка `🔴 ОТМЕНЯЕТ ПРЕЖНЕЕ` с обеими датами. 🔴 Главный тезис фазы: **глубокий ресёрч НЕ заменяет интервью и создаёт ложное ощущение готовности** — из тридцати разобранных инцидентов фабрики ни один не был багом сборки.

**5 · Раскадровка** (`05-raskadrovka/`, внутри Фазы I). Вход: **утверждённый контракт `KONTRAKT-<артефакт>.md` (4.5, гейт G16 зелёный)** + закрытый источник (4) + бриф (1). Действие: режет источник на слайды по нити — на КАЖДЫЙ: archetype (из таблицы) · дистилляция смысла (сжатый тезис, НЕ финальный текст) · список сцен (≤3) · описание иллюстрации (род+смысл+феасибилити); считает бюджет слайдов (число×2мин ≈ длительность из брифа); **финализирует** поле `register`+`word_budget_per_slide` в `brief.md` (контракт 5→6, главное отличие от старой формы). Выход: кликабельное HTML-демо + наполнение `<лекция>/src/`: канон-скелет (копия) · `slides/<id>.html` рамочные каркасы · `illustrations/<name>` плейсхолдеры · `brief.md` со `slide_order`+`accent_tag`+регистр+бюджет. Гейт «сколько слайдов и что на каждом — ясно?»: `slide_order` покрывает все слайды без пропусков/сирот · на каждый заполнены archetype+дистилляция+сцены+илл.-описание · регистр+бюджет зафиксированы ЯВНО, не подразумеваются. Развилки: throughline не режется на слайды чисто → возврат в арку 1/4 (контракт возврата явно не проговорён — открытый вопрос, дублируется в DOK); структура записи слайда (атрибуты-на-каркасе vs таблица в brief vs гибрид) и форма кликабельного демо — открытые развилки владельцу, не решаются здесь.

**6 · Плакатный текст → предвёрсточный документ** (`06-tekst/`, **конец Фазы I**, СТОП-точка автора). Вход: раскадровка (архетип+смысл+сцены+илл.) + регистр/бюджет + гибрид-источник. Действие: плакатный текст со шорткатами Р2 — **интерактивно, в Cowork, с владельцем**, сразу в финальном объёме и стиле; раскладка слайда решается здесь же (`поле:mn **Раскладка.**`); иллюстрации на первом круге — плейсхолдерами. Выход: **лента** `raskadrovka/teksty/<блок>.md` + собранный `view.html` (`../disciplina/_generator/build_doc.py`, пересборка бесплатна — гонять после каждой правки), из них порождаются `src/content/<id>.md`. Гейт: **G7 «предвёрсточный документ принят»** (10 пунктов, автор-чекпоинт; ключевой — чтение ленты целиком). Развилки: не влезает после честного сжатия → **SPLIT наверх, в раскадровку**, либо **канвас** — но не обрывок формулировки (`06-tekst/DOK.md` §Пункт 2); регистр/бюджет не переданы → **чекпоинт**. Внутреннее: термины — сверка с `TERMINY.md` (Р17, не внешний вызов). **Кругов правки много — это норма шага:** здесь правка стоит копейки, в Фазе II — дорого.

## Контракт возврата throughline (B14, сквозной по Фазе I)
throughline брифа (1) — КАНДИДАТ, не приговор. Если ресёрч (2) не подтверждает разворотом, или нарратив/раскадровка (4/5) обнаруживают, что нить не держится / не режется на слайды чисто — **поднять владельцу явно**, не чинить молча и не тянуть дальше на честном слове. Это конкретный случай общего правила «гейты не рельсы»: волна назад в арку 1 — норма, а не откат к провалу.

## Фаза II (шаги 7–10): существующий детерминированный драйвер
Индивидуальность автора уже заперта в Фазе I (гибрид-источник + раскадровка). Здесь линия детерминирована — «почти как на Python»: конкретные шаги, жёсткое чтение, ясные развилки, каждый шаг в своём чате Claude Code.

- **Состояние живёт на диске** (см. общий преамбул): `<лекция>/src/` (растёт по слоям) + накопленный контекст лекции (гибрид-источник арки 4, раскадровка арки 5). Между шагами контекст НЕ держится в памяти — каждый шаг стартует с пустого контекста и читает названное.
- **Один шаг = один чат Claude Code.** Из Cowork показываешь ему `konvejer/NN-<имя>/ZAHOD.md`; он читает свой `DOK.md` + `FORMAT-ISTOCHNIKA.md` + `PRIMERY.md` + накопленный контекст, делает шаг, пишет в СВОЙ слой `src/`, отдаёт отчёт.
- **Cowork судит по гейту** (не построчно), двигает дальше или возвращает на точечную дочистку. Развилку, требующую вкуса, поднимает владельцу.

```
# драйвер Фазы II (псевдокод)
state = <лекция>/src/                      # + гибрид-источник, раскадровка как контекст
assert precondition_phase2(state)          # вход Фазы II готов (см. выше); иначе → Фаза I
for step in [7, 8, 9, 10]:                 # 9 может идти параллельно 8 (см. DAG); шаг 6 — в Фазе I
    assert precondition(step, state)       # нужные слои на месте; иначе стоп → предыдущий шаг
    chat = open_claude_code()              # свежий пустой контекст
    feed(chat, f"konvejer/{step}/ZAHOD.md")
    run(step)                              # пишет в свой слой src/, не трогает чужие
    for fork in forks(step):               # напр. SPLIT слайда, 3D-vs-SVG, регистр
        if fork.needs_taste: ask_owner(fork)   # точка взаимодействия
        else: decide_by_criterion(fork)        # по правилу из DOK
    if not gate(step).passed:              # критерий-который-может-провалиться из ZAHOD
        fix_in_place() or back_to(step or upstream)   # ПЕТЛЯ, не вперёд
    snapshot(state)                        # точка отката (git), сверка после
# выход: шаг 10 собрал dist/index.html + прошёл 5 слоёв гейта
```
