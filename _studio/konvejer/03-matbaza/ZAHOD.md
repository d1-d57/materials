## 4. ВЕРИФИКАТОР
Гейт «математика верна?» — и есть верификатор, причём ДРУГИМ методом относительно «написал вывод»:
холодная пере-читка каждого доказательства как рецензент (не автор) — это proof-self-review ВНУТРЬ. По
каждой единице: (а) греп — закрыт ли `⚑ Флаг`; (б) есть ли источник; (в) есть ли прыжок / потерян ли
вопрос-мотивировка; (г) сходится ли численно/логически конец с началом. При доступности параллельных
заходов — свежий субагент-рецензент на независимую пере-проверку (ДРУГОЙ проход). НЕ звать внешний
`proof-self-review` до решения владельца. Результат — по каждой единице «прошёл / не прошёл + почему».
