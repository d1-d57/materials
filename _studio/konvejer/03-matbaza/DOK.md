# Арка 3 — Строгая матбаза = слой skelet (математика-котёл) · GREENFIELD

> **Когда:** ресёрч (арка 2) в ТОЙ ЖЕ сессии собрал карточный граф; карточки котла `математика` надо вырастить в строгий слой `skelet` — полные доказательства из логичных вопросов. · **Вход:** карточки котла математика + карта/источники того же графа (не пересборка с нуля). · **Выход:** слой **`skelet`** — Определение/Утверждение/Доказательство/Источник/Уровень, в финальном объёме, с якорями; 0 открытых `⚑ Флаг`. · **Гейт «математика верна?»** — жёсткая дверь между 3 и 4. · **next:** арка 4 (нарратив 4a + сборка источника 4b) — та же сессия/накопленный контекст. · **Модель:** `../../docs/spravka/FAZA-1-REDESIGN.md` (стадия 2, математический документ). · **Грунтовка:** `distillat-format-teksta.md` (§2/§5, шаблон skelet), `distillat-catalan-kartochki.md`.

Арка 3 — вторая половина ОДНОГО потока 2→3 (B9): не отдельный вызов, а продолжение сессии арки 2 без обнуления. Это математический котёл в его строгой форме — **«эталон истины»** для авторской вычитки: доказательства несвёрнутые, в полном объёме. Критерий котла (редизайн): **лекцию можно заменить набором вопросов, отвечая на которые слушатель сам переизобретёт математику** — каждый шаг вырастает из логичного вопроса, ничего не падает с неба. Формат-инвариант верхней Фазы I — **markdown-поток doc-движка** (вкладка `Математика`, `build_doc.py` → `view.html`), НЕ рукописный HTML (старый one-stream отменён).

## Слой `skelet` — шаблон на блок (grounded в `distillat-format-teksta §2/§5`, не изобретать)
Строгий мат-текст, наследующий порядок из карточного графа; КАЖДЫЙ сегмент по шаблону Каталана:
```
Определение N (…).                      ← нумерация сквозная по всему потоку
Утверждение N (Теорема/Лемма/Следствие).
Доказательство. … $\blacksquare$        ← настоящий LaTeX в $…$/$$…$$, не юникод-приближение
> поле:источник <книга §/стр>           ← поле карточки «источник», развёрнутое как inline-провенанс
> поле:уровень школьно | требует-приручения | вне-школы   ← поле карточки «уровень»
```
Уровень-тег ОБЯЗАТЕЛЕН на каждый мат-блок (дешёвая, нагруженная смыслом пометка честности). Растит доказательства из карточек котла математика: карточка несла `находку` (связь/удивление) — skelet разворачивает её в полный вывод. В конце потока — хвостовой бэклог **«Пробелы и точки для следующей волны ресёрча»** (закрытые пункты зачёркиванием) — дёшево, даёт аудиторский след.

## Мат-долг = `⚑ Флаг → Флаг закрыт` (A3 в markdown-виде; B11)
Честный долг (авторский, не-цитатный результат до верификации; или утверждение, требующее вывода) помечается прямо в тексте маркером **`⚑ Флаг:`** (грепаемый, виден в рендере) и закрывается позже строкой **`Флаг закрыт:`** с обоснованием (проверено подстановкой/верификатором). Это редизайн-эквивалент старого «мат-долга» `<details class="math-debt">` (A3-Б), нативный для doc-движка (демо `_generator/doc-demo/matematika.md`). **Арка 3 закрывает и снимает долг** до гейта 3→4 (её зона — вывод); арка 4 только сверяет, что открытых флагов не осталось (B11). Нет короткого доказательства в литературе → честная пометка `Флаг закрыт: краткого вывода нет, приводим формулировку+ссылку`, НЕ выдумка «по мотивам».

## Гейт «математика верна?» — метод proof-self-review ВНУТРЬ (Р17)
Дверь между 3 и 4: арка 4 не стартует нарратив, пока гейт не зелёный (иначе провал «платоновых тел» — нарратив раньше, чем математика заперта). Проверка:
- каждое утверждение сверено с ≥1 авторитетным источником;
- каждый шаг вывода без логических прыжков (читается как доказательство, не пересказ результата);
- нотация единообразна по ВСЕМУ потоку;
- термины — сверены с per-project `TERMINY.md` (не внешний скилл, см. ниже);
- **adversarial пере-review** — метод `proof-self-review`, перенесённый ВНУТРЬ короткими шагами (Р17, не вызов): (1) холодная пере-читка каждого вывода как РЕЦЕНЗЕНТ, не автор; (2) численная сверка конца с началом на малых значениях; (3) при доступности параллельных заходов — свежий субагент-рецензент на независимую пере-проверку ДРУГИМ проходом. Результат — по каждому блоку «прошёл / не прошёл + почему», не общий вердикт.

## Стык с аркой 4
Арка 4 получает карточный граф с выросшим слоем skelet (математика финального объёма, с якорями, верифицированная) + карточки котла научпоп. **4a (нарратив)** тянет НИТЬ из графа в `rasskaz`; **4b (сборка)** сшивает `rasskaz`+`skelet` цитатой-сноской (модель Каталана: два параллельных слоя, видимый цитирует строгий — НЕ переписывает вывод). Арка 4 не трогает математику, обрамляет её.

## Ловушки
- **Нарратив/линия до закрытия гейта.** Тянуть нить или полировать прозу, пока хоть один `⚑ Флаг` открыт, — запрещено (диаграмма провала). Гейт «математика верна?» — жёсткая дверь.
- **Выдуманное доказательство.** Нет короткого вывода в литературе → честный `Флаг закрыт: краткого нет`, НЕ синтез «по мотивам».
- **Разнобой нотации** по потоку → гейт валится (единообразие по ВСЕМУ потоку, не по абзацу).
- **Термин «на слух».** Не сверен с `TERMINY.md` → риск неканоничного названия, расползётся в арки 4/6.
- **SVG-набросок руками.** Сложный шаг просит картинку → оставить пометку `🖼 …{N}` (демо-синтаксис), не рисовать (арка 9).
- **Не срезать вопрос-мотивировку.** Шаг без логичного вопроса, из которого он вырастает, ломает критерий котла («слушатель переизобретёт») — восстановить мотивировку.
