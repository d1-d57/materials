## 1. Блок skelet по шаблону Каталана (ГРУНТОВКА §2/§5)
Карточка котла математика (`area-defect`, арка 2) выросла в строгий блок — из логичного вопроса, полный вывод:
```markdown
## Утверждение 4 (сферический избыток).
Площадь треугольника на сфере радиуса $R$ равна $S = R^2(\alpha+\beta+\gamma-\pi)$.

Доказательство. Продолжим стороны до больших кругов — они рассекают сферу на двуугольники (луны).
Луна с углом $\theta$ имеет площадь $2R^2\theta$ (доля $\theta/\pi$ от полусферы $2\pi R^2$).
Три пары лун втрое накрывают треугольник и его антипод; складывая площади шести лун,
$$4R^2(\alpha+\beta+\gamma) = 4\pi R^2 + 4S,\qquad\text{откуда}\qquad S = R^2(\alpha+\beta+\gamma-\pi). \quad\blacksquare$$

> поле:источник Girard 1629; вывод по Rosenfeld 1988 гл.1; ср. Coxeter §6.4
> поле:уровень требует-приручения
🖼 Сфера, три больших круга, шесть лун разного цвета; треугольник в пересечении. {2}
```
Что работает: вырос из логичного вопроса («не прячется ли площадь в избытке углов?» — карточка `находка`);
вывод ЦЕЛИКОМ, не «≈ по площади лун» — эталон истины; `> поле:источник` + `> поле:уровень` (обязателен);
настоящий LaTeX; пометка `🖼 …{2}` ТЕКСТОМ (SVG не рисуется, арка 9); якорь `Утверждение 4` стабилен —
арка 4 сошлётся, сшивая цитатой-сноской.

## 2. `⚑ Флаг → Флаг закрыт` — честный долг, снят аркой 3 (ГРУНТОВКА `doc-demo`, B11)
Долг помечается в потоке и ЗАКРЫВАЕТСЯ той же аркой 3 до гейта 3→4:
```markdown
⚑ Флаг: знак в замкнутой форме — свериться подстановкой малых $n$.
...
Флаг закрыт: знак верный, проверено подстановкой $n=1,2,3$ — все три дают значение из таблицы.
```
Честный «нет короткого доказательства» — тоже закрытие, не пустая заглушка:
```markdown
## Теорема (Гаусса–Бонне, для нашего случая).
Флаг закрыт: полного элементарного вывода в литературе нет — приводим формулировку и ссылку
(do Carmo §4-5); в видимой части источника (арка 4) останется результат, полный вывод сворачивается
цитатой-сноской на строгий слой.
```
Что работает: честность вместо выдумки (критерий п.8); греп по потоку открытых `⚑ Флаг` не находит — все
сняты аркой 3 (B11); арка 4 только сверит, что открытых нет.

## 3. proof-self-review ВНУТРЬ + термины `TERMINY.md` (Р17, НЕ внешние скиллы)
Гейт «математика верна?» — пере-читка рецензентом, не автором:
```
Рецензент-проход (внутрь, не скилл): численная сверка для прямоуг. октанта α=β=γ=π/2 →
  S = R²·π/2 — восьмая часть 4πR² ✓ (конец сходится с началом).
Термины (TERMINY.md, не math-russian-terminology): «Girard → Жирар»; «lune → двуугольник/луна»
  (сверено с рус. лит.). Новые термины дописаны в список, едет в арку 4.
```
Что работает: adversarial-проверка — ДРУГИМ методом (рецензент), не повтор «написал вывод»; внешний
`proof-self-review` НЕ зовётся (дефолт захода, развилка владельцу); термины — списком, не скилл-триггером.

## 4. Гейт «математика верна?» — как выглядит провал (дверь между 3 и 4)
- **Провал п.1:** греп находит открытый `⚑ Флаг` → арка 4 НЕ стартует, долг не снят.
- **Провал п.3 (прыжок / потерян вопрос):** «складывая луны, получаем формулу» без промежуточного
  $4R^2\sum=4\pi R^2+4S$ → пересказ результата, не вывод; либо шаг «с неба» без логичного вопроса —
  восстановить мотивировку (иначе слушатель не переизобретёт).
- **Провал п.4 (нотация):** акт углы $\alpha,\beta,\gamma$, другой блок те же углы $A,B,C$ → разнобой, к одному.
- **Провал п.8:** численно конец не сходится с началом → ошибка, поднять как находку, НЕ подгонять.
