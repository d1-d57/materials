## Место на диске
`<лекция>/dnevnik/zhurnal.md` — физически внутри папки лекции, рядом с рабочим дневником (`NAVIGATOR.md`/`PLAN.md`/`SESSIYA.md`, см. `../docs/spravka/PAPKA-LEKCII.md`). Обоснование: журнал — история конкретной лекции (какой заход что заявил по её гейтам), а не общестудийный лог; живёт и переезжает вместе с папкой лекции. `dnevnik/` — новая подпапка (не смешивать с `SESSIYA.md`, который остаётся прозой-дистиллятом хода работы; `zhurnal.md` — строго построчный машиночитаемый формат).

## Кто пишет
Дописывает драйвер/аналитик (или человек) ПОСЛЕ сессии/волны — не сам `sostoyanie.py` (тот read-only, см. `GEJTY.md` границы захода③). Одна строка = одна заявка «на этом гейте мы получили такой результат».

## Формат строки
Одна строка на сессию/волну × гейт, поля через ` · ` (пробел-точка-пробел), append-only (новые строки — в конец файла, старые не редактируются):

```
дата · функция · волна# · гейт · результат(PASS|недобор) · время · токены
```

- **дата** — `YYYY-MM-DD`.
- **функция** — роль/агент, дописавший строку (напр. `аналитик`, `Sonnet-③`, `Opus-план`).
- **волна#** — номер волны арки (напр. `1`, `2`).
- **гейт** — id из `GEJTY.md` (`G1`…`G11`, `H1`…`H5`).
- **результат** — ровно `PASS` или `недобор` (свободный текст статуса сюда не пишется — сверка `sostoyanie.py` матчит буквально эти два значения).
- **время** — потраченное время хода (напр. `45м`, `2ч`).
- **токены** — потраченные токены хода (напр. `120k`).

Пример:
```
2026-07-10 · Sonnet-③ · 2 · G1 · PASS · 20м · 45k
2026-07-10 · Sonnet-③ · 2 · G2 · недобор · 40м · 90k
```

## Что делает `sostoyanie.py` при наличии журнала
1. Печатает последовательность вызовов как есть (в порядке файла).
2. **Сверяет журнал↔диск** — для каждой строки с результатом `PASS` пересчитывает соответствующий гейт по признаку-на-диске (та же логика, что и обычный прогон); расхождение (журнал говорит PASS, а диск-аудит гейта — FAIL) → печатает `⚠ молчаливый недобор: <гейт> (журнал PASS, диск FAIL) — <деталь>`. Это ядро ценности трекера: ловит «где-то недоработали, а дальше пошли» тихо, без явного файлового расхождения.
3. Отсутствие `dnevnik/zhurnal.md` — не ошибка (журнал опционален для самого read-only аудита гейтов); сверка просто не печатается.

## Не делает
Не парсит вольный текст, не восстанавливает историю из git — только буквальные строки этого формата. Малейшее отклонение формата строки (не 7 полей, разделитель не ` · `) — строка пропускается с пометкой в выводе `sostoyanie.py` (не роняет прогон).
