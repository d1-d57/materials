## 1. ДИСЦИПЛИНА (Карпатов)
- **Развилка A1, не закрытая владельцем (назови в ПЛАНЕ, возьми дефолт, не молчи):** формат микро-
  интервью — 3 кандидата (К1 одна пачка / К2 три хода / К3 дефолт-первый). Дефолт захода — **гибрид**:
  предложи черновой бриф целиком (логистику — с дефолтами по контексту), НО throughline вынеси
  отдельным явным открытым вопросом (самое дорогое поле, неверная догадка дороже вопроса). Владелец
  правит одной репликой. Полный бриф текстом сразу → не интервьюируй (Phase 0).
- **Строгость (A2) — ОБЯЗАТЕЛЬНО явная MC, не тихий дефолт** (интуитивный / выкладки свёрнуты / полностью
  строгий). **Формат события (A4) — тоже явно** (устный доклад / текст для чтения → регистр): не
  наследуй молча. **Лекция/курс (Р18) — спроси:** если курс, бриф двуступенчатый (сперва концепт курса).
- **Разведка, не приговор.** Throughline — КАНДИДАТ (гипотеза), не вердикт «тема тянет». Разворот «но»
  проверит арка 2. Не выноси решение о развороте в интервью.
- **Минимум ходов.** Микро-интервью на 1–2 минуты, не дизайн-сессия. Не задавай выводимый вопрос (тест
  the-interviewer). НЕ предлагай «выбор концепции лекции» (brainstorming Phase 1 — Р13 это снял).
- **Арифметика бюджета — здесь и сейчас:** длительность → число слайдов (1 содержательный ≈ 2 мин, ≤3
  сцены). Не «прикинем позже» — гейт требует посчитанного числа.
- **Оспорить ложную предпосылку:** если тема как дана для лекции сомнительна (нет даже замысла
  разворота) — назови это мягко в брифе как РИСК для арки 2, не выдавай пустую тему за готовый бриф.
- **Критерий, который может провалиться:** см. `## 3 → КРИТЕРИЙ ГОТОВНОСТИ`.

**КРИТЕРИЙ ГОТОВНОСТИ** (проверяемый, способен провалиться):
1. Все 8 полей заполнены (ни одно не пусто и не «уточним позже»).
2. throughline-кандидат — ОДНА фраза, не абзац (проверяемо: одно предложение). Назван как ГИПОТЕЗА.
3. Бюджет слайдов ПОСЧИТАН из длительности арифметически (видно число и как получено из минут).
4. Уровень строгости выбран ЯВНО (одна из опций названа), не подразумевается.
5. Формат события назван ЯВНО (устный/читаемый → регистр); лекция-или-курс решено (курс → концепт).
6. «Что резать» — явный список отсечений (не пусто и не слито с throughline в одну фразу).
7. Форма — ~6–8 строк / 8 полей, не раздутый сценарий (нет спроектированных актов/структуры).
8. Ничего из зон арок 2/4 не сделано (нет фактов со ссылками, нет доказательств, нет вердикта «тянет»).
