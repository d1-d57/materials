## 1. ДИСЦИПЛИНА (Карпатов)
- **Развилка, не закрытая владельцем (назови в ПЛАНЕ, возьми дефолт, не молчи):** тег-над-одним-графом
  vs два-набора-карточек. Дефолт захода — **один граф + поле `котёл` на карточке + две вкладки-фильтра**.
- **Находка без карточки = потеряна.** Каждый нетривиальный факт — карточкой ТЕМ ЖЕ ходом (авто-хук),
  с `источник`. Пропустишь — исчезнет молча (эквивалент «мат-долга» «платоновых тел»).
- **Дисциплина карточек:** id стабилен; новый узел → строка в карте (иначе сирота); понижать-не-удалять
  (кунсткамера, не стирать); открытое несогласие литературы → узел `на-сверку`, не тихо разрешать.
- **Термины — per-project `TERMINY.md`** (образец `TERMINY-russkie.md`), НЕ внешний скилл (Р17):
  заполняй список канонических написаний по ходу, сверяйся при первом появлении термина.
- **Держи котлы раздельно:** математика (каждый шаг из логичного вопроса) ‖ научпоп (каждый факт —
  законченная история). Вместе выглядят плохо.
- **Минимум без спекуляций:** ни одной находки без источника; НЕ выдумывать доказательства (арка 3).
- **Оспорить ложную предпосылку:** нет разворота «но» → не тяни тему к арке 3; чекпоинт владельцу (B8).
- **Ранний нарратив — НЕ делать:** ни единой линии, ни прозовой полировки, ни актов-скелета. Только граф.
- **Критерий, который может провалиться:** см. `## 3 → КРИТЕРИЙ ГОТОВНОСТИ`.
- Субагенты (если распараллеливаешь поиск по под-темам): ≤5 одновременно, рейт-лимит = отступить и
  доложить, не слепой ретрай.

## 3. ЗАДАЧА
Собрать фактуру лекции `<LECTURE>` в карточный граф: (1) 5–15 разноплановых заходов, дайджест якорь-
источников; (2) каждая находка — карточкой STANDART (`id·род·котёл·находка·связи·уровень·источник·статус`)
тем же ходом; (3) карта связей резолвит каждый id; (4) карточки тегированы котлом; читаемый
двухвкладочный doc-вид (математика‖научпоп); (5) `TERMINY.md` заполняется по ходу.

**КРИТЕРИЙ ГОТОВНОСТИ** (проверяемый, способен провалиться):
1. ≥5 РАЗНЫХ источников (не Wikipedia-only); **0 находок без карточки/источника** (проверяемо: каждая
   карточка несёт `источник`; каждый id из `связи` резолвится в карте — 0 висящих рёбер).
2. Карточки тегированы котлом `математика‖научпоп`; котлы держатся раздельно (двухвкладочный вид).
3. В материале есть реальный разворот «но» (не пересказ) — назван явно. Нет → честный no-go в отчёт +
   чекпоинт владельцу (не тянуть тему дальше).
4. Формат карточки — терсный STANDART (5–10 строк, без определений/полных конструкций); понижения в
   кунсткамеру и узлы `на-сверку` оформлены дисциплиной, не стёрты/не разрешены тихо.
5. `TERMINY.md` заведён и пополнен (канонические написания встреченных имён/теорем).
6. Ничего из зон арок 3/4/6 не сделано преждевременно (нет полных доказательств, нет единой линии/нити-
   в-сюжет, нет прозы, нет текста слайдов, нет раннего throughline+актов-скелета).
