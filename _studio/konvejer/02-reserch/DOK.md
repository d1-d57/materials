## Карточный граф (перенос из «Каталана», grounded — не изобретать)
Ресёрч — рабочая память АГЕНТА на карточках (не проза, не для владельца). Три слоя (`distillat-catalan-kartochki`, `catalan/spravochnik/{STANDART-uzla,KARTA-OBLASTI}.md`):

1. **Карточка-узел** (`STANDART-uzla`), 5–10 строк:
```
id · род (объект|утверждение|биекция|мостик|затравка|находка) · суть (1 строка)
котёл: математика | научпоп            ← тег разреза (см. развилку ниже)
находка: <1-3 фразы — связь/несущий удивительный момент, НЕ определение>
связи: [id →/↔ однофразное «почему»]
уровень: школьно | требует-приручения | вне-школы
источник: <файл §/стр>
статус: seed | черновик | готово | ПОДТВЕРЖДЁН
```
Запрет: определения, полные конструкции, разборы примеров — всё восстановимо по `источник`, не дублируется («если строку можно убрать и мысль восстановима по указателю — убрать»). Лёгкая сестра — **«объекты-ручки»** (`id·род·суть·счёт·источник`, одна строка) для общих объектов, на которые ссылаются несколько нитей.
2. **Карта связей** (`KARTA-OBLASTI`): резолвит КАЖДЫЙ `id` (суть строкой) + группирует по роду. `id` в чьих-то `связи` и отсутствующий в карте — «висящее ребро».
3. **Нить**: именованный УПОРЯДОЧЕННЫЙ маршрут (затравка→…→кульминация→выход); узлы — бусины, `связи` — локальные рёбра, нить — глобальная сборка в сюжет. Узел вне всех нитей — «мёртвый груз» (привязать или удалить). **Нарезка нитей НЕ форсируется** в арке 2 — каталог-без-нитей это нормальное промежуточное состояние; нить тянет арка 4a, когда котёл наполнен.

## Два котла = тег над ОДНИМ графом, двухвкладочный вид (D1)
Котлы `математика ‖ научпоп` — НЕ два независимых документа, а **один граф с тегом-котлом** на карточке, показанный doc-движком как две вкладки (`build_doc.py`, демо `_generator/doc-demo/{matematika,naupop}.md`: фронтматтер `tab/status/registr`, CSS-вкладки без JS). Один `*.md`-поток на котёл = одна вкладка; вкладка `математика` = карточки с тегом математика (уходят в арку 3 = слой skelet), `научпоп` = карточки с тегом научпоп. Критерии котлов (из редизайна, держать РАЗДЕЛЬНО — вместе выглядят плохо):
- **математика:** каждый шаг вырастает из логичного вопроса; **лекцию можно заменить набором вопросов, отвечая на которые слушатель сам переизобретёт математику**; ничего не падает с неба.
- **научпоп/контекст:** приложения, история, люди, портреты, отступления; **каждый факт читается как маленькая законченная интересная история** (нужен лёгкий нарративный нюх при отборе — но НЕ единая линия).

> ⚠ **РАЗВИЛКА владельцу (не решаю молча):** тег-над-одним-графом vs два-набора-карточек. `distillat-catalan-kartochki §6`: либо (а) один граф + поле `котёл` в карточке + два тег-фильтра, либо (б) два параллельных набора карточек с одной картой-индексом. **Дефолт захода: (а)** — совпадает с двухвкладочным doc-видом. Финал за владельцем (см. Открытые вопросы).

## Дисциплина карточек (обязательная гигиена стадии 2)
- **Авто-хук:** карточка пишется ТЕМ ЖЕ ходом, что находка, не откладывается до конца. Мантра — **«находка без карточки = потеряна»** (это редизайн-эквивалент старого «мат-долга»: несохранённое исчезает молча).
- **id стабилен** (переименование рвёт входящие рёбра); новый узел без строки в KARTA-OBLASTI — сирота.
- **Понижать, не удалять:** правки владельца («это не нужно») уводят узел в «кунсткамеру» (статус понижен), не стирают — остаётся след «проверили и отклонили», не перересёрчивается.
- **Честность развилки:** открытое несогласие литературы — явный узел «на сверку» (`статус: на-сверку`), не тихо разрешается.
- **Компактность — цель:** «база помещается в один взгляд, а не пересказывает источники».

## Источники (biblioteka-модель) → дайджест → карточка
Конвейер сжатия (`distillat-catalan-kartochki §5`): якорь-книги/статьи/конспекты → **дайджест `VYCHITANO`** (обязательная первая остановка перед веб-поиском) → терсная карточка STANDART → место в нити → индекс в KARTA-OBLASTI. НЕ тащить многословность seed-kb-уровня (псевдокод/таблицы верификации — артефакт чужого назначения). Метод ресёрча (перенос `popsci-research` ВНУТРЬ, Р17 — не вызов): 5–15 разноплановых заходов (канон · лучшие научпоп-пересказы 3Blue1Brown/Quanta/Квантик/elementy · неожиданные углы · визуальный пейзаж для арки 9 · рус-источники); ≥5 РАЗНЫХ источников, не Wikipedia-only; каждая находка — сразу карточкой с `источник`.

## Термины — per-project список (Р17, НЕ скилл-триггер)
Вместо внешнего `math-russian-terminology`: **per-project `TERMINY.md`** (образец `../../../catalan/spravochnik/TERMINY-russkie.md`) — список канонических русских написаний имён/теорем/терминов, заполняется по ходу ресёрча; + шаг «сверься с ним» при первом появлении термина. ## Гейт «фактура + разворот»
≥5 разных источников · **ни одной находки без карточки** (греп: каждый нетривиальный факт адресован `источник`) · в материале реально есть «но» (разворот, не пересказ). Разворота нет → тема нечестно не тянет: **чекпоинт владельцу** (B8), не тянуть дальше (Р6 «гейты автора»).

## Ловушки
- **Ранний нарратив (наследие).** Полная прозовая линия / throughline+акты-скелет В АРКЕ 2 — ЗАПРЕЩЕНЫ (редизайн): линию тянет арка 4a из наполненного графа. Здесь — карта сюжетов без линии.
- **Находка мимо карточки.** Осталась в промпте/голове — исчезнет ровно как «мат-долг» в «платоновых телах». Карточка = механизм персистентности, не декларация.
- **Схлопнуть котлы.** Математика и научпоп вместе выглядят плохо (редизайн) — держать разными вкладками/тегом.
- **Wikipedia-only / находка без источника.** Гейт валится.
- **Форсировать нарезку нитей** до наполнения котла — не нужно (каталог-без-нитей нормален).
