## 1. Карточка-узел — формат STANDART + тег котла (ГРУНТОВКА Каталана)
Каждая находка остаётся В КАРТОЧКЕ (5–10 строк, рабочая память агента), тем же ходом:
```
id: area-defect · род: утверждение · суть: избыток углов сфер. треугольника = его площадь
котёл: математика
находка: сумма углов ВЫДАЁТ площадь — геометрия перестаёт быть локальной (несущий разворот темы)
связи: [luna →/ площадь луны 2R²θ — кирпич вывода; harriot ↔/ кто первым]
уровень: требует-приручения
источник: Girard 1629; Rosenfeld 1988 гл.1 §VYCHITANO
статус: черновик
```
```
id: harriot · род: находка · суть: Хэрриот вывел формулу за век до Жирара
котёл: научпоп
находка: приписывают Жирару, но Хэрриот 1603 — раньше; «неожиданный угол» (сырьё для «но»)
связи: [area-defect ↔/ та же формула, кто первый]
уровень: школьно · источник: Rosenfeld 1988 гл.1 · статус: черновик
```
Что работает: находка — СВЯЗЬ/удивление, не определение (определение восстановимо по `источник`);
`котёл` тегирует разрез; `связи` — локальные рёбра с однофразным «почему»; тот же факт живёт как ДВЕ
карточки в разных котлах (математика: вывод; научпоп: история первенства) — это норма разреза.

## 2. Карта связей + нить (ГРУНТОВКА)
`KARTA-OBLASTI` резолвит КАЖДЫЙ id одной строкой, группирует по роду; id из чьих-то `связи`, которого нет
в карте — «висящее ребро» (чинить):
```
## Утверждения (котёл математика)
- area-defect — избыток углов = площадь; вывод через луны
- luna — площадь двуугольника 2R²θ (объект-ручка, на неё ссылаются area-defect и др.)
## Находки/контекст (котёл научпоп)
- harriot — первенство Хэрриота над Жираром
```
**Нить** (упорядоченный маршрут, тянет её АРКА 4a, не здесь) — узел вне всех нитей = «мёртвый груз».
В арке 2 нить можно ещё не резать: каталог-без-нитей — нормальное промежуточное состояние.

## 3. Двухвкладочный вид котлов — doc-движок (ГРУНТОВКА `doc-demo`)
Два `*.md`-потока = две вкладки (`build_doc.py`, CSS-переключение без JS). Шапка потока-котла:
```markdown
---
tab: Математика
status: chernovik
registr: читаемый
---
# <Тема> — математический котёл (карточки тега «математика»)
$$S = R^2(\alpha+\beta+\gamma-\pi)$$
> поле:уровень требует-приручения
⚑ Флаг: знак в формуле — свериться подстановкой малых значений.
🖼 Сфера, три больших круга, шесть цветных лун. {2}
```
Соседняя вкладка — `tab: Научпоп`, `registr: устный`: тот же сюжет голосом контекста (истории,
первенство, приложения). Критерий математики-котла: **лекцию можно заменить набором вопросов**; критерий
научпоп-котла: **каждый факт — законченная мини-история**. `⚑ Флаг` — редизайн-эквивалент «мат-долга»
(честная пометка, закрывается `Флаг закрыт` в арке 3); KaTeX-CDN здесь — авторский рантайм-ВИД (Р7),
не финал.

## 4. Термины — per-project `TERMINY.md` (Р17, НЕ внешний скилл)
```
Girard → Жирар (не «Джирард»)
lune → двуугольник / луна (сверить принятое в рус. лит.: МЦНМО/Квант)
spherical excess → сферический избыток
```
Что работает: список канонических написаний заполняется ПО ХОДУ ресёрча и едет в арки 3/4; скилл-триггер,
заново гуглящий написание после каждого куска, — не зовём (Р17, это баг).

## 5. Гейт «фактура + разворот» — как выглядит провал
- **Провал п.1:** три находки, все из одной статьи Википедии → «≥5 разных источников» не выполнен; или
  карточка `area-defect` ссылается на `luna`, а `luna` в карте нет → висящее ребро, чинить.
- **Провал п.3 (тихий no-go):** тема «определение медианы треугольника» — карточки есть, но «но» нет →
  честно в отчёт: тема не тянет wow-лекцию, чекпоинт владельцу (B8), не тянуть в арку 3. Это НЕ поражение
  захода, а сработавший гейт.
- **Провал «находка без карточки»:** факт «Хэрриот раньше Жирара» записан СЛОВАМИ в план, а не карточкой
  → потерян ровно как «мат-долг» «платоновых тел».

## 6. Что НЕ делает арка 2 (границы на примере)
- НЕ пишет доказательство площади — это арка 3 (математика-котёл = слой skelet, следом, та же сессия).
- НЕ тянет единую линию/нить-в-сюжет и НЕ пишет прозу «Жирар сидел над глобусом…» — это арка 4a (нарратив).
- НЕ формулирует текст слайда со сценами `{@N}` — это арка 6.
- НЕ пишет ранний throughline+акты-скелет (наследие старого дизайна — отменено).
