## Что такое шаг конвейера (пакет)
Каждый шаг = **папка-пакет** `NN-<имя>/` из трёх файлов:
- **`DOK.md`** — подробная документация шага (паттерн SKILL.md, Р9: когда · класс · контракт вход→выход · гейт · алгоритм · ловушки · якоря · открытые вопросы). Выверенная спека.
- **`ZAHOD.md`** — готовый промт-заход под **Claude Code** (по `../docs/kak-delat/RUKOVODSTVO-zahodami.md`, дисциплина Карпатова, петли + критерий-который-может-провалиться). Из Cowork показываешь Claude Code этот файл — он читает `DOK.md` + `FORMAT-ISTOCHNIKA.md` + накопленный контекст лекции и делает шаг.
- **`PRIMERY.md`** — примеры выполнения из живых деков (реальные `content/*.md`, `slides/*.html`, `illustrations/*.svg`).

Исполнитель (Claude Code или субагент) читает ТОЛЬКО пакет шага + названные им якоря, работает с пустым контекстом, отдаёт наверх дистиллят, а не сырьё. Cowork судит по гейту, не перепроверяя построчно.

**Как линия гоняется целиком — `ALGORITM.md`:** driver-модель (Cowork ↔ Claude Code, состояние на диске), вход Фазы II (стык с Фазой I), линия 6→10 (DAG) с гейтами/развилками/чекпоинтами владельцу, и стыки с архитектурой (скелет, `base.css`, `audit.py`, SVGO).

## Инвариант архитектуры (общий для всех шагов)
Источник-папка `<лекция>/src/` (`brief.md` · `content/*.md` · `slides/*.html` · `illustrations/*` · `tokens.css` · `fonts/` · `shablon.html` · `engine.js`; опц. `chapters/`+`drivers/`+`lib/three` · `sims/` · `math/katex.json`) → генератор `../../_generator/build_deck.py` собирает в ОДИН самодостаточный `dist/index.html` (0 внешних URL). Правка = дешёвое изменение markdown/ассета, гейтится нормализованной render-identity сверкой с оригиналом (Р1). Канон визуала (два плана paper/board/card, Forum + Glacial Indifference + Noto, палитра-ядро) заморожен. Формат-инвариант: источник Фазы I — HTML+MathJax с шага 3; финальный дек — статический KaTeX-кэш, не рантайм.

**Формат хранения дека — отдельный контракт: `FORMAT-ISTOCHNIKA.md`** (что где лежит, конвенции имён, манифест `brief.md`, стык каждого шага со слоем). Фабрика ОБЯЗАНА выдавать ровно этот формат — иначе теряется дешёвая правка. Читать перед любым шагом, который пишет в источник (6/7/8/9) или собирает его (10).

## Открытые вопросы уровня конвейера
- **Base-слой канона.** Сейчас общий стандарт = `shablon.html` (инлайн `<style>`) + `tokens.css`, повторяется в каждом деке копированием. Часть «механических» правил (blur-reveal CSS, `transition-delay:0s` синк, sim-контракт) живёт per-deck в `overlay.css`. Кандидат на вынос в единый `base.css`/канон-`shablon` (одна правка на все деки) — см. `08-sceny/DOK.md`, `10-sborka-qa/DOK.md`. Пересекается с Р8 (токены-tiers) и math-арком (Р7) — ещё не собраны.
- **Delivery vs working копия.** `engine.js` несёт feedback-инструменты (E/A/X: editMode/noteMode/showReport). Нужна ли лектору чистая копия без них — за владельцем (`10-sborka-qa/DOK.md`).
