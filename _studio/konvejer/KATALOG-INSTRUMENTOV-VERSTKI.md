**Известный дубль (не чиню, называю).** Кегль заголовка слайда (`frametitle`) назван
дважды НЕЗАВИСИМЫМИ числами:
- `tokens.css:67` — `--t-frametitle: 76px; --lh-frametitle: 1.333` (целевое значение из `.sty:183`);
- `sborka/smeta.py:71` — `ZAGOLOVOK_PX = 128.99` (калибровочная константа сметы, получена
  промером, а не пересчётом первого числа).

Смета сама называет себе цену неточности (`smeta.py:66-70`): у типов с иллюстрацией
заголовок занимает УЗКУЮ роль (`--t-frametitle-n: 64px × 1.4`), а `ZAGOLOVOK_PX` одна на
все типы — расхождение ~11px признано вслух в коде, но не устранено (это работа
следующего захода, солвер этим заходом не трогаем, §2 arka TZ).

**Устарело в карте В** (`INVENTARIZACIYA-SBORKI.md §4`, дата данных 2026-08-10 утро,
до заходов `konstantnyj-sloj`/`primenenie-vizuala` того же дня) — проверено по живым
файлам, не по описанию:
- «Собственная палитра `lenta.py:93-107`» — **больше не существует**: все шесть литералов
  заменены на `var(--paper|--ink|--steel|--board|--brick)`, `lenta.py:92-95` сам это
  документирует («заход konstantnyj-sloj, Ш7»).
- «Раскиданный литерал `font-family:'Forum',serif` в шести местах» — **сведено к нулю
  для структурных ролей**: `base.css:28,43,45`, `tipy.py:43,279` теперь все на

- «Сырой hex `#2b3038`/`#8a96a3` в летербоксе» — тоже устарело: `#2b3038` в файле

Обе находки не мои — их уже сделал и закрыл заход `konstantnyj-sloj` 2026-08-10 тем же
днём, ПОСЛЕ того как `inventarizaciya-sborki` их описал. Карта `INVENTARIZACIYA-SBORKI.md`

## 2. Библиотеки источника Б — какие задачи они решают

Владелец просил смотреть «не только на элементы, но и на подключённые библиотеки: чем
автор решал задачи и какие из этих задач есть у нас». Разобрано `1.base-packages.sty` +
`1.memoir-packages.sty` (128/147 строк, списки `\usepackage` почти идентичны — второй
версия для книжного тела, добавляет `geometry`/`hyperxmp`/`standalone`).

| задача | библиотека(и) Б | есть ли она у нас |
|---|---|---|
| Коммутативные диаграммы, диаграммы категорий | `amscd`, `tikz-cd` | ЕСТЬ, другим путём: SVG-иллюстрации от руки (`_illustracii/`), не автогенерация из формулы |
| Обтекание текста рисунком | `wrapfig` | ОТСУТСТВУЕТ — у нас зона делится жёстко (`--liniya` + `calc()`), не обтекание в потоке |
| Позиционирование текста абсолютными координатами | `textposition`, `zref-user/zref-abspage`, `tikzpagenodes` | НЕ НУЖНО в HTML: любой элемент уже адресуем через CSS-селектор, абсолютная привязка «current page» — обход ограничения TeX, которого у нас нет |
| Многострочные/многоколоночные ячейки таблиц | `makecell`, `multirow`, `multicol`, `nicematrix` | ОТСУТСТВУЕТ — таблица у нас (`build_doc.py:263-274`) простой markdown → `<table>`, без объединения ячеек |
| Единицы измерения (числа+юниты) | `siunitx` | вероятно НЕ НУЖНО — курс без физических величин, не проверял по содержанию лекций (вне зоны) |
| Примечания на полях | `marginnote` | ОТСУТСТВУЕТ у нас нигде (ни слайд, ни лента) — см. также §3, строка «сноска блока» |
| Псевдокод/алгоритмы | `algorithmicx`, `algorithm`, `algpseudocode` | НЕ ПРОВЕРЯЛ — не встречал в теме А и в проверенных частях кода; вероятно неприменимо к курсу теории категорий |
| Оглавление (гибкое, по уровням) | `etoc` | ЕСТЬ аналог у ленты: `build_doc.py:365-582` (`toc`, `_toc_title`, CSS `.toc`); у СЛАЙДА нет вовсе (арка, очередь №5) |
| Колонтитулы (номер страницы, бегущее название раздела) | `fancyhdr` | ЧАСТИЧНО: `#lect-number` (`base.css:109-118`, адрес пересчитан 2026-08-13, `grep -n "#lect-number" base.css`) — только номер, без бегущего заголовка раздела в углу |
| Автоматические умные ссылки | `hyperref`, `cleveref` (закомментирован в Б) | ЕСТЬ по-своему: якоря `id="%s-%s-%s"` у утверждений ленты (`build_doc.py:318`) |
| Библиография | `biblatex` | НЕ ПРОВЕРЯЛ, вне зоны — курс, вероятно, не требует |
| Водяной знак / микротекст логотипа | `background`, `eso-pic`, макросы `2.metadata.sty` | НЕ НУЖНО: секция `2.metadata.sty` — брендинг чужой книги, к содержанию вёрстки не относится (файл дал ноль строк каталога, см. §5) |

**Находка, не почищено (read-only): `4.blocks.sty` в источнике Б мёртв внутри самого
источника.** Все три входные точки (`beamer.sty:1`, `memoir.sty:11`, `tikz.sty` — грепом
по `\input`/`\usepackage`) подключают только `4.components.sty`; `4.blocks.sty` не
`\input`-ится НИГДЕ, хотя лежит рядом и несёт почти дословно ту же машинерию
(`universalbox`/`unibox`/`prepareblock`/`classifycase`). Разница не косметическая:
`4.blocks.sty` жёстко ссылается на цвета `ImportantBg`/`ExampleBg`/`NoteBg`/
`ImportantTexture` и т.п., которых нет ни в одном скопированном файле (`2.colors.sty`
несёт только `Primary/Complement/Accent`) — то есть `4.blocks.sty`, будь он подключён,
попросту не собрался бы. Похоже на более ранний черновик, вытесненный `4.components.sty`
(та же машинерия, но цвет уже через пространство имён `/style/#2/…` — ровно принцип 1
Р52). Каталог в §3.4 цитирует именно `4.components.sty` (живой файл), не `4.blocks.sty`.

## 4. Чего нет ни у кого — кандидаты

Списком, без проработки — решение владельца, не этого захода.

- **Короткая цветная коробка-акцент** (важное/пример/комментарий, 2-3 строки текста, не
  полноценная врезка) — слайд/лента. Ближайший образец — `unibox` источника Б (§3.4).
- **Токены трекинга шрифта** (letter-spacing/word-spacing как именованные переменные,
  не голое число в CSS-правиле) — оба.
- **Отдельное начертание для роли «подпись»** (light/italic, не только размер) — оба.
- **Таблица как элемент фабрики** (роль цвета, текстура заголовка, чередование строк) —
  лента прежде всего, слайд — если понадобится таблица на слайде.
- **Сноска/примечание на полях** (лента) — ни аналога в грамматике карточки, ни в
  CSS-словаре нет вовсе.
- **Бегущий заголовок раздела в колонтитуле ленты** (рядом с уже существующим номером).
- **Маркер списка второго уровня** — появится сам собой, если/когда в грамматику войдут
  вложенные списки; сейчас заводить некуда.
