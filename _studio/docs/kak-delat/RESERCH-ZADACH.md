# RESERCH-ZADACH — алгоритм ресёрча задач (третий ресёрч-поток фабрики)

> **КОГДА читать:** курсу/лекции нужны задачи — под листок (Ф7), картотеку, «руками». Отдельный процесс рядом с ресёрчем математики (матбаза) и научпопа (popsci). · **ЧТО дописывать сюда:** правки самого алгоритма по итогам прогонов (§Правки). Каталог баз — НЕ сюда, а `../spravka/BAZY-ZADACH.md`. · **КУДА дальше:** карта баз — `../spravka/BAZY-ZADACH.md`; место в конвейере — `../spravka/ARHITEKTURA-FABRIKI.md`; выход Ф7 + профили — `../spravka/PROFILI-CIFERBLATY.md`.

Это **алгоритм**, не эссе: на входе иди по шагам §2, ни одного не пропуская, каждый — с гейтом (условием, которое может провалиться). Цель — чтобы поиск задач под курс был воспроизводимым и максимально простым.

У фабрики три ресёрч-потока, у каждого своя единица. **Матбаза** (шаг 3 конвейера) — единица ФАКТ/доказательство, вопрос «верно ли». **Научпоп** (шаг 2, котёл popsci) — единица СЮЖЕТ, вопрос «интересно ли». **Ресёрч задач** (этот док) — единица **ЗАДАЧА**, вопрос «решается ли залом и красива ли». Единица описывается карточкой: `источник · возраст/уровень · идея решения · чем «бриллиант»`. Не факт (матбазе нужно доказательство в объёме) и не сюжет (научпопу нужна история вокруг): задача — самодостаточный вход, условие, которое зал захочет решать немедленно.

## §1. Пайплайн одним взглядом
`тема + возраст` → **[0]** рамка: целевые кластеры × приёмы → **[1]** карта→источники → **[2]** развернуть скрытые ярлыки → **[3]** достать источник (тир доступности + гейт полноты) → **[4]** вычитать → дайджест (факты сверить вживую) → **[5]** гейт доступности к возрасту → **[6]** триангуляция + отбор бриллиантов → **[7]** записать в картотеку/листок → **[8]** статусы + «возвращаться» → `картотека темы + листок ~10`.

Две оси, по которым устроен ландшафт (`BAZY-ZADACH.md §1–§2`): **задачные корпуса** (ищем по теме) × **методические тексты** (ищем по идее решения). Каждая лекция должна быть содержательна на ОБЕИХ осях.

## §2. Шаги (не перескакивать)

### [0] Рамка — разложить тему на две оси
- **Вход:** тема курса/лекции + аудитория (возраст/уровень) + throughline (если есть).
- **Выход:** список целевых КЛАСТЕРОВ (тем-подтем) и список целевых ПРИЁМОВ (идей решения: инвариант, раскраска, чётность, экстремум, двойной подсчёт, граф-модель…).
- **Гейт:** названы ОБЕ оси — и что за темы, и какими приёмами их берём. Нет приёмов → §2 не начат.

### [1] Карта → источники-кандидаты
- **Вход:** кластеры × приёмы из [0].
- **Действие:** по `../spravka/BAZY-ZADACH.md` для каждого кластера выписать корпуса (§1 карты), для каждого приёма — методические тексты (§2 карты).
- **Выход:** короткий список источников-кандидатов со статусами и тирами доступности.
- **Гейт:** у каждого целевого кластера и приёма есть ≥1 источник. Пусто где-то → добрать поиском, пометить лакуну.

### [2] Развернуть скрытые ярлыки — ГЛАВНЫЙ приём
Задача почти никогда не лежит под своим именем: графовая выглядит как раскраска, переправа, игра, чётность, подсчёт; слово «граф» в условии не появляется (problems.ru: в «Графах» 390, а скрыто-графовых в других разделах 500+).
- **Действие:** для каждого приёма из [0] выписать ЧУЖИЕ рубрики, где он прячется (по `BAZY-ZADACH.md §4 мосты`): раскраска → «Инвариант»; переправа/переливание → «Игры/Процессы»/граф состояний; ДНВ → «функции на путях»/«засада на переправе»; турнир → «ориентированные графы». Расширить список разделов для поиска этими ярлыками.
- **Выход:** карта «приём → под какими рубриками искать».
- **Гейт:** для каждого приёма назван ≥1 чужой ярлык. Верить мосту, а не рубрике: если задача по СУТИ про нужный объект — берём, даже если каталог положил её в другой раздел.

### [3] Достать источник — тир доступности + гейт полноты
*(закалка dry-run 2026-07-11)*
- **Тир доступности** (проставить в [1], качать по нему):
  - **A — free-online** (PDF/HTML в открытом доступе): скачать в `istochniki/` зоны курса.
  - **B — платно** (litres / biblio.mccme.ru и т.п.): НЕ качать; работать по оглавлению/вторичке или купить осознанно. Пометить `тир B`.
  - **C — print-only** (только бумага/скан без текст-слоя): пометить `тир C`, при нужде — постраничный скан.
- **Гейт полноты (обязателен для каждого скачанного PDF):** проверить, что файл ПОЛНЫЙ, а не демо-огрызок — постраничной сверкой нумерации (footer не обрывается/не прыгает). *Урок:* 3 из 4 книжек ШМК с бесплатных зеркал оказались только 1-м занятием; без сверки выглядело бы как «скачано, всё ок». Неполное — честно пометить в MANIFEST («ПОЛНЫЙ N/N» либо «демо, занятий нет»), не выдумывать содержимое.
- **Выход:** файлы в `istochniki/` + запись в `istochniki/MANIFEST.md` (`файл · что · кластеры · URL · тир · полнота`).
- **Гейт:** каждый скачанный прошёл гейт полноты; каждый B/C — помечен, не выдаётся за скачанный.

### [4] Вычитать → дайджест (факты сверять вживую)
- **Действие:** на каждый подключённый источник — дайджест в `istochniki/VYCHITANO.md`: `что ЕСТЬ / чего НЕТ / стр. / уровень / для каких кластеров`. Отмечать скрытые ярлыки (где раскраска/переправа/игра = граф) — подтверждение приёма [2].
- **Живые факты.** Числа и рубрикаторы источника ПРОВЕРЯТЬ вживую, не по карте: *урок dry-run* — счётчики problems.ru уплыли (Раскраски 161→150, Инварианты 199→48; сайт реструктурировал разделы). Расхождение с картой — зафиксировать, при нужде обновить `BAZY-ZADACH.md`.
- **Выход:** VYCHITANO с дайджестом на каждый подключённый.
- **Гейт:** **источник без дайджеста = не читан** (0 подключённых без дайджеста).

### [5] Гейт доступности к возрасту
- **Действие:** каждую задачу-кандидата пропустить через возраст аудитории. Для 6 кл — без квадратных уравнений, золотого сечения, подсчёта углов, буквенных сумм. Пометить: `доступна визуально` (разобрать вместе) / `доступна строго` / `за скобки`.
- **Гейт:** каждая задача, идущая в листок, прошла гейт. Гейт — не «сложно/просто вообще», а «посильно ЭТОЙ аудитории».

### [6] Триангуляция + отбор бриллиантов
- **Триангуляция:** кластер считать устойчивым, если подтверждён ≥2–3 независимыми традициями (русская кружковая, венгерская KöMaL, англ. enrichment, олимпиадная). Одна традиция = гипотеза; три = опора.
- **Бриллианты:** отобрать 2–3 на листок — яркий неожиданный результат, разбирается у доски вместе с залом, красивый поворот.
- **Гейт:** у листка есть бриллианты; целевые кластеры триангулированы или помечены «гипотеза».

### [7] Записать в картотеку / листок (наш формат)
Задачи оседают в картотеку зоны курса (НЕ в этот док и НЕ в общую карту). Эталон формата — `../../../nagliadnaya-geometriya/kartoteka/`:
- Файл на тему `NN-tema.md`; строка находки — `находка · суть · чем наглядна · источник · возраст? · как показать/руками`.
- Раздел **БРИЛЛИАНТЫ** (💎) — 2–3 сильных задачи с «чем наглядна» и «как руками».
- Раздел **ЗАДАЧИ** — листок ~10: каждая с источником в скобках, `∗` = посложнее, ссылка на бриллиант; метки Ф7 `[пример]/[лемма]/[биекция]/[?]/[∗]` (`../spravka/PROFILI-CIFERBLATY.md §Ф7`).
- **МИКРОСЮЖЕТЫ/руками · КРОСС-ТЕМЫ · Источники.**
- Опорные точки — формат «Задача N» (номер по листку-первоисточнику), формулировка ДОСЛОВНО, картинка/решение ПОСЛЕ условия (Р23).
- **Гейт:** листок ~10, у каждой источник, формат соблюдён.

### [8] Статусы + «возвращаться»
- **Действие:** обновить статус каждого тронутого источника: `первый проход` → `просмотрен/оценён` → `возвращаться` (есть непройденные разделы) → `достаточно`. Незакрытое (непрофильтрованные разделы, тир-B книги, лакуны) — вынести в явный список «возвращаться».
- **Гейт:** каждый тронутый источник имеет статус; широкую базу держим сверху, курс курирует из неё (Р25) — узкий курс не требует срезать базу.

## §3. Три закалки из dry-run (держать в фокусе)
Прогон 2026-07-11 на семени graph-course вскрыл три грабли — они вшиты в шаги выше, повторяю коротко:
1. **Тир доступности** [3] — бесплатно лежит не всё; полные ШМК — платно. Не приравнивать «есть книга» к «скачал».
2. **Гейт полноты** [3] — бесплатное зеркало может отдать демо-огрызок; ловится только постраничной сверкой.
3. **Факты вживую** [4] — счётчики/рубрики источников протухают; карта — ориентир, истина на живом сайте.

## §4. Как чейнится с матбазой и научпопом
Ресёрч задач даёт точку входа, два других потока её достраивают:
- **→ матбаза.** Задача-бриллиант отдаёт утверждение в слой `skelet` — там доказывают в объёме (шаг 3). Задача = условие; матбаза = почему верно.
- **→ научпоп.** Задача отдаёт историю в котёл popsci — контекст, автор, вау (Кёнигсберг, фуллерен C₆₀). Задача = вход; научпоп = зачем красиво.
- **→ нить лекции.** «Каждая лекция начинается с задачи, в которой объект не виден; язык появляется как инструмент решения, теория — post factum» (`../../../graph-course/concept_note.md`).
Порядок: сначала задача (этот поток), потом её доказательство (матбаза) и её история (научпоп).

## §5. Когда применять — и граница «механизм vs прогон»
- **Применять:** курс-масштаб с листком (циферблат «лекция↔курс» к «курс» → Ф7-Задачи); профиль «мини-курс вокруг одной идеи»; отдельная лекция «на доске» (объём меньше, шаги те же).
- **НЕ применять:** содержание уже лежит в книге-якоре (профиль ОТ-КНИГИ) — задачи берутся из неё.
- **Граница (важно).** Скачивание/вычитка (шаги [3]–[4] на живом корпусе) — это применение алгоритма к КОНКРЕТНОМУ реальному курсу. Построение самого механизма (эта арка) алгоритм НЕ прогоняет: незачем гонять на курсе-примере. Единственный прогон на семени graph-course (2026-07-11) был разовым dry-run для закалки шагов (§3), не провизионированием курса; корпус оставлен спящим.
