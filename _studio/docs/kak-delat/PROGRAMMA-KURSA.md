# PROGRAMMA-KURSA — программа короткого курса (лёгкий профиль)

> **КОГДА читать:** нужна ТОЛЬКО программа курса (внутренний план + публичный анонс) без разворачивания полного конвейера — короткий путь для профиля ЛЁГКИЙ-научпоп или ОТ-КНИГИ. · **ЧТО дописывать сюда:** правки самого захода по итогам прогона (см. низ файла). · **КУДА дальше:** профили/циферблаты — `../spravka/PROFILI-CIFERBLATY.md`; как вести арку — `ARKA.md`; как писать заход Code — `RUKOVODSTVO-zahodami.md`.

Готовый заход: вставляешь в свежую сессию Cowork (внутри арки курса) — получаешь программу нового курса в двух слоях: внутренний план (из чего курс состоит) и публичную программу на отправку тем, кто просит. Профиль — ЛЁГКИЙ-научпоп или ОТ-КНИГИ, см. `PROFILI-CIFERBLATY.md` (без глубокого ресёрча и вечнозелёного справочника). ПОЛНЫЙ профиль — по полному конвейеру `ARHITEKTURA-FABRIKI.md`, не этим заходом.

## Когда брать
- Стандартный короткий курс, где содержание в целом понятно (напр. введение в теорвер, цепи Маркова, Фибоначчи).
- Нужна программа: понять устройство курса И получить текст на отправку.
- НЕ для глубоких тем с ресёрч-волнами и справочником — там профиль ПОЛНЫЙ.

## Заполни под курс (шапка захода)
Перед запуском впиши:
- **Тема**
- **Аудитория и уровень**
- **Длительность** — число лекций/дней
- **Профиль** — лёгкий-научпоп | от-книги
- **Якорь** — книга/конспект, если есть; для «от-книги» обязателен
- **Что уже есть** — список задач/идей/набросков
- **Дедлайн / кому отправляешь**

## Заход (копировать целиком в свежую сессию Cowork, внутри арки курса `zhurnal/<дата>_<курс>/`)

```
Новый курс: «<ТЕМА>». Профиль — <лёгкий-научпоп | от-книги>. Цель сессии — программа курса в двух слоях: (1) внутренний план «из чего курс состоит», (2) публичная программа на отправку.

Тыл: профили и циферблаты — `_studio/docs/spravka/PROFILI-CIFERBLATY.md`. Арка уже заведена (или заведи по `_studio/docs/kak-delat/ARKA.md`); профиль запиши решением в `_studio/docs/pochemu-i-videnie/RESHENIYA.md`.

Работай лёгким профилем: знание тонкое, глубокого ресёрча и справочника НЕ строим. Дисциплина — плотно, по-русски, без воды и похвал, по 1-2 вопроса; возражать по существу, не складываться просто потому что я возразил.

Шаги:

Ф0 · Рамка (интервью). По 1-2 вопроса собери рамку: аудитория и уровень, длительность (сколько лекций/дней), что ТОЧНО входит и что НЕ входит, какой якорь (книга/конспект/мои задачи), какой крючок хочу вперёд. Я могу заходить длинными рассуждениями — не обрывай, вытаскивай суть. Сверни в go/no-go: тянет ли на курс заявленного объёма. На go — короткое ТЗ в `zhurnal/<дата>_<курс>/TZ.md` (курс-специфичные поля — см. `PROFILI-CIFERBLATY.md` «TZ курс-специфичные поля»).

Ф1 · Ресёрч-лайт. Возьми общее место темы и якорь, если есть; ресёрч-волн не гоняй. Якорь прочитай, дай дайджест «что ЕСТЬ / чего НЕТ / уровень» (формат — `PROFILI-CIFERBLATY.md` «Дайджест источника»). Веб — только если реально чего-то не хватает. Не уверен в факте — честная пометка, не выдумывай.

Ф-план · Внутренний план (из чего курс). Собери сюжеты и техники темы, разложи на N лекций: у каждой название, 1-2 фразы сути, ключевой объект или задача, источник/якорь. Сверху — throughline (одна линия, которая держит курс) и явный список «что НЕ входит». Структуру жёстко не лочь: связи ищутся по ходу. Открытые развилки — отдельным списком. Клади в `zhurnal/<дата>_<курс>/plan-vnutrenniy.md`.

Ф-программа · Публичная (= Ф8-Анонс). Из плана выжми короткий текст на отправку. Веди задачей-крючком, а не определением. Убери жаргон и пересказ сюжета. Вперёд — самое интригующее (красивый факт, поворот), не «первая половина / вторая половина». Пререквизиты назови конкретно (какие именно знания). Дай: название + подзаголовок, для кого, пререквизиты, строку на каждую лекцию (тема — крючок), финал-подводку. Клади в `zhurnal/<дата>_<курс>/programma.md`.

Гейты перед выдачей публичной программы: термины (если есть математика) — сверить по проектному списку терминов (внутренний шаг, Р17, не внешний скилл). Стиль анонса — [ОТКРЫТЫЙ ВОПРОС, см. `PROFILI-CIFERBLATY.md` Ф8: локальный презентационный стиль (Р4) или `russian-editor`? — решить перед этим шагом, не по умолчанию]. Внутренний план — без стилевых гейтов.

Закрытие: план и программа → `zhurnal/<дата>_<курс>/`; решения → `RESHENIYA.md`; каждый новый `.md` → строка в `KARTA.md` §6 (сирот 0); строка в `SVODKI.md`.
```

## Что на выходе
- `zhurnal/<дата>_<курс>/plan-vnutrenniy.md` — внутренний план: лекции, throughline, границы, источники, развилки.
- `zhurnal/<дата>_<курс>/programma.md` — публичная программа/анонс (= Ф8-Анонс), готовая к отправке.

## Стандарт лекции · листок · метод ресёрча (научпоп мини-курс)
*Применяется, когда курс сужен вокруг ОДНОЙ идеи (профиль «мини-курс вокруг одной идеи» — `../spravka/PROFILI-CIFERBLATY.md`); по этому шаблону курируется КАЖДАЯ лекция после программы.*

**Стандарт описания лекции.** Каждая лекция готовится по шаблону: (1) название + место в нити (какой аспект сквозной идеи; № по нарастанию сложности); (2) цель в 1 фразу; (3) ядро-бриллиант — одна красивая идея, выводимая ВМЕСТЕ с залом (не готовая теорема); (4) теория-минимум (≤ полулекции; без больших теорем, маленькие доказуемые — можно); (5) листок ~10 задач; (6) «руками»; (7) микросюжеты/вау; (8) мост к соседям (нить); (9) гейт доступности + что за скобки; (10) источники (реестр зоны — MANIFEST/VYCHITANO).

**Критерии листка (~10 задач).** Каждая — простая, наглядная, доступная аудитории; есть сильные «бриллиантовые» задачи (яркий неожиданный результат); задачи, которые можно разбирать у доски вместе с залом; ∗ — посложнее; у каждой источник; гейт доступности (для 6 кл — без квадратов/золотого сечения/углов).

**Как искать материал под такой курс.** Экономно, по темам последовательно (без роя агентов); русские источники в приоритет; на каждой задаче гейт доступности; каждую находку регистрировать в реестре зоны (MANIFEST + дайджест VYCHITANO), чтобы не перечитывать; держать широкую базу, курс курировать сверху (узкий курс не требует срезать базу). Каталог источников — `../spravka/PRAJOR-ART.md`.

## Заметки
- Профиль **от-книги** (пример источника — Фибоначчи): ресёрч почти не нужен, якорь-книга держит содержание; Ф1 сворачивается до дайджеста книги, сразу к плану. Формат можно дублировать под сильную/слабую группу — одна база, две подачи.
- Публичная программа — по сути Ф8-Анонс. Крючок-задачей, без жаргона, интрига вперёд — самое хрупкое место захода, не жалеть на него внимания (какой бы гейт стиля ни выбрали — см. открытый вопрос).
- После первого прогона — короткая заметка «что в схеме поправить» → правь этот файл и `PROFILI-CIFERBLATY.md`.
