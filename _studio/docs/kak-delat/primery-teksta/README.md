## Механизм одной страницей

Если читать некогда — вот всё, ради чего папка существует:

1. **Режь словарь, а не сюжет.** Чёрный ящик есть для утверждений и не существует для понятий. Значит дорого стоит не доказательство, а словарь — и урезание начинается с вопроса «нельзя ли спросить то же самое без этого понятия?». (`05`)
2. **Нерв — до конца, всё остальное — торгуется.** Приём, ради которого текст существует, доказывается полностью. Провал #16 сэкономил ровно на нём. (`04`, `00`)
3. **Инструмент нужно оправдать до его появления.** Блок «почему это не делается голыми руками» превращает красивый трюк в необходимость. (`02`)
4. **Долг всегда назван и всегда оплачен.** Статус у каждого утверждения; у каждого чёрного ящика — ручная проверка рядом. (`03`, `07`)

## Как дополнять

Новый образец заводится, когда на прогоне принято решение, которого в контракте нет. Формат файла:

```
# NN · Название приёма
> Правило контракта, к которому это относится.
## Образец   — цитата из живого текста, не выдуманная
## Что здесь работает   — по пунктам, ПОЧЕМУ, а не «красиво»
## Антипаттерн рядом    — как это выглядит, когда сделано плохо
## Проверка             — механическое действие, которым автор проверит себя
```

Раздел **Проверка** обязателен: образец без проверки — вдохновение, а не инструмент.
