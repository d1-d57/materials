## §4. Верифицированные мосты (задача под чужим ярлыком)
Ключ метода (`../kak-delat/RESERCH-ZADACH.md §3`) — где искать по сути, а не по названию:
1. **Раскраска ↔ инвариант ↔ граф** — раскраска в кружках лежит в «Инварианте», не «Графах» (Генкин, Engel, Канель-Белов).
2. **Переправы/переливания = графы состояний** — рассеяны вне «Графов»; по сути графовые (60+ задач в педлитературе).
3. **ДНВ (дискретная непрерывность)** = утверждение о функциях на путях; Шаповалов — «засада на переправе».
4. **Турниры = ориентированные полные графы** (Заславский сам строит мост).
5. **Игры = графы позиций** (ним, Sprouts).
6. **Чётность → графы/игры/процессы** (Медников; Ловас §5, Engel гл.2, Winkler гл.2).
7. **Экстремальные задачи — не экзотика** — отд. главы у Ловаса, Томеску, Aigner–Ziegler, «Кванта».
8. **Универсальность явления** — mathraining.be: «Les graphes sont généralement cachés».

> **Подтверждено в первоисточнике** (dry-run 2026-07-11, не в пересказе): Медников — «чётность… инструмент… графы, игры» (мост 6); Шаповалов — «Засада на переправе» (мост 3). Мост часто прямо в авторском предисловии/названии приёма — читать по авторскому слову.
