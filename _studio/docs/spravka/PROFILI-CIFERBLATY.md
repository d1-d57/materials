## Зачем отдельный файл, а не раздел ARHITEKTURA-FABRIKI

`ARHITEKTURA-FABRIKI.md` — карта ФИКСИРОВАННЫХ 10 шагов производства ОДНОГО дека (Фаза I + Фаза II), зарегистрирована в `KARTA.md` узко: «дизайн фабрики / карта 10 шагов». Циферблаты — ортогональный слой НАД этой картой: не новые шаги, а то, НАСКОЛЬКО громко играть уже существующие (глубина ресёрча, строгость, размер арок) плюс СОВСЕМ новая ось — масштаб «одна лекция ↔ курс из N лекций», которой в карте шагов нет вообще (курс = карта шагов, пройденная несколько раз). Смешивать «карту шагов» и «дозировку шагов» в одном файле утяжелило бы ARHITEKTURA-FABRIKI за пределы его текущей узкой регистрации (KONSTITUCIYA §14: дом существует, но не подходит по объёму и регистру — заводим новый).

## Профили — пресеты циферблатов

Примеры ниже — из источника (курс-проекты kurs-fabrika), не проекты `_studio`; иллюстрируют профиль, не обязывают.

- **ПОЛНЫЙ** (пример источника — «Каталан»): глубокий ресёрч + вечнозелёный справочник + строгая матбаза (шаг 3) в полном объёме + HTML (шаги 6-10) + курс-масштаб через рекурсивный запуск (см. циферблат «лекция↔курс» ниже) + Ф7-Задачи/Ф8-Анонс. Многосессионные арки, полная петля Cowork↔Code.
- **ЛЁГКИЙ-научпоп** (примеры источника — введение в теорвер; цепи Маркова «меньше математики, больше красоты»): ресёрч по верхам, знание тонкое (+опционально якорь-книга), упор на красоту/картинки, короткие арки, матбаза эскизная.
- **ОТ-КНИГИ** (пример источника — Фибоначчи, комбинаторный взгляд): содержание уже лежит в одной книге → ресёрч почти не нужен, якорь = та книга, сразу к рассказу → тонкая матбаза → HTML. Формат может дублироваться под разные аудитории (сильная/слабая группа) — одна база, две подачи.

Профиль — не клетка: миксуй циферблаты под конкретный проект.

## Циферблаты

1. **Глубина знания / ресёрча.** ПОЛНЫЙ (вечнозелёный справочник + библиотека источников с дайджестами, см. опцию ниже) ⟷ ЛЁГКИЙ (берётся из общего места, справочник тонкий). Средняя позиция — **якорная литература**: полный справочник не строим, но прицепляем 1-2 ключевые книги и ориентируемся внутри них (пример источника — комбинаторный взгляд на Фибоначчи по одной книге о красивых доказательствах). Выставляется на входе арки, до шага 1 (Бриф).
2. **Строгость ⟷ научпоп.** ПОЛНЫЙ — строгая матбаза (шаг 3), доказательства в полном объёме. ЛЁГКИЙ — больше красоты и картинок, меньше доказательной машинерии: матбаза тоньше или эскизная.
3. **Размер арок.** Полный проект — многосессионные арки (несколько заходов Code на шаг конвейера). Микро-проект — одна-две арки, часто вообще без петли Cowork↔Code (влезает в один чат аналитика).
4. **Роль Code.** Тяжёлая вёрстка/механика/массовый поиск → заходом (`../kak-delat/RUKOVODSTVO-zahodami.md`). Лёгкий проект может обойтись без петли — аналитик делает сам.
5. **[НОВОЕ — сконструировано этим заходом, готового образца нет ни в источнике, ни у нас] Масштаб: лекция ↔ курс.** Реализует принцип Р18 (`../pochemu-i-videnie/RESHENIYA.md`): лекция и курс — один механизм, курс = запуск фабрики многократно. Две позиции циферблата — два разных технических решения одной задачи:
   - **лёгкий полюс — распил.** Один растущий гибрид-источник (шаг 4) пишется на весь курс сразу, затем режется на лекции/вкладки (правки: ссылки перепровязать, объёмы проверить видимыми). Источник кита называл это Ф6; у нас это опция для лёгких профилей, не отдельный шаг конвейера.
   - **тяжёлый полюс — рекурсивный запуск (Р18).** Сначала арка-концепт всего курса (сюжеты, порядок лекций, мосты/пересечения между ними — фиксируются явно как durable), затем фабрика (Арх.2, шаги 1-10) запускается ЗАНОВО отдельной аркой на КАЖДУЮ лекцию, уточняя/наполняя большой документ курса.
   - Корреляция с профилем — мягкая, не жёсткое правило: ЛЁГКИЙ тяготеет к распилу, ПОЛНЫЙ — к рекурсии; миксовать можно (см. «профиль — не клетка» выше). **Открытый вопрос** — конкурируют ли распил и рекурсия как модели, или это буквально два полюса одного циферблата (см. `## ВОПРОСЫ` в `kod_absorb-prizemlenie.md`) — этим заходом не решено.

## Ф7 · Задачи и Ф8 · Анонс — курс-масштабные deliverable

Появляются только когда циферблат «лекция↔курс» (см. выше) сдвинут к полюсу «курс» — на масштабе одной лекции их нет. В текущей карте шагов (`ARHITEKTURA-FABRIKI.md` Арх.2, 10 шагов) прямого аналога нет — это новые типы выхода, не новые шаги внутри Фазы I/II.

- **Ф7 · Задачи.** Единый листок задач на весь мини-курс, с метками по типу ([пример] / [лемма] / [биекция] / [?] открытый / [∗] сложный). Готово, когда листок покрывает материал курса этими метками.
- **Ф8 · Анонс.** Публичный текст-анонс курса — «этот курс я хочу прочитать». Короткий путь сборки — `../kak-delat/PROGRAMMA-KURSA.md`. Готово, когда анонс готов к публикации.

Гейты — по Р17 внутренние, не внешний скилл: термины (если есть математика) сверяются по проектному списку терминов, не зовут `math-russian-terminology`. **Стиль текста Ф8 — ОТКРЫТЫЙ ВОПРОС**, не решено этим заходом: источник зовёт `russian-editor`; наш Р4 отвергает `russian-editor` для стиля СЛАЙДОВ (локальный плакатный стиль), но анонс — другой жанр (публичный текст на отправку, не слайд). Решение — за аналитиком, см. `## ВОПРОСЫ` в `kod_absorb-prizemlenie.md`.

## Опционально для ПОЛНЫЙ-профиля (перенесено дёшево, не срочно)

- **Ф2 · Карта (справочника).** Источник предлагает отдельный шаг: находки ресёрча оседают в персистентных узлах справочника (по STANDART-uzla источника) + карта нитей (маршруты-сюжеты); готово, когда 0 висячих узлов и карта резолвит каждый id. У нас частичный аналог — ресёрч (шаг 2, Фаза I) без персистентных узлов. Не встраивается в конвейер этим заходом — фиксируется опцией на будущее (Р18: «масштаб держим в уме, пока не расширяем»).
- **Дайджест источника.** По каждому вычитанному источнику — короткая карточка «что ЕСТЬ / чего НЕТ / стр. / уровень», тем же ходом, что и чтение. Правило источника кита: «источник без дайджеста = не читан».

## TZ курс-специфичные поля

Источник держал это отдельным шаблоном (`shablon/zhurnal/_TEMPLATE-arka/TZ.md`). У нас общий шаблон TZ/NAVIGATOR — для курс-масштабных арок добавляй явно:
- аудитория и уровень;
- формат (число лекций / дней);
- профиль + выставленные циферблаты (см. выше);
- throughline (одна ось, которая держит курс);
- ворота go/no-go (тянет ли материал на заявленный объём).
