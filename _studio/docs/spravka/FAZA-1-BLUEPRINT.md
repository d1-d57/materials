# FAZA-1-BLUEPRINT — детальный дизайн Фазы I (из отчёта «платоновы тела»)

> **КОГДА читать:** когда строишь арки Фазы I (интервью→раскадровка), особенно линчпин — гибрид-источник (арка 4). · **ЧТО дописывать сюда:** уточнения дизайна Фазы I. · **КУДА дальше:** карта всего конвейера — `ARHITEKTURA-FABRIKI.md`.

Источник — прогон «платоновы тела» (отчёт владельца `process-report.md`, ч. 3): фаза «идея → содержание слайдов» провалилась как цепочка конфликтующих скиллов (2 ч, 7 итераций). Лечится ОДНИМ линейным алгоритмом, где растёт ОДИН документ по этапам с гейтами. **Формат-инвариант:** HTML+MathJax+SVG с этапа 2 (не Markdown).

## Этапы (выход + гейт)
- **0. Бриф** (микро-интервью, не открытый диалог; под матлекцию — Р13): тема · аудитория · длительность→бюджет слайдов (1 содерж. ≈ 2 мин, ≤3 сцены) · throughline-кандидат · что резать · референс. → бриф 5 строк.
- **1. Ресёрч:** проверенные факты + ссылки + неожиданные углы; НЕ выбрасываются — живут в источнике. → гейт: фактура + throughline есть?
- **2. Строгая матбаза** (для верификации автором): доказательства в ПОЛНОМ объёме, HTML+MathJax+SVG — «эталон истины». → гейт: **математика верна?**
- **3. Гибрид-источник** — главный артефакт, которого нет ни в одном скилле. ОДИН HTML, три слоя:
  - **видимый** — живая история (throughline, И-Но-Поэтому, сцены, закольцовка) + **математика в финальном объёме** (доказательства в тексте, не «на потом»);
  - **свёрнутые `<details>`** — строгие выкладки + ссылки на теоремы (из этапа 2);
  - **описания иллюстраций 🖼** на каждый такт (кормят фазу рисования).
  Стиль-проверка — named-шаг здесь. Роли слоёв: технический = «ЧТО объясняем» (строгость); нарратив = «КАК интересно». Но два СЛОЯ одного документа, не два документа. → гейт: источник закрыт?
- **4. Раскадровка:** из источника — список слайдов + бюджет; на каждый archetype + дистилляция + сцены + описание илл. **Содержание, не финальный текст.** → гейт: сколько слайдов, что на каждом — ясно?

## Что это чинит (из провала)
(A) нет единого алгоритма → этапы 0–4 фиксируют порядок и выходы. (B) скиллы срезают математику → гибрид-документ первоклассен, правило «финальный объём + доказательства в тексте». (C) метания MD↔HTML → HTML с этапа 2. (E) матошибки → гейт «математика верна» между 2 и 3. (F) стиль поздно → named-шаг в этапе 3.

## Оркестровка (детали из отчёта)
Не полагаться на кастомные `subagent_type` (в харнессе только встроенные) → general-purpose + инлайн-роль + явный `Skill` + `model`-оверрайд. Выход фазы 1 = гибрид-источник (HTML), не отдельный `scenario.md`. Выход раскадровки = кликабельное HTML-демо (плейсхолдеры илл. + сцены + рамочные слайды).
