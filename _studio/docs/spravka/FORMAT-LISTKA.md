# FORMAT-LISTKA — стандарт печатного листка (Ф7 → печать)

> **КОГДА читать:** листок готов по СОДЕРЖАНИЮ (картотека, состав отобран с владельцем) и надо ФИНАЛИЗИРОВАТЬ внешний вид для печати. Это про ВЁРСТКУ, не про подбор задач (тот — `../kak-delat/RESERCH-ZADACH.md`). · **ЭТАЛОН:** листки L1/L2 курса `informacia-i-kody` (`kartoteka/L1-*`, `L2-print.html`). · **ТРИГГЕР:** запускать ВСЕГДА при финализации печатного вида листка — один и тот же конвейер, минимум усилий.

## Инвариант (не обсуждается)
- **A4, цель — одна страница.** Кружковый листок на ЗАНЯТИЕ = ≤ ~15 задач и влезает на 1 лист. (Листки на неделю / спецмат — отдельный разговор, другой объём.)
- **Только задачи.** Шапка (тема + «N класс · занятие K · дата») + нумерованный список условий. БЕЗ выдуманных заголовков-секций, БЕЗ подводок («занятие по статье…»), БЕЗ комментариев исполнителя, БЕЗ пояснений «как играть / оборот пустой» в теле листка. Как в L1/L2. Отсебятина = брак.
- **Шрифт** Georgia/Times serif ~10.5pt; числа в условии — моноширинным (`.mono`); `∗` у сложных; сквозная нумерация.
- **Гейт:** WeasyPrint HTML→PDF → `pdftoppm`→PNG → посмотреть глазами (кириллица; влезание на лист; нумерация сквозная, не перезапускается).

## Пайплайн (наш «генератор»)
1. Условия — в HTML по эталонному CSS `informacia-i-kody/kartoteka/L2-print.html`: `@page{size:A4;margin:…}`, `.head`, `ol/li`. **Счётчик номеров — на `body`/`.sheet` (`counter-reset:z`), НЕ на каждом `<ol>`** — иначе нумерация перезапускается по секциям (грабли, поймано на L3).
2. `python3 -m weasyprint listok.html listok.pdf`
3. `pdftoppm -png -r 96 listok.pdf preview` → глазами → печатать PDF.

TeX на кружковом уровне не обязателен — WeasyPrint достаточно; внешне это простая вещь, вёрстки почти не нужно. (Спецмат — можно LaTeX, отдельно.)

## Вариант с ВЫРЕЗНЫМИ карточками (реквизит на листе)
Когда детям нужны карточки/полоски, которые они вырезают из своего листа. **Карточки ПУСТЫЕ** — дети заполняют сами (в этом смысл). Дизайн минимальный: 1 горизонтальная пунктирная линия (отделяет зону карточек от текста, с отступом ~строка после последней задачи) + 3 вертикальные пунктирные (делят на 4); внешние границы = край листа. Бледные ①②③④ — по желанию (для ссылок в задачах). НИКАКИХ подписей/инструкций в зоне карточек.

- **Предпочтительно — ОДНА страница, ОДНОСТОРОННЯЯ печать** (проще всего; оборот карточек чист автоматически, двусторонней возни не нужно). Все задачи сверху, зона карточек — внизу оставшимся местом. `.page{min-height:275mm;display:flex;flex-direction:column}`, блок задач — natural, `.cutzone{flex:1 1 auto;min-height:~50mm;border-top:1.5px dashed;display:flex}` (растёт до низа). Если не влезает — ужать формулировки (гейт-PNG покажет). **Эталон — `informacia-i-kody/kartoteka/L3-print.html`** (13 задач + карточки на одном листе).
- **Фолбэк — две страницы, двусторонняя,** только если задачи не помещаются на 1 лист: текст в ВЕРХНЕЙ части ОБОИХ листов, карточки — в НИЖНЕЙ части ПЕРВОГО, низ ВТОРОГО ПУСТОЙ. ⚠ Тонкость: текст стр.2 должен быть КОРОЧЕ зоны над карточками, иначе заедет на оборот — поэтому одна страница надёжнее.
