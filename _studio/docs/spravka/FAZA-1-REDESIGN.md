## Ядро: ресёрч и нарратив — РАЗНЫЕ фазы и сессии
Раньше (`distillat-reserch-matbaza.md`) — «один поток с ранним нарративным скелетом». Пересмотр: **ресёрч идёт БЕЗ навязанной истории; нарратив — отдельной сессией из собранного.** Это разные режимы работы (в ресёрче гуглим широко, ходим в стороны; потом из накопленного тащим линию), поэтому и разные чаты.

## Стадии верхней части Фазы I
1. **Интервью — лёгкая разведка** (НЕ решение «тянет ли математика»). Собираем: что хочется (тема · аудитория · формат); есть ли статьи/тексты под аудиторию, читал ли кто такие лекции; **это лекция или курс** (Р18). Красивое доказательство / тянет тема — решается в ресёрче, не тут.
2. **Ресёрч — отдельная сессия, широко, без сюжета. ДВА параллельных документа («две вкладки»):**
   - **Математический** — утверждения, доказательства, связи; плотный TeX-текст, иллюстрации. Критерий: каждый шаг вырастает из логичного вопроса; **лекцию можно заменить набором вопросов, отвечая на которые слушатель сам переизобретёт математику**; ничего не падает с неба немотивированно. (= `skelet`.)
   - **Научпоп / контекст** — приложения (Данделен → дробление камней), история, люди, портреты, отступления. Критерий: **каждый факт читается как маленькая законченная интересная история** (поэтому уже нужен лёгкий нарративный нюх при отборе).
   - Держим РАЗДЕЛЬНО (вместе выглядят плохо). Выход фазы: **«плавильный котёл»** — карта сюжетов по теме, ещё БЕЗ единой линии (альманах сюжетов, связанных темой).
3. **Нарратив — отдельная сессия:** вытащить ЛИНИЮ из котла и сшить в единую историю (`rasskaz` = видимый слой источника), с добором ресёрча там, где провисает. (Логика `popsci-narrative`, но внутренне.)
4. Дальше — раскадровка → тексты слайдов → сцены → иллюстрации → сборка (Фаза II, шаги 5–10).

## Костяк-текст = лекция ИЛИ курс (Р18)
Один механизм. **Курс:** сначала концепт всего курса (какие лекции, набор сюжетов, порядок, мосты), потом каждая лекция — уточняя/наполняя тот же большой документ (как `catalan`). Мосты/пересечения между лекциями фиксируем.

## Скиллы — внутрь, не в прод (Р17)
`popsci-research` / `popsci-narrative` / `the-interviewer` / `math-russian-terminology`: прочитать, разобрать на куски, разложить по нашим шагам. Термины — per-project документ-список + шаг «сверься», не скилл-триггер.

## Формат документа (grounded в текстах владельца — `catalan`, `kurs leto`)
Шаблон обзора (шапка-`>` со статусом/throughline/указателем на skelet → вопрос-крючок → акты «задача→прозрение→стержень-идея→новая область» → закрытие с кольцеванием и честным зазором) + слои `rasskaz`/`skelet` + пометки `.insight`/`.mn`/`.foot` + **мат-долг `⚑ Флаг`→`Флаг закрыт`** + **гейт-против-воды** (приём-заглушка «аккуратно разложим» ОБЯЗАН нести рядом конкретный шаг-механизм). Полностью — `distillat-format-teksta.md`.
