# CLAUDE.md — вход для агента-исполнителя (Claude Code / субагент)

> **КОГДА читать:** первым, когда работаешь в `_studio/` как исполнитель по заходу. · **ЧТО дописывать сюда:** только короткий вход исполнителя. · **КУДА дальше:** файл-заход, на который указал аналитик.

## Что это
`_studio/` — проект фабрики презентаций внутри git-репозитория `materials/`. Стратегию и документацию ведёт аналитик (Cowork); ты — точечные кодовые/файловые заходы.

## Главное правило — один файл-заход
Тебе указывают ОДИН файл-заход (`zhurnal/<арка>/kod_<тема>.md` или инлайн-ТЗ субагента). **Читай ТОЛЬКО его** и то, что он называет поимённо. НЕ изучай весь проект. Чего не хватает — спроси в `## ВОПРОСЫ`, не додумывай.

## Дисциплина (жёсткая — цена ошибки = переделка)
- **⚙️ HTML — только готовым генератором `_generator/`** (`build_doc.py` — документ-вид, `build_deck.py` — слайды); новый генератор НЕ писать, правь источник, HTML — выход.
- **Думать, не угадывать.** Предпосылку захода — даже от владельца — проверь по живым файлам, прежде чем строить. Ложна → скажи с доказательством, не гоняйся за фантомом.
- **Минимум.** Ровно то, что решает задачу; без спекулятивных абстракций и попутных «улучшений». Каждая изменённая строка трассируется к заданию; чужой стиль сохранять.
- **Не ломать.** Якорные строковые замены — abort, если совпадений ≠ 1. Один риск за раз: read-only разведка → мутация по плану → сверка.
- **Откат.** `materials` под git — откат из git; рискованно-структурный заход → сперва zip-бэкап. Двигаешь/удаляешь/сжимаешь → встрой свежий верификатор ДРУГИМ проходом (ничего не потеряно, ссылки не побиты — программно).
- **Сохранять по умолчанию.** Безопасное — делай; рискованно-неоднозначное — оставь и опиши в отчёте.
- **Субагенты — аккуратно:** ≤~5 параллельно за раз, рейт-лимит = отступить и доложить (не слепой ретрай), назвать сколько и на что.

## Твой след — в заходе
- `## ВОПРОСЫ` — что неясно / требует решения владельца.
- `## ОТЧЁТ` — что сделал и ЗАЧЕМ / как проверил / что НЕ трогал / результат верификатора / **время прогона + токены**.

Новых доков не плодить; границы захода не расширять. Документацию авторит аналитик, не ты.
