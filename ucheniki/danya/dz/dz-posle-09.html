  1. Докажите, что квадрат можно разрезать на n квадратов (возможно, разных размеров) при любом n больше пяти.

  2. В каждом из трёх доказательств есть ошибка. Найдите её.

    (а) Утверждение: если треугольник разбит на n треугольников, то хотя бы один из них не остроугольный.

    База. При n = 2 верно: два угла новых треугольников дополняют друг друга до развёрнутого, значит один из них не острый. Шаг. Рассмотрим треугольник, разбитый на n треугольников. Разобьём один из них на два. Один из двух новых треугольников не остроугольный, значит утверждение верно и для n + 1.

    (б) Утверждение: любые n точек лежат на одной прямой.

    База. При n = 1 и n = 2 верно: через любые две точки проходит прямая. Шаг. Возьмём точки p₁, …, pₙ₊₁. По предположению первые n точек лежат на прямой l, а последние n — на прямой l′. Прямые l и l′ имеют две общие точки p₂ и pₙ, значит совпадают. Стало быть, все n + 1 точек лежат на одной прямой.

    (в) Утверждение: если в связном графе на n вершинах степень каждой вершины не меньше двух, то при удалении любого ребра он остаётся связным.

    База. При n = 3 верно: из треугольника можно убрать ребро, связность сохранится. Шаг. Возьмём граф на n вершинах и добавим ещё одну. Если из неё выходит хотя бы два ребра, то при удалении любого из них она остаётся соединённой со старым графом. А при удалении ребра старого графа он остаётся связным по предположению индукции.

  3. Дано n различных по весу камней. Имеются весы, позволяющие сравнить по весу любые два камня. Какое наименьшее число взвешиваний потребуется, чтобы найти самый тяжёлый камень?

    б) Как изменится ответ, если порядок взвешиваний надо указывать заранее?

  4. Сколькими способами прямоугольник 2 × n можно разрезать на прямоугольники 1 × 2? Найдите ответ и докажите его.

  5. В графе n вершин (n > 2). Докажите, что можно покрасить не более n − 1 его рёбер так, чтобы из каждой вершины выходило чётное число неокрашенных рёбер.
