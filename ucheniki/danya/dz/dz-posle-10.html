  1. Докажите, что для любого целого n ≥ 3 можно найти n различных натуральных чисел, сумма которых делится на каждое из них.

  2. На прямой отмечены четыре точки: 0, 1, 2, 3. Частица стоит в точке 0. За один ход она переходит в соседнюю отмеченную точку — влево или вправо; уйти за крайние точки нельзя.

    (а) Сколько существует различных траекторий длиной в n ходов? Посчитайте для маленьких n и угадайте ответ.

    (б) Докажите его.

    (в) А если отмеченных точек пять — 0, 1, 2, 3, 4? Посчитайте и объясните, почему ответ устроен иначе.

  3. В турнире каждый участник сыграл с каждым ровно одну партию, ничьих не бывает.

    Докажите, что всех участников можно выстроить в ряд так, чтобы каждый выиграл у того, кто стоит сразу за ним.

  4. Напомним, что C(n, k) — число способов выбрать k предметов из n различных.

    Докажите, что для любого n

    C(n, 0)² + C(n, 1)² + C(n, 2)² + … + C(n, n)² = C(2n, n).

    Проверьте равенство на строках треугольника Паскаля при n = 2, 3, 4, прежде чем доказывать.

  5. Сколько циклов может быть в графе с n вершинами и n + 1 ребром?
