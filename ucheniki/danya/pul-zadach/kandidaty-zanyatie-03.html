Занятие №3 · расширенный пул

Отобрать ~5

ЦПМ Хамовники 7 + наш старый банк. Раскраску 5×5 снял, вместо неё — любимое-но-не-данное из маминого набора. Источник помечен, ключи проверены.

Графы

1ЦПМдвойной подсчётсредняя

В классе не более 37 учеников. Каждый знаком ровно с тремя мальчиками и семью девочками из этого же класса (знакомство взаимно). Сколько учеников может быть в классе?

Его любимый тип — граф через двойной подсчёт, на ступень выше «мальчиков и девочек».

ключ
20 или 30. Пары «человек — знакомый мальчик» двумя способами: 3n = сумма степеней мальчиков = 10m; аналогично 10d = 7n, значит n кратно 10. Так как мальчик знаком с тремя другими мальчиками (m ≥ 4) и учеников ≤ 37: n = 20 (6 и 14) или 30 (9 и 21).
2ЦПМперебор конфигурацийсредняя

В компании из шести человек каждый знаком ровно с тремя другими. Сколько существует по существу различных таких компаний? (Две одинаковы, если знакомства одной получаются из другой переименованием людей.)

Его жанр в графах: конкретное число вершин, маленький честный разбор — вместо общей теоремы.

ключ
Ровно две. Возьмите A и его знакомых B, C, D; с A не знакомы ещё двое — E и F. Если внутри {B,C,D} знакомств нет — выходит K3,3 (части {B,C,D} и {A,E,F}); если есть хотя бы одно — «треугольная призма». Других вариантов условие «ровно три» не оставляет.

Перебор и оценка — его фронт

3ЦПМконструкция + оценкасредняя

Какое наибольшее количество натуральных чисел, не превосходящих 1000, можно выбрать так, чтобы ни для каких двух их сумма не делилась на их разность?

Короткий ход: запрет на разности 1 и 2 сразу даёт оценку — без лобового перебора.

ключ
334. Разность 1 делит любую сумму; при разности 2 числа одной чётности, сумма чётна. Значит любые два отличаются ≥ 3, поэтому их ≤ 334. Пример: 1, 4, 7, …, 1000 (≡ 1 mod 3): разность кратна 3, сумма ≡ 2 — не делится.
4ЦПМпринцип крайнегосредняя

В клетках доски 8×8 расставлены различные натуральные числа. Докажите, что найдутся две соседние по стороне клетки, числа в которых отличаются не меньше чем на 5.

ключ
Кратчайший путь по соседним клеткам от числа 1 до числа 64 не длиннее 14 шагов. Вдоль него рост 63; будь каждый шаг ≤ 4, вышло бы ≤ 56 < 63 — значит где-то скачок ≥ 5.

Теория чисел

5ЦПМразложение p⁴−1трудная

Найдите все тройки простых чисел p, q, r, для которых четвёртая степень каждого, уменьшенная на единицу, делится на произведение двух остальных.

ключ
Только (2, 3, 5): 2⁴−1 = 15 = 3·5; 3⁴−1 = 80 ⋮ 2·5; 5⁴−1 = 624 ⋮ 2·3. Ни одно из простых не делит свою четвёртую степень минус 1, поэтому они различны; перебор по малым (с учётом разложения) других не даёт.
6наш банк · мамин наборсумма цифрсредняя-трудная

Сумма цифр числа N равна 2222, а сумма цифр числа N + 1 равна 990. Чему может быть равна сумма цифр числа N + 1000?

Чистое «подумать про переносы», без вычислений — то, что ему полезно вместо тяжёлого инструмента.

ключ
1017. Из S(N+1) = S(N) − 9k + 1 (k девяток на конце): 990 = 2222 − 9k + 1, значит k = 137. Прибавление 1000 превращает 134 девятки (позиции 4–137) в нули и добавляет 1 к 138-й цифре: 2222 − 9·134 + 1 = 1017.
7наш банк · мамин наборостатки · взаимная простотасредняя-трудная

Решите в натуральных числах уравнение x4 + x2 = 7y · z2.

Из твоего любимого маминого набора, мы её не давали: красивый короткий довод через остаток по модулю 7.

ключ
Решений нет. Запишем x²(x² + 1) = 7yz². Соседние числа x² и x² + 1 взаимно просты. Квадрат по модулю 7 даёт остатки 0, 1, 2, 4, поэтому x² + 1 на 7 не делится — значит вся степень семёрки сидит в x². Тогда x² + 1 (взаимно простое и с 7, и с x²) обязано само быть точным квадратом; но между x² и (x+1)² квадратов нет, а x² + 1 = квадрат даёт лишь x = 0. В натуральных решений нет.

Инвариант

8ЦПМбаланс / инварианттрудная

В вершинах n-угольника (n > 2) лежат фишки. За ход выбирают вершину, где не меньше двух фишек, убирают две и кладут по одной в соседние. Докажите: если фишки вернулись к исходному расположению, то число ходов делится на n.

ключ
Пусть fv — число ходов в вершине v. Возврат фишек даёт −2fv + fv−1 + fv+1 = 0, поэтому разности fv+1 − fv одинаковы по кругу; их сумма по циклу равна нулю, значит все fv равны, и ходов n·f.
