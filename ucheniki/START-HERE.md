# START-HERE — индивидуальные занятия (вход для Cowork)

> Свежая сессия: прочитай ЭТО → `METOD.md` → журнал нужного ученика. Один диалог — один ученик.

## Что это

Не курс, а **практика**. Еженедельные индивидуальные занятия со взрослыми и сильными школьниками: разбор ДЗ + одна тема вглубь. Здесь готовим материалы к ним и ведём журнал.

Принцип: **метод общий, журнал у каждого свой.** Новый ученик — новая папка при том же `METOD.md`.

## Профиль — ЛЁГКИЙ, вне канона генератора

Решение владельца 20.07.2026 при переезде из облака. HTML для ученика (ДЗ со спойлерами, интерактивная проверка ответа) собираем **вручную**, а не через `../_generator/`. Это осознанное исключение из правила репо «HTML — только генератором»: формат ДЗ движок не умеет, а переделывать формат ради единообразия дороже, чем оставить как есть.

Пересмотреть можно, но только явно: сперва проверить `../_generator/build_doc.py` по живым файлам, потом решать.

## Цикл

Один виток на занятие, повторяется еженедельно:

1. **После занятия** — владелец наговаривает, как прошло. В журнал идёт **дистиллят**: что трудно / в самый раз / легко, что сдвинулось, смены направления. Процесс раскопок в журнал не идёт.
2. **Сборка ДЗ** — фильтр над пулом задач, не поиск с нуля. Сперва согласовать набор, потом собирать файл.
3. **План следующего занятия** — центральная задача + опоры, пополнение пула.
4. **Заход за задачами** — отдельно, когда пул по теме истощился.

Метод, стиль материалов, дисциплина контекста — `METOD.md`. Он же системный промпт проекта.

## Раскладка

```
ucheniki/
├── START-HERE.md   ← ты здесь
├── METOD.md        метод: одинаков для всех учеников, правится редко
├── literatura/     сборники задач, общие на всех
└── maksim/         ученик: журнал + его материалы
```

## Как завести нового ученика

Папка латиницей по имени, внутри — `START-HERE.md` (где мы сейчас), `ZHURNAL.md` (источник правды) и те подпапки, которые реально понадобятся. Не копировать структуру Максима целиком заранее: `kartochki-miro/` нужны только тому, с кем работаем на доске.

`METOD.md` не трогать — всё, что относится к конкретному ученику, живёт в его журнале.

## Что НЕ делать

- **Не переписывать журнал целиком** — правки хирургические, по секциям. HTML-выжимка пересобирается из markdown, они не расходятся.
- **Не собирать артефакт вокруг несогласованных задач.** Предложить набор дёшево, переделать готовый файл дорого.
- **Не указывать источники** в материалах ученика — ни книги, ни школы, ни номера листков.
- **Не отдавать непроверенный ответ.** Ученик не должен получить неверный ключ.
- **Не нарративить ресёрч** — ни в ответах, ни в журнале.
