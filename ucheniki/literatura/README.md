## Шень, «Математическая индукция» — `shen-matematicheskaya-indukciya.pdf`

МЦНМО, 5-е изд. 2016, 32 страницы. Метод разобран на **46 задачах, из 19 есть подробные решения**. Свободно распространяется: <http://www.mccme.ru/free-books/induction/induction.zip>.

Заведено 06.08.2026 под Даню: полную индукцию он не понимает, а на ней держится ключевой шаг в деревьях (выкинуть мост → граф распался на два меньших → применить предположение к каждому).

**Второй, более удобный вход в ту же тему — база спецмата** (`spetsmat/spetsmat_db/db.sqlite3`, картографированные листки): по индукции там **семь листков**, самые полные — Шень (id 303, 19 задач) и спецклассы 57-й школы (id 243, 14 задач). Оттуда взяты раскраска плоскости прямыми, уголки в квадрате 2ᵏ и многоугольник с диагоналями. Запрос по теме:

```sql
select s.id, s.title from mapcat_sheet s
left join mapcat_topic t on t.id = s.primary_topic_id
where s.title like '%ндукц%' or t.title like '%ндукц%';
```
