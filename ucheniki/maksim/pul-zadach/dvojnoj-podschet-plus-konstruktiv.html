Двойной подсчёт + конструктив · целевая жила

Счёт даёт условие — конструкция реализует

Тип, который мы ищем: подсчёт двумя способами даёт необходимое условие или оценку (чётность, делимость, граница), а затем строится сам объект, показывающий, что условие и достаточно. Архетип — граф степени 3: счёт → n чётно, конструкция → для чётных строим.

  1. В турнире n игроков каждый сыграл с каждым по разу, ничьих не было. При каких n все игроки могут набрать поровну побед?
    .
    Всего побед столько же, сколько партий: n(n−1)/2. Если поровну, каждому достаётся (n−1)/2 — целое только при нечётном n (счёт даёт условие). Для нечётного n строим: посадим игроков по кругу и пусть каждый побеждает (n−1)/2 ближайших по часовой стрелке — тогда у всех ровно по (n−1)/2 побед. Ответ: n нечётно.
  2. n команд (n чётно) проводят круговой турнир: каждая играет с каждой ровно раз. Игры идут турами, и в одном туре каждая команда играет не больше одной игры. За какое наименьшее число туров можно провести весь турнир?
    .
    Всего игр n(n−1)/2, а в одном туре их не больше n/2 (каждая команда занята максимум в одной). Значит туров не меньше n−1 (счёт даёт оценку). Ровно n−1 тур строится «каруселью»: одна команда стоит на месте, остальные сдвигаются по кругу; каждый тур — это n/2 игр без пересечений. Ответ: n−1.
  3. При каких n существует граф на n вершинах, в котором каждая вершина имеет ровно k рёбер (обобщение случая k = 3)?
    .
    Сумма степеней равна nk и равна удвоенному числу рёбер, поэтому nk чётно (счёт даёт условие). При нечётном k это значит, что n чётно. Для всех подходящих n (и n ≥ k + 1) граф строится явно: вершины по кругу, каждую соединяем с k ближайшими (для нечётного k — ещё с противоположной). Счёт отсекает невозможное, конструкция закрывает остальное.
