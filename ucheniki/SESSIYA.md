Бабичева и Богомолов собраны pdfTeX с cp1251-раскладкой; `pdftotext` отдаёт символы, файл выглядит машиночитаемым, но любой `grep` по нему молча врёт. Лечится перекодировкой latin-1 → cp1251 — проверено, кириллица поднимается с 0% до ~98%. Вшито в инструмент: `--tekst` чинит, если починка увеличивает долю кириллицы, и возвращает исходник, если нет.

**Сканы: OCR в песочнице недоступен.** `tesseract` установлен, но с языками eng+osd; русского пакета нет, `apt-get` без прав. Вывод для планирования: скан не мёртв, но дорог — адресно (одно занятие) дёшево, целиком 370 страниц нет.

**Главный практический результат — сборники Знаменской разбираются на структуру.** `--znamenskaya` отдаёт JSON {номер: {задача, подсказка, ответ}} по всем пяти классам. То есть отбор задач идёт по тексту, а не листанием PDF, и ключ к каждой задаче уже готов — самое дорогое место сборки набора (`METOD.md`: «ответ прогонять программой, а не памятью») по этому источнику отпадает.

**Грабли парсера, записаны в самом файле.** Наивное деление «по сбросу нумерации» ломается: внутри условий и решений тоже встречаются строки, начинающиеся с числа. Допуск в два номера собирает оба целиком и не ломает 2, 3, 5 класс. Проверено прогоном по всем пяти, цифры в докстринге.

**Ограничение источника, важное для отбора.** У части задач условие опирается на рисунок, которого в тексте нет, а у части пуст ответ — он был картинкой. Значит текстовый отбор не самодостаточен: такие задачи либо идут с распечаткой страницы, либо не идут. Побочно это же и ресурс: задача с картинкой приносит ученику готовый носитель для работы — ровно то, чего не хватает по разделу «запись не держит рассуждение».
