# Индивидуальные занятия по математике — материалы ученикам и память о каждом

<!-- gen:podrobno — пишет генератор описаний; правки сюда пропадут, править ответы анкеты -->

Папка индивидуальных занятий: не курс, а практика с еженедельным витком на каждого ученика. У неё два адресата, и они нарочно разведены. Ученику уходят материалы: домашние задания, подборки, карточки в HTML. Память о занятиях (`PROFIL.md` — кто ученик и как с ним работать, `ZHURNAL.md` — что было и что дальше) написана в markdown для сессий Claude. По этой схеме параллельно ведутся несколько учеников.

В корне методика: `METOD.md` (метод и стиль материалов, общие для всех), `CIKL.md` (цикл занятия в четыре фазы: собрать набор, наблюдать, разобрать, разнести по памяти), `PRIYOM.md` (как принять ученика из облачного чата), `PROBNOE.md` (пробное занятие с незнакомым ребёнком), дневник, хэндоффы и выгрузки. Дальше по папке на ученика: вход `START-HERE`, профиль, журнал, домашние задания, занятия, пул задач, карточки. `_TEMPLATE-uchenik/` — скелет новой папки, `literatura/` — описание общих сборников задач (сами PDF в git не лежат).

Работа идёт в Cowork: перед занятием собирается набор задач из существующих источников, задачи не придумываются; после занятия — разбор и запись в память. HTML-материалы делаются вне канона генератора (решение 20.07.2026). С 30.07 готовится переход на прототип своего движка листков `disciplina/_generator/build_listok.py` над банком `_fond/zadachi/bank/`; прототип ждёт согласования.

Папка заведена 20.07.2026 переносом из облака. Ученики появлялись тремя путями: приёмом из облачного чата, с пробного занятия и по интервью о давнем ученике. Цикл из четырёх фаз и третий способ приёма записаны 13.09.2026. Последние материалы — 20.09.2026.

Сюда идти перед занятием с конкретным учеником (вход — его `START-HERE.md`, затем хвост `ZHURNAL.md`) или чтобы завести нового по `_TEMPLATE-uchenik/` и `PRIYOM.md`. В папке персональные данные учеников. Связи: банк задач `_fond/` и прототип движка листков в `disciplina`; по содержанию близко к листкам `../diskmat-57/`, но это разные работы.
