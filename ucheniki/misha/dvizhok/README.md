# Движок занятий Миши

> Один самодостаточный HTML из файла содержания. Запускается локально двойным щелчком, без сервера. Процесс сборки и правила — `../RECEPT-zanyatie.md`; дизайн — `DIZAJN.md` (кандидат в канон, ждёт подтверждения владельца).

## Формат содержания
```python
LESSON = {'id': 'dz-2026-09-27', 'title': '…', 'badge': 'к 4 октября',
  'sections': [{'title': 'Разбей удобно', 'items': [ …пункты… ]}, …]}
```
Раздел = экран с листалкой пунктов (точки внизу). Пункт — словарь с `type`; `q` — условие (пустое — не показывается), `sub` — вторая строка.

| type | поля | как проверяется |
|---|---|---|
| `cover` | `title`, `text`, `button`; `final: True` — итог со звёздами | — |
| `slots` | `lines`: строки с полями; `draft: N` — черновик справа; `rule` — своё правило | каждое поле по ответу; или `rule` над числами полей `v[0..]` |
| `choice` | `options` (текст или svg), `ok` — индексы, `multi` | набор выбранных = `ok` |
| `euler` | `svg` (из `euler()`), `lines` | как `slots` |
| `fix` | `steps`: `[n]` — правимое число, `{выражение от v0,v1…}` — вычисляемое; `answer`, `ok` | каждая часть после «=» равна `answer` И `ok` (есть `split(v,A,B)`) |
| `grid` | `kind`: `sudoku` / `futoshiki` / `takuzu`; `rows` (`.` — пусто), `ineq` | по правилам головоломки — любое верное решение; пункт необязателен |
| `error` | старый тип (выбор строки) — не использовать | |

Синтаксис полей в строке: `{5}` — ответ, `{5|6}` — варианты, `{#4;9}` — множество (любой порядок и разделители), `{?∈/⊂=∈}` — выбор знака, `{_}` — свободное поле без проверки.

## Поведение (слой 1)
Звезда только с первой проверки; после ✗ поля остаются правимыми; «→» закрыта до первой проверки (кроме головоломок); ⏭ — переход куда угодно; ↺ — сбросить пункт; Enter — проверить / дальше. Всё состояние и журнал — в localStorage ключом `misha:<id>`; общий счёт звёзд — `misha:stars`. Журнал: Ctrl+Shift+J или долгое нажатие на звёзды → таблица (открыл, решил, время, попыток, итог, простой > 1,5 мин), «скопировать», «скачать JSON».

## Известные ограничения
Печать из этого же содержания не собирается (печать — `zanyatiya/gen/listok.py`); банк задач не подключён; журнал живёт в браузере ребёнка; звёзды не тратятся.
