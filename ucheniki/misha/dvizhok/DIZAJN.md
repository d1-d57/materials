# Дизайн движка занятий Миши — канон (кандидат, 27.09.2026)

> Один дизайн на все занятия и ДЗ. Меняется только здесь и в engine.css; содержание его не трогает.

- **Сцена 1440×810**, масштабируется под окно целиком (без прокрутки и приближения). Сверху — раздел, прогресс, срок (плашка), звёзды, ⏭. Снизу — ← · точки пунктов · ↺ сбросить · ✓ Проверить · →.
- **Рабочая зона подгоняется автоматически:** содержимое пункта масштабируется, чтобы занять место (до ×1.6). Задача с черновиком — две колонки: задача слева, черновик справа.
- **Текст — минимум.** На экране только то, без чего не понять, что делать: условие или короткая метка («25 = 20 + 5», «Где ошибка?»). Инструкций к интерфейсу, объяснений про звёзды, подсказок-пояснений нет. Если пример сам по себе задача — он и есть заголовок, без подписи.
- **Цвета:** бумага #fbfcfe, чернила #18202e, акцент #2f5fd0 (поля ввода, выбор), верно #1d8049, неверно #c03636, исправлено #b7791f, звезда #e8a317.
- **Шрифты:** Golos Text (текст, числа), Rubik (заголовки, цифры в головоломках).
- **Проверка перед выдачей:** сборка → снимок каждого экрана при 1440×810 → просмотр свежим взглядом → правка → повторный снимок.
