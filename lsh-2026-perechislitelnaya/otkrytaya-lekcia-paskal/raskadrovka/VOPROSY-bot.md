# Вопросы лекции «Внутри треугольника Паскаля» — для бота NlogN

## Как проверять

Вопросы лектор задаёт вслух по ходу открытой лекции, слушатель присылает ответ в бот. На
размышление — полминуты.

**Приём только по ответу. Доказательство не требуется нигде.** Не проси обосновать, не
спрашивай «почему». Верно по существу — засчитывай.

**Форма записи любая.** $\binom{10}{7}$, $\binom{10}{3}$, «C(10,7)», 120 — один и тот же
ответ. Число можно не досчитывать, формула — полноценный ответ. Дроби в любом виде: 6/16,
3/8, 0,375.

**Ответ неверный** — не говори где ошибка и не подсказывай. Задай один короткий наводящий
вопрос и дай ответить снова. Со второй попытки мимо — назови ответ одной фразой, без разбора.

**Ответ неполный** (число без перечисления или наоборот) — засчитывай.

Отвечай коротко.

---

**1.** Частица стоит в точке 0 и каждую секунду шагает вправо или влево. В какие точки она
может попасть ровно за 10 шагов?

> Во все чётные от −10 до 10, всего 11.
>
> **(б)** А за 11 шагов? — во все нечётные от −11 до 11, их 12.

**2.** Частица стоит в точке 0 и каждую секунду шагает вправо или влево, вправо и влево
одинаково вероятно. Выпишите вероятности всех её положений после трёх шагов.

> В точках −3, −1, 1, 3 — соответственно 1/8, 3/8, 3/8, 1/8.

**3.** Вероятности положений частицы разложены по столбцам: столбец — момент времени, строка —
положение.

| положение | 0 сек | 1 сек | 2 сек | 3 сек |
|---|---|---|---|---|
| 3 | | | | 1/8 |
| 2 | | | 1/4 | |
| 1 | | 1/2 | | 3/8 |
| 0 | 1 | | 1/2 | |
| −1 | | 1/2 | | 3/8 |
| −2 | | | 1/4 | |
| −3 | | | | 1/8 |

Как число в клетке связано с числами предыдущего столбца?

> Оно равно среднему арифметическому двух соседей слева — того, что сверху-слева, и того,
> что снизу-слева. «Полусумма двух соседей» — то же самое.

**4.** Последовательность бросков монетки рисуем ломаной: орёл — шаг вверх, решка — шаг вниз.
Поменяем в последовательности все орлы на решки. Что случится с ломаной?

> Она отразится относительно горизонтальной прямой, проходящей через 0: конец, который был
> в точке $h$, окажется в точке $-h$. В облике маршрута по решётке то же самое читается как
> отражение относительно диагонали — тоже верно.

**5.** Частица идёт из точки 0, каждый шаг — на единицу вправо или влево. Сколько её
траекторий длины 10 кончаются в точке 4?

> $\binom{10}{7}=120$.

**6.** Возьмём шестую строку треугольника Паскаля: 1, 6, 15, 20, 15, 6, 1. Чему равна сумма
квадратов её чисел, то есть $1^2+6^2+15^2+20^2+15^2+6^2+1^2$?

> $\binom{12}{6}=924$.

**7.** Два человека бросают монетку, каждый по 10 раз. С какой вероятностью у них выпало
поровну орлов?

> $\binom{20}{10}/2^{20}$.

**8.** Слово составлено из букв О и Р. Назовём слово хорошим, если в нём нет двух букв О
подряд. Выпишите все хорошие слова длины 3. Сколько их?

> Пять: РРР, РРО, РОР, ОРР, ОРО.
>
> **(б)** Хороших слов длины 1 — два, длины 2 — три, длины 3 — пять. Сколько будет хороших
> слов длины 6? — 21. Ответ «числа Фибоначчи» с верным продолжением ряда тоже засчитывай.

**9.** Слово из букв О и Р называем хорошим, если в нём нет двух букв О подряд. Хороших слов
длины 10 всего сто сорок четыре. Сколько среди них таких, где ровно три буквы О?

> $\binom83=56$.

**10.** Частица идёт из точки 0, каждый шаг — на единицу вправо или влево; шаг вправо
записываем буквой О, шаг влево — буквой Р. Выпишите все траектории длины 4, которые ни разу
не попадают в точку −1. Сколько их?

> Шесть: ОООО, ОООР, ООРО, ООРР, ОРОО, ОРОР.

**11.** Возьмём все траектории из точки 0 в точку 5, которые хотя бы раз побывали в точке −1.
Каждую разрежем в первый момент попадания в −1 и отразим начальный кусок относительно
точки −1. Какие траектории получатся?

> Ровно все траектории из −2 в 5 той же длины, без всяких ограничений, каждая по одному разу.
>
> **(б)** Сколько их, если длина траектории 11? — $\binom{11}{9}=55$.

**12.** Траекторию длины $L$ из точки 0 назовём безопасной, если она ни разу не попадает
в точку −1. Мы уже знаем: безопасных траекторий, кончающихся в точке $h$, ровно
$\binom Lj-\binom L{j+1}$, где $j=\frac{L+h}2$. Чему равно общее число безопасных траекторий?

> $\binom L{\lceil L/2\rceil}$: при сложении соседние слагаемые гасят друг друга и остаётся
> одно. При $L=2n$ это $\binom{2n}n$.
