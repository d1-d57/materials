# КАРТА ОБЛАСТИ — «otkrytaya-lekcia-paskal»

Индекс всех узлов: по роду и по нитям. Адресация по `id`. Тела узлов — `obiekty.md`.

## Узлы по роду

**Биекции**

| id | суть |
|---|---|
| `bij-razrez-posledniy-minimum` | разрез моста в последнем минимуме, первый кусок задом наперёд → неотрицательные пути. **Конструкция владельца** |
| `bij-otrazhenie-v-rekordah` | `T = 2M − S`, отражение в линии рекордов → строго положительные пути |
| `bij-razryv` | двое ходят по очереди, следим за разрывом → пары с общим концом ↔ мосты |

**Мостики**

| id | суть |
|---|---|
| `most-vandermond-para` | `ΣC(n,k)² = C(2n,n)` = «две прогулки встретились» — вход в финал без нового языка |

## Нити

**Нить «от Вандермонда к ответу»** (целевая арка лекции):
`most-vandermond-para` → `bij-razryv` → `bij-otrazhenie-v-rekordah` **или**
`bij-razrez-posledniy-minimum` → ответ `C(2n,n)`.

Открытый узел нити: **прямая биекция `most-vandermond-para` → неотрицательный путь**, минуя
промежуточный мост. Если найдётся — нить схлопывается в один ход и лекция идёт прямой линией.
Заход на поиск — `zahod-bijekciya-para-katalan.md`.
