# START-HERE — мини-курс «Информация и коды с исправлением ошибок» (вход для Cowork)

> Свежая сессия Cowork: прочитай ЭТО + `../_studio/COWORK.md` + `../_studio/docs/KARTA.md`, войди в активную арку — веди владельца по стадиям (`ARKA §10`). Стандарт под этот тип курса — профиль «мини-курс вокруг одной идеи».

## Что это
Мини-курс на **4 занятия** про **информацию и коды с исправлением ошибок** (школьники, кружково-олимпиадный уровень; профиль ЛЁГКИЙ-научпоп / «мини-курс вокруг одной идеи»). Формат как у курса «Характеристика Эйлера»: одна сквозная идея, наращивается по лекциям; мало теории, много наглядности, игры с залом, небольшие листки. По сути — несколько листков + лекционный рассказ. Владелец тему знает, читал подобную лекцию. Это **негеометрический курс на ПЕРВЫЙ 5-дневный блок лагеря** (геометрия Эйлера — второй блок, после перерыва).

## Сквозная идея — ИНФОРМАЦИЯ
Сколько информации несёт один вопрос «да/нет»; как её измерять (биты, двоичная запись); как **избыточность защищает информацию от ошибок** (коды с исправлением ошибок). Одна нить связывает угадывание числа, ложь в ответах, колпаки, взвешивания.

## Занятия (условно, 4)
1. **Разнобой (ЗАВТРА, первое занятие).** Медли из маленьких ярких сюжетов про информацию / коды / шифры — лёгкий вход, разнообразие, игротека. Задать тон.
2–4. **Систематическая теория (разложить по глубине):**
   - **Угадай число за вопросы** — минимум вопросов «да/нет» (двоичный поиск, ~log₂); собираем двоичную запись «по дороге». Игра с залом.
   - **С ложью** — можно соврать ровно один раз / не более одного раза (задача Реньи–Улама) → тут естественно рождаются **коды с исправлением ошибок (Хэмминга)**. Ядро/кульминация курса.
   - **Колпаки** — угадать свой цвет; сюжет про информацию и договорённость-код.
   - **Взвешивания + разрешающие деревья** — нижние оценки («быстрее нельзя») той же техникой, что в угадывании числа.
   Порядок 2–4 и где кульминация — на ресёрч + владельца.
