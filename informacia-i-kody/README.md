# Информация и коды — кружковый мини-курс для 6 класса на четыре листка

<!-- gen:podrobno — пишет генератор описаний; правки сюда пропадут, править ответы анкеты -->

Мини-курс «Информация и коды» на четыре занятия для сильного 6 класса в кружковом формате: листок с большой подборкой задач, час с лишним самостоятельного решения, устная сдача преподавателям. Это первый пятидневный блок летнего лагеря, второй блок для той же группы — «Кривая дракона». Сквозная идея — передать информацию: сколько её (да/нет, двоичная запись), как защитить от ошибок (избыточность, коды Хэмминга) и где предел. Шифры здесь только вход, а не весь курс.

`kartoteka/` — листки по занятиям: «Шифры и числовые ребусы», «Сколько информации» (магические карточки, угадай число вопросами «да/нет», двоичная запись), «Кодирование» (чётность, обнаружение ошибок, Хэмминг), «Ошибки и ложь». У каждого есть HTML для преподавателя с решениями и чёрно-белая версия A4 для детей. Там же карта курса, добор задач к первому листку, пул на отбор к четвёртому и станция командной игры на последний день смены: пять задач и пять в резерве, ответы проверены перебором. `istochniki/` — реестр и выжимки: материалы Клепцына, ФКН, раздел «Криптография» на problems.ru.

Листки подбирались процессом фабрики «ресёрч задач», по арке на занятие. Правило отбора: во вводный листок идут только задачи, которые дальше не всплывут, а задачи-мостики (двоичная запись, чётность, оценки) берегутся для следующих занятий. Преподаватель берёт HTML с решениями, детям печатают `L*-print.html`.

Курс заведён 11.07.2026 как негеометрический блок вместо наглядной геометрии. Первый листок готов 12.07, остальные — к 20.07. 21.07 добавлены архив задач ЛМШ-57 и станция игры. Формат листков стал образцом для «Кривой дракона». Вводный `START-HERE` отстал от дел: там четвёртый листок ещё «не определён», хотя он собран.

Сюда идти за готовым кружковым блоком для 6–7 класса об информации, двоичных кодах и исправлении ошибок, за листками «с решениями и для печати» или за станцией командной игры. Связи: `krivaya-drakona/`, `nagliadnaya-geometriya/` (курс, который этот заменил), `_fond/zadachi/arhiv-lmsh57-2025/`.
