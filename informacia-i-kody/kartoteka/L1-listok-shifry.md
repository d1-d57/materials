# Занятие 1 · Шифры и числовые ребусы — состав листка

*Полные условия + решения в красивом виде — `L1-listok-shifry.html`. Здесь — индекс состава (уклон в математику: расшифровка через перебор/логику, а не через язык). Полный пул задач — `../istochniki/VYCHITANO.md`.*

## Простые
1. **Города-числа** — problems.ru #88151 (Козлова). Цифрами 21221–211221 записаны 2 города. → **Уфа — Баку** (буквы с номерами 1,2,11,12,21,22). *★ разбор у доски.*
2. **Тарабарская грамота** — #88134 (Козлова). Задача-шутка: шифр и обычная фраза почти совпадают (две строки друг под другом). → попарная замена согласных, гласные на месте.
3. **Ребус КИС+КСИ=ИСК** — #88261 (Козлова). → **495+459=954** (К<И → И=9, К=4, С=5).
4. **Ребус А+ВВ+А=ССС** — #88232 (Козлова). → **6+99+6=111**.

## Средние
5. **Шифр Робота** ◆ — #65600 (Матпраздник-2016, Хачатурян). РОБОТ=3112131233, КРОКОДИЛ=БЕГЕМОТ; зашифровать МАТЕМАТИКА. → **2232331122323323132** (коды переменной длины из 1,2,3).
6. **Цифры за 5 вопросов** ◆ — #66987 (Матпраздник-2022, Заславский). 0-9↔A-J, узнать за 5 вопросов о суммах. → сумма всех =45 → по 2 цифры за вопрос.
7. **Виженер (ключ А,Б,В)** — #35683. Прочесть РБЬНПТСИТСРРЕЗОХ. → **НАШ КОРРЕСПОНДЕНТ** (3 варианта на букву). *★ разбор у доски.*
8. **Шифр Цезаря** (авторский). Сдвиг, алфавит 32 буквы, ПХНФЧУИХЕЩНД. → **КРИПТОГРАФИЯ** (сдвиг 5).
9. **Какой обрывок помогает** — #35764. «термометр» vs «ремонт». → **«ремонт»** (важен набор разных букв).
10. **Ребус с дробями** — Матпраздник-2023 №2 (Акопян). Ф/Е + ВР/АЛЬ = 1, найти любое. → напр. **2/4 + 79/158 = 1**.
